Fix the proof predicate before making claims about it

Let \(T\supseteq Q\) be a theory in the arithmetic language with computably enumerable axiom codes. Retain a specific primitive-recursive axiom-certificate relation \(E(a,s)\) presenting exactly \(T\), the corresponding certified proof checker \(P_T(p,a)\), and a chosen numeralwise representative \(\operatorname{Proof}_T(p,x)\) in \(Q\). Set

\[\operatorname{Prov}_T(x):=\exists p\,\operatorname{Proof}_T(p,x).\]

For an arithmetic sentence \(A\), abbreviate its provability sentence by

\[\Box_T A:=\operatorname{Prov}_T(\overline{\ulcorner A\urcorner}).\]

The box is notation in our exposition, not a new symbol in the arithmetic language. In particular, \(\Box_T\Box_T A\) means to form the arithmetic sentence \(\Box_T A\), compute that sentence's code, and substitute its numeral into the same provability formula. Both the proof coding and the chosen representing formula matter.

What the predicate means in the standard natural numbers

For every arithmetic sentence \(A\),

\[\mathbb N_A\models\Box_T A\quad\Longleftrightarrow\quad T\vdash A.\]

Proof

In \(\mathbb N_A\), numeralwise positive and negative representation makes \(\operatorname{Proof}_T(m,a)\) equivalent to the checker's acceptance at every pair of natural numbers. Existential quantification over \(m\) therefore means that an actual certified proof exists. The certificate/derivation equivalence identifies that existence with \(T\vdash A\). □

This is a metatheoretic equivalence. It does not say \(T\vdash\Box_T A\leftrightarrow A\), and it does not assert that \(T\)'s theorems are all true.

An actual proof gives a proof of provability

For every sentence \(A\), the chosen predicate satisfies the first derivability condition:

\[(\mathrm{D1})\qquad T\vdash A\quad\Longrightarrow\quad T\vdash\Box_T A.\]

More precisely, \(T\vdash A\) already implies \(Q\vdash\Box_T A\).

Proof

Take an actual accepted certified proof with code \(m\). The particular numerical fact \(P_T(m,\ulcorner A\urcorner)\) has a proof in \(Q\) through the chosen representing formula:

\[Q\vdash\operatorname{Proof}_T(\overline m,\overline{\ulcorner A\urcorner}).\]

Existential introduction gives \(Q\vdash\Box_T A\). Since \(Q\subseteq T\), weakening gives \(T\vdash\Box_T A\). Neither step requires \(T\) to be consistent or sound. □

D1 is a rule about the existence of finite derivations. The expression \(T\vdash A\) is outside the arithmetic formula, so D1 is not itself one universally quantified sentence of arithmetic.

Combine certified proofs by a primitive-recursive operation

Suppose \(p\) certifies a proof of \(A\to B\), and \(q\) certifies a proof of \(A\). There is a primitive-recursive numerical operation \(M(p,q,b)\), with \(b=\ulcorner B\urcorner\), which constructs a certified proof of \(B\):

\[P_T(p,\ulcorner A\to B\urcorner)\land P_T(q,\ulcorner A\urcorner)\ \Longrightarrow\ P_T(M(p,q,\ulcorner B\urcorner),\ulcorner B\urcorner).\]

Proof

A certified record contains its derivation, root context, and one axiom certificate for every context entry. Concatenate the two root contexts and their certificate lists. Attach an implication-elimination root to the unchanged child derivations, using this combined context. Each child's former root context is included in it, so the checker's context conditions hold. The combined list still certifies every axiom assumption, and the new conclusion is \(B\). No eigenparameter is introduced by implication elimination.

Extracting components, concatenating finite lists, and making the fixed new root are primitive recursive. This constructs \(M\) on all numerical inputs; the displayed correctness implication is required on accepted input certificates. Malformed inputs do not need to produce an accepted proof. □

This strengthens the existing operation on derivation records by carrying along the actual certificates for axioms in the combined context.

Every concrete successful combination can be verified in Q

For fixed ordinary natural numbers \(p,q\) that certify the displayed premises, let \(m=M(p,q,\ulcorner B\urcorner)\). Then

\[Q\vdash\operatorname{Proof}_T(\overline m,\overline{\ulcorner B\urcorner}).\]

Proof

The preceding construction proves the external fact \(P_T(m,\ulcorner B\urcorner)\). Positive numeralwise representation supplies exactly its displayed \(Q\)-proof. An unsuccessful proposed output certificate instead has its negated numerical instance provable in \(Q\), by negative representation. □

Here each calculation has fixed numerical inputs. This statement does not quantify over proof codes inside \(Q\), and it does not say that one \(Q\)-proof certifies all successful combinations simultaneously. This is the same distinction as numeralwise versus uniform totality.

A terminating procedure can turn an accepted proof into a proof of provability

For the fixed axiom-certificate relation \(E\), there is a total recursive function \(I(p,n)\) such that

\[P_T(p,n)\ \Longrightarrow\ P_T\bigl(I(p,n),\ulcorner\operatorname{Prov}_T(\overline n)\urcorner\bigr).\]

Its inputs are arbitrary natural numbers. The code of the sentence \(\operatorname{Prov}_T(\overline n)\) is itself primitive recursive in \(n\).

Proof

First run the primitive-recursive check \(P_T(p,n)\). If it fails, return a fixed number immediately; no correctness assertion is required on this branch. If it succeeds, D1's numerical-witness argument supplies a \(Q\)-proof of \(\operatorname{Prov}_T(\overline n)\), hence a \(T\)-proof. Search through all certified \(T\)-proofs until one proves this sentence. The certificate/derivation equivalence guarantees success on the accepted branch. The target sentence code is computed by the existing numeral-substitution operation. Thus the test and subsequent search define a total recursive function with the claimed property. □

This proof gives termination, without a primitive-recursive bound on the proof search. It is an external procedure on ordinary proof codes; it does not yet give an arithmetic proof that the procedure works at every internal input.

The internal implication needed to reason with arbitrary proofs

The second derivability condition for a fixed predicate is the following requirement, for every pair of arithmetic sentences \(A,B\):

\[(\mathrm{D2})\qquad T\vdash\Box_T(A\to B)\to(\Box_T A\to\Box_T B).\]

Each displayed instance is a single arithmetic sentence with quantifiers over possible proof codes inside the box abbreviations. The direct proof-combination argument establishes it by verifying the operation on arbitrary internal proof codes. Correctness of \(M\) on ordinary natural numbers, together with a separate \(Q\)-proof for each concrete accepted output, does not by itself supply that verification. If \(T\) is inconsistent, it proves the displayed sentence simply by explosion.

Numeralwise representation alone does not establish D2 for this arbitrary representing formula. For a separately constructed PA predicate, the formula follows the actual checker's construction, and internal preservation of implication elimination proves D2. That argument verifies the particular programs and formulas at arbitrary internal inputs; agreement on ordinary numerical inputs alone is insufficient.

The internal assertion that provability is itself provable

The third derivability condition is the requirement, for every sentence \(A\),

\[(\mathrm{D3})\qquad T\vdash\Box_T A\to\Box_T\Box_T A.\]

D1 can start with a particular external proof of \(A\), verify that certificate, and build a proof of \(\Box_T A\). D3 asks arithmetic to prove an implication from the assertion that a proof exists, including witnesses that might be nonstandard in a model of \(T\). Applying D1 to each externally known proof does not discharge that quantifier.

As with D2, the condition is a schema of arithmetic derivability statements for the specified predicate. The arbitrary numeralwise representative fixed here has no assumed internal proof-construction properties or particular arithmetic complexity. The separately constructed PA predicate satisfies D3 by formalized completeness. This does not transfer D3 to the present representative without a proved internal comparison.

The second and third conditions are true in the standard model

For the chosen predicate and every pair of sentences \(A,B\),

\[\mathbb N_A\models\Box_T(A\to B)\to(\Box_T A\to\Box_T B),\]
\[\mathbb N_A\models\Box_T A\to\Box_T\Box_T A.\]

Proof

For the first sentence, standard correctness turns its two hypotheses into actual derivations of \(A\to B\) and \(A\). Implication elimination gives a derivation of \(B\), and standard correctness yields its box. For the second, standard correctness turns the hypothesis into \(T\vdash A\); D1 gives \(T\vdash\Box_T A\); standard correctness, now applied to the sentence \(\Box_T A\), gives the required outer box. □

Truth in \(\mathbb N_A\) is weaker than the required \(T\)-derivability of these sentences. First incompleteness already explains why a true arithmetic sentence need not have a proof in a given effective theory. These semantic observations therefore establish only the displayed standard-model claims for the arbitrary representative.

Reflection is a claim about soundness

The following two external conditions are equivalent:

\[\mathbb N_A\models\Box_T A\to A\text{ for every sentence }A;\]
\[T\vdash A\ \Longrightarrow\ \mathbb N_A\models A\text{ for every sentence }A.\]

Proof

In the standard model, the antecedent \(\Box_T A\) holds exactly when \(T\vdash A\), by . Substituting that equivalence gives precisely the second condition, which says that \(T\) is sound in \(\mathbb N_A\). □

This condition differs from external consistency: consistency rules out a proof of a contradiction, whereas standard soundness requires every theorem to be true. Even standard soundness would establish these reflection implications as true sentences; it would not supply their proofs inside \(T\).

A consistent theory cannot prove every reflection instance

Assume in addition that \(T\) is consistent. For its specified Gödel sentence \(G_T\),

\[T\nvdash\Box_T G_T\to G_T.\]

Proof

Suppose \(T\) proved this implication. Its fixed-point equivalence gives \(T\vdash G_T\leftrightarrow\neg\Box_T G_T\). If \(\Box_T G_T\) were assumed inside a derivation, the proposed reflection implication would give \(G_T\), and the fixed-point equivalence would give \(\neg\Box_T G_T\). Discharging the assumption yields \(T\vdash\neg\Box_T G_T\). The other direction of the equivalence then gives \(T\vdash G_T\), contradicting its unprovability under consistency. □

This argument uses the fixed-point equivalence and consistency, without assuming D2 or D3. It identifies a particular reflection sentence that cannot be a theorem; it does not say that all reflection instances fail.

What follows by applying D1 to an actual theorem

If \(T\vdash A\), then \(T\vdash\Box_T A\) and \(T\vdash\Box_T\Box_T A\).

Proof

Apply D1 first to \(A\), then to the actual arithmetic theorem \(\Box_T A\) obtained on that first application. This proves both conclusions without using D3. □

The hypothesis is still the existence of an external derivation of \(A\). It has not become the arithmetic antecedent \(\Box_T A\) inside a proof of an implication.

Write the consistency sentence for this particular predicate

Define

\[\operatorname{Con}_T:=\neg\Box_T\bot=\neg\operatorname{Prov}_T(\overline{\ulcorner\bot\urcorner}).\]

Here \(\bot\) is the actual contradiction formula of the shared calculus; its code is fixed. The right-hand side is a sentence of the original arithmetic language. The equality displayed above defines notation; it is not an equality between arithmetic terms.

External consistency means that no actual finite derivation of \(\bot\) from \(T\) exists. The formula \(\operatorname{Con}_T\) expresses that assertion through this specified proof checker and representing formula. Changing those choices requires a new comparison rather than assuming that the resulting consistency sentences are interchangeable inside arithmetic.

The consistency sentence has its intended standard meaning

For the chosen predicate,

\[\mathbb N_A\models\operatorname{Con}_T\quad\Longleftrightarrow\quad T\text{ is consistent}.\]

Proof

Standard correctness, applied to \(\bot\), says that \(\mathbb N_A\models\Box_T\bot\) exactly when \(T\vdash\bot\). Negate the equivalence. □

This establishes what the consistency sentence means in the standard model. It does not establish whether \(T\) proves that sentence. D1 and the concrete numerical proof operations hold under the hypotheses given here. The separately constructed PA predicate has its own consistency sentence. A proved internal comparison is needed before consistency sentences formed from different representatives can be interchanged in a derivation.
