Keep an ordered presentation of the finite assumptions

A presented goal is a pair \(g=(H,E)\), where \(H\) is a finite list of shared reduced propositional formulas and \(E\) is reduced as well. Atom names have decidable equality. The underlying sequent is \(\operatorname{set}(H)\Rightarrow E\), where the list's finite set forgets order and repetitions. A certificate of the presented goal is an actual G4ip tree of that sequent.

The core search below works on these reduced goals. Its native-input version accepts arbitrary native formulas and first expands every primitive negation, including those inside assumptions. Define the presented-goal weight by

\[W(H,E)=W\bigl(\operatorname{set}(H)\Rightarrow E\bigr).\]

The right side is the established sequent weight; repeated assumptions are counted once. The list supplies a finite order in which to visit possible principals, without choosing an order on the atom set.

Remove every copy of the selected principal

Let \(\operatorname{remove}(F,H)\) be the list obtained by retaining exactly those members of \(H\) unequal to \(F\), in their original order. Then

\[\operatorname{set}(\operatorname{remove}(F,H))=\operatorname{set}(H)\setminus\{F\},\qquad \operatorname{set}(A::H)=\{A\}\cup\operatorname{set}(H).\]

A formula belongs to the filtered list exactly when it belongs to \(H\) and differs from \(F\). This is precisely membership in the set difference. A formula belongs to \(A::H\) exactly when it equals \(A\) or belongs to \(H\), proving the second identity. Thus prefixing replacement formulas to the filtered list represents the exact erased-principal contexts of G4ip, even when \(H\) originally contained repeated copies of \(F\).

The finite option list contains every primitive nonleaf choice

For each presented goal, form \(\operatorname{Moves}(H,E)\) by listing the applicable right moves in the order shown, then visiting each member of \(H\) from left to right and appending its applicable left move. This is an effectively computed finite list. Every nonleaf primitive G4ip inference with that underlying conclusion has a corresponding move in this list, with the same premise sequents and reconstruction constructor.

Inspect the right conclusion's outer constructor to obtain its listed right choices. For a left inference its selected formula belongs to \(\operatorname{set}(H)\), hence occurs at some position of \(H\). Visiting that occurrence inspects its outer constructor and, for an implication, the constructor of its input. The table contains every allowed case. In the atomic-input case list membership decides the required atom test. The finite-set bridge identifies all the premise contexts. An atom or falsum has no nonleaf left rule of its own.

The list has finitely many positions, each giving at most one left move, and there are at most two right moves. Duplicate occurrences may repeat a choice, but cannot remove it or create a new kind of inference. Each move has at most two premises. This establishes finite branching together with the actual enumeration, rather than just an abstract finiteness assertion.

Each generated premise inherits the G4ip weight decrease

If \(g'\) is a premise of a generated move for \(g\), then \(W(g')<W(g)\). Generated premises of a reduced goal are reduced.

The finite-set bridge turns this particular premise into exactly a G4ip backward step, whose strict inequality applies. Repeated list occurrences cause no discrepancy, because both weights use the underlying finite sets. Reducedness follows by inspecting the same tables: a replacement uses components of the reduced principal, combines reduced components by implication, or introduces an already reduced right-input formula. Filtering and prefixing retain those properties.

Close falsum and atomic identities before branching

The leaf test \(\operatorname{Leaf}(H,E)\) returns a certificate of \((H,E)\) if \(\bot\in H\), using falsum-left. Otherwise, if \(E\) is an atom present in \(H\), it returns atomic identity. In every other case it returns \(\mathsf{none}\). These tests are finite membership calculations. The order gives falsum-left priority when both tests apply.

The returned value includes the actual primitive certificate. A compound formula already in \(H\) is handled by the rule search and derived identity, rather than an additional primitive leaf.

Solve every premise of one selected move

Let \(s\) be a supplied solver that returns either \(\mathsf{none}\) or an actual certificate for each presented goal. The all-premise calculation \(\operatorname{All}_s\) acts on a finite list of goals. It returns the empty tuple on the empty list. For \(g::G\), first run \(s(g)\). If that fails, return \(\mathsf{none}\). If it returns \(p\), calculate \(\operatorname{All}_s(G)\); return \(\mathsf{none}\) if this fails, and otherwise return the tuple formed by prefixing \(p\) to the returned certificates.

Thus \(\operatorname{All}_s(G)\) succeeds exactly when \(s\) succeeds at every member of \(G\). Its returned tuple supplies a certificate at each exact goal, including repeated goals. Applied to a move's premise list, reconstruction turns that tuple into a certificate of the parent. Both operations are finite recursions on explicit data.

Backtrack across rule choices

The move trial \(\operatorname{Try}_s(M)\), for a finite list of moves of one fixed parent goal, tries them in order. For the empty list it returns \(\mathsf{none}\). At the head move, run \(\operatorname{All}_s\) on its premise list. If this succeeds, reconstruct and return the parent certificate. If it fails, try the remaining moves.

Consequently \(\operatorname{Try}_s(M)\) succeeds exactly when some move in \(M\) has all of its premises solved by \(s\). The successful value comes from the first such move. Failure of one move continues with the next alternative; failure of either premise of a binary move rejects that entire move.

Give every recursive call a smaller fuel value

The fuelled search \(S_n(g)\) returns an optional actual certificate of the presented goal \(g\). Its defining recurrence is

\[S_0(g)=\mathsf{none}.\]
\[S_{n+1}(g)=\begin{cases} \mathsf{some}(p),&\operatorname{Leaf}(g)=\mathsf{some}(p),\\ \operatorname{Try}_{S_n}(\operatorname{Moves}(g)),&\operatorname{Leaf}(g)=\mathsf{none}. \end{cases}\]

The full search is \(S(g)=S_{W(g)}(g)\). The natural-number recursion decreases fuel at every recursive goal call. The auxiliary calculations recurse on their finite premise and move lists. These definitions therefore execute and terminate on every finite input. The weight theorem will justify the chosen initial fuel; fuel exhaustion at a smaller arbitrary value has not yet been given a logical interpretation.

Success returns the promised primitive proof tree

For every fuel \(n\) and presented goal \(g=(H,E)\), if \(S_n(g)=\mathsf{some}(p)\), then the returned \(p\) is an actual G4ip certificate of \(\operatorname{set}(H)\Rightarrow E\). In particular, full-search success implies native intuitionistic derivability of its reduced underlying endsequent.

Induct on fuel. Zero returns no certificate. At successor fuel, a successful leaf test directly supplies the stated primitive rule. Otherwise a successful move trial supplies a tuple of successful recursive child results. Induction gives actual certificates for those children. The selected move's reconstruction operation applies exactly its G4ip constructor, with the finite-set context identities already established. It returns the promised parent tree. The G4ip interpretation then yields a native intuitionistic deduction. This proof checks the returned tree itself, rather than replacing success by a claim that some unrelated proof exists.

The endsequent weight is sufficient fuel

If a G4ip certificate proves the underlying sequent of a presented goal \(g\), then \(S_n(g)\) succeeds whenever \(W(g)\leq n\). Hence

\[S(g)\ne\mathsf{none}\quad\Longleftrightarrow\quad g\text{ has a G4ip certificate}.\]

A full-search failure therefore rules out every G4ip certificate of that goal.

Induct on \(n\), with the goal and its supplied certificate arbitrary. Zero cannot satisfy the weight assumption: every conclusion has weight at least two. At successor fuel, if a leaf test succeeds there is nothing to prove. If it fails, the supplied certificate cannot be a falsum-left or atomic-identity leaf. Inspect its last constructor. The exhaustive move-list lemma supplies the corresponding listed move and its actual child certificates, transported through the finite-set identities.

For each child \(g'\), strict weight decrease and \(W(g)\leq n+1\) give \(W(g')\leq n\). The induction hypothesis makes \(S_n\) succeed at every child. The all-premise calculation therefore succeeds for this move. The move trial either succeeds earlier or reaches this successful move, so \(S_{n+1}(g)\) succeeds. This establishes the fuel claim.

Set \(n=W(g)\) for completeness of full search. Soundness gives its converse. If full search returns \(\mathsf{none}\), a hypothetical certificate would force success by the proved fuel claim, a contradiction. This conclusion uses the specified sufficient bound, not an arbitrary failed partial run.

Decide the full native intuitionistic input

For a finite native premise list \(H\) and native conclusion \(E\), let \(g^\circ=(\operatorname{map}(A\mapsto A^\circ,H),E^\circ)\). The executable Boolean answer \(\operatorname{Prove}(H,E)\) is one exactly when \(S(g^\circ)\) succeeds. Then

\[\operatorname{Prove}(H,E)=1\quad\Longleftrightarrow\quad \operatorname{set}(H)\vdash_{\mathrm I}E.\]

When the answer is one, the same computation retains an actual G4ip certificate of the expanded endsequent.

List mapping and the finite-set bridge identify the expanded antecedent with \(\{A^\circ:A\in\operatorname{set}(H)\}\). Full-search success is equivalent to G4ip provability by . The native expansion correspondence identifies this exactly with the displayed native consequence. All list, membership, formula and fuel calculations are effective from the input. Taking whether the optional certificate is present gives the Boolean decision.

Reject excluded middle and prove its double negation

For an atom \(p\), the full native search rejects \(\varnothing\Rightarrow p\lor\neg p\), and succeeds on \(\varnothing\Rightarrow\neg\neg(p\lor\neg p)\).

After expansion the first goal is \(\varnothing\Rightarrow p\lor(p\to\bot)\). The first right choice asks for \(p\) with no assumptions, which has no closing leaf or move. The second asks for \(p\to\bot\); its right-implication child is \(\{p\}\Rightarrow\bot\), which also has no closing leaf or move. Thus every option fails, with the full bound available.

For the double negation, put \(F=(p\lor(p\to\bot))\to\bot\). Right implication leaves \(\{F\}\Rightarrow\bot\). The disjunction-input left move replaces \(F\) by \(p\to\bot\) and \((p\to\bot)\to\bot\). Select the latter implication-input move. Its second premise contains falsum and closes. Its first premise has assumptions \(p\to\bot\) and \(\bot\to\bot\), with conclusion \(p\to\bot\). Right implication adds \(p\); atomic implication-left on \(p\to\bot\) then introduces falsum, so this premise closes too. Reconstructing these choices gives a G4ip certificate. The sufficient-fuel theorem ensures the exhaustive search finds one, and direct execution on the numbered atom \(p_0\) gives the same two answers.

Order and repeated premises do not change the decision

If two finite native premise lists \(H,K\) have the same underlying finite set, then \(\operatorname{Prove}(H,E)=\operatorname{Prove}(K,E)\) for every native conclusion \(E\). In particular, permuting a list or inserting a repeated assumption preserves the answer.

The native decision theorem makes each answer one exactly when the shared finite set proves \(E\). The two answers therefore have the same truth value and, as Booleans, are equal. A permutation or repetition preserves that finite set. The implementation may visit the alternatives in a different order, but every accepted result is still a primitive certificate of its stated endsequent.

It asks for \(q\) under the empty context. There is no closing leaf and no move, so that trial fails. The move trial then visits the right-disjunct choice. Does every fuelled failure prove nonderivability?
