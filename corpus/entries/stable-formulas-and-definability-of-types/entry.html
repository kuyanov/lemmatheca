Keep only the tests made by one partitioned formula

Fix a complete theory \(T\), a nonempty model \(M\models T\), and an actual first-order formula \(\varphi(\bar x;\bar y)\), with finite tuple lengths \(n,m\). No countability assumption is imposed on \(L\). The convention \(M^0=\{()\}\) permits an empty tuple group. For \(\bar b\in M^m\), its named instance \(\varphi_{\bar b}(\bar x)\) is the \(L(M)\)-formula obtained by replacing the parameter variables by their names and retaining the object variables.

A local \(\varphi\)-type over \(M\) is a set \(P\subseteq M^m\) for which every finite \(F\subseteq M^m\) has a tuple \(\bar a\in M^n\) satisfying

\[M\models\varphi[\bar a;\bar b]\quad\Longleftrightarrow\quad\bar b\in P\qquad(\bar b\in F).\]

Its signed instance set is \(p_P=\{\varphi_{\bar b}:\bar b\in P\}\cup\{\neg\varphi_{\bar b}:\bar b\notin P\}\). Write \(S_\varphi(M)\) for the set of these local types. The word “local” refers to the one fixed formula: \(P\) chooses an answer to every one of its parameter tests, rather than deciding every formula in the language.

Local types are restrictions of genuine complete parameter types

The signed set \(p_P\) of a local type is a partial type over \(\operatorname{Th}(M_M)\). Every complete type \(q\in S_n^M(M)\) has the local restriction \(P_q=\{\bar b:\varphi_{\bar b}\in q\}\), and this restriction belongs to \(S_\varphi(M)\). Conversely every \(P\in S_\varphi(M)\) is \(P_q\) for some such \(q\).

A finite subset of \(p_P\) uses only finitely many parameter tuples. The defining finite test gives one object tuple satisfying all their signed instances. The finite parameter-type test therefore makes \(p_P\) a partial type in the actual named language.

A complete \(q\) contains exactly one of \(\varphi_{\bar b},\neg\varphi_{\bar b}\). Every finite set of its selected answers is realized in \(M\), again by the finite parameter-type test, proving that \(P_q\) is a local type. In the converse direction, complete the partial type \(p_P\) to \(q\). Its prescribed positive and negative instances force \(\bar b\in P_q\) exactly when \(\bar b\in P\), so the same local type is recovered.

Realization preserves the actual parameter assignment

Every \(P\in S_\varphi(M)\) has an elementary-extension realization: there are an elementary embedding \(h:M\to N\) and \(\bar a\in N^n\) with

\[N\models\varphi[\bar a;h(\bar b)]\quad\Longleftrightarrow\quad\bar b\in P\qquad(\bar b\in M^m).\]

Here \(h(\bar b)\) applies \(h\) to each coordinate. Conversely, any such tuple and elementary embedding determine a local type by the displayed rule. After identifying the elementary copy of \(M\), these are realizations with all original parameters fixed.

Apply parameter realization to \(p_P\). Substituting each named parameter by its interpretation \(h(b_j)\) says exactly that its native instance is true at \(\bar a\) if \(\bar b\in P\), and false otherwise. Thus the assertion is about the actual original formula, not a separate relation standing in for it.

Conversely, a finite collection of these signs is expressed by a single existential formula with finitely many parameters from \(M\). It holds in \(N\) at the displayed image parameters. Elementarity transfers that formula to \(M\), supplying the finite witness required in . This also handles the empty finite collection and empty tuple groups.

Finitely many rows can distinguish the two answers

For \(P\in S_\varphi(M)\), a separating row list is a finite list \(\bar a_0,\ldots,\bar a_{k-1}\in M^n\) such that

\[\bar b\in P,\ \bar c\notin P\quad\Longrightarrow\quad\exists i<k\;\bigl(\varphi[\bar a_i;\bar b]\not\leftrightarrow\varphi[\bar a_i;\bar c]\bigr),\]

where the truth values are evaluated in \(M\). Its row vector at \(\bar b\) is \(r(\bar b)=(\mathbf1_{M\models\varphi[\bar a_i;\bar b]})_{i<k}\in\{0,1\}^k\). Separation means that equal row vectors cannot occur on opposite sides of \(P\). An empty row list is allowed; it separates exactly when \(P=\varnothing\) or \(P=M^m\).

Failure of finite separation constructs two triangular arrays

If \(P\) has no separating row list, there are sequences \(\bar a_i\in M^n\) and \(\bar b_i,\bar c_i\in M^m\), for \(i\in\mathbb N\), with \(\bar b_i\in P\), \(\bar c_i\notin P\), and

\[\begin{aligned}i\ge j&\Longrightarrow M\models\varphi[\bar a_i;\bar b_j]\ \land\ \neg\varphi[\bar a_i;\bar c_j],\\i<j&\Longrightarrow\bigl(M\models\varphi[\bar a_i;\bar b_j]\iff M\models\varphi[\bar a_i;\bar c_j]\bigr).\end{aligned}\]

Suppose rows \(\bar a_0,\ldots,\bar a_{i-1}\) have been chosen. Since they do not separate, choose \(\bar b_i\in P\) and \(\bar c_i\notin P\) on which every earlier row agrees. The defining finite test for the local type now supplies \(\bar a_i\) realizing its answers on all \(\bar b_j,\bar c_j\) for \(j\le i\). In particular the first is positive and the second negative for each of these pairs.

Recursion gives the sequences. The finite test at stage \(i\) proves the first line, and the choice of the pair at stage \(j\) proves the second. Thus the lower triangle has the fixed pair of values \((1,0)\), while each upper-triangle entry has equal values \((\epsilon_{ij},\epsilon_{ij})\). Choice is used for this sequence of witnesses.

A homogeneous upper triangle gives every finite order pattern

The arrays in imply that \(\varphi\) has a \(k\)-order pattern in the same model \(M\) for every positive integer \(k\).

Color a pair \(i<j\) by the common upper-triangle truth value \(\epsilon_{ij}\). The infinite Ramsey theorem gives increasing indices \(h(0)<h(1)<\cdots\) on which every such pair has one fixed color \(\epsilon\). Relabel all three sequences along \(h\).

If \(\epsilon=1\), then \(\varphi[\bar a_i;\bar c_j]\) is true exactly when \(i<j\): the upper triangle is true, and the diagonal and lower triangle are false. The first \(k\) rows and columns give the required pattern.

If \(\epsilon=0\), then \(\varphi[\bar a_i;\bar b_j]\) is true exactly when \(j\le i\). For the required size \(k\), choose rows \(\bar a_{k-i}\) and columns \(\bar b_{k+1-j}\), for \(i,j<k\). Their truth condition is

\[k+1-j\le k-i\quad\Longleftrightarrow\quad i<j.\]

All indices used are natural numbers in the infinite homogeneous sequences. The shift removes the diagonal and reversing the finite indices puts the strict order in the required orientation. Both colors therefore give every finite pattern.

Every stable local type has a finite separating row list

If \(\varphi\) is stable in \(T\), every \(P\in S_\varphi(M)\) has a separating row list.

Otherwise the two preceding lemmas produce, in the actual model \(M\models T\), a \(k\)-order pattern for every positive \(k\). This is the order property, contradicting stability. Equivalently, take a finite forbidden size from the definition of stability and apply at precisely that size. No regularity, language cardinality bound, or uniform bound on the length of the separating list is assumed.

Write the definition as an actual finite Boolean formula

Given a row list \(\bar a=(\bar a_i)_{i<k}\) and a pattern \(\eta\in\{0,1\}^k\), its Boolean cell formula is the native \(L(M)\)-formula

\[C_{\bar a,\eta}(\bar y)=\bigwedge_{i<k}\begin{cases}\varphi(\bar a_i;\bar y)&\eta(i)=1,\\\neg\varphi(\bar a_i;\bar y)&\eta(i)=0.\end{cases}\]

Here the object variables are replaced by the named coordinates of the supplied rows; the parameter variables become the free variables \(\bar y\), with all quantified slots protected. For a set \(S\subseteq\{0,1\}^k\), define its cell union formula

\[\delta_{\bar a,S}(\bar y)=\bigvee_{\eta\in S}C_{\bar a,\eta}(\bar y).\]

Both operations are finite. The empty conjunction is \(\top\), represented by \(\neg\bot\), and the empty disjunction is \(\bot\). Consequently \(M_M\models\delta_{\bar a,S}[\bar b]\) if and only if \(r(\bar b)\in S\), by substitution and the native connective truth clauses.

Stability defines the positive tests of every local type

If \(\varphi\) is stable in \(T\), then for every \(P\in S_\varphi(M)\) there are a finite row list \(\bar a\) from \(M^n\) and \(S\subseteq\{0,1\}^{|\bar a|}\) such that

\[M_M\models\delta_{\bar a,S}[\bar b]\quad\Longleftrightarrow\quad\bar b\in P\qquad(\bar b\in M^m).\]

Thus \(P\) is definable with finitely many parameters from \(M\), using a finite Boolean combination of the displayed rows of \(\varphi\).

Take a separating list from and let \(S=\{r(\bar b):\bar b\in P\}\). This is a subset of the finite set \(\{0,1\}^k\). A positive tuple has its vector in \(S\). Conversely, if \(r(\bar c)\in S\), some positive \(\bar b\) has the same vector; separation excludes \(\bar c\notin P\). Hence \(\bar c\in P\). The cell-formula truth identity gives exactly the displayed equivalence.

The formula uses only the finitely many coordinates of the chosen rows as extra parameters. If \(k=0\), separation makes \(P\) empty or all of \(M^m\), and the empty-disjunction or empty-conjunction convention gives the corresponding definition. The formula defines which parameter tests are positive; it does not supply a single object tuple realizing them all.

An infinite model has at most its own size many local types

If \(M\) is infinite and \(\varphi\) is stable in \(T\), then

\[|S_\varphi(M)|\le |M|.\]

Put \(\kappa=|M|\). A code for a displayed definition consists of an integer \(k\), a list in \((M^n)^k\), and a subset of the finite pattern set \(\{0,1\}^k\). For each fixed \(k\), there are at most \(\kappa\) such codes: finite powers of an infinite cardinal are at most \(\kappa\), and the remaining choice is finite. This includes \(n=0\) and \(k=0\). A countable union of those code sets still has size at most \(\kappa\), by infinite sum arithmetic.

Choose one defining code for each local type using . The choice is injective: one fixed code has one truth set in \(M^m\), and the displayed theorem identifies it with the local type. This bounds the number of local types by the number of codes. Since \(\varphi\) is fixed, this count does not multiply by the size of the language.

The conclusion counts restrictions to one fixed formula over a whole model. It does not by itself give the full complete-type bound for an entire language or arbitrary parameter subsets.

A definable local type can still be omitted

In an infinite equality structure \(M\), take \(\varphi(x;y)\) to be \(x=y\). Its local types over \(M\) are precisely \(P=\{a\}\), for \(a\in M\), and \(P=\varnothing\). They are defined, respectively, by \(y=a\) and \(\bot\). Each singleton type is realized by \(a\), while the empty positive set is omitted in \(M\).

A finite test containing two distinct positive parameters cannot be realized by one object. Thus a local type has at most one positive parameter. If it has the positive parameter \(a\), it is exactly \(\{a\}\), and the object \(a\) witnesses all its tests. The empty positive set is a local type because each finite test asks for a point outside a finite set, which exists in the infinite \(M\). Every actual point, however, equals itself, so no point makes all these equality tests false.

The two formulas displayed define exactly their positive sets. Equality is stable: in a putative three-order pattern, row zero forces \(b_1=b_2=a_0\), whereas row one would force \(a_1=b_2\) and \(a_1\ne b_1\), a contradiction. This direct check agrees with the full equality-type classification. Parameter realization still gives the omitted type a new point in an elementary extension.

Does a formula defining the positive set realize the original type?

For the omitted equality type above, \(\delta(y)=\bot\) has no solutions in \(M\). Why is it nevertheless a definition of that type? Would the same empty positive set be a local equality type over a finite nonempty model?

Show answerHide answer

The free variable of \(\delta\) is the parameter variable \(y\). A definition has to describe exactly those parameters whose equality tests are positive. There are none, so a formula false at every parameter is exactly right. A realization would instead be one object \(x\) unequal to every parameter in the whole domain; no point of \(M\) does that.

For finite nonempty \(M\), use the finite test \(F=M\). It asks that the single object be unequal to every element of its own domain, which is impossible. Thus the empty positive set is not a local type there. In fact finite models realize every full parameter type, and completing a local type therefore realizes it as well.

Must one formula template define all types over every parameter set?

Does the theorem supply one fixed formula template \(\psi(\bar y;\bar z)\) whose instances, with \(\bar z\) chosen from any parameter set \(A\), define all local types over that \(A\)? Consider equality with \(A=\{a\}\) in an infinite equality structure.

Show answerHide answer

There are two local equality types over this singleton: the positive test \(x=a\), and the negative test \(x\ne a\). Their positive traces on \(A\) are \(\{a\}\) and \(\varnothing\). They are individually defined over \(A\), for example by \(y=a\) and \(\bot\).

For any one fixed finite length of \(\bar z\), there is only one tuple from the singleton \(A\), including the unique empty tuple if that length is zero. A fixed \(\psi\) therefore has only one such instance and cannot define both opposite traces. A finite family of templates avoids this obstruction; one template also needs additional coding conventions if it is to cover every parameter set. The theorem above asserts individual definitions over whole base models. It neither asserts this all-sets uniformity nor rules out individual definability over arbitrary sets.
