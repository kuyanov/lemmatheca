Distinguish an assumption-free proof from a closed formula

Fix a first-order language \(L\), original free names \(X\), and the full equality-free intuitionistic sequent calculus. Its cut-free proof collection \(\mathcal P_X(\Gamma,A)\) consists of actual cut-free trees of \(\Gamma\Rightarrow A\). Abbreviate \(\mathcal P_X(\varnothing,A)\) to \(\mathcal P_X(A)\). Define raw cut-free derivability, written \(\vdash_{0,X}A\), as nonemptiness of this last collection.

A proof with empty antecedent has no undischarged assumptions. Its conclusion may still contain names from \(X\). A closed formula, by contrast, has no free names. Extraction below starts from a supplied finite tree, retaining its parameter set and actual rule data. Equality atoms and logical equality rules are outside this calculus.

An empty antecedent rules out every left inference

A tree in \(\mathcal P_X(A\lor B)\) ends in one of the two disjunction-right rules. A tree in \(\mathcal P_X(\exists xB)\) ends in existential-right.

Inspect the complete primitive rule list. Atomic identity requires an atom in the antecedent, and falsum-left requires falsum there. Each conjunction-, disjunction-, implication-, negation-, universal- or existential-left rule likewise requires its principal formula in that antecedent. All these membership conditions are impossible for \(\varnothing\).

The remaining rules introduce the outer constructor of their conclusion. Conjunction-, implication-, negation- and universal-right have the wrong outer constructor for both displayed targets. Disjunction-right has the correct constructor only for the first; existential-right has it only for the second. There is no primitive cut, weakening or compound-identity constructor to provide another final case.

Record a selected side together with its proof

A disjunct packet for \(A,B\) is either a left tag with a tree \(q\in\mathcal P_X(A)\), or a right tag with a tree \(q\in\mathcal P_X(B)\). Thus it records which formula was selected and a particular proof of that formula. Denote the collection of these packets by \(\mathsf D_X(A,B)\).

The tags need not be determined by the formulas alone. If both disjuncts have proofs, different supplied disjunction trees can select different sides.

Read the selected disjunct from an assumption-free tree

There is a specified operation

\[\mathsf{disj}:\mathcal P_X(A\lor B)\longrightarrow\mathsf D_X(A,B).\]

Consequently, \(\vdash_{0,X}A\lor B\) if and only if \(\vdash_{0,X}A\) or \(\vdash_{0,X}B\).

By , the supplied tree ends with left or right disjunction introduction. In the first case return the left tag and its actual child tree; in the second return the right tag and its actual child. Conversely apply the indicated disjunction introduction to the proof in any supplied packet. Passing to existence gives the displayed equivalence.

This extends the propositional extraction to full equality-free formulas, whose disjuncts may contain quantifiers. The proof uses the final constructor of a particular tree, without deciding whether either formula is generally derivable.

Keep the witness term and its exact instance proof

Let \(B\) be an equality-free body with one available bound slot. For a term \(t\in\operatorname{Term}_L(X)\), let \(B(t)\) be its capture-free instance. A witness packet is a pair

\[\mathsf W_X(B)=\{(t,q):t\in\operatorname{Term}_L(X),\ q\in\mathcal P_X(B(t))\}.\]

The term is a finite syntax tree over the same names \(X\). It is not merely an element chosen from a model, and a general signature gives it no interpretation as a numeral.

Extract one actual term and the proof that it works

There is a specified operation

\[\mathsf{wit}:\mathcal P_X(\exists xB)\longrightarrow\mathsf W_X(B).\]

Equivalently, \(\vdash_{0,X}\exists xB\) holds exactly when some term \(t\in\operatorname{Term}_L(X)\) has \(\vdash_{0,X}B(t)\).

The final rule is existential-right. It already stores a particular term \(t\), and its premise is a particular tree of \(\varnothing\Rightarrow B(t)\). Return those two pieces unchanged. Conversely the genuine existential-right rule turns any supplied packet into a tree of the existential conclusion.

Even when the bound slot is unused, the operation returns the term stored by this inference. Equal instance formulas need not determine equal stored terms. This is a single witnessed instance, whereas classical Herbrand extraction generally returns several instances together with a propositional factor proof.

Normalize a supplied proof before inspecting its last rule

The two extraction operations also accept supplied pure raw trees with cut, and supplied raw intuitionistic natural deductions with equality disabled and equality-free conclusions. Their output is respectively a chosen disjunct proof or a term with its instance proof, over the original names \(X\).

For a cutful sequent input use the actual cut-removal operation, which preserves its empty antecedent and conclusion. Then apply or .

For a native input use the proved native-to-cut-free construction. It first purifies any equality-containing intermediate formulas, then translates to cutful sequents and removes cuts. Its input already has logical equality rules disabled; it does not remove enabled equality rules. The extracted sequent proofs can be read back as actual native deductions of the selected endpoints. Each construction acts on the supplied tree, so existence of an input gives existence of the corresponding output as well.

Expose the reserved names in a public existential witness

For public certificates put \(Y=X\sqcup U\), where \(U\) is the fixed countable reserve, and let \(j:X\to Y\) be the left inclusion. Write \(A^j\) for free renaming, also at a body's available bound scope. A public proof of \(A\) is a raw tree of \(A^j\) over \(Y\).

A supplied public proof of \(A\lor B\) gives a public proof of one original disjunct. A supplied public proof of \(\exists xB\) gives an actual term \(t\in\operatorname{Term}_L(Y)\) and a raw proof of \((B^j)(t)\). These assertions also hold for public cutful or native equality-disabled inputs with pure endpoints.

Use on the underlying raw tree over exactly \(Y\). Free renaming preserves the outer disjunction or existential constructor. For disjunction its selected endpoint is \(A^j\) or \(B^j\), precisely an original disjunct's public certificate. For existence its instance is \((B^j)(t)\), with exactly the term returned by raw extraction. Nothing in these operations deletes a reserve name occurring inside \(t\).

An original term lets us remove every reserved name

Suppose a term \(r\in\operatorname{Term}_L(X)\) is supplied. Define the free substitution \(\sigma_r:Y\to\operatorname{Term}_L(X)\) by sending each original name to itself as a variable and each reserve name to \(r\). From a public existential witness packet \((t,q)\), one obtains the original term \(t[\sigma_r]\) and a raw original-name proof of \(B(t[\sigma_r])\).

Apply the actual tree substitution to \(q\). Its empty antecedent remains empty. The capture-free instance identity gives

\[((B^j)(t))[\sigma_r]=B(t[\sigma_r]).\]

Indeed free substitution fixes every original name in \(B^j\), protects each bound slot, and substitutes into the term \(t\). The returned term replaces reserve variables recursively inside all its function applications. The transformed tree is therefore the required instance proof. Applying existential-right also gives a raw proof of the original existential. Without a supplied original term, this argument has no replacement for the reserve.

A universal parameter may occur inside the extracted term

Let \(B(x,y)\) be an equality-free two-slot body. A supplied raw cut-free tree of \(\forall x\exists yB(x,y)\), with empty antecedent, gives a term \(t\) over \(X\sqcup\{e\}\) and a proof of \(B(e,t)\) with empty antecedent over those names. Here opening the outer slot replaces \(x\) by \(e\) while keeping the inner slot \(y\) available until its instance is taken.

No left rule or leaf can end the original tree, and only universal-right has its outer constructor. Its actual premise is therefore an assumption-free tree of \(\exists yB(e,y)\). Apply to that premise. The returned term may contain the arbitrary protected parameter \(e\); no new function symbol is introduced. The same argument follows cut removal for cutful or equality-disabled native inputs. For public inputs the starting original-name set is first enlarged by its existing reserve.

Follow the stored term through a short proof

Suppose \(L\) has a constant \(c\), unary function \(f\) and unary relation \(P\). There is a raw assumption-free proof of \(E=\exists x(P(x)\to P(x))\) whose extracted witness is exactly \(f(c)\):

\[\frac{\displaystyle\frac{P(f(c))\Rightarrow P(f(c))}{\varnothing\Rightarrow P(f(c))\to P(f(c))}\;\to R}{\varnothing\Rightarrow\exists x(P(x)\to P(x))}\;\exists R\,[f(c)].\]

The leaf is relation identity. Implication-right discharges its sole assumption, and existential-right uses the displayed original ground term. The existential extractor returns that stored term and the implication premise. If we append left disjunction-right to prove \(E\lor\bot\), the disjunction extractor first selects \(E\) and returns this same existential tree. Composing the operations therefore returns \(f(c)\) and its instance proof.

Changing the final existential term to \(c\) gives another proof of the same \(E\), now with extracted witness \(c\). Thus the procedure follows proof data rather than assigning a canonical witness to a theorem.

A public theorem need not supply an original ground term

In the empty language, with no original free names, the formula \(\exists x(\bot\to\bot)\) has a public cut-free proof. Its specified witness is \(u_0\in U\). There is no raw proof over the empty original-name set, even if cuts are allowed.

Over \(U\), falsum-left proves \(\bot\Rightarrow\bot\); implication-right gives the empty-antecedent implication. Existential-right at \(u_0\) gives the public theorem. Its unused bound slot makes its instance exactly \(\bot\to\bot\), but the proof still stores \(u_0\).

There is no original term: a term would be a variable from the empty name set or an application of a function symbol, and neither exists. A raw cut-free existential proof would yield such a term by , a contradiction. A raw cutful proof would first give that cut-free proof. This gives a last-rule explanation of the established reserve boundary. The hypothesis on \(r\) in consequently cannot be dropped.

Can the disjunction extractor retain arbitrary assumptions?

Does a proof of \(\Gamma\Rightarrow A\lor B\) always select a proof of \(\Gamma\Rightarrow A\) or \(\Gamma\Rightarrow B\)?

Show answerHide answer

No. Use two nullary relation symbols \(P,Q\) and \(\Gamma=\{P\lor Q\}\). Compound identity gives a cut-free proof of its member. A one-element structure interpreting \(P\) as false and \(Q\) as true satisfies \(\Gamma\) and refutes \(P\). Interchanging those two truth values satisfies \(\Gamma\) and refutes \(Q\). Ordinary soundness excludes each proposed factor proof, including public ones and proofs with cut.

The empty-antecedent proof ruled out disjunction-left by its membership condition. Here that rule is available, and identity for the compound disjunction expands through it. This is the quantified-language version of the ordinary-assumption obstruction.

Can an existential assumption select an original-name witness?

Does a proof of \(\Gamma\Rightarrow\exists xP(x)\) always give some original term \(t\) and a proof of \(\Gamma\Rightarrow P(t)\)?

Show answerHide answer

No. Take only a unary relation symbol \(P\), no function symbols, and one original free name \(a\). Put \(\Gamma=\{\exists xP(x)\}\). Compound identity supplies the displayed existential proof. Every term over this signature and original-name set is the variable \(a\): the function-application case is impossible, and the variable case has that sole name.

Use the two-element structure \(\{0,1\}\), set \(P=\{0\}\), and assign \(a\) the value \(1\). The existential assumption is true, while \(P(a)\) is false. Soundness excludes its raw and public deduction, hence excludes every original-term instance in this example. This strengthens the prescribed-instance obstruction by classifying all available original terms. A genuine theorem has no assumed existential principal that could end in existential-left.

The extraction results concern pure logical proofs with no undischarged axioms. An HA certificate instead permits a finite supporting set of arithmetic axioms. Logical cut removal preserves these assumptions, so it does not place an arbitrary HA theorem under the empty-antecedent hypotheses above.
