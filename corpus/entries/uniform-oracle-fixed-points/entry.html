Choose a program before choosing its oracle

Use the oracle program numbering \(\varphi_e^A\) and its specified parameter map \(s\). For an ordinary total computable numerical map \(F:\mathbb N^2\to\mathbb N\), an all-oracle fixed-point selector is an ordinary total computable map \(h:\mathbb N\to\mathbb N\) such that

\[\varphi_{h(a)}^A(x)\simeq\varphi_{F(h(a),a)}^A(x)\qquad\text{for every }A,a,x.\]

Here \(\simeq\) is equality of partial values: both sides diverge, or both terminate with the same value. The order of choice is \(\exists h\,\forall A,a,x\). The index transformer \(F\), the algorithm for \(h\), and its numerical outputs do not receive the oracle as an input. Their resulting programs may ask oracle questions when run.

Prepare the numerical input of one common driver

The driver input map \(T:\mathbb N\to\mathbb N\) is specified by

\[T(\langle p,\langle b,y\rangle\rangle)=\left\langle p,\left\langle s(s(b,b),\pi_1(y)),y\right\rangle\right\rangle.\]

Pairing is the fixed primitive-recursive pairing, with inverse projections \(\pi_1,\pi_2\); hence this rule defines \(T\) on every natural number. It is ordinary primitive recursive, since every operation displayed, including \(s\), is ordinary primitive recursive. Choose once an ordinary program \(t\) computing \(T\) totally, then embed it as a query-free oracle program. This chosen finite syntax works for every oracle by the ordinary-program embedding.

Run the prepared input through the universal oracle program

Let \(\mathsf u\) be the specified common universal oracle program. The common driver index is

\[R=\#\operatorname{comp}(\mathsf u,\operatorname{embed}(t)).\]

For every oracle \(A\) and every \(p,b,y\), it obeys

\[\varphi_R^A(\langle p,\langle b,y\rangle\rangle)\simeq\varphi_p^A(\langle s(s(b,b),\pi_1(y)),y\rangle).\]

The embedded ordinary program first returns exactly \(T(\langle p,\langle b,y\rangle\rangle)\). Universality then runs index \(p\) on the second component of that pair. The preliminary calculation always terminates, so strict composition preserves divergence of this final computation as well as every output. Both program texts were chosen before \(A\), making this one identity for all oracles.

Apply the parameter map three times

Define the driver specialization \(r\), self-specialized index \(q\), and fixed-point compiler \(H\) by

\[r(p)=s(R,p),\qquad q(p)=s(r(p),r(p)),\qquad H(p,a)=s(q(p),a).\]

These are numerical functions, independent of every oracle. In particular the same number \(H(p,a)\) can be used under any oracle; the theorem below will identify its behavior there.

The compiler is primitive recursive and retains its two inputs

The specified map \(H\) is ordinary primitive recursive jointly in \((p,a)\), and is jointly injective:

\[H(p,a)=H(p',a')\quad\Longrightarrow\quad p=p'\ \text{ and }\ a=a'.\]

Each defining operation is the specified primitive-recursive map \(s\), with constants, projections or previous outputs as arguments; composition therefore gives the primitive-recursive assertion. For injectivity, use the actual joint injectivity of parameter insertion. Equality of the final specialized codes first gives \(a=a'\) and \(q(p)=q(p')\). Decoding this second specialization gives \(r(p)=r(p')\); decoding the first gives \(p=p'\). This recovers numerical inputs from syntax, without asserting that different inputs produce different partial functions.

The specialized driver receives its own code as an argument

For every oracle \(A\) and all \(p,b,y\),

\[\varphi_{r(p)}^A(\langle b,y\rangle)\simeq\varphi_p^A(\langle s(s(b,b),\pi_1(y)),y\rangle).\]

Parameter insertion replaces the left side by \(\varphi_R^A(\langle p,\langle b,y\rangle\rangle)\). The identity in gives the asserted right side. This is a computation of the specified driver, rather than a new choice of an index depending on \(A\).

One compiler supplies self-reference for every oracle

The specified ordinary primitive-recursive compiler \(H\) satisfies, for every oracle \(A\) and every \(p,a,x\),

\[\varphi_{H(p,a)}^A(x)\simeq\varphi_p^A(\langle H(p,a),\langle a,x\rangle\rangle).\]

Insert the parameter \(a\), then unfold \(q(p)=s(r(p),r(p))\):

\[\varphi_{H(p,a)}^A(x)\simeq\varphi_{q(p)}^A(\langle a,x\rangle)\simeq\varphi_{r(p)}^A(\langle r(p),\langle a,x\rangle\rangle).\]

Apply with \(b=r(p)\) and \(y=\langle a,x\rangle\). Since \(\pi_1(y)=a\), the first component of the resulting input to \(p\) is \(s(s(r(p),r(p)),a)=H(p,a)\). Its second component is exactly \(\langle a,x\rangle\). This is the displayed conclusion, including simultaneous divergence. The argument used no special fact about \(A\), and every numerical code in it was already fixed.

A supplied common program gives a partial-family interface

Suppose a family of partial values \(g^A(n,a,x)\) is represented by one supplied oracle index \(p\), with

\[\varphi_p^A(\langle n,\langle a,x\rangle\rangle)\simeq g^A(n,a,x)\qquad\text{for every }A,n,a,x.\]

Then the specified map \(a\mapsto H(p,a)\) is ordinary primitive recursive and satisfies

\[\varphi_{H(p,a)}^A(x)\simeq g^A(H(p,a),a,x)\qquad\text{for every }A,a,x.\]

Fixing \(p\) in the jointly primitive-recursive compiler gives the numerical claim. Substitute the supplied representation into . No totality of \(g^A\) is assumed. The hypothesis retains one common index before \(A\) varies; separate representations chosen for unrelated families at each oracle do not supply this hypothesis.

Compile an ordinary computable index transformer once

For an ordinary total computable \(F:\mathbb N^2\to\mathbb N\), define its dispatch input map by

\[D_F(\langle n,\langle a,x\rangle\rangle)=\langle F(n,a),x\rangle.\]

A dispatch code for \(F\) is an ordinary program \(c\) satisfying \(E(c,w)\simeq D_F(w)\) for every \(w\). Such a code exists by ordinary program completeness: projections, \(F\), and pairing make \(D_F\) total computable. Choose this code once. The dispatcher index supplied by \(c\) is

\[P_c=\#\operatorname{comp}(\mathsf u,\operatorname{embed}(c)).\]

Only computability of \(F\) is required; \(F\) may take arbitrarily long to return an index and need not be primitive recursive. Its totality ensures that the numerical index calculation always finishes.

The supplied dispatcher has the same interpretation under all oracles

For any dispatch code \(c\) for \(F\), every oracle \(A\), and all \(n,a,x\),

\[\varphi_{P_c}^A(\langle n,\langle a,x\rangle\rangle)\simeq\varphi_{F(n,a)}^A(x).\]

The embedding identity says that \(\operatorname{embed}(c)\) returns exactly the ordinary result \(\langle F(n,a),x\rangle\), regardless of \(A\). The same universal program \(\mathsf u\) then runs that index on \(x\) under \(A\). Its divergence or output is the entire result of the composition. Thus the ordinary code is chosen before the oracle, while the computation it dispatches can depend on that oracle.

Every ordinary computable transformer has one selector for all oracles

For every ordinary total computable \(F:\mathbb N^2\to\mathbb N\), there is one ordinary primitive-recursive map \(h:\mathbb N\to\mathbb N\) with

\[\varphi_{h(a)}^A(x)\simeq\varphi_{F(h(a),a)}^A(x)\qquad\text{for every }A,a,x.\]

More precisely, for any supplied dispatch code \(c\), take \(h(a)=H(P_c,a)\).

Fix a dispatch code before choosing \(A\), using . The map \(h\) is primitive recursive by with its first input fixed. The common fixed-point identity gives \(\varphi_{h(a)}^A(x)\simeq\varphi_{P_c}^A(\langle h(a),\langle a,x\rangle\rangle)\). Apply to obtain the asserted identity. The possibly slow computation of \(F\) is part of the fixed dispatcher program; computing the selector's numerical output only inserts a parameter into fixed program text.

A single fixed-point index works under every oracle

For every ordinary total computable \(f:\mathbb N\to\mathbb N\), there is an index \(e\), chosen before the oracle, with

\[\varphi_e^A(x)\simeq\varphi_{f(e)}^A(x)\qquad\text{for every }A,x.\]

Apply to the ordinary computable map \(F(n,a)=f(n)\), then take \(e=h(0)\). Its identity for parameter zero is exactly the assertion. This strengthens a separate existence statement at each fixed oracle by retaining the same number \(e\).

Must the chosen program number equal its transformed number?

For \(F(n,a)=n+1\), can an all-oracle selector satisfy \(h(a)=F(h(a),a)\)? Does a selector still exist?

Show answerHide answer

No natural number equals its successor, so numerical equality is impossible at every parameter. This transformer is ordinary primitive recursive and hence total computable. The theorem nevertheless supplies a primitive-recursive \(h\) for which \(\varphi_{h(a)}^A\) and \(\varphi_{h(a)+1}^A\) are equal partial functions for every oracle \(A\). Equal computations can have different indices, exactly as in oracle padding.

Why does a separate witness for each oracle not suffice?

Does \(\forall A\,\exists h_A\) by itself justify \(\exists h\,\forall A\)? Compare the simpler condition that a numerical bit \(b\) equal \(\chi_A(0)\).

Show answerHide answer

For each \(A\), the bit \(b=\chi_A(0)\) exists, so \(\forall A\,\exists b\;(b=\chi_A(0))\) holds. But no single numerical bit works for all \(A\): the empty oracle requires zero and the oracle \(\{0\}\) requires one. Thus exchanging the quantifiers is not a valid logical inference. This example concerns the logical inference alone; it does not refute the fixed-point theorem.

In our proof the driver, the ordinary dispatch code, and every application of the parameter map are fixed before the oracle varies. Their all-oracle evaluation identities establish the stronger quantifier order directly.
