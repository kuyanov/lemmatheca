Infinitely many premises still ask for one valuation

Suppose there is an atom \(p_n\) for each natural number \(n\), and we require every \(p_n\) to be true. Any finite selection of these requirements can be met. Here the entire collection can be met too: give every atom value true. Compactness says that this passage from finite tests to one simultaneous solution works for every collection of ordinary propositional formulas.

Let \(P\) be any set of atoms. Use the finite propositional formulas formed from atoms, \(\bot\), negation, conjunction, disjunction and implication. A theory \(\Gamma\) is a set of these formulas, with no finiteness assumption. A valuation \(v:P\to\{0,1\}\) satisfies \(\Gamma\) when it makes every member true. The theory is satisfiable when such a valuation exists, and finitely satisfiable when each finite subset is satisfiable.

Write \(\Gamma\models C\) when every valuation satisfying \(\Gamma\) also makes \(C\) true. These definitions extend the finite-context notions. Each formula still has only finitely many atoms. Write \(\operatorname{At}(A)\) for this finite support; its truth value depends only on those atoms. We work in ordinary classical mathematics with the axiom of choice.

Finitely many atoms give finitely many possible solutions

Let \(F\subseteq P\) be finite, and let \(\Delta\) be a finitely satisfiable set of formulas whose atoms all lie in \(F\). Then some assignment \(r:F\to\{0,1\}\) makes every formula in \(\Delta\) true.

Proof

There are exactly \(2^{|F|}\) assignments on \(F\). Suppose none satisfies \(\Delta\). For each assignment \(r\), select a formula \(A_r\in\Delta\) that it makes false. The set of selected formulas is finite. Finite satisfiability gives a valuation satisfying all of them. Its restriction to \(F\) is one of the assignments, say \(r_0\). By locality it makes \(A_{r_0}\) true, contrary to its selection. □

The lemma includes \(F=\varnothing\). There is one empty assignment, and atomless formulas still exist: \(\bot\) is false and \(\top:=\neg\bot\) is true. An assignment on \(F\) can always be extended to \(P\), for example by giving all other atoms value zero. Locality makes its truth values on the formulas under consideration independent of the chosen extension.

A binary tree proves compactness for countably many atoms

If the atoms occurring in \(\Gamma\) form an at most countable set and \(\Gamma\) is finitely satisfiable, then \(\Gamma\) is satisfiable.

Proof

If the set of occurring atoms is finite, apply and extend the resulting assignment to all of \(P\). Otherwise list the occurring atoms as \(p_0,p_1,\ldots\), without repetitions. Put \(F_n=\{p_0,\ldots,p_{n-1}\}\). At level \(n\), keep exactly the binary strings \(s\) of length \(n\) which satisfy every formula of \(\Gamma\) whose support is contained in \(F_n\). Here \(s(i)\) assigns the value of \(p_i\).

Every level is nonempty. Indeed, the formulas supported on \(F_n\) form a finitely satisfiable subtheory, so supplies a satisfying assignment on \(F_n\). Every level is finite, since it has at most \(2^n\) strings. Restrictions of retained strings are retained: a formula supported on \(F_m\), for \(m\le n\), is also supported on \(F_n\), and changing values outside its support cannot change its truth value.

Thus the retained strings form a tree under extension, closed under initial segments and with a nonempty finite level at every natural number. By König's lemma, it has a branch through all these levels. Take the union of the strings on this branch to assign values to every occurring atom, and assign zero to any remaining atoms of \(P\).

For \(A\in\Gamma\), its finite support lies in some \(F_n\). The branch's level-\(n\) string makes \(A\) true. Locality shows that the full valuation does too. Hence the valuation satisfies every member of \(\Gamma\). □

Equivalently, one may cut off a binary string as soon as it falsifies a formula whose atoms have all been assigned. A branch which survives every finite stage cannot falsify any formula, because each formula is completely determined at a finite stage.

Finite tests suffice for an arbitrary set of atoms

Propositional compactness. For any atom set \(P\) and any theory \(\Gamma\) of finite propositional formulas, \(\Gamma\) is satisfiable if and only if every finite subset of \(\Gamma\) is satisfiable.

Proof

A satisfying valuation satisfies every subset. Conversely, suppose \(\Gamma\) is finitely satisfiable. For each finite \(F\subseteq P\), let \(\mathcal S_F\) consist of the assignments \(r:F\to\{0,1\}\) satisfying every \(A\in\Gamma\) with \(\operatorname{At}(A)\subseteq F\). The relevant subtheory is finitely satisfiable, so proves \(\mathcal S_F\ne\varnothing\), even if there are infinitely many formulas supported on \(F\).

These allowed assignments are preserved by restriction. If \(F\subseteq G\) and \(r\in\mathcal S_G\), then every formula supported on \(F\) is already among those satisfied by \(r\); its truth value is unchanged on restriction. Thus \(r\mathbin{\upharpoonright}F\in\mathcal S_F\).

Apply the theorem for finite-valued constraints preserved by restriction, with two available values at each atom. It gives a valuation \(v:P\to\{0,1\}\) such that \(v\mathbin{\upharpoonright}F\in\mathcal S_F\) for every finite \(F\). For \(A\in\Gamma\), take \(F=\operatorname{At}(A)\). The restriction satisfies \(A\), so locality makes \(v\) satisfy \(A\). □

This proof uses choice through the cited finite-constraint theorem. It assumes no countability of \(P\) or \(\Gamma\). It also covers the empty atom set and the empty theory.

Every contradiction appears in finitely many premises

A theory \(\Gamma\) is unsatisfiable if and only if some finite \(\Delta\subseteq\Gamma\) is unsatisfiable.

Proof

If every finite subset were satisfiable, would make \(\Gamma\) satisfiable. Conversely, a valuation satisfying \(\Gamma\) would satisfy any finite subset, so an unsatisfiable subset rules out such a valuation. □

A consequence needs only finitely many premises

For every theory \(\Gamma\) and formula \(C\),

\[\Gamma\models C\quad\Longleftrightarrow\quad\exists\text{ finite }\Delta\subseteq\Gamma\text{ such that }\Delta\models C.\]

Proof

First note that \(\Gamma\models C\) exactly when \(\Gamma\cup\{\neg C\}\) is unsatisfiable: a valuation satisfying this enlarged set would satisfy all premises and falsify the conclusion. Suppose \(\Gamma\models C\). By , a finite set \(\Theta\subseteq\Gamma\cup\{\neg C\}\) is unsatisfiable. Put \(\Delta=\Theta\cap\Gamma\). If a valuation satisfied \(\Delta\) and falsified \(C\), it would satisfy \(\neg C\) and hence every member of \(\Theta\), a contradiction. Thus \(\Delta\models C\).

For the converse, a valuation satisfying \(\Gamma\) satisfies \(\Delta\), so it makes \(C\) true whenever \(\Delta\models C\). □

A proof from an infinite theory is still finite

Use exactly the classical natural-deduction rules, including classical contradiction. For an arbitrary theory \(\Gamma\), write \(\Gamma\vdash C\) when some finite \(\Delta\subseteq\Gamma\) has a derivation of \(C\) in that calculus.

This agrees with allowing a finite derivation tree whose open assumptions belong to \(\Gamma\). Such a tree has only finitely many leaves, so its open assumptions form a finite set \(\Delta\subseteq\Gamma\). Conversely, a derivation from a finite subset uses only assumptions allowed by \(\Gamma\). For a finite \(\Gamma\), the definition agrees with the existing finite-context relation: one direction chooses \(\Delta=\Gamma\), and the other uses weakening.

Call \(\Gamma\) consistent if \(\Gamma\nvdash\bot\). This concerns proofs, whereas satisfiability concerns valuations.

Truth and finite proofs agree for every theory

Strong completeness. For every atom set \(P\), theory \(\Gamma\) and formula \(C\), \(\Gamma\models C\) if and only if \(\Gamma\vdash C\), using the specified classical natural-deduction calculus.

Proof

If \(\Gamma\models C\), supplies a finite \(\Delta\subseteq\Gamma\) with \(\Delta\models C\). The finite-premise completeness theorem gives a derivation from \(\Delta\), which is a proof from \(\Gamma\) by definition.

Conversely, a proof from \(\Gamma\) is a derivation from some finite \(\Delta\subseteq\Gamma\). By soundness, every valuation satisfying \(\Delta\) makes \(C\) true. A valuation satisfying \(\Gamma\) satisfies \(\Delta\), so \(\Gamma\models C\). □

The proof combines two distinct facts: formulas and derivations are finite, and compactness extracts finitely many premises from an arbitrary semantic consequence.

Consistency means a simultaneous truth assignment exists

An arbitrary theory \(\Gamma\) is consistent if and only if it is satisfiable.

Proof

A satisfying valuation rules out a derivation of \(\bot\) by soundness. If \(\Gamma\) were unsatisfiable, it would entail \(\bot\) vacuously; would then give \(\Gamma\vdash\bot\). Taking the contrapositive proves that consistency implies satisfiability. □

Does one finite subset replace the whole theory?

Let \(p_0,p_1,\ldots\) be distinct atoms and put \(\Gamma=\{p_n:n\in\mathbb N\}\). Does compactness give a finite \(\Delta\subseteq\Gamma\) with exactly the same satisfying valuations as \(\Gamma\)?

Show answerHide answer

No. For any finite \(\Delta\), choose \(p_k\notin\Delta\). Give \(p_k\) value zero and every other atom value one. This valuation satisfies \(\Delta\) and fails \(\Gamma\). The finite subset in may depend on the conclusion: for the consequence \(p_k\), the singleton \(\{p_k\}\) suffices. Compactness does not promise one finite subset for all conclusions.

Why does each formula need to be finite?

Suppose we add an expression \(\bigwedge_{n\in\mathbb N}p_n\), defined to be true exactly when every \(p_n\) is true. For distinct atoms \(p_n\), consider

\[\Gamma=\{p_n:n\in\mathbb N\}\cup\left\{\neg\bigwedge_{n\in\mathbb N}p_n\right\}.\]

Is this enlarged-language theory finitely satisfiable? Is it satisfiable?

Show answerHide answer

Every finite subset is satisfiable. Choose an index \(k\) whose positive requirement \(p_k\) is absent, make \(p_k\) false, and make all other atoms true. The listed positive requirements hold, and the infinite conjunction is false, so its negation is true too. But the entire theory requires every \(p_n\) true and also requires their infinite conjunction false. It is therefore unsatisfiable. This expression is outside our finite propositional syntax; its truth depends on infinitely many atoms, so the finite-support step in the compactness proof cannot apply.
