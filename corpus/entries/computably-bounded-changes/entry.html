Let the permitted number of revisions depend on the input

Use the prefix change counter \(c_a(s,x)\) for a binary approximation \(a(s,x)\). A computable change bound for \(a\) is a total computable function \(b:\mathbb N\to\mathbb N\) such that

\[c_a(s,x)\le b(x)\qquad\text{for every }s,x.\]

A set \(A\subseteq\mathbb N\) is \(\omega\)-computably enumerable, or \(\omega\)-c.e., if it has a jointly computable binary approximation \(a\) and a computable change bound \(b\) with \(a(0,x)=0\) and \(a(s,x)\to\chi_A(x)\). Write \(\mathcal E_\omega\) for this class. As in the finite change classes, only transitions between successive stages count as revisions.

The value \(b(x)\) is available effectively from the input. It may grow with \(x\), whereas an \(n\)-c.e. approximation uses the same allowance \(n\) for all inputs. A bound counts possible revisions; it does not say when they occur.

An input-dependent finite bound still forces convergence

If a binary approximation \(a\) satisfies \(c_a(s,x)\le b(x)\) for every \(s,x\), then it converges pointwise to the characteristic function of some set. Neither computability nor a common constant bound is needed for this conclusion.

Fix \(x\). The nondecreasing counter takes its values in the finite set \(\{0,\ldots,b(x)\}\). Choose a stage \(t\) attaining its largest value. At every later stage it has that same value. If \(a(u,x)\ne a(t,x)\) for some \(u\ge t\), the endpoint counter lemma would force a strictly larger counter value at \(u\). Thus the bit is constant from \(t\) onward. Collect the inputs with eventual bit one into a set \(A\); the other inputs have eventual bit zero, giving convergence to \(\chi_A\).

The choice of \(t\) was made separately for each input. Even when \(a\) and \(b\) are computable, this argument supplies no computable function choosing such a stage.

Keep a natural-number reserve that decreases at each revision

A natural-number countdown for an approximation \(a\) is a total function \(r:\mathbb N\times\mathbb N\to\mathbb N\) satisfying

\[r(s+1,x)\le r(s,x),\qquad a(s+1,x)\ne a(s,x)\Longrightarrow r(s+1,x)<r(s,x).\]

It is a computable countdown when the function is jointly computable in the stage and input. A countdown may decrease even when the guess stays the same. Its values are ordinary natural numbers, and no reserve below zero is available. There is no requirement that the reserve be exhausted: the final guess can retain unused units.

Subtract the number of spent revisions from the supplied bound

If \(a\) is jointly computable and \(b\) is a computable change bound for it, the specified function

\[r_b(s,x)=b(x)-c_a(s,x)\]

is a computable countdown. Here subtraction is truncated at zero, and \(r_b(0,x)=b(x)\).

The counter is computable, so subtraction gives joint computability of \(r_b\). The counter never decreases, hence the reserve never increases. If the bit changes at \(s\to s+1\), then \(c_a(s+1,x)=c_a(s,x)+1\le b(x)\). In this case the earlier count is strictly below \(b(x)\), and ordinary subtraction gives \(r_b(s+1,x)=r_b(s,x)-1<r_b(s,x)\). If the bit stays fixed, the counts and reserves agree. Finally the initial count is zero, giving the initial-reserve identity.

Every revision must be paid for from the initial reserve

For any natural-valued countdown \(r\) for \(a\), whether computable or not,

\[c_a(s,x)+r(s,x)\le r(0,x)\qquad\text{for every }s,x.\]

Consequently \(c_a(s,x)\le r(0,x)\). A computable countdown therefore supplies the computable change bound \(b_r(x)=r(0,x)\).

Induct on \(s\), with \(x\) fixed. At stage zero the counter is zero. If the next guess agrees with the current one, the counter is unchanged and the reserve does not increase, preserving the inequality. If the guess changes, the counter increases by one, while strict decrease of natural numbers gives \(r(s+1,x)+1\le r(s,x)\). Adding these two inequalities proves the induction step. Dropping the nonnegative final reserve yields the counter bound. Evaluating a jointly computable \(r\) at stage zero computes \(b_r\).

Computable change bounds and computable countdowns describe the same class

A set \(A\) is \(\omega\)-c.e. if and only if some jointly computable binary approximation \(a\), starting at zero and converging to \(\chi_A\), has a computable natural-number countdown.

Given a computable change bound, use exactly \(r_b=b-c_a\) from . Given a computable countdown, use exactly its initial reserve \(b_r(x)=r(0,x)\), as proved in . Neither direction changes the approximation or its limit. Convergence to some binary limit is automatic from either form of bound by ; convergence to the specified \(A\) identifies which set is represented.

Every finite change class lies inside the computably bounded class

For every \(n\in\mathbb N\), \(\mathcal E_n\subseteq\mathcal E_\omega\), and every \(\omega\)-c.e. set is limit computable.

For an \(n\)-c.e. approximation take the constant computable bound \(b(x)=n\). Its computability, initial value and limit already have the required properties. For the second assertion, forget the change bound: the same computable binary approximation is a limit-computable presentation. These inclusions alone do not say whether every set in \(\mathcal E_\omega\) has some approximation with a constant change bound.

The second inclusion is strict: a diagonal construction against all proposed computable bounds gives a limit-computable set outside \(\mathcal E_\omega\).

A delayed complement adds one unit to the input's allowance

If \(a\) witnesses that \(A\) is \(\omega\)-c.e. with computable bound \(b\), then the delayed complement \(\bar a(0,x)=0\), \(\bar a(s+1,x)=1-a(s,x)\) witnesses that \(A^c\) is \(\omega\)-c.e. with bound \(b(x)+1\).

The established delayed-complement construction is jointly computable, binary, initial zero and converges to \(\chi_{A^c}\). Its exact count identity is \(c_{\bar a}(s+1,x)=1+c_a(s,x)\), since the original initial bit is zero. This is at most \(b(x)+1\), while its count at stage zero is zero. The new bound is total computable, so it supplies all the required data.

A computable translation transports the input-dependent allowance

If \(a\) witnesses that \(A\) is \(\omega\)-c.e. with computable bound \(b\), and \(f:\mathbb N\to\mathbb N\) is total computable, then \(f^{-1}(A)\) has the specified approximation \(a_f(s,x)=a(s,f(x))\) and computable bound \(b(f(x))\). Thus \(\mathcal E_\omega\) is closed under computable preimages.

The pullback construction preserves joint computability, binary values, the initial bit and convergence to the indicated preimage. Its counter is exactly \(c_{a_f}(s,x)=c_a(s,f(x))\), by induction on the stage. Applying the original bound at \(f(x)\) gives the asserted allowance. Composition computes \(b\circ f\).

Unions and intersections add the two input-dependent bounds

If \(a,d\) witness \(\omega\)-c.e. sets \(A,B\) with computable bounds \(b,c\), respectively, then \(\max(a,d)\) and \(\min(a,d)\), taken pointwise, witness \(A\cup B\) and \(A\cap B\) with computable bound \(b(x)+c(x)\).

The binary combination construction gives the stated limits and preserves computability and the initial zero. If an output bit changes, at least one of its two input bits changes at that transition. Thus each output counter is at most \(c_a(s,x)+c_d(s,x)\), as in the sum-of-counts estimate. Apply the two input-dependent bounds and compute their sum. Along with complements this gives closure under every fixed finite Boolean combination, by induction on that combination.

Join the diagonal escape sets into one membership problem

Use the uniform diagonal escape sets \(D_n\) and their specified approximations \(d_n(s,e)\). The diagonal join is

\[E=\{\langle n,e\rangle:e\in D_n\}.\]

With \(\pi_1,\pi_2\) denoting the two computable decoding maps for the fixed pairing bijection, define its join approximation and join bound by

\[h(s,z)=d_{\pi_1(z)}(s,\pi_2(z)),\qquad b_E(z)=\pi_1(z)+1.\]

The first coordinate determines the column and its permitted allowance. The preceding uniform construction provides a single jointly computable function of \(n,s,e\), so the displayed rule is one algorithm for \(h\).

The displayed join has a computable bound on every input

The specified \(h\) is jointly computable, binary and initial zero, has \(c_h(s,z)\le b_E(z)\) for all \(s,z\), and converges to \(\chi_E\). In particular \(E\in\mathcal E_\omega\).

Decode \(z=\langle n,e\rangle\). Its row is exactly \(d_n(s,e)\), so induction on the stage identifies its counter with \(c_{d_n}(s,e)\). The diagonal construction bounds that counter by \(n+1=b_E(z)\), starts at zero, and converges to the bit for \(e\in D_n\), which is the bit for \(z\in E\). Computable decoding and the joint computability of \((n,s,e)\mapsto d_n(s,e)\) compute \(h\). Decoding and successor compute \(b_E\). Every assertion concerns the displayed approximation and bound, rather than an unspecified replacement.

One computably bounded set escapes every fixed finite allowance

The specified set \(E\) is \(\omega\)-c.e. and is not \(n\)-c.e. for any \(n\in\mathbb N\). Hence \(\bigcup_{n<\omega}\mathcal E_n\) is a proper subclass of \(\mathcal E_\omega\).

Membership of \(E\) follows from . Fix \(n\), and consider the total computable map \(f_n(e)=\langle n,e\rangle\). The definition of the join gives \(f_n^{-1}(E)=D_n\). If \(E\) had an \(n\)-c.e. approximation, finite-level preimage closure would make \(D_n\) \(n\)-c.e., contrary to diagonal disagreement. This works for each fixed \(n\), proving exclusion from their union. The reverse inclusion follows from .

The availability of an \((n+1)\)-change approximation separately for each \(D_n\) would not by itself supply an algorithm for their join. Here joint computability was proved for the specified diagonal family before forming \(E\), so it justifies the actual join approximation.

Does an unbounded displayed allowance force escape from every finite level?

Suppose a computable change bound \(b(x)\) is unbounded as \(x\) varies. Must the limit set of the supplied approximation lie outside every finite change class?

Show answerHide answer

No. Take \(a(s,x)=0\) and \(b(x)=x\). The bound is computable and unbounded, but the counter is always zero and the limit is the empty set, already in \(\mathcal E_0\). A bound is an upper estimate and may waste arbitrarily many units. The join's exclusion from finite levels was proved by its diagonal columns; it does not follow merely from the unboundedness of \(b_E\).

Can the computed allowance reveal a computable final stage?

Does a computable change bound, or even a constant bound of one, provide a computable convergence modulus for a supplied approximation?

Show answerHide answer

No. The canonical increasing approximation to the halting set starts at zero and changes at most once on each input, so the constant bound one is computable. If it had a computable final-stage function \(m(x)\), evaluating that approximation at \(m(x)\) would decide the halting set. This contradicts halting undecidability, exactly as in the modulus argument. A countdown can remain positive forever when an input never enters the set; its unused units do not certify that no future revision will occur.
