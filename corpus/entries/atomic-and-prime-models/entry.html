Every realized finite description is isolated

Fix a satisfiable complete theory \(T\) in a countable first-order language \(L\). All models are nonempty, and “countable” includes finite. A model \(M\models T\) is atomic if, for every finite tuple \(\bar a\in M^n\), its complete type \(\operatorname{tp}^M(\bar a)\) is isolated: some formula \(\theta(\bar x)\) true at \(\bar a\) implies, modulo \(T\), every formula in that type.

Atomicity concerns the types actually realized in \(M\). It does not assert that every complete type of \(T\) is isolated. The empty tuple is included; its type is isolated by \(\top\), since completeness of \(T\) fixes the truth of every sentence. The definition itself does not require \(M\) to be countable.

A finite map preserving all formulas

For models \(M,N\models T\), a finite partial elementary map \(p:M\rightharpoonup N\) is a map with finite domain \(A\subseteq M\) such that, for every first-order formula \(\varphi(x_0,\ldots,x_{r-1})\) and tuple \(\bar a\in A^r\),

\[M\models\varphi(\bar a)\iff N\models\varphi(p(\bar a)).\]

The domain need not be a substructure. Equality formulas imply that \(p\) is injective, so it is a bijection from \(A\) to its finite image. Its inverse map has this image as domain and is again partial elementary, by the same equivalences in reverse. A restriction of \(p\) keeps its values on a subset of \(A\); the required equivalences are a subset of those already true for \(p\).

One such map extends another when it has the larger domain and retains every old value. The empty map between models of \(T\) is partial elementary: the only tuples to check have length zero, and the two models agree on sentences because \(T\) is complete.

Equal tuple types specify a finite elementary map

Tuples \(\bar a\in M^n\), \(\bar b\in N^n\) have the same complete type if and only if the assignment \(a_i\mapsto b_i\) is a well-defined partial elementary map between their ranges. Repeated coordinates are allowed.

If the types agree, they agree on every equality \(x_i=x_j\). Thus \(a_i=a_j\) exactly when \(b_i=b_j\), making the assignment well-defined and injective. For any finite tuple from the range of \(\bar a\), choose indices \(i_0,\ldots,i_{r-1}\) for its coordinates. A formula about that tuple becomes a formula about \(\bar a\) by substituting \(x_{i_0},\ldots,x_{i_{r-1}}\) for its displayed variables, avoiding capture as in semantic substitution. Equality of the original types gives the required truth equivalence for the selected tuple.

Conversely, apply partial elementarity to the tuple \(\bar a\) itself and every formula in those variables. The two tuples satisfy exactly the same formulas, which is equality of their complete types. For \(n=0\), this is the empty map and agreement on sentences.

Isolation separates into a tuple and its remaining parameters

For finite tuples \(\bar a,\bar b\) in a model \(M\models T\), the joint type \(\operatorname{tp}(\bar a,\bar b)\) is isolated if and only if both \(\operatorname{tp}(\bar a)\) and \(\operatorname{tp}(\bar b/\bar a)\) are isolated. A type over the tuple means the type over its finite set of coordinates, with those parameters fixed.

Suppose \(\theta(\bar x,\bar y)\) isolates the joint type. Then \(\exists\bar y\,\theta(\bar x,\bar y)\) is true at \(\bar a\). Any formula \(\rho(\bar x)\) true there also belongs to the joint type, so \(T\models\theta\to\rho\), with universal closure understood. Consequently \(T\models(\exists\bar y\,\theta)\to\rho\), giving an isolator for \(\operatorname{tp}(\bar a)\). The formula \(\theta(\bar a,\bar y)\) isolates the parameter type of \(\bar b\): every formula with those parameters can be written as \(\eta(\bar a,\bar y)\), and isolation of the joint type gives the corresponding implication after substituting \(\bar a\).

Conversely, let \(\psi(\bar x)\) isolate \(\operatorname{tp}(\bar a)\), and let \(\chi(\bar a,\bar y)\) isolate \(\operatorname{tp}(\bar b/\bar a)\). Their conjunction is true at \((\bar a,\bar b)\). For any \(\eta(\bar x,\bar y)\) true there, parameter isolation gives

\[M\models\forall\bar y\,(\chi(\bar a,\bar y)\to\eta(\bar a,\bar y)).\]

The displayed assertion is a formula about \(\bar a\), so its truth is forced by \(\psi\). Hence \(T\models(\psi(\bar x)\land\chi(\bar x,\bar y))\to\eta(\bar x,\bar y)\). This conjunction therefore isolates the joint type.

Atomicity can be checked one element at a time

A model \(M\models T\) is atomic if and only if \(\operatorname{tp}(b/A)\) is isolated for every finite \(A\subseteq M\) and every \(b\in M\).

If \(M\) is atomic, enumerate \(A\) by a finite tuple \(\bar a\). The joint type of \((\bar a,b)\) is isolated, so isolates the type of \(b\) over those parameters.

Conversely, induct on tuple length. The empty tuple has the isolator \(\top\). If the type of \(\bar a\) is isolated, the hypothesis isolates \(\operatorname{tp}(b/\bar a)\), and isolates the joint type of \((\bar a,b)\). This includes tuples with repeated coordinates and proves atomicity.

A model that embeds elementarily into every model

A model \(M\models T\) is prime if, for every model \(N\models T\), there is an elementary embedding \(M\to N\). Thus every formula about a tuple from \(M\) has the same truth value after the embedding. No inclusion of carriers is assumed, and the embedding need not be unique.

Atomicity is a condition on finite descriptions within a model. Primeness compares that model with every model of the theory. The following constructions connect these two conditions.

An atomic source lets a finite elementary map extend by one element

Let \(M\models T\) be atomic, let \(N\models T\), and let \(p:M\rightharpoonup N\) be finite partial elementary. For every \(a\in M\), there is a finite partial elementary extension \(q\supseteq p\) with domain \(\operatorname{dom}(p)\cup\{a\}\).

If \(a\) is already in the domain, retain \(p\). Otherwise enumerate its finite domain as \(\bar c\), allowing the tuple to be empty, and put \(\bar d=p(\bar c)\). Atomicity of the source \(M\) provides an isolating formula \(\theta(\bar x,y)\) for \(\operatorname{tp}^M(\bar c,a)\).

The formula \(\exists y\,\theta(\bar x,y)\) holds at \(\bar c\). Partial elementarity makes it true at \(\bar d\) in \(N\), so choose \(b\in N\) with \(N\models\theta(\bar d,b)\). Both joint tuples realize the type isolated by \(\theta\), and therefore have the same complete type. By , the assignment extending \(p\) by \(a\mapsto b\) is partial elementary.

It is genuinely a map with the claimed domain. In particular, the joint type contains each inequality \(y\ne x_i\), so its isolator forces \(b\ne d_i\) whenever \(a\) is a new domain element. Thus no old image point is reused.

A countable atomic model embeds while preserving a specified finite match

Let \(M\models T\) be countable and atomic, and let \(N\models T\). Every finite partial elementary map \(p:M\rightharpoonup N\) extends to an elementary embedding \(f:M\to N\) with \(f(a)=p(a)\) for every \(a\in\operatorname{dom}(p)\). Consequently \(M\) is prime.

Enumerate \(M\) as \(m_0,m_1,\ldots\), repeating elements if the domain is finite. Start with \(p_0=p\), and use to extend \(p_s\) to a finite partial elementary map \(p_{s+1}\) containing \(m_s\) in its domain. Every old assigned pair is retained.

The union \(f=\bigcup_s p_s\) is a function defined on all of \(M\). It is injective because any two domain elements occur together in one stage. For a finite tuple \(\bar a\), choose a stage containing all its coordinates, taking stage zero for the empty tuple. Partial elementarity there gives \(M\models\varphi(\bar a)\iff N\models\varphi(f(\bar a))\) for every formula. Thus \(f\) is elementary and preserves the original map \(p\).

To obtain primeness, begin with the empty partial elementary map. The target \(N\) was arbitrary.

Countable atomic models are isomorphic with any given finite match preserved

If \(M,N\models T\) are countable and atomic, every finite partial elementary map \(p:M\rightharpoonup N\) extends to an isomorphism \(f:M\cong N\). In particular, the countable atomic model is unique up to isomorphism. If tuples \(\bar a\in M^n\), \(\bar b\in N^n\) have the same complete type, the isomorphism may be required to satisfy \(f(a_i)=b_i\) for every coordinate.

Enumerate both carriers, repeating elements in a finite carrier. Starting with \(p\), alternate two operations. At a forth stage, use atomicity of \(M\) and to include the next source element in the domain. At a back stage, invert the current finite map, use atomicity of \(N\) to include the next target element in its domain, and invert back. Both operations retain every previously assigned pair.

The union is an elementary embedding by the finite-tuple argument in , and the back stages make it surjective. A bijective elementary embedding is an isomorphism: atomic formulas already preserve the interpreted functions and relations, and its inverse preserves them as well. The union extends the specified \(p\).

The empty map gives uniqueness without a prescribed match. For the tuple version, start with the finite partial elementary map from . In the case \(M=N\), this gives an automorphism sending the specified tuple to the other tuple.

For the resulting description of symmetries in a unique countable model, see complete types as automorphism orbits.

Prime models are exactly countable atomic models

For a satisfiable complete theory in a countable language, a model is prime if and only if it is countable and atomic.

The reverse implication is . For the forward implication, let \(M\) be prime. By downward Löwenheim–Skolem, \(T\) has a countable model \(N\). An elementary embedding \(M\to N\) is injective, so \(M\) is countable.

If some tuple \(\bar a\in M^n\) had a nonisolated complete type \(p\), the omitting types theorem, applied just to \(p\), would give a countable model \(N'\models T\) omitting it. Primeness supplies an elementary embedding \(f:M\to N'\). By preservation of tuple types, \(f(\bar a)\) realizes \(p\), a contradiction. Every realized finite-tuple type in \(M\) is therefore isolated.

Strengthening a possible formula to one complete description

An \(L\)-formula \(\varphi(\bar x)\) is consistent with \(T\) if some tuple in some model of \(T\) satisfies it. An isolating refinement of \(\varphi\) is a formula \(\psi(\bar x)\) consistent with \(T\) that isolates a complete type and satisfies

\[T\models\forall\bar x\,(\psi(\bar x)\to\varphi(\bar x)).\]

Say that \(T\) has isolating refinements if every \(T\)-consistent formula, in every finite tuple of variables, has one. Equivalently, every consistent formula belongs to some isolated complete type: its isolator then implies that formula; conversely, a refinement isolates a type containing the original formula.

A finite named condition can isolate the type of any named tuple

Suppose \(T\) has isolating refinements. Adjoin fresh constants \(C=\{c_0,c_1,\ldots\}\). If \(\Gamma\) is a finite set of \(L(C)\)-sentences with \(T+\Gamma\) satisfiable, then for any finite tuple \(\bar c\) of these names there is an isolating \(L\)-formula \(\psi(\bar x)\) such that \(T+\Gamma+\{\psi(\bar c)\}\) remains satisfiable. Repeated names and the empty tuple are allowed.

Take the formula \(\chi_{\Gamma,\bar c}(\bar x)\) from the finite-condition formula lemma. It says exactly that the old-language structure can be expanded to satisfy \(\Gamma\) while giving the indicated names the displayed tuple values. Since \(T+\Gamma\) has a model, \(\chi\) is consistent with \(T\).

Choose an isolating refinement \(\psi\) of \(\chi\). Its consistency gives \(M\models T\) and \(\bar a\) satisfying \(\psi\), hence \(\chi\). The defining equivalence for \(\chi\) supplies an expansion satisfying \(\Gamma\) with \(\bar c\) interpreted by \(\bar a\). That expansion also satisfies \(\psi(\bar c)\), proving satisfiability of the extended condition.

The formula \(\chi\) includes the equalities imposed by repeated names. Thus choosing a refinement cannot give contradictory values to two occurrences of the same name. No distinctness of names or their interpreted values has been assumed.

Every named tuple receives an isolating formula

An atomic construction task in \(L(C)\) is one of: decide a sentence; supply a conditional witness \((\exists z\,\eta(z))\to\eta(c_k)\); or add an isolating formula \(\psi(\bar c)\) for a specified finite tuple of names \(\bar c\). The third task permits repeated indices and includes every tuple length, including zero.

These tasks form a countable set. The first two sets are countable by the countable-language enumeration. The index tuples for the third form \(\bigcup_{n<\omega}\mathbb N^n\), a countable union of countable sets. Fix a sequence containing every task.

An atomic finite-stage construction is an increasing sequence of finite conditions \(\Gamma_s\), starting with \(\Gamma_0=\varnothing\), such that \(T+\Gamma_s\) is satisfiable and the next stage meets the scheduled task. Use the decision-and-witness lemma to decide sentences and choose fresh witness names; for the third task use the isolating-extension lemma. These rules recursively produce such a sequence whenever \(T\) has isolating refinements. Each stage adds one sentence, so its added condition stays finite.

The named model of the construction is atomic

If \(T\) has isolating refinements, an atomic finite-stage construction produces a nonempty countable atomic model of \(T\).

Let \(U=T\cup\bigcup_s\Gamma_s\). Every finite subset lies in some satisfiable \(T+\Gamma_s\), using stage zero if there are no added sentences, so compactness gives an \(L(C)\)-model \(N^*\models U\). Let \(N\) be its \(L\)-reduct, and let \(S=\{c_k^{N^*}:k\in\mathbb N\}\).

The set \(S\) is nonempty and countable. It is a substructure because the witness task for \(z=f(\bar c)\) names every old function value on named arguments, including old constants when the argument tuple is empty. For any existential \(L\)-formula with parameters from \(S\), choose names for its parameter tuple. Its conditional witness task names a witness whenever the existential formula holds. Thus the Tarski–Vaught criterion gives \(S\preccurlyeq N\), and \(S\models T\). This is exactly the named-model argument, which uses only the witness tasks.

Now take any finite tuple \(\bar a\) from \(S\) and choose a tuple of names \(\bar c\) with those values. The task for that very name tuple adds some isolating formula \(\psi(\bar c)\) to \(U\). Hence \(N\models\psi(\bar a)\), and elementarity gives \(S\models\psi(\bar a)\). An isolator has only one complete type containing it, so \(\operatorname{tp}^S(\bar a)\) is that isolated type. Every finite tuple is covered, including tuples requiring repeated names. Therefore \(S\) is atomic.

Exactly the theories with isolating refinements have prime models

For a satisfiable complete theory \(T\) in a countable language, the following are equivalent: \(T\) has isolating refinements; \(T\) has a nonempty countable atomic model; \(T\) has a prime model.

Isolating refinements give a countable atomic model by . A countable atomic model is prime, and a prime model is countable and atomic, by .

For the remaining implication, let \(M\models T\) be atomic, and let \(\varphi(\bar x)\) be consistent with \(T\). The sentence \(\exists\bar x\,\varphi\) is true in some model of \(T\); completeness therefore makes it true in every model, including \(M\). Choose \(\bar a\) in \(M\) satisfying \(\varphi\). An isolator \(\psi\) of \(\operatorname{tp}^M(\bar a)\) is consistent and implies \(\varphi\), because \(\varphi\) belongs to that type. It is the required refinement.

The construction uses countably many tuple requirements, rather than a request to omit an arbitrary collection of nonisolated types.

Having only countably many complete types in each finite context is one useful sufficient condition: the small-theory construction omits all nonisolated types to obtain a countable atomic and prime model.

The independent-predicate theory gives an example with no isolated one-types and hence no prime model.

Is the real order prime because its tuple types are isolated?

Both structures are atomic: the finite ordered equality patterns isolate every realized finite-tuple type, including repeated coordinates. The rational order is countable, so makes it prime.

The real order is uncountable and cannot embed injectively into the countable rational order, which is another model of the same complete theory. It is therefore not prime, in agreement with . Atomicity alone, without countability, does not imply primeness.

The fully named rational order gives another comparison: it is prime, and its theory has no countable saturated model.
