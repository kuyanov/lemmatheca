Realize every description using finitely many parameters

Fix a nonempty first-order \(L\)-structure \(M\). For \(A\subseteq M\), recall the named expansion \(M_A\) and the complete types \(S_n^M(A)=S_n(\operatorname{Th}(M_A))\). We work with classical choice. No countability assumption on \(L\) is made in this entry.

The structure \(M\) is \(\omega\)-saturated if, for every finite \(A\subseteq M\), every complete one-type over \(A\) is realized in \(M\):

\[\forall A\subseteq M\text{ finite}\;\forall q\in S_1^M(A)\;\exists b\in M\quad \operatorname{tp}^M(b/A)=q.\]

When the carrier is countable, we also call such a structure saturated in this entry. For an uncountable carrier we retain the explicit term “\(\omega\)-saturated”. Each type may contain infinitely many formulas; it is the set of available parameters that is required to be finite.

Every nonempty structure has an omega-saturated elementary extension. That general existence theorem imposes no bound on the size of the extension.

Complete types can be replaced by partial types

The structure \(M\) is \(\omega\)-saturated if and only if every partial one-type over every finite parameter set \(A\subseteq M\) is realized in \(M\). In particular, every finite nonempty structure is \(\omega\)-saturated.

Every partial type has a complete extension. A tuple realizing that extension realizes the original collection of conditions. Conversely a complete type is a partial type, and a realization determines exactly that complete type. For a finite structure, every partial type in finitely many variables is already realized, so the one-variable condition follows.

Preserve every formula on a finite domain

Let \(M,N\) be nonempty \(L\)-structures. A finite partial elementary map is a bijection \(f:A\to B\), with finite \(A\subseteq M\) and \(B\subseteq N\), such that, for every \(L\)-formula \(\varphi(x_0,\ldots,x_{r-1})\) and tuple \(\bar a\in A^r\),

\[M\models\varphi[\bar a]\quad\Longleftrightarrow\quad N\models\varphi[f(\bar a)].\]

The empty tuple is included. The finite sets need not be closed under functions or contain language constants. Terms and quantifiers are evaluated in the ambient structures. Every such map is therefore a finite partial isomorphism, with preservation strengthened from atomic formulas to all formulas.

A map \(g\) extends \(f\) if it has a larger domain and assigns the same value to every element of \(A\). We write \(f\subseteq g\), identifying a map with its graph.

This is the finite partial elementary map notion used for atomic models, applied here to the specified structures. Saturation supplies another hypothesis for extending these maps.

Start from the empty map and reverse a finite map

The empty map from \(M\) to \(N\) is partial elementary exactly when \(M\equiv N\). The inverse of a finite partial elementary map is partial elementary, as is its restriction to any subset of its domain.

On the empty domain the only available tuples have length zero, so the defining condition is agreement on all sentences: elementary equivalence. For the inverse, lift a tuple from the range through the finite bijection and reverse the same truth equivalence. For a restriction, every tuple in the smaller domain was already a tuple in the original domain.

Transport a type along the given finite elementary map

Let \(f:A\to B\) be a finite partial elementary map from \(M\) to \(N\). Replace each parameter name \(c_a\) by \(c_{f(a)}\), keeping the original language symbols and displayed variables. Write \(\varphi^f\) for this renaming. For every \(q\in S_n^M(A)\), its pushforward type

\[f_*q=\{\varphi^f:\varphi\in q\}\]

belongs to \(S_n^N(B)\). Renaming back with \(f^{-1}\) recovers \(q\).

Consider finitely many formulas from \(f_*q\), and choose their preimages \(\varphi_0,\ldots,\varphi_{k-1}\in q\). By the finite parameter-type test, their conjunction has a realizing tuple in \(M\). Equivalently the sentence with parameters \(\exists\bar x\,\bigwedge_{i<k}\varphi_i\) is true in \(M_A\). Replace its finitely many parameter names by free variables. Partial elementarity of \(f\) transfers that formula, with those parameter values, to \(N\). Thus the renamed conjunction has a solution in \(N_B\).

The same finite test proves consistency over \(\operatorname{Th}(N_B)\). Renaming by a bijection of parameter names is a bijection on formulas and commutes with negation. Since \(q\) decides every formula, the consistent set \(f_*q\) does too, and is complete. Applying the inverse renaming restores every original formula and hence the original type. Empty conjunctions and zero-variable types obey the same argument.

One realized type extends the specified map by one point

Suppose \(N\) is \(\omega\)-saturated and \(f:A\to B\) is a finite partial elementary map from \(M\) to \(N\). For every \(a\in M\), there are \(b\in N\) and a finite partial elementary map

\[f':A\cup\{a\}\longrightarrow B\cup\{b\},\qquad f'\!\upharpoonright A=f,\qquad f'(a)=b.\]

If \(a\notin A\), the chosen \(b\) lies outside \(B\).

If \(a\in A\), take \(b=f(a)\) and \(f'=f\). Otherwise put \(q=\operatorname{tp}^M(a/A)\). By , \(f_*q\in S_1^N(B)\). Since \(B\) is finite, choose a realization \(b\in N\) using \(\omega\)-saturation. Each inequality \(x\ne c_d\), for \(d\in A\), belongs to \(q\), so \(b\ne f(d)\) for every old domain point. Thus adjoining \(a\mapsto b\) gives a bijection of the displayed finite sets.

To check all formulas, take a tuple from \(A\cup\{a\}\) and a formula \(\theta\) on that tuple. Replace every occurrence of the new value \(a\) in its tuple by one variable \(x\), and replace each remaining coordinate by its parameter name from \(A\). This gives an \(L(A)\)-formula \(\psi(x)\), possibly using \(x\) several times or not at all. Truth of \(\theta\) in \(M\) is membership of \(\psi\) in \(q\); truth after applying \(f'\) in \(N\) is membership of \(\psi^f\) in the type of \(b\), which is \(f_*q\). The two assertions agree, so \(f'\) is partial elementary.

One-variable saturation already realizes every finite tuple type

A nonempty structure \(M\) is \(\omega\)-saturated if and only if, for every finite \(A\subseteq M\) and every natural number \(n\), every partial \(n\)-type over \(A\) in \(M\) is realized in \(M\).

Assume \(\omega\)-saturation. By elementary realization, realize the given type by \(\bar c\) in an elementary extension \(M\preccurlyeq E\). The identity on the finite set \(A\) is a partial elementary map from \(E\) to \(M\). Apply successively to \(c_0,\ldots,c_{n-1}\), always taking \(E\) as source and \(M\) as target. Each intermediate domain is finite. Previously assigned values stay fixed, including all parameters in \(A\).

The final map sends \(\bar c\) to a tuple \(\bar b\in M^n\). Partial elementarity, with the fixed parameters from \(A\), transfers every formula of the original type to \(\bar b\). Coordinates may repeat or already belong to \(A\); the first case of the extension lemma handles both. When \(n=0\), the identity on \(A\) already transfers all the required sentences, so the empty tuple realizes the type. Conversely, apply the displayed property at \(n=1\) to complete types.

Naming finitely many points preserves saturation

If \(M\) is \(\omega\)-saturated and \(C\subseteq M\) is finite, the named expansion \(M_C\), in the language \(L(C)\), is \(\omega\)-saturated. More generally, adjoining finitely many constant symbols with chosen interpretations preserves \(\omega\)-saturation, even when several symbols name the same element.

Take a partial one-type over a finite \(B\subseteq M_C\). Its formulas use original \(L\)-symbols, the already named elements of \(C\), and the additional parameters from \(B\). Regard every such name instead as a parameter name from the finite union \(B\cup C\), identifying names with the same interpreted value. For arbitrary finitely many new constant symbols, replace \(C\) by the finite set of their interpreted values. This produces a collection of \(L(B\cup C)\)-formulas.

Every finite part has a solution in \(M\): the original finite part has a solution in \((M_C)_B\) by the parameter-type test, and interpreting the renamed constants by the same elements changes no truth value. The renamed collection is therefore a partial type over \(B\cup C\) in \(M\). Realize it using . The same point satisfies all original formulas in \((M_C)_B\). The partial-type test, now for the language \(L(C)\), proves the assertion.

The example of naming all rationals shows that an infinite family of new constant symbols can destroy omega-saturation.

Isomorphic structures have the same saturation property

If the specified map \(h:M\to N\) is an isomorphism, then \(M\) is \(\omega\)-saturated if and only if \(N\) is \(\omega\)-saturated.

Assume \(M\) is \(\omega\)-saturated. Given finite \(B\subseteq N\), let \(A=h^{-1}[B]\), which is finite because \(h\) is a bijection. Restricting \(h\) gives a finite partial elementary bijection \(A\to B\), since an isomorphism is elementary. Pull any \(q\in S_1^N(B)\) back along its inverse using . Realize the resulting type by \(a\in M\). Isomorphism invariance of formulas, with these same renamed parameters, says that \(h(a)\) realizes \(q\). This proves saturation of \(N\). Apply the same argument to \(h^{-1}\) for the converse.

Build an elementary embedding by answering every source request

Let \(M\) have countable carrier and let \(N\) be \(\omega\)-saturated. Every finite partial elementary map \(f\) from \(M\) to \(N\) extends to an elementary embedding \(e:M\to N\). Consequently, if \(M\equiv N\), such an embedding exists.

List \(M\) as \(a_0,a_1,\ldots\), allowing repetitions for a finite carrier. Start from the prescribed \(f_0=f\). Given \(f_i\), use to obtain \(f_{i+1}\) extending it with \(a_i\) in its domain. A repeated request leaves the map unchanged. Every stage has finite domain, so saturation applies at every step.

The union \(e=\bigcup_{i<\omega}f_i\) is a total function because every source point was requested, and compatibility makes its value independent of the stage. Any two arguments occur in one stage, so stagewise injectivity makes \(e\) injective. Any finite tuple also occurs together in one stage: take the maximum of its finitely many first-appearance indices. All formulas on that tuple agree in the two structures because that stage is partial elementary.

In particular, applying this agreement to relations on variables and to \(y=g(\bar x)\), with the function value included in the tuple, proves preservation of the language operations and relations, including constants and nullary relations. Thus \(e\) is an elementary embedding and extends the original \(f\). When \(M\equiv N\), supplies the empty initial map. The target need not have countable carrier.

For the condition ensuring a countable saturated target exists, see the countable saturation existence criterion.

Use requests from both sides to obtain an isomorphism

If \(M,N\) have countable carriers and both are \(\omega\)-saturated, every finite partial elementary map \(f\) from \(M\) to \(N\) extends to an isomorphism \(M\cong N\). In particular, elementarily equivalent countable saturated structures are isomorphic.

Enumerate both carriers, allowing repetitions. Begin with the specified \(f\). At even steps, use saturation of \(N\) to put the next point of \(M\) into the domain. At odd steps, invert the current finite elementary map, use saturation of \(M\) to put the next point of \(N\) into that inverse domain, and then invert back. This answers a range request while preserving every previous assignment.

The family of all finite partial elementary maps is nonempty, since it contains \(f\), and satisfies these two extension requirements. It is therefore a back-and-forth system after forgetting all-formula preservation down to atomic preservation. The countable back-and-forth theorem gives an isomorphism extending the original map; equivalently their compatible union is bijective and preserves every interpretation. For the final assertion, elementary equivalence again supplies the empty map. No enumeration of formulas or language symbols is used.

Equal finite-tuple types give an automorphism with the required values

Let \(M\) be countable and \(\omega\)-saturated, let \(A\subseteq M\) be finite, and let \(\bar a,\bar b\in M^n\) have the same complete type over \(A\). There is an automorphism \(g\) of \(M\) fixing \(A\) pointwise and satisfying \(g(a_i)=b_i\) for every \(i<n\).

On \(A\cup\{a_i:i<n\}\), send every point of \(A\) to itself and each \(a_i\) to \(b_i\). Equality of types preserves the equations \(x_i=x_j\) and \(x_i=c_d\) for \(d\in A\), and their negations. Thus these assignments give a well-defined bijection onto \(A\cup\{b_i:i<n\}\), including when coordinates repeat or meet \(A\).

A formula on a tuple from the displayed finite domain can be written as an \(L(A)\)-formula on \(\bar a\): replace domain coordinates in \(A\) by their parameter names and the others by the appropriate tuple coordinates. Its renamed image is the same formula on \(\bar b\). Equality of the two types therefore makes the prescribed map partial elementary. Apply with source and target both \(M\). The resulting automorphism has exactly the required old values. For empty tuples this gives an automorphism fixing \(A\), with no extra coordinate requirements.

For finite parameters in a countable omega-saturated model, complete types are exactly the parameter-fixing automorphism orbits.

Does compactness make the standard natural numbers saturated?

Is the standard arithmetic structure \(\mathbb N_A\) \(\omega\)-saturated? Here the subscript denotes its arithmetic language, not a named parameter set.

Show answerHide answer

No. The partial type \(p(x)=\{x\ne\overline{k}:k\in\mathbb N\}\) uses no parameters and is finitely realized in \(\mathbb N_A\), but no standard natural number realizes all its conditions. This contradicts if \(\mathbb N_A\) were \(\omega\)-saturated. Equivalently, complete \(p\) over \(\operatorname{Th}(\mathbb N_A)\); that complete one-type is omitted by the standard structure.

Compactness realizes the type in an elementary extension. Saturation demands a realization in the specified structure itself. In contrast, finite nonempty structures are saturated by , even though they cannot realize a consistent description demanding an element different from every point of their domain: that last description already has an unrealizable finite subset.
