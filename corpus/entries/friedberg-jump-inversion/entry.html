Every jump can decide ordinary halting

For every set \(X\subseteq\mathbb N\), the ordinary diagonal halting set \(K\) satisfies \(K\le_T X'\). Consequently, if \(X'\equiv_T B\), then \(K\le_T B\).

The empty set reduces to \(X\) by the constant-zero program. Jump monotonicity therefore gives \(J(\varnothing)\le_T X'\). The ordinary halting recoding gives \(K\equiv_T J(\varnothing)\). Composing these actual reductions proves the first assertion; composing once more with \(X'\le_T B\) proves the consequence.

Append one chosen bit after each deterministic generic extension

Fix a set \(B\subseteq\mathbb N\) and a finite binary word \(\rho\). Use exactly the deterministic selector \(H\): it chooses the word coordinate of the least successful numerical pair candidate, or keeps the current word if no extension belongs to the designated c.e. collection. Define the coding history by

\[\sigma_0=\rho,\qquad\tau_n=H(n,\sigma_n),\qquad\sigma_{n+1}=\tau_n\chi_B(n).\]

The last expression appends one bit. The construction itself depends on \(B,\rho\), and the fixed \(H\); a program witnessing \(K\le_T B\) will be needed to compute it from \(B\). Define the coded set \(G_{B,\rho}\) by

\[\chi_{G_{B,\rho}}(x)=\sigma_{x+1}(x).\]

The length and compatibility assertions below justify this bit and identify the set with the union of the stage words. A numerical initial input is normalized by the established map \(N\); for the supplied valid word code \(u_\rho\), normalization leaves that code unchanged.

Each stage preserves the old prefix and records its coding bit

Every stage word is binary, and for all \(n\),

\[\sigma_n\preceq\tau_n\preceq\sigma_{n+1},\qquad|\sigma_{n+1}|=|\tau_n|+1,\qquad|\sigma_n|\ge|\rho|+n.\]

The set \(G_{B,\rho}\) extends every \(\sigma_n\), is the unique such set, and satisfies

\[\chi_{G_{B,\rho}}(|\tau_n|)=\chi_B(n).\]

Begin with the supplied binary word. The selector returns a binary extension; appending a characteristic bit preserves validity and increases length by one. These facts inductively prove the prefix and length assertions. In particular \(|\sigma_{x+1}|>x\), so the bit defining the union exists. The compatible-union lemma gives existence, extension of every stage word and uniqueness.

Position \(|\tau_n|\) is the new last position of \(\sigma_{n+1}\). Its bit is exactly the appended \(\chi_B(n)\), and the union preserves it. This proves the coding identity for the same set defined above.

The coding bits do not disrupt genericity

For every \(B\) and finite binary \(\rho\), the set \(G_{B,\rho}\) is 1-generic and extends \(\rho\).

At stage \(e\), \(\tau_e\) belongs to the densification \(S_e^*\). If \(\tau_e\in S_e\), the union meets \(S_e\). Otherwise no extension of \(\tau_e\) belongs to \(S_e\), so the union avoids it above that prefix. Appending either bit preserves the selected word, and all later stages preserve it as well. Every c.e. collection occurs as some \(S_e\), so these permanent alternatives give 1-genericity. The initial word is preserved by the same prefix invariant.

A supplied halting decider replaces the selector's oracle queries

Suppose an actual finite oracle program \(d\) witnesses \(K\le_T B\), so

\[E_B(d,q)\downarrow=\chi_K(q)\qquad\text{for every }q.\]

For the already fixed selector program \(h\), define \(h[d]=\operatorname{subst}(d,h)\). Then

\[E_B(h[d],\langle e,u\rangle)\downarrow=H(e,u)\qquad\text{for every }e,u.\]

The actual query-substitution theorem identifies this evaluation with \(E_K(h,\langle e,u\rangle)\), including all intermediate query answers. The specified selector identity identifies that value with \(H(e,u)\). Forming \(h[d]\) is an ordinary effective operation on the supplied finite program; it uses neither \(B\) nor an oracle to find a reduction witness.

One program family computes the exact coding history

From the supplied program \(d\), one can form an actual program \(C_d\), independently of \(B\) and \(\rho\), such that whenever \(d\) computes \(\chi_K\) under \(B\),

\[E_B(C_d,\langle u_\rho,n\rangle)\downarrow=\langle n,u_{\sigma_n}\rangle\qquad\text{for every valid }\rho\text{ and }n.\]

Keep both the stage counter and current word in the recursion state. Let \(f\) be a fixed ordinary program for the total finite operation

\[F(\langle n,\langle v,b\rangle\rangle)=\langle n+1,\operatorname{appendBit}(v,b)\rangle.\]

The established coded append operation reduces an arbitrary numerical \(b\) modulo two; an actual query answer already is a bit. Let \(I\) be the identity program, and let \(\iota\) embed an ordinary program into the oracle syntax. The base program \(b_0=\operatorname{pair}(\mathbf0,\iota(N))\) returns the state \(\langle0,N(u_\rho)\rangle\). Here and below an embedded numerical function denotes one fixed ordinary program computing that function.

A primitive-recursion step receives \(\langle u_\rho,\langle n,s\rangle\rangle\), where \(s\) is the previous state. Define the actual projection programs

\[S=\operatorname{comp}(\mathbf R,\mathbf R),\qquad J=\operatorname{comp}(\mathbf L,\mathbf R).\]

Thus \(S\) returns \(s\), while \(J\) returns \(n\). Form

\[T_d=\operatorname{comp}(h[d],S),\qquad M_d=\operatorname{pair}(T_d,\operatorname{comp}(\mathbf Q,J)),\]
\[V_d=\operatorname{comp}(\iota(f),\operatorname{pair}(J,M_d)),\qquad C_d=\operatorname{prec}(b_0,V_d).\]

Induct on \(n\), with the stated evaluation as the induction invariant. Initially normalization fixes the valid input word. If the old state is \(\langle n,u_{\sigma_n}\rangle\), the transported selector returns exactly \(u_{\tau_n}\), and the direct query at \(n\) returns \(\chi_B(n)\). The finisher therefore returns \(\langle n+1,u_{\tau_n\chi_B(n)}\rangle\), exactly the next state. Every call terminates by the supplied reduction hypothesis and selector totality. This proves the identity for this finite program family.

The same history gives a characteristic program under B

There is an actual program family \(A_d\) such that, under the same reduction hypothesis,

\[E_B(A_d,\langle u_\rho,x\rangle)\downarrow=\chi_{G_{B,\rho}}(x).\]

Consequently \(G_{B,\rho}\le_T B\).

Use the ordinary maps \(a(\langle u,x\rangle)=\langle u,x+1\rangle\) and \(v(\langle\langle u,x\rangle,\langle n,w\rangle\rangle)=\beta(w,x)\), where \(\beta\) is the established finite-word bit function. Define

\[A_d=\operatorname{comp}\bigl(\iota(v),\operatorname{pair}(I,\operatorname{comp}(C_d,\iota(a)))\bigr).\]

The inner call computes precisely the stage-\(x+1\) state. The output map reads its word at \(x\); the length invariant makes that position available. The union's defining bit identity therefore gives the claimed total characteristic evaluation. Hard-code the finite initial word \(u_\rho\) to obtain a unary reduction program.

Reconstruct a history by reading the bit after each selected extension

For any set \(X\) and supplied binary word \(\rho\), define the recovery history by

\[\eta_0=\rho,\qquad\theta_n=H(n,\eta_n),\qquad b_n=\chi_X(|\theta_n|),\qquad\eta_{n+1}=\theta_nb_n.\]

Every \(\eta_n\) and \(\theta_n\) is a binary word, by selector validity and the bit-valued query. These equations give a total history from \(X\oplus K\): the halting component computes the fixed \(H\), and the other component supplies the indicated bit. The recovery history is defined even when \(X\) is not one of the coded sets.

For the coded union, recovery follows the same words exactly

Take \(X=G_{B,\rho}\). At every stage the recovery history satisfies

\[\eta_n=\sigma_n,\qquad\theta_n=\tau_n,\qquad b_n=\chi_B(n).\]

The initial words agree. Suppose \(\eta_n=\sigma_n\). Both constructions now apply the identical deterministic function \(H\) at the same index to that same word, so \(\theta_n=\tau_n\). The coding-bit identity gives \(\chi_{G_{B,\rho}}(|\theta_n|)=\chi_B(n)\). Appending that bit gives \(\eta_{n+1}=\sigma_{n+1}\), completing the induction.

This argument uses the fixed first-candidate rule. Merely choosing some word in the same densification in each computation would not identify the coding position.

A fixed actual decoder reads B from the coded set joined with K

There are fixed actual programs \(D,R\), independent of \(B\) and its reduction witness, with the following evaluations. For every \(X\), the program \(D\) under \(X\oplus K\) returns \(\langle n,u_{\eta_n}\rangle\) on \(\langle u_\rho,n\rangle\). The program \(R\) returns the bit \(b_n\) from that recovery history. In particular,

\[E_{G_{B,\rho}\oplus K}(R,\langle u_\rho,n\rangle)\downarrow=\chi_B(n).\]

Use the even/odd join. Let \(Q_0,Q_1\) query positions \(2x,2x+1\), respectively, on input \(x\). These are actual programs obtained by ordinary preprocessing followed by \(\mathbf Q\). Under \(X\oplus K\), their outputs are \(\chi_X(x),\chi_K(x)\). Put \(h_1=\operatorname{subst}(Q_1,h)\), so the substitution identity makes it compute exactly \(H\) using the odd component.

Let \(\ell\) be a fixed ordinary program computing word-code length. Define a state-reading program and the step helpers

\[P=\operatorname{comp}\bigl(Q_0,\operatorname{comp}(\iota(\ell),h_1)\bigr),\qquad T=\operatorname{comp}(h_1,S),\]
\[M=\operatorname{pair}(T,\operatorname{comp}(P,S)),\qquad V=\operatorname{comp}(\iota(f),\operatorname{pair}(J,M)).\]

Use the same base \(b_0\), finisher \(f\), and projections \(S,J\) as in the coding program, and set \(D=\operatorname{prec}(b_0,V)\), \(R=\operatorname{comp}(P,D)\). Inductively, the old state is \(\langle n,u_{\eta_n}\rangle\). The two occurrences of \(h_1\) compute the same \(\theta_n\); \(P\) reads the even-component bit at its length. The finisher appends that bit and increments the counter, exactly implementing the recovery recurrence. Both selector calls terminate for every \(X\), because the odd component is \(K\). The final composition reads \(b_n\) from the stage-\(n\) state.

Thus the decoder has the asserted complete evaluations under every \(X\oplus K\). For the particular coded union, identifies its output with \(\chi_B(n)\). Hard-coding \(u_\rho\) gives the required reduction of \(B\) to \(G_{B,\rho}\oplus K\).

The coded set together with halting recovers exactly B

If \(d\) witnesses \(K\le_T B\), then the specified set satisfies

\[B\equiv_T G_{B,\rho}\oplus K.\]

The fixed decoder gives \(B\le_T G_{B,\rho}\oplus K\). Conversely, the characteristic program gives \(G_{B,\rho}\le_T B\), and the supplied \(d\) gives \(K\le_T B\). The common-upper-bound program for the join combines these reductions into \(G_{B,\rho}\oplus K\le_T B\). These comparisons concern the same constructed set, coding history and decoder.

Every problem above halting is a jump of a strictly weaker oracle

For every set \(B\) with \(K\le_T B\) and every finite binary word \(\rho\), the specified set \(G_{B,\rho}\) is 1-generic, extends \(\rho\), and satisfies

\[G_{B,\rho}'\equiv_T B,\qquad G_{B,\rho}<_T B.\]

Choose an actual finite program \(d\) witnessing the given reduction. Genericity and the generalized-low identity give \(G_{B,\rho}'\equiv_T G_{B,\rho}\oplus K\). The exact-join theorem identifies the latter degree with that of \(B\), proving jump inversion for this constructed set.

The stage program already gives \(G_{B,\rho}\le_T B\). If \(B\le_T G_{B,\rho}\), then \(G_{B,\rho}'\le_T B\le_T G_{B,\rho}\), contradicting jump strictness. Hence the upper comparison is strict. The construction's set is chosen from \(B,\rho\); its computation uses the supplied program \(d\), while the decoder is fixed independently of that witness.

The range of the degree jump is exactly the cone above zero-prime

For every Turing degree \(\mathbf b\),

\[\exists\mathbf a\;(\mathbf a'=\mathbf b)\quad\Longleftrightarrow\quad\mathbf0'\le\mathbf b.\]

For the forward implication choose a representative \(X\) of \(\mathbf a\). The necessary lower bound gives \(K\le_T X'\), so \(\mathbf0'\le\mathbf a'=\mathbf b\). Conversely choose a representative \(B\) of \(\mathbf b\). The representative interpretation of the degree order turns \(\mathbf0'\le\mathbf b\) into \(K\le_T B\). Jump inversion with the empty initial word yields a set \(G\) whose jump is Turing equivalent to \(B\); the well-defined degree jump therefore sends \([G]\) to \(\mathbf b\).

The effective program construction takes a supplied reduction witness. This degree statement makes an existence assertion and does not supply numerical program data merely from an unnamed degree.

Does inversion require B to be strictly above ordinary halting?

Can the construction be applied at \(B=K\), with any supplied finite binary word? What does it give?

Show answerHide answer

The query program witnesses \(K\le_T K\), so the hypotheses include this endpoint. The constructed set is 1-generic and extends the prescribed word, with \(G_{K,\rho}'\equiv_T K\) and \(G_{K,\rho}<_T K\). It is noncomputable by generic noncomputability, and its displayed jump identity says it is low. Thus the result does not require a strict inequality in its hypothesis.

Can two different degrees have the same jump?

If \(A'\equiv_T C'\), must \(A\equiv_T C\)? Is an inverse degree in jump inversion uniquely determined?

Show answerHide answer

No. Take \(A=\varnothing\), and let \(C\) be a specified noncomputable low generic. Then \(A'\equiv_T K\equiv_T C'\). But \(A\) is computable and \(C\) is not, so the computable-degree characterization excludes \(A\equiv_T C\). The degree jump is therefore not injective, and even the jump degree \(\mathbf0'\) has distinct inverse degrees.
