Counting complete descriptions

Throughout, \(L\) is a countable first-order language and \(T\) is a complete satisfiable \(L\)-theory. All structures are nonempty. Countable includes finite. Write \(S_n(T)\) for the complete types in the fixed context \(x_0,\ldots,x_{n-1}\).

The theory \(T\) is small if \(S_n(T)\) is countable for every natural number \(n\). The condition includes \(n=0\); completeness makes that type set a singleton. Countability of the language gives only countably many individual formulas. It does not by itself give only countably many complete types, which are sets of formulas.

For a model \(M\models T\) and a subset \(A\subseteq M\), retain the notation \(S_n^M(A)=S_n(\operatorname{Th}(M_A))\) from types over parameters. The subscripted structure interprets a new constant \(c_a\) by each \(a\in A\).

The independent-predicate example has a countable language and continuum many complete one-types.

A finite list of parameters can become extra coordinates

Let \(M\models T\), let \(A\subseteq M\) be finite, and let \(\bar a=(a_0,\ldots,a_{m-1})\) enumerate \(A\) without repetition. For every finite \(r\), there is an injection

\[S_r^M(A)\longrightarrow S_{r+m}(T).\]

Given \(p\in S_r^M(A)\), realize it in an elementary extension \(M\preccurlyeq N\), say by \(\bar b\). Choose one such realization for each \(p\), and send \(p\) to \(q=\operatorname{tp}^N_T(\bar b,\bar a)\).

To recover \(p\), take any \(L(A)\)-formula \(\varphi(\bar x)\). Replace each constant \(c_{a_j}\) by the extra free variable \(y_j\), obtaining an \(L\)-formula \(\widehat\varphi(\bar x,\bar y)\). This is a syntactic operation: old function and relation symbols stay fixed, constants in \(A\) become the indicated variables, and quantified variables stay quantified. Induction on terms and formulas gives

\[N_A\models\varphi[\bar b]\quad\Longleftrightarrow\quad N\models\widehat\varphi[\bar b,\bar a].\]

At a quantifier, the added free coordinates retain their assigned parameter values while the quantified coordinate varies. Consequently \(\varphi\in p\) if and only if \(\widehat\varphi\in q\). Equal image types therefore recover equal original types, proving injectivity. This argument also handles an empty parameter list or an empty tuple of object variables.

There are countably many requests over a countable model

If \(T\) is small and \(M\models T\) is countable, then the set of pairs \((A,p)\), where \(A\subseteq M\) is finite and \(p\in S_1^M(A)\), is countable.

For each finite \(A\), the injection just proved embeds \(S_1^M(A)\) into \(S_{1+|A|}(T)\), a countable set. The finite subsets of a countable set form a countable set: enumerate their finite lists and then forget the order and repetitions. A countable union of countable sets is countable, so all the pairs can be put in one list \((A_s,p_s)\), \(s\in\mathbb N\). Repetitions are harmless.

The same proof counts types in any fixed finite tuple context over each finite \(A\). We use one-variable requests because the definition of omega-saturation asks for those.

One request can be met without losing countability

Let \(M\preccurlyeq N\) be countable models of \(T\), let \(A\subseteq M\) be finite, and let \(p\in S_1^M(A)\). There is a countable elementary extension \(N\preccurlyeq N'\) containing a realization of \(p\), with each parameter from \(A\) kept fixed.

Every finite part of \(p\) is realized in \(M_A\) by the finite parameter test, and hence in \(N_A\) by elementarity. The elementary realization theorem gives an elementary extension \(N\preccurlyeq P\) and an element \(b\in P\) realizing \(p\).

Apply downward Löwenheim–Skolem inside \(P\) to the countable subset \(N\cup\{b\}\). Obtain a countable elementary substructure \(N'\preccurlyeq P\) containing that set. Since \(N\preccurlyeq P\), the inclusion \(N\subseteq N'\) is elementary: both structures evaluate a formula with parameters from \(N\) just as \(P\) does. Elementarity also retains the formulas of \(p\) at \(b\).

If the realization theorem first gives an elementary embedding rather than a literal inclusion, use renaming of the elementary copy before applying this construction. Thus the specified old parameters are preserved throughout.

Realizing every type over the original finite parameter sets

If \(T\) is small and \(M\models T\) is countable, there is a countable elementary extension \(M\preccurlyeq M^+\) realizing every member of \(S_1^M(A)\) for every finite \(A\subseteq M\).

Use one enumeration \((A_s,p_s)\) of all these requests. Starting with \(N_0=M\), apply the preceding lemma at stage \(s\) to obtain a countable elementary extension \(N_s\preccurlyeq N_{s+1}\) realizing \(p_s\). Here \(A_s\) always lies in the original \(M\), which is an elementary substructure of every \(N_s\). Earlier realizations remain realizations in later stages.

Let \(M^+=\bigcup_{s<\omega}N_s\), using compatible elementary inclusions. The elementary chain theorem makes each stage elementary in the union, so \(M\preccurlyeq M^+\). The union is countable, and the witness added for every listed request still satisfies its entire type there.

It establishes realization only over finite subsets of the original \(M\). New elements of \(M^+\) may be used as parameters, and requests involving those elements were absent from the original list. Another construction is needed to cover such requests. The next argument repeats the entire pass with an enlarged parameter base at each outer stage.

A countable saturated elementary extension

If \(T\) is small, every countable \(M\models T\) has a countable omega-saturated elementary extension.

Build a second elementary chain \(M_0\preccurlyeq M_1\preccurlyeq\cdots\), beginning with \(M_0=M\), by taking \(M_{i+1}=M_i^+\) from the whole preceding construction. Thus each outer successor already contains a union of an inner countable chain meeting all requests based on \(M_i\).

Let \(U=\bigcup_{i<\omega}M_i\). It is countable and is an elementary extension of every \(M_i\). Given a finite \(A\subseteq U\), choose a stage containing all its elements, by taking the largest of their finitely many stage indices. For \(A=\varnothing\), take stage \(0\). If \(p\in S_1^U(A)\), elementarity gives \(\operatorname{Th}((M_i)_A)=\operatorname{Th}(U_A)\). Hence \(p\) is also a member of \(S_1^{M_i}(A)\), and it is realized in \(M_{i+1}\), therefore in \(U\).

This is precisely omega-saturation. The inner enumeration handles all types over an already fixed base; the outer chain ensures every finite parameter set in the final model eventually belongs to such a base.

A countable saturated model can realize only countably many types

If \(T\) has a countable omega-saturated model \(U\), then \(T\) is small.

Fix \(n\). Completeness of \(T\) identifies its complete types with those over the empty parameter set in \(U\). By finite-tuple realization in a saturated model, every \(p\in S_n(T)\) is realized by a tuple of \(U^n\). Thus the map \(\bar b\mapsto\operatorname{tp}^U_T(\bar b)\) from \(U^n\) onto \(S_n(T)\) is surjective. A finite power of a countable set is countable, so \(S_n(T)\) is countable. For \(n=0\), the source is the singleton containing the empty tuple.

A model receiving every countable model

A countable elementary-universal model of \(T\) is a countable model \(U\models T\) such that every countable \(N\models T\) admits an elementary embedding \(N\to U\). The embeddings must preserve every first-order formula, including formulas with parameters from the source.

A countable omega-saturated model has this property by the successive extension of finite elementary maps. Elementary universality itself imposes no explicit condition on types over finite parameter sets in \(U\).

A universal model receives a realization of every type

If \(T\) has a countable elementary-universal model \(U\), then \(T\) is small.

For each \(p\in S_n(T)\), countable realization of a type gives a countable \(N\models T\) and a realizing tuple \(\bar a\). An elementary embedding \(f:N\to U\) preserves the type, so \(f(\bar a)\) realizes \(p\) in \(U\). Therefore \(U^n\) again surjects onto \(S_n(T)\), which is countable.

Smallness characterizes the two existence questions

The following are equivalent: \(T\) is small; \(T\) has a countable omega-saturated model; \(T\) has a countable elementary-universal model. Moreover, when these conditions hold, every countable model of \(T\) has a countable omega-saturated elementary extension.

A countable model of \(T\) exists by downward Löwenheim–Skolem applied to any model. Smallness and the extension construction then give a countable saturated model. Saturation gives elementary universality by the earlier embedding theorem. Conversely universality forces smallness. The stronger elementary-extension assertion is exactly the construction already proved.

The equivalence concerns existence. Given a particular elementary-universal model, its universality proves smallness and hence the existence of a saturated model; this reasoning does not assert that the given model is saturated.

Small theories also have a countable prime model

If \(T\) is small, then \(T\) has a countable atomic model and hence a prime model.

For each \(n\), the nonisolated members of \(S_n(T)\) form a countable set. Their disjoint union over all finite arities is countable. Apply simultaneous omission with varying finite arities to this family. It gives a countable \(N\models T\) omitting every listed type.

For any finite tuple \(\bar b\) in \(N\), its complete type is realized in \(N\), so it cannot be one of the omitted nonisolated types. It is therefore isolated. This says exactly that \(N\) is atomic. A countable atomic model is prime.

The omission list includes every finite tuple length, rather than only one-variable types, because atomicity is a condition on all finite tuples.

Together with countable saturation, this atomic-model existence result yields a third countable model for every small noncategorical theory in a countable language with an infinite model.

Naming every rational gives a prime model whose theory has continuum many complete one-types.

The earlier categorical examples satisfy the criterion

A countably categorical complete theory in a countable language with an infinite model has a countable omega-saturated model and a countable prime model.

By the categoricity criterion, every \(S_n(T)\) is finite, hence countable. Apply the existence criterion and the prime-model conclusion.

In particular this applies to the theory of infinite sets in the equality language and to dense linear orders without endpoints, using their existing classifications. In each case uniqueness of the countable model identifies the saturated and prime models obtained above, although their constructions meet different sets of requirements.
