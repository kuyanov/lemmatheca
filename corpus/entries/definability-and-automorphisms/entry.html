Describing a subset by a formula

In the real-number order, the formula \(a<x\) picks out the numbers to the right of a chosen point \(a\). Without choosing that point, the order language has no name for where the ray starts. Definability asks which subsets can be described by formulas, and which elements must be supplied as parameters.

Fix a nonempty structure \(M\) in a language \(L\). For a formula \(\varphi(\bar x,\bar y)\), a tuple \(\bar b\in M^m\), and \(n\) object variables \(\bar x\), write

\[\varphi(M,\bar b)=\{\bar a\in M^n:M\models\varphi[\bar a,\bar b]\}.\]

The displayed variables include all free variables; the brackets use the assignment convention. Both tuples have finite length. A set \(X\subseteq M^n\) is definable over \(A\subseteq M\), or \(A\)-definable, if \(X=\varphi(M,\bar b)\) for some formula and some finite tuple \(\bar b\) of elements of \(A\). It is parameter-free definable when \(m=0\), and definable with parameters when parameters from all of \(M\) are allowed. Language constants are already part of \(L\); they are distinct from the extra parameters supplied to a formula.

For \(n=0\), the power \(M^0\) consists of the single empty tuple. Its two subsets correspond to a false or true sentence. Definability concerns one fixed structure: a formula can define different subsets in different structures.

A parameter can locate a point

For any \(a\in M\), the formula \(x=a\), with \(a\) supplied as a parameter, defines \(\{a\}\). A finite set \(\{a_0,\ldots,a_{k-1}\}\) is defined by

\[\bigvee_{i<k}x=a_i.\]

For \(k>0\), the displayed disjunction holds exactly when the value of \(x\) equals one of the listed parameters. When \(k=0\), use the false formula \(x\ne x\). Thus every finite subset is definable with parameters. This says nothing about whether its points can be described without those parameters.

In \((\mathbb R,<)\), where the language contains only strict order, the positive ray \(\{x:0<x\}\) is definable over \(\{0\}\) by \(y<x\) with \(y\) assigned \(0\). The symbol for zero is not in this language. We will show in that this parameter cannot simply be omitted.

Relations and functions are described by their graphs

An \(n\)-ary relation is \(A\)-definable when its subset of \(M^n\) is \(A\)-definable. A function \(f:M^n\to M\) is \(A\)-definable when its graph

\[\{(\bar a,b)\in M^{n+1}:b=f(\bar a)\}\]

is \(A\)-definable. A defining formula must therefore give exactly one output for every input. A formula defining an arbitrary relation is not automatically the graph of a function.

The identity function has the parameter-free graph formula \(y=x\). The constant function with value \(a\) has graph formula \(y=a\), using the parameter \(a\). Merely choosing a function in the surrounding mathematics does not establish that its graph is definable in \(M\).

Combining definitions

For fixed arity \(n\) and parameter set \(A\), the \(A\)-definable subsets of \(M^n\) contain \(\varnothing\) and \(M^n\), and are closed under complement, union, intersection, and difference.

Suppose \(X\) and \(Y\) are defined by \(\varphi(\bar x,\bar b)\) and \(\psi(\bar x,\bar c)\). Put their finite parameter lists into one combined list. Keep the object-variable names fixed and relabel each free parameter name to the slot for its value in that list. This is substitution of free names by free names: the disjoint scoped placeholders remain unchanged, so their occurrences stay bound to the same quantifiers. With these common variable lists, the formulas \(\neg\varphi\), \(\varphi\lor\psi\), \(\varphi\land\psi\), and \(\varphi\land\neg\psi\) define \(M^n\setminus X\), \(X\cup Y\), \(X\cap Y\), and \(X\setminus Y\), respectively. Falsity and its negation define the empty and full sets, including at arity zero. Each assertion follows directly from the truth clauses.

Forgetting coordinates by asking for a witness

If \(X\subseteq M^{n+m}\) is \(A\)-definable, its projection onto the first \(n\) coordinates is \(A\)-definable:

\[\pi(X)=\{\bar a\in M^n:\exists\bar c\in M^m\;(\bar a,\bar c)\in X\}.\]

Suppose \(\varphi(\bar x,\bar y,\bar b)\) defines \(X\), where \(\bar y\) denotes its \(m\) discarded free coordinate names. Turn those names into the placeholders \(z_0,\ldots,z_{m-1}\), obtaining a body \(\widehat\varphi\) at context size \(m\). Increase the indices of every existing binder and its placeholders by \(m\), so each occurrence stays attached to its original binder. The object and parameter names remain free. The formula

\[\exists z_0\cdots\exists z_{m-1}\,\widehat\varphi(\bar x,z_0,\ldots,z_{m-1},\bar b)\]

is complete, and its satisfaction clause says exactly that a tuple of discarded coordinates exists. No new parameters have been introduced. For \(m=0\), this is the original formula and the identity projection; for \(n=0\), it asks whether \(X\) is nonempty. Any finite choice of retained coordinates works after a permutation of the coordinate list.

Symmetries that preserve the whole structure

An automorphism of \(M\) is an isomorphism \(g:M\to M\): a bijection preserving interpreted constants and functions and preserving and reflecting interpreted relations. It fixes \(A\subseteq M\) pointwise if \(g(a)=a\) for every \(a\in A\).

On tuples, apply \(g\) coordinate by coordinate: \(g\bar a=(g(a_0),\ldots,g(a_{n-1}))\). A subset \(X\subseteq M^n\) is invariant under \(g\) when \(\bar a\in X\) if and only if \(g\bar a\in X\) for every tuple. Equivalently, the tuplewise image satisfies \(g[X]=X\). The inverse of an automorphism fixing \(A\) also fixes \(A\).

Definitions cannot distinguish parameter-preserving symmetries

Every \(A\)-definable subset \(X\subseteq M^n\) is invariant under every automorphism \(g\) of \(M\) fixing \(A\) pointwise:

\[\bar a\in X\quad\Longleftrightarrow\quad g\bar a\in X.\]

Take a definition \(X=\varphi(M,\bar b)\) with \(\bar b\) from \(A\). Satisfaction is preserved by an isomorphism, so

\[M\models\varphi[\bar a,\bar b]\quad\Longleftrightarrow\quad M\models\varphi[g\bar a,g\bar b].\]

Since each parameter is fixed, \(g\bar b=\bar b\). The right side is therefore exactly the assertion that \(g\bar a\in X\). This also proves the claim at arity zero.

To show that a particular set is not \(A\)-definable, it is enough to find one automorphism fixing \(A\) and one tuple whose membership changes. The language matters: adding a constant or relation can remove an available symmetry.

The order alone does not identify the positive reals

The positive ray \(P=\{x\in\mathbb R:0<x\}\) is not parameter-free definable in \((\mathbb R,<)\).

The translation \(g(x)=x-2\) is a bijection, with inverse \(x\mapsto x+2\). It preserves and reflects strict order because \(x-2<y-2\) is equivalent to \(x<y\). There are no function or constant symbols to preserve. Thus \(g\) is an automorphism. But \(1\in P\) and \(g(1)=-1\notin P\), contradicting if \(P\) were parameter-free definable.

There is no conflict with : this translation does not fix the allowed parameter \(0\). If the language itself names zero, it is no longer an automorphism of that expanded structure.

Even all finite parameter lists cannot define every subset

Let \(L\) be a countable language and \(M\) an infinite \(L\)-structure of cardinality \(\kappa\). There are at most \(\kappa\) subsets of \(M\) definable with finite parameters from \(M\). Consequently, some subset of \(M\) is not definable even with parameters.

The variables, logical symbols and symbols of \(L\) form a countable alphabet. Finite strings over this alphabet form a countable set, using finite products and countable unions. Hence there are at most countably many formulas and choices of their finite variable lists.

For every positive finite \(m\), there are \(\kappa^m=\kappa\) tuples of parameters by finite powers of an infinite cardinal. The empty tuple contributes one more possibility. Taking all finite lengths gives \(\kappa\cdot\aleph_0=\kappa\) parameter tuples. Thus pairs consisting of a formula and a matching tuple number at most \(\aleph_0\cdot\kappa=\kappa\). Each pair describes at most one subset, and every definable subset has such a description. Different descriptions may define the same subset, which only lowers the count.

By Cantor's theorem, \(\mathcal P(M)\) has cardinality strictly larger than \(\kappa\). The definable subsets cannot exhaust it.

This is an external count in the surrounding mathematics. It neither supplies a formula naming all definable subsets inside \(M\), nor identifies a particular undefinable subset.

A structure can have no nontrivial symmetries

Call a structure rigid if its only automorphism is the identity. The structure \((\mathbb N,0,S)\), with \(S(n)=n+1\), is rigid.

An automorphism \(g\) must preserve the named zero, so \(g(0)=0\). If \(g(n)=n\), preservation of successor gives \(g(n+1)=g(S(n))=S(g(n))=n+1\). Induction on \(n\) shows \(g(n)=n\) for every natural number.

Every subset of this structure is invariant under every automorphism, since the identity changes no element. Nevertheless, gives a subset not definable even with parameters. Therefore automorphism invariance is a necessary condition for definability, but is not a sufficient condition in general.

What happens on a finite domain?

If \(M\) is finite and all its elements are allowed as parameters, can any subset of \(M\) fail to be definable?

Show answerHide answer

No. Every subset is finite, so the equality disjunction in defines it. The counting theorem requires an infinite domain because the count of possible finite parameter lists then collapses to \(|M|\). It makes no such claim for a finite domain.

Which symmetries can test a definition?

A set is defined using a parameter \(a\), but an automorphism moving \(a\) also moves the set. Does this disprove its definability over \(\{a\}\)?

Show answerHide answer

No. The theorem tests automorphisms fixing the allowed parameters. For example, \(\{a\}\) is defined by \(x=a\), and an automorphism with \(g(a)\ne a\) sends it to \(\{g(a)\}\). An automorphism fixing \(a\) necessarily preserves its singleton. More generally, satisfaction invariance gives \(g[\varphi(M,\bar b)]=\varphi(M,g\bar b)\): keeping the formula while moving its parameters describes the transported set.
