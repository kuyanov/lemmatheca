Let each approximation retain every earlier answer

Use unary partial functions and graph inclusion \(f\sqsubseteq g\): every defined answer of \(f\) is the same answer of \(g\). Write \(\bot\) for the nowhere-defined function. An increasing chain is a sequence \((f_n)_{n\in\mathbb N}\) with \(f_n\sqsubseteq f_{n+1}\) for every \(n\).

Its union graph consists of every input–output pair appearing at some finite stage. Thus its intended partial function \(h=\bigcup_n f_n\) satisfies

\[h(x)\downarrow=y\quad\Longleftrightarrow\quad\exists n\;f_n(x)\downarrow=y.\]

The next result proves that these observations define one partial function, including at inputs for which no stage returns a value.

The union of an increasing chain is a partial function

Every increasing chain has a unique union partial function with the displayed output condition. It extends each \(f_n\); if every \(f_n\sqsubseteq g\), then its union also satisfies \(h\sqsubseteq g\).

First, \(f_m\sqsubseteq f_n\) whenever \(m\le n\), by induction on the difference, using transitivity of graph inclusion. If stage \(m\) returns \(y\) at \(x\) and stage \(n\) returns \(z\) there, both values occur at stage \(\max(m,n)\). That stage is a partial function, so \(y=z\). The union graph is therefore single-valued. Give \(h(x)\) this common value when some stage supplies one, and leave it undefined otherwise. The output condition uniquely specifies every partial value.

Any stage output is a union output, proving \(f_n\sqsubseteq h\). If all stage outputs belong to \(g\), every union output does too, which is the asserted least-upper-bound property. No computability hypothesis on the chain or on \(g\) was used.

One finite stage contains any finite piece of the union

If \(h=\bigcup_n f_n\) is the union of an increasing chain and \(d\) is a valid finite-fragment code, then

\[\delta_d\sqsubseteq h\quad\Longleftrightarrow\quad\exists n\;\delta_d\sqsubseteq f_n.\]

For each pair in the finite table \(D_d\), inclusion in \(h\) supplies a stage at which that very output appears. Choose a stage for each of these finitely many observations, and let \(N\) be their maximum. All observations persist to \(N\), so the finite-table lookup identity gives \(\delta_d\sqsubseteq f_N\). An empty table needs no observations: take \(N=0\). Repeated identical pairs cause no problem. Conversely, inclusion in one stage implies inclusion in its union.

Finite positive rules commute with increasing unions

Let \(\Phi\) be an effective operator on unary partial numerical functions. For every increasing chain \((f_n)\),

\[\Phi\left(\bigcup_n f_n\right)=\bigcup_n\Phi(f_n).\]

The chain on the right is increasing by monotonicity. This preservation of increasing unions is the chain-continuity property used here.

If \(\Phi(h)(x)\downarrow=y\), finite information gives a valid fragment \(\delta_d\sqsubseteq h\) already producing that output. By , this fragment is included in some \(f_N\). Monotonicity transfers the output from \(\Phi(\delta_d)\) to \(\Phi(f_N)\), placing it in the right-hand union. Conversely each \(f_n\sqsubseteq h\), so every output of \(\Phi(f_n)\) is an output of \(\Phi(h)\). The two implications identify all defined values and also the undefined inputs. Neither the chain nor its union needs to be computable.

Start recursive approximation with no defined answers

Fix one effective endofunction \(\Phi\): it takes unary partial functions to unary partial functions. The same input and output type is required to form repeated applications and the equation \(\Phi(f)=f\). Its bottom iterates and their candidate limit are

\[f_0=\bot,\qquad f_{n+1}=\Phi(f_n),\qquad f_\infty=\bigcup_n f_n.\]

A fixed point is a partial function \(g\) with \(\Phi(g)=g\). A least fixed point is a fixed point included in every other fixed point under \(\sqsubseteq\), including fixed points that are not computable.

Iteration from bottom produces an increasing chain

For the specified bottom iterates, \(f_n\sqsubseteq f_{n+1}\) for all \(n\). Consequently \(f_\infty\) is a well-defined partial function.

There is no output of \(\bot\) to check, so \(f_0\sqsubseteq f_1\). If \(f_n\sqsubseteq f_{n+1}\), monotonicity gives \(\Phi(f_n)\sqsubseteq\Phi(f_{n+1})\), which is precisely \(f_{n+1}\sqsubseteq f_{n+2}\). Induction proves the chain condition; then supplies its union.

Iterate program indices without waiting for their programs

Suppose \(r\) enumerates coherent positive rules \(R\) representing \(\Phi=\Phi_R\). Use the actual primitive-recursive compiler \(q(r,e)\), and fix the bottom index \(b=u(d_\varnothing)\), where \(d_\varnothing\) is the empty-table code and \(u\) is the existing finite-fragment compiler. Define the iterate-index sequence by

\[i(r,0)=b,\qquad i(r,n+1)=q(r,i(r,n)).\]

This is primitive recursion with an unchanged parameter on numerical indices. Hence \(i\) is primitive recursive jointly in \(r,n\). Computing the next index changes program text; it does not require any computation of the previous program to finish.

The same numerical sequence names the specified function iterates

For every coherent positive rule index \(r\) and all \(n,x\), \(\varphi_{i(r,n)}(x)\simeq f_n(x)\), where \(f_n\) are the bottom iterates of the operator represented by \(r\).

At stage zero, the empty-fragment compiler identity says \(\varphi_b=\bot=f_0\). If \(\varphi_{i(r,n)}=f_n\), the actual compiler correctness theorem gives

\[\varphi_{i(r,n+1)}=\varphi_{q(r,i(r,n))}=\Phi_R(\varphi_{i(r,n)})=\Phi_R(f_n)=f_{n+1}.\]

This induction identifies the entire partial function at every stage. The same numerical sequence works before the runtime input varies.

Search all finite approximations through bounded certificates

The union search \(L(r,x)\) scans natural pair codes \(w=\langle n,k\rangle\) in increasing order. It accepts when the existing bounded output code satisfies \(b(k,i(r,n),x)>0\), and returns \(b(k,i(r,n),x)-1\). If no candidate succeeds, it remains undefined.

Every test is total primitive recursive jointly in \(r,x,w\), because the index iteration and bounded evaluator are primitive recursive. Consequently \(L\) is jointly partial recursive. This search does not wait for \(\varphi_{i(r,0)}(x)\) to terminate before inspecting later indices; the zeroth program never terminates.

Choose one fixed program index \(z\) satisfying \(\varphi_z(\langle r,x\rangle)\simeq L(r,x)\) for all \(r,x\), and define the least-fixed-point compiler \(\ell(r)=s(z,r)\). The actual specialization operation makes \(\ell\) primitive recursive on every numerical input, whether or not its supplied rules satisfy the hypotheses.

The specified union program computes exactly the increasing union

For every \(r\) enumerating coherent positive rules, the same program index \(\ell(r)\) satisfies

\[\varphi_{\ell(r)}(x)\simeq L(r,x)\simeq f_\infty(x)\qquad(x\in\mathbb N).\]

The first equality is the exact specialization identity for the fixed master \(z\). If candidate \(\langle n,k\rangle\) succeeds with returned value \(y\), bounded-evaluation correctness gives \(\varphi_{i(r,n)}(x)\downarrow=y\). By , this is an output of \(f_n\), hence of its union.

Conversely, an output \(f_\infty(x)\downarrow=y\) occurs at some stage \(n\). The index identity supplies that output for \(\varphi_{i(r,n)}(x)\), so a successful bounded allowance \(k\) exists. The numerical search eventually reaches this pair. An earlier successful candidate can name a different stage, but the increasing-chain property forces its output to be the same \(y\). With no union output, the first implication excludes every successful candidate and the program diverges. Thus it computes the whole union partial function.

The union solves the recursive equation

The union \(f_\infty\) of the bottom iterates satisfies \(\Phi(f_\infty)=f_\infty\).

Apply to the increasing iterates:

\[\Phi(f_\infty)=\bigcup_n\Phi(f_n)=\bigcup_n f_{n+1}=\bigcup_n f_n=f_\infty.\]

The third equality drops only the zeroth stage, which has no outputs. Every later stage still occurs in both unions, so this equality also covers an empty union of outputs. The calculation proves the fixed-point equation on all inputs.

Every fixed point contains all the finite approximations

If an arbitrary partial function \(g\) satisfies \(\Phi(g)=g\), then \(f_\infty\sqsubseteq g\). There is no computability assumption on \(g\).

Induct on \(n\) to prove \(f_n\sqsubseteq g\). The base case is the empty graph. From \(f_n\sqsubseteq g\), monotonicity gives \(f_{n+1}=\Phi(f_n)\sqsubseteq\Phi(g)=g\). Thus every finite approximation is included in \(g\). The union property in gives \(f_\infty\sqsubseteq g\), as asserted.

Every effective endofunction has a computable least fixed point

Every effective operator \(\Phi\) from unary partial numerical functions to unary partial numerical functions has a least fixed point

\[f_\Phi=\bigcup_{n\in\mathbb N}\Phi^n(\bot).\]

This partial function is computable. More precisely, for any coherent positive rule index \(r\) representing \(\Phi\), the specified primitive-recursive compiler \(\ell\) satisfies \(\varphi_{\ell(r)}=f_\Phi\). Leastness is with respect to all partial-function fixed points. This is Kleene's first recursion theorem in the finite-information representation.

The iterates form an increasing chain by . Its union is a fixed point by , and proves its leastness. An effective operator has one jointly enumerable positive coherent rule relation, hence an ordinary index \(r\) for that coded relation. The actual program in computes precisely this union. These facts prove all parts of the theorem without assuming that any fixed point is total.

A recursive equation can add one answer per approximation

The operator \(\Gamma\) given by

\[\Gamma(f)(0)=0,\qquad \Gamma(f)(n+1)\simeq f(n)+1\]

is effective, where successor is applied by strict composition to a partial value. Thus the second expression is undefined when \(f(n)\) is undefined.

Use all valid tables as possible evidence. At input zero allow exactly output zero, with empty evidence already sufficient. At input \(n+1\), allow output \(y+1\) exactly when the table contains \((n,y)\). Finite inspection decides this one joint rule relation. Compatible tables agree at \(n\), so their output successors agree; the zero-input case is also coherent. An applicable rule gives the displayed partial value, and any such value supplies the corresponding singleton table. These rules give the stated effective operator.

The finite initial segments converge to the identity function

Let \(g_n=\Gamma^n(\bot)\). Then, for every \(n,x,y\),

\[g_n(x)\downarrow=y\quad\Longleftrightarrow\quad x<n\text{ and }y=x.\]

Consequently the least fixed point of \(\Gamma\) is the total identity function \(x\mapsto x\).

At \(n=0\), both sides are false. For the successor stage, input zero has output zero. At input \(x=m+1\), the defining rule returns \(m+1\) exactly when \(g_n(m)\) returns \(m\). By induction this is equivalent to \(m<n\), or \(x<n+1\). No other output is possible. This proves the formula at every finite stage. For each fixed \(x\), stage \(x+1\) includes its answer \(x\); the union therefore gives the identity function, and identifies this union as the least fixed point.

A least fixed point may be partial and have other fixed points

The effective operator \(\Psi\) defined by

\[\Psi(f)(0)=0,\qquad \Psi(f)(x)\simeq f(x+1)\quad(x>0)\]

has least fixed point \(h\) defined only at zero, with \(h(0)=0\). For each \(k\in\mathbb N\), the total function \(h_k\) given by \(h_k(0)=0\) and \(h_k(x)=k\) for \(x>0\) is another fixed point. Thus leastness implies neither totality nor uniqueness.

Positive rules at input zero require no observation and return zero. At positive input \(x\), accept exactly an observed pair \((x+1,y)\) and return \(y\). These rules are jointly decidable and coherent, so they define an effective operator with the stated values. Starting from bottom gives the singleton graph \(\{(0,0)\}\) after one application. A further application gives no positive-input answer, because \(x+1>0\) and that singleton is undefined there. Hence every later iterate is the same singleton. Its union is \(h\), and the first recursion theorem proves that it is least.

For \(x=0\), \(\Psi(h_k)(x)=0=h_k(x)\). For \(x>0\), both \(h_k(x+1)\) and \(h_k(x)\) equal \(k\), proving the fixed-point equation. The value at input one distinguishes the different \(h_k\), and each properly extends the partial least fixed point.

Does an index fixed point automatically give the least solution?

For the identity operator \(I(f)=f\), the total computable index map \(H(e)=e\) realizes its action. Does the semantic fixed-point equation \(\varphi_e=\varphi_{H(e)}\) force \(\varphi_e\) to be the least fixed point of \(I\)?

Show answerHide answer

No. The precomposition example with \(k(x)=x\) shows that \(I\) is effective. Every partial function is a fixed point of \(I\), and its least fixed point is bottom: iteration from bottom never adds any output. Every numerical index satisfies \(\varphi_e=\varphi_{H(e)}\), including an index for the total constant-zero function, which is not bottom.

The index recursion theorem establishes equality of the two indexed partial functions. For an extensional computable transformation, Myhill–Shepherdson supplies an effective operator extending its action, and the first recursion theorem additionally selects its least solution. The stronger leastness conclusion comes from the bottom iteration and finite-information argument; it is not part of an arbitrary semantic index fixed-point equation.
