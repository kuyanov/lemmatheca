Infinitely many independent questions about one element

Let \(L_{\mathrm{ind}}\) be the first-order language with equality and unary relation symbols \(P_n\), one for each \(n\in\mathbb N\), and with no constants or function symbols. Its terms are variables. An \(L_{\mathrm{ind}}\)-structure is a nonempty set \(M\) with a subset \(P_n^M\subseteq M\) for each \(n\).

For disjoint finite sets \(F,G\subseteq\mathbb N\), the cell specified by \((F,G)\) is

\[C_M(F,G)=\{a\in M:(\forall n\in F)\,P_n(a)\text{ and }(\forall n\in G)\,\neg P_n(a)\}.\]

Its defining formula is \(\chi_{F,G}(x)\), the conjunction of the corresponding positive and negative predicate literals. An empty conjunction is \(\top\), so \(C_M(\varnothing,\varnothing)=M\). A repeated request has the same meaning as one occurrence; requests for both \(P_n\) and \(\neg P_n\) are inconsistent and are excluded by \(F\cap G=\varnothing\).

Axioms saying every finite pattern has infinitely many witnesses

The independent-predicate theory \(T_{\mathrm{ind}}\) contains, for each disjoint finite \(F,G\) and every \(k\in\mathbb N\), the sentence

\[\exists x_0\cdots\exists x_{k-1}\;\Bigl(\bigwedge_{i<k}\chi_{F,G}(x_i)\;\land\!\bigwedge_{i<j<k}x_i\ne x_j\Bigr).\]

Thus \(M\models T_{\mathrm{ind}}\) exactly when every such cell is infinite. The \(k=0\) instance is true; positive instances require arbitrarily many distinct witnesses. Both the language and the axiom set are countable: finite subsets and finite lists of natural numbers can be enumerated. All structures below remain nonempty.

A countable model made from finite subsets

Let \(M_{\mathrm{fin}}\) have domain \(\operatorname{Fin}(\mathbb N)\), the set of finite subsets of \(\mathbb N\), with \(P_n(A)\) meaning \(n\in A\). Then \(M_{\mathrm{fin}}\) is a countably infinite model of \(T_{\mathrm{ind}}\).

Finite subsets are images of finite lists, and the set of finite lists of natural numbers is countable. The singleton map \(n\mapsto\{n\}\) is injective, so the domain is infinite. Fix disjoint finite \(F,G\), and choose \(K\) larger than every member of \(F\cup G\), taking \(K=0\) if that union is empty. The distinct sets \(F\cup\{K+r\}\), for \(r\in\mathbb N\), all belong to \(C_{M_{\mathrm{fin}}}(F,G)\). They contain \(F\), avoid \(G\), and differ at their added element. This proves every cell is infinite, including the cell with no conditions.

A model containing every complete membership pattern

Let \(M_{\mathrm{all}}\) have domain \(\mathcal P(\mathbb N)\), again with \(P_n(A)\) meaning \(n\in A\). Then \(M_{\mathrm{all}}\models T_{\mathrm{ind}}\).

The same witnesses \(F\cup\{K+r\}\) used in the finite-subset model are also distinct elements of \(\mathcal P(\mathbb N)\). Hence every finite cell is infinite in this structure as well. In particular, the axioms are satisfiable in two explicitly specified structures, one countable and one uncountable.

A finite pattern can avoid finitely many old elements

If \(M\models T_{\mathrm{ind}}\), \(F,G\) are disjoint finite subsets of \(\mathbb N\), and \(a_0,\ldots,a_{m-1}\in M\), there is \(b\in C_M(F,G)\) different from every \(a_i\).

The axiom for \((F,G,k=m+1)\) supplies \(m+1\) distinct members of the cell. A set of at most \(m\) old elements cannot contain them all. Choosing one outside that set proves the assertion. The old tuple may repeat elements, and for \(m=0\) the axiom with \(k=1\) supplies a witness.

Eliminating a conjunction of literals

For every finite conjunction of literals \(\Gamma(\bar x,y)\), the formula \(\exists y\,\Gamma(\bar x,y)\) is equivalent modulo \(T_{\mathrm{ind}}\) to a quantifier-free formula in \(\bar x\).

A literal is an atom or its negation. Here atoms are equalities of variables or expressions \(P_n(z)\). If \(\Gamma\) contains \(y=x_i\) or \(x_i=y\), replace every occurrence of \(y\) by \(x_i\). The resulting conjunction is equivalent to the existential formula: any witness must equal \(x_i\), and \(x_i\) itself is a witness when that substituted conjunction holds. This is the equality-witness substitution argument.

Otherwise discard the tautology \(y=y\). A literal \(y\ne y\), or the simultaneous requirements \(P_n(y)\) and \(\neg P_n(y)\), makes the conjunction impossible, so use \(\bot\). In every other case, collect the predicate requirements on \(y\) into disjoint finite sets \(F,G\). All remaining equalities involving \(y\) are inequalities \(y\ne x_i\); orientations can be reversed. The literals not involving \(y\) form a conjunction \(\Gamma_0(\bar x)\).

Existence of a witness implies \(\Gamma_0\). Conversely, if \(\Gamma_0\) holds, a fresh cell witness satisfies every required predicate and avoids all the finitely many forbidden coordinates. Thus the existential formula is equivalent to \(\Gamma_0\). This includes an empty old-variable context and an empty list of predicate requirements.

All formulas reduce to finite predicate and equality tests

The theory \(T_{\mathrm{ind}}\) has quantifier elimination in its actual first-order language.

Apply the literal-conjunction criterion to the preceding lemma. More explicitly, a quantifier-free matrix is a finite disjunction of finite conjunctions of literals; existential quantification distributes over that disjunction. Eliminate the quantified variable in each conjunction and take the resulting disjunction. Structural induction on formulas then eliminates innermost quantifiers, using \(\forall y\,\varphi\equiv\neg\exists y\,\neg\varphi\). Each step uses only finitely many symbols, although the language itself has infinitely many predicates.

All models satisfy the same sentences

The theory \(T_{\mathrm{ind}}\) is complete and has an infinite model.

Satisfiability follows from the countable model. Quantifier elimination replaces every sentence by a quantifier-free sentence. There are no closed terms, since there are no constants or functions. Consequently a closed quantifier-free formula has no equality or predicate atoms: it is built from \(\bot\) by Boolean connectives. Its truth value is the same in every structure. Hence all models of \(T_{\mathrm{ind}}\) agree on every sentence, which is completeness. The empty-pattern axioms require arbitrarily many distinct elements, so every model is infinite.

In one variable, the predicate answers determine the entire type

Suppose \(M,N\models T_{\mathrm{ind}}\), \(a\in M\), and \(b\in N\). If \(P_n^M(a)\) and \(P_n^N(b)\) have the same truth value for every \(n\), then \(\operatorname{tp}^M(a)=\operatorname{tp}^N(b)\).

The atoms in a quantifier-free formula with just the free variable \(x\) are \(x=x\) and \(P_n(x)\). Equality is true at both elements, and every predicate agrees by assumption. Induction through Boolean connectives gives agreement for each quantifier-free formula. Quantifier elimination gives agreement for every formula in that context. A tuple type is exactly the collection of those formulas true at the tuple, so the types are equal.

There are continuum many complete one-types

The map \(A\mapsto p_A=\operatorname{tp}^{M_{\mathrm{all}}}(A)\) is a bijection from \(\mathcal P(\mathbb N)\) to \(S_1(T_{\mathrm{ind}})\). In particular, \(|S_1(T_{\mathrm{ind}})|=2^{\aleph_0}\).

If \(A\ne B\), some \(n\) belongs to exactly one of them. The formula \(P_n(x)\) belongs to exactly one of \(p_A,p_B\), proving injectivity.

For surjectivity, let \(p\in S_1(T_{\mathrm{ind}})\), and realize this complete type by an element \(b\) of some model \(N\models T_{\mathrm{ind}}\). Put \(A=\{n:P_n(x)\in p\}\). Completeness of \(p\) and realization give \(P_n^N(b)\) exactly when \(n\in A\). The element \(A\) of \(M_{\mathrm{all}}\) has those same predicate answers. By the preceding lemma, its complete type is \(p\), so \(p=p_A\).

A single formula can inspect only finitely many predicate coordinates

For each quantifier-free formula \(\psi(x)\), there is a finite set \(J\subseteq\mathbb N\) such that, for all \(A,B\subseteq\mathbb N\), agreement of \(A\) and \(B\) on \(J\) implies

\[M_{\mathrm{all}}\models\psi[A]\quad\Longleftrightarrow\quad M_{\mathrm{all}}\models\psi[B].\]

Let \(J\) be the set of indices of predicates occurring in the finite syntax tree of \(\psi\). At an atom \(P_n(x)\), its index lies in \(J\), so the assumed membership agreement identifies its truth values. Equality atoms are \(x=x\) and have fixed truth; falsity is false. Boolean induction proves the displayed equivalence. Negated predicates require the same indices, and repeated occurrences do not enlarge the set.

No single formula isolates a complete one-type

Every complete one-type of \(T_{\mathrm{ind}}\) is nonisolated.

Write the type as \(p_A\) using the bijection. Suppose a formula \(\theta(x)\in p_A\) isolated it. By quantifier elimination choose a quantifier-free \(\psi(x)\) equivalent to \(\theta\) modulo \(T_{\mathrm{ind}}\). Let \(J\) be its finite predicate support, choose \(m\notin J\), and let \(B=A\mathbin{\triangle}\{m\}\), changing only membership of \(m\).

The elements \(A,B\) agree on \(J\), so \(\psi\), and therefore \(\theta\), holds at both in \(M_{\mathrm{all}}\). Thus \(\theta\in p_B\), but \(p_A\ne p_B\) because they disagree on \(P_m(x)\). This contradicts the unique-completion characterization of isolation.

Which complete one-types does the countable model realize?

In \(M_{\mathrm{fin}}\), is the description \(\{P_n(x):n\in\mathbb N\}\) realized? More generally, which of the types \(p_A\) occur?

The realized types are exactly \(p_A\) for finite \(A\). In particular, the description requiring every predicate is omitted, although every finite part is realized.

An element of \(M_{\mathrm{fin}}\) is a finite set \(F\). Its predicate answers are exactly membership in \(F\), so its type is \(p_F\). Conversely each finite \(F\) is an element and realizes that type. The description containing all \(P_n(x)\) would require the infinite set \(\mathbb N\), which is absent from this domain. Every finite part mentions only finitely many positive predicates; their finite index set is a witness. Its unique complete extension is \(p_{\mathbb N}\), by the classification.

There is no atomic model and no prime model

The theory \(T_{\mathrm{ind}}\) has no atomic model and no prime model.

Every nonempty model contains an element \(a\), and its complete one-type is nonisolated by the theorem. This violates atomicity, which requires the type of every finite tuple to be isolated. In a countable language, every prime model of a complete satisfiable theory is countable and atomic by the prime-model characterization. Hence there is no prime model either.

No countable model can receive all complete descriptions

The theory \(T_{\mathrm{ind}}\) has no countable omega-saturated model and no countable elementary-universal model.

The bijection \(\mathcal P(\mathbb N)\to S_1(T_{\mathrm{ind}})\), together with Cantor's theorem, makes this type set uncountable. Thus \(T_{\mathrm{ind}}\) is not small. The existence criterion for countable saturated and elementary-universal models excludes both.

Concretely, a countable model has only countably many elements, hence realizes only countably many complete one-types. A saturated model would realize all of them. An elementary-universal model would also realize all of them: every complete one-type is realized in a countable model, and an elementary embedding into the universal model preserves that type. Both demands therefore exceed what a countable domain can supply.
