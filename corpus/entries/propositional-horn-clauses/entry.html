One possible positive conclusion

Fix a set \(P\) of atoms. A Horn clause is a finite clause with at most one positive literal. It can be written as a Horn rule \(B\Rightarrow h\), where the body \(B\subseteq P\) is finite and the head \(h\) is either an atom or the symbol \(\bot\). Its meaning is the implication

\[ \bigwedge_{b\in B}b\ \longrightarrow\ h. \]

A rule with an atomic head is definite. A rule with head \(\bot\) is a constraint. A definite rule with empty body is a fact; its head must be true. The constraint \(\varnothing\Rightarrow\bot\) is always false. A finite Horn theory \(\Gamma\) is a finite set of these rules. The empty conjunction means \(\top\), as in the normal-form conventions.

Writing a rule as a clause gives the finite set \(\{\neg b:b\in B\}\cup\{h\}\) for an atomic head, and just \(\{\neg b:b\in B\}\) for a constraint. Conversely, take the atoms of the negative literals as the body, and the unique positive literal, if present, as the head. This recovers the original clause. An atom may occur both in the body and as the head: the rule then expresses a tautology, which is harmless. Repetitions and ordering are immaterial because bodies and clauses are finite sets.

Rule satisfaction is ordinary clause satisfaction

Identify a valuation with its true set \(X\subseteq P\). It satisfies a definite rule \(B\Rightarrow p\) exactly when \(B\subseteq X\) implies \(p\in X\), and it satisfies a constraint \(B\Rightarrow\bot\) exactly when \(B\nsubseteq X\). These conditions are equivalent to satisfying the associated clauses, with precisely the same valuation. Consequently they describe the same models as the CNF formed from those clauses.

The associated clause is true if some \(b\in B\) is false, or its atomic head is true. The first alternative means \(B\nsubseteq X\). If every body atom is true, the clause therefore requires the head to be true; without an atomic head it is false. This proves both cases, including empty bodies. Conjoining over the finite theory gives the CNF assertion. The finite-set and finite-list clause representations have the same truth conditions, so no new interpretation of propositional logic is being introduced.

Add the conclusions whose premises are already known

The support \(S\) of a finite Horn theory \(\Gamma\) is the finite set of all its body and head atoms. For a finite set \(X\subseteq P\), define the forward step

\[ F_\Gamma(X):=X\cup\{p:(B\Rightarrow p)\in\Gamma,\ B\subseteq X\}. \]

Constraints add no atoms. The forward stages start with \(X_0=\varnothing\) and satisfy \(X_{i+1}=F_\Gamma(X_i)\). This is a simultaneous update: a rule can use atoms added at stage \(i+1\) only in the next step. For \(n=|S|\), call \(L_\Gamma:=X_n\) the forward closure. A set \(Y\subseteq P\), finite or infinite, is closed under the definite rules when every definite rule with body contained in \(Y\) has its head in \(Y\).

Each update is a finite calculation: inspect every definite rule, test membership of each body atom in the current finite set, and add the head when all tests succeed. Thus \(n\) updates specify an algorithm, without a search over all valuations. An earlier stop when a stage does not change gives the same closure, as proved next.

Stages grow within every closed set

For all finite sets \(X\subseteq Y\), we have \(X\subseteq F_\Gamma(X)\) and \(F_\Gamma(X)\subseteq F_\Gamma(Y)\). Every stage lies in \(S\), and \(X_i\subseteq X_{i+1}\). If \(Y\subseteq P\) is closed under the definite rules, then \(X_i\subseteq Y\) for every \(i\). Finally, if \(X_{i+1}=X_i\), every later stage equals \(X_i\).

The first inclusion follows from the union in the definition of \(F_\Gamma\). A body contained in \(X\) is also contained in \(Y\), proving monotonicity. Starting with the empty set, a step adds only head atoms of \(\Gamma\), which belong to \(S\). Induction proves the support assertion and the increasing-stage assertion.

For the closed-set invariant, induct on \(i\). There is nothing to prove at zero. If \(X_i\subseteq Y\), an atom of \(X_{i+1}\) either already belongs to \(X_i\), or is the head of a rule whose body lies in \(X_i\), hence in \(Y\). Closure puts that head in \(Y\). This proves the next induction step. If two consecutive stages are equal, applying the same function to equal inputs gives the next equality; induction keeps the process stationary forever.

The support size bounds the number of updates

If \(n=|S|\), then \(X_{n+1}=X_n\). In particular, the forward closure is a fixed point of \(F_\Gamma\), and every stage at or after \(n\) equals \(L_\Gamma\).

A strict increase of finite sets adds at least one element, so it increases cardinality by at least one. If \(X_{n+1}\ne X_n\), no earlier consecutive stages could have been equal, by . All \(n+1\) inclusions from \(X_0\) to \(X_{n+1}\) would therefore be strict. Starting with cardinality zero gives \(|X_{n+1}|\ge n+1\). But \(X_{n+1}\subseteq S\), so \(|X_{n+1}|\le n\), a contradiction. The stationary-stage conclusion now follows from the same invariant. If \(S=\varnothing\), no rule has an atomic head, and the conclusion says correctly that the empty initial stage is already fixed.

The closure is the least model of the definite rules

For a finite Horn theory \(\Gamma\), the forward closure \(L_\Gamma\) is closed under its definite rules and is contained in every set closed under those rules. In particular, if \(\Gamma\) has no constraints, then \(L_\Gamma\) is its least model, ordered by inclusion of true atoms.

If a definite rule has body contained in \(L_\Gamma\), its head belongs to \(F_\Gamma(L_\Gamma)\). The fixed-point identity puts that head in \(L_\Gamma\), so the closure is closed. The closed-set invariant in , applied at stage \(|S|\), puts \(L_\Gamma\) in every closed set. For a theory consisting of definite rules, closed sets are exactly the satisfying true sets by . This proves the least-model assertion, including truth values of atoms outside the support: the least model makes them false.

For rules containing variables, grounding and finite-body closure extend this construction to a least model on closed terms; its ground base need not be finite.

Check constraints only after forward chaining

A finite Horn theory \(\Gamma\) is satisfiable if and only if no constraint body is contained in \(L_\Gamma\):

\[ \Gamma\text{ is satisfiable}\quad\Longleftrightarrow\quad\forall(B\Rightarrow\bot)\in\Gamma,\ B\nsubseteq L_\Gamma. \]

When this condition holds, \(L_\Gamma\) is a model of \(\Gamma\), contained in every other model. Computing \(|S|\) forward steps and then testing these finite bodies is a terminating decision procedure.

Suppose a constraint body \(B\) lies in \(L_\Gamma\). Every model of \(\Gamma\) is closed under the definite rules, so it contains \(L_\Gamma\), and hence contains \(B\). It would violate that constraint, a contradiction. Thus a model can exist only if every constraint passes the stated test.

Conversely, if all constraints pass, \(L_\Gamma\) satisfies them by . It satisfies every definite rule by , so it is a model of the whole theory. Its containment in all other models follows from the same theorem. There are finitely many updates and finitely many body tests, each on a finite set, so this is an actual terminating calculation. No estimate for an optimized implementation's running time is needed.

Exactly which atoms must be true?

If a finite Horn theory \(\Gamma\) is satisfiable, an atom \(p\) is true in every model of \(\Gamma\) exactly when \(p\in L_\Gamma\).

Every model contains the forward closure, so membership in \(L_\Gamma\) makes \(p\) true in every model. Conversely, supplies the particular model \(L_\Gamma\). If \(p\) is true in every model, it is true in this one, which means \(p\in L_\Gamma\). Satisfiability is necessary for this equivalence: an inconsistent theory has no models and therefore entails every atom, even atoms never added by its definite rules.

Follow the simultaneous updates

On distinct atoms \(p,q,r,s\), take the rules \(\varnothing\Rightarrow p\), \(\{p\}\Rightarrow q\), \(\{p,q\}\Rightarrow r\), \(\{r\}\Rightarrow q\), and the constraint \(\{r,s\}\Rightarrow\bot\). What are the forward stages and the least model? Does the theory entail \(s\), or \(\neg s\)?

Show answerHide answer

The stages are \(X_0=\varnothing\), \(X_1=\{p\}\), \(X_2=\{p,q\}\), and \(X_3=\{p,q,r\}\). The next stage is unchanged, and \(n=4\) because \(s\) occurs in the constraint. Thus \(L_\Gamma=\{p,q,r\}\). Since \(s\notin L_\Gamma\), the constraint passes and this is the least model. The theory does not entail \(s\). It does entail \(\neg s\): every model contains \(r\), and the constraint then forces \(s\) to be false. The positive-consequence test concerns atoms; it is not a test saying that every atom outside the closure can independently be made true.

Can two rules start one another?

On distinct atoms \(p,q\), consider \(\{p\}\Rightarrow q\) and \(\{q\}\Rightarrow p\). Do these rules force either atom? What changes if the fact \(\varnothing\Rightarrow p\) is added? What if the constraint \(\{q\}\Rightarrow\bot\) is then also added?

Show answerHide answer

Without a fact, no body is contained in \(X_0=\varnothing\), so every stage is empty. The least model is empty and neither atom is forced. Both atoms may also be true: \(\{p,q\}\) is another model. A cycle permits truth to propagate once it is supplied; it does not supply a starting fact.

With the fact, the stages are \(\varnothing,\{p\},\{p,q\}\), followed by the same set. Both atoms are now forced. Adding the final constraint leaves the forward closure unchanged, but its body \(\{q\}\) is contained in the closure. The resulting theory is unsatisfiable. This also gives a failure of the positive-consequence equivalence without its satisfiability hypothesis: an atom \(r\) distinct from \(p,q\) is not in the closure, yet it is true in every model because there are no models.

Intersecting models preserves Horn rules

If \(\mathcal M\) is a nonempty family of models of a Horn theory \(\Gamma\), then \(\bigcap\mathcal M\) is a model of \(\Gamma\). Here the theory need not be finite, but every rule still has a finite body. In contrast, the clause \(p\lor q\), with distinct \(p,q\), has two models whose intersection is not a model.

Suppose a rule's body is contained in the intersection. It is then contained in every member of \(\mathcal M\). For a definite rule, satisfaction puts its head in every member, hence in their intersection. For a constraint, choose a member of the nonempty family; it could not contain that body, a contradiction. Thus every rule is satisfied. This argument in fact works for arbitrary bodies whenever their conjunction is interpreted by containment.

For the contrast, the true sets \(\{p\}\) and \(\{q\}\) both satisfy \(p\lor q\), but their intersection is empty and satisfies neither disjunct. Nonemptiness in the Horn assertion matters as well: the intersection of an empty family of subsets of \(P\) is \(P\), which violates any constraint with body contained in \(P\).

Ask which finite families of valuations Horn clauses can describe

For the remaining blocks, the whole atom set \(P\) is finite. A family \(\mathcal M\subseteq\mathcal P(P)\) is intersection closed when \(X,Y\in\mathcal M\) implies \(X\cap Y\in\mathcal M\). This requires binary intersections, hence all nonempty finite intersections by induction; it does not require the intersection of an empty family to belong to \(\mathcal M\). The empty family is therefore intersection closed.

The common Horn theory \(\Gamma_{\mathcal M}\) is the set of all Horn rules over \(P\) satisfied by every \(Y\in\mathcal M\). This is a finite theory: each rule has one of the finitely many bodies \(B\subseteq P\), and one of the \(|P|+1\) possible heads, counting \(\bot\). Every member of \(\mathcal M\) satisfies \(\Gamma_{\mathcal M}\) by its definition.

One Horn rule excludes each rejected valuation

If \(\mathcal M\) is intersection closed and \(X\subseteq P\) is not in \(\mathcal M\), there is a rule in \(\Gamma_{\mathcal M}\) that \(X\) violates.

Consider \(\mathcal M_X=\{Y\in\mathcal M:X\subseteq Y\}\). If this family is empty, the constraint \(X\Rightarrow\bot\) is satisfied by every allowed valuation: none contains its body. It is violated by \(X\) itself.

If \(\mathcal M_X\) is nonempty, it is finite because \(P\) is finite. Intersecting its members one at a time shows that \(C=\bigcap\mathcal M_X\) belongs to \(\mathcal M\). Also \(X\subseteq C\). Equality would put \(X\) in \(\mathcal M\), so some \(p\in C\setminus X\) exists. The definite rule \(X\Rightarrow p\) is true in every \(Y\in\mathcal M\): if its body is contained in \(Y\), then \(Y\in\mathcal M_X\) and \(p\in C\subseteq Y\). The rule is false in \(X\), where its body is true but its head is false.

In both cases the separating rule is one of the rules defining \(\Gamma_{\mathcal M}\). The body is a legal finite body, even when \(X\) is empty.

Intersection closure exactly characterizes finite Horn definability

For finite \(P\), a family \(\mathcal M\subseteq\mathcal P(P)\) is the exact family of models of a finite Horn theory if and only if it is intersection closed. In the forward direction binary intersections suffice; in the reverse direction the specific theory \(\Gamma_{\mathcal M}\) has exactly the models \(\mathcal M\).

The forward implication is applied to a pair of models. Conversely, each allowed valuation satisfies all rules of \(\Gamma_{\mathcal M}\). Each rejected valuation violates a rule by , so no other models occur. This proves exactness. The shared clause and CNF interpretation turns the same finite rule theory into a Horn CNF with the same valuations.

Definite rules additionally require the all-true valuation

For finite \(P\), a family \(\mathcal M\) is the model family of a finite theory of definite Horn rules if and only if it is intersection closed and contains \(P\), the all-true valuation.

Every definite rule is satisfied by \(P\), and intersections preserve its models. For the converse, \(P\in\mathcal M_X\) for every \(X\subseteq P\). Thus the nonempty case of always applies, giving a separating definite rule for each rejected valuation. The finite set of all definite rules true on \(\mathcal M\) therefore has exactly those models.

Can the empty family be Horn definable?

What theory defines the empty model family, and can a definite Horn theory do so? What happens when the atom set itself is empty?

Show answerHide answer

The single constraint \(\varnothing\Rightarrow\bot\) has no models. A definite theory cannot define the empty family because the all-true valuation satisfies every definite rule. When \(P=\varnothing\), its only valuation is \(\varnothing\). The empty rule theory defines the singleton family \(\{\varnothing\}\), and the same empty-body constraint defines the empty family. Both families are intersection closed, while only the first contains \(P\).
