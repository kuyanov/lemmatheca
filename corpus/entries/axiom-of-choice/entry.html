Making one selection for each member of a family

Let \((A_i)_{i\in I}\) be a family of nonempty sets, and put \(U=\bigcup_{i\in I}A_i\). A choice function is a function \(c:I\to U\) such that \(c(i)\in A_i\) for every \(i\in I\). The axiom of choice, abbreviated AC, says that every such set-indexed family has a choice function.

Each individual set being nonempty says that a suitable value exists for each index. AC supplies a single function making all those selections together. We will show that this principle is equivalent to two statements about orders. The arguments use ordinary set formation, including the Replacement principle, but invoke choice only where indicated.

Some families already provide a rule for choosing

A finite family of nonempty sets has a choice function without assuming AC. So does any family of nonempty subsets of a given well-ordered set.

Proof

For a finite family, induct on its number of indices. The empty family has the empty function. At the next step, choose a member of the one additional nonempty set and extend the earlier function. For subsets of a well-ordered set, assign to each subset its least member. Uniqueness specifies a function on the entire family. □

For example, nonempty subsets of \(\mathbb N\) have canonical least members. A general countably indexed family need not come with such a rule; finite induction by itself does not supply one function on all its indices.

What happens when emptiness is allowed?

Compare a family with no indices and a family containing an empty set.

Show answerHide answer

If \(I=\varnothing\), the empty function is the unique choice function. If \(A_i=\varnothing\) for some index \(i\), no choice function exists: its value at that index would have to belong to the empty set. Thus AC requires each member of the family to be nonempty, but allows the family itself to be empty.

Every set can be arranged in a well-order

The well-ordering principle says that every set admits a well-order. It asserts that some suitable order exists, not that any order already given is a well-order. For instance, the usual order on \(\mathbb R\) is not a well-order: the interval \((0,1)\) has no least point.

A well-order permits selection by least members and supports recursion. Its unique ordinal representative records the order, but the principle does not prescribe which order to use.

Chains with upper bounds lead to maximal elements

Zorn’s lemma states: if a nonempty partially ordered set \(P\) has an upper bound in \(P\) for every chain, then \(P\) has a maximal element. A chain is a subset whose points are pairwise comparable, and an upper bound \(u\) of a chain \(C\) satisfies \(c\le u\) for every \(c\in C\).

A maximal point \(m\) has no point strictly above it. A greatest point lies above every point of \(P\). These notions differ: in a two-point antichain both points are maximal, and neither is greatest. Zorn’s lemma guarantees maximality.

Here the empty subset counts as a chain. In a nonempty poset it has an upper bound, since any point is one. All posets and families under discussion are sets; we do not apply Zorn’s lemma to the collection of all ordinals.

Is it enough to bound every finite chain?

Every finite chain in \(\mathbb N\) has an upper bound. Does Zorn’s lemma give a largest natural number?

Show answerHide answer

No. The chain \(\mathbb N\) itself has no upper bound in \(\mathbb N\), so the hypothesis fails. Bounding only finite chains is insufficient. Moreover, the conclusion of Zorn’s lemma would be a maximal point; it would be greatest here because the order is total.

A set cannot contain distinct choices for arbitrarily long

For every set \(A\), there is an ordinal \(h\) for which no injection \(h\to A\) exists. This fact, called Hartogs’s theorem, does not require AC.

Proof

All well-orders on subsets of \(A\) form a set: their domains belong to \(\mathcal P(A)\), and their relations belong to \(\mathcal P(A\times A)\). Each has a unique ordinal type. Replacement collects these types into a set \(T\). Let \(h=\sup\{\alpha+1:\alpha\in T\}\), which exists by the supremum theorem.

If \(h\) injected into \(A\), transport its well-order to the image. This would make \(h\) one of the types in \(T\), and hence \(h+1\le h\), a contradiction. □

Only a set of order types is collected. There is no appeal to a set of all ordinals. The empty well-order is among the possibilities, so the bound also works when \(A\) is empty.

Choice lets us list an entire set in well-ordered stages

AC implies the well-ordering principle.

Proof

Fix a set \(A\). Apply AC to its nonempty subsets to obtain a selector \(s\), with \(s(B)\in B\). Fix a marker \(*\) outside \(A\), and an ordinal \(h\) as in . Use recursion on \(h\), with fixed value set \(A\cup\{*\}\). Given earlier values \(f\mathbin{\upharpoonright}\alpha\), let

\[ f(\alpha)= \begin{cases} s\bigl(A\setminus\operatorname{ran}(f\mathbin{\upharpoonright}\alpha)\bigr),&\text{if this remaining set is nonempty},\\ *,&\text{otherwise}. \end{cases} \]

This rule is defined for every history, so the recursion theorem applies. Before the first marker, each value is a new member of \(A\). If a marker never appeared, \(f\) would inject \(h\) into \(A\), contradicting the bound. Let \(\lambda\) be the first marker stage. At that stage nothing remains, so \(f\mathbin{\upharpoonright}\lambda\) is a bijection onto \(A\). Transfer the ordinal order of \(\lambda\) along it to well-order \(A\). For \(A=\varnothing\), the first marker occurs at zero and the resulting order is empty. □

A well-order prevents endless strict extension

The well-ordering principle implies Zorn’s lemma.

Proof

Let \(P\) satisfy Zorn’s hypotheses, and fix a well-order of its underlying set. Suppose there is no maximal point. Every chain \(C\) then has a strict upper bound: take an upper bound \(u\). If \(u\notin C\), every point of \(C\) is strictly below \(u\). If \(u\in C\), nonmaximality gives \(v>u\), which is strictly above all of \(C\). For the empty chain any point is a strict upper bound, vacuously.

Choose for each chain the least strict upper bound in the fixed well-order of \(P\). Recursively on a Hartogs bound \(h\) for \(P\), make the next value this chosen bound of the earlier values. To define the rule on all possible histories, use a fixed point of the nonempty set \(P\) whenever the history has no strict upper bound.

Induction shows that the actual history is always a chain and that every new value is strictly above all earlier values. At a limit, any two earlier values already occur together at an earlier stage. Thus the fallback is never used, and the recursion gives an injection \(h\to P\). This contradicts . A maximal point must exist. □

A maximal partial selection must select everywhere

Zorn’s lemma implies AC.

Proof

For a family \((A_i)_{i\in I}\) of nonempty sets, order its partial choice functions by extension of their graphs. These graphs are subsets of \(I\times U\), where \(U=\bigcup_i A_i\), so they form a set. The empty graph is one such function.

The union of a chain of partial choice functions is a partial choice function: any two assigned values at the same index occur together in one of the functions in the chain, and therefore agree. Every assigned value still belongs to the required set. The union extends every member of the chain; the empty chain has the empty function as an upper bound.

Zorn gives a maximal partial function \(c\). If an index \(i\) were missing from its domain, take one member \(a\in A_i\). Adjoining \((i,a)\) would properly extend \(c\), a contradiction. Thus \(c\) is defined on all of \(I\). Choosing this one witness in a contradiction argument does not assume a simultaneous choice function for the original family. □

The three principles have the same strength

The axiom of choice, the well-ordering principle, and Zorn’s lemma are equivalent.

Proof

The preceding results give the cycle AC implies well-ordering, well-ordering implies Zorn, and Zorn implies AC. Following the cycle yields every other implication. There is also a direct proof that well-ordering implies AC: well-order the union of a family of nonempty sets and choose the least member of each set. □

The principles offer different ways to express the same assumption. Choice functions specify selections, well-orders permit least-element arguments and recursion, and Zorn’s lemma turns closure under chains into a maximal object.

Choice is also a way to reverse surjections

AC is equivalent to the assertion that every surjection \(p:E\to I\) has a section: a map \(s:I\to E\) with \(p\circ s=\operatorname{id}_I\).

Proof

Under AC, choose one point of every nonempty fiber \(p^{-1}(\{i\})\); these choices form a section. Conversely, for nonempty sets \(A_i\), let \(E=\{(i,a):i\in I,\ a\in A_i\}\). Projection onto \(I\) is surjective. A section has the form \(s(i)=(i,c(i))\), and its second coordinates give a choice function. Empty index sets cause no difficulty. □

Two incomparable points can be placed in order

Let \(R\) be a strict partial order on \(A\), and write \(\le_R\) for its reflexive closure. If \(a,b\) are incomparable, the relation

\[ R'=R\cup\{(x,y):x\le_R a\text{ and }b\le_R y\} \]

is a strict partial order extending \(R\) and containing \((a,b)\).

Proof

A new loop at \(x\) would imply \(b\le_R x\le_R a\), contrary to incomparability. For transitivity, two old comparisons compose in \(R\). An old comparison followed by a new one still has its first point below \(a\); a new comparison followed by an old one still has its last point above \(b\). In either case the composed comparison is new or already old. Two new consecutive comparisons would require \(b\le_R y\le_R a\) at their middle point, which is impossible. Thus \(R'\) is irreflexive and transitive. The pair \((a,b)\) is genuinely new. □

Every partial order can be extended to a total order

Assuming AC, every partial order on a set \(A\) has a total order extension on the same set.

Proof

Let \(R_0\) be its strict part. Order by inclusion the set of all strict partial orders on \(A\) containing \(R_0\). It is nonempty because it contains \(R_0\). The union of a chain is irreflexive. It is transitive because any two consecutive comparisons in the union belong together to one member of the chain. The union is therefore an upper bound; for the empty chain use \(R_0\).

Zorn gives a maximal relation \(R\). If two points were incomparable, would produce a larger strict partial order, contradicting maximality. Thus \(R\) compares every pair of distinct points. Its reflexive closure is the required total order and preserves every original comparison. The construction also covers the empty set. □

Maximality here concerns inclusion of order relations. It does not claim that the elements of \(A\) themselves have a greatest point.

Must an extension be unique or well-ordered?

What total extensions does a two-point antichain have? Does the extension theorem ensure a well-order?

Show answerHide answer

Its two total extensions put either point first, so uniqueness fails. Totality alone does not ensure well-ordering. Indeed, an extension of the usual total order on \(\mathbb Z\) must keep that order, which has no least element. The well-ordering principle gives some well-order of the underlying set; it need not preserve a previously specified partial order.

The first uncountable ordinal exists without Choice

The bound in is the Hartogs number \(h(A)\): the least ordinal that does not inject into \(A\). Indeed, if \(\beta<h(A)=\sup_{\alpha\in T}(\alpha+1)\), then \(\beta\le\alpha\) for some \(\alpha\in T\). Restricting the corresponding enumeration injects \(\beta\) into \(A\). The bound itself does not inject.

Define \(\omega_1=h(\omega)\). It is the first uncountable ordinal: its members are exactly the ordinals admitting an injection into \(\omega\), which are the countable ordinals. Conversely, a countable ordinal cannot be at least \(\omega_1\), since restricting its injection would inject \(\omega_1\) into \(\omega\).

Every countable ordinal \(\alpha\) has countable successor \(\alpha+1\): shift an injection of \(\alpha\) into \(\omega\) to the positive integers and send the new point to zero. Thus \(\omega_1\) is a limit ordinal. It is not the successor \(\omega+1\), which is still countable. This construction takes place in ZF and assumes no Choice.

Comparability of all sizes is equivalent to Choice

Over ZF, AC is equivalent to the assertion that for every two sets \(A,B\), there is an injection \(A\to B\) or an injection \(B\to A\).

Proof

Under AC, well-order both sets. Their ordinal types are comparable by ordinal comparison; inclusion of the smaller type into the larger gives the required injection after transporting it to the sets.

Conversely, compare any set \(A\) with its Hartogs bound \(h\). There is no injection \(h\to A\), so comparability supplies an injection \(A\to h\). Pull back the ordinal order along this injection to well-order \(A\). The well-ordering principle implies AC by . □

Cantor–Schröder–Bernstein proves that injections in both directions give equal sizes without Choice. Comparability asks for at least one direction for every pair of sets, and this stronger assertion is precisely where AC is needed.

Every chain extends to a maximal chain

The Hausdorff maximal principle says that every chain in a partially ordered set is contained in a chain maximal under inclusion. Over ZF it is equivalent to AC.

Proof

Assume Zorn's lemma and fix a chain \(C_0\) in a poset \(P\). Order the set of chains containing \(C_0\) by inclusion. It is nonempty, and the union of a nonempty inclusion-chain is again a chain containing \(C_0\): two of its points occur together in one constituent. For the empty inclusion-chain use \(C_0\) as an upper bound. Zorn gives a maximal chain extending \(C_0\).

Conversely, suppose the maximal principle holds and \(P\) satisfies Zorn's hypotheses. Extend the empty chain to a maximal chain \(C\), and let \(u\) be an upper bound for \(C\). Since \(C\cup\{u\}\) is a chain, maximality forces \(u\in C\). If \(v>u\), then \(C\cup\{v\}\) would be a larger chain. Thus \(u\) is maximal in \(P\), proving Zorn's lemma and hence AC. □

Finite tests lead to maximal members

A family \(\mathcal F\subseteq\mathcal P(X)\) has finite character if, for every \(A\subseteq X\), membership \(A\in\mathcal F\) is equivalent to every finite subset of \(A\) belonging to \(\mathcal F\). Tukey's lemma says that if \(\mathcal F\) is nonempty and has finite character, every \(A_0\in\mathcal F\) extends to an inclusion-maximal member. Over ZF it is equivalent to AC.

Proof

Assume Zorn's lemma. Order the members of \(\mathcal F\) containing \(A_0\) by inclusion. For a nonempty chain, every finite subset of its union lies in one chain member: find a containing member for each of the finitely many points and take the largest of those finitely many members. Finite character puts the finite subset, and then the union, in \(\mathcal F\). The empty chain has upper bound \(A_0\). Zorn supplies a maximal extension.

Conversely, the family of chains in any poset has finite character: a subset is a chain exactly when every two of its points are comparable, and this is detected on finite subsets. Tukey's lemma therefore gives the Hausdorff maximal principle, and hence AC. □

Finite character includes the empty subset in its tests. A nonempty family of finite character must contain the empty set.
