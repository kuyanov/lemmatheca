Choose the allowed truth functions before forming terms

A Boolean operation of arity \(n\ge 0\) is a function \(f:\{0,1\}^n\to\{0,1\}\). A basis \(S\) is a set of such operations, each retaining its arity. An \(S\)-term on inputs \(x_1,\ldots,x_m\) is an input, or an expression \(f(t_1,\ldots,t_n)\) with \(f\in S\) and already formed \(S\)-terms \(t_i\). Repetition of a term is allowed. A nullary operation supplies a term without requiring any inputs. Every term is finite, even if \(S\) is infinite.

Evaluate a term by evaluating its children and then applying the displayed operation. We say that \(S\) generates an operation when some term has precisely that truth function. Inputs not used in the term are harmless dummy inputs. This extends the familiar propositional formation rules: the usual connectives are particular Boolean operations. Conversely each allowed operation can be expanded into its canonical DNF, so the evaluation remains the same ordinary truth-table semantics.

Substitution composes generated truth functions

If \(f\) has arity \(n\) and each \(g_i\) has arity \(m\), their superposition is

\[f(g_1,\ldots,g_n)(u)=f(g_1(u),\ldots,g_n(u)).\]

If all these functions are generated by \(S\), replacing the inputs of a term for \(f\) by terms for the \(g_i\) gives a term for this superposition. Induction on the outer term proves the displayed evaluation identity, just as in the substitution principle. Every input projection is generated by an input term.

The basis is complete for positive arities if it generates every operation of every arity \(m\ge1\). It is fully complete if it also generates both operations of arity zero. The latter is the completeness convention including zero inputs. A closed term has no input occurrences. A unary term whose value happens to be constant is not thereby a closed term.

Five restrictions on a Boolean truth table

Write \(\bar u\) for the row obtained by reversing every bit of \(u\), and order bits by \(0\le1\). For rows, \(u\le v\) means coordinatewise comparison. Use \(a\oplus b\) for exclusive or, equal to one exactly when the bits differ. A Boolean operation \(f\) has the following properties:

The five restrictions preserved by composition
PropertyDefining condition
Zero preserving\(f(0,\ldots,0)=0\).
One preserving\(f(1,\ldots,1)=1\).
Monotone\(u\le v\) implies \(f(u)\le f(v)\).
Self-dual\(f(\bar u)=\neg f(u)\) for every row \(u\).
AffineFor some bit \(c\) and some set of positions \(I\subseteq\{1,\ldots,n\}\), \(f(u)=c\oplus\bigoplus_{i\in I}u_i\).

The empty exclusive-or sum is zero. Constants are affine by taking \(I=\varnothing\); a projection is affine by taking one position and \(c=0\). All five conditions apply to nullary operations too: monotonicity is automatic, self-duality is impossible, and zero or one preservation tests the single value. The affine condition is also called a parity or counting condition: changing a selected input reverses the output, while an unselected input never changes it.

Each restriction passes from the gates to the whole term

For each one of the five properties, if every operation in \(S\) has that property, every operation generated by \(S\) has it.

Projections have each property. For zero preservation, if all original inputs are zero, the induction hypothesis makes every child zero, so the outer operation returns zero. The one-preserving case is identical. For monotonicity, increasing the original inputs cannot decrease any child value; monotonicity of the outer operation then cannot decrease the result. For self-duality, reversing the original row reverses every child value by induction, so self-duality of the outer operation reverses its output.

For affineness, substitute the affine expressions for the children into the affine expression of the outer operation. Exclusive or is associative and commutative, and \(b\oplus b=0\). Thus constants combine to one bit, and each original input remains precisely when it occurs an odd number of times. The result is again a constant exclusive-or sum of a selected set of original inputs. These identities follow from the two-bit truth table, so no linear-algebra assumption is being used. Structural induction on the term proves all assertions, including nullary applications.

A complete basis must escape every restriction

If \(S\) is complete for positive arities, then, for each of the five properties, some operation in \(S\) fails it. The witnesses need not be distinct.

Otherwise all generated functions would have the missing property's restriction by . Negation fails zero preservation, one preservation and monotonicity. A unary constant fails self-duality. Conjunction is not affine: changing its first input has no effect when the second is zero, but reverses the output when the second is one. In an affine expression each selected coordinate always reverses the output and each unselected coordinate never does. Completeness for positive arities requires these unary and binary functions, giving the contradictions.

A failure of monotonicity contains one descending edge

If \(f\) is not monotone, there are two rows differing in just one position, with that position changing from zero to one, on which the output changes from one to zero.

Choose \(a\le b\) with \(f(a)=1\) and \(f(b)=0\). Change the coordinates where \(a\) and \(b\) differ one at a time, in their numerical order. This gives a finite path from \(a\) to \(b\), each step increasing one bit. Since its output starts at one and ends at zero, take the first row on the path whose output is zero. The preceding row has output one, and their step is the required edge. The path is nonempty, so this argument also shows that a nonmonotone operation has positive arity.

Three failures already provide negation

If \(S\) contains an operation that is not one preserving, one that is not zero preserving, and one that is not monotone, then \(S\) generates unary negation.

Let the first two operations be \(a,b\). Put \(u(p)=a(p,\ldots,p)\) and \(v(p)=b(p,\ldots,p)\); a nullary operation is simply evaluated without arguments. We have \(u(1)=0\) and \(v(0)=1\). If \(u(0)=1\), then \(u\) is negation. If \(v(1)=0\), then \(v\) is negation. In the remaining case, \(u\) is the constant-zero unary function and \(v\) the constant-one unary function.

Take a descending edge of the supplied nonmonotone operation \(h\), from . Substitute the available unary constant functions into all its unchanged positions, according to their fixed bits, and substitute \(p\) into its changing position. At \(p=0\) the result is one; at \(p=1\) it is zero. Superposition therefore supplies a term for negation. This argument constructs a unary function and does not claim that either constant term has no input occurrences.

A failure of self-duality provides constant-valued unary terms

If \(S\) generates negation and contains a non-self-dual operation, it generates both unary constant functions.

Non-self-duality gives a row \(z\) with \(f(z)=f(\bar z)=c\): two bits fail to be opposites exactly when they are equal. In position \(i\), substitute \(p\) if \(z_i=1\) and \(\neg p\) if \(z_i=0\). The argument row is \(z\) at \(p=1\), and \(\bar z\) at \(p=0\), so the resulting unary term is constantly \(c\). Negating this term gives the other constant. If \(f\) is nullary the same construction is its constant value, with no positions to fill.

Measure what one input flip changes

For a Boolean operation \(f\), a position \(i\), and a row \(u\), define its coordinate difference

\[\Delta_i f(u)=f(u[i:=0])\oplus f(u[i:=1]).\]

The replacement notation changes just position \(i\). The difference is zero when that flip preserves the output and one when it reverses the output. It ignores the original value \(u_i\), since both replacements are performed.

Affineness is exactly constancy of every coordinate difference

An operation \(f\) is affine if and only if, for every position \(i\), the function \(u\mapsto\Delta_i f(u)\) is constant.

In an affine expression, replacing position \(i\) cancels every other summand in the exclusive or. The difference is one if \(i\in I\) and zero otherwise, independently of the row.

Conversely, suppose each difference is the constant bit \(d_i\), and put \(c=f(0,\ldots,0)\). For a row \(u\), begin at the all-zero row and visit positions \(1,\ldots,n\). At step \(i\), leave that coordinate zero if \(u_i=0\), and change it to one if \(u_i=1\). The defining identity for the constant difference says that the value after this step is the preceding value exclusive or \(d_i\) in the latter case. Induction on the visited positions gives

\[f(u)=c\oplus\bigoplus_{\{i:u_i=1\}}d_i=c\oplus\bigoplus_{\{i:d_i=1\}}u_i.\]

This is the required affine expression. With no positions, the operation is already constant, so the equivalence also covers arity zero. In particular, a nonaffine operation has one position whose difference takes both values zero and one. This is the precise bridge to the source's counting condition.

A nonaffine operation yields a binary table of odd parity

If \(S\) generates negation and both unary constants and contains a nonaffine operation, it generates a binary operation \(h\) whose four outputs have exclusive-or sum one.

By , choose a position \(i\) and rows \(u,v\) with \(\Delta_i f(u)=0\) and \(\Delta_i f(v)=1\). In position \(i\), substitute the input \(q\). In every other position \(j\), choose a unary function of \(p\) that equals \(u_j\) at zero and \(v_j\) at one. The four possibilities are the two constants, \(p\), and \(\neg p\), all available. This defines a generated binary operation \(h(p,q)\), with

\[h(0,0)=h(0,1),\qquad h(1,0)\ne h(1,1).\]

The first pair has exclusive-or sum zero and the second has sum one. Hence all four outputs have sum one, so exactly one or exactly three of them are one. The construction needs no assumption that the chosen rows themselves differ in only one coordinate.

Negating inputs and output turns an odd table into conjunction

If \(S\) generates negation and a binary operation with odd output parity, it generates binary conjunction.

Such a table has one exceptional row \((a,b)\): all other rows have a common value \(c\), and the exceptional row has value \(\neg c\). For a bit \(a\), put \(\ell_a(p)=p\) when \(a=1\), and \(\ell_a(p)=\neg p\) when \(a=0\). Then \(\ell_a(p)=a\) holds exactly when \(p=1\). Thus

\[k(p,q)=h(\ell_a(p),\ell_b(q))\]

takes its exceptional value exactly when \(p=q=1\). If \(c=0\), this is conjunction. If \(c=1\), negating \(k\) is conjunction. Each input change and possible output negation is a generated operation, so superposition completes the construction.

Escaping all five restrictions is necessary and sufficient

A basis \(S\) is complete for positive arities if and only if, for each of zero preservation, one preservation, monotonicity, self-duality and affineness, some operation in \(S\) fails that property. This is Post's functional completeness criterion.

Necessity is . For sufficiency, the first three failures supply negation by . The self-duality failure supplies both unary constants by . The affine failure supplies an odd binary table by , and then conjunction by . Negation and conjunction also give disjunction by De Morgan's identity.

Fix any arity \(m\ge1\) and a desired truth table. Its canonical DNF is built from negation, conjunction, disjunction and constants. Replace each connective by its generated term. Whenever a constant is needed, use its unary constant term with the available input \(x_1\) substituted for its input. These replacements introduce no new inputs. Induction through the DNF construction therefore gives an \(S\)-term for exactly the desired table.

Zero inputs require a genuine closed term

A basis \(S\) is fully complete if and only if it escapes all five restrictions and has a closed term. Equivalently, the extra condition is that \(S\) contains a nullary operation.

Full completeness includes completeness for positive arities and a term for a nullary truth function, so the two stated conditions are necessary. Conversely, supplies completeness for positive arities. Take a closed term \(E\). Substitute it for the one input of the generated unary constant-zero and constant-one terms. Substitution preserves evaluation and creates no input occurrences, giving closed terms for both nullary functions. The positive arities were already covered.

A nullary operation immediately gives a closed term. In the other direction, every finite term tree has a leaf. A leaf of a closed term cannot be an input, so it is a nullary operation from \(S\). Equivalently, induction on the term shows that, without a nullary operation, every term must contain an input occurrence. This distinguishes an identically constant unary function from an expression usable with no inputs at all.

Why does NAND succeed while exclusive or and negation fail?

Apply the criterion to the binary NAND operation alone, and to the basis consisting of exclusive or and negation. What changes for NAND when zero inputs must also be represented?

Show answerHide answer

NAND has table values one, one, one, zero on rows \(00,01,10,11\). It fails zero preservation and one preservation. The increase from \(00\) to \(11\) lowers its output, so it is not monotone. Its values on the opposite rows \(01,10\) are equal, so it is not self-dual. Its first-coordinate difference is zero when the second input is zero and one when the second input is one; hence it is not affine. It therefore supplies all five witnesses by itself and is complete for positive arities, agreeing with the explicit NAND construction. It has no nullary operation, so it is not fully complete. Adding either nullary constant supplies the missing closed term.

Exclusive or and negation are both affine: they have forms \(p\oplus q\) and \(1\oplus p\). Every generated operation is consequently affine. Conjunction is not, so this basis is not complete for positive arities, even after either or both nullary constants are added. Constants too are affine.

Must one operation fail all five conditions?

Does a basis that is complete for positive arities have to contain an operation that itself belongs to none of the five classes? Test the familiar basis consisting of negation and conjunction.

Show answerHide answer

No. Negation is self-dual and affine, so it is not a witness against those two restrictions. Conjunction is zero preserving, one preserving and monotone, so it fails none of those three restrictions. But negation fails those first three, while conjunction fails self-duality (its values at \(01,10\) are both zero) and affineness. Together they meet all five requirements, and the basis is complete for positive arities. The quantifiers are “for each property, there exists an operation,” allowing a different operation for different properties.
