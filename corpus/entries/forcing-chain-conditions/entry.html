The chain condition is measured inside the ground model

A forcing order \(P\) satisfies the countable chain condition, abbreviated ccc, if every forcing antichain in \(P\) is countable. Countable includes finite and empty sets.

For the model assertions in this entry, let \(M\) be an externally countable transitive set model of ZFC, let \(P,\le,1_P\in M\) be forcing-order data, and let \(G\subseteq P\) be \(M\)-generic, as in the extension convention. The required hypothesis is

\[M\models\text{“}\,P\text{ is ccc.”}\]

Thus every antichain \(A\in M\) is countable in \(M\): it has a finite enumeration or an enumeration by \(\omega\) belonging to \(M\). Compatibility and being an antichain for a supplied \(A\in M\) are absolute, since their quantifiers are bounded by the order data. Countability need not be absolute in the reverse direction. In fact every subset of \(P\) is externally countable, since \(P\subseteq M\); that observation alone supplies no internal enumeration.

A named ordinal can be decided after strengthening

Under the ground-model convention of , let \(\tau\in M\) be a \(P\)-name and suppose \(p\Vdash\text{“}\tau\text{ is an ordinal.”}\) Put

\[D=\{q\le p:\exists\beta\in\operatorname{Ord}^M\ (q\Vdash\tau=\check\beta)\}.\]

Then \(D\in M\) and \(D\) is dense below \(p\). Each \(q\in D\) decides a unique such \(\beta\). If also \(p\Vdash\tau\in\check\delta\), where \(\delta\in M\) is an ordinal, every decided value is below \(\delta\).

The definability theorem makes the displayed property a fixed first-order formula over \(M\), so Separation gives \(D\in M\). The ordinal quantifier is a class quantifier inside that formula; we have not formed a set of all ordinals.

For \(r\le p\), take a generic filter \(H\) through \(r\). The value \(\tau[H]\) is an ordinal of \(M[H]\), hence an ordinal \(\beta\in M\), because the extension has exactly the ground ordinals. The truth lemma supplies \(s\in H\) forcing \(\tau=\check\beta\). A common refinement \(q\in H\) of \(s,r\) still forces this equality and lies below \(r\). Thus \(q\in D\), proving density. Density below a fixed condition is absolute for these ground sets, so this is also the density statement used inside \(M\).

If one condition decided two values, a generic through it would give \(\beta=\tau[H]=\gamma\), proving uniqueness. If it also lies below \(p\) and \(p\) forces membership in \(\check\delta\), the same generic gives \(\beta\in\delta\). These are actual ordinal equalities and membership assertions.

Choose a countable antichain of actual deciding conditions

Assume \(M\models\text{“}P\text{ is ccc”}\), and let \(D\in M\) be dense below \(p\). There is \(A\in M\), with \(A\subseteq D\cap\{q:q\le p\}\), such that \(A\) is an antichain, is countable in \(M\), and every \(q\le p\) is compatible with some \(a\in A\). Every \(M\)-generic filter containing \(p\) meets \(A\).

Inside \(M\), apply Zorn's lemma to the antichains contained in \(D\cap\{q:q\le p\}\), ordered by inclusion. The empty set is allowed, and the union of an inclusion chain is an antichain: two of its members occur together in one member of the chain. Hence there is a maximal such \(A\in M\).

If \(q\le p\) were incompatible with every member of \(A\), density would give \(r\le q\) in \(D\). This \(r\) would also be incompatible with all of \(A\), so could be adjoined, a contradiction. This proves the stated maximality below \(p\). Internal ccc now makes \(A\) internally countable.

Let \(A^\downarrow=\{r:\exists a\in A\ (r\le a)\}\). The set

\[E=A^\downarrow\cup\{q:q\perp p\}\]

belongs to \(M\) and is dense in \(P\). Indeed, if \(q\) is compatible with \(p\), refine them to \(r\le q,p\); then refine \(r\) and a compatible member of \(A\) to a member of \(A^\downarrow\) below \(q\). If \(q\perp p\), it already belongs to \(E\). A generic containing \(p\) cannot contain a condition incompatible with \(p\), since any two filter members have a common refinement. It therefore meets \(A^\downarrow\), and upward closure then makes it meet \(A\). This is the maximal-antichain test applied below a condition.

One named ordinal has a countable ground set of possible values

Assume the standing ground-model convention and internal ccc. If \(p\Vdash\text{“}\tau\text{ is an ordinal”}\), there is a set \(C\in M\) of ordinals, countable in \(M\), such that

\[p\in H\text{ and }H\text{ is }M\text{-generic}\quad\Longrightarrow\quad\tau[H]\in C.\]

If \(p\Vdash\tau\in\check\delta\) for an ordinal \(\delta\in M\), we may take \(C\subseteq\delta\).

Use and to choose an internally countable deciding antichain \(A\in M\) below \(p\). For each \(a\in A\), there is a unique ordinal \(\beta_a\) with \(a\Vdash\tau=\check\beta_a\). This relation is definable in \(M\). Replacement there forms the function \(a\mapsto\beta_a\) and its range \(C\in M\). An image of an internally countable set is internally countable.

A generic \(H\) containing \(p\) meets \(A\), say at \(a\). Semantic forcing gives \(\tau[H]=\beta_a\in C\). In the bounded case every \(\beta_a<\delta\) by , so the same construction has \(C\subseteq\delta\). The antichain consists of actual deciding conditions; a list of candidate names alone would not provide this conclusion.

Bound a new function by a ground union of countable sets

Assume the standing convention and internal ccc. Let \(\alpha,\delta\in M\) be ordinals, and suppose \(p\) forces that a ground-model name \(\dot f\) is a function from \(\check\alpha\) to \(\check\delta\). There is a family \((C_\xi)_{\xi<\alpha}\in M\) such that each \(C_\xi\subseteq\delta\) is countable in \(M\), and every generic \(H\) through \(p\) satisfies

\[\begin{aligned}\dot f[H](\xi)&\in C_\xi\quad(\xi<\alpha),\\[3pt] \operatorname{ran}(\dot f[H])&\subseteq U:=\bigcup_{\xi<\alpha}C_\xi.\end{aligned}\]

Moreover \(U\in M\), and its cardinality computed in \(M\) satisfies

\[|U|^M\le\max(\aleph_0,|\alpha|^M).\]

For each \(\xi<\alpha\), the deciding-conditions argument applies to the assertion \(\dot f(\check\xi)=\check\beta\): any generic through a refinement of \(p\) has exactly one such value \(\beta<\delta\), and the truth lemma supplies a stronger condition deciding it. The assertion is a fixed membership-language formula expressing function evaluation; no new function-symbol forcing relation is needed. The antichain construction and Replacement therefore produce a suitable \(C_\xi\) in \(M\).

These witnesses can be assembled inside \(M\), rather than selected externally one at a time. Their defining property is uniform in \(\xi\). Collection first gives a set containing a candidate for every \(\xi\), and Choice inside \(M\) selects one candidate at each index. Replacement collects the chosen family, and Union produces \(U\). Thus all sets and choices in the displayed ground cardinal estimate belong to \(M\).

Inside \(M\), choose for each nonempty \(C_\xi\) an injection into \(\omega\). To inject \(U\) into \(\alpha\times\omega\), assign \(\beta\in U\) to its least index \(\xi\) with \(\beta\in C_\xi\), together with its code in that injection. Distinct \(\beta\)'s have distinct pairs. If \(\alpha=0\), then \(U=\varnothing\); otherwise the same estimate and infinite cardinal multiplication give the asserted upper bound, including finite \(\alpha\). Finally the coordinate conclusions follow from the deciding antichains met by \(H\), so their union contains the actual range.

The countable chain condition preserves every cardinal

Let \(M\) be an externally countable transitive set model of ZFC, let its forcing order satisfy \(M\models\text{“}P\text{ is ccc”}\), and let \(G\) be \(M\)-generic. Then \(M\) and \(M[G]\) have exactly the same cardinal ordinals. This includes singular cardinals.

The extension theorem gives transitive ZFC-models with the same ordinals; in particular, their set of natural numbers is identical. Each finite ordinal has exactly its usual finite set of predecessors in both models. No smaller finite ordinal surjects onto a larger one, or onto \(\omega\). Hence the finite cardinals and \(\omega\) remain cardinals. This case uses finite-set and ordinal absoluteness, rather than an estimate claimed to be strictly below \(\omega\).

Now let \(\kappa\) be an uncountable cardinal of \(M\). If it ceased to be a cardinal in \(M[G]\), Choice there would give a surjection \(f:\alpha\to\kappa\) for some ordinal \(\alpha<\kappa\). Choose a ground-model name \(\dot f\) for \(f\). The truth lemma supplies \(p\in G\) forcing that it is such a surjection. The ground ordinals \(\alpha,\kappa\) have canonical names, so gives a ground set \(U\subseteq\kappa\) containing its range, with

\[|U|^M\le\max(\aleph_0,|\alpha|^M)<\kappa.\]

The strict inequality holds because \(\kappa\) is an uncountable ground cardinal and \(\alpha<\kappa\); no regularity assumption is used. In \(M\), choose \(\beta\in\kappa\setminus U\). Membership in these ground sets is unchanged, so \(\beta\) is still outside the range of \(f\) in \(M[G]\), contradicting surjectivity.

Conversely, if an ordinal was not a cardinal in \(M\), a ground bijection with a smaller ordinal still exists in \(M[G]\). Being a bijection between these supplied sets is absolute. It therefore cannot become a cardinal. This proves equality of the cardinal ordinals in both directions.

Cofinalities are preserved as well

Under the hypotheses of , every ground-model ordinal \(\delta\) satisfies \(\operatorname{cf}^{M[G]}(\delta)=\operatorname{cf}^M(\delta)\).

Cofinality zero for \(0\), and cofinality one for successor ordinals, are immediate in both models. Let \(\delta\) be a nonzero limit ordinal and put \(\mu=\operatorname{cf}^M(\delta)\). By regularity of cofinality, \(\mu\) is an infinite regular cardinal in \(M\). A ground cofinal map \(\mu\to\delta\) remains cofinal: its assertion quantifies only over the fixed ordinals and its fixed graph. Cardinal preservation keeps \(\mu\) a cardinal, so the extension cofinality is at most \(\mu\).

If \(\mu=\omega\), it cannot become smaller: a finite subset of a limit ordinal is bounded, since its maximum, when nonempty, has successor still below \(\delta\). Thus there is no finite cofinal map, and the old countable cofinal map proves equality.

Suppose \(\mu>\omega\) and, towards a contradiction, the extension has a cofinal map \(f:\lambda\to\delta\), where \(\lambda<\mu\). Taking a name and a condition in \(G\) forcing this property, supplies a ground set \(U\subseteq\delta\) containing its range and satisfying \(|U|^M\le\max(\aleph_0,|\lambda|^M)<\mu\). Inside \(M\), the definition of \(\mu=\operatorname{cf}(\delta)\) implies that \(U\) is not cofinal. Hence there is \(\gamma<\delta\) such that every member of \(U\) is below \(\gamma\). To see the strict bound, first obtain a point no member of \(U\) reaches, using the failure of cofinality; \(\delta\)'s being a limit handles the empty set as well.

This bound is a ground ordinal assertion about ground sets, so it remains valid in the extension. It bounds the range of \(f\), contradicting cofinality. Hence extension cofinality cannot be smaller than \(\mu\), and the two cofinalities agree. This argument uses countable possible values and the ground cofinality separately from the cardinal-preservation theorem.

Finite binary maps satisfy the chain condition

For any set \(I\), let \(\operatorname{Fn}(I,2,{<}\omega)\) be the finite partial functions from \(I\) to \(\{0,1\}\), ordered by reverse inclusion: \(q\le p\) means that \(q\) extends \(p\). This order is ccc. Consequently, if \(I\in M\), then \(M\) regards its finite-binary-map order as ccc, and its generic extensions preserve all cardinals and cofinalities.

Two finite maps are compatible exactly when they agree on their common domain; their union then gives a common extension, by the finite-map compatibility criterion. If an antichain were uncountable, the delta-system argument would give an uncountable pairwise compatible subfamily. Such a subfamily contains two distinct maps, contradicting the antichain property. Thus every antichain is countable.

This is a ZFC argument for arbitrary \(I\), so it can be carried out inside \(M\) for its set \(I\). It establishes the internal hypothesis needed for and . Externally counting the conditions would not establish that hypothesis.

Taking the index set to be \(\omega\times\omega_2^M\) gives the many-coordinate Cohen order. Its named injection of columns, together with cardinal preservation, produces a generic extension in which CH fails under the same countable-transitive-ground-model hypothesis.

Countable orders can preserve cardinals while adding a real

If \(M\models\text{“}P\text{ is countable”}\), then \(M\models\text{“}P\text{ is ccc”}\). In particular the finite-binary-map order on \(\omega\) preserves all cardinals and cofinalities, yet its generic extension contains a new binary sequence.

Inside \(M\), restrict an enumeration of \(P\) to any subset to see that every antichain is countable. For the particular order, its finite domains and finite bit assignments can be coded by natural numbers, so it is internally countable. The preservation conclusions follow from the two main theorems. Meanwhile the Cohen union is a total binary sequence and differs from every ground binary sequence; its explicit name puts it in the extension. Preservation of cardinal ordinals therefore allows new subsets of an old cardinal.

Does external countability supply the required chain condition?

For an externally countable transitive \(M\), must \(M\models\text{“}P\text{ is ccc”}\) hold for every forcing order \(P\in M\), since \(P\) is externally countable?

Show answerHide answer

No. In \(M\), take one condition \(a_\xi\) for each \(\xi<\omega_1^M\), together with a largest condition \(1\), and order them by \(a_\xi\le1\), with no comparisons between distinct \(a_\xi\)'s. Distinct \(a_\xi,a_\eta\) have no common refinement, so \(A=\{a_\xi:\xi<\omega_1^M\}\in M\) is an antichain internally in bijection with \(\omega_1^M\). Thus \(M\) regards it as uncountable and regards \(P\) as failing ccc. Externally the entire set \(P\subseteq M\), including \(A\), is countable. The missing internal enumeration is exactly what prevents the external observation from proving the hypothesis.

Must the possible values lie below one smaller ordinal?

If \(\kappa\) is an uncountable ground cardinal and \(\alpha<\kappa\), must a union of \(\alpha\) countable subsets of \(\kappa\) be bounded below \(\kappa\)? Would the bound in be strictly below \(\kappa\) also when \(\kappa=\omega\)?

Show answerHide answer

Neither assertion holds. In the ground model, let \(\kappa=\aleph_\omega\) and \(C_n=\{\aleph_n\}\) for \(n<\omega\). Every \(C_n\) is a singleton, yet their union is cofinal in \(\kappa\). Its cardinality is only \(\aleph_0<\kappa\). The cardinal-preservation proof uses this smaller cardinality to leave some ordinal outside the union; it never asserts that the union is bounded. For cofinality preservation, the relevant bound is instead below \(\operatorname{cf}^M(\delta)\), as used in the separate proof.

For \(\kappa=\omega\), take \(\alpha=1\) and \(C_0=\omega\). Then \(\max(\aleph_0,|\alpha|)=\aleph_0\) equals \(\kappa\). This explains why the proof treats finite cardinals and \(\omega\) by absoluteness before applying the strict union-cardinality estimate to uncountable cardinals.
