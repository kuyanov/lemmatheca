A uniform list with exactly one name for each enumerable set

A family \((U_n)_{n\in\mathbb N}\) of subsets of \(\mathbb N\) is uniformly computably enumerable if

\[\{\langle n,y\rangle:y\in U_n\}\]

is c.e., using the fixed numerical pairing. A Friedberg numbering of the c.e. sets is such a family for which every c.e. set occurs as exactly one row. Equivalently, all rows are distinct and, for every standard domain \(W_e\), there is an \(n\) with \(U_n=W_e\).

The standard family \(W_e=\{y:\varphi_e(y)\downarrow\}\) is uniform and contains every c.e. set, but its rows repeat. Here uniqueness concerns equality of sets, even when the programs enumerating those sets have different numerical indices. The objects to be listed in this entry are sets of natural numbers.

Separate the initial segments from the other rows

An initial segment of \(\mathbb N\) is a set \(A\) such that \(b\in A\) and \(a<b\) imply \(a\in A\). Write

\[I_k=\{0,1,\ldots,k\}\qquad(k\in\mathbb N).\]

The initial segments are precisely \(\varnothing\), \(\mathbb N\), and the finite sets \(I_k\). Consequently a set is not an initial segment exactly when there are \(a<b\) with \(a\notin A\) and \(b\in A\).

The listed sets are downward closed. Conversely, if an initial segment is proper, let \(c\) be its least missing number. Every number below \(c\) belongs to it, and no number above \(c\) can belong to it, since downward closure would then include \(c\). For \(c=0\) the set is empty; otherwise it is \(I_{c-1}\). Negating downward closure gives the stated two-number witness for a noninitial set.

For a finite set \(B\subseteq I_x\), being an initial segment is a finite test: check whether \(a<b\le x\), \(b\in B\), and \(a\notin B\) ever occur. Thus the test does not decide whether an infinite c.e. set is an initial segment.

Every standard index receives arbitrarily late visits

At stage \(s\), visit the requirement with index

\[e(s)=\operatorname{left}(s),\]

where \(\operatorname{left}\) is the first coordinate of the inverse pairing. For every \(e,S\in\mathbb N\), some stage \(s\ge S\) visits \(e\).

The stage \(s=\langle e,k\rangle\) visits \(e\). The pairing lower bound gives \(s\ge e+k\), so choosing \(k\ge S\) makes the visit at least as late as \(S\). Each requirement therefore has infinitely many visits, with no assumption about whether its set is finite or empty.

Allocate a follower, copy its set, or retire its row

Use the increasing finite sets \(W_{e,s}\) from the standard stage construction. A follower for requirement \(e\) is an allocated row label \(x\) temporarily assigned to copy \(W_e\). The finite state at the start of stage \(s\) records the following data: the number \(N_s\) of allocated rows; a finite table assigning at most one active follower to each visited requirement; the finite contents \(V_{x,s}\) of each allocated row; which rows have been retired; and the latest retirement endpoint \(g_s\).

Initially \(N_0=0\), there are no followers or retired rows, and \(g_0=0\). Put \(V_{x,s}=\varnothing\) for unallocated labels \(x\ge N_s\). At stage \(s\), visit \(e=e(s)\) and perform exactly one of these actions.

  1. If \(e\) has no active follower, allocate the fresh label \(x=N_s\), give its row empty contents, assign it to \(e\), and increase the allocated count by one.
  2. If \(e\) has follower \(x\), test whether \(W_{e,s}\cap I_x\) is noninitial and differs from \(W_{j,s}\cap I_x\) for every \(j<e\). If both tests hold, retain \(x\) and put \(V_{x,s+1}=W_{e,s}\).
  3. If \(e\) has follower \(x\) and either test fails, retire \(x\) permanently and remove it from the follower table. Let \(m\) be the largest number in its entire current row \(V_{x,s}\), with \(m=0\) when that row is empty. Choose the endpoint
\[g_{s+1}=2\bigl(\max(g_s,m)+1\bigr),\qquad V_{x,s+1}=I_{g_{s+1}}.\]

In the first two cases leave the latest endpoint unchanged. In every case leave all other row contents, followers and retirement records unchanged. A retired row is never assigned again and is never modified. The endpoint formula makes each newly retired row contain its whole old contents, including numbers above its label \(x\).

Every update preserves the finite enumeration already made

All stages of are total computable finite operations. For every \(s,x\), the construction satisfies:

  • The allocated labels are exactly \(0,\ldots,N_s-1\). Each allocated row is either retired or is the follower of exactly one requirement, and no requirement has two followers.
  • Rows increase: \(V_{x,s}\subseteq V_{x,s+1}\). If \(x\) currently follows \(e\), then \(V_{x,s}\subseteq W_{e,s}\).
  • Each retired row is a fixed finite \(I_k\). Its assigned endpoint \(k\) is positive and even. Successive retirement endpoints strictly increase, and \(g_s\) records the latest one, or zero before the first retirement.

Induct on the stage. A fresh allocation uses exactly the next label, starts empty, and is made only when that requirement has no follower. For a retained follower, its old contents came from an earlier stage of the same increasing approximation \(W_{e,s}\); replacing them by \(W_{e,s}\) keeps every old member. The new row is still contained in \(W_{e,s+1}\). Other active rows retain their contents, which remain contained in their own increasing source approximations.

On retirement, put \(M=\max(g_s,m)\). The endpoint \(2(M+1)\) is even, positive, greater than \(g_s\), and at least every element of \(V_{x,s}\). Thus replacement by its initial segment preserves all old members. Removing the sole follower assignment leaves the row retired, and later stages cannot alter it. These are all possible updates, so the invariants persist.

Every test concerns finitely many indices \(j<e\), numbers at most \(x\), and computable finite approximations. Maximum, table lookup and finite set updates are effective operations on coded finite data. Iterating this total update computes the complete finite state at any requested stage, and hence computes \(V_{x,s}\) uniformly in \(x,s\).

A fixed finite observation eventually stops changing

For each \(e,b\in\mathbb N\), there is an \(S\) such that

\[W_{e,s}\cap I_b=W_e\cap I_b\qquad(s\ge S).\]

The same stage can be chosen for any specified finite list of indices and bounds.

For every \(y\in W_e\cap I_b\), choose a stage at which \(y\) appears. There are only finitely many such \(y\), so a maximum of their appearance stages exists; if there are none, use zero. At later stages all required members are present. No number outside \(W_e\) ever appears, since every stage is a subset of \(W_e\). This proves equality. Taking one more finite maximum handles finitely many observations simultaneously.

This is an existence argument for a settling stage on a fixed finite window. It gives no algorithm for recognizing that stage from \(e,b\), in agreement with the earlier settling-bound distinction.

A permanent follower represents a new noninitial set

Call a follower permanent if, once allocated, it is never retired. If \(x\) is a permanent follower for \(e\), then

\[V_x:=\bigcup_s V_{x,s}=W_e,\]

the set \(W_e\) is noninitial, and \(W_e\ne W_j\) for every \(j<e\). Thus \(e\) is the least standard index for its set.

The active-row invariant puts every member of \(V_x\) in \(W_e\). Conversely, if \(y\in W_e\), it belongs to \(W_{e,s}\) at all sufficiently large stages. There is a later visit to \(e\). Its follower is still \(x\), so the tests pass and that visit copies the whole current \(W_{e,s}\) into row \(x\), including \(y\). Hence \(V_x=W_e\).

Apply to the fixed window \(I_x\) for \(e\) and every \(j<e\). At a visit after their common settling stage, the successful tests say that \(W_e\cap I_x\) is noninitial and differs from each \(W_j\cap I_x\). A missing smaller number and present larger number in that window witness that \(W_e\) is noninitial. Each finite-window difference also witnesses \(W_e\ne W_j\). This proves every asserted property.

Every least index for a noninitial set gets a permanent follower

Suppose \(W_e\) is noninitial and \(W_e\ne W_j\) for every \(j<e\). Then requirement \(e\) eventually has a permanent follower.

Choose \(a<b\) with \(a\notin W_e\) and \(b\in W_e\). For each of the finitely many \(j<e\), choose a number witnessing \(W_e\ne W_j\). Let \(B\) bound all these numbers, including \(a,b\). There is a stage \(S\) after which every source approximation with index at most \(e\) has settled on \(I_B\).

At any later visit, a follower with label \(x\ge B\) passes both tests. The window \(I_x\) contains the stable missing/present witness \(a,b\), so it is noninitial, and contains every stable difference witness against earlier indices. Changes outside \(I_B\) cannot remove these witnesses. Such a follower can therefore never be retired.

Suppose no follower of \(e\) were permanent. Every allocated follower would eventually retire; a later visit would then allocate another fresh one. Fair visits would produce infinitely many followers for \(e\). Their labels are distinct, so are unbounded, and infinitely many of their allocation stages occur after \(S\). In particular some follower allocated after \(S\) has label at least \(B\). The preceding argument makes it permanent, a contradiction. Hence the required permanent follower exists.

The empty-set requirement forces every label to be used

There are infinitely many allocations and infinitely many retirements. Every natural-number row label is eventually allocated, and the retirement endpoints are unbounded.

Fix an index \(e_\varnothing\) for the nowhere-defined program, so \(W_{e_\varnothing}=\varnothing\). Every finite stage of that set is empty. Whenever this requirement is visited with an active follower, its noninitiality test fails and that follower retires. Whenever it is visited without one, it obtains a fresh follower. Its infinitely many visits therefore alternate between allocation and retirement, regardless of what other requirements do.

The allocated count increases by one on each allocation, and the labels used are an initial segment. Infinitely many allocations thus force the count beyond every fixed label. Likewise the positive integer endpoints strictly increase at each retirement, so infinitely many retirements make them unbounded. In particular there are no permanently unallocated rows whose empty limits could accidentally repeat.

The preliminary rows are distinct and contain every noninitial enumerable set

Let \(V_x=\bigcup_s V_{x,s}\), and let the retirement endpoint set be

\[G=\{k:\text{some row is actually retired with endpoint }k\}.\]

The family \((V_x)\) is uniformly c.e. and has no repeated rows. Its rows are exactly all noninitial c.e. sets together with the finite initial segments \(I_k\) for \(k\in G\). Neither \(\varnothing\) nor \(\mathbb N\) occurs among these rows.

To recognize \(y\in V_x\), simulate successive finite states until \(y\in V_{x,s}\). Each stage test is total computable, so this is a joint recognizer in \(x,y\). Every label is eventually allocated. Once allocated, it either retires at some finite stage or remains a permanent follower; there is no third possibility.

A retired row is exactly its assigned \(I_k\). Distinct retirements use distinct endpoints, hence distinct finite initial segments. A permanent row is noninitial by , so cannot equal a retired row. Two permanent rows cannot belong to the same requirement, which has at most one follower at a time; if one permanent row follows \(e\) and another follows \(f>e\), their source sets differ because the permanent follower of \(f\) witnesses inequality against every earlier index. Thus all rows are distinct.

Every noninitial c.e. set has a least standard index. By , that index gets a permanent row equal to the set. Conversely permanent rows are noninitial and retired rows are precisely the \(I_k\) assigned on actual retirements. These finite rows are nonempty, and neither a finite row nor a noninitial row is \(\mathbb N\). This proves the complete range description.

The actual retirement endpoints form a decidable set

The set \(G\) is decidable. It consists of positive even numbers, and its complement is infinite.

On input \(n\), simulate the construction until the latest endpoint \(g_s\) is at least \(n\). This eventually happens by . Inspect the finite record of endpoints assigned on retirements up to that stage. The number \(n\) belongs to \(G\) exactly when it occurs in that record: every future endpoint will be strictly larger than \(g_s\ge n\).

For \(n=0\), the simulation may stop immediately at \(g_0=0\), but the retirement record is then empty. The placeholder zero is not an assigned endpoint. Similarly, idle stages introduce no endpoints into \(G\). Every actual endpoint is positive and even by the invariant, so zero and every odd number lie outside \(G\). This gives an infinite complement and completes the decision procedure.

List all initial-segment endpoints omitted by retirement

There is a total computable strictly increasing function \(h:\mathbb N\to\mathbb N\) whose range is \(\mathbb N\setminus G\). Specify it by

\[h(0)=0,\qquad h(n+1)=\min\{k>h(n):k\notin G\}.\]

Zero is the least omitted endpoint. The complement of \(G\) is decidable and infinite, so it is unbounded, and each successor search has a witness. These are total searches over a computable predicate. The increasing-enumeration theorem proves that the specified recursion is total computable, strictly increasing, and exhaustive for the complement. Thus every omitted finite initial segment has exactly one endpoint name \(h(n)\).

Complete the family with the missing initial segments

Define the completed family \((U_e)\) by

\[U_0=\mathbb N,\qquad U_2=\varnothing,\]
\[U_{2n+1}=V_n,\qquad U_{2n+4}=I_{h(n)}\qquad(n\in\mathbb N).\]

These cases cover every natural row label exactly once. Define its joint recognizer \(R(e,y)\) by the following single partial procedure, always returning zero when it halts. At row zero return immediately; at row two run forever. At an odd row \(2n+1\), simulate the follower construction until \(y\in V_{n,s}\). At an even row \(2n+4\), compute \(h(n)\), return zero if \(y\le h(n)\), and otherwise run forever.

This procedure is partial recursive jointly in \(e,y\), and its behavior is exactly

\[R(e,y)\simeq\begin{cases}0&y\in U_e,\\\text{undefined}&y\notin U_e.\end{cases}\]

Parity, the exceptional labels zero and two, and the corresponding value of \(n\) are computed by total arithmetic operations. The odd-row search uses a total computable finite-stage test; it halts exactly on the union defining \(V_n\). The even-row branch uses the total computable \(h\) and a finite comparison. The two perpetual branches can use the nowhere-defined program. Strict composition and unbounded search therefore give one jointly partial recursive procedure with the displayed behavior.

Every computably enumerable set occurs exactly once

The completed family \((U_e)\) is a Friedberg numbering of all c.e. subsets of \(\mathbb N\): it is uniformly c.e., its rows are pairwise distinct, and every c.e. set equals one row.

The joint recognizer proves that the flattened set \(\{\langle e,y\rangle:y\in U_e\}\) is c.e. For uniqueness, odd rows are distinct by . Among the added finite rows, strict increase of \(h\) makes the sets \(I_{h(n)}\) distinct. Their endpoints lie outside \(G\), so none equals a retired odd row, whose endpoint belongs to \(G\); none equals a noninitial odd row either. All these rows are nonempty proper subsets of \(\mathbb N\), so they are distinct from rows two and zero. Those two exceptional rows are also distinct.

For exhaustiveness, a noninitial c.e. set occurs among the \(V_n\), hence at an odd label. The two initial segments \(\mathbb N\) and \(\varnothing\) occur at their exceptional labels. Every other initial segment is \(I_k\). If \(k\in G\), it occurs as a retired odd row. If \(k\notin G\), exactly one \(n\) has \(h(n)=k\), and it occurs at label \(2n+4\). These cases include every c.e. set and show that each has exactly one name.

Each new row name compiles to a standard program index

Choose one standard index \(r\) for the actual joint recognizer, so \(\varphi_r(\langle e,y\rangle)\simeq R(e,y)\) for every \(e,y\). Let \(s\) be the fixed numerical specialization function and define

\[t(e)=s(r,e).\]

This specified map \(t\) is primitive recursive and injective, and for every \(e,y\),

\[\varphi_{t(e)}(y)\simeq R(e,y),\qquad W_{t(e)}=U_e.\]

Joint partial recursiveness of \(R\) and completeness of the program numbering supply one fixed \(r\). The parameter theorem makes \(e\mapsto s(r,e)\) primitive recursive and gives its exact evaluation identity on every runtime input, including divergence. Taking domains gives the row equality. If \(t(e)=t(f)\), those two standard programs have the same domain, so \(U_e=U_f\). The uniqueness theorem then gives \(e=f\), proving injectivity of this very compiler.

No computable translator selects the unique name of every standard domain

There is no total computable function \(q:\mathbb N\to\mathbb N\) satisfying

\[U_{q(e)}=W_e\qquad\text{for every }e\in\mathbb N.\]

Fix an ordinary index \(e_\varnothing\) with empty domain. If such a total computable \(q\) existed, unique row names would give

\[W_e=\varnothing\quad\Longleftrightarrow\quad q(e)=q(e_\varnothing).\]

The right side is decidable: compute \(q(e)\) and compare it with the fixed number \(q(e_\varnothing)\). The left side is a nontrivial extensional property of programs. A nowhere-defined program has it, whereas a constant-zero program does not. Rice’s theorem rules out its decidability. This contradiction proves that no such translator exists.

The conclusion concerns names for c.e. domains. The chosen recognizers all return zero on their domains; this construction makes no assertion that those recognizers enumerate every partial recursive function.

How do these two uses of injectivity differ?

Why does an injective enumeration of one infinite c.e. set not already give a Friedberg numbering? Why does the injective compiler \(t\) not provide a total reverse translator?

Show answerHide answer

An enumeration \(g:\mathbb N\to\mathbb N\) of one set has distinct numerical outputs and range equal to that chosen set. A Friedberg family instead has distinct sets as rows, includes every c.e. set, and has a single joint membership recognizer. Suppressing repeated numbers in one stream does not test equality of different c.e. rows or coordinate their eventual contents. The follower construction supplies precisely that additional coordination.

The compiler \(t\) sends a row name to a standard program with the same domain. A reverse translator would have to take every standard index \(e\) and find the unique \(n\) with \(W_e=U_n\). This asks for equality of represented domains, rather than equality of numerical program names. Searching for a literal equality \(t(n)=e\) can succeed only when \(e\) is one of the compiler's numerical outputs. Having some program \(t(n)\) for the same domain does not make its index equal to the given \(e\). The preceding theorem rules out any total computable solution to the domain-name problem.
