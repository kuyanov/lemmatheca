A language naming every rational point

Let the named rational order be the structure \(Q_*=(\mathbb Q,<,(c_q)_{q\in\mathbb Q})\), where \(c_q^{Q_*}=q\). Its language \(L_*\) has the strict-order relation and one constant for each rational number. Put \(T=\operatorname{Th}(Q_*)\), the set of all \(L_*\)-sentences true in this structure.

The language is countable and \(T\) is complete and satisfiable. Every model \(M\models T\) is a nonempty dense linear order without endpoints, and its named points satisfy \(c_p^M<c_q^M\) exactly when \(p<q\). Thus \(q\mapsto c_q^M\) is an order embedding. The theory permits elements outside the named copy of \(\mathbb Q\): the named real order below supplies such a model. An infinite disjunction saying that a point equals one of all the rational names would not be a first-order formula.

A tuple of named points has an isolating formula

For \(\bar a=(a_0,\ldots,a_{n-1})\in\mathbb Q^n\), the formula

\[\theta_{\bar a}(\bar x)=\bigwedge_{i<n}x_i=c_{a_i}\]

isolates \(\operatorname{tp}^{Q_*}(\bar a)\) over \(T\). For \(n=0\), the conjunction is \(\top\).

The formula is true at \(\bar a\). If \(\varphi(\bar x)\) is also true there, the sentence \(\varphi(c_{a_0},\ldots,c_{a_{n-1}})\) belongs to \(T\). In any model of \(T\), a tuple satisfying \(\theta_{\bar a}\) has precisely these named coordinates. Substitution of equal values therefore gives \(T\models\forall\bar x\,(\theta_{\bar a}\to\varphi)\). This is the definition of an isolator. Repeated coordinates impose compatible equalities. For the empty tuple, the same argument says that every true sentence already belongs to \(T\).

The named rational order is prime

The countable model \(Q_*\) is atomic and prime. For every \(M\models T\), its unique elementary embedding into \(M\) is the specified map \(q\mapsto c_q^M\).

The preceding isolators make every realized finite-tuple type isolated, so \(Q_*\) is atomic. It is countable, and the atomic embedding theorem makes it prime.

Any elementary embedding preserves constants. Consequently every such embedding \(f\) satisfies \(f(q)=f(c_q^{Q_*})=c_q^M\). Existence supplies an elementary embedding with exactly these values, and the same equation proves its uniqueness.

The isolated one-types are exactly the named points

A complete one-type \(p\in S_1(T)\) is isolated if and only if \(p=\operatorname{tp}^{Q_*}(q)\) for some \(q\in\mathbb Q\). Different rational numbers give different such types.

An isolated type is realized in every model of the complete theory, hence in \(Q_*\). Its realizing element is some rational \(q\), which identifies the type. Conversely \(x=c_q\) isolates that point type by the named-tuple lemma. For distinct rationals \(a,b\), the formula \(x=c_a\) holds at \(a\) and fails at \(b\), so their types differ.

A consistent request above every named rational

The partial one-type \(p_\infty(x)=\{c_q<x:q\in\mathbb Q\}\) is finitely realized in \(Q_*\), but is omitted by \(Q_*\).

A finite subset mentions only finitely many rationals. Choose a rational greater than all of them, taking \(0\) if the subset is empty. It satisfies the finite subset. No rational \(a\) realizes the whole collection, because its member \(c_a<x\) would require \(a<a\).

A countable prime model need not be saturated

The model \(Q_*\) is not omega-saturated, despite being countable, atomic and prime.

The conditions in \(p_\infty\) are formulas in the language \(L_*\) itself; they need no additional parameters. Their finite realizability makes them consistent with \(T\), by the finite consistency test. Omega-saturation would realize this partial type over the empty parameter set, by the partial-type criterion. The preceding omission contradicts that conclusion.

The original order \( (\mathbb Q,<) \), before these names are added, is omega-saturated by the categorical order example. Thus naming infinitely many elements can destroy saturation, although naming finitely many preserves it.

The real order is another model with the same rational names

Let \(R_*=(\mathbb R,<,(q)_{q\in\mathbb Q})\), where each constant is interpreted by the corresponding rational real number. The ordinary inclusion \(\mathbb Q\to\mathbb R\), with all these names retained, is elementary. In particular \(R_*\models T\).

Both original order structures are dense linear orders without endpoints. The inclusion is an order embedding, so quantifier elimination makes that very map elementary in the original order language.

For a formula in \(L_*\), only finitely many constant names occur. Replace those occurrences by extra free variables. Truth of the original formula is recovered by assigning those variables their named rational values, as in the translation of names to variables. The original elementary inclusion preserves the translated formula and sends every such parameter to the same rational real number. It therefore preserves the original named formula. Agreement on sentences gives \(R_*\models\operatorname{Th}(Q_*)\). This is also the elementary-diagram interpretation of naming an elementary embedding.

Different real cuts give different complete types

For \(r\in\mathbb R\), let \(p_r=\operatorname{tp}^{R_*}(r)\in S_1(T)\). The map \(r\mapsto p_r\) is injective.

If \(r<s\), choose a rational \(q\) with \(r<q<s\), using rational order density in the reals. The formula \(x<c_q\) belongs to \(p_r\) and does not belong to \(p_s\). Thus the types differ. Interchanging the two reals handles the other strict order. In the Dedekind-cut construction, this is the same separation of two cuts by a rational cut.

A countable language gives at most continuum many types

For any theory \(U\) in a countable first-order language and any finite \(n\), the set \(S_n(U)\) has cardinality at most \(\mathfrak c=2^{\aleph_0}\). In particular this holds for \(S_1(T)\).

There are countably many formulas in each fixed finite-variable context: each is a finite string built from a countable alphabet. Each complete type is a subset of this countable formula set, and different types have different subsets. Injecting that formula set into \(\mathbb N\) injects its power set into \(\mathcal P(\mathbb N)\). Therefore \(|S_n(U)|\le 2^{\aleph_0}\), with no completeness or satisfiability hypothesis on \(U\).

There are continuum many complete one-types

The complete named rational-order theory satisfies \(|S_1(T)|=\mathfrak c\). Its isolated one-types are only the countably many named-point types.

The injection \(r\mapsto p_r\) gives \(\mathfrak c\le |S_1(T)|\). The opposite bound gives equality. The isolated types are exactly those indexed by the rationals; their distinctness makes that set countably infinite.

The same cut patterns appear as types over a countable parameter set in the order-property analysis of dense orders.

The theory has a prime model but no countable saturated or universal model

The theory \(T\) is not small. It has no countable omega-saturated model and no countable elementary-universal model.

Cantor's theorem gives \(\mathfrak c>\aleph_0\), so the one-type set is uncountable. This already violates smallness. Both nonexistence conclusions follow from the countable-model existence criterion. Meanwhile \(Q_*\) is prime.

This distinguishes an omitted request in the particular prime model from the stronger conclusion that no countable model of the theory can realize all finite-parameter types.

Realized irrational cuts are nonisolated

The type \(p_r\) is isolated exactly when \(r\) is rational.

If \(r=q\) is rational, the elementary inclusion in the named real model identifies \(p_r\) with the named-point type in \(Q_*\), which is isolated. If \(p_r\) were isolated for irrational \(r\), the characterization of isolated point types would identify it with some named-point type. That type contains \(x=c_q\), forcing \(r=q\) in \(R_*\), a contradiction.

Do the rational names determine the whole countable model?

Must every countable model of \(T\) be isomorphic to \(Q_*\)?

Show answerHide answer

No. There is a countable model with an element above every named rational, and it is not isomorphic to \(Q_*\).

Extend \(p_\infty\) to a complete type, by completion of a consistent type. Countable realization gives a countable \(M\models T\) with a point \(b\) above every \(c_q^M\). The unique elementary map \(Q_*\to M\) has precisely the named points as its image, so \(b\) lies outside that image. The model \(M\) realizes \(p_\infty\), whereas \(Q_*\) omits it; an isomorphism would preserve every named condition, so they are not isomorphic.

Have the real points listed every complete one-type?

Does every complete one-type of \(T\) equal \(p_r\) for some \(r\in\mathbb R\)?

Show answerHide answer

No. Every complete extension of \(p_\infty\) is omitted by the named real model.

A complete extension of \(p_\infty\) contains \(c_q<x\) for every rational \(q\). For any real \(r\), choose a rational \(q\) strictly between \(r\) and \(r+1\). The formula \(c_q<x\) is false at \(r\), so this complete extension differs from \(p_r\). The real-point types suffice for the cardinality lower bound; they need not exhaust the type set.
