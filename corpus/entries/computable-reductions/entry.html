Translate the question before asking it

Let \(A,B\subseteq\mathbb N\). A many-one reduction of \(A\) to \(B\) is a total computable function \(f:\mathbb N\to\mathbb N\) such that

\[x\in A\quad\Longleftrightarrow\quad f(x)\in B\qquad(x\in\mathbb N).\]

Write \(A\le_m B\) when such a function exists. “Computable” means total recursive, with the equivalent machine interpretation already proved in the machine correspondence. The reduction must finish even when the answer is no. It asks one membership question about \(B\) and preserves both answers. It need not be injective.

Which properties travel through a reduction?

Many-one reducibility is reflexive and transitive. If \(A\le_m B\), then decidability of \(B\) implies decidability of \(A\), and computable enumerability of \(B\) implies computable enumerability of \(A\). The same reduction also gives \(\mathbb N\setminus A\le_m\mathbb N\setminus B\).

The identity function reduces a set to itself. If \(f\) reduces \(A\) to \(B\) and \(g\) reduces \(B\) to \(C\), then \(g\circ f\) is total computable and

\[x\in A\ \Longleftrightarrow\ f(x)\in B\ \Longleftrightarrow\ g(f(x))\in C.\]

For decidability, compute \(f(x)\) and apply the decision procedure for \(B\). The resulting characteristic function is \(\chi_B\circ f\). For enumerability, run a recognizer for \(B\) on \(f(x)\): it halts exactly for \(x\in A\). This is the computable preimage construction. Finally, negating the defining equivalence proves the complement claim.

Thus an undecidable set reducing to \(B\) proves that \(B\) is undecidable. This is the useful direction: a proposed procedure for the target would supply the missing procedure for the source.

The halting problem receives every enumerable problem

Let \(K_0=\{\langle e,x\rangle:\varphi_e(x)\downarrow\}\), using the fixed program enumeration and numerical pairing. The set \(K_0\) is c.e., and every c.e. set \(A\subseteq\mathbb N\) satisfies \(A\le_m K_0\). A c.e. set with this property is called many-one complete among c.e. sets.

Enumerability of \(K_0\) was proved in the halting-set theorem. If \(A\) is c.e., choose an index \(e\) for a partial recursive function with domain \(A\), by the domain characterization. The function \(f(x)=\langle e,x\rangle\) is total computable and satisfies

\[x\in A\quad\Longleftrightarrow\quad\varphi_e(x)\downarrow\quad\Longleftrightarrow\quad\langle e,x\rangle\in K_0.\]

This one function supplies the reduction. The index \(e\) is fixed for the chosen set; the reduction does not have to discover an index from an arbitrary description of a set.

Three questions about a sentence

Fix the finite arithmetic language with \(0,S,+,\times\), and the actual sentence coding. For a sentence \(A\), distinguish:

  • Validity: every nonempty structure for this language satisfies \(A\), with no arithmetic axioms assumed.
  • Satisfiability: some nonempty structure satisfies \(A\).
  • Theoremhood in \(Q\): there is a formal derivation \(Q\vdash A\).

Let \(\mathrm{Val}\), \(\mathrm{Sat}\) and \(\mathrm{Thm}(Q)\) be their sets of numerical codes. A number that is not a sentence code belongs to none of these sets. Sentencehood is decidable, so a procedure specified only for sentences can always be extended to reject other inputs.

In a validity question, the symbols need not have their usual numerical meanings. This is why undecidability of truth in the standard natural numbers does not by itself prove undecidability of validity.

Put all seven Robinson axioms into one antecedent

Write the seven closed Robinson axioms, in their displayed order, as \(q_1,\ldots,q_7\), and put \(q=q_1\land(q_2\land\cdots\land q_7)\). A structure satisfies \(q\) exactly when it is a model of \(Q\). For every arithmetic sentence \(A\),

\[Q\vdash A\quad\Longleftrightarrow\quad\models(q\to A).\]

If \(Q\vdash A\), soundness makes \(A\) true in every model of \(Q\). In an arbitrary structure, either \(q\) is false, making \(q\to A\) true, or \(q\) is true and all seven axioms hold, so \(A\) is true. Thus the implication is valid.

Conversely, if the implication is valid, every model of \(Q\) satisfies its antecedent and hence \(A\). The completeness theorem gives \(Q\vdash A\). Both soundness and completeness matter here: the translation connects formal arithmetic theoremhood to semantic validity.

The translation is an actual terminating computation

Let \(\mathrm{Sent}(n)\) be the fixed sentence test and let \(\mathrm{imp}(a,b)\) build the code of an implication. Define

\[f(n)=\begin{cases}\mathrm{imp}(\ulcorner q\urcorner,n),&\mathrm{Sent}(n),\\\ulcorner\bot\urcorner,&\text{otherwise}.\end{cases}\]

This is primitive recursive, and therefore total computable. It satisfies

\[n\in\mathrm{Thm}(Q)\quad\Longleftrightarrow\quad f(n)\in\mathrm{Val}.\]

The sentence test and implication-code constructor are primitive recursive. On a sentence code, correctness is the preceding equivalence. On any other input the left side is false, and the output \(\bot\) is false in the standard natural-number structure, so the right side is false as well. This checks the reduction on all numerical inputs, including invalid ones.

First-order validity is undecidable

There is no total computable test for validity of first-order sentences in the arithmetic language. More precisely, \(\mathrm{Thm}(Q)\le_m\mathrm{Val}\), and \(\mathrm{Val}\) is undecidable. Consequently, a procedure deciding validity for arbitrary finite first-order languages is impossible as well.

The function in the translation lemma is the reduction. Robinson arithmetic is consistent, as witnessed by the standard natural numbers. The essential-undecidability theorem, applied to \(Q\) itself, says that \(\mathrm{Thm}(Q)\) is undecidable. A decider for \(\mathrm{Val}\), composed with \(f\), would contradict that theorem. A decider for arbitrary finite languages would in particular decide this fixed language.

This is a form of Church’s theorem. The statement concerns validity in all structures, rather than truth in the intended arithmetic structure or consequence of a complete arithmetic theory. By the established machine correspondence, the same impossibility holds for the specified machine model.

Proof search recognizes precisely the valid sentences

The set \(\mathrm{Val}\) is c.e., but the set of sentence codes that are not valid is not c.e.

Take the empty axiom set in the enumeration theorem for semantic consequences. Soundness and completeness say that its provable sentences are precisely the valid ones. To recognize validity, search for a proof; there is no promised stopping point for invalid sentences.

If the nonvalid sentences were also enumerable, combine that enumeration with the decidable set of nonsentence codes. This would enumerate the whole numerical complement of \(\mathrm{Val}\). The two-sided recognition theorem would then make \(\mathrm{Val}\) decidable, contradicting Church’s theorem.

Satisfiable sentences cannot be enumerated

The set \(\mathrm{Sat}\) of satisfiable arithmetic sentence codes is not c.e. In particular, it is undecidable.

A sentence \(A\) is nonvalid exactly when some structure falsifies it, equivalently when \(\neg A\) is satisfiable. Negation of a sentence is an effective operation. To handle all numerical inputs, define \(g(n)\) to be the negation code when \(n\) is a sentence code, and the code of \(\neg\bot\) otherwise. Then

\[n\notin\mathrm{Val}\quad\Longleftrightarrow\quad g(n)\in\mathrm{Sat}.\]

For invalid inputs both sides are true: the input is outside \(\mathrm{Val}\), and \(\neg\bot\) has a model. Thus \(g\) is a total computable reduction of the complement of \(\mathrm{Val}\) to \(\mathrm{Sat}\). If \(\mathrm{Sat}\) were c.e., its computable preimage would make that complement c.e., which the preceding argument rules out. Every decidable set is c.e., so satisfiability is undecidable too.

The asymmetry has a concrete reason. A proof is finite evidence of validity. Satisfiability may require an infinite structure; searching through finite structures would miss such sentences.

Restricted languages can admit such a search: monadic logic with equality has a computable finite model bound, so finite-table search decides satisfiability there.

Does taking the opposite answer give a many-one reduction?

Given membership answers for \(K_0\), we can decide membership in its complement by reversing the answer. Does this show \(\mathbb N\setminus K_0\le_m K_0\)?

No. A many-one reduction must preserve the yes answer as well as the no answer; it cannot reverse the response. If this reduction existed, enumerability of \(K_0\) would imply enumerability of its complement by pullback. The nonhalting theorem rules that out. The ability to use membership answers with arbitrary subsequent computation is a different notion, not the one defined here.
