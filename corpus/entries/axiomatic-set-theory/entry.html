One relation describes a universe of sets

The language of sets and maps lets us work with numbers, maps, and collections without choosing their internal construction. We now ask which assumptions justify those constructions. In ZF, or Zermelo–Fraenkel set theory, every object over which we quantify is a set. The basic relation is membership, \(x\in y\); equality belongs to the underlying logic. Numbers and maps will be represented by sets rather than added as separate kinds of object.

We use classical first-order logic. A formula is a finite expression made from membership, equality, logical connectives, and quantifiers over sets. A formula may have fixed set parameters. For example, \(\varphi(x,B)\) might mean \(x\in B\). Subset notation abbreviates

\[ A\subseteq B\quad\Longleftrightarrow\quad\forall x\,(x\in A\Rightarrow x\in B). \]

An axiom is an assumption of the theory. A theorem must follow from the axioms and logic. The axioms below specify set constructions and restrictions on membership; listing them does not itself prove that the theory is consistent.

Members determine a set

Extensionality says that sets with exactly the same members are equal:

\[ \forall A\,\forall B\,\bigl[\forall x\,(x\in A\Longleftrightarrow x\in B)\Rightarrow A=B\bigr]. \]

Our presentation also includes the Empty Set axiom, asserting that a set with no members exists. Extensionality makes it unique; write it as \(\varnothing\). This axiom is convenient but redundant in presentations that obtain an empty set by Separation from an existing set.

Extensionality is a criterion for equality, not permission to collect everything satisfying a condition. We still need existence axioms.

Separate a definable part of an existing set

For each formula \(\varphi(x,p_1,\ldots,p_k)\), the Separation schema asserts that for every set \(A\) and every choice of set parameters there is a set \(B\) satisfying

\[ \forall x\,\bigl[x\in B\Longleftrightarrow x\in A\ \text{and}\ \varphi(x,p_1,\ldots,p_k)\bigr]. \]

Write \(B=\{x\in A:\varphi(x,p_1,\ldots,p_k)\}\). The variable for \(B\) is not free in \(\varphi\). A schema provides an axiom for each formula, rather than one axiom quantifying over formulas. The bounding set \(A\) is essential.

For instance, \(A\cap C\) and \(A\setminus C\) exist by separating elements that belong, or do not belong, to the parameter \(C\). Separation gives definable subsets; it does not assert that every subset can be defined by a formula.

Russell’s argument rules out a universal set

For every set \(A\), the set \(R_A=\{x\in A:x\notin x\}\) is not a member of \(A\). In particular, no set contains every set.

Proof

Separation constructs \(R_A\). If \(R_A\in R_A\), its defining condition gives \(R_A\notin R_A\), a contradiction. Thus \(R_A\notin R_A\). If \(R_A\in A\), this fact would make \(R_A\) satisfy the defining condition and hence belong to \(R_A\), again a contradiction. Therefore \(R_A\notin A\). A universal set would contain \(R_A\), which is impossible. □

This proof uses Separation, not Foundation. Unrestricted comprehension, asserting a set \(\{x:\varphi(x)\}\) for every condition without a bounding set, would fail for \(\varphi(x)\) meaning \(x\notin x\).

Classes describe collections that may be too large

A definable class is the collection described by a formula with fixed set parameters. Class notation \(C=\{x:\varphi(x)\}\) abbreviates that condition: \(x\in C\) means \(\varphi(x)\). It does not add an object to the universe. The class is a proper class if no set has exactly those members.

The class \(V=\{x:x=x\}\) of all sets is proper by . The class of all ordinals is another example. A set is also described by a class condition, such as \(x\in A\), but a proper class cannot be a member of a set.

In ZF we quantify over sets, not over arbitrary classes. Statements using class notation must expand into formulas about sets. We will use only definable classes here; theories that take classes as additional objects require their own axioms.

Pairing and Union build collections from existing sets

Pairing asserts that for any sets \(a,b\), a set \(\{a,b\}\) exists with precisely those members. Taking \(a=b\) gives the singleton \(\{a\}\).

Union asserts that for every set \(\mathcal A\), a set \(\bigcup\mathcal A\) exists such that

\[ x\in\bigcup\mathcal A\quad\Longleftrightarrow\quad\exists B\in\mathcal A\,(x\in B). \]

Consequently \(A\cup B=\bigcup\{A,B\}\) exists. Union collects members of members: \(\bigcup\{\{a\},\{b,c\}\}=\{a,b,c\}\). The family \(\mathcal A\) must itself be a set; Union does not collect a proper class of sets into a set.

What happens to an empty intersection?

How do we construct the intersection of a nonempty set \(\mathcal A\) of sets? Why can we not use the same unrestricted membership condition when \(\mathcal A=\varnothing\)?

Show answerHide answer

Choose one \(B\in\mathcal A\), and use Separation to form \(\{x\in B:\forall C\in\mathcal A\,(x\in C)\}\). This is the intersection, independently of which \(B\) was chosen. For an empty family, the condition \(\forall C\in\varnothing\,(x\in C)\) holds for every set \(x\); its unrestricted collection would be the proper class \(V\).

With a specified ambient set \(U\), the relative intersection \(\{x\in U:\forall C\in\mathcal A\,(x\in C)\}\) is always a set and equals \(U\) for an empty family. A convention assigning \(\varnothing\) to an unbounded empty intersection is also possible, but it does not satisfy the unrestricted membership condition.

Power Set collects all subsets at once

The Power Set axiom asserts that for every set \(A\), a set \(\mathcal P(A)\) exists with

\[ B\in\mathcal P(A)\quad\Longleftrightarrow\quad B\subseteq A. \]

This collects all subsets, rather than only the subsets described by a selected list of formulas. Together with Separation it lets us construct sets of relations and maps.

Ordered pairs and products are sets

Define the Kuratowski pair by \(\langle a,b\rangle=\{\{a\},\{a,b\}\}\). Then \(\langle a,b\rangle=\langle c,d\rangle\) exactly when \(a=c\) and \(b=d\). For sets \(A,B\), the collection \(A\times B\) of these pairs is a set.

Proof

Pairing constructs the coded pair. The intersection of its members is \(\{a\}\), so equality of coded pairs gives \(a=c\). The union of its members is \(\{a,b\}\), hence \(\{a,b\}=\{a,d\}\). If this is a singleton, both \(b,d\) equal \(a\); otherwise its unique member other than \(a\) is both \(b\) and \(d\). Thus \(b=d\). The converse follows directly from the definition.

If \(a\in A\) and \(b\in B\), both \(\{a\}\) and \(\{a,b\}\) are subsets of \(A\cup B\). The pair therefore belongs to \(\mathcal P(\mathcal P(A\cup B))\). Separate from this set the objects equal to \(\langle a,b\rangle\) for some \(a\in A,b\in B\). This gives \(A\times B\), including the empty product when either factor is empty. □

Graphs and collections of functions need no new axiom

A function \(f:A\to B\) is represented by its graph, a subset of \(A\times B\) with exactly one pair \(\langle a,b\rangle\) for every \(a\in A\). The collection \(B^A\) of all such graphs is a set.

Proof

Use Separation on \(\mathcal P(A\times B)\) with the condition that every input has exactly one output. For an individual graph, \(f(a)=b\) abbreviates membership of \(\langle a,b\rangle\) in the graph. If \(A=\varnothing\), the empty graph is the unique function, even when \(B=\varnothing\). If \(A\ne\varnothing\) and \(B=\varnothing\), no graph meets the condition. □

For a fixed graph \(f:A\to B\), its image is a subset of the already known set \(B\), so Separation suffices. Replacement is useful when no such output bound has yet been constructed.

Replacement collects uniquely specified outputs

For each formula \(\psi(x,y,p_1,\ldots,p_k)\), the Replacement schema says: if for every \(x\in A\) there is exactly one set \(y\) satisfying \(\psi\), then a set \(B\) exists with

\[ y\in B\quad\Longleftrightarrow\quad\exists x\in A\,\psi(x,y,p_1,\ldots,p_k). \]

The parameters are fixed, and the variable for \(B\) is not free in \(\psi\). The formula is a definable rule; its full collection of input-output pairs may be a proper class. Replacement says its values on a set-sized domain form a set. Applying Replacement also to \(x\mapsto\langle x,y\rangle\) constructs the restricted graph.

For example, the unique ordinal representing a well-order can be collected for each order in a set of well-orders. Separation alone does not supply a set of candidate ordinals from which to select the outputs. Replacement does.

Existence and uniqueness are hypotheses to prove. Replacement is not a choice principle: it does not choose among several possible outputs. Nor does it collect the outputs of a proper-class domain into a set.

Infinity supplies one set containing all finite stages

Write \(S(x)=x\cup\{x\}\). A set \(I\) is inductive if \(\varnothing\in I\) and \(x\in I\) implies \(S(x)\in I\). The Infinity axiom asserts that an inductive set exists.

The other construction axioms build \(0=\varnothing\), \(1=S(0)\), \(2=S(1)\), and every subsequent finite stage. Infinity goes further: it places all these stages inside one set. The least inductive set gives a construction of \(\omega\).

Foundation requires a membership-minimal member

The Foundation axiom, also called Regularity, says that every nonempty set \(A\) has a member \(a\) such that \(a\cap A=\varnothing\). Equivalently, no member of \(A\) belongs to \(a\).

This does not say that \(a\) is empty or unique. For example, let \(0=\varnothing\), \(1=\{0\}\), \(2=\{0,1\}\), and \(A=\{1,\{2\}\}\). Both members have empty intersection with \(A\), although neither is empty.

Foundation controls membership, whereas the axioms above mostly construct sets. Its consequences, including membership induction and ranks, are developed in the foundation entry.

Choice is a further assumption

The axioms and schemas just stated form our presentation of ZF. ZFC is ZF together with the Axiom of Choice: for every set \(\mathcal A\) of nonempty sets there is a function \(c\) on \(\mathcal A\) with \(c(A)\in A\) for each \(A\in\mathcal A\).

The empty family has the empty choice function. For a nonempty family, the difficulty is supplying one function that makes all selections together. Replacement collects outputs of a uniquely specified rule; Choice asserts existence of a selection even when such a rule has not been supplied.

The constructions of natural numbers, integers, rationals, and real numbers, and membership ranks use ZF and do not require Choice. An assertion that some principle cannot be proved from ZF would require a separate independence argument; none is being claimed merely by giving it a different name.

Which axiom collects a family of power sets?

Given a set \(A\), justify the existence of \(\{\mathcal P(x):x\in A\}\). Does the justification require Choice?

Show answerHide answer

Power Set produces \(\mathcal P(x)\) for every \(x\), and Extensionality makes it unique. Replacement therefore collects those uniquely specified outputs on the domain \(A\). Choice is unnecessary. When \(A=\varnothing\), the collected family is empty.

There is also a bounded construction: \(x\subseteq\bigcup A\) for \(x\in A\), so \(\mathcal P(x)\subseteq\mathcal P(\bigcup A)\). Separate the desired power sets from \(\mathcal P(\mathcal P(\bigcup A))\). This example admits both methods; it does not establish that Replacement is needed for every family construction.
