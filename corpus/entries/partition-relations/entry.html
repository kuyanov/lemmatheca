Colour the subsets, then look for one colour throughout

Work in ZFC, and write \(\omega=\mathbb N=\{0,1,2,\ldots\}\). For a set \(X\) and a natural number \(n\), let

\[ [X]^n=\{s\subseteq X:|s|=n\}. \]

Thus \([X]^1\) consists of singletons and \([X]^2\) of unordered pairs of distinct elements. This notation does not permit repetitions. For a natural number \(r\), write \(I_{r}=\{0,\ldots,r-1\}\), with \(I_0=\varnothing\), as in finite-set counting.

A colouring is a map \(c:[X]^n\to K\), where \(K\) is a set of labels called colours. A set \(H\subseteq X\) is homogeneous in colour \(i\in K\) if

\[ (\forall s\in[H]^n)\ c(s)=i. \]

It is homogeneous if such a colour exists. Throughout the finite-colour results, \(K=I_{k}\) for a positive natural number \(k\). A colouring need not use every available colour. If \(|H|<n\), then \([H]^n\) is empty, so \(H\) is homogeneous in every available colour.

The partition relation \(\kappa\to(\lambda)^n_k\) says that every colouring of the \(n\)-element subsets of a set of cardinality \(\kappa\) into \(k\) colours has a homogeneous subset of cardinality \(\lambda\). Here \(n\) is finite and \(k>0\); the cardinals used below are finite or countably infinite. We write \(\omega\to(\omega)^n_k\) for the countably infinite case. A crossed arrow \(\nrightarrow\) denotes failure of the assertion.

Changing the names of the points preserves homogeneity

Let \(b:X\to Y\) be a bijection and \(c:[Y]^n\to K\) a colouring. Then

\[ d:[X]^n\to K,\qquad d(s)=c(b[s]) \]

is a colouring, and \(H\subseteq X\) is homogeneous for \(d\) in colour \(i\) exactly when \(b[H]\) is homogeneous for \(c\) in colour \(i\). The two sets have the same cardinality.

Proof

A bijection takes an \(n\)-element set to an \(n\)-element set. It also gives a bijection between \([H]^n\) and \([b[H]]^n\), with inverse \(t\mapsto b^{-1}[t]\). The defining equalities for homogeneity therefore correspond term by term. □

In particular, a result for colourings on \(\omega\) applies to colourings on any infinite \(S\subseteq\omega\): use its increasing enumeration. This will allow the Ramsey argument to be repeated inside an infinite subset.

A finite partition of an infinite set has an infinite cell

If \(S\) is infinite and \(f:S\to I_{k}\), where \(k>0\) is finite, then some fiber \(f^{-1}(\{i\})\) is infinite. Also, deleting finitely many elements from an infinite set leaves an infinite set.

Proof

A union of finitely many finite sets is finite: concatenate their finite lists, removing repeated elements. If all \(k\) fibers were finite, their union \(S\) would be finite, a contradiction. If \(S\setminus F\) and \(F\) were both finite, their union would make \(S\) finite as well. □

For an infinite subset of \(\omega\), deletion of \(I_{a+1}\) leaves infinitely many points greater than \(a\). This finite deletion will keep each step of the construction moving upwards.

A colouring can allow one colour on an infinite set and forbid the other on a triple

Colour a pair \(\{a,b\}\subseteq\omega\) by \(0\) when \(a,b\) have the same parity, and by \(1\) when they have different parity. The even numbers form an infinite \(0\)-homogeneous set, and so do the odd numbers. There is no \(1\)-homogeneous set of three elements.

Proof

Every pair of even numbers, or of odd numbers, has colour \(0\). Among any three natural numbers, two have the same parity by the pigeonhole principle, so their pair has colour \(0\). Hence those three points cannot have all their pairs coloured \(1\). □

Ramsey's theorem guarantees a homogeneous set in some colour. It does not promise one in each colour.

Infinite Ramsey's theorem gives an infinite homogeneous set

For every pair of positive natural numbers \(n,k\), every colouring \(c:[\omega]^n\to I_{k}\) has an infinite homogeneous subset of \(\omega\). In partition notation, \(\omega\to(\omega)^n_k\).

Proof

Fix \(k>0\), and induct on \(n\ge1\). For \(n=1\), apply to the map \(a\mapsto c(\{a\})\).

Suppose the assertion holds for \(n\), and let \(c:[\omega]^{n+1}\to I_{k}\). We construct increasing points \(a_0,a_1,\ldots\), nested infinite sets \(A_0\supseteq A_1\supseteq\cdots\), and colours \(d_i\in I_{k}\) so that all points of \(A_i\) exceed \(a_i\) and

\[ (\forall s\in[A_i]^n)\ c(\{a_i\}\cup s)=d_i. \label{eq:ramsey-tails} \]

Begin with \(a_0=0\). On the infinite set of positive natural numbers, colour each \(n\)-element subset \(s\) by \(c(\{a_0\}\cup s)\). The induction hypothesis, transferred by , gives an infinite homogeneous set \(A_0\) and its colour \(d_0\).

Given \(A_i\), take \(a_{i+1}=\min A_i\). The set \(B=A_i\setminus I_{a_{i+1}+1}\) is infinite by . Colour \([B]^n\) by \(s\mapsto c(\{a_{i+1}\}\cup s)\), and apply the induction hypothesis again. It gives an infinite \(A_{i+1}\subseteq B\) and a colour \(d_{i+1}\) satisfying \eqref{eq:ramsey-tails}. The unions in these formulas have \(n+1\) elements because the points of \(B\) exceed \(a_{i+1}\). These choices can be made recursively under the stated Choice assumption.

Apply to \(i\mapsto d_i\). There is an infinite set of indices \(I\subseteq\omega\) on which \(d_i\) has one value \(d\). Put \(H=\{a_i:i\in I\}\), which is infinite since the \(a_i\) strictly increase.

Take any \((n+1)\)-element subset of \(H\), and list its points as \(a_{i_0}<a_{i_1}<\cdots<a_{i_n}\). Every later point \(a_{i_j}\), \(j>0\), lies in \(A_{i_0}\): it was chosen from \(A_{i_j-1}\subseteq A_{i_0}\). Equation \eqref{eq:ramsey-tails} gives colour \(d_{i_0}=d\) to this subset. Thus all of \([H]^{n+1}\) has colour \(d\), completing the induction. □

Does the proof need a point in every infinite tail?

Must the intersection \(\bigcap_i A_i\) in the Ramsey proof be infinite, or even nonempty?

Show answerHide answer

No. In fact this intersection is empty. The strictly increasing sequence \((a_i)\) is unbounded in \(\omega\), and every point of \(A_i\) exceeds \(a_i\). Any fixed natural number is therefore excluded from some \(A_i\).

The proof tests one finite subset of \(H\) at a time. Its least point \(a_{i_0}\) determines the single tail \(A_{i_0}\) that contains all its other points. No common point of all tails is required.

Length-tagged finite colourings form a tree with finite levels

Fix positive natural numbers \(n,k\). A node is a pair \((r,c)\), where \(r\in\omega\) and \(c:[I_r]^n\to I_{k}\). Order the nodes by restriction:

\[ (r,c)\le_T(s,d) \quad\Longleftrightarrow\quad r\le s\ \text{ and }\ c=d\mathbin{\upharpoonright}[I_r]^n. \]

This is a tree; the node \((r,c)\) has height \(r\), and each finite level is finite.

Proof

Restrictions compose, so the relation is reflexive and transitive. If two nodes extend each other, their lengths agree and their colourings agree, proving antisymmetry. The strict predecessors of \((r,c)\) are exactly

\[ (t,c\mathbin{\upharpoonright}[I_t]^n),\qquad t<r, \]

in their increasing order of lengths. They have order type \(r\), which proves the height assertion.

The power set of \(I_{r}\) is finite: each subset is specified by \(r\) yes-or-no membership choices, giving \(2^r\) possibilities. Consequently \([I_r]^n\) is finite. If it has \(q\) members, there are \(k^q\) colourings on it, since each of those \(q\) members independently receives one of \(k\) labels. This is a finite number, including \(q=0\), when there is one empty colouring. Thus the nodes at height \(r\) form a finite level. □

The length is part of the node even if its colouring has empty domain. For example, when \(n=2\), the empty colouring on \(I_0\) and the empty colouring on \(I_1\) have the same graph, but \((0,\varnothing)\) and \((1,\varnothing)\) are different nodes at different heights.

Finite Ramsey's theorem gives a finite bound for every target size

For positive natural numbers \(n,k,m\), there is a natural number \(N\ge m\) such that every colouring \(c:[I_N]^n\to I_{k}\) has a homogeneous subset of \(I_{N}\) with exactly \(m\) elements. Equivalently, \(N\to(m)^n_k\).

Proof

If \(m<n\), take \(N=m\); the whole set \(I_{m}\) is homogeneous vacuously. Now suppose \(m\ge n\), and assume for contradiction that no finite \(N\ge m\) works.

In the tree from , keep just the nodes \((r,c)\) for which \(c\) has no homogeneous \(m\)-element subset of \(I_{r}\). Call them bad nodes. Restricting a bad colouring to a smaller initial segment leaves it bad: a homogeneous \(m\)-element subset in the restriction would also be homogeneous for the original colouring. Thus every predecessor of a bad node is still in the retained tree, and its height remains its length \(r\).

For each \(r\), take any \(N\ge\max(r,m)\). Our contrary assumption supplies a bad colouring on \(I_{N}\); its restriction gives a bad node of length \(r\). The retained tree therefore has a nonempty finite level at every natural height and has height \(\omega\). By König's lemma, it has a cofinal branch. Write its unique node at height \(r\) as \((r,c_r)\). Comparability gives

\[ r\le s\quad\Longrightarrow\quad c_r=c_s\mathbin{\upharpoonright}[I_r]^n. \]

Take the union of the graphs of the \(c_r\). Agreement on overlaps makes this a function \(c:[\omega]^n\to I_{k}\). Its domain is all of \([\omega]^n\), since every finite subset of \(\omega\) is contained in some \(I_{r}\).

By , \(c\) has an infinite homogeneous set \(H\). Choose \(m\) of its elements and call their set \(F\). Since \(F\) is finite, some \(I_{r}\) contains it. The colouring \(c_r\) agrees with \(c\) on every \(n\)-element subset of \(F\), so \(F\) is homogeneous for \(c_r\). This contradicts the badness of \((r,c_r)\). □

The least such \(N\) exists by the well-ordering of the natural numbers; write it as \(R(n,k,m)\). The theorem establishes finiteness without calculating this number.

Six points force a homogeneous triple, and five do not

For two colours on unordered pairs, \(R(2,2,3)=6\).

Proof

First colour all pairs from a six-element set by \(0\) or \(1\). Fix a point \(a\). Among its five pairs with the other points, at least three have the same colour \(i\). Let those three other points be \(b,c,d\). If any pair among them has colour \(i\), that pair together with \(a\) gives a homogeneous triple. Otherwise all three pairs from \(\{b,c,d\}\) have the other colour, giving a homogeneous triple again. Hence six points suffice.

For the lower bound, on \(I_5=\{0,1,2,3,4\}\) give colour \(0\) precisely to

\[ \{0,1\},\ \{1,2\},\ \{2,3\},\ \{3,4\},\ \{0,4\}, \]

and give colour \(1\) to all other pairs. No triple has colour \(0\) throughout: if it contains \(\{0,4\}\), its third point would have to be both \(1\) and \(3\); without that pair, three points cannot be pairwise consecutive natural numbers. For a hypothetical colour-\(1\) triple \(a<b<c\), the first two gaps must satisfy \(b-a\ge2\) and \(c-b\ge2\). Within \(I_5\) this forces \((a,b,c)=(0,2,4)\), but \(\{0,4\}\) has colour \(0\). Thus there is no homogeneous triple on these five points.

Restrictions give counterexamples on smaller sets as well. Together with the six-point argument this proves the claimed minimum. □

Can one infinite set satisfy several finite-colour requirements?

Suppose \(c_j:[\omega]^{n_j}\to I_{k_j}\) for \(j<r\), where \(r\) is finite and every \(n_j,k_j\) is positive. Is there one infinite \(H\) homogeneous for every \(c_j\)? Must the resulting colours agree?

Show answerHide answer

Yes. Start with \(H_0=\omega\). At step \(j<r\), apply inside \(H_j\), using , and choose an infinite \(H_{j+1}\subseteq H_j\) homogeneous for \(c_j\). Homogeneity survives taking subsets, so the final \(H_r\) satisfies all \(r\) requirements. For \(r=0\), take \(H=\omega\).

The colours may differ. For example, one colouring can be constantly \(0\) and another constantly \(1\), with both using the colour set \(I_2\).

Does one colour work for subsets of every finite size at once?

Colour every nonempty finite subset \(s\subseteq\omega\) by \(0\) if \(|s|\) is even and by \(1\) if \(|s|\) is odd. Does the infinite Ramsey theorem give an infinite set whose nonempty finite subsets all have one colour?

Show answerHide answer

No. Every infinite set has both a singleton, of colour \(1\), and a two-element subset, of colour \(0\). The theorem fixes one subset size \(n\) before seeking homogeneity. In this example every \(n\)-element subset already has one colour, but that colour depends on \(n\). The simultaneous finite-colouring result likewise allows different colours for different requirements.

Infinitely many colours can prevent even a small homogeneous set

For every positive natural number \(n\), the colouring

\[ c:[\omega]^n\to\omega,\qquad c(s)=\min s \]

has no homogeneous subset of size \(n+1\). Consequently it has no infinite homogeneous subset.

Proof

Let \(F=\{a_0<a_1<\cdots<a_n\}\). Its two \(n\)-element subsets \(F\setminus\{a_n\}\) and \(F\setminus\{a_0\}\) have different minima, \(a_0\) and \(a_1\), so they have different colours. Every larger homogeneous set would have a homogeneous \((n+1)\)-element subset, which is impossible. □

For pairs this means there is no homogeneous triple. There can still be a homogeneous pair, because a two-element set has only one unordered pair. Finiteness of the colour set is essential to the Ramsey conclusions.

What happens at subset size zero or with no available colours?

How does \(n=0\) behave? Why were the main results stated with \(k>0\)?

Show answerHide answer

For every set \(X\), \([X]^0=\{\varnothing\}\). A colouring into a nonempty colour set assigns a single value to \(\varnothing\), and every \(H\subseteq X\) is homogeneous in that value. Thus the zero-size version is immediate. The minimum colouring in requires \(n>0\), since the empty set has no minimum.

With \(k=0\), a colouring exists only when its domain is empty. Even then there is no colour witnessing homogeneity under our definition. Keeping \(k>0\) avoids these empty-codomain cases and makes the vacuous homogeneity of sets smaller than \(n\) consistent throughout the entry.
