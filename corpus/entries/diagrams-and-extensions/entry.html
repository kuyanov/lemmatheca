Recall the maps that a diagram must describe

Fix nonempty structures in a language \(L\), and work in classical set theory with choice. Recall that an embedding \(f:M\hookrightarrow N\) is injective, preserves every interpreted function including constants, and preserves and reflects every interpreted relation. Its image is a substructure, and the specified map onto that image is an isomorphism.

An elementary embedding additionally preserves and reflects every formula, including formulas with quantifiers. We now encode the facts ensuring these two kinds of maps by naming the elements of the source.

The literal criterion for embeddings

A specified map \(f:|M|\to|N|\) is an embedding if and only if it preserves every literal at every finite tuple, or equivalently preserves and reflects every atomic formula. This is the atomic embedding criterion. Every embedding also preserves and reflects quantifier-free formulas.

Giving each element a name

For an \(L\)-structure \(M\), let the language with names for \(M\), denoted by \(L(M)\), be obtained by adjoining a fresh constant symbol \(c_a\) for every \(a\in|M|\). These symbols are distinct from the original symbols. Let \(M_M\) be the canonical expansion of \(M\), in which \(c_a^{M_M}=a\).

If \(N^*\) is any \(L(M)\)-structure, its reduct \(N=N^*\!\upharpoonright L\) keeps the same domain and forgets the interpretations of the added symbols. The names determine the canonical map

\[h_{N^*}:|M|\longrightarrow|N|,\qquad h_{N^*}(a)=c_a^{N^*}.\]

Before imposing any sentences, this map need not be injective or preserve any relations.

For an \(L\)-formula \(\varphi(\bar x)\) and a tuple \(\bar a\) assigning all its free variables, write \(\varphi(c_{\bar a})\) for the sentence obtained by replacing the free occurrences of each variable by its corresponding name. The substitution rule gives

\[N^*\models\varphi(c_{\bar a})\quad\Longleftrightarrow\quad N\models\varphi[h_{N^*}(\bar a)].\]

Every \(L(M)\)-sentence uses only finitely many added names. Replacing those names by distinct fresh free variables expresses it in this form, with bound variables renamed when needed. If the sentence is a literal or is quantifier-free, the resulting formula has the same property.

The signed atomic diagram

The signed atomic diagram of \(M\), denoted \(\operatorname{Diag}(M)\), is the set of all \(L(M)\)-literal sentences true in \(M_M\). Thus, for every atomic \(L(M)\)-sentence \(\alpha\), it contains \(\alpha\) if \(\alpha\) is true and \(\neg\alpha\) if \(\alpha\) is false.

For example, it contains \(c_a\ne c_b\) whenever \(a\ne b\), the function facts

\[g(c_{a_0},\ldots,c_{a_{k-1}})=c_{g^M(\bar a)},\]

and either \(R(c_{a_0},\ldots,c_{a_{k-1}})\) or its negation, according to its truth in \(M\). For an original constant \(d\), the corresponding function fact is \(d=c_{d^M}\).

One sometimes defines the diagram using all true quantifier-free sentences instead. The two versions have exactly the same models: the literals determine the truth of every atom, and induction on the logical connectives then determines every quantifier-free sentence.

Models of the signed diagram contain an embedded copy

For every \(L(M)\)-structure \(N^*\), we have \(N^*\models\operatorname{Diag}(M)\) if and only if the canonical map \(h_{N^*}:M\to N^*\!\upharpoonright L\) is an embedding.

Consequently, an \(L\)-structure \(N\) admits an embedding of \(M\) if and only if \(N\) can be expanded to a model of \(\operatorname{Diag}(M)\).

Suppose \(N^*\) satisfies the diagram. Whenever an \(L\)-literal \(\lambda(\bar x)\) is true in \(M\) at \(\bar a\), the named sentence \(\lambda(c_{\bar a})\) belongs to the diagram. Hence it is true in \(N^*\), and makes \(\lambda\) true at \(h_{N^*}(\bar a)\) in the reduct. The literal criterion in shows that this particular map is an embedding.

Conversely, if \(h_{N^*}\) is an embedding, express any literal in the diagram as \(\lambda(c_{\bar a})\). Its truth in \(M_M\) means \(M\models\lambda[\bar a]\). The embedding preserves this truth, so the named sentence is true in \(N^*\). Thus all of the diagram holds.

Finally, given an embedding \(f:M\hookrightarrow N\), expand \(N\) by interpreting each \(c_a\) as \(f(a)\). Its canonical map is exactly \(f\), so this expansion satisfies the diagram. The reverse implication follows from the first part.

Can the negative facts be omitted?

The positive atomic diagram contains only the true atomic sentences. Would its models still supply embeddings by interpreting the names?

Show answerHide answer

No. In the equality-only language, let \(M\) have two elements and \(N\) one element. Every true atomic sentence with names is an equality between names of the same element. It remains true if all names are interpreted by the sole element of \(N\). The positive diagram therefore holds, although its canonical map is not injective. The missing sentence is the inequality between the two distinct names.

Even injectivity is insufficient. Take a language with one unary relation \(P\), let \(M\) be a singleton in which \(P\) is false, and let \(N\) be a singleton in which \(P\) is true. Interpreting the sole new name by the sole element satisfies the positive diagram. The canonical map is injective but does not reflect \(P\). The signed diagram excludes this model by including \(\neg P(c_a)\).

The positive diagram instead describes homomorphisms through its canonical map, which need neither injectivity nor relation reflection.

Recording every first-order fact with names

The elementary diagram of \(M\) is the complete theory of its canonical expansion:

\[\operatorname{ElDiag}(M)=\operatorname{Th}(M_M).\]

Here the theory of a structure consists of all sentences true in it. Unlike the signed atomic diagram, the elementary diagram also records sentences containing quantifiers. In named form, it contains \(\varphi(c_{\bar a})\) exactly when \(M\models\varphi[\bar a]\).

Both diagrams are satisfiable: \(M_M\) itself is a model. The elementary diagram contains the signed diagram. It is important to distinguish it from \(\operatorname{Th}(M)\), which uses only the original language and has no names for arbitrary elements of \(M\).

Models of the elementary diagram contain an elementary copy

For every \(L(M)\)-structure \(N^*\), we have \(N^*\models\operatorname{ElDiag}(M)\) if and only if the canonical map \(h_{N^*}:M\to N^*\!\upharpoonright L\) is an elementary embedding.

Thus an \(L\)-structure \(N\) admits an elementary embedding of \(M\) if and only if it can be expanded to a model of \(\operatorname{ElDiag}(M)\).

Suppose the elementary diagram holds. For an \(L\)-formula \(\varphi\) and tuple \(\bar a\) from \(M\), either \(\varphi(c_{\bar a})\) or its negation belongs to \(\operatorname{ElDiag}(M)\), according to its truth in \(M\). The same choice must hold in \(N^*\). By ,

\[M\models\varphi[\bar a]\quad\Longleftrightarrow\quad N^*\!\upharpoonright L\models\varphi[h_{N^*}(\bar a)].\]

This is exactly elementarity of the canonical map.

Conversely, every sentence of the elementary diagram has the form \(\varphi(c_{\bar a})\). Elementarity transports its truth from \(M\) to the reduct at the interpreted names, so the sentence holds in \(N^*\). Given an elementary embedding \(f:M\to N\), interpret \(c_a\) as \(f(a)\); the resulting expansion has canonical map \(f\) and satisfies the diagram.

Turning an embedded copy into an extension

Let \(h:M\to N\) be an elementary embedding of nonempty \(L\)-structures. There exist an elementary extension \(M\preccurlyeq N'\) and an isomorphism \(e:N'\to N\) such that \(e(a)=h(a)\) for every \(a\in|M|\). The structure \(N'\) has the same cardinality as \(N\), and the extension is proper if \(h\) is not onto.

The domains of \(M\) and \(N\) need not be nested. The image characterization gives \(h(M)\preccurlyeq N\), isomorphic to \(M\).

To obtain a literal extension of \(M\), rename the points of \(h(M)\) by their unique preimages in \(M\), and rename the remaining points by fresh labels outside \(|M|\). More precisely, choose a set \(C\) disjoint from \(|M|\) and a bijection from \(C\) onto \(|N|\setminus h(M)\). On \(D=|M|\cup C\), let \(e:D\to|N|\) be that bijection on \(C\) and let \(e(a)=h(a)\) on \(|M|\). These two pieces make \(e\) a bijection.

Transport the structure of \(N\) along \(e\): define

\[g^{N'}(\bar d)=e^{-1}(g^N(e(\bar d))),\]
\[R^{N'}(\bar d)\quad\Longleftrightarrow\quad R^N(e(\bar d)).\]

Then \(e:N'\cong N\), and on \(|M|\) the transported functions and relations agree with those of \(M\), because \(e\) restricts to the embedding \(h\). For every formula and tuple from \(M\), isomorphism invariance and elementarity of \(h\) give agreement between \(N'\) and \(M\). Thus \(M\preccurlyeq N'\). If \(h\) was not onto, \(C\) is nonempty and this extension is proper. Renaming preserves cardinality and, in particular, countability.

A countable infinite structure has a proper countable elementary extension

Let \(L\) be countable and let \(M\) be a countably infinite \(L\)-structure. There are a countably infinite \(L\)-structure \(N\), an elementary embedding \(h:M\to N\), and an element \(b\in|N|\setminus h(M)\). After renaming the copy as in , this gives a proper countable elementary extension of \(M\).

Adjoin all the names \(c_a\), and one further fresh constant \(d\). Consider the theory

\[U=\operatorname{ElDiag}(M)\cup\{d\ne c_a:a\in|M|\}.\]

The diagram sentences are viewed in the enlarged language without changing their meaning. This language is countable because \(L\) and \(|M|\) are countable.

Every finite subset \(F\subseteq U\) is satisfiable in an expansion of \(M\). Interpret all \(c_a\) by \(a\). Only finitely many inequalities \(d\ne c_a\) occur in \(F\). Since \(M\) is infinite, choose an element outside this finite set and use it for \(d\). All diagram sentences hold by the canonical interpretation, and all selected inequalities hold by the choice of \(d\).

Countable-language compactness gives a model of \(U\), so \(U\) is consistent by soundness. The countable model theorem lets us choose such a model \(N^*\) with countable domain. Its reduct \(N\) contains the elementary image of \(M\) by . Put \(b=d^{N^*}\). Every inequality in \(U\) holds, so \(b\ne h(a)\) for all \(a\in|M|\). Finally, \(N\) is infinite because it contains an injective image of the infinite structure \(M\).

The countability assumptions concern this compactness application. The diagram definitions and the two diagram lemmas impose no countability restrictions.

Finite structures cannot have proper elementary extensions

If \(M\) is finite, every elementary embedding \(h:M\to N\) is onto.

List \(|M|=\{a_0,\ldots,a_{m-1}\}\), where \(m\ge1\). In \(M\), the formula with these parameters

\[\forall y\;\bigvee_{i<m}y=a_i\]

is true. Elementarity makes \(\forall y\,\bigvee_{i<m}y=h(a_i)\) true in \(N\), so every element lies in the image. Equivalently, the elementary diagram itself includes the named sentence \(\forall y\,\bigvee_{i<m}y=c_{a_i}\), which prevents an additional point.

This also pinpoints the failed finite test in the extension construction: the covering sentence together with \(d\ne c_{a_i}\) for all \(i<m\) is already a finite unsatisfiable subset.

A new point beyond all the original natural numbers

Can the strict-order structure \((\mathbb N,<)\) have a countable elementary extension containing an element greater than every original natural number?

Show answerHide answer

Yes. In the countable language with names for the natural numbers and one additional constant \(d\), use

\[\operatorname{ElDiag}(\mathbb N,<)\cup\{c_n<d:n\in\mathbb N\}.\]

Any finite subset holds in the original natural-number order after choosing \(d\) larger than its finitely many lower bounds; if there are none, any natural number works. The same compactness and countable-model argument gives a countable expanded model \(N^*\). Let \(N\) be its order reduct and put \(b=d^{N^*}\). The canonical map \(h:\mathbb N\to N\) is elementary and satisfies \(h(n)<b\) for every original \(n\). The new element cannot equal an \(h(n)\), since strict order is irreflexive. Rename the elementary image if a literal extension is desired.

There is no conflict with \(\mathbb N\models\forall x\,\exists y\;(x<y)\). That sentence also holds in the elementary extension, so the new point has still larger points above it. Being above every member of the original copy does not mean being greatest in the larger order.

The finite-realizability criterion for parameter types gives the general form of this construction.
