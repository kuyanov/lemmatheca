Keep the symbols and add one fresh relation

Fix a first-order language \(L\), allowing function and relation symbols of every finite arity, including zero. The equality-relation language \(L^E\) has exactly the same function symbols as \(L\), one distinguished copy of each old relation symbol, and one further binary relation symbol \(E\). The old copies are disjoint from \(E\), even if an old relation happened to have that printed name. Terms are therefore carried to \(L^E\) by preserving every variable and function application; write \(t^E\) for this term translation.

Both languages still have logical equality in their syntax and ordinary structures interpret it as identity. We shall construct formulas of \(L^E\) that never use its equality constructor. Calling them equality-free means precisely that no logical equality atom occurs; relation atoms, falsity, implication and quantifiers are allowed. We work throughout with nonempty structures, as in first-order semantics.

Replace equality at its actual place in the syntax

The equality translation \(A\mapsto A^E\) acts on the actual scoped first-order syntax. It preserves every free variable name and every in-scope bound slot. Its clauses are

\[\bot^E=\bot,\qquad (s=t)^E=E(s^E,t^E),\qquad R(\bar t)^E=R(\bar t^E).\]
\[(A\to B)^E=A^E\to B^E,\qquad (\forall x\,A)^E=\forall x\,A^E.\]

Negation, conjunction, disjunction, biconditional and existential quantification are the usual abbreviations, so the translation commutes with them too. Under a quantifier the new bound slot is retained, and the translation is applied to its body with that larger slot context. There is no substitution or renaming of variables in this operation. Structural induction immediately shows that \(A^E\) is equality-free: the equality case becomes a relation atom and no other case introduces equality.

The five requirements on the new relation

The equality axiom schemes \(\operatorname{EqAx}(L)\) consist of the universal closures of the following formulas. Here \(f\) ranges over every \(k\)-ary function symbol of \(L\), \(R\) over every \(k\)-ary old relation symbol, and \(k\) over all natural numbers. All displayed variables in a formula are universally quantified independently of those in other formulas.

\[E(x,x).\]
\[E(x,y)\to E(y,x).\]
\[E(x,y)\land E(y,z)\to E(x,z).\]
\[\bigwedge_{i<k}E(x_i,y_i)\to E(f(\bar x),f(\bar y)).\]
\[\bigwedge_{i<k}E(x_i,y_i)\land R(\bar x)\to R(\bar y).\]

The first three express reflexivity, symmetry and transitivity. The fourth is function congruence; the fifth is relation congruence. The relation scheme is stated as one implication. Symmetry applied to each \(E(x_i,y_i)\) gives the reverse implication as well, so related tuples have exactly the same relation truth value. No additional congruence scheme for \(E\) itself is necessary: if \(E(a,a')\) and \(E(b,b')\), symmetry and transitivity give \(E(a,b)\leftrightarrow E(a',b')\).

The empty conjunction, when \(k=0\), is true. Thus a constant \(c\) contributes \(E(c,c)\), and a zero-ary relation contributes \(R()\to R()\). Keeping these harmless instances makes the schemes apply uniformly to every arity.

An ordinary model gives an equality-axiom model

For every nonempty \(L\)-structure \(M\), let its identity expansion \(M^=\) retain the domain, functions and old relations and interpret \(E(a,b)\) as \(a=b\). Then \(M^=\models\operatorname{EqAx}(L)\). At every free-name assignment \(v\) and every assignment \(w\) to its bound slots, an actual scoped formula satisfies

\[M^=\models A^E[v,w]\quad\Longleftrightarrow\quad M\models A[v,w].\]

Identity is reflexive, symmetric and transitive. Pointwise identical tuples are identical tuples, so their function values and relation truth values agree. This proves all schemes, including empty tuples. Induction on terms shows that \(t^E\) has exactly the value of \(t\). At an equality atom, the definition of \(E\) makes the two truth conditions identical; at an old relation atom, the relation and argument values are unchanged. Falsity and implication preserve the induction claim. A universal quantifier ranges over the same domain on both sides and extends the same slot assignment by the same element; apply the induction hypothesis to each such extension. This proves the displayed equivalence for all scoped formulas.

Collapse the pairs that the axioms identify

Let \(N\) be a nonempty \(L^E\)-structure satisfying \(\operatorname{EqAx}(L)\). Put \(a\sim b\) exactly when \(N\models E(a,b)\). The first three schemes make this an equivalence relation. Its quotient model \(Q_N\) has domain \(N/{\sim}\), with \(q(a)=[a]\). Define its old symbols by

\[f^{Q_N}([a_0],\ldots,[a_{k-1}])=[f^N(a_0,\ldots,a_{k-1})].\]
\[R^{Q_N}([a_0],\ldots,[a_{k-1}])\quad\Longleftrightarrow\quad R^N(a_0,\ldots,a_{k-1}).\]

These rules do not depend on representatives. Replacing \(a_i\) by \(b_i\sim a_i\) makes the two function outputs related, by function congruence, hence gives the same output class. Relation congruence in both directions gives the same relation truth value. This is the criterion for defining rules on classes. In particular, \(c^{Q_N}=[c^N]\) for a constant, and a zero-ary relation keeps its original truth value.

The projection \(q\) is onto because every class has a representative, and the quotient is nonempty because \(q(a)\) exists for any \(a\in N\). Also

\[q(a)=q(b)\quad\Longleftrightarrow\quad N\models E(a,b).\]

Equality in \(Q_N\) is actual equality of classes. This general construction uses the same kind of representative check as the Henkin term model, but its starting objects may be arbitrary elements of an expanded structure.

Evaluation of terms commutes with projection

For \(N,Q_N,q\) as in , every actual term \(t\) and assignment \(u\) of all its variables satisfy

\[t^{Q_N}[q\circ u]=q\bigl((t^E)^N[u]\bigr).\]

For a scoped term, the variables here comprise both its free names and its current bound slots, so the statement also applies to their combined assignment.

A variable gives \(q(u(x))\) on both sides. If \(t=f(t_0,\ldots,t_{k-1})\), the induction hypotheses identify the values of its children with \(q((t_i^E)^N[u])\). The defining rule for \(f^{Q_N}\) then gives the class of \(f^N((t_0^E)^N[u],\ldots,(t_{k-1}^E)^N[u])\), which is precisely the right side. This includes the zero-argument application, so constants require no exceptional argument.

The quotient preserves truth through every quantifier

Let \(N\models\operatorname{EqAx}(L)\) be nonempty. For every actual scoped \(L\)-formula \(A\), every assignment \(v\) to its free names and every assignment \(w\) to its current bound slots,

\[Q_N\models A[q\circ v,q\circ w]\quad\Longleftrightarrow\quad N\models A^E[v,w].\]

Induct on the actual formula constructors, keeping both assignments arbitrary. At \(s=t\), the term lemma changes equality of the quotient values to equality of the classes of \((s^E)^N\) and \((t^E)^N\). The projection equality criterion says precisely that these two elements satisfy \(E\) in \(N\), which is truth of \((s=t)^E\). At \(R(\bar t)\), the term lemma and the definition of the quotient relation give truth of \(R(\bar t^E)\). Falsity is false on both sides. For an implication, the two induction equivalences identify its antecedent and consequent truth conditions.

It remains to justify a universal quantifier. Write its body as \(B\); its new slot is assigned the quantified element. If \(Q_N\models\forall x\,B\), take any \(a\in N\). Apply this universal statement to \(q(a)\), then the induction hypothesis at the extended assignments. It yields \(N\models B^E[v,w,a]\). Since \(a\) was arbitrary, \(N\models\forall x\,B^E\).

Conversely, suppose \(N\models\forall x\,B^E\). To test \(B\) at an arbitrary \(b\in Q_N\), use surjectivity to choose \(a\in N\) with \(q(a)=b\). The hypothesis gives \(B^E\) at the extended slot assignment \((w,a)\); the induction hypothesis gives \(B\) at \((q\circ w,b)\). Projection commutes with extending a slot assignment, so these are exactly the assignments required by the quantifier clause. Thus \(Q_N\models\forall x\,B\), completing the induction.

Existential quantification follows as an abbreviation, or by projecting a witness in one direction and choosing a representative in the other. Surjectivity is the step that extends the atomic argument to all formulas.

One fixed translation works for every theory

For an arbitrary \(L\)-theory \(T\), let \(T^E=\{A^E:A\in T\}\), a theory of actual \(L^E\)-sentences.

Choose \(L^E\), the translation, and \(\operatorname{EqAx}(L)\) from \(L\) once and for all, before choosing \(T\). For every theory \(T\),

\[T\text{ has a nonempty model}\quad\Longleftrightarrow\quad T^E\cup\operatorname{EqAx}(L)\text{ has a nonempty model}.\]

If \(M\models T\), its identity expansion satisfies the axioms and every translated sentence by . Conversely, let \(N\) satisfy the theory on the right. Construct \(Q_N\). For each \(A\in T\), truth of \(A^E\) transfers to truth of \(A\) by with the empty assignments. The nonempty quotient therefore models all of \(T\). Neither construction requires \(T\) to be finite or countable, and the added symbols and translation do not depend on which axioms belong to \(T\).

Translate clauses that contain actual equality atoms

An original atom over variables \(\mathbb N\) is either a pair of actual \(L\)-terms \((s,t)\), denoting logical equality \(s=t\), or an actual relation atom \(R(\bar t)\) of \(L\). An original equality clause is a finite set of signed original atoms. Its native formula \(\operatorname{eqcl}(C)\) is the disjunction of the corresponding positive or negated actual atomic formulas. The empty set denotes falsity; asserting a clause requires truth under every assignment of its natural-number variables.

The clause translation \(C\mapsto C^E\) sends \(s=t\) to the actual relation atom \(E(s^E,t^E)\), sends \(R(\bar t)\) to the old-copy relation atom \(R(\bar t^E)\), preserves every sign, and takes the finite image of the signed set. Thus \(C^E\) is an actual equality-free relation clause, in exactly the representation of Herbrand relation clauses. Any duplicate image literals merge. For a set of original clauses \(\Delta\), write \(\Delta^E=\{C^E:C\in\Delta\}\). All variables are preserved, and each translated clause is independently asserted under all assignments.

The five schemes are equality-free signed clauses

Use the actual relation atoms and signed finite-set clauses over variables \(x_0,x_1,\ldots\). A positive atom denotes itself and a negative atom its negation; the clause denotes their disjunction. Define the equality axiom clause family \(\mathcal E_L\) by the following five kinds of finite sets, with the last two taken for every old symbol of every arity:

\[\{E(x_0,x_0)\}.\]
\[\{\neg E(x_0,x_1),\ E(x_1,x_0)\}.\]
\[\{\neg E(x_0,x_1),\ \neg E(x_1,x_2),\ E(x_0,x_2)\}.\]

For an arity \(k\), put \(\bar x=(x_{2i})_{i<k}\) and \(\bar y=(x_{2i+1})_{i<k}\). The remaining clauses are

\[\{\neg E(x_{2i},x_{2i+1}):i<k\}\cup\{E(f(\bar x),f(\bar y))\}.\]
\[\{\neg E(x_{2i},x_{2i+1}):i<k\}\cup\{\neg R(\bar x),R(\bar y)\}.\]

Every term in these atoms is an actual translated \(L^E\)-term, and \(E\) is an ordinary relation symbol in each atom. Hence these are clauses in the same equality-free representation used for ground instances. Each clause has its own universal variable assignment; there is no single shared choice of values for variables across the family. At arity zero, the first finite set is empty: a constant gives the unit clause \(\{E(c,c)\}\), while a zero-ary relation gives the tautological clause \(\{\neg R(),R()\}\).

Clause satisfaction is exactly axiom satisfaction

Let \(N\) be any nonempty \(L^E\)-structure. Then \(N\models\operatorname{EqAx}(L)\) if and only if, for every \(C\in\mathcal E_L\) and every assignment \(u:\mathbb N\to N\), the actual first-order clause formula \(\operatorname{cl}(C)\) is true at \(u\). Each \(\operatorname{cl}(C)\) is equality-free. Universally closing just its finitely many occurring variables gives the corresponding axiom sentence.

The native clause truth bridge says that \(\operatorname{cl}(C)\) is true exactly when some signed member of \(C\) is true. A disjunction \(\neg P_0\lor\cdots\lor\neg P_{k-1}\lor Q\) is true exactly when \((\bigwedge_{i<k}P_i)\to Q\). The same observation with the extra negative literal \(\neg R(\bar x)\) gives the relation implication. For the first three finite sets it gives reflexivity, symmetry and transitivity directly. Empty conjunctions and duplicate literals cause no change in this truth equivalence.

If the five schemes hold, these observations show that every listed clause is true at every assignment. For the converse, arbitrary elements \(a,b,c\) can be assigned to \(x_0,x_1,x_2\). For arbitrary tuples \(\bar a,\bar b\in N^k\), assign \(x_{2i}\) the value \(a_i\) and \(x_{2i+1}\) the value \(b_i\). These coordinates are distinct, so this prescribes a consistent finite partial assignment. Choose one element of the nonempty domain for all remaining variables. Clause truth now gives precisely the required function or relation congruence implication for those tuples. Thus all instances of all schemes hold.

Only the finitely many occurring variables affect a clause formula. Every assignment to them extends to all natural-number variables using the same default element. Truth at every total assignment is consequently equivalent to truth of its universal closure, proving the claimed sentence formulation as well.

Every equality-clause set has a concrete relation-clause reduction

For every original clause \(C\), every expanded structure \(N\), and every assignment \(u:\mathbb N\to N\),

\[N\models (\operatorname{eqcl}(C))^E[u]\quad\Longleftrightarrow\quad N\models\operatorname{cl}(C^E)[u].\]

If \(N\models\operatorname{EqAx}(L)\), the same truth bridge and the quotient theorem give

\[Q_N\models\operatorname{eqcl}(C)[q\circ u]\quad\Longleftrightarrow\quad N\models\operatorname{cl}(C^E)[u].\]

Consequently, for every set \(\Delta\) of original equality clauses,

\[\Delta\text{ has a nonempty clause model}\quad\Longleftrightarrow\quad\Delta^E\cup\mathcal E_L\text{ has a nonempty clause model}.\]

For each signed original atom, translating its native formula gives exactly the translated positive atom or its negation. Both clause truth conditions therefore say that some signed member of \(C\) has true translated formula. Taking a finite image preserves this existence condition: each image member comes from a source member, and each source member has an image. Neither enumeration order nor merging duplicate literals changes a disjunction's truth. This proves the first equivalence without assuming the equality axioms. Apply to the actual formula \(\operatorname{eqcl}(C)\) to obtain the second.

If an ordinary structure satisfies \(\Delta\), its identity expansion satisfies all translated clauses by the first equivalence and , and satisfies \(\mathcal E_L\) by . Conversely, suppose \(N\) models the displayed clause union. It satisfies the equality axioms, so form \(Q_N\). Given an assignment of the variables of a clause \(C\) to quotient elements, choose a representative for each of its finitely many occurring variables, and extend these choices to all natural-number variables using one fixed element of \(N\). The projected assignment agrees on every variable of \(C\). The second truth equivalence and assignment agreement show that \(C\) holds at the given quotient assignment. Hence \(Q_N\) is a nonempty clause model of all of \(\Delta\).

The reduction can be supplied to an equality-free clause method

Let \(T\) be an \(L\)-theory and let \(\Gamma\) be a set of equality-free relation clauses over natural-number variables in \(L^E\). Suppose that, in each nonempty \(L^E\)-structure \(N\), the universally asserted native clause formulas of \(\Gamma\) are true exactly when \(N\models T^E\). Then

\[T\text{ has a nonempty model}\quad\Longleftrightarrow\quad\Gamma\cup\mathcal E_L\text{ has a nonempty clause model}.\]

The representation hypothesis is about the same expanded structure: all clauses in \(\Gamma\) hold under all assignments if and only if all translated theory sentences hold there. It does not allow a separate model for each clause or each sentence.

A structure satisfies every clause in the union if and only if it satisfies all clauses in \(\Gamma\) and all clauses in \(\mathcal E_L\). The hypothesis identifies the first condition with \(T^E\), and identifies the second with \(\operatorname{EqAx}(L)\). Thus a nonempty model of that clause union is precisely a nonempty model of \(T^E\cup\operatorname{EqAx}(L)\). Apply to obtain the equivalence.

This gives an exact interface to any equality-free clause method when its representation hypothesis has been established. If clausification adds further symbols, its separate satisfiability-preservation theorem must retain the equality-axiom clauses along with the translated theory. No clausification procedure or inference strategy is asserted here.

Constants, sentences and a one-point quotient

Suppose \(L\) has two constants \(c,d\) and a zero-ary relation \(P\). Describe an equality-axiom model of \(E(c,d)\land P()\) and its quotient. Is a one-element model always possible for the equality axioms alone?

Show answerHide answer

Take the one-element domain \(\{*\}\), interpret both constants as \(*\), set \(E(*,*)\) true, and set \(P()\) true. All equivalence axioms hold. Each function tuple has the same unique output, so function congruence holds; every relation is evaluated on identical tuples, so relation congruence holds. In particular, the constant clauses are true and the zero-ary relation clause is \(\neg P()\lor P()\). The quotient has one class, the two constants name it, and \(P()\) remains true.

More generally, every language has a one-element model of \(\operatorname{EqAx}(L)\): interpret all functions by the unique possible output, choose any truth value for each old relation, and make \(E\) the unique true binary relation on that domain. This is the identity expansion of that one-element ordinary structure. Additional translated theory axioms can of course exclude it; for example, \(\exists x\exists y\,\neg E(x,y)\) does.

An equivalence relation alone does not suffice

On the two-element domain \(\{0,1\}\), interpret \(E\) as the total relation and a unary predicate \(P\) by \(P(0)\) true and \(P(1)\) false. Does the quotient give an interpretation of \(P\)? Which axiom clause detects the problem?

Show answerHide answer

Total \(E\) is an equivalence relation, and any functions would respect it, since every pair of outputs is related. The quotient has one class, \([0]=[1]\). But the proposed rule for the unary relation would make \(P([0])\) true using representative \(0\) and false using representative \(1\). Thus the representative rule fails to define a relation.

The relation-congruence clause is \(\neg E(x_0,x_1)\lor\neg P(x_0)\lor P(x_1)\). Under \(x_0=0,x_1=1\), all three literals are false. This failure explains the need for the fifth scheme: compatibility of functions cannot supply compatibility of predicates.
