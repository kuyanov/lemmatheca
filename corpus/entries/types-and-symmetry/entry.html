The symmetries that leave the parameters in place

Let \(L\) be a countable first-order language and \(M\) a nonempty \(L\)-structure. For \(A\subseteq M\), let \(\operatorname{Aut}(M/A)\) denote the automorphisms fixing every element of \(A\). Fixing is pointwise: \(g(a)=a\) for every \(a\in A\).

The orbit of a finite tuple \(\bar b\) over \(A\) is

\[O_A(\bar b)=\{g(\bar b):g\in\operatorname{Aut}(M/A)\},\qquad g(\bar b)=(g(b_0),\ldots,g(b_{n-1})).\]

For a single element write \(O_A(b)\). The identity puts each tuple in its own orbit; inverse and composition show that being in the same orbit is an equivalence relation. Repeated coordinates are allowed. The empty tuple has a singleton orbit.

A parameter-fixing symmetry preserves the complete description

If \(g\in\operatorname{Aut}(M/A)\), then \(\operatorname{tp}^M(g(\bar b)/A)=\operatorname{tp}^M(\bar b/A)\). In particular every set definable over \(A\) is a union of these orbits.

Expand \(M\) by names for \(A\). Since \(g\) fixes their interpretations, it is an automorphism of this named structure. Formula preservation gives the same truth value for every \(L(A)\)-formula at \(\bar b\) and \(g(\bar b)\). Complete type membership is precisely this truth assertion. Applying the same preservation to a defining formula shows that membership in its solution set is constant on every orbit.

In a countable saturated model, a complete type is an orbit

Suppose \(M\) is countable and omega-saturated and \(A\subseteq M\) is finite. Two finite tuples of the same length have equal complete types over \(A\) if and only if an automorphism fixing \(A\) sends the first tuple to the second.

The reverse implication is type preservation. For the forward implication, apply the specified-tuple homogeneity theorem. Equality of the \(L(A)\)-types makes the map from the distinct coordinates of the first tuple to those of the second elementary. Equality formulas make it well-defined even when coordinates repeat.

Naming the finite set \(A\) retains omega-saturation. The back-and-forth construction in the countable named structure extends that finite elementary map to an automorphism of \(M_A\), with the indicated coordinate values. Its old-language reduct fixes every named parameter and sends exactly the given tuple to the other. The same argument includes the empty tuple.

Saturation detects a finite obstruction to avoiding a finite set

Assume \(M\) is omega-saturated, \(A\subseteq M\) is finite, and \(p(x)\) is a complete type over \(\operatorname{Th}(M_A)\). Let \(S\subseteq M\) be finite. If every finite subset of \(p\) has a realization in \(M\setminus S\), then \(p\) has a realization in \(M\setminus S\).

Put \(B=A\cup S\), a finite parameter set. View the formulas of \(p\) as \(L(B)\)-formulas through the inclusion of parameter names, and adjoin the finitely many inequalities \(x\ne c_s\), \(s\in S\). Each finite subset of this new collection contains a finite set of original conditions. By assumption those have a witness outside all of \(S\), which also satisfies every requested inequality. The collection is therefore finitely realized in the named structure \(M_B\).

The partial-type test for omega-saturation, with the finite parameter set \(B\), realizes the whole collection in \(M\). Its original conditions realize \(p\), and its inequalities put the realizing element outside \(S\). Parameter inclusion changes the labels available in a formula, not the interpretation of the original names from \(A\).

A finite orbit has one defining formula over the original parameters

If \(M\) is countable and omega-saturated, \(A\subseteq M\) is finite, and \(O_A(b)\) is finite, then \(O_A(b)\) is definable over \(A\).

Put \(p=\operatorname{tp}^M(b/A)\) and \(S=O_A(b)\). By the orbit theorem, the realizations of \(p\) in \(M\) are exactly \(S\). Hence no realization of \(p\) lies outside \(S\).

The contrapositive of finite exclusion gives a finite subset \(\Delta\subseteq p\) with no realization outside \(S\). Let \(\delta(x)\) be its conjunction, with the empty conjunction interpreted as \(\top\). Every realization of \(p\) satisfies \(\delta\), so \(S\) is contained in its solution set. Conversely, a solution of \(\delta\) outside \(S\) would realize \(\Delta\) there, which is impossible. Thus \(\delta\) defines exactly \(S\).

Although the exclusion argument temporarily names the elements of \(S\), the extracted conjunction \(\delta\) uses only formulas of \(p\), hence only the original parameters \(A\). This removal of the extra names supplies the required definition over \(A\).

Unique definition means that every parameter-fixing symmetry fixes the point

In a countable omega-saturated structure, for finite \(A\subseteq M\),

\[b\in\operatorname{dcl}_M(A)\quad\Longleftrightarrow\quad O_A(b)=\{b\}.\]

If \(b\) is uniquely definable over \(A\), its singleton is preserved by every automorphism fixing \(A\), by the earlier invariance lemma. Thus every orbit point equals \(b\), and the identity supplies \(b\) itself.

Conversely, a singleton orbit is finite, so the preceding lemma defines it over \(A\). This is exactly membership in definable closure.

A finite list of definable possibilities means finitely many conjugates

In a countable omega-saturated structure, for finite \(A\subseteq M\),

\[b\in\operatorname{acl}_M(A)\quad\Longleftrightarrow\quad O_A(b)\text{ is finite}.\]

If \(b\) lies in a finite set defined over \(A\), invariance puts its whole orbit inside that finite set. Hence the orbit is finite.

Conversely, a finite orbit is itself a finite set definable over \(A\), and it contains \(b\). It witnesses membership in algebraic closure. This characterizes the number of actual conjugates inside the specified model; no larger ambient model is needed.

A countably categorical model has finitely many definable tuple orbits

Let \(T\) be a complete satisfiable theory in a countable language, countably categorical and with an infinite model. If \(M\models T\) is countable, then for each finite \(n\) there are finitely many automorphism orbits on \(M^n\), and every such orbit is definable without parameters.

The countable categoricity criterion identifies the tuple orbits with the finitely many complete \(n\)-types. Each type is isolated by one formula. A tuple satisfies that isolator exactly when it has the corresponding type, so the formula defines its orbit. These are the supplied-tuple orbit calculation and its isolator conclusion.

This proof uses the earlier categoricity results directly. It does not require a later existence construction for countable saturated models. At \(n=0\), the single empty tuple is the unique orbit and is defined by \(\top\).

In a countably categorical model, symmetry detects every parameter-free definition

Under the hypotheses of the preceding lemma, a subset \(D\subseteq M^n\) is definable without parameters if and only if it is invariant under every automorphism of \(M\).

A parameter-free defining formula is preserved by every automorphism, so the forward implication holds in any structure.

Conversely, invariance makes \(D\) a union of whole tuple orbits: if one tuple belongs, every automorphic image belongs, and applying inverse automorphisms gives the reverse membership implication. There are only finitely many orbits, each defined by an isolating formula. Disjoin the formulas of the orbits contained in \(D\). This is a finite first-order formula and defines exactly \(D\). If \(D\) is empty, use \(\bot\); the same reasoning includes the empty tuple context.

Can arbitrary unions of orbits always be defined?

Every invariant set is a union of automorphism orbits. Why does that observation alone fail to prove definability in an arbitrary countable structure?

Show answerHide answer

There may be infinitely many orbits, and first-order formulas do not permit arbitrary infinite disjunctions. Invariance can therefore leave many more sets than the formulas describe.

The rigid structure \((\mathbb N,0,S)\) has only the identity automorphism. Each singleton is an orbit, so every subset is invariant. Its language has only countably many formulas, whereas \(\mathcal P(\mathbb N)\) is uncountable. Hence some invariant subsets are not parameter-free definable. The categorical theorem supplies the missing finite bound on the number of tuple orbits; it does not follow from invariance alone.
