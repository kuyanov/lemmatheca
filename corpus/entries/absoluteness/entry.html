Compare the same parameters under actual membership

Let \(M\subseteq N\) be nonempty transitive sets, equipped with actual membership. We use the set-domain satisfaction convention; for definable proper classes the same notation has the formula-by-formula meaning. Transitivity means that \(x\in y\in M\) implies \(x\in M\), and similarly for \(N\).

A membership-language formula \(\varphi(\bar a)\) is absolute between \(M\) and \(N\), at parameters \(\bar a\) from \(M\), if

\[M\models\varphi[\bar a]\quad\Longleftrightarrow\quad N\models\varphi[\bar a].\]

It is upward absolute if the forward implication holds and downward absolute if the reverse implication holds. These terms refer to every allowed tuple when no particular tuple is specified. Agreement always concerns the same actual objects as parameters. We will not assume that arbitrary membership structures, with an unrelated interpreted relation, have these properties.

Bounded quantifiers search the members of one set

A bounded quantifier has one of the forms

\[(\exists x\in y)\,\psi\;:=\;\exists x\,(x\in y\land\psi),\qquad (\forall x\in y)\,\psi\;:=\;\forall x\,(x\in y\to\psi).\]

Here \(y\) is a variable already available outside this quantifier; rename bound variables to avoid capture. The bounded formulas, or \(\Delta_0\) formulas, are built from equality and membership atoms by Boolean connectives and these bounded quantifiers. Falsity and truth may be included as logical abbreviations. There are no additional function symbols: a notation such as \(\mathcal P(y)\) must first be expanded into a defining formula.

For example, \((\forall u\in x)(u\in y)\) is bounded. The formula \(\forall z\,(z\subseteq y\to z\in p)\) has an unbounded quantifier over \(z\), even though expanding its subset test introduces only bounded quantifiers. Merely writing a finite formula, or giving it finitely many variable slots, does not make its quantifiers bounded in this set-theoretic sense.

Bounded syntax expands into ordinary first-order syntax

The guard expansion \(G(\varphi)\) of a bounded formula leaves its atoms unchanged, commutes with Boolean connectives, and expands every bounded quantifier by the displayed membership guard. In any membership structure \((D,E)\), under any assignment of the available variables in \(D\), the ordinary formula \(G(\varphi)\) has exactly the truth value obtained by evaluating the bounded grammar: a quantifier bounded by \(y\) tests precisely the \(b\in D\) with \(E(b,y)\).

Induct on that grammar. The atom and Boolean cases are unchanged. For a bounded existential, the expansion \(\exists x(x\in y\land G(\psi))\) asks for exactly a domain element satisfying \(E(x,y)\), then evaluates the child formula with that value assigned to \(x\). For a bounded universal, the implication guard requires the child exactly at those domain elements. The child induction hypothesis applies to each extended assignment. Renaming bound variables preserves the earlier assignment and prevents capture of the bounding variable or parameters.

Hence bounded formulas use the same ordinary satisfaction relation as other membership formulas. Their special feature is the restricted form of their quantifiers, not a second truth relation.

Transitivity makes every bounded formula absolute

If \(M\) is a nonempty transitive set and \(\bar a\) is a tuple of its members, then for every \(\Delta_0\) formula \(\varphi\),

\[M\models\varphi[\bar a]\quad\Longleftrightarrow\quad\varphi(\bar a)\text{ holds in the ambient universe}.\]

Consequently every bounded formula is absolute between nonempty transitive sets \(M\subseteq N\). The same assertions hold schematically for nonempty definable transitive classes.

Induct on the bounded construction of \(\varphi\), retaining the assertion for every assignment of its available variables in \(M\). An equality or membership atom compares the same actual sets and relation on both sides. Boolean connectives preserve equivalence, so their steps follow from the induction hypotheses.

Consider \((\exists x\in y)\,\psi\), where the assigned value of \(y\) lies in \(M\). A witness inside the structure is an actual \(b\in y\) that also belongs to \(M\). The induction hypothesis makes \(\psi\) true at that same witness in the ambient universe. Conversely, any ambient witness \(b\in y\) is in \(M\) by transitivity. Extend the assignment by this \(b\), apply the induction hypothesis to \(\psi\), and obtain a witness in the structure. This proves both directions for the bounded existential.

For \((\forall x\in y)\,\psi\), the possible values of \(x\) are again exactly all actual members of \(y\) on both sides. The induction hypothesis therefore gives the same answer for every value. Equivalently, use the bounded existential case and negation. The induction proves the first assertion. Apply it to both \(M\) and \(N\) to compare their answers through the common ambient answer.

For a definable transitive class, repeat this proof for each fixed formula using its quantifier relativization. No set collecting the whole class or uniform truth predicate is used.

No axiom-system assumption on \((M,\in)\) is needed. The two essential conditions are actual membership and transitivity, with every displayed parameter already in the domain.

Empty sets, inclusion, and pairs have bounded tests

The following formulas are bounded and test the stated actual set constructions:

\[\begin{aligned}x=\varnothing&\quad\Longleftrightarrow\quad(\forall u\in x)\,u\ne u,\\x\subseteq y&\quad\Longleftrightarrow\quad(\forall u\in x)\,u\in y,\\x=\{y,z\}&\quad\Longleftrightarrow\quad y\in x\land z\in x\land(\forall u\in x)(u=y\lor u=z).\end{aligned}\]

The first test says that \(x\) has no member: any member would have to differ from itself. The second is exactly the definition of inclusion. In the third, the first two conjuncts put both prescribed elements in \(x\), and the bounded universal excludes all other elements. Extensionality identifies the set as \(\{y,z\}\). The argument allows \(y=z\).

Each displayed quantifier is bounded, so applies whenever all its parameters lie in the transitive domain. In particular, setting \(y=z\) gives the singleton test. These are tests of a supplied candidate \(x\), not assertions that the domain contains a candidate for every pair.

Transitivity and ordinalhood can also be tested boundedly

Write

\[\operatorname{Tr}(x)\;:=\;(\forall u\in x)(\forall v\in u)\,v\in x.\]

This bounded formula holds exactly when \(x\) is transitive. In the ambient ZF mathematics, the following bounded test holds exactly when \(x\) is a von Neumann ordinal:

\[\operatorname{OrdTest}(x)\;:=\;\operatorname{Tr}(x)\land(\forall u\in x)\operatorname{Tr}(u)\land(\forall u\in x)(\forall v\in x)(u\in v\lor u=v\lor v\in u).\]

The transitivity test just expands the definition. Every ordinal is transitive, its members are transitive ordinals, and any two members are comparable by membership. Thus an ordinal passes the displayed test.

Conversely suppose the test holds. Membership on \(x\) is transitive because every \(w\in x\) is a transitive set: \(u\in v\in w\) implies \(u\in w\). It is irreflexive by Foundation and compares any two distinct members by the last conjunct. If \(B\subseteq x\) is nonempty, Foundation gives \(u\in B\) with no member in \(B\). For any \(v\in B\), the alternative \(v\in u\) is excluded, so comparison gives \(u=v\) or \(u\in v\). Thus \(u\) is a least point of \(B\). Membership well-orders \(x\), which is transitive, so \(x\) is an ordinal.

The empty set passes the test and is the ordinal zero. Bounded absoluteness preserves this test on transitive domains. If an alternative definition is only provably equivalent in a theory, transferring that equivalence to a domain additionally requires that it satisfy the theory, as below.

This bounded test defines the ordinal part of each transitive constructible level, which allows the next level to contain its index ordinal.

One unbounded block changes the available witnesses

A \(\Sigma_1\) presentation is a formula \(\exists x_1\cdots\exists x_k\,\psi\) with a bounded matrix \(\psi\). A \(\Pi_1\) presentation is \(\forall x_1\cdots\forall x_k\,\psi\) with a bounded matrix. The block is finite; an empty block is allowed, so bounded formulas qualify for both. These are the first levels of the Lévy hierarchy of membership formulas.

We use these specified presentations, or formulas logically equivalent to them, when applying the next result. Equivalence obtainable only from the axioms of a theory needs the extra model hypotheses of . Negating a \(\Sigma_1\) presentation yields a \(\Pi_1\) presentation, and conversely, because the negation of a bounded formula is bounded.

Existential witnesses move upward and universal tests move downward

For nonempty transitive domains \(M\subseteq N\) and parameters \(\bar a\) from \(M\),

\[M\models\sigma[\bar a]\ \Longrightarrow\ N\models\sigma[\bar a]\qquad(\sigma\text{ a }\Sigma_1\text{ presentation}),\]
\[N\models\pi[\bar a]\ \Longrightarrow\ M\models\pi[\bar a]\qquad(\pi\text{ a }\Pi_1\text{ presentation}).\]

The statements include definable class domains under the same schematic convention.

Write \(\sigma=\exists\bar x\,\psi\) with bounded \(\psi\). A witnessing finite tuple \(\bar b\) in \(M\) also lies in \(N\). Bounded absoluteness, applied with both \(\bar a\) and \(\bar b\), transfers the truth of \(\psi\) to \(N\). The same tuple witnesses \(\sigma\) there. This argument also covers an empty block.

If the universal presentation \(\pi\) were false in \(M\), its negation would have an existential presentation true in \(M\). The first part would make that negation true in \(N\), contradicting the hypothesis. This proves the universal assertion by contraposition. Alternatively, every tuple tested in \(M\) is among the tuples tested in \(N\), and their bounded matrices agree.

The reverse directions already fail in small finite domains

Take \(M=V_1=\{\varnothing\}\) and \(N=V_2=\{\varnothing,\{\varnothing\}\}\). Both are nonempty transitive sets and \(M\subseteq N\). The \(\Sigma_1\) sentence \(\exists x\exists y\,(x\in y)\) is true in \(N\) and false in \(M\). Its \(\Pi_1\) negation \(\forall x\forall y\,(x\notin y)\) is true in \(M\) and false in \(N\).

The witnesses \(x=\varnothing\), \(y=\{\varnothing\}\) belong to \(N\) and satisfy membership. In \(M\), both variables must equal \(\varnothing\), and \(\varnothing\notin\varnothing\). The statements about the universal sentence are the negations of these two answers. Transitivity follows immediately by inspecting the displayed members.

Thus downward \(\Sigma_1\) absoluteness and upward \(\Pi_1\) absoluteness need not hold. Neither the positive theorem nor this counterexample assumes that these domains are models of ZF.

Reflection selects particular larger stages where a prescribed finite family, including unbounded formulas, does agree.

A theory can supply two equivalent descriptions

For a membership-language theory \(T\), a formula \(\theta(\bar x)\) is \(\Delta_1\) in \(T\) if there are a \(\Sigma_1\) presentation \(\sigma\) and a \(\Pi_1\) presentation \(\pi\), with the same free parameters, such that \(T\) proves the universal closures of

\[\theta(\bar x)\leftrightarrow\sigma(\bar x),\qquad\theta(\bar x)\leftrightarrow\pi(\bar x).\]

This definition records proofs from \(T\), not just an accidental agreement of the formulas in the ambient universe. A transitive domain need not satisfy \(T\); to use those equivalences inside it, we require that additional hypothesis.

Two descriptions give agreement in both directions

Suppose \(M\subseteq N\) are nonempty transitive models of \(T\), and \(\theta\) is \(\Delta_1\) in \(T\). Then \(\theta\) is absolute between \(M\) and \(N\) at every parameter tuple from \(M\).

By soundness, both models satisfy the two proved equivalences. If \(M\models\theta[\bar a]\), use its existential description to get \(M\models\sigma[\bar a]\). Upward absoluteness gives \(N\models\sigma[\bar a]\), and the equivalence in \(N\) gives \(N\models\theta[\bar a]\).

Conversely, from \(N\models\theta[\bar a]\) use its universal description \(\pi\). Downward absoluteness gives \(M\models\pi[\bar a]\), and the equivalence in \(M\) recovers \(M\models\theta[\bar a]\). Each direction uses one description and the relevant model's equivalence.

Bounded formulas themselves supply both presentations without additional theory. For more elaborate definitions, the assumptions that the domains satisfy the theory must be retained; bounded absoluteness alone does not supply them.

Does an absolute pair test supply a missing pair?

Let \(M=2=\{0,1\}\), using von Neumann finite ordinals. It is transitive and contains both \(0\) and \(1\). Does absoluteness of the bounded pair test imply \(M\models\exists x\,(x=\{0,1\})\)?

Show answerHide answer

No. The actual pair \(\{0,1\}=2\) is not a member of \(M\); its only candidates are \(0\) and \(1\), neither equal to that pair. The bounded test therefore rejects both candidates in \(M\), as it does externally. The existential assertion has an unbounded quantifier asking for an object of the domain. It is false in \(M\), although it is true in the ambient universe, where \(2\) supplies the witness. Pairing is an extra closure property, not a consequence of transitivity.

Why can a transitive domain miss subsets?

Let \(M=4=\{0,1,2,3\}\), with actual membership, and take parameters \(a=2\), \(p=3\) in \(M\). Evaluate the formula

\[\operatorname{Pow}(p,a)\;:=\;\forall z\,\bigl(z\in p\leftrightarrow(\forall u\in z)\,u\in a\bigr).\]

Does this formula have the same answer in \(M\) and outside it? Is it a bounded formula?

Show answerHide answer

The domain \(M\) is transitive. Among its four possible values of \(z\), exactly \(0,1,2\) are subsets of \(a=2\): the first three pass by inspecting their members, and \(3\) fails because \(2\in3\) but \(2\notin2\). These same three objects are precisely the members of \(p=3\). Hence \(M\models\operatorname{Pow}(3,2)\).

Externally, \(z=\{1\}\) is a subset of \(2=\{0,1\}\) but is not an element of \(3=\{0,1,2\}\). Thus \(\operatorname{Pow}(3,2)\) is false outside \(M\). For two set domains, compare \(M\) with \(V_4\): this transitive stage contains all four finite ordinals below \(4\) and also \(\{1\}\), so the same witness makes the formula false there.

The outer quantifier \(\forall z\) is unbounded. Transitivity supplies the members of each set present; it does not supply every subset of that set as a new object. The bounded subset test for a given \(z\) is absolute, while the universal search over all candidate subsets can change. This example makes no assertion that either finite domain satisfies the axioms of ZF.
