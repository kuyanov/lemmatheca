Give symbols numerical names before coding expressions

A proof is a finite object, so it can be recorded by a natural number. The useful claim is stronger than countability: a calculation should recover its formulas, check every inference and reject an incorrect proof. We shall code the existing scoped syntax and the existing sentence natural-deduction calculus, rather than introduce a different proof system.

An effective signature supplies numerical names for its function and relation symbols, with primitive-recursive tests \(F(a,k)\) and \(R(a,k)\) for “\(a\) names a symbol of arity \(k\).” The names are unique. We also require primitive-recursive symbol constructors and destructors when we use them. Finite signatures satisfy these conditions by finite case distinctions. The arithmetic language has function names \(0,1,2,3\) for zero, successor, addition and multiplication, of arities \(0,1,2,2\), and no relation symbols. Equality is logical syntax. The equality-only language has no symbols; the order language has one binary relation. These are our concrete examples.

For proofs, add auxiliary constants \(c_0,c_1,\ldots\). Give each auxiliary constant its own tagged leaf. It has arity zero, so this is an effective extension of the signature. A free name \(x_i\), a scoped placeholder \(z_j\), and a constant \(c_i\) remain three different objects. Only the last may serve as an eigenparameter.

A tag records how an expression was built

Use the square pairing \(\langle a,b\rangle\) and the finite-list code already constructed. Write \([a_0,\ldots,a_{r-1}]^\#\) for that list code and set

\[N(t;a_0,\ldots,a_{r-1})=1+\langle t,[a_0,\ldots,a_{r-1}]^\#\rangle.\]

The outer tag and the exact list length must both match. Define expression codes by the following table; brackets \(\ulcorner E\urcorner\) mean the code of the displayed expression.

Expand negation, conjunction, disjunction, existential quantification and biconditional using their fixed abbreviations before encoding. No simplification is performed. For example, the codes of \(0+0\) and \(0\) differ even though arithmetic proves them equal. The number \(\ulcorner A\urcorner\) is an external name for a formula; its arithmetic numeral \(\overline{\ulcorner A\urcorner}\) is a term. A numerical code does not acquire the meaning of the formula merely by being written inside arithmetic.

Every child has a smaller code

Every entry in a nonempty coded list is smaller than the list code. Hence each expression child of \(N(t;\bar a)\) has code strictly less than its parent. The tag, argument list, its length and each argument are primitive-recursive functions of the parent code; use harmless default values at zero.

Proof

A nonempty list is \(1+\langle a,q\rangle\), so its head and tail are smaller than it by the proved pairing bounds. Iterating the tail proves the claim for every entry. The outer successor and pairing give the corresponding parent bound. Predecessor, the two unpairing functions, length and indexed access are primitive recursive by the earlier coding results. Their compositions give every decoder just listed. □

Recognizing a term or formula is primitive recursive

Let \(\operatorname{Term}(n,e)\) mean that \(e\) codes a term allowed at context size \(n\), and let \(\operatorname{Form}(n,e)\) mean that it codes a formula at that size. A free-name leaf \(N(0;i)\) and an auxiliary-constant leaf \(N(8;j)\) are always allowed. A placeholder leaf is allowed exactly when its index is less than \(n\). A function or relation application must have the specified arity and correctly formed term arguments. Equality requires two terms. Implication requires two formulas at size \(n\). A universal node requires one formula at size \(n+1\). The falsity node has no arguments. Reject every other tag, wrong-length argument list and the number zero.

These tests are primitive recursive, uniformly in \(n,e\). So are the following restricted tests. A closed term has no free-name leaf and no placeholder, but may contain auxiliary constants. An extended sentence is a formula at context size zero with no original free-name leaf; it may contain auxiliary constants and is used inside derivations. An original-language sentence is an extended sentence with no auxiliary-constant leaf. Write \(\operatorname{Sent}(e)\) for this last test. More generally, \(\operatorname{NamedForm}(n,e)\) tests formulas at size \(n\) with no original free names.

Proof

Compute a table for all codes up to \(e\), taking the appropriate finite case at each code. Children always have smaller codes. The only changing parameter is context size: along a path in a code at most \(e\) universal nodes can be crossed, so it is enough to compute the table at sizes \(0,\ldots,n+e\). To avoid referring to a later context-size entry, fill this finite table in increasing code order, for all these sizes, with the universal clause at the top boundary set arbitrarily; no value reachable from the requested \((n,e)\) uses that boundary. All loops have primitive-recursive bounds, and their updates use only decoding, symbol tests and earlier table entries. Recursion on finite histories makes this a primitive-recursive computation. Tracking the presence of original free names and auxiliary constants gives the restricted predicates. □

Decoding recovers the original syntax

For every scoped term or formula, encoding and then decoding at its context size returns that same expression. Conversely, every code accepted by the corresponding recognition test decodes to exactly one expression with that code. In particular, coding is injective.

Proof

For the first direction use structural induction. Unpairing recovers the tag and list exactly; list decoding recovers the symbol name and ordered children. The induction hypotheses recover each child, including the body at size \(n+1\) under a quantifier. For the converse use strong induction on the accepted code. Its successful case selects a unique constructor. The symbol name and arity fix its argument type, and each accepted child has a smaller code, so the induction hypotheses reconstruct its children uniquely. The two constructions are inverse. If two expressions have one code, decoding that code recovers both, so they are equal. □

This is a coding of the earlier syntax itself. Scoped indices retain their meaning, and formulas that happen to be logically equivalent need not have equal codes.

Substitution and numerals can be computed on codes

There are primitive-recursive functions \(\operatorname{num}(m)\) and \(\operatorname{sub}(n,e,i,t)\) such that

\[\operatorname{num}(m)=\ulcorner\overline m\urcorner,\qquad \operatorname{sub}(n,\ulcorner A\urcorner,i,\ulcorner t\urcorner)=\ulcorner A[t/x_i]\urcorner.\]

In the substitution assertion, \(A\) is a scoped formula at context size \(n\) and \(t\) has no placeholders. Invalid inputs return zero. The operation leaves all placeholders alone and inserts each replacement unchanged. It is the existing free-name substitution.

Proof

Start \(\operatorname{num}(0)\) with the zero-term code, and attach one successor node at each recursion step. For substitution, process the finite syntax tree from children to parent. At the free-name leaf \(x_i\) return \(t\); at other free names, auxiliary constants and every placeholder return the original leaf. At an application or logical constructor rebuild the node from its computed children. The number of nodes visited is bounded by the original code. Although the output code can be much larger than the input, a bounded traversal with a coded table of earlier outputs is still primitive recursive: the loop count is bounded, not the values it produces. Induction on the expression proves that this calculation is exactly substitution. □

Opening a bound slot and replacing constants are also effective

The code of the instance \(A(t)\) is primitive recursive in the codes of the one-slot body \(A\) and closed term \(t\), allowing auxiliary constants but no original free names in either. So is uniform replacement of one auxiliary constant by a closed term. Both operations return zero on invalid inputs.

Proof

For opening the outer slot, replace a placeholder leaf \(z_0\) by \(t\), and replace every \(z_{j+1}\) by \(z_j\). Rebuild all constructors, including those below further quantifiers; these quantifiers now bind the shifted indices. An auxiliary constant remains unchanged. The inserted term has no placeholders, so it cannot be captured. Constant replacement instead changes exactly the matching auxiliary-constant leaf and leaves every variable index alone. Both are bounded tree traversals of the same kind as free-name substitution. Structural induction proves agreement with the stated operations. □

Freshness is a finite test

The tests “\(c_j\) occurs in \(A\)” and “\(c_j\) occurs in some member of the finite context \(\Gamma\)” are primitive recursive on codes. So is a function choosing an auxiliary constant absent from a given finite list of expressions.

Proof

During the syntax traversal, record whether a leaf has the auxiliary-constant tag and index \(j\). Take the disjunction over children and over the coded finite context. For a fresh index, record the largest auxiliary index in the list and add one; take zero when no auxiliary constant occurs. Maximum is computed by a bounded list fold. The result exceeds every index in the list, and all these operations are primitive recursive. □

Checking that a constant is absent only from the conclusion is insufficient. The rules also inspect the one-slot body and all assumptions left open, exactly as in the freshness conditions.

A proof record includes the information needed to check its rule

Record a finite derivation tree by nodes containing a rule tag, a finite context of undischarged assumptions, the concluding extended sentence, the child proof records and the rule's extra data. Extra data include the closed witness term for a quantifier instance, the one-slot body for equality substitution, the fresh constant for an eigenparameter rule and the assumption being discharged. Store the code of each piece in a tagged finite list. Each child proof is a smaller code, by the same successor-pair construction as for syntax.

Contexts are finite lists interpreted as sets; repetitions and order have no effect on derivability. A node may allow a larger context than the union of the actual remaining open assumptions. This is precisely weakening. It is checked by bounded membership tests between the displayed finite lists. Discharging \(A\) checks a child under \(\Gamma\cup\{A\}\). It permits zero or more uses of \(A\), as the original rule does. A use that is to remain open is included separately in the parent context.

Use primitive propositional rules, the four quantifier rules and the two equality rules. Any derived proof operation is first expanded into its finite proof-tree construction. We shall not accept a rule tag meaning merely “a valid consequence.”

Every primitive inference has a primitive-recursive check

Whether a node is a correct application of its displayed rule is primitive recursive. It checks extended-sentence and closed-term validity, the exact conclusions of its children, the context conditions and the following rule-specific data.

  • An assumption must belong to its finite context. Implication introduction checks a child concluding \(B\) under \(\Gamma\cup\{A\}\) and concludes \(A\to B\). Implication elimination checks \(A\to B\) and \(A\). The other classical propositional rules use their stated finite patterns and discharged assumptions.
  • Universal elimination checks \(\forall z_0 A\) and concludes \(A(t)\) for its displayed closed term. Existential introduction checks \(A(t)\) and concludes \(\exists z_0 A\).
  • Universal introduction checks \(A(c_j)\), concluding \(\forall z_0 A\), and checks that \(c_j\) is absent from \(A\) and the parent context. Existential elimination checks \(\exists z_0 A\) and a proof of \(B\) under the parent context together with \(A(c_j)\); it checks absence of \(c_j\) from \(A\), \(B\) and the parent context.
  • Equality introduction concludes \(t=t\) for a closed term. Equality elimination checks \(s=t\) and \(A(s)\), and concludes \(A(t)\), using its displayed one-slot body.

Proof

There are only finitely many rule tags. Each case uses equality of numbers, finite context membership, syntax recognition, an already constructed substitution or freshness test, and fixed formula constructors. These are all primitive recursive and are closed under finite Boolean combinations. Rule data are supplied in the record, so we never search without a bound for a witness term or a possible formula body. This last point matters: the conclusion need not contain the term used to derive it. □

Checking a whole finite proof needs only bounded work

There is a primitive-recursive predicate \(\operatorname{Der}(d,\gamma,a)\) saying that \(d\) is a correctly formed derivation record with context code \(\gamma\) and conclusion code \(a\). Every child is checked, not just the last inference.

Proof

Traverse all proof subcodes in increasing code order. Accept a node only if its local rule test passes and all its child nodes have already been accepted with the required contexts and conclusions. Child codes are strictly smaller. Decode the record's finite context and reject malformed entries and entries that are not extended sentences. A finite table up to \(d\) records the result; its construction is primitive recursive by bounded history recursion. Its root entry, together with equality of the displayed context and conclusion, is the required predicate. Induction on the record proves that acceptance has exactly the stated meaning. □

An enumerable axiom can carry a finite certificate

Suppose a theory \(T\) is supplied by a primitive-recursive relation \(E(a,s)\) with

\[A\in T\quad\Longleftrightarrow\quad\exists s\;E(\ulcorner A\urcorner,s).\]

Here \(A\) ranges over sentences of the original language. The number \(s\) certifies that \(A\) is an axiom. This includes a primitive-recursive axiom test, by ignoring \(s\), and an enumeration, by using a finite successful computation record as certificate. It does not assume that membership in \(T\) is decidable. An unsuccessful wait for an axiom gives no evidence that it will never appear.

Certify the open assumptions as well as the inferences

A certified \(T\)-proof consists of a derivation record \(d\), its finite root context \(\Gamma=(A_0,\ldots,A_{r-1})\), and witnesses \((s_0,\ldots,s_{r-1})\) with \(E(\ulcorner A_i\urcorner,s_i)\) for every \(i<r\). Its conclusion must be a sentence in the original language, and every root assumption must also belong to that language. Auxiliary constants may occur in its internal extended sentences and closed terms, subject to the checked freshness conditions.

Let \(\operatorname{Prf}_E(p,a)\) mean that \(p\) is such a certified proof concluding with code \(a\). Reject malformed records, incorrect inferences, mismatched certificate-list lengths, auxiliary constants in the root context or conclusion, and unsuccessful axiom certificates.

Derivability is existence of a checkable certificate

For an effective signature and a theory supplied by a primitive-recursive axiom-certificate relation \(E\), the predicate \(\operatorname{Prf}_E\) is primitive recursive. For every original-language sentence \(A\),

\[T\vdash A\quad\Longleftrightarrow\quad\exists p\;\operatorname{Prf}_E(p,\ulcorner A\urcorner).\]

The derivability on the left is the corpus's existing first-order natural deduction.

Proof

The checker first applies \(\operatorname{Der}\), then performs bounded tests on the two finite lists at the root. Each axiom test is an application of the supplied primitive-recursive relation \(E\). Original-language membership is another finite syntax traversal. Hence the complete check is primitive recursive.

If a certificate passes, decode its derivation and induct on its nodes. Each accepted local tag is exactly its corresponding natural-deduction rule, with the checked closedness and freshness conditions; checked context inclusions justify weakening. Its root assumptions are axioms by their certificates. Thus the decoded finite proof establishes \(T\vdash A\).

Conversely, take a finite proof of \(A\) from \(T\), expanding its derived proof operations into primitive rules. Its finitely many auxiliary names can be renamed to distinct names from our countable supply, avoiding the finitely many names already in use. At each node list its actual remaining open assumptions and the finite additional contexts used by discharged subproofs. Encoding the formulas, closed witnesses, one-slot bodies and rule choices gives an accepted derivation record. The finite root context consists of axioms of \(T\). Choose one witness \(s_i\) for each of those finitely many axioms and attach their list. The resulting certified code passes \(\operatorname{Prf}_E\). □

This theorem concerns calculations on ordinary natural numbers. It has not yet produced a formula of \(Q\) expressing the checker, nor proved that arithmetic can establish its correctness for all codes.

Why must premises come from smaller proofs?

Suppose a proposed linear proof checker allows modus ponens to use the line currently being checked. What goes wrong even if every implication on an earlier line was proved correctly?

Show answerHide answer

First prove \(A\to A\), which is a logical theorem. On the next line put any sentence \(A\). The defective checker can use the earlier \(A\to A\) and the current \(A\) itself as its two premises. It therefore accepts \(A\), even when \(A=\bot\). A genuine proof is well-founded: premise lines have strictly earlier indices, or premise trees are strictly smaller child trees. The fact that each individual rule is sound does not make a circular purported proof sound.

Finite proof constructions can be carried out on codes

The following two constructions on accepted proof records are primitive recursive on their codes, whenever their displayed context conditions hold. Joining proofs of \(A\to B\) and \(A\) gives a proof of \(B\); adding implication introduction gives a proof of \(A\to B\) from a proof of \(B\) under the extra assumption \(A\). For these two operations the existing auxiliary names may be retained: neither operation introduces an eigenparameter or changes the internal freshness conditions of either child.

Proof

Each construction forms a fixed tagged list from its supplied data and copies or combines finite contexts. All these list operations are primitive recursive. The implication-elimination and implication-introduction checker clauses prove that the respective new root is accepted, while the earlier roots already certify its children. The established operations here attach an inference to unchanged child records; the result does not decide whether an arbitrary sentence has a proof. □
