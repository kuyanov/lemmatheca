Dense orders leave room between every two points

A nonempty linear order \(L\) is dense if whenever \(x<y\), some \(z\) satisfies \(x<z<y\). It has no endpoints if every point has both a smaller and a larger point. A subset \(D\subseteq L\) is order-dense if every interval \(x<y\) contains a member of \(D\) strictly between its endpoints. The order is separable if it has a countable order-dense subset.

We call \(L\) Dedekind complete if every nonempty subset bounded above has a least upper bound in \(L\). This differs from a complete lattice: a line without endpoints has no upper bound for its whole carrier. The word “separable” here concerns order density; no topology is needed.

The rationals are countable, dense, and have no endpoints, by rational enumeration and rational density. Here \(\mathbb R\) denotes the ordered set of Dedekind cuts from the number-system construction. It is complete and has the rationals as an order-dense subset, by cut completeness and density of rational cuts. We work in ZF; the constructions below require no Choice.

A finite matching can accommodate another point

Let \(f\) be an order isomorphism between finite subsets of linear orders \(A,B\), and suppose \(B\) is nonempty, dense, and without endpoints. For any \(a\in A\) outside the domain, \(f\) extends to an order isomorphism on a domain also containing \(a\).

Proof

Among the finitely many domain points below \(a\), take the greatest if one exists; among those above it, take the least if one exists. Their images specify where the new image must go. If both exist, use a point strictly between their images. If just one exists, use a point on the required side of it. If neither exists, the domain was empty and any point of \(B\) works. Density and absence of endpoints supply these points. No existing image occupies the chosen position, since the neighboring domain points were consecutive around \(a\). □

Every countable linear order embeds in the rationals

Every countable linear order, and in particular every countable ordinal with its ordinal order, admits an order embedding into \(\mathbb Q\).

Proof

The empty order has the empty embedding. Otherwise fix a list \(a_0,a_1,\ldots\) covering the carrier, with repetitions allowed, and fix a list of \(\mathbb Q\). Start with the empty finite map. At stage \(n\), do nothing if \(a_n\) is already in its domain; otherwise apply . Among suitable rational images, use the one with least index in the rational list. This gives a specified step rule, so natural-number recursion constructs the sequence without any choice axiom.

The union of the finite maps is defined on every point and is injective. Any two points occur together at a finite stage, where their order is preserved and reflected. The union is therefore an order embedding. □

A well-ordered subset of \(\mathbb Q\) can have any countable ordinal type, even though the whole rational order is not a well-order. The embedding need not have a dense image.

The rationals are the unique countable dense order without endpoints

Any two nonempty countable dense linear orders without endpoints are order-isomorphic. Consequently every such order is order-isomorphic to \(\mathbb Q\). This is Cantor's back-and-forth theorem.

Proof

Fix enumerations of \(A\) and \(B\), and start with the empty finite isomorphism. At even stages, include the first unused point of \(A\) in its domain using . At odd stages, apply that lemma to the inverse map to include the first unused point of \(B\) in its range. Each time use the suitable new point of least index in the other enumeration. Both orders are infinite, so a first unused point always exists at a finite stage.

Recursion produces compatible finite maps. Their union preserves and reflects order, and the alternating steps eventually cover every point of both enumerations. Thus it is an order isomorphism \(A\to B\). The least-index rule avoids any appeal to dependent choice. □

Completeness and a countable dense subset characterize the real order

Every nonempty Dedekind-complete dense linear order without endpoints that has a countable order-dense subset is order-isomorphic to \(\mathbb R\).

Proof

Let \(D\) be a countable order-dense subset of \(L\). With its inherited order it is nonempty, dense, and has no endpoints: to find a point below a given \(d\in D\), first take a smaller point in \(L\), then use order density between it and \(d\); the other conditions follow the same way. By , fix an isomorphism \(e:D\to\mathbb Q\).

Assign to each \(x\in L\) the rational lower set

\[ C_x=\{e(d):d\in D,\ d<x\}. \]

It is a Dedekind cut. There are members of \(D\) below and above \(x\), so it is nonempty and proper. It is downward closed, and order density between \(d<x\) gives another member strictly above \(e(d)\), so it has no greatest member. If \(x<y\), a \(d\in D\) between them witnesses \(C_x\subsetneq C_y\).

Conversely, for any rational cut \(C\), put \(S=e^{-1}[C]\). It is nonempty and bounded above by the inverse image of any rational outside \(C\). Let \(x=\sup_L S\). If \(d\in S\), the absence of a greatest member gives \(d'\in S\) with \(d<d'\le x\), hence \(d<x\). If \(d\notin S\), downward closure makes \(d\) an upper bound of \(S\), hence \(x\le d\). Thus \(C_x=C\). This proves that \(x\mapsto C_x\) is an order isomorphism onto the real cuts. □

Once \(e\) is fixed, this extension is unique: every \(x\) is the supremum of the points of \(D\) below it. Without fixing the dense-set identification, the order isomorphism need not be unique. This result concerns order alone; the ordered-field characterization additionally preserves arithmetic.

Why do countability and completeness play different roles?

Why does Cantor's theorem not identify \(\mathbb Q\) with \(\mathbb R\)? Does having a countable dense subset make an order countable?

Show answerHide answer

Both are dense without endpoints, but the real carrier is uncountable, so the countable-order theorem does not apply. A countable dense subset need only supply points between other points; it need not contain every point of the order. The rationals inside the reals demonstrate this distinction. Completeness also separates the two orders: the rationals have missing cuts, while the real order realizes each rational cut as a point.
