Increasing ordinal functions that preserve limits

A definable class function \(f:\mathrm{Ord}\to\mathrm{Ord}\) is normal if it is strictly increasing and, at every nonzero limit ordinal \(\lambda\),

\[ f(\lambda)=\sup_{\alpha<\lambda}f(\alpha). \]

A class function is a formula giving a unique ordinal value at each ordinal, with fixed set parameters; it is not a set containing all its input-output pairs. Replacement collects its values over any set of indices. We work in ZF without Choice, using transfinite induction and set-valued recursion and Cantor normal form.

For fixed \(\delta\), the functions \(\alpha\mapsto\delta+\alpha\), \(\alpha\mapsto\delta\cdot\alpha\) when \(\delta>0\), and \(\alpha\mapsto\delta^\alpha\) when \(\delta>1\) are normal, by the comparison and limit rules of ordinal arithmetic and ordinal powers. The successor function is increasing but not normal: its value at \(\omega\) is \(\omega+1\), whereas the supremum of its finite values is \(\omega\).

Normal functions stay above their indices and preserve nonempty suprema

For every normal \(f\), \(\alpha\le f(\alpha)\). For every nonempty set \(S\) of ordinals,

\[ f(\sup S)=\sup_{\alpha\in S}f(\alpha). \]

Proof

For the first assertion, use transfinite induction. Zero is immediate. Strict increase takes \(\alpha\le f(\alpha)\) to \(\alpha+1\le f(\alpha)+1\le f(\alpha+1)\). At a limit take suprema and use normality.

If \(S\) has a greatest member, monotonicity proves the second assertion. Otherwise \(\lambda=\sup S\) is a nonzero limit, and \(S\) is cofinal in it: every \(\beta<\lambda\) is below some member of \(S\). The values on \(S\) therefore have the same supremum as all the values below \(\lambda\). Normality gives the claim. □

The nonempty condition matters. For \(f(\alpha)=\omega^\alpha\), the empty supremum is zero, but \(f(0)=1\).

Fixed points of a normal function form a closed unbounded class

A fixed point satisfies \(f(\alpha)=\alpha\). The fixed points of a normal function are unbounded, meaning that there is one strictly above every ordinal. They are closed, meaning that the supremum of any nonempty set of fixed points is again a fixed point. These are properties of a class of ordinals, with no topological prerequisites.

Proof

Given \(\beta\), recursively put \(a_0=\beta\) and \(a_{n+1}=f(a_n)\), and let \(a=\sup_{n<\omega}a_n\). Set-valued recursion and Replacement produce the sequence and its supremum. The sequence is nondecreasing by . That lemma also gives

\[ f(a)=\sup_{n<\omega}f(a_n)=\sup_{n<\omega}a_{n+1}=a. \]

If \(c\ge\beta\) is fixed, induction gives \(a_n\le c\) for every \(n\), hence \(a\le c\). Thus \(a\) is the least fixed point at or above \(\beta\). Starting instead at \(\beta+1\) gives one strictly above \(\beta\).

For a nonempty set \(S\) of fixed points, the same supremum lemma gives \(f(\sup S)=\sup_{\alpha\in S}f(\alpha)=\sup S\), proving closure. □

Epsilon numbers are fixed points of powers of omega

An epsilon number is an ordinal \(\varepsilon\) with \(\omega^\varepsilon=\varepsilon\). The function \(\alpha\mapsto\omega^\alpha\) is normal, so supplies a closed unbounded class of epsilon numbers.

Let \(\varepsilon_0\) be the least one. More generally, define \(\varepsilon_{\alpha+1}\) to be the least epsilon number strictly above \(\varepsilon_\alpha\), and at a nonzero limit put \(\varepsilon_\lambda=\sup_{\alpha<\lambda}\varepsilon_\alpha\). Closedness makes the limit an epsilon number; strict increase makes it greater than all earlier values. The least-fixed-point construction specifies each successor value uniquely, so set-valued transfinite recursion defines this enumeration without Choice.

There is no epsilon number between consecutive values, and the limit value is the least upper bound of its predecessors. Thus this lists the epsilon numbers in their ordinal order. For any one epsilon number, its predecessors form a set; their order type locates it in the enumeration.

The first epsilon number is the limit of finite towers

Put \(t_0=1\) and \(t_{n+1}=\omega^{t_n}\). Then

\[ \varepsilon_0=\sup_{n<\omega}t_n=\sup\{1,\omega,\omega^\omega,\omega^{\omega^\omega},\ldots\}. \]

Proof

The sequence is strictly increasing: \(1<\omega\), and strict increase of powers propagates each inequality. The iteration theorem makes its supremum a fixed point. Every epsilon number is at least one, so induction places every \(t_n\) below it. Their supremum is therefore the least epsilon number. □

Every \(\alpha<\varepsilon_0\) is below some finite tower. No finite tower is itself an epsilon number.

Ordinals below epsilon zero have finite hereditary expressions

The ordinals below \(\varepsilon_0\) are exactly those expressible by finite terms built from zero using Cantor normal forms, with every exponent itself expressed in the same way. For example, \(\omega^{\omega^2+3}\cdot2+\omega+5\) is such a term. This is a hereditary Cantor normal form.

Proof

If \(\alpha<t_{n+1}=\omega^{t_n}\), every exponent in its normal form is below \(t_n\). Indeed, an exponent at least \(t_n\) would make the leading term at least \(\omega^{t_n}\). Induction on \(n\), with \(\alpha<t_0=1\) giving only zero, therefore expands all exponents in finitely many layers. Every \(\alpha<\varepsilon_0\) has such a tower bound.

Conversely, argue by induction on a finite expression. Its already evaluated exponents are below \(\varepsilon_0\). Choose one tower \(t_n\) strictly above all of them. By closure of smaller terms under finite sums, the resulting normal form is below \(\omega^{t_n}=t_{n+1}<\varepsilon_0\).

Finite expressions can be encoded by finite strings of natural numbers: use distinct symbols for punctuation, powers, and sums, and encode coefficients as natural numbers. A string is determined by its finite graph in \(\omega\times\omega\). The countability of pairs and of their finite subsets therefore give a natural-number code for every string. Evaluation maps the valid strings onto \(\varepsilon_0\). Taking the least code of each ordinal injects \(\varepsilon_0\) into \(\omega\). Thus \(\varepsilon_0\) is countably infinite without using a choice axiom. □

Writing a number in a base also used inside its exponents

For a natural-number base \(b\ge2\), write \(m\) uniquely as \(b^{e_0}c_0+\cdots+b^{e_{k-1}}c_{k-1}\), with decreasing exponents and \(0<c_i<b\), omitting zero coefficients. Repeated integer division by \(b\) gives the digits and proves uniqueness: the remainder is the last digit, and division strips it off. Now expand every exponent in base \(b\), and repeat inside its exponents. Every positive exponent used to represent \(m\) is smaller than \(m\), so natural-number induction gives a finite expression. Zero is the empty expression. This is the hereditary base-\(b\) representation.

For example, \(4=2^{2^1}\) in hereditary base two. Let \(B_b^c(m)\), for \(c>b\), be the natural number obtained by replacing every occurrence of the base \(b\) by \(c\), including those in exponents. Coefficients stay unchanged. Let \(o_b(m)\) be the ordinal obtained by replacing those base occurrences by \(\omega\). It is below \(\varepsilon_0\) by .

Base changes preserve the ordinal measure

For \(b\ge2\), \(c>b\), and natural numbers \(m,n\),

\[ m<n\ \Longrightarrow\ o_b(m)<o_b(n),\qquad o_c(B_b^c(m))=o_b(m). \]

Proof

Ordinary base representations compare at the highest exponent where their digits differ. A larger exponent outweighs all lower places, since their total is less than the next base power. Compare their lists of nonzero exponent–coefficient pairs, treating a missing suffix as smaller than a nonempty one. Induct simultaneously on \(\max(m,n)\) to show that this comparison is preserved when the base is replaced by \(c\) and when it is replaced by \(\omega\). All exponent comparisons concern smaller numbers, so the induction hypothesis applies to them. Coefficient comparisons are unchanged. For \(\omega\), normal-form comparison gives exactly this ordering. Zero and one have no positive exponent comparisons and start the induction.

In particular, base change keeps the exponents decreasing. The unchanged coefficients are less than \(b<c\), so the resulting expression is already the canonical hereditary base-\(c\) representation of its value. Replacing \(c\) by \(\omega\) in it gives precisely the same hereditary ordinal term as replacing \(b\) by \(\omega\) in the original. This proves the second identity. □

Every Goodstein sequence eventually reaches zero

Start with any natural number \(g_0\), using base two. At stage \(n\), let \(b=n+2\) and define

\[ g_{n+1}=\begin{cases}B_b^{b+1}(g_n)-1,&g_n>0,\\0,&g_n=0.\end{cases} \]

This is a Goodstein sequence. Despite possible rapid increases in its natural-number values, it reaches zero after finitely many steps.

Proof

Measure stage \(n\) by \(\alpha_n=o_{n+2}(g_n)\). If \(g_n>0\), base change preserves positivity, and gives

\[ \alpha_{n+1}=o_{b+1}(B_b^{b+1}(g_n)-1)<o_{b+1}(B_b^{b+1}(g_n))=o_b(g_n)=\alpha_n. \]

If zero were never reached, these ordinals would form an infinite strictly decreasing sequence. Its range is a set by Replacement and has a least ordinal; the next term after that ordinal would be smaller, a contradiction. Thus some \(g_n=0\). □

The proof uses ordinals below \(\varepsilon_0\) and no Choice. Assertions about which formal arithmetic systems can prove this theorem require a separate account of syntax, provability, and those systems.
