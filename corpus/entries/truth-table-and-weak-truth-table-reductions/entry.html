Choose a finite table before receiving oracle answers

A prefix truth-table scheme consists of total computable numerical functions \(u(x)\) and \(t(x,w)\), with \(t(x,w)\in\{0,1\}\) for all inputs. On input \(x\), it uses the first \(u(x)\) membership bits of its oracle. If \(\sigma\) is that binary word and \(u_\sigma\) is its list code, the answer is \(t(x,u_\sigma)\). For sets \(A,B\subseteq\mathbb N\), write \(A\le_{\mathrm{tt}}B\), or say that \(A\) is truth-table reducible to \(B\), if one such scheme satisfies

\[\chi_A(x)=t\bigl(x,u_{B\upharpoonright u(x)}\bigr)\qquad(x\in\mathbb N).\]

For fixed \(x\), only the \(2^{u(x)}\) binary words of length \(u(x)\) are used. The values of \(t\) on these words are the finite truth table. They can all be computed before any oracle answer is supplied: start with the list containing the empty word, and at each step append zero and one to every listed word. After \(u(x)\) steps this lists exactly the required rows. Apply \(t\) to each code. Conversely, a computable procedure producing the bound and these finitely coded rows gives such a total lookup function: compare a supplied word with the listed rows, return its listed bit when present, and zero otherwise.

This prefix convention permits unused bits. A table that depends only on a few specified positions is represented by a prefix ending after the largest of those positions and ignoring the other coordinates. A bound of zero permits one row, the empty word, and no oracle questions.

A table may combine answers instead of copying one

For every \(B\subseteq\mathbb N\), the set

\[X_B=\{x:\text{exactly one of }x,x+1\text{ belongs to }B\}\]

is truth-table reducible to \(B\). One scheme has \(u(x)=x+2\) and \(t(x,u_\sigma)=(\sigma(x)+\sigma(x+1))\bmod2\) on words of that length; put zero on other supplied word codes.

The bound and finite bit tests are computable. The four relevant pairs of answers give precisely the following table, regardless of the unused earlier bits.

Exclusive-or of the membership bits at \(x\) and \(x+1\).
\(\chi_B(x)\)\(\chi_B(x+1)\)\(\chi_{X_B}(x)\)
000
011
101
110

Thus the table outputs one exactly for the defining condition of \(X_B\). The two relevant questions and the rule combining their answers are fixed from \(x\); no later question has to be chosen after seeing an earlier answer.

A use bound limits positions, including negative answers

Use the successful derivations and query records \(c;x\Downarrow_\tau y\). For a finite record \(\tau\), let \(Q(\tau)\) be its set of queried positions. Its use is the already specified bound

\[\operatorname{use}(\tau)=\max\bigl(\{0\}\cup\{q+1:q\in Q(\tau)\}\bigr).\]

Thus \(\operatorname{use}(\tau)\le m\) means that every recorded query has position strictly below \(m\). An empty record has use zero. A negative answer at a position still counts as a query at that position; repetitions do not increase the maximum.

For a fixed oracle \(B\), program \(c\), and total numerical function \(u\), say that a successful computation has use bounded by \(u\) on input \(x\) if it has a record consistent with \(B\) whose use is at most \(u(x)\). This bounds oracle positions, rather than the number of ordinary computational steps.

Require a computable bound for the successful computations

A weak truth-table reduction of \(A\) to \(B\) consists of one actual oracle program \(c\) and a total computable \(u:\mathbb N\to\mathbb N\) such that, for every \(x\), there is a finite record \(\tau\) satisfying

\[c;x\Downarrow_\tau\chi_A(x),\qquad\tau\text{ is consistent with }B,\qquad\operatorname{use}(\tau)\le u(x).\]

Write \(A\le_{\mathrm{wtt}}B\) when such a program and bound exist. By trace correctness, the program terminates with \(\chi_A(x)\) under \(B\) for every input. The same computable function bounds all these successful uses. There is no requirement that this program terminate under every other oracle.

The bound identifies a whole cylinder of unchanged answers

Suppose \(c,u\) witness \(A\le_{\mathrm{wtt}}B\). If an oracle \(C\) agrees with \(B\) below \(u(x)\), then \(E_C(c,x)\downarrow=\chi_A(x)\).

Choose the successful record from the definition. Every query position in it is below \(u(x)\), and agreement preserves its recorded zero or one answer. The same derivation is consequently consistent with \(C\). Soundness gives the claimed output. This is the finite-use replay argument with a supplied computable bound; it proves nothing about an oracle with a different prefix at these positions.

One query program evaluates every row of a truth-table scheme

Given a prefix truth-table scheme \(u,t\), there is one oracle program \(c_{u,t}\) such that, for every oracle \(C\) and input \(x\),

\[E_C(c_{u,t},x)\downarrow=t\bigl(x,u_{C\upharpoonright u(x)}\bigr).\]

It has a successful record using only positions below \(u(x)\). In particular it terminates for every oracle, and a scheme witnessing \(A\le_{\mathrm{tt}}B\) gives a weak truth-table reduction with that same bound.

First compute \(u(x)\) by an ordinary total program. Retain \(x\), start with the empty word code, and perform the finite recursion

\[r_C(x,0)=u_{[]},\qquad r_C(x,j+1)=\operatorname{append}\bigl(r_C(x,j),\chi_C(j)\bigr).\]

The step is an ordinary effective append operation and one query at \(j\). The closure of the actual query-program language under primitive recursion therefore supplies a fixed program for this recurrence. Induction on \(j\) gives its invariant: the stored code is exactly \(u_{C\upharpoonright j}\), and every query so far has position below \(j\). The base record is empty. A successor concatenates the preceding record with the single query \((j,\chi_C(j))\), proving the record assertion too.

At \(j=u(x)\), run an ordinary total program for \(t\) on \(x,r_C(x,u(x))\). Its ordinary embedding adds no queries. Composition gives the specified \(c_{u,t}\). Every finite recursion and lookup terminates under every \(C\), and the invariant proves both the evaluation identity and the use bound, including \(u(x)=0\).

Stronger restrictions still give ordinary oracle reductions

For all sets \(A,B\subseteq\mathbb N\),

\[A\le_m B\quad\Longrightarrow\quad A\le_{\mathrm{tt}}B\quad\Longrightarrow\quad A\le_{\mathrm{wtt}}B\quad\Longrightarrow\quad A\le_T B.\]

If a total computable \(f\) gives \(x\in A\Longleftrightarrow f(x)\in B\), take \(u(x)=f(x)+1\) and let the table return the bit at position \(f(x)\). Bit lookup on a finite word is computable, with zero as default on an invalid position. The actual program can simply compute \(f(x)\) and ask that one question. This proves the first implication. The second is . For the last implication, the successful consistent derivation in the weak truth-table definition gives \(E_B(c,x)=\chi_A(x)\) by trace soundness, exactly the definition of Turing reducibility.

All-oracle termination supplies a computable uniform allowance

Fix an oracle-program index \(e\) whose program terminates on every input under every oracle. There is a total computable \(h:\mathbb N\to\mathbb N\) such that every binary word \(\sigma\) of length \(h(x)\) has

\[D(\sigma,e,x)>0.\]

Here \(D\) is the fixed bounded prefix certificate: its word length is also its evaluation allowance.

For a fixed \(x\), consider the binary tree

\[T_x=\{\sigma:D(\sigma,e,x)=0\}.\]

It is closed under prefixes: a successful certificate at a shorter word would persist to the longer word by . Membership is decidable, uniformly in the word and \(x\), because the certificate checker is primitive recursive. If this tree had a node at every length, the ordinary König lemma would give an infinite binary path \(C\) all of whose prefixes fail the test. But the program terminates under \(C\), so prefix adequacy gives a successful prefix, a contradiction. Hence some level of \(T_x\) is empty.

To compute \(h(x)\), test levels \(n=0,1,2,\ldots\). List all \(2^n\) binary words by the finite append construction in , compute their certificate values, and stop at the first level where all are positive. Each level test finishes, and the preceding argument guarantees a successful level. Thus this one ordinary search is total for the fixed \(e\), uniformly in \(x\). Its totality uses the all-oracle hypothesis; it does not decide which arbitrary indices satisfy that hypothesis.

Truth tables are exactly reductions total for every oracle

For sets \(A,B\subseteq\mathbb N\), the following are equivalent:

  • \(A\le_{\mathrm{tt}}B\).
  • There is one oracle program \(c\) that terminates under every oracle on every input, and satisfies \(E_B(c,x)\downarrow=\chi_A(x)\) for every \(x\).
  • There are an oracle-program index \(e\) and a total computable \(h\) such that \(b_B(h(x),e,x)=\chi_A(x)+1\) for every \(x\), where \(b\) is the fixed bounded output code.

The first condition gives the second by . For the second, take an index \(e\) for \(c\) and the computable \(h\) from . The prefix \(B\upharpoonright h(x)\) certifies a value. Soundness identifies that value with \(\chi_A(x)\), and agreement below the allowance identifies its certificate with \(b_B(h(x),e,x)\). This gives the third condition.

For the converse, use prefix bound \(h(x)\). On a supplied word of that length, run the ordinary finite checker at allowance \(h(x)\), index \(e\), and input \(x\). Give the table value one exactly when this checker returns code two, meaning output one; otherwise give zero. This defines a total computable Boolean lookup, even at a word where the bounded computation fails or produces another number. At the actual prefix of \(B\), the checker equals \(b_B(h(x),e,x)=\chi_A(x)+1\). The table therefore returns exactly \(\chi_A(x)\), proving the first condition.

Outputs of \(c\) under other oracles need not be Boolean. The finite lookup just described keeps the distinction “output one” versus “any other result”; only its agreement with the characteristic function under \(B\) is required. The third condition bounds an allowance of this evaluator, not the number of tape-machine transitions.

The bounded-allowance condition applies to every Turing reduction below a hyperimmune-free oracle: that oracle computes its own first successful allowance function, which has a computable majorant. Hence Turing reducibility collapses to truth-table reducibility below such an oracle.

Compose finite tables by evaluating the inner rows first

Truth-table reducibility is reflexive and transitive. More precisely, let \(u,t\) witness \(A\le_{\mathrm{tt}}B\), and let \(v,s\) witness \(B\le_{\mathrm{tt}}C\). A scheme for \(A\le_{\mathrm{tt}}C\) has bound

\[w(x)=\max\bigl(\{0\}\cup\{v(i):i<u(x)\}\bigr).\]

Given a binary word \(\sigma\) of length \(w(x)\), construct a word \(\rho\) of length \(u(x)\) by

\[\rho(i)=s\bigl(i,u_{\sigma\upharpoonright v(i)}\bigr)\qquad(i<u(x)).\]

Every required prefix is available because \(v(i)\le w(x)\). Let the new lookup return \(t(x,u_\rho)\). On other supplied word lengths return zero. The maximum, finite list of prefixes, calls to the total lookup \(s\), and call to \(t\) are all computable; the generated entries are Boolean. If \(\sigma=C\upharpoonright w(x)\), every inner-table identity gives \(\rho(i)=\chi_B(i)\). Thus \(\rho=B\upharpoonright u(x)\), and the outer identity gives \(\chi_A(x)\). This proves transitivity for the specified composite table. If \(u(x)=0\), then \(w(x)=0\), \(\rho=[]\), and the same calculation uses its single empty row.

For reflexivity, take bound \(x+1\) and return the bit at position \(x\). This is the one-query scheme for the identity many-one map.

Replacing a query replaces its record by the answering computation

Suppose \(c;x\Downarrow_\tau y\) is consistent with \(B\), and \(d,v\) witness \(B\le_{\mathrm{wtt}}C\). Then the specified query substitution has a successful derivation

\[\operatorname{subst}(d,c);x\Downarrow_\rho y\]

consistent with \(C\). Every query position \(r\) in \(\rho\) is below \(v(q)\) for some position \(q\) queried in the original \(\tau\).

At each original query \((q,b)\), consistency gives \(b=\chi_B(q)\). Choose the successful \(C\)-consistent derivation of \(d\) at \(q\) supplied by its reduction, with use at most \(v(q)\). Replace that query leaf by this derivation; its final numerical value is the same bit \(b\), so it leaves every intermediate value of the original calculation unchanged.

Induct on the finite original derivation tree. Ordinary leaves keep their empty records. A query leaf uses the chosen replacement. Pairing and composition concatenate the transformed child records in the original order. A primitive recursion keeps its counter and successive numerical values and transforms each derivation in its finite chain. A successful search likewise keeps its final witness and all earlier positive test values, transforming the test derivations in order. These are exactly the rules for the substituted program, and all resulting records are consistent with \(C\).

Every query in the new record belongs to one of the replacement records. That record came from an original position \(q\), and all its positions are below \(v(q)\). This proves the final assertion. In particular an original empty query record remains empty. The chosen replacement derivations justify the execution of the one fixed syntactic substitution; they do not define a different program for each input.

A computable use bound survives query substitution

Weak truth-table reducibility is reflexive and transitive. If \(c,u\) witness \(A\le_{\mathrm{wtt}}B\) and \(d,v\) witness \(B\le_{\mathrm{wtt}}C\), then \(\operatorname{subst}(d,c)\), with the computable bound

\[w(x)=\max\bigl(\{0\}\cup\{v(i):i<u(x)\}\bigr),\]

witnesses \(A\le_{\mathrm{wtt}}C\).

For each input take the original successful record \(\tau\), with every queried \(q<u(x)\). The record-substitution lemma produces a consistent successful record for the specified new program, with the same final output \(\chi_A(x)\). Its every position \(r\) satisfies \(r<v(q)\le w(x)\) for some such \(q\). Thus its use is at most \(w(x)\). The finite maximum is computable uniformly in \(x\), proving the claimed reduction.

If \(u(x)=0\), the original record is empty, the replacement record is empty, and \(w(x)=0\), so the boundary case is included. Reflexivity uses the query program and bound \(u(x)=x+1\); its record is \([(x,\chi_A(x))]\).

Finite Boolean combinations preserve either reduction

For a fixed oracle \(B\), each of the two families

\[\{A:A\le_{\mathrm{tt}}B\},\qquad\{A:A\le_{\mathrm{wtt}}B\}\]

contains every computable set and is closed under finite Boolean combinations, including complements, unions, and intersections.

A computable characteristic function gives a truth-table scheme of bound zero whose one row returns that bit. The implication chain gives its weak truth-table reduction as well. This includes both constant sets.

For truth tables, complement the lookup bit to obtain a table for the complement. Given tables with bounds \(u_0,u_1\), use \(\max(u_0(x),u_1(x))\), take the two required prefixes, and apply Boolean disjunction or conjunction to their two lookup bits. These are total computable tables and have exactly the desired membership identities.

For weak truth-table reductions, an ordinary Boolean-negation program after the given program adds no oracle queries. For a union or intersection, run the two given programs by the actual pairing constructor, then apply the ordinary two-bit Boolean operation to their paired outputs. Both computations terminate under \(B\). Their records concatenate; all queried positions lie below \(\max(u_0(x),u_1(x))\). Hence this maximum bounds the use of the composite program. Induction on a finite Boolean expression proves the general assertion, with constant sets as the empty-expression cases.

Reversing one answer already goes beyond many-one reducibility

If \(B\) is c.e. and undecidable, then

\[\overline B\le_{\mathrm{tt}}B\qquad\text{and}\qquad\overline B\not\le_m B.\]

In particular \(\overline K\le_{\mathrm{tt}}K\) and \(\overline K\not\le_m K\) for ordinary diagonal halting \(K\).

Use bound \(x+1\) and let the table return one minus the bit at position \(x\). This computes \(\chi_{\overline B}(x)\) for every oracle \(B\), so proves the first assertion. The previous preimage argument proves the second: a many-one reduction to the c.e. set \(B\) would make \(\overline B\) c.e.; then both sides would be c.e., making \(B\) decidable. The ordinary halting set has the required enumerability and undecidability.

The simple truth-table complete construction gives a c.e. target receiving halting by a finite table while receiving no many-one reduction of halting.

Let \(N=\mathsf{find}'(\mathsf{comp}(\mathsf{succ},\mathsf{zero}))\), the ordinary divergent program whose every search test returns one. Use the actual oracle program

\[c=\mathsf{comp}\!\left(\mathsf{prec}(\mathsf{zero},N),\mathsf{pair}(\mathsf{zero},\mathsf{comp}(\mathbf Q,\mathsf{zero}))\right).\]

On any input it queries position zero and forms \(\langle0,\chi_C(0)\rangle\). If \(0\notin C\), the primitive recursion has counter zero and its base returns zero. If \(0\in C\), its first step runs \(N\), which diverges. Under \(B=\varnothing\), this therefore decides \(A=\varnothing\) with record \([(0,0)]\) and the constant computable use bound one. Under \(C=\{0\}\), it never returns.

This program is a valid weak truth-table witness and is not total for every oracle. The two sets in the example nevertheless have a truth-table reduction too: the constant-zero table has bound zero. A property of one supplied program is distinct from the existence of some program witnessing a reduction. Bounding positions also does not bound arbitrary ordinary work after those queries; the separate bounded-allowance criterion in is stronger information.
