Complete the actual arithmetic axiom set

Work in the fixed first-order arithmetic language, with Peano arithmetic \(\mathrm{PA}\), the actual proof calculus, and the sentence codes already constructed. A PA completion is a consistent, complete, deductively closed theory \(T\) in that same language with \(\mathrm{PA}\subseteq T\). Thus it contains exactly one of \(\theta,\neg\theta\) for each sentence \(\theta\), and \(\theta\in T\) exactly when \(T\vdash\theta\). These are the established conventions for deductive closure and complete theories.

The code set of the completion is

\[C_T=\{\ulcorner\theta\urcorner:\theta\text{ is an arithmetic sentence and }\theta\in T\}.\]

Malformed sentence codes are outside \(C_T\). No effective enumeration of \(T\) is assumed. Its consistency is syntactic consistency in the stated calculus; the completeness theorem also makes it satisfiable.

Ask which oracles can compute a completion

An oracle \(A\subseteq\mathbb N\) has PA degree if \(C_T\le_T A\) for some PA completion \(T\). A PA degree is the Turing degree of such an oracle. Here \(\le_T\) requires an actual oracle program deciding the indicated code set.

A binary DNC set is a set \(D\subseteq\mathbb N\) whose characteristic function \(f=\chi_D\) is diagonally noncomputable:

\[\forall e,y\qquad \varphi_e(e)\downarrow=y\quad\Longrightarrow\quad f(e)\ne y.\]

The fixed bit convention is membership equals one. The separator characterization says exactly that \(f=1\) on \(D_0=\{e:\varphi_e(e)\downarrow=0\}\) and \(f=0\) on \(D_1=\{e:\varphi_e(e)\downarrow=1\}\). Computing such a function and computing its one-set are equivalent: evaluate the function and test for one in one direction, and ask one membership query in the other.

Turn opposite computation certificates into provable opposite sentences

There is a fixed arithmetic formula \(\Theta(z)\) such that the map \(e\mapsto\ulcorner\Theta(\overline e)\urcorner\) is primitive recursive and

\[e\in D_0\Longrightarrow Q\vdash\Theta(\overline e),\qquad e\in D_1\Longrightarrow Q\vdash\neg\Theta(\overline e).\]

The tests \(C_i(e,s)\Longleftrightarrow b(s,e,e)=i+1\), for \(i=0,1\), are primitive recursive, using the fixed bounded evaluator. Choose formulas \(R_i(z,w)\) that represent them with positive and negative numeral proofs in \(Q\). Using the particular arithmetic order abbreviation from finite numeral cuts, set

\[\Theta(z)\;:\!\Longleftrightarrow\;\exists s\,\bigl(R_0(z,s)\land\forall t\le s\,\neg R_1(z,t)\bigr).\]

This is a formula of the existing arithmetic language, with one free variable. The two representing formulas are fixed. Numeral substitution on codes therefore makes the stated sentence-code map primitive recursive.

If \(e\in D_0\), choose a standard certificate \(s\) for output zero. There is no certificate for output one, by uniqueness of the partial output. Thus \(Q\) proves \(R_0(\overline e,\overline s)\) and each of the finitely many sentences \(\neg R_1(\overline e,\overline t)\), \(t\le s\). In every model of \(Q\), an element at most \(\overline s\) is one of these numerals, so these proofs establish the bounded universal condition. The witness \(\overline s\) gives \(\Theta(\overline e)\) in every such model, hence a \(Q\)-proof by completeness.

If \(e\in D_1\), fix a standard certificate \(t\) for output one. Then \(Q\) proves \(R_1(\overline e,\overline t)\), and it proves \(\neg R_0(\overline e,\overline j)\) for every standard \(j\). Work in any model of \(Q\) and consider a possible witness \(s\) for \(\Theta(\overline e)\). If \(t>0\), the numeral-cut theorem at \(t-1\) says that either \(s=\overline j\) for some \(j<t\), or \(\overline t\le s\). The first case contradicts the relevant negative \(R_0\)-instance. In the second case the positive \(R_1\)-instance contradicts the required bounded universal. If \(t=0\), one always has \(\overline0\le s\): in the abbreviation \(\exists z\,(z+0=s)\), take \(z=s\). The second contradiction therefore applies to every \(s\). No witness exists in any model of \(Q\), giving \(Q\vdash\neg\Theta(\overline e)\).

This argument uses finite cuts at external numeral bounds. It requires neither a global order law for arbitrary elements of \(Q\)-models nor a soundness assumption about a completion.

A completion computes binary diagonal avoidance

Every PA completion \(T\) computes a binary DNC set. More precisely, the specified computable preimage

\[D_T=\{e:\ulcorner\Theta(\overline e)\urcorner\in C_T\}\]

is binary DNC, and \(D_T\le_T C_T\).

The formula-code map is primitive recursive. An ordinary program computes that code and makes one \(C_T\)-membership query, giving an actual total oracle program for the displayed preimage. If \(e\in D_0\), the preceding lemma and \(Q\subseteq\mathrm{PA}\subseteq T\) give \(T\vdash\Theta(\overline e)\); deductive closure puts its code in \(C_T\). If \(e\in D_1\), the lemma gives \(T\vdash\neg\Theta(\overline e)\), and consistency excludes \(\Theta(\overline e)\) from \(T\). Thus \(D_T\) separates \(D_0,D_1\), so is binary DNC. Substituting any supplied \(A\)-oracle decider for \(C_T\) into the one-query program also gives \(D_T\le_T A\).

Contradictions from finitely many extra sentences have a uniform check

For a finite list \(L\) of arithmetic sentence codes, let \(\Gamma_L\) be \(\mathrm{PA}\) together with the sentences on \(L\). There is one primitive-recursive Boolean test \(\operatorname{Bad}(L,p)\) such that

\[\exists p\,\operatorname{Bad}(L,p)=1\quad\Longleftrightarrow\quad\Gamma_L\vdash\bot.\]

Use the actual PA axiom certificates. For a proposed axiom code \(a\), let a certificate \(\langle0,s\rangle\) invoke the PA test \(E_{\mathrm{PA}}(a,s)\). A certificate \(\langle1,j\rangle\) is accepted when \(j\) is within the finite list and its \(j\)-th entry is \(a\). Reject other tags and malformed sentence codes. This is one primitive-recursive axiom test jointly in the finite-list code, \(a\), and the certificate. For a valid list it presents exactly \(\Gamma_L\).

Run the existing certified proof checker with that axiom test and conclusion \(\bot\). Its finite syntax, rule and axiom scans are primitive recursive jointly in the extra list parameter, giving \(\operatorname{Bad}\). The certificate theorem for the same calculus proves the equivalence. The construction also supplies a total test on arbitrary numerical list codes, rejecting invalid entries when they are offered as axioms.

Compile the two possible failures before choosing a side

There is a primitive-recursive index compiler \(q(L,a)\), defined for every numerical list code \(L\) and sentence code \(a\), with this behavior at every runtime input: search successive \(p\) for

\[\operatorname{Bad}(L^\frown[a],p)=1\quad\text{or}\quad\operatorname{Bad}(L^\frown[\operatorname{neg}(a)],p)=1.\]

Return zero if the first successful stage passes the first test, and one otherwise; a tie returns zero. Here \(\operatorname{neg}\) is the fixed negation-code operation. If neither search succeeds, the program is undefined.

The displayed tests are total primitive recursive. Least-success search and the indicated output rule therefore give a jointly partial recursive function \(V(\langle L,a\rangle,z)\), ignoring runtime input \(z\). Fix one ordinary index \(v\) for it and put \(q(L,a)=s(v,\langle L,a\rangle)\). Specialization proves

\[\varphi_{q(L,a)}(z)\simeq V(\langle L,a\rangle,z)\qquad\text{for all }L,a,z.\]

The numerical compiler terminates before either proof search is run. This exact identity includes both divergent cases and the fixed tie behavior.

A diagonal-avoiding bit selects a consistent extension

Suppose \(\Gamma_L\) is consistent, \(a=\ulcorner\theta\urcorner\), and \(D\) is binary DNC with \(f=\chi_D\). Append \(a\) if \(f(q(L,a))=0\), and append \(\operatorname{neg}(a)\) if \(f(q(L,a))=1\). The resulting finite extension of PA is consistent.

The two extensions cannot both be inconsistent. By the deduction theorem, a contradiction from \(\Gamma_L+\theta\) would give \(\Gamma_L\vdash\neg\theta\), while a contradiction from \(\Gamma_L+\neg\theta\) would give \(\Gamma_L\vdash\neg\neg\theta\). Together these contradict consistency of \(\Gamma_L\). Equivalently, a model of \(\Gamma_L\) satisfies one of the two sentences.

If the positive extension is inconsistent, only its contradiction search can succeed, so \(\varphi_{q(L,a)}(q(L,a))=0\). Diagonal avoidance forces \(f(q(L,a))=1\), selecting the consistent negative extension. If the negative extension is inconsistent, the program instead returns one, forcing bit zero and the positive extension. If neither extension is inconsistent, either bit is safe. This proves the assertion for all possibilities; in particular the construction uses bit zero for the positive choice and bit one for the negative choice.

Make one signed choice for every sentence code

Let \(\alpha_n\) be the arithmetic sentence with code \(n\) when \(n\) is a valid sentence code, and the fixed tautology \(\top\) otherwise. The map \(n\mapsto a_n=\ulcorner\alpha_n\urcorner\) is primitive recursive by sentence recognition. For a binary DNC set \(D\), define its completion history by

\[L_0=[],\qquad b_n=\chi_D(q(L_n,a_n)).\]
\[L_{n+1}=\begin{cases}L_n^\frown[a_n]&b_n=0,\\L_n^\frown[\operatorname{neg}(a_n)]&b_n=1.\end{cases}\]

Every \(L_n\) is a finite list of actual sentence codes. Define the chosen axiom set and its completion by

\[\Gamma_D=\mathrm{PA}\cup\{\theta:\ulcorner\theta\urcorner\text{ occurs on some }L_n\},\qquad T_D=\operatorname{Cn}(\Gamma_D).\]

The recurrence specifies a single choice history for the supplied oracle, including every malformed-code stage. At such a stage it processes \(\top\); it does not try to decode an invalid expression.

The union of the finite choices gives a PA completion

For every binary DNC set \(D\), all theories \(\Gamma_{L_n}\) in its completion history are consistent, and \(T_D\) is a PA completion.

Inductively maintain three assertions: \(L_n\) contains only sentence codes, \(L_n\) is a prefix of \(L_{n+1}\), and \(\Gamma_{L_n}\) is consistent. The empty list has these properties because PA has its standard model. At the next stage, the selected sentence is valid by construction, appending retains all previous choices, and preserves consistency. This proves the invariant.

If \(\Gamma_D\) proved a contradiction, that finite derivation would use only finitely many chosen axioms. Every such choice appears on some list, and the lists increase; one sufficiently late \(L_n\) contains them all. The same derivation would contradict consistency of \(\Gamma_{L_n}\). Hence \(\Gamma_D\) is consistent.

Every arithmetic sentence \(\theta\) is processed at stage \(n=\ulcorner\theta\urcorner\), so one of \(\theta,\neg\theta\) belongs to \(\Gamma_D\). Its deductive closure \(T_D\) is therefore complete, contains PA and is consistent: the closure has the same models as \(\Gamma_D\). Closure is idempotent, so \(T_D\) is deductively closed as well. These facts establish all parts of the definition.

The same oracle computes membership in the chosen completion

There is one actual oracle program \(P\), independent of the binary DNC set \(D\), that decides \(C_{T_D}\) under \(D\). For every input \(n\), its output is

\[\chi_{C_{T_D}}(n)=\begin{cases}1-b_n&n\text{ is a valid sentence code},\\0&n\text{ is malformed}.\end{cases}\]

Reject a malformed code by the total syntax test. Otherwise compute the finite recurrence through \(L_n\), evaluate the primitive-recursive compiler \(q(L_n,a_n)\), and make the indicated \(D\)-membership query to obtain \(b_n\). Code the whole current list as the state of a primitive recursion. Its successor operation computes \(a_i\) and \(q\), asks one query, and appends the appropriate signed code. All other operations are ordinary total computable functions. The actual oracle-program closure theorem therefore constructs one finite program for this recurrence and final output. Its text contains the fixed checker and compiler, rather than the oracle's answers. Induction on the number of steps proves that its state is precisely \(L_i\) for every \(i\); each query terminates, so every run described here is total.

For a valid input \(n=\ulcorner\theta\urcorner\), bit zero at stage \(n\) puts \(\theta\) into the chosen axioms and therefore into \(T_D\). Bit one puts \(\neg\theta\) into the chosen axioms, and consistency excludes \(\theta\) from \(T_D\). This proves the exact output formula for the same deductive closure, even if the sentence or its negation appeared at an earlier stage. Consequently \(C_{T_D}\le_T D\). By oracle substitution, any oracle computing a binary DNC set also computes this completion.

Record which child cone is first seen to die

Fix a computable binary tree \(T\), with a supplied ordinary program deciding its coded nodes. For a finite binary word \(\sigma\), let \(E_j(\sigma,m)\), \(j=0,1\), say that no node in \(T\) of length \(|\sigma|+1+m\) extends \(\sigma^\frown j\). These are total computable finite-level tests by the dead-cone criterion.

If either test ever succeeds, search the least stage \(m\) at which one does. Put \(\sigma\) into the left-dead set \(L_T\) if \(E_0(\sigma,m)\) holds at that stage, and into the right-dead set \(R_T\) otherwise. A tie goes only into \(L_T\). If neither test succeeds, put \(\sigma\) in neither set. Invalid binary-word codes are excluded from both sets.

The two finite-failure lists are enumerable and disjoint

The sets \(L_T,R_T\) are disjoint c.e. sets, with recognizer indices obtained effectively from the supplied tree-decider index. If \(\sigma\) has an infinite cone in \(T\), at most one child cone dies, and a dying left child puts \(\sigma\) into \(L_T\), while a dying right child puts it into \(R_T\).

On a valid word code, perform the specified least-stage race and accept precisely the chosen side. The finite tests terminate, so both side recognizers are ordinary partial recursive procedures. A single success stage has only one chosen side; hence no word enters both sets, even when both child cones eventually die. Invalid codes are rejected before the race. Fixing one joint program with the tree-decider index as an inserted parameter gives the two recognizer indices by specialization.

At an extendible node, the surviving-child lemma prevents both children from dying. If the left child dies, the right one never passes a dead-cone test, so the first success is necessarily on the left. The right-child case is symmetric. If neither dies, both cones have nodes arbitrarily far above the child.

A binary DNC oracle selects a surviving child

For the supplied computable tree \(T\), there is a specified ordinary total computable map \(g_T\) such that, for every binary DNC set \(D\),

\[s_D(\sigma)=\chi_D(g_T(\sigma))\]

selects an extendible child \(\sigma^\frown s_D(\sigma)\) whenever \(\sigma\) is an extendible binary node. The numerical map is fixed before \(D\) varies.

Use the two recognizer indices from in the specified reduction of any disjoint c.e. pair to \((D_0,D_1)\). Write \(a_T,b_T\) for the two recognizer indices and \(r_0\) for a fixed paired-input race-program index from that construction. Take the specified map \(g_T(\sigma)=s(r_0,\langle a_T,\langle b_T,\sigma\rangle\rangle)\). It is total computable, and \(\sigma\in L_T\Longleftrightarrow g_T(\sigma)\in D_0\), while \(\sigma\in R_T\Longleftrightarrow g_T(\sigma)\in D_1\). The DNC separator condition therefore forces \(s_D=1\) on \(L_T\) and \(s_D=0\) on \(R_T\).

If the left child dies, the selected bit is one and the right child survives. If the right child dies, the selected bit is zero and the left child survives. If neither dies, either bit selects an extendible child. These cases exhaust extendible parent nodes. The same numerical map works for all binary DNC oracles; its program is built from the supplied tree recognizers and the fixed canonical-pair compiler.

Iterating the selector computes a path through the original tree

If \(T\) is a nonempty-path computable binary tree and \(D\) is binary DNC, define

\[\sigma_0=\varnothing,\qquad \sigma_{n+1}=\sigma_n^\frown s_D(\sigma_n),\qquad X_D=\{n:s_D(\sigma_n)=1\}.\]

Then \(X_D\) is a path through \(T\) and \(X_D\le_T D\). For a supplied tree decider, one actual oracle program computes these bits for every binary DNC oracle; it does not depend on which such oracle is supplied.

A path in \(T\) makes the empty word extendible. Induction, using , gives that \(\sigma_n\) is valid, has length \(n\), and is extendible, and that \(\sigma_n\) is a prefix of \(\sigma_{n+1}\). Extendibility in particular gives \(\sigma_n\in T\), by the length-\(n\) test. The bits are binary, so \(\chi_{X_D}(n)=s_D(\sigma_n)\). The successive words are therefore precisely the prefixes of \(X_D\), proving the path assertion.

Here is the oracle program. Starting at the empty-word code, repeat \(n\) times: compute \(g_T\) at the current word, query the supplied set, and append that bit using the fixed binary-word code operation. At the resulting word \(\sigma_n\), compute \(g_T\) once more and return its membership answer. The state update is ordinary computable code followed by one query and a computable append; oracle primitive recursion constructs its finite text. The state invariant above also proves its exact evaluation identity \(E_D(P_T,n)=\chi_D(g_T(\sigma_n))=\chi_{X_D}(n)\). All finite recursions and queries terminate. Thus this is a reduction for the same path in the same coded tree, with one program \(P_T\) fixed before \(D\) varies.

If \(D\le_T A\), substitute its supplied characteristic-function program into \(P_T\). The substitution identity gives an \(A\)-oracle program for this path, preserving every computed bit.

The ability to choose paths includes a binary DNC path

If an oracle \(A\) computes a path through every computable binary tree having a path, then it computes a binary DNC set.

Apply the hypothesis to the fixed diagonal separator tree. It is computable and has a path, and its paths are exactly the binary DNC sets. The path supplied by the hypothesis is therefore the required \(A\)-computable set.

Arithmetic completions, diagonal avoidance and path selection coincide

For every oracle \(A\subseteq\mathbb N\), the following are equivalent:

  • \(A\) has PA degree.
  • \(A\) computes a binary DNC set.
  • For every computable binary tree \(T\) with at least one infinite path, \(A\) computes some path through \(T\).

A computed PA completion yields a computed binary DNC set by and oracle substitution. Conversely a computed binary DNC set yields the particular computed PA completion \(T_D\) by and . Binary DNC computes paths through every indicated tree by , and the path property yields binary DNC by . These prove all three equivalences with actual oracle programs.

The property belongs to a degree and is preserved above it

If \(A\) has PA degree and \(A\le_T B\), then \(B\) has PA degree. Thus the definition is invariant under Turing equivalence. Every oracle \(A\) with \(K\le_T A\) has PA degree, and no computable oracle has PA degree.

Choose a completion with \(C_T\le_T A\). Transitivity gives \(C_T\le_T B\), proving upward closure; two applications give degree invariance. The existing halting-computable binary DNC example and the characterization show that \(K\), and hence every oracle above it, has PA degree. If a computable oracle had PA degree, eliminating that oracle from its DNC reduction would give a computable binary DNC function, contrary to diagonal noncomputability. This also explains why the computable degree is excluded.

Some PA degrees lie strictly below the halting degree

There is a binary DNC set \(D\) of PA degree such that \(D'\equiv_T K\) and

\[\mathbf0<\deg_T(D)<\mathbf0'.\]

The low binary DNC theorem supplies a noncomputable \(D\) with \(D'\le_T K\). The ordinary halting lower bound gives \(K\le_T D'\), so its jump is equivalent to \(K\). The characterization makes \(D\) a PA oracle. Since \(D\le_T D'\le_T K\), its degree is at most \(\mathbf0'\). If \(K\le_T D\), jump monotonicity would give \(K'\le_T D'\le_T K\), contradicting strictness of the jump. Thus the upper comparison is strict, and noncomputability gives the strict lower comparison.

There are also hyperimmune-free PA oracles, obtained by applying the corresponding basis theorem to the same binary DNC tree. These noncomputable oracles are not computable from ordinary halting.

The superlow basis argument supplies such a binary DNC oracle with \(D^{\prime}\le_{\mathrm{tt}}K\), equivalently a computably bounded-change jump. The binary-DNC characterization therefore gives a noncomputable superlow PA degree.

An explicit singleton-selector construction turns a binary DNC function into a total fixed-point-free function on ordinary domain indices using the same oracle. Thus the low binary DNC example computes such a function while remaining incomplete; Arslanov’s criterion forces this example to be non-c.e.

Which properties of the completion did the arithmetic reduction use?

Let \(T\) be any consistent, deductively closed extension of \(Q\), and let \(C_T\) be its set of sentence codes. Prove that the same preimage \(D_T=\{e:\ulcorner\Theta(\overline e)\urcorner\in C_T\}\) is binary DNC. Is completeness of \(T\) needed for this assertion?

Completeness is not needed here. If \(e\in D_0\), the explicit comparison lemma gives \(Q\vdash\Theta(\overline e)\). Extension and deductive closure put this sentence into \(T\). If \(e\in D_1\), it gives \(Q\vdash\neg\Theta(\overline e)\); extension and consistency exclude \(\Theta(\overline e)\) from \(T\). Thus \(D_T\) is the required separator, exactly as before. The same one-query program computes it from \(C_T\).

Both conclusions rest on checked standard computation certificates and finitely many positive or negative numeral instances, combined with the finite-cut theorem. The argument never infers a standard witness merely from a sentence's membership in \(T\). Completeness of the first-order proof calculus turns statements about every model of \(Q\) into proofs; this supplies the two specific derivability assertions used in the reduction.
