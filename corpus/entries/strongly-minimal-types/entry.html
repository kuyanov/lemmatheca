Finite choices and the remaining complete description

Fix a complete satisfiable strongly minimal theory \(T\) in a set-sized language \(L\), a model \(M\models T\), and any parameter set \(A\subseteq M\). Thus \(M\) is infinite, and every unary definable set with parameters is finite or cofinite in every model of \(T\). We work classically with choice. No countability assumption is in force yet.

Use the parameter language \(L(A)\) and the complete named theory \(\operatorname{Th}(M_A)\). For an \(L(A)\)-formula \(\varphi(x)\), let \(\varphi(M)\) denote its set of solutions in that named structure. A complete one-type \(p\in S_1^M(A)\) is algebraic if it contains some formula \(\varphi\) for which \(\varphi(M)\) is finite. It is nonalgebraic otherwise.

These types must be compatible with the entire theory of \(M_A\), which fixes the first-order behavior of the original parameters. Merely satisfying \(T\) after giving the names arbitrary interpretations would be a different condition. We will construct exactly one nonalgebraic type and count all the algebraic types.

A finite definable set gains no points in an elementary extension

Suppose \(M\preccurlyeq N\), and \(\varphi(x)\) uses finitely many parameters from \(M\). If \(\varphi(M)\) is finite, then \(\varphi(N)=\varphi(M)\), with the old elements identified through the elementary inclusion. If \(\varphi(M)\) is cofinite, its complement in \(N\) is the same finite set as its complement in \(M\).

List the finite set as \(\{b_1,\ldots,b_m\}\). The statement

\[\forall x\,\bigl(\varphi(x)\leftrightarrow(x=b_1\lor\cdots\lor x=b_m)\bigr)\]

holds in \(M\), using its original parameters and the displayed \(b_i\) as parameters. Elementarity makes it hold in \(N\). Thus precisely the same elements solve \(\varphi\) there. If \(m=0\), the disjunction is \(\bot\), so this also covers the empty set. Apply the finite-set result to \(\neg\varphi\) to obtain the cofinite conclusion.

Consequently \(\operatorname{acl}_N(A)=\operatorname{acl}_M(A)\) for every \(A\subseteq M\). Indeed, each finite \(A\)-definable set in \(M\) persists unchanged. Conversely, if \(\varphi(N)\) is finite, its subset \(\varphi(M)\) is finite, so the result makes those solution sets equal. Taking their unions gives the closure equality. This assertion concerns algebraic closure of old parameters, not algebraic closure of the whole larger domain.

Collect every condition that holds away from finitely many points

Define the cofinite conditions over \(A\) by

\[p_A=\{\varphi(x)\in\operatorname{Form}_1(L(A)):\varphi(M)\text{ is cofinite in }M\}.\]

The formula may use no parameters, and may use any finite selection of names from \(A\). The definition concerns all unary formulas, with quantifiers allowed. We have defined a collection of formulas; consistency and completeness still need proof.

Every finite list of cofinite conditions has an old witness

Every finite subset of \(p_A\) is realized in \(M\). Hence \(p_A\) is a partial type over \(A\) in \(M\).

Let \(\varphi_1,\ldots,\varphi_k\) belong to \(p_A\). Each complement \(M\setminus\varphi_i(M)\) is finite, so their union is finite. Since \(M\) is infinite, choose a point outside that union. It satisfies every \(\varphi_i\). For \(k=0\), any point of \(M\) witnesses the empty list.

The finite parameter-type test now gives consistency with \(\operatorname{Th}(M_A)\). This is exactly where finite consistency becomes simultaneous consistency in a suitable model; it need not supply a simultaneous witness in \(M\).

The cofinite conditions form a complete type

The collection \(p_A\) is a complete nonalgebraic one-type over \(A\). We call it the generic type over \(A\).

Let \(\varphi(x)\) be any \(L(A)\)-formula. Strong minimality says that \(\varphi(M)\) is finite or cofinite. In the finite case, \(\neg\varphi\in p_A\); in the cofinite case, \(\varphi\in p_A\). The two cases cannot overlap, because an infinite set is not the union of two finite sets. Thus exactly one of \(\varphi\) and \(\neg\varphi\) belongs to \(p_A\).

We already proved that \(p_A\) is consistent. A consistent collection deciding every formula is a complete type. Every formula in \(p_A\) has an infinite solution set, so none witnesses algebraicity. Thus the complete type is nonalgebraic.

There is only one nonalgebraic one-type

Every \(p\in S_1^M(A)\) is either algebraic or equal to \(p_A\). In particular, \(p_A\) is the unique nonalgebraic complete one-type over \(A\).

Suppose \(p\) is nonalgebraic and \(\varphi\in p_A\). Its complement is finite. Therefore \(\neg\varphi\) cannot belong to \(p\), since that would witness algebraicity. Completeness forces \(\varphi\in p\). We have shown \(p_A\subseteq p\), and maximal consistency of these complete types gives equality.

Equivalently, a formula belonging to a nonalgebraic type can never have finite solution set, so it must be cofinite. The finite/cofinite alternative leaves no further complete nonalgebraic description.

The generic points are precisely the points outside algebraic closure

For every elementary extension \(M\preccurlyeq N\) and \(b\in N\),

\[\operatorname{tp}^N(b/A)=p_A\quad\Longleftrightarrow\quad b\notin\operatorname{acl}_N(A).\]

The generic type is realized in some elementary extension of \(M\). Inside \(M\), its realizations are exactly \(M\setminus\operatorname{acl}_M(A)\).

Suppose \(b\) realizes \(p_A\), but lies in a finite \(A\)-definable set \(\varphi(N)\). Its source solution set \(\varphi(M)\) is finite too. Hence \(\neg\varphi\in p_A\), contradicting \(N\models\varphi[b]\). Thus \(b\) is outside algebraic closure.

Conversely, suppose \(b\notin\operatorname{acl}_N(A)\). If \(\varphi\in p_A\), then \(M\setminus\varphi(M)\) is finite. By , the same complement in \(N\) is finite and \(A\)-definable. It cannot contain \(b\). Therefore \(N\models\varphi[b]\) for every \(\varphi\in p_A\), so \(b\) realizes that complete type. Its whole type equals \(p_A\), by maximality of complete types.

Finally, elementary realization of parameter types applies to the finite consistency already proved. It supplies some elementary extension and a point realizing \(p_A\). Taking \(N=M\) in the equivalence proves the last assertion.

All algebraic types already occur in the original model

Every algebraic \(p\in S_1^M(A)\) equals \(\operatorname{tp}^M(b/A)\) for some \(b\in\operatorname{acl}_M(A)\). Conversely, every such point has an algebraic type. For each formula with finite solution set, only finitely many complete types contain that formula.

Choose \(\varphi\in p\) with \(\varphi(M)\) finite. Realize \(p\) at \(b\) in an elementary extension \(M\preccurlyeq N\). Since \(b\in\varphi(N)\), gives \(b\in\varphi(M)\subseteq\operatorname{acl}_M(A)\). Elementarity preserves the parameter type of this old point, so \(p=\operatorname{tp}^M(b/A)\).

If \(b\in\operatorname{acl}_M(A)\), a finite \(A\)-definable set containing \(b\) supplies an algebraic formula in its type. The argument above also shows that every complete type containing a fixed finite-solution formula \(\varphi\) is the type of one of its finitely many solutions in \(M\). There can therefore be only finitely many such types.

The map from algebraic points to algebraic types is surjective. Counting types uses this surjectivity: every algebraic type has a representative in algebraic closure.

A finite formula can be refined to isolate one algebraic type

Every algebraic \(p\in S_1^M(A)\) is isolated by an \(L(A)\)-formula with finite solution set. A formula witnessing algebraicity need not itself isolate the type.

Choose a finite-solution \(\varphi\in p\). List the complete types containing \(\varphi\) as \(p,q_1,\ldots,q_k\), with the \(q_i\) distinct from \(p\), using . For each \(i\), choose \(\psi_i\in p\setminus q_i\), which exists because the types differ and are complete. Put

\[\theta(x)=\varphi(x)\land\bigwedge_{i=1}^k\psi_i(x).\]

The formula \(\theta\) belongs to \(p\), since a realization of \(p\) satisfies every conjunct. Its source solution set is a subset of the finite set \(\varphi(M)\). Any complete type containing \(\theta\) contains \(\varphi\) and each \(\psi_i\), so cannot be any \(q_i\). Thus \(p\) is the only complete type containing \(\theta\). By the unique-completion criterion for isolation, \(\theta\) isolates \(p\). If there are no other types, the conjunction is empty and \(\theta=\varphi\).

Finite formulas give a small algebraic closure

Put \(\lambda=\max(|A|,|L|,\aleph_0)\). There are at most \(\lambda\) unary \(L(A)\)-formulas, and

\[|\operatorname{acl}_M(A)|\le\lambda.\]

The language adds one constant for each member of \(A\). Its symbols, logical symbols and countable stock of variables form an alphabet of size at most \(\lambda\). Formulas are finite strings over this alphabet, so the formula-counting bound gives at most \(\lambda\) formulas, including the unary ones. The infinite cardinal \(\lambda\) handles finite or empty parameter sets and finite languages without a separate arithmetic exception.

By the definition of algebraic closure, \(\operatorname{acl}_M(A)\) is the union of the finite solution sets among these formulas. Index those finite sets by their formulas. Choice permits an enumeration of each finite set, so their disjoint union has size at most \(\lambda\cdot\aleph_0\). The union cannot be larger than that disjoint union. Since \(\lambda\) is infinite, infinite cardinal arithmetic gives \(\lambda\cdot\aleph_0=\lambda\), proving the assertion.

Strong minimality replaces the power-set bound by a linear bound

For every \(M\models T\) and \(A\subseteq M\),

\[|S_1^M(A)|\le\max(|A|,|L|,\aleph_0).\]

More precisely, the algebraic one-types are the image of \(\operatorname{acl}_M(A)\) under \(b\mapsto\operatorname{tp}^M(b/A)\), and there is exactly one further type, the generic type \(p_A\).

Let \(\lambda=\max(|A|,|L|,\aleph_0)\). The surjection from algebraic points and closure bound give at most \(\lambda\) algebraic types. By , the only remaining type is \(p_A\), and it is not algebraic. Therefore \(|S_1^M(A)|\le\lambda+1=\lambda\).

There is also a direct count by formulas. Choose a finite-solution isolating formula for each algebraic type, using . Distinct types cannot have the same isolating formula. This injects the algebraic types into a set of at most \(\lambda\) formulas and gives the same bound.

For a general theory, the elementary syntax bound only gives \(2^\lambda\) types, since a type is a set of formulas. Strong minimality makes almost all possible complete choices algebraic, leaving only one generic choice.

Omega-stability uses the one-variable counting convention

Following the existing cardinal definition, \(T\) is \(\omega\)-stable, also called \(\aleph_0\)-stable, if for every model \(M\models T\) and every at most countable \(A\subseteq M\), there are at most countably many members of \(S_1^M(A)\).

This definition counts complete types in one object variable. All stability conclusions below use precisely that convention. We are not using a general reduction from finite-tuple types to one-types.

A countable strongly minimal theory is omega-stable

If \(L\) is countable, the complete satisfiable strongly minimal theory \(T\) is \(\omega\)-stable. More generally, \(T\) is \(\kappa\)-stable for every infinite cardinal \(\kappa\ge |L|\), using the one-variable definition.

If \(L\) and \(A\) are at most countable, then \(\max(|A|,|L|,\aleph_0)=\aleph_0\). The one-type bound therefore gives \(|S_1^M(A)|\le\aleph_0\) for every such \(M,A\), which is exactly \(\omega\)-stability.

For the general assertion, if \(|A|\le\kappa\), \(|L|\le\kappa\), and \(\kappa\) is infinite, all three cardinals in the maximum are at most \(\kappa\). Thus the same bound is at most \(\kappa\), as required by \(\kappa\)-stability.

In pure equality the generic type avoids exactly the named points

For the complete theory of infinite equality structures and any \(A\subseteq M\), algebraic closure is \(A\). The algebraic one-types are exactly the types of the individual points of \(A\), and the remaining generic type is determined by all conditions \(x\ne a\), \(a\in A\). Thus \(|S_1^M(A)|=|A|+1\).

The equality closure calculation gives \(\operatorname{acl}_M(A)=A\). Each \(a\in A\) has a type containing \(x=a\); these types are distinct, since the parameter names distinguish their points. By , they are all the algebraic types.

The equality one-type calculation, using quantifier elimination, says that the inequalities against all named points determine one further complete type. Its realizations in an elementary extension are exactly the points outside \(A\), so identifies it with \(p_A\). Counting the distinct algebraic types and that additional type gives the claimed equality, including finite or empty \(A\).

In a general strongly minimal theory, avoiding the elements of \(A\) alone need not give the generic type. It must avoid every finite \(A\)-definable set, including algebraic points not individually named in \(A\).

Does a generic type always require a new element?

In an infinite equality structure \(M\), compare the generic type over \(A=\varnothing\) with the generic type over \(A=M\). Which is realized inside \(M\)? What is the corresponding answer for an arbitrary parameter set in a strongly minimal model?

Show answerHide answer

In pure equality, \(\operatorname{acl}_M(\varnothing)=\varnothing\), so every point of \(M\) realizes the generic type over the empty set. Over \(A=M\), the generic type includes \(x\ne a\) for every \(a\in M\), so none of the original points realizes it. Finite subsets still have witnesses because \(M\) is infinite. The generic type is consequently realized in a proper elementary extension.

For arbitrary \(A\subseteq M\), gives exactly the answer: its realizations in \(M\) are \(M\setminus\operatorname{acl}_M(A)\). In particular, over \(A=M\), every old point is algebraic by its equality formula, so the generic type is omitted in the original model. If \(|M|>\max(|A|,|L|,\aleph_0)\), the closure cardinal bound guarantees a point outside algebraic closure and hence a generic realization already in \(M\).

Are inequalities against the parameter names enough?

Take the complete theory of an infinite equality structure with one constant symbol \(c\), and let \(A=\varnothing\). Is the empty list of conditions \(\{x\ne a:a\in A\}\) already a complete generic type?

Show answerHide answer

No. The symbol \(c\) belongs to the original language, even when no parameter names are added. The named-point calculation gives \(\operatorname{acl}_M(\varnothing)=\{c^M\}\). There is an algebraic type containing \(x=c\), and a different generic type containing \(x\ne c\). The empty collection decides neither formula and so is not a complete type.

Here the generic type is determined by \(x\ne c\), using equality quantifier elimination. In general it is the collection of all cofinite formulas, rather than merely inequalities against additional parameter names.
