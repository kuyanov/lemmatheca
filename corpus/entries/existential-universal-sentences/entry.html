Witnesses first, arbitrary elements afterwards

A relational language with constants has relation symbols, equality, and constant symbols, but no function symbol of positive arity. A Bernays–Schönfinkel sentence is a sentence in such a language of the form

\[\sigma=\exists x_1\cdots\exists x_m\,\forall y_1\cdots\forall y_n\,\theta(\bar x,\bar y),\]

where the matrix \(\theta\) is quantifier-free. Either block of quantifiers may be empty. Domains are nonempty, and constants need not denote different elements. A model of \(\sigma\) is a structure in which \(\sigma\) is true; \(\sigma\) is satisfiable if it has a model.

Only finitely many symbols occur in a sentence. For algorithmic inputs, fix a finite presentation: constants are numbered from \(0\) to \(c-1\), relation symbols are numbered from \(0\) to \(s-1\), and a finite list records their arities. These symbol numbers give the effective signature used by the syntax codes. An expression written with other finitely many symbol names can first be renamed using a finite symbol table; no algorithm for an arbitrary unpresented abstract vocabulary is assumed. We work with that finite occurring vocabulary and write \(c\) for its number of constants. Unused symbols can be restored afterwards: give every extra constant any domain element and every extra relation, for example, the empty interpretation. Thus satisfiability in the occurring vocabulary is equivalent to satisfiability in the full original relational language.

Restricting a relational structure

Let \(A\) be a structure and let \(D\subseteq A\) be nonempty and contain the interpretation of every constant. The induced structure on \(D\) keeps those constant values and interprets each \(r\)-ary relation by

\[R^D=R^A\cap D^r.\]

Equality is actual equality on \(D\). This is a substructure: a term is either a variable or a constant, so all its values stay in \(D\). No closure under further operations is required. If the language had a unary function, an arbitrary subset containing the constants would generally fail this closure condition.

Quantifier-free truth does not change

For an induced structure \(D\subseteq A\), a quantifier-free formula \(\theta\), and an assignment \(v\) taking all its variables into \(D\),

\[D\models\theta[v]\quad\Longleftrightarrow\quad A\models\theta[v].\]

Every term is a variable or a constant and therefore has the same value in the two structures. An equality of two terms has the same truth value because inclusion of \(D\) is injective. A relation application has the same truth value by the definition of the induced relations. Falsity has the same truth value. Induction through the Boolean connectives completes the argument: in the primitive syntax, if both children agree, their implication agrees. This proves the assertion for negations and all the other connective abbreviations as well. Quantifiers were excluded: \(\exists z\,(z\ne x)\) can hold in \(A\) and fail in its singleton substructure.

A bounded model contains all necessary witnesses

If a Bernays–Schönfinkel sentence with \(m\) leading existential quantifiers and \(c\) occurring constants is satisfiable, it has a nonempty finite model with at most \(\max(1,m+c)\) elements.

Let \(A\models\sigma\). Choose witnesses \(a_1,\ldots,a_m\) for the existential block and let \(d_1,\ldots,d_c\) be the interpretations of the constants. Put \(D_0=\{a_1,\ldots,a_m,d_1,\ldots,d_c\}\). Repeated values are listed only once, so \(|D_0|\le m+c\). If \(D_0\ne\varnothing\), take \(D=D_0\). If \(D_0=\varnothing\), choose one element of the nonempty domain of \(A\) and let \(D\) be its singleton. In either case \(D\) contains every required value and \(1\le |D|\le\max(1,m+c)\).

Give \(D\) its induced structure. Retain the witnesses \(a_i\). Every universal tuple \(\bar b\in D^n\) is also a tuple in \(A^n\), so \(A\models\theta[\bar a,\bar b]\). The restriction lemma gives \(D\models\theta[\bar a,\bar b]\). This holds for every \(\bar b\), proving the universal block in \(D\), and its existential witnesses prove \(D\models\sigma\).

The quantifier order matters: all existential witnesses were chosen before the universal tuple. The construction retains a fixed finite list of witnesses; it need not supply new ones in response to each possible universal choice.

Why are constants counted in the bound?

Can the preceding bound always be replaced by \(\max(1,m)\), even when the original language contains constants?

Show answerHide answer

No. The sentence \(d_1\ne d_2\) has no existential quantifiers but needs at least two elements. More generally \(\bigwedge_{i<j\le c}d_i\ne d_j\) needs at least \(c\) elements. Existential witnesses may also be required to be distinct from all the constants and from one another, giving a sentence that needs exactly \(m+c\) elements whenever \(m+c>0\). When \(m=c=0\), the true sentence \(\top\) still requires a nonempty model under our convention; the extra \(1\) handles precisely that boundary.

One can eliminate the constants before applying the constant-free theorem: replace each occurring constant by a fresh variable and put existential quantifiers for those variables at the front. There are now \(m+c\) existential variables. This preserves satisfiability, because a choice of their values is exactly a choice of the old constant interpretations. It does not justify using the old value of \(m\).

Writing every bounded structure as finite data

For \(d\ge1\), a labelled structure of size \(d\) has domain \(\{0,\ldots,d-1\}\). Its structure table consists of a value below \(d\) for every constant and one bit for every tuple of each relation. Tuples are listed lexicographically. Thus for relation symbols of arities \(r_1,\ldots,r_s\), there are exactly

\[d^c\,2^{\,d^{r_1}+\cdots+d^{r_s}}\]

tables. Nullary relations, if present, contribute one bit because \(d^0=1\). A finite structure with \(d\) elements can be relabelled by a bijection with this domain. Under that bijection every term value and every atomic truth value is transported, and induction through connectives and quantifiers transports truth of every sentence. Consequently every model of size \(d\) has an isomorphic labelled model represented by one of these tables.

Truth in a table is a terminating calculation

Given a finite vocabulary, a structure table on a nonempty domain of size \(d\), and a sentence \(\varphi\), its truth is computed by recursion on \(\varphi\).

A variable is evaluated at its assigned value and a constant by its table entry. Compare term values to evaluate equality, and look up the appropriate tuple bit to evaluate a relation. Falsity returns \(0\); implication returns \(\neg b\lor b'\) from its two child truth values. For \(\forall z\,\psi\), append each of \(0,\ldots,d-1\) to the assignment and take the conjunction of the resulting \(d\) body truth values. An existential quantifier uses disjunction instead. The finite domain makes each loop finite; each recursive call evaluates a strictly smaller syntax tree.

Induction on terms proves the computed term values correct. Structural induction on formulas then proves the computed bit equals its truth value under every assignment. In the universal step the loop checks exactly every possible value of the newly bound placeholder, which is the universal truth clause. The connective and atomic cases are their corresponding truth clauses. The outer sentence has no free names, so the result needs no supplied assignment.

A finite search decides satisfiability

There is a terminating algorithm that, on input a Bernays–Schönfinkel sentence, returns \(1\) exactly when the sentence is satisfiable, and \(0\) otherwise. A sentence in this fragment has a model if and only if it has a finite model.

Read the finite occurring vocabulary, the prefix, and its quantifier-free matrix from the input. The input consists of the finite signature header, the two prefix lengths, and the code of a matrix at the corresponding placeholder depth. Check that its terms are variables or constants and its formulas are quantifier-free. Equality, repeated variable occurrences, and empty quantifier blocks are permitted. If the input instead supplies the whole sentence, read its displayed prefix using the fixed canonical expansion \(\exists z\,A=\neg\forall z\,\neg A\); the header and prefix lengths fix which occurrences form that prefix. Reject a failed syntax check. Put \(N=\max(1,m+c)\). For \(d=1,\ldots,N\), enumerate all structure tables and compute the truth of the input sentence by finite model checking. Return \(1\) as soon as a table satisfies it, and \(0\) after the list is exhausted.

The input syntax tree is finite; its symbol and prefix scans terminate. The outer sizes, tables, assignments and formula traversals are finite, so the algorithm terminates. If it returns \(1\), the accepted table is a nonempty model. Conversely, a satisfiable input has a model of some size \(1\le d\le N\) by the bounded-model theorem. Relabel it onto \(\{0,\ldots,d-1\}\). Its table occurs in the search, and the model checker accepts it. A return of \(0\) therefore proves unsatisfiability, not just failure to find a small example.

This algorithm acts on the shared first-order syntax codes. Each constructor is read from its tag and finite child list. A variable or constant is a leaf; relation and equality nodes use their child term codes; implication and universal nodes use their child formula codes. The fixed negation and existential abbreviations are expanded using those same constructors. A bound on the syntax-tree height supplied by the numerical code makes this a recursive finite traversal, including on malformed inputs. Thus the procedure is a genuine computation on finite expressions, rather than an appeal to the law of excluded middle for the statement that a model exists.

Testing a small sentence by hand

Over a language with one unary relation \(P\), determine whether

\[\exists x\exists z\forall y\,\bigl(P(x)\land\neg P(z)\land(y=x\lor y=z)\bigr)\]

is satisfiable. What changes if the last disjunction is replaced by \(y=x\land y=z\)?

Show answerHide answer

The bound is \(2\). No singleton works: both witnesses would be the same element, which cannot both satisfy and fail \(P\). On \(\{0,1\}\), let \(P=\{0\}\), choose \(x=0\) and \(z=1\), and check both universal values. This is a model. With the conjunction, nonemptiness lets us choose a value of \(y\); it must equal both witnesses. Hence \(x=z\), contradicting \(P(x)\land\neg P(z)\). No model exists, so the finite search rejects every table.

Which hypotheses keep the bound finite?

Must satisfiable sentences still have finite models if positive-arity functions are allowed, or if an existential quantifier follows a universal quantifier?

Show answerHide answer

Neither extension preserves the assertion. In a language with a constant \(a\) and unary function \(f\), the universal sentence

\[\forall x\forall y\,\bigl((f(x)=f(y)\to x=y)\land f(x)\ne a\bigr)\]

has the natural-number model \(a=0\), \(f(n)=n+1\). It has no nonempty finite model: an injective self-map of a finite set is surjective, contradicting omission of \(a\). A finite subset need not be closed under \(f\).

For the quantifier-order boundary, use a binary relation \(R\). The sentence

\[\forall x\forall z\forall w\exists y\,\bigl(\neg R(x,x)\land((R(x,z)\land R(z,w))\to R(x,w))\land R(x,y)\bigr)\]

says that \(R\) is irreflexive, transitive, and has a strict successor above every element. Nonemptiness allows unused variables to be filled when extracting these three assertions. The usual strict order on \(\mathbb N\) is a model. A finite model is impossible: starting at any element and repeatedly choosing a larger one yields a repetition, while transitivity and irreflexivity forbid a cycle. Here witnesses for \(y\) depend on the universally chosen \(x\); retaining a single finite witness tuple is no longer enough.

The unary case behaves differently: with equality but no constants or functions, monadic sentences have bounded finite models even with arbitrary quantifier alternation. Its profile argument supplies the representatives needed when witnesses depend on previous choices.
