A path may have computably bounded numerical computations

Use the coded binary trees \(T\subseteq2^{<\omega}\), with \([T]=\{A:\forall n\;(A\mathbin{\upharpoonright}n\in T)\}\). A hyperimmune-free path is \(A\in[T]\) such that every total \(f:\mathbb N\to\mathbb N\) computed by an actual finite \(A\)-oracle program has a total computable eventual bound. This is exactly hyperimmune-freeness of the path's set of one-positions.

By the finite-exception patch, eventual bounds can equivalently be replaced by pointwise majorants. The function-graph bridge identifies these numerical computations with their coded graph oracles. Write \(\Phi_e^A(x)\) for evaluation in the fixed oracle-program numbering.

Turn one arbitrary-input computation into a diagonal computation

There is an ordinary primitive-recursive numerical map \(j(e,x)\), fixed before the oracle varies, with

\[\Phi_{j(e,x)}^A(z)\simeq\Phi_e^A(x)\qquad\text{for all }A,e,x,z.\]

In particular the diagonal computation at \(z=j(e,x)\) has the same output, or diverges, together with \(\Phi_e^A(x)\).

Use the existing input-freezing compiler: form the actual program \(\operatorname{comp}(c_e,\mathsf{const}(x))\) and take its index. The constant subprogram ignores \(z\) and returns \(x\); strict composition then performs exactly the specified \(e\)-computation. The numerical constructors and constant-code map are primitive recursive, proving both uniformity and the entire partial-value identity.

Keep the nodes that have not yet certified a chosen computation

Let \(C(\sigma,d,y)\) be the finite-prefix certificate value: zero means no successful certificate at allowance \(|\sigma|\), while \(v+1\) certifies output \(v\). This allowance bounds the actual finite evaluation as well as the available oracle prefix.

For a binary tree \(S\), define its divergence subtree at \((e,x)\) by

\[D(S,e,x)=\{\sigma\in S:C(\sigma,j(e,x),j(e,x))=0\}.\]

This is precisely the existing divergence restriction with the singleton list \([j(e,x)]\). More generally retain the notation \(T_L=\{\sigma\in T:\forall d\in L\;C(\sigma,d,d)=0\}\) for any finite list \(L\).

The computable subtree represents exactly divergence on the original input

For a binary tree \(S\), \(D(S,e,x)\) is a binary subtree of \(S\), and

\[[D(S,e,x)]=\{A\in[S]:\Phi_e^A(x)\uparrow\}.\]

If \(S\) is computable, this subtree is computable as well.

If a prefix \(\tau\preceq\sigma\) of a retained node had a positive certificate, persistence of successful certificates would make the certificate at \(\sigma\) positive too. Prefix closure of \(S\) also puts \(\tau\) in \(S\), so the set is a binary subtree. When a decider for \(S\) is supplied, run it and the one primitive-recursive certificate test to decide membership in the subtree.

For a path \(A\) through this subtree, every prefix has zero certificate. If \(\Phi_e^A(x)\) halted, the frozen diagonal computation would halt with the same value, and finite-prefix completeness would give a positive certificate at a prefix of \(A\), a contradiction. Conversely a positive certificate at a prefix of \(A\in[S]\) is sound for \(A\); the frozen identity would then make \(\Phi_e^A(x)\) halt. If that computation diverges, all prefixes therefore remain in the subtree. This proves the exact equality for the original input \(x\).

Test one finite level for successful certificates everywhere

For a binary tree \(S\), define the successful-level test

\[G_S(e,x,m)\quad\Longleftrightarrow\quad\forall\sigma\in S\cap2^m\;C(\sigma,j(e,x),j(e,x))>0.\]

When \(S\) is computable, this is a total computable Boolean test jointly in \((e,x,m)\), using its supplied decider. List the finitely many binary words of length \(m\), discard those outside \(S\), and inspect the remaining certificate values. The empty level passes the test vacuously.

Halting on every path supplies a successful finite level

If \(S\) is a binary tree and \(\Phi_e^A(x)\) halts for every \(A\in[S]\), then \(G_S(e,x,m)\) holds for some \(m\).

The characterization says that \(D(S,e,x)\) has no path. If every one of its levels were nonempty, binary branch existence would give a path. Hence it has an empty level \(m\).

A word \(\sigma\in S\cap2^m\) with zero certificate would lie in that supposedly empty level of \(D(S,e,x)\). Therefore every such certificate is positive, exactly \(G_S(e,x,m)\). If \([S]\) itself is empty, the same argument still works; an empty level of \(S\) is already a successful level.

Search a level and maximize its certified outputs

Fix an ordinary decider index \(t\) for \(S\), so \(\varphi_t(u)\downarrow=\chi_S(u)\) on every word code. The finite-level bound search \(V(t,e,x)\) tests \(m=0,1,2,\ldots\) until \(G_S(e,x,m)\) first holds. At that level it returns

\[\max\Bigl(\{0\}\cup\{C(\sigma,j(e,x),j(e,x))-1:\sigma\in S\cap2^m\}\Bigr).\]

This is one ordinary partial-recursive algorithm: every finite level test terminates, and sequential search waits for a successful one. Its finite maximum is zero when the level is empty. Fix one ordinary index \(v\) for the joint algorithm on input \(\langle\langle t,e\rangle,x\rangle\). The actual specialization map gives the primitive-recursive compiler \(q(t,e)=s(v,\langle t,e\rangle)\), with

\[\varphi_{q(t,e)}(x)\simeq V(t,e,x).\]

The program index is formed from the supplied decider and \(e\) before \(x\) or a path varies. It asks no infinite-path questions. When the search terminates for every \(x\), denote its resulting total function by \(h_{S,e}\).

Totality on a computable path class gives one computable output bound

Let \(S\) be a computable binary tree with a supplied decider \(t\). If \(\Phi_e^A(x)\) is defined for every \(A\in[S]\) and every \(x\), then the specified program \(q(t,e)\) is total. Its total computable function \(h_{S,e}\) satisfies

\[A\in[S]\text{ and }\Phi_e^A(x)\downarrow=y\quad\Longrightarrow\quad y\le h_{S,e}(x).\]

For each input \(x\), supplies a successful level, so the ordinary sequential search terminates. This proves totality of the one program \(q(t,e)\), rather than choosing an unrelated bound separately for each input.

Let \(m\) be its first successful level at \(x\). A path \(A\in[S]\) has prefix \(\sigma=A\mathbin{\upharpoonright}m\) in the finite maximum. Its certificate is positive; write it as \(v+1\). Soundness gives \(\Phi_{j(e,x)}^A(j(e,x))\downarrow=v\), and the frozen identity gives \(\Phi_e^A(x)\downarrow=v\). Uniqueness of the output gives \(v=y\). That value is one of the maximized numbers, proving the bound simultaneously for every path. For an empty path class totality still follows from the finite-level argument, while the asserted pathwise bound is vacuous.

At each functional, force a divergence if some path permits it

Fix a computable binary tree \(T\) with \([T]\ne\varnothing\). Define its hyperimmune-free restriction history \(L_e\) and trees \(T_e=T_{L_e}\) by \(L_0=[]\) and the following rule. At stage \(e\), ask the mathematical question

\[\exists x\quad[T_{j(e,x)::L_e}]\ne\varnothing.\]

If it holds, let \(x_e\) be the least such \(x\), and put \(L_{e+1}=j(e,x_e)::L_e\). If it fails, put \(L_{e+1}=L_e\). Here \(T_{j(e,x)::L_e}=D(T_e,e,x)\), since its tests retain every old restriction and add that one frozen computation.

The choice of the least \(x\) specifies a sequence mathematically; no computable procedure for answering the displayed question is asserted. Each particular \(L_e\) is nevertheless a finite list of natural numbers.

The trees remain computable and nonempty, and each stage resolves one functional

For every \(e\), \(T_e\) is a computable binary tree with a nonempty path class, and \(T_{e+1}\subseteq T_e\). Moreover at stage \(e\) exactly the rule's following alternative is obtained: either some \(x_e\) satisfies \(\Phi_e^A(x_e)\uparrow\) for every \(A\in[T_{e+1}]\), or \(T_{e+1}=T_e\) and the function \(h_{T_e,e}\) is a computable bound on \(\Phi_e\)'s outputs on every path of \(T_e\).

Induct on \(e\), starting with \(T_0=T\). Every finite restriction is a computable binary subtree. In the first branch the selected class is nonempty by its defining choice. Its characterization gives divergence at \(x_e\) on every retained path. Adding one restriction gives the inclusion into the old tree.

In the second branch no input permits a divergent path. Thus for each \(A\in[T_e]\) and each \(x\), \(\Phi_e^A(x)\) is defined. The uniform output-bound theorem supplies the specified total computable \(h_{T_e,e}\), while the tree is unchanged and remains nonempty. This proves the whole induction invariant. A fixed stage has a decider obtained from the initial decider and its finite list \(L_e\); the induction does not make these lists or deciders computable uniformly in \(e\).

All the selected restrictions have a common infinite path

There is a set \(A\) that belongs to \([T_e]\) at every stage.

For a fixed length \(n\), the sets \(T_e\cap2^n\) are nonempty and decrease inside the same finite set \(2^n\). Their intersection is nonempty: otherwise each word in the initial finite level would disappear at some stage, and taking the maximum of those finitely many stages would produce an empty later level.

Consequently \(T_\infty=\bigcap_eT_e\) is a binary tree with a node at every length. Binary branch existence gives a path through it, hence through every \(T_e\). This is exactly the earlier descending-level compactness lemma; it requires neither a computable intersection tree nor an effective sequence of the trees.

Every infinite computable binary tree has a hyperimmune-free path

If \(T\) is a computable binary tree with a node at every length, then some \(A\in[T]\) is hyperimmune-free.

Binary branch existence makes \([T]\) nonempty, so form the histories and take a common path \(A\). It belongs to \(T_0=T\). Suppose an actual \(A\)-oracle program \(c\) computes a total numerical function \(f\). The fixed numbering supplies its actual index \(e=\#c\), with \(\Phi_e^A(x)\downarrow=f(x)\) for every \(x\).

Stage \(e\) cannot have taken the divergence branch: since \(A\in[T_{e+1}]\), that branch would make this same computation diverge at \(x_e\), contradicting totality. It therefore took the second branch. Its ordinary computable function \(h_{T_e,e}\) bounds the outputs on every path of \(T_e\), in particular \(f(x)\le h_{T_e,e}(x)\) for all \(x\). Every total numerical function computed from \(A\) thus has a computable majorant, proving hyperimmune-freeness. The bounding function is allowed to depend on the program.

Every nonempty effectively closed binary class has a hyperimmune-free member

Every nonempty effectively closed class of binary sequences has a hyperimmune-free member. The same holds for the nonempty path class of a co-c.e. binary tree.

The established computable-tree representation gives a computable binary tree with exactly the specified class of paths. Nonemptiness supplies a node at every length, so applies, preserving membership in that same class. For a co-c.e. tree, first use the same-path conversion to a computable tree. Both transfers concern infinite paths; the finite trees need not be equal.

There are noncomputable hyperimmune-free paths of PA degree

There is a noncomputable hyperimmune-free set \(A\) whose characteristic function is binary diagonally noncomputable. This same \(A\) has PA degree: it computes the coded theorem set of a complete consistent deductively closed extension of actual Peano arithmetic.

Use the existing computable separator tree for the canonical disjoint diagonal pair. It has a node at every length, and its paths are exactly the binary DNC sets. Apply the hyperimmune-free basis theorem to this very tree. The resulting path \(A\) is binary DNC and hyperimmune-free. The diagonal argument makes it noncomputable. Since it computes itself, the established PA-degree characterization says that it computes such a complete consistent arithmetic extension. This uses the already specified set-of-sentence-codes interpretation of PA degree.

A noncomputable hyperimmune-free set is not below ordinary halting

If \(A\) is noncomputable and hyperimmune-free, then \(A\not\le_TK\), and \(A\) is not low. In particular the hyperimmune-free binary DNC and PA set from has both properties.

Every noncomputable set below \(K\) has hyperimmune degree, which excludes hyperimmune-freeness. Therefore \(A\not\le_TK\). A low set satisfies \(A'\equiv_TK\) and \(A\le_TA'\), hence \(A\le_TK\); this is impossible for the present \(A\). Thus a noncomputable set cannot be both low and hyperimmune-free. The low basis theorem and the hyperimmune-free basis theorem need not select the same member of a path class.
