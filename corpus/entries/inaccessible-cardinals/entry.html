Two ways a cardinal can be inaccessible

A limit stage of the rank hierarchy can contain pairs, unions and power sets without automatically collecting the range of every internally defined function. The missing issue is whether a set of output ranks can approach the height of the stage. We work throughout in ambient ZFC, and identify each cardinal with its initial ordinal.

An uncountable cardinal \(\kappa\) is weakly inaccessible if it is regular and a limit cardinal. It is strongly inaccessible if it is regular and a strong limit:

\[2^\mu<\kappa\qquad\text{for every cardinal }\mu<\kappa.\]

A limit cardinal is a nonzero cardinal that is not a successor cardinal. These definitions impose properties on a supplied cardinal; they do not assert that such cardinals exist.

In the remainder of the entry, “inaccessible” means strongly inaccessible. The two ingredients will have different jobs: the power-set bound controls sizes at successor stages, and regularity bounds unions and output ranks.

A strong limit cannot be a successor cardinal

Every strongly inaccessible cardinal is weakly inaccessible.

If \(\kappa=\mu^+\), then \(\mu<\kappa\). Cantor's theorem gives \(\mu<2^\mu\), so the definition of successor cardinal yields \(\kappa\le 2^\mu\). This contradicts the strong-limit inequality. Uncountability and regularity are already part of the hypotheses.

For comparison, \(\aleph_0\) is regular and a strong limit, because the power set of a finite set is finite. It is excluded by the uncountability requirement. The first uncountable cardinal is regular, but it is not a strong limit: \(2^{\aleph_0}\ge\aleph_1\).

Every earlier rank stage has size below the inaccessible height

If \(\kappa\) is inaccessible, then

\[|V_\beta|<\kappa\qquad(\beta<\kappa).\]

Use transfinite induction on \(\beta<\kappa\). The initial stage is empty, so its size is zero. At a successor stage, the induction hypothesis and the strong-limit condition give

\[|V_{\gamma+1}|=|\mathcal P(V_\gamma)|=2^{|V_\gamma|}<\kappa.\]

At a nonzero limit \(\beta<\kappa\), the stage is \(\bigcup_{\gamma<\beta}V_\gamma\). There are \(|\beta|<\kappa\) indices, and every member of this family has size below \(\kappa\) by induction. The small-union characterization of regularity therefore gives the required bound for their union. These are all cases of the rank recursion.

This controls the size of an entire rank stage, not just the cardinality of an ordinal below \(\kappa\).

Every object in the rank model is externally small

If \(x\in V_\kappa\), then \(|x|<\kappa\).

Put \(\rho=\operatorname{rank}(x)\). The rank characterization gives \(\rho<\kappa\), and every member of \(x\) has rank below \(\rho\). Thus \(x\subseteq V_\rho\), including the case \(x=\varnothing\). Consequently

\[|x|\le |V_\rho|<\kappa\]

by the stage-size bound.

Fewer than kappa many output ranks have a common bound

Suppose \(\kappa\) is regular uncountable, \(|I|<\kappa\), and a set-indexed family \((y_i)_{i\in I}\) consists of members of \(V_\kappa\). Then its range \(Y=\{y_i:i\in I\}\) belongs to \(V_\kappa\).

Every \(\operatorname{rank}(y_i)+1\) is below \(\kappa\), since an infinite initial ordinal is a limit ordinal. Replacement forms their set \(B\), whose cardinality is at most \(|I|<\kappa\). By regularity, \(B\) is bounded below \(\kappa\), so

\[\gamma=\sup B<\kappa.\]

For nonempty \(I\), the inequalities \(\operatorname{rank}(y_i)+1\le\gamma\) put every \(y_i\) in \(V_\gamma\). Hence \(Y\subseteq V_\gamma\), and \(\operatorname{rank}(Y)\le\gamma<\kappa\). If \(I\) is empty, then \(Y=\varnothing\), whose rank is zero. In both cases \(Y\in V_\kappa\).

Only regularity is used in this lemma. Inaccessibility will supply its small index set when \(I\) is an object of the rank model.

Internal functional definitions have ranges inside the stage

For inaccessible \(\kappa\), the actual-membership structure \((V_\kappa,\in)\) satisfies every instance of Replacement.

Fix one membership-language formula \(\varphi(a,b,\bar p)\), parameters \(\bar p\in V_\kappa\), and \(x\in V_\kappa\). Suppose the structure satisfies that every \(a\in x\) has exactly one output \(b\) satisfying \(\varphi\).

By set-domain relativization, this says in the ambient universe that each actual \(a\in x\) has a unique \(b\in V_\kappa\) with \(\varphi^{V_\kappa}(a,b,\bar p)\). Transitivity ensures that all members of \(x\) are available in the domain. The relativized condition is an ordinary fixed formula with the set \(V_\kappa\) as an additional parameter. Ambient Replacement therefore collects its unique outputs into a set \(Y\).

By the smallness of members, \(|x|<\kappa\). Apply the output-rank bound to this family indexed by \(x\). It yields \(Y\in V_\kappa\). For every \(b\) in the domain,

\[b\in Y\quad\Longleftrightarrow\quad (V_\kappa,\in)\models\exists a\in x\,\varphi(a,b,\bar p).\]

Thus this very set is a witness to the internal Replacement instance. The argument works for each fixed formula and every allowed parameter tuple.

The membership axioms and Infinity have their actual witnesses

For inaccessible \(\kappa\), the structure on \(V_\kappa\) satisfies Extensionality, Foundation, Empty Set, Pairing, Union and Infinity.

The cardinal \(\kappa\) is a nonzero limit ordinal. The limit-stage axiom checks therefore apply. In detail, transitivity makes internal membership in each object its full actual membership, so ambient Extensionality identifies objects with the same members. Ambient Foundation supplies an actual membership-minimal member of each internally nonempty object; transitivity puts that witness in the domain.

The empty set has rank zero. For \(x,y\in V_\kappa\), the pair has rank \(\max(\operatorname{rank}(x),\operatorname{rank}(y))+1<\kappa\); the union of \(x\) has rank at most \(\operatorname{rank}(x)<\kappa\). These actual sets therefore witness the corresponding internal axioms. Finally \(\omega\in V_\kappa\), since its rank is \(\omega<\kappa\). Its zero and finite successors are all present, with their actual membership equations, so it witnesses Infinity.

Separation uses the relativized formula on an existing set

The structure on \(V_\kappa\) satisfies every instance of Separation.

Fix a formula \(\psi(a,\bar p)\), its parameters from the domain, and \(x\in V_\kappa\). Ambient Separation forms

\[z=\{a\in x:\psi^{V_\kappa}(a,\bar p)\}.\]

Because \(z\subseteq x\), its rank is at most the rank of \(x\), so \(z\in V_\kappa\). Relativized satisfaction identifies its defining condition with the required internal formula. This supplies the actual desired subset for every fixed instance, even when \(\psi\) has unbounded quantifiers.

Here the outputs are already bounded by \(x\). Replacement needed a separate bound on the ranks of its outputs.

The internal power set contains every ambient subset

For \(x\in V_\kappa\), the actual \(\mathcal P(x)\) belongs to \(V_\kappa\) and is its internal power set of \(x\).

Write \(\rho=\operatorname{rank}(x)<\kappa\). The power set has rank \(\rho+1<\kappa\). Every actual subset \(z\subseteq x\) has rank at most \(\rho\), so it too lies in the domain. At every candidate \(z\) in that domain, the bounded subset test agrees with actual inclusion. Thus the members of the actual power set are exactly the candidates required by the internal Power Set axiom. There are no missing ambient subsets.

A relation on an object still has rank below the height

If \(\kappa\) is an infinite limit ordinal, \(x\in V_\kappa\), and \(R\subseteq x\times x\), then \(R\in V_\kappa\). Use the usual Kuratowski ordered pairs.

Let \(\rho=\operatorname{rank}(x)<\kappa\). For \(a,b\in x\), the ordered pair \(\langle a,b\rangle=\{\{a\},\{a,b\}\}\) has rank \(\max(\operatorname{rank}(a),\operatorname{rank}(b))+2\), hence rank at most \(\rho+2\). The rank equation consequently gives \(\operatorname{rank}(R)\le\rho+3\). Every finite successor of an ordinal below a limit remains below that limit, so \(\rho+3<\kappa\). The rank criterion puts \(R\) in \(V_\kappa\). The bound is deliberately sufficient rather than sharp.

An ambient well-order is an internal witness to Choice

For inaccessible \(\kappa\), the structure on \(V_\kappa\) satisfies the well-ordering principle and hence Choice.

Take \(x\in V_\kappa\). Ambient Choice provides a strict well-order \(R\subseteq x\times x\). The relation-rank bound gives \(R\in V_\kappa\). Its ordered pairs and their membership tests have the same meanings internally: their constituents have rank below \(\kappa\), and the defining bounded membership conditions are absolute.

Irreflexivity, transitivity and linear comparison therefore hold internally. Any internally considered nonempty subset \(A\subseteq x\) is an actual nonempty subset of \(x\). The ambient well-order has a least element \(a\in A\), and transitivity puts \(a\) in the domain. Its leastness against every element of \(A\) is unchanged. Thus \(R\) is an internal well-order of \(x\). Indeed every actual subset of \(x\) is available, though only the stated direction is needed.

We have already verified all the ZF axioms in this structure, including each Replacement and Separation instance. The ZF proof from well-ordering to Choice consequently applies inside it. This use of ambient Choice has been explicit from the start.

An inaccessible height gives a transitive model of ZFC

In ambient ZFC, if \(\kappa\) is strongly inaccessible, then the nonempty transitive actual-membership structure \((V_\kappa,\in)\) satisfies ZFC, including every instance of Separation and Replacement.

The rank hierarchy gives a transitive set, and the empty set makes it nonempty. The preceding axiom checks establish Extensionality, Foundation, Empty Set, Pairing, Union, Infinity, Power Set and Choice. For each fixed formula the Separation and Replacement constructions establish its corresponding instance with arbitrary parameters in the domain. These are exactly the asserted axioms and schemas.

This is a conditional model construction from the supplied inaccessible cardinal. It does not produce such a cardinal from the axioms used in the proof, and it asserts no converse characterization of all heights whose rank stages satisfy ZFC.

Where do the three parts of inaccessibility enter?

Why are uncountability, regularity and the strong-limit condition all visible in the proof? Would the regular strong-limit cardinal \(\aleph_0\) suffice?

Show answerHide answer

The strong-limit condition bounds the cardinality of a successor rank stage. Regularity bounds limit-stage unions and then the set of output ranks in Replacement. The stage-size induction combines these facts to show that every object of \(V_\kappa\) has size below \(\kappa\).

Uncountability ensures \(\omega<\kappa\), so the stage contains \(\omega\) itself as an Infinity witness. At \(\kappa=\omega\), the domain is \(V_\omega\), the hereditarily finite sets. Every internally inductive member would contain all finite ordinals, hence would be infinite; no member of this domain can do that. Thus dropping uncountability already loses Infinity, despite regularity and the strong-limit property.

How does this differ from finite-family reflection?

Reflection produced a rank model of each fixed finite axiom fragment. What additional conclusion is supplied by a given inaccessible height?

Show answerHide answer

At the single supplied height \(\kappa\), the same cardinal and rank estimates verify each Separation and Replacement instance, whatever its fixed formula and parameters. Thus every axiom of the full theory holds in this one set structure. The height does not change with the instance.

The earlier reflection construction starts from a finite list and selects a height appropriate to that list. It supplies no single common height from those separate choices. Inaccessibility is an additional hypothesis that makes the uniform choice of the one height possible in the present argument. Neither proof justifies exchanging the quantifiers in the other, and no existence theorem for inaccessible cardinals has been supplied.
