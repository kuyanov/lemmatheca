A tree has a well-ordered history below each node

Work in ZFC. A tree is a partially ordered set \((T,\le_T)\) such that for each \(t\in T\), its strict predecessors \(\{s:s<_Tt\}\) are well-ordered by \( <_T\). The height of \(t\), written \(\operatorname{ht}(t)\), is the order type of that predecessor set. The \(\alpha\)-th level is \(T_\alpha=\{t:\operatorname{ht}(t)=\alpha\}\), and the height of the tree is

\[ \operatorname{ht}(T)=\sup\{\operatorname{ht}(t)+1:t\in T\}. \]

The empty tree has height zero. A tree need not have a unique root: its level zero consists of all nodes with no predecessor.

For each \(\beta<\operatorname{ht}(t)\), there is exactly one predecessor of \(t\) at level \(\beta\). Indeed, enumerate the predecessors in their well-order; those preceding its \(\beta\)-th member are exactly that member's own predecessors, so its height is \(\beta\). In particular, if one level is nonempty, every smaller level is nonempty. If \(s<_Tt\), then \(\operatorname{ht}(s)<\operatorname{ht}(t)\).

Branches follow one history and antichains separate histories

A chain is a subset whose members are pairwise comparable. A branch here means a downward-closed chain: whenever it contains \(t\), it contains every predecessor of \(t\). An antichain is a subset whose distinct members are incomparable. Each level is an antichain, and a branch has at most one node at each level.

A branch is cofinal if it meets every level below the height of the tree. At a limit height this is equivalent to its node heights being unbounded: the unique predecessors fill every smaller level. Its order type is then the height of the tree.

Some authors reserve “branch” for a maximal chain. A maximal chain in a tree is automatically downward closed, since any missing predecessor is comparable with every member and could be added. Our convention also permits shorter downward-closed chains. The assertion that a cofinal branch exists is the same under either convention: a chain meeting every level cannot be enlarged, because there is already one node at the level of any proposed new member.

Initial segments of functions form trees

For a nonempty set \(X\) and an ordinal \(\theta\), let \(X^{<\theta}\) be the functions \(s:\alpha\to X\) with \(\alpha<\theta\), ordered by extension of their graphs. The strict predecessors of \(s\) are exactly \(s\mathbin{\upharpoonright}\beta\), \(\beta<\alpha\), in that order. Thus its height is its domain \(\alpha\), and this tree has height \(\theta\). A subfamily closed under restrictions is also a tree, with the same heights for its members.

The binary tree \(2^{<\omega}\) consists of finite words in zero and one. Level \(n\) has \(2^n\) nodes, and their countable union is countable. Every infinite binary sequence \(x\) gives the cofinal branch \(\{x\mathbin{\upharpoonright}n:n<\omega\}\), and every cofinal branch arises uniquely this way by taking its union. Consequently a countable tree can have continuum many cofinal branches.

The words \(0,10,110,1110,\ldots\) form an infinite antichain: no one is an initial segment of another. The words \(\varnothing,0,00,000,\ldots\) form a cofinal branch. The sets of binary prefixes use precisely these paths through finite words.

König's lemma gives a cofinal branch when every finite level is finite

If a tree \(T\) has height \(\omega\) and every level \(T_n\) is finite, then \(T\) has a cofinal branch, containing one node at every level.

Proof

The tree is infinite, since every finite level is nonempty. Every node lies above a unique root in the finite set \(T_0\). Partitioning \(T\) by those roots, the finite pigeonhole principle gives a root \(t_0\) with infinitely many descendants, counting itself.

Suppose \(t_n\in T_n\) has infinitely many descendants. Its strict descendants are partitioned by their unique ancestors at level \(n+1\). Only finitely many such ancestors exist, because \(T_{n+1}\) is finite. One, call it \(t_{n+1}\), must itself have infinitely many descendants. It lies strictly above \(t_n\).

Recursively choose these nodes, using a fixed well-order of \(T\) to select the least eligible one at each stage. Then \(t_0<_Tt_1<_T\cdots\). The predecessors of \(t_n\) are exactly \(t_0,\ldots,t_{n-1}\), by uniqueness at each level. Thus \(\{t_n:n<\omega\}\) is downward closed and meets every level. □

No unique-root assumption or extension condition on every node is required. At each step the proof follows a node with infinitely many descendants.

What happens if the finite levels are merely countable?

Does a tree of height \(\omega\) with countable levels necessarily have an infinite branch?

Show answerHide answer

No. Take all finite strictly decreasing sequences of natural numbers, including the empty sequence, ordered by extension. This is a rooted tree, and each level is countable as a subset of a finite power of \(\mathbb N\). Every finite level is nonempty: level \(n\) contains \((n-1,n-2,\ldots,0)\). Its height is therefore \(\omega\). An infinite branch would give an infinite strictly decreasing sequence in \(\mathbb N\), contrary to well-ordering. A sequence starting at \(m\) has length at most \(m+1\), so every path stops after finitely many steps.

A \(\kappa\)-tree has small levels at height \(\kappa\)

For an infinite cardinal \(\kappa\), a \(\kappa\)-tree has height \(\kappa\) and \(|T_\alpha|<\kappa\) for every \(\alpha<\kappa\). A \(\kappa\)-Aronszajn tree is a \(\kappa\)-tree with no cofinal branch. Without a cardinal qualifier, an Aronszajn tree means an \(\omega_1\)-Aronszajn tree.

An \(\omega\)-tree has finite levels, so König's lemma excludes \(\omega\)-Aronszajn trees. An \(\omega_1\)-tree has countable levels; we will construct one with no branch through all \(\omega_1\) levels. The construction uses that every ordinal below \(\omega_1\) is countable.

Injections into the naturals obstruct an uncountable branch

Let \(J\) be the tree of all injections \(t:\alpha\to\mathbb N\), \(\alpha<\omega_1\), ordered by extension. It has height \(\omega_1\) and no cofinal branch, but it is not an \(\omega_1\)-tree.

Proof

Restrictions of injections are injections, and every countable ordinal admits an injection into \(\mathbb N\). Thus all levels below \(\omega_1\) occur. The union of a cofinal branch would be an injection from \(\omega_1\) into \(\mathbb N\): compatibility makes it a function, cofinality makes its domain all of \(\omega_1\), and any two arguments lie together in one injective node. Such an injection contradicts uncountability.

However, level \(\omega\) is uncountable. For each binary sequence \(x:\mathbb N\to\{0,1\}\), the map \(n\mapsto2n+x(n)\) is injective, and different \(x\)'s give different maps. There are uncountably many binary sequences. So \(J_\omega\) is too large for an \(\omega_1\)-tree. □

We must thin this tree without losing any level. Finite modifications will keep each chosen level countable.

Finite modifications on a fixed countable domain form a countable class

For functions \(f,g:D\to\mathbb N\) with the same domain, write \(f=^*g\) if \(\{d\in D:f(d)\ne g(d)\}\) is finite. This is an equivalence relation, analogous to equality modulo finite errors for sets. If \(D\) is countable, then for each \(f\) the class \(\{g:g=^*f\}\) is countable. If \(f,g\) are injections and \(f=^*g\), their ranges differ by only finitely many values; in particular one range is coinfinite exactly when the other is.

Proof

Reflexivity and symmetry are immediate; the disagreement set for \(f,h\) is contained in the union of the disagreement sets for \(f,g\) and \(g,h\), proving transitivity. Each finite modification is determined by the finite graph of its changed values, a finite subset of the countable set \(D\times\mathbb N\). The countability of finite subsets bounds the number of modifications.

If the disagreement set is \(E\), then \(\operatorname{ran}(g)\setminus\operatorname{ran}(f)\subseteq g[E]\) and \(\operatorname{ran}(f)\setminus\operatorname{ran}(g)\subseteq f[E]\). These sets are finite. Removing or adding finitely many values cannot change whether the complement in \(\mathbb N\) is infinite. □

Here coinfinite means that the complement in \(\mathbb N\) is infinite. When domains differ, we compare a function to an explicitly specified restriction, rather than writing \(=^*\) for two different domains.

Finitely many collisions can be repaired while avoiding a finite reserve

Let \(A\subseteq B\), let \(f:B\to\mathbb N\) be an injection with coinfinite range, and let \(g:A\to\mathbb N\) be an injection with \(g=^*f\mathbin{\upharpoonright}A\). If \(R\subseteq\mathbb N\) is finite and disjoint from \(\operatorname{ran}(g)\), there is an injection \(h:B\to\mathbb N\) extending \(g\), with \(h=^*f\), coinfinite range, and range disjoint from \(R\).

Proof

On \(B\setminus A\), retain the values of \(f\) except at

\[ E=\{b\in B\setminus A:f(b)\in\operatorname{ran}(g)\cup R\}. \]

The set \(E\) is finite. Values of \(f\) at new arguments cannot lie in \(\operatorname{ran}(f\mathbin{\upharpoonright}A)\), by injectivity. The difference \(\operatorname{ran}(g)\setminus\operatorname{ran}(f\mathbin{\upharpoonright}A)\) is finite, because \(g\) changes only finitely many arguments. Each of those values, or of the finitely many values in \(R\), is used by \(f\) at most once.

The partial map consisting of \(g\) and the retained values is injective and avoids \(R\). Its range is contained in \(\operatorname{ran}(f)\) together with finitely many changed values of \(g\); hence its complement is infinite. Fill the finitely many holes \(E\) with distinct fresh values outside that range and outside \(R\). There are enough fresh values because excluding an additional finite set leaves an infinite supply. The resulting \(h\) is total, injective, and avoids \(R\). It differs from \(f\) only on \(E\) and the finite disagreement set on \(A\), so its range is still coinfinite by . □

Coinfinite injections can agree with all earlier stages up to finite errors

There is a family \((s_\alpha)_{\alpha<\omega_1}\) such that each \(s_\alpha:\alpha\to\mathbb N\) is injective with coinfinite range, and

\[ \beta<\alpha\quad\Longrightarrow\quad s_\alpha\mathbin{\upharpoonright}\beta=^*s_\beta. \label{eq:coherence} \]

Proof

Use transfinite recursion. Put \(s_0=\varnothing\). At a successor, extend \(s_\alpha\) by assigning to \(\alpha\) a value outside its range. This preserves injectivity and coinfiniteness, and leaves all earlier restrictions unchanged.

At a nonzero limit \(\alpha<\omega_1\), choose a strictly increasing cofinal sequence \((\alpha_n)_{n<\omega}\) in \(\alpha\), which exists by countable limit cofinality. We construct total injections \(h_n:\alpha_n\to\mathbb N\) and finite sets \(R_n\subseteq\mathbb N\) satisfying

\[ h_n=^*s_{\alpha_n},\quad h_n\subseteq h_{n+1},\quad R_n\subseteq R_{n+1},\quad |R_n|=n,\quad R_n\cap\operatorname{ran}(h_n)=\varnothing. \]

Start with \(h_0=s_{\alpha_0}\) and \(R_0=\varnothing\). The earlier coherence and finite-error transitivity give \(h_n=^*s_{\alpha_{n+1}}\mathbin{\upharpoonright}\alpha_n\). Apply with \(f=s_{\alpha_{n+1}}\), \(g=h_n\), and reserve \(R_n\). This gives a total injection \(h_{n+1}:\alpha_{n+1}\to\mathbb N\) extending \(h_n\), finitely differing from \(s_{\alpha_{n+1}}\), with coinfinite range avoiding \(R_n\).

Choose a fresh number

\[ r_n\in\mathbb N\setminus \bigl(\operatorname{ran}(h_{n+1})\cup R_n\bigr), \qquad R_{n+1}=R_n\cup\{r_n\}. \]

This excludes both the current range and all previous reserved numbers, so the reserves really grow by one at every stage. Subsequent extensions continue to avoid them.

Set \(s_\alpha=\bigcup_{n<\omega}h_n\). Compatibility makes this a function; cofinality of the domains makes it total on \(\alpha\); increasing injective extensions make it injective. Its range misses the infinite set \(\bigcup_nR_n\): a number reserved at one stage is avoided at all later stages, and earlier ranges are contained in later ranges. Thus its range is coinfinite.

Finally, for \(\beta<\alpha\), choose \(n\) with \(\beta<\alpha_n\). The restriction \(s_\alpha\mathbin{\upharpoonright}\beta=h_n\mathbin{\upharpoonright}\beta\) finitely differs from \(s_{\alpha_n}\mathbin{\upharpoonright}\beta\), which finitely differs from \(s_\beta\) by the recursion hypothesis. This proves \eqref{eq:coherence} and completes the construction. □

The \(s_\alpha\) are coherent up to finite errors; they do not form a chain of exact extensions. Exact coherence at every stage would produce the forbidden injection \(\omega_1\to\mathbb N\).

There is an Aronszajn tree with countable levels and no uncountable branch

There exists a tree of height \(\omega_1\) with every level countable and no cofinal branch. In fact every branch is countable.

Proof

Take the coherent family from and define

\[ T_\alpha=\{t:\alpha\to\mathbb N: t\text{ is injective and }t=^*s_\alpha\},\qquad T=\bigcup_{\alpha<\omega_1}T_\alpha, \]

ordered by extension. If \(t\in T_\alpha\) and \(\beta<\alpha\), then \(t\mathbin{\upharpoonright}\beta=^*s_\alpha\mathbin{\upharpoonright}\beta=^*s_\beta\), so its restriction lies in \(T_\beta\). Thus \(T\) is closed under restrictions and has exactly these levels. Each is nonempty because it contains \(s_\alpha\), and each is countable by . Hence \(T\) is an \(\omega_1\)-tree.

A cofinal branch in \(T\) would be a cofinal branch in the full injection tree \(J\), which excludes. More generally, if a branch were uncountable, its distinct node heights would form an uncountable subset of \(\omega_1\), hence would be unbounded by regularity of \(\omega_1\). Downward closure would make that branch cofinal. Therefore every branch is countable. □

Does extension to every higher level force a cofinal branch?

Is the constructed tree rooted? Can each of its nodes be extended to every higher level? If so, why is there still no cofinal branch?

Show answerHide answer

The empty function is its unique root. Given \(t\in T_\alpha\) and \(\alpha<\beta<\omega_1\), coherence gives \(t=^*s_\beta\mathbin{\upharpoonright}\alpha\). Apply the finite-repair extension lemma with \(R=\varnothing\). It supplies an injection \(u:\beta\to\mathbb N\) extending \(t\) with \(u=^*s_\beta\), so \(u\in T_\beta\). Thus every node has an extension at every prescribed higher level.

These separate extension assertions do not give a coherent chain through all \(\omega_1\) levels. At a limit stage, the union of the nodes chosen so far may fail to belong to the constructed level: it need not finitely agree with its selected \(s_\alpha\), and it might already use all natural-number values. The tree admits extensions of each individual node, without promising an upper bound for every increasing chain. The no-branch proof still rules out an \(\omega_1\)-long choice of mutually extending nodes. Conditions described as “normality” vary between authors; we use the explicit extension property here rather than rely on that name.
