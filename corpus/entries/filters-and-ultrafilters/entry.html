A filter records which subsets count as large

A proper filter on a set \(X\) is a family \(\mathcal F\subseteq\mathcal P(X)\) such that \(X\in\mathcal F\), \(\varnothing\notin\mathcal F\), the intersection of any two members is a member, and every subset of \(X\) containing a member is itself a member. In this entry, “filter” always means a proper filter.

These rules express a consistent notion of largeness: the whole space is large, the empty set is not, two large conditions can hold together, and enlarging a large set keeps it large. Induction gives closure under every finite intersection, with the empty intersection interpreted as \(X\). Closure under infinite intersections is not required.

There is no proper filter on the empty set, since its whole space is empty. On nonempty \(X\), the family \(\{X\}\) is a filter and is contained in every filter on \(X\).

A fixed nonempty set generates a principal filter

For a nonempty subset \(S\subseteq X\), its principal filter is \(\mathcal F_S=\{A\subseteq X:S\subseteq A\}\). It is a filter: every member contains \(S\), intersections preserve this condition, and the empty set cannot contain \(S\).

For \(x\in X\), write \(\mathcal U_x=\mathcal F_{\{x\}}\). Its members are exactly the subsets containing \(x\). A filter is called principal if it equals \(\mathcal F_S\) for some nonempty \(S\); otherwise it is nonprincipal.

Ignoring finitely many exceptions gives a filter on an infinite set

If \(X\) is infinite, the cofinite filter is \(\mathcal F_{\mathrm{cof}}=\{A\subseteq X:X\setminus A\text{ is finite}\}\).

Proof

The complement of \(X\) is empty, while the complement of the empty set is the infinite set \(X\). A superset of a cofinite set has a smaller, hence finite, complement. Also \(X\setminus(A\cap B)=(X\setminus A)\cup(X\setminus B)\), a union of two finite sets when \(A,B\) are cofinite. These verify the filter rules. □

On \(\mathbb N\), membership means that a condition holds for all but finitely many natural numbers. For finite \(X\), this same family contains the empty set and is not a proper filter.

Must infinitely many large sets have a large intersection?

In the cofinite filter on \(\mathbb N\), consider \(T_n=\{m\in\mathbb N:m\ge n\}\). Is \(\bigcap_{n\in\mathbb N}T_n\) a member?

Show answerHide answer

Every \(T_n\) is cofinite, and every finite intersection is another tail, hence cofinite. The intersection of all tails is empty: no natural number is at least every natural number. It is therefore not a filter member. The distinction between finite and infinite intersections is essential.

A family can generate a filter exactly when its finite requirements are compatible

A family \(\mathcal B\subseteq\mathcal P(X)\) has the finite intersection property if every finite subfamily has nonempty intersection. The empty subfamily has intersection \(X\), so this condition requires \(X\ne\varnothing\). It allows \(\mathcal B\) itself to be empty when \(X\) is nonempty.

Define the generated family by

\[ \langle\mathcal B\rangle= \left\{A\subseteq X:\text{some finite }\mathcal E\subseteq\mathcal B \text{ satisfies }\bigcap\mathcal E\subseteq A\right\}. \]

Finite intersections of the proposed generators supply the basic large sets; taking supersets then supplies the whole filter.

The generated filter is the least filter containing its generators

A family \(\mathcal B\) is contained in a proper filter exactly when it has the finite intersection property. In that case, \(\langle\mathcal B\rangle\) is a proper filter and is contained in every filter containing \(\mathcal B\).

Proof

If a proper filter contains \(\mathcal B\), every finite intersection of generators is a filter member and cannot be empty. Conversely, suppose the finite intersection property holds. The empty subfamily puts \(X\) in the generated family. No finite intersection can be contained in the empty set, so the empty set is excluded. Upward closure follows from containment. If finite subfamilies \(\mathcal E,\mathcal D\) witness membership of \(A,B\), their union witnesses membership of \(A\cap B\), because its intersection is contained in both sets. Thus the generated family is a proper filter. Every generator belongs to it by its singleton subfamily. Any filter containing the generators must contain their finite intersections and all supersets, proving minimality. □

On \(\mathbb N\), the tails \(T_n\) from generate the cofinite filter: each finite intersection is a tail, and every cofinite set contains a tail. For an empty generating family on nonempty \(X\), the result is \(\{X\}\).

A new set can be made large unless its complement is already large

Given a filter \(\mathcal F\) on \(X\) and \(A\subseteq X\), there is a filter containing both \(\mathcal F\) and \(A\) exactly when \(X\setminus A\notin\mathcal F\).

Proof

If the complement belongs to \(\mathcal F\), any such extension would contain both \(A\) and its complement and therefore their empty intersection. Conversely, if the complement does not belong, every \(B\in\mathcal F\) meets \(A\): otherwise \(B\subseteq X\setminus A\) would put the complement in \(\mathcal F\). A finite intersection of members of \(\mathcal F\) is still a member, so it too meets \(A\). Consequently \(\mathcal F\cup\{A\}\) has the finite intersection property; apply . □

An ultrafilter chooses exactly one side of every complement pair

An ultrafilter on \(X\) is a filter \(\mathcal U\) such that, for every \(A\subseteq X\), either \(A\in\mathcal U\) or \(X\setminus A\in\mathcal U\). It cannot contain both, since their intersection is empty. Thus exactly one belongs.

Each \(\mathcal U_x\) is an ultrafilter: exactly one of \(A\) and its complement contains \(x\). The cofinite filter on \(\mathbb N\) is not an ultrafilter: neither the even numbers nor the odd numbers are cofinite.

Ultrafilters are exactly the maximal proper filters

A filter \(\mathcal U\) is an ultrafilter exactly when it has no strictly larger proper filter on the same set.

Proof

If a maximal filter omitted both \(A\) and its complement, would give a proper extension containing \(A\), contradicting maximality. Hence a maximal filter decides every complement pair. Conversely, suppose an ultrafilter had a proper extension containing a new member \(A\). Since \(A\notin\mathcal U\), its complement belongs to \(\mathcal U\) and therefore to the extension. The extension would contain the empty intersection, a contradiction. □

Maximality here is under inclusion of families of subsets. It does not assert that an ultrafilter contains every other filter; different point ultrafilters already give distinct maximal examples.

Every proper filter extends to an ultrafilter

Assuming the axiom of choice, for each filter \(\mathcal F\) on \(X\) there is an ultrafilter \(\mathcal U\supseteq\mathcal F\).

Proof

Order the proper filters containing \(\mathcal F\) by inclusion. They form a set, since each is a member of \(\mathcal P(\mathcal P(X))\), and this set is nonempty because it contains \(\mathcal F\). For a nonempty chain, take the union of its filters. It contains \(X\) and excludes the empty set. It is upward closed. If \(A,B\) belong to the union, they belong to two filters of the chain; the larger of these filters contains both, hence also \(A\cap B\). Thus the union is a proper filter and an upper bound for the chain. The empty chain has \(\mathcal F\) as an upper bound.

Zorn’s lemma now supplies a maximal member. Any proper extension would still contain \(\mathcal F\), so it is maximal among all proper filters on \(X\). By it is an ultrafilter. □

Combining this with , every family with the finite intersection property is contained in an ultrafilter. The use of Zorn’s lemma is the choice assumption in this existence proof.

An ultrafilter selects one cell of every finite partition

If finitely many pairwise disjoint subsets partition \(X\), exactly one cell belongs to an ultrafilter \(\mathcal U\) on \(X\). In particular, if a finite set belongs to \(\mathcal U\), some singleton belongs to \(\mathcal U\).

Proof

Two different cells cannot both belong, because their intersection is empty. If no cell belonged, all their complements would belong, so their finite intersection, the empty set, would belong. This proves the partition statement. If a finite \(A\in\mathcal U\) contained no singleton in \(\mathcal U\), all complements of its singletons would belong; intersecting these finitely many complements would put \(X\setminus A\) in \(\mathcal U\), contradicting \(A\in\mathcal U\). □

A finite large set forces an ultrafilter to concentrate on one point

For an ultrafilter \(\mathcal U\), the following are equivalent: it contains a finite set; it contains a singleton \(\{x\}\); it equals \(\mathcal U_x\); it is principal.

Proof

A finite member supplies a singleton by . If \(\{x\}\in\mathcal U\), upward closure puts every set containing \(x\) in \(\mathcal U\). No set omitting \(x\) can belong, because its intersection with \(\{x\}\) is empty. Thus \(\mathcal U=\mathcal U_x\), which is principal. If \(\mathcal U=\mathcal F_S\) is principal, choose \(x\in S\). Then \(\mathcal F_S\subseteq\mathcal U_x\); maximality forces equality, giving a singleton and therefore a finite member. □

It follows that every ultrafilter on a nonempty finite set is a point ultrafilter, since its whole space is a finite member.

There are ultrafilters on the natural numbers that contain no finite set

Assuming choice, every infinite set \(X\), and in particular \(\mathbb N\), has a nonprincipal ultrafilter. For ultrafilters on infinite \(X\), nonprincipality is equivalent to containing the cofinite filter.

Proof

Extend the cofinite filter using . If a finite set belonged to this extension, its cofinite complement would belong too, giving an empty intersection. Therefore the extension has no finite member and is nonprincipal by . Conversely, a nonprincipal ultrafilter has no finite member. Deciding the complement of each finite subset then puts every cofinite subset in it. □

This proves existence without selecting a particular nonprincipal ultrafilter. On \(\mathbb N\), such an ultrafilter extends the notion of “all but finitely many” by deciding every other subset as well.

Finite changes do not affect membership in a nonprincipal ultrafilter

If \(\mathcal U\) is nonprincipal and subsets \(A,B\subseteq X\) differ on only finitely many points, then \(A\in\mathcal U\) exactly when \(B\in\mathcal U\).

Proof

Let \(D=(A\setminus B)\cup(B\setminus A)\), which is finite. Its complement belongs to \(\mathcal U\) by . If \(A\in\mathcal U\), the intersection \(A\cap(X\setminus D)\) belongs and is contained in \(B\), so \(B\in\mathcal U\). Interchange \(A,B\) for the converse. □

Can either the even or the odd numbers be declared large?

Must all nonprincipal ultrafilters on \(\mathbb N\) make the same choice between even and odd numbers?

Show answerHide answer

No. Every cofinite set meets the infinite set of even numbers, so gives a filter containing the cofinite filter and the evens. Extend it to an ultrafilter, which remains nonprincipal. The same construction with the odds gives another nonprincipal ultrafilter. Each decides the even–odd partition, and they decide it differently. A nonprincipal ultrafilter need not regard every infinite set as large.
