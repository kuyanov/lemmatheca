Require the jump to compute the second halting problem

Write \(K\) for ordinary diagonal halting and \(A'\) for the jump in the fixed oracle numbering. A set \(A\subseteq\mathbb N\) is high if \(K'\le_T A'\). The comparison \(K\equiv_T\varnothing'\) identifies the lower degree as the second jump of the computable degree. This definition places a requirement on the jump of \(A\), without requiring \(A\) to be c.e. or to lie below \(K\).

For total numerical functions use the existing actual-program meaning of \(g\le_T A\). Say that \(g\) dominates all computable functions if

\[\forall f\text{ total computable}\quad\exists N\quad\forall n\ge N\quad f(n)\le g(n).\]

The threshold may depend on \(f\). The single function \(g\) is fixed before \(f\) varies.

Totality carries the second halting degree

The ordinary totality index set \(\mathrm{TOT}=\{e:\forall x\;\varphi_e(x)\downarrow\}\) satisfies \(\mathrm{TOT}\equiv_T K'\).

The actual ordinary-halting recoding gives many-one reductions between \(K\) and the first empty-oracle jump. The ordinary computable jump translations therefore give many-one reductions between \(K'\) and the second empty jump. By Post’s completeness theorem, \(K'\) is \(\Sigma_2\)-complete and \(\overline{K'}\) is \(\Pi_2\).

The complement of \(\mathrm{TOT}\) is \(\Sigma_2\), so it has an ordinary total computable many-one reduction to \(K'\). Query there and reverse the answer to decide \(\mathrm{TOT}\). Conversely the \(\Pi_2\)-completeness of totality gives an ordinary total computable map \(v\) with \(e\notin K'\) exactly when \(v(e)\in\mathrm{TOT}\). Query \(\mathrm{TOT}\) there and reverse the answer to decide \(K'\). The equivalence asserted is Turing equivalence; the two sets have opposite quantifier polarities.

A high oracle can guess which ordinary programs are total

If \(A\) is high, there is a jointly \(A\)-computable binary approximation \(a(s,e)\) converging to \(\chi_{\mathrm{TOT}}(e)\). Fix one actual index \(c\) for it:

\[\Phi_c^A(\langle s,e\rangle)\downarrow=a(s,e)\quad\text{for all }s,e.\]

By and highness, \(\mathrm{TOT}\le_T A'\). The relative set limit lemma, with base exactly \(A\), supplies the approximation and the actual joint program. Convergence is eventual equality on each fixed index. It supplies no computable settling stage.

Wait for a value or for withdrawal of a totality guess

Use the ordinary bounded output code \(b(k,e,x)\): zero means no successful result at allowance \(k\), and output \(y\) has code \(y+1\). At input \(n\), consider only indices \(e\le n\) with \(a(n,e)=1\). For each such index, test stages \(r=n,n+1,\ldots\) in order:

  1. If \(b(r,e,n)=y+1>0\), return \(y\).
  2. Otherwise compute \(a(r,e)\). If it is zero, cancel this candidate and return zero; if it is one, try the next stage.

Call the returned value \(v(n,e)\); put \(v(n,e)=0\) when \(e>n\) or the initial guess is zero. A successful computation takes precedence when both conditions occur at one stage. The allowance \(r\) is the resource parameter of the existing checker, rather than a claim about tape steps.

Every selected candidate eventually finishes

Under the convergent totality approximation, \(v(n,e)\) is defined for every \(n,e\).

If \(e>n\) or the initial guess is zero, the rule immediately returns zero. Otherwise there are two cases. If \(e\in\mathrm{TOT}\), then \(\varphi_e(n)\) converges. Completeness and monotonicity of bounded evaluation give a successful allowance at some tested \(r\ge n\), unless an earlier cancellation has already finished the race. If \(e\notin\mathrm{TOT}\), convergence of its guesses gives some \(S\) with \(a(r,e)=0\) for all \(r\ge S\). The race then cancels at or before a tested stage beyond \(\max(n,S)\), unless it has already returned a successful value.

Each individual stage terminates: bounded evaluation is ordinary total computable, and the supplied approximation program is total on every pair. Only the number of stages is unbounded. These arguments justify least search; they do not decide which case a given index belongs to.

Take one plus the finite maximum of the race values

\[g(n)=1+\max\bigl(\{0\}\cup\{v(n,e):e\le n\}\bigr).\]

For each \(n\), run the finitely many races in order and take their maximum, using zero as the initial value. All finish by . The added one will make the eventual comparison strict.

The same finite driver computes the maximum from the supplied approximation

There is an ordinary primitive-recursive index map \(R\), fixed before \(A\) and \(c\) vary, such that every total convergent binary totality approximation with index \(c\) satisfies

\[\Phi_{R(c)}^A(n)\downarrow=g(n)\quad\text{for all }n.\]

Choose one oracle-program driver with input \(\langle c,n\rangle\). It obtains guesses by calling the existing universal oracle evaluator at index \(c\) on \(\langle r,e\rangle\). It embeds the ordinary bounded checker, uses finite conditionals with the success-first rule, searches the tested stages, and folds a maximum over \(0,\ldots,n\). These are the established oracle closure operations, so they give one finite program, independent of the oracle and of the supplied approximation index.

Fix its numerical index \(r_0\) and let \(R(c)=s_{\rm or}(r_0,c)\) using the actual oracle parameter compiler. Specialization evaluates the same driver with parameter \(c\); induction through the finite loops, together with each race’s first successful test, identifies its output with the displayed \(g(n)\). The compiler is primitive recursive on every index. Its total-output guarantee uses the approximation assumptions proved above. In particular \(g\le_T A\), with the existing function/graph interpretation.

Every total ordinary program is eventually included without cancellation

The function \(g\) strictly eventually dominates every ordinary total computable function.

Fix a total computable \(f\), and choose an ordinary index \(e\) with \(\varphi_e(n)=f(n)\) for every \(n\). Since \(e\in\mathrm{TOT}\), choose \(S\) such that \(a(r,e)=1\) whenever \(r\ge S\). For every \(n\ge\max(e,S)\), the index \(e\) is among the finitely many candidates and its initial guess is one. Every tested stage \(r\ge n\) also has guess one, so the race cannot cancel. It returns exactly \(f(n)\) when a successful bounded computation first appears. Hence \(f(n)\le\max_{j\le n}v(n,j)<g(n)\).

The function \(g\) was chosen from the one approximation before \(f\) or its settling threshold was selected. Thus proves the high-to-domination direction.

A total program has a computable deadline for each finite input interval

For an ordinary index \(e\in\mathrm{TOT}\), define

\[h_e(n)=\mu k\quad\forall x\le n\quad b(k,e,x)>0.\]

This is the least allowance by which all inputs through \(n\) have successful bounded outputs. The definition is used under the stated totality hypothesis; no total deadline function is claimed for a partial index.

The finite deadline is ordinary total computable

For each fixed \(e\in\mathrm{TOT}\), the function \(h_e\) is total computable, and \(k\ge h_e(n)\) implies \(b(k,e,x)>0\) for every \(x\le n\).

For each of the finitely many inputs \(x\le n\), totality supplies one successful allowance. Take their maximum. Monotonicity of the checker preserves every success at this common allowance, so a witness to the search exists. The test at any proposed \(k\) is a finite conjunction of ordinary computable comparisons. Least search therefore computes \(h_e(n)\), and its witness property followed by monotonicity proves the last assertion.

One ordinary partial two-argument program carries out this search on \(\langle e,n\rangle\). Fixing \(e\) by the ordinary parameter theorem gives a program for its deadline; membership in \(\mathrm{TOT}\) establishes that this particular specialization is total. The procedure itself does not first test totality.

Use a dominating function as the allowance in a totality test

Now suppose a total \(g\le_T A\) dominates every ordinary total computable function, and fix an actual index \(d\) with \(\Phi_d^A(s)\downarrow=g(s)\) for all \(s\). Define the binary guesses

\[z(s,e)=\begin{cases}1,&\forall x\le s\quad b(g(s),e,x)>0,\\0,&\text{otherwise}.\end{cases}\]

There is one ordinary primitive-recursive index map \(Q\), fixed before \(A,d\) vary, with \(\Phi_{Q(d)}^A(\langle s,e\rangle)\downarrow=z(s,e)\). A fixed driver calls the supplied oracle index \(d\) on \(s\), then performs the finite ordinary checks. The actual oracle parameter compiler freezes \(d\) into this driver. Totality of the supplied \(g\)-program makes these guesses jointly \(A\)-computable.

The bounded guesses converge exactly to totality

For every fixed ordinary index \(e\), \(z(s,e)\) is eventually \(\chi_{\mathrm{TOT}}(e)\).

If \(e\in\mathrm{TOT}\), its ordinary total computable deadline \(h_e\) is one of the functions dominated by \(g\). Thus for all sufficiently large \(s\), \(h_e(s)\le g(s)\). The deadline lemma gives a successful bounded output for every \(x\le s\), so the bounded guess is one.

If \(e\notin\mathrm{TOT}\), choose an input \(x_0\) on which it diverges. Soundness of bounded evaluation makes \(b(k,e,x_0)=0\) for every \(k\). For all \(s\ge x_0\), this input is included in the bounded conjunction, forcing \(z(s,e)=0\). These two cases prove convergence; no common stage for all indices is asserted.

Highness is exactly the ability to dominate every computable function

For every oracle \(A\),

\[A\text{ is high}\quad\Longleftrightarrow\quad\exists g\le_T A\;\forall f\text{ total computable}\quad f\le^*g.\]

Highness is upward closed and independent of the representative

If \(A\le_T B\) and \(A\) is high, then \(B\) is high. Turing-equivalent sets are high simultaneously, and \(K\) is high.

Jump monotonicity gives \(A'\le_T B'\), so compose \(K'\le_T A'\) with this reduction. Apply it in both directions for equivalent oracles. For \(K\), the required comparison is the identity reduction \(K'\le_TK'\).

Highness implies hyperimmune degree, with a stronger quantifier pattern

Every high oracle has hyperimmune degree. The converse fails, even for noncomputable c.e. sets.

Let \(g\le_T A\) dominate all total computable functions. If a total computable \(h\) eventually bounded \(g\), then the total computable function \(n\mapsto h(n)+1\) would eventually be at most \(g(n)\). Beyond both thresholds we would have \(h(n)+1\le g(n)\le h(n)\), an impossibility. Thus this same \(g\) is a hyperimmune function, witnessing the first assertion.

For the converse use the actual simple set \(L\) produced in the low-simple construction. It is c.e., noncomputable, and low. The noncomputable-low theorem makes its degree hyperimmune. It cannot be high: lowness gives \(L'\le_TK\), so highness would imply \(K'\le_TK\), contradicting jump strictness.

The distinction is quantitative. A hyperimmune function only escapes each proposed computable bound at arbitrarily late inputs. A dominating function is eventually above each computable function at every remaining input. These are different quantifier patterns, and the specified low example separates the degree properties.

Since \(K\le_TK'\), the theorem supplies its specified 1-generic set \(A\) with \(A'\equiv_TK'\) and \(A<_TK'\). Thus \(A\) is high. It is noncomputable, because a computable set has jump equivalent to \(K\), whereas \(K'\not\le_TK\).

The strict upper bound is a comparison with the second halting problem. Incompleteness below \(K\) still needs proof, and the construction does not supply c.e. enumerability of \(A\). The further c.e. and incomplete-below-\(K\) assertions require a separate construction. They do not follow by replacing the upper oracle’s name in this inversion theorem.
