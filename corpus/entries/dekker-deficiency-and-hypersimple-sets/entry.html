Record a smaller number arriving later

Fix a noncomputable c.e. set \(A\subseteq\mathbb N\). It is infinite, since every finite set is decidable. The repetition-removal construction supplies a total computable injective enumeration \(a:\mathbb N\to\mathbb N\) with range \(A\). Fix this particular enumeration and an ordinary program computing it. Its deficiency set is

\[D_a=\{s:\exists t>s\quad a(t)<a(s)\},\qquad C_a=\mathbb N\setminus D_a.\]

The elements of these sets are positions in the enumeration. A position is deficient when a smaller value appears later. A position in \(C_a\) is nondeficient: no later value is smaller. Changing the enumeration can change these sets, so the supplied \(a\) remains fixed throughout the construction.

A nondeficient position supplies a lower bound on its tail

For every position \(s\),

\[s\in C_a\quad\Longleftrightarrow\quad\forall t>s\quad a(s)<a(t).\]

Consequently, if \(s\in C_a\) and \(x<a(s)\), then

\[x\in A\quad\Longleftrightarrow\quad\exists i\le s\quad a(i)=x.\]

Nondeficiency excludes \(a(t)<a(s)\) for \(t>s\). Injectivity excludes equality, leaving \(a(s)<a(t)\). The converse follows immediately from that strict inequality. If \(x<a(s)\), no position after \(s\) can output \(x\). Since the range of \(a\) is \(A\), membership of \(x\) is therefore decided by the finite initial segment through \(s\).

Deficiency has a positive finite witness

The specified set \(D_a\) is computably enumerable. More precisely, the following ordinary partial program has domain exactly \(D_a\): on input \(s\), test \(t=s+1,s+2,\ldots\) in order, and return zero as soon as \(a(t)<a(s)\).

Each test terminates because the supplied program for \(a\) is total. Comparison, composition, and least-witness search give an actual partial recursive program. It halts exactly when the defining witness \(t\) exists, so the domain characterization proves enumerability. If no witness exists, the program continues searching; a finite quiet interval does not certify nondeficiency.

There are arbitrarily late nondeficient positions

The set \(C_a\) is infinite. Its values \(\{a(s):s\in C_a\}\) are also unbounded.

Fix any position bound \(N\). The nonempty set of tail values \(\{a(t):N\le t\}\) has a least member. Let \(s\ge N\) be a position attaining it. For every \(t>s\), minimality gives \(a(s)\le a(t)\), and injectivity makes the inequality strict. Thus \(s\in C_a\). This works for every \(N\), proving infinitude.

If all values at positions in \(C_a\) were at most \(x\), injectivity would put this infinite set of positions into the finite set \(\{0,\ldots,x\}\). That is impossible. Hence for every \(x\), some \(s\in C_a\) satisfies \(x<a(s)\). These are existence statements; the tail minimum was not claimed to be computable.

Deficiency decisions recover the original set

There is an actual oracle program \(P_a\), built from the supplied ordinary program for \(a\), such that

\[E_{D_a}(P_a,x)\downarrow=\chi_A(x)\quad\text{for every }x.\]

Its instructions are to search for the first position \(s\) satisfying \(s\notin D_a\) and \(x<a(s)\), then return one exactly when \(x\) occurs among \(a(0),\ldots,a(s)\). In particular \(A\le_T D_a\).

At each candidate \(s\), compute \(a(s)\) and query the oracle bit for \(s\). These are terminating computations. The unboundedness in guarantees that some candidate passes. The final bounded test uses only the fixed program for \(a\). Its answer is correct by .

These instructions are finite oracle-program syntax: pair the parameters, compose the embedded ordinary \(a\)-program with projections, use the query constructor for membership, use least search for the passing position, and use finite recursion for the final list of comparisons. Thus \(P_a\) is a program with the displayed identity, not merely a set-theoretic membership equivalence. It uses the same supplied enumeration.

The original oracle decides deficiency by a finite prefix test

For every position \(s\),

\[s\in D_a\quad\Longleftrightarrow\quad\exists x<a(s)\;\bigl[x\in A\ \land\ \forall i<s\quad a(i)\ne x\bigr].\]

There is an actual program \(Q_a\), built from the same ordinary \(a\)-program, with

\[E_A(Q_a,s)\downarrow=\chi_{D_a}(s).\]

If \(s\) is deficient, choose \(t>s\) with \(x=a(t)<a(s)\). Then \(x\in A\), and injectivity excludes \(a(i)=x\) for all \(i<s\). Conversely, a witness \(x\) belongs to the range of \(a\), so \(a(t)=x\) for some \(t\). It cannot have \(t<s\) by the finite test, or \(t=s\) because \(x<a(s)\). Hence \(s<t\), proving deficiency.

To implement \(Q_a\), first compute \(a(s)\). For each \(x<a(s)\), query membership in \(A\) and compare \(x\) with the finitely many values \(a(i)\) for \(i<s\). Return one if any \(x\) passes, and zero otherwise. All loops are bounded after computing \(a(s)\); composition, queries, and finite recursion give the required oracle syntax. At \(a(s)=0\), the search interval is empty and the answer is zero, as it should be. This proves \(D_a\le_T A\).

The specified deficiency set has exactly the original degree

For every noncomputable c.e. \(A\) and every supplied total computable injective enumeration \(a\) of \(A\), the specified deficiency set is c.e., has infinite complement, and satisfies \(D_a\equiv_T A\).

Enumerability is , and the infinite complement is . The actual programs \(P_a\) and \(Q_a\) in and witness the two reductions. In particular \(D_a\) is noncomputable: a computable oracle for it could be eliminated from \(P_a\), deciding \(A\). It is therefore infinite as well.

A hypersimple set leaves a hyperimmune complement

A set \(S\subseteq\mathbb N\) is hypersimple if it is c.e. and its complement \(\overline S\) is hyperimmune. In particular the complement must be infinite. By the strong-array characterization, this is equivalently the combination of c.e. enumerability, an infinite complement, and

\[\forall (F_n)\text{ strong array}\quad\exists n\quad F_n\subseteq S.\]

Here a strong array is a pairwise disjoint sequence of finite sets with a total computable finite-list description. An array hits \(\overline S\) exactly when every \(F_n\) contains an omitted number. Negating that condition gives one \(F_n\) disjoint from the complement, or equivalently contained in \(S\). Empty members cause no exception: an empty member is already contained in \(S\) and prevents the array from hitting its complement.

The earlier Post simple set is not hypersimple

Let \(P\) be the particular Post set obtained from the threshold selector. Its complement has principal function satisfying

\[p_{\overline P}(n)\le 2n\quad\text{for every }n\in\mathbb N.\]

Consequently \(P\) is simple but not hypersimple. Thus hypersimplicity is a strictly stronger condition on c.e. sets than simplicity.

The complement is infinite by the earlier omission bound, so its increasing principal function is defined. That bound says that at least \(n+1\) omitted numbers lie in \(\{0,\ldots,2n\}\). The principal function lists omitted numbers in increasing order, starting at index zero; its value at \(n\) is therefore at most \(2n\). In detail, if that value exceeded \(2n\), every omitted number in the interval would have one of the first \(n\) indices, contradicting the lower bound of \(n+1\).

The total computable function \(n\mapsto2n\) is a pointwise majorant, so \(\overline P\) is not hyperimmune and \(P\) is not hypersimple. The same set \(P\) is already proved simple. Conversely, every hypersimple set is simple because hyperimmunity implies immunity of its complement. These facts establish the strict implication without changing the earlier construction.

Disjoint finite tests eventually avoid every small enumerated value

Suppose \((F_n)\) is a strong array whose members are all nonempty. For every \(x\), some \(n\) satisfies

\[\forall s\in F_n\quad x<a(s).\]

The first such \(n\) can be found computably from \(x\), the supplied \(a\)-program, and the supplied list-code program for the array.

There are at most \(x+1\) bad positions \(s\) with \(a(s)\le x\), because \(a\) is injective. Pairwise disjointness allows each bad position to occur in at most one array member. Thus among the first \(x+2\) sets, at least one contains no bad position. In particular a passing index exists, even among \(0,\ldots,x+1\).

For any proposed \(n\), compute its complete finite list and compute \(a(s)\) for every listed entry. This decides the displayed condition, regardless of repetitions in a list. Least search therefore terminates and gives a total ordinary computation. The list's maximum can then be computed too. Nonemptiness ensures that this maximum is a member and bounds every position in the list.

An array hitting all nondeficient positions would decide the range

If a strong array \((F_n)\) hits \(C_a\), there is an ordinary total program deciding \(A\). On input \(x\), find the first \(n\) with \(x<a(s)\) for every \(s\in F_n\), compute \(M=\max F_n\), and return one exactly when

\[\exists i\le M\quad a(i)=x.\]

Hitting \(C_a\) makes every array member nonempty. Hence the search and maximum computation terminate by . Choose \(t\in F_n\cap C_a\). The search gives \(x<a(t)\), and every position after \(t\) has value greater than \(a(t)\). Since \(t\le M\), no position after \(M\) can output \(x\). The finite test through \(M\) therefore agrees exactly with membership in the range of \(a\).

The chosen nondeficient \(t\) is used only to prove correctness. The program never identifies it or queries \(C_a\). It uses just the given computable list descriptions, the given program for \(a\), least search over finite tests, a finite maximum, and a bounded range test. These operations specify an ordinary program whose output is \(\chi_A(x)\). Because \(A\) was assumed noncomputable, no such hitting strong array exists.

Deficiency sets are hypersimple

For the specified enumeration of a noncomputable c.e. set \(A\), the complement \(C_a\) is hyperimmune. Thus \(D_a\) is hypersimple and simple, with the same Turing degree as the original set.

The complement is infinite by . No strong array hits it by , so the array characterization proves hyperimmunity. Since \(D_a\) is c.e., it is hypersimple. Hyperimmune sets are immune, so its complement is immune and \(D_a\) is simple. Finally gives the stated degree equality.

Every nonzero enumerable degree has a hypersimple representative

Every nonzero Turing degree containing a c.e. set contains a hypersimple set. In particular hypersimple sets exist.

Choose a c.e. representative \(A\) of that degree. The degree is nonzero precisely when this representative is noncomputable. It is then infinite, so injective enumeration supplies an \(a\) as required. The set \(D_a\) from is hypersimple and has the same degree. Applying this to the c.e. noncomputable ordinary halting set gives an example.

The conclusion asserts that a suitable representative exists in each degree. It does not assert that every c.e. representative of that degree has a hyperimmune complement.

Every hypersimple representative is nevertheless truth-table incomplete. In particular, a hypersimple representative of the halting Turing degree has a strictly weaker truth-table degree.

Does every injective enumeration produce a hypersimple deficiency set?

Remove the assumption that the range is noncomputable. For the computable injective enumeration

\[a(2n)=2n+1,\qquad a(2n+1)=2n,\]

find \(D_a\) and \(C_a\). Is \(D_a\) hypersimple?

The range is \(\mathbb N\). Every even position \(2n\) is deficient, because the next value \(2n\) is smaller than \(2n+1\). An odd position \(2n+1\) outputs \(2n\), and every later value is larger. Therefore

\[D_a=\{2n:n\in\mathbb N\},\qquad C_a=\{2n+1:n\in\mathbb N\}.\]

The singleton sets \(F_n=\{2n+1\}\) form a computable strong array hitting \(C_a\), so \(C_a\) is not hyperimmune. Consequently \(D_a\) is not hypersimple. The earlier existence of infinitely many nondeficient positions remains true; it was the contradiction with noncomputability in that excluded a hitting array.

Which set is hyperimmune, and which one is hypersimple?

For a noncomputable c.e. range, is the deficiency set itself hyperimmune? What are the respective properties and Turing degrees of \(D_a\) and \(C_a\)?

Show answerHide answer

The set \(D_a\) is c.e., infinite, and hypersimple. It cannot itself be hyperimmune: an infinite c.e. set contains an infinite c.e. subset, namely itself, whereas every hyperimmune set is immune. Its complement \(C_a\) is the hyperimmune set in the construction.

A set and its complement have the same Turing degree. One common oracle program queries membership and swaps the two answers zero and one; with oracle \(D_a\) it decides \(C_a\), and with oracle \(C_a\) it decides \(D_a\). Hence

\[C_a\equiv_T D_a\equiv_T A.\]

Thus this construction gives both a hypersimple c.e. representative and a hyperimmune representative of the same nonzero c.e. degree. The hyperimmune representative is not c.e. This is consistent with the distinction between a set being hyperimmune and its degree being hyperimmune.
