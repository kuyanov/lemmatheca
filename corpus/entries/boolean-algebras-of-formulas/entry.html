Identify formulas with the same truth conditions

Fix a set \(P\) of atoms and let \(\mathrm{Form}(P)\) be the finite propositional formulas. Write \(A\sim B\) if \(v(A)=v(B)\) for every valuation \(v:P\to\{0,1\}\). This is semantic equivalence. It is reflexive, symmetric, and transitive, since equality of truth values has those properties. The Boolean algebra of formulas will have underlying set \(\mathbb B(P)=\mathrm{Form}(P)/{\sim}\). Write \([A]\) for the equivalence class of \(A\).

Here and below \(\top\) abbreviates \(\neg\bot\). The relation \(\sim\) concerns every valuation, not just those satisfying a particular theory. Thus \([A]\) is fixed before any premises are chosen.

Equivalence can also be expressed by proofs

For formulas \(A,B\), we have \(A\sim B\) exactly when both \(\{A\}\vdash B\) and \(\{B\}\vdash A\), in the existing natural-deduction calculus.

By soundness and finite-premise completeness, the two derivabilities are equivalent to \(v(A)=1\Rightarrow v(B)=1\) and \(v(B)=1\Rightarrow v(A)=1\), for every \(v\). Two truth values satisfy both implications exactly when they are equal. This proves both directions.

The connectives become operations on equivalence classes

Define meet, join, complement, zero, and one on \(\mathbb B(P)\) by

\[ [A]\wedge[B]=[A\wedge B],\qquad [A]\vee[B]=[A\vee B],\qquad \neg[A]=[\neg A]. \]
\[ 0=[\bot],\qquad 1=[\top]. \]

These definitions are independent of representatives. For example, if \(A\sim A'\) and \(B\sim B'\), then for each \(v\), the truth value of \(A\wedge B\) is the conjunction of the same two truth values as that of \(A'\wedge B'\). Hence their classes agree. The argument for disjunction is identical with “or” in place of “and”; negation applies the same Boolean complement to equal truth values.

The quotient order is \([A]\leq[B]\) if every valuation making \(A\) true makes \(B\) true. Equivalent representatives give the same condition. Thus smaller elements impose stronger demands.

The quotient is a Boolean algebra

The operations above make \(\mathbb B(P)\) a Boolean algebra. Moreover, \([A]\leq[B]\) exactly when \(\{A\}\vdash B\), and implication has the algebraic expression \([A\to B]=\neg[A]\vee[B]\).

To verify an equality of classes it suffices to evaluate at an arbitrary \(v\). Under evaluation, meet, join, and complement become the usual operations on \(\{0,1\}\). Their truth tables give commutativity, associativity, absorption, both distributive laws, the zero and one laws, and

\[ x\wedge\neg x=0,\qquad x\vee\neg x=1. \]

For the order, reflexivity and transitivity follow from implication of truth values. If \(x\leq y\) and \(y\leq x\), their representatives have equal truth values everywhere, so \(x=y\). The condition \(x\leq y\) is also equivalent to \(x\wedge y=x\). Conjunction is the greatest lower bound: it implies both factors, and any formula implying both factors implies their conjunction. Disjunction gives the least upper bound by the dual argument. This verifies the ordered-algebra definition as well as the identities.

Soundness and completeness give the asserted proof description of the order. Finally, \(v(A\to B)=v(\neg A\vee B)\) for each valuation by the implication truth table, giving the last identity.

Each class is its set of satisfying valuations

The map \(\Theta:\mathbb B(P)\to\mathcal P(\{0,1\}^{P})\), given by \(\Theta([A])=\{v:v(A)=1\}\), is injective. It carries meet to intersection, join to union, complement to set complement, \(0\) to the empty set, and \(1\) to the whole valuation space. It also reflects inclusion: \(\Theta(x)\subseteq\Theta(y)\) exactly when \(x\leq y\).

Equivalent formulas have the same satisfying valuations, so the map is well-defined. Conversely, equal truth sets mean that at each valuation either both formulas are true or both are false. Their truth values therefore agree and their classes are equal. Each operation assertion follows directly from its truth table. The inclusion assertion is the definition of the quotient order.

How many classes are there on finitely many atoms?

If \(P\) has \(n\) elements, how many elements does \(\mathbb B(P)\) have?

Show answerHide answer

There are \(2^n\) valuations, and every subset of this finite valuation space is the truth set of a formula. For a valuation \(v\), conjoin the literals \(p\) when \(v(p)=1\) and \(\neg p\) when \(v(p)=0\), over all \(p\in P\). This formula is true only at \(v\). Disjoin these formulas over the desired subset, using \(\bot\) for the empty disjunction. When \(P\) is empty, the one empty conjunction is \(\top\), so the argument still applies. The injectivity of \(\Theta\) now gives \(|\mathbb B(P)|=2^{2^n}\).

A closed theory contains all its consequences

A deductively closed propositional theory is a set \(T\subseteq\mathrm{Form}(P)\) such that \(T\vdash A\) implies \(A\in T\). Here derivability from a set still means a finite proof using finitely many members of that set. Every member of \(T\) is derivable by the assumption rule, so closure says \(A\in T\) exactly when \(T\vdash A\).

For any set of premises \(\Gamma\), its consequence closure is \(\operatorname{Cn}(\Gamma)=\{A:\Gamma\vdash A\}\). This is closed: by strong completeness, it is equally the set of formulas true in every valuation satisfying \(\Gamma\). Any valuation satisfying \(\Gamma\) satisfies all those formulas, so a consequence of \(\operatorname{Cn}(\Gamma)\) is already a consequence of \(\Gamma\).

A theory is consistent if it does not derive \(\bot\). A closed theory is therefore consistent exactly when \(\bot\notin T\).

Closed theories are exactly Boolean filters

Deductively closed theories and filters on \(\mathbb B(P)\) correspond by

\[ F_T=\{[A]:A\in T\},\qquad T_F=\{A:[A]\in F\}. \]

These constructions are mutually inverse and preserve inclusion. A closed theory is consistent exactly when its corresponding filter is proper.

First let \(T\) be closed. If \(A\sim B\), then \(A\in T\) implies \(B\in T\): every model of \(T\) satisfies \(A\) and hence \(B\), so strong completeness and closure apply. Thus \(F_T\) does not depend on representatives. A tautology belongs to \(T\), so \(1\in F_T\). If \(A,B\in T\), every model of \(T\) satisfies \(A\wedge B\), so \([A]\wedge[B]\in F_T\). If \([A]\leq[B]\) and \(A\in T\), the same argument gives \(B\in T\). These are the filter conditions.

Conversely let \(F\) be a filter, and suppose \(T_F\vdash C\). The proof uses a finite list \(A_1,\ldots,A_k\) from \(T_F\). Let \(D=A_1\wedge\cdots\wedge A_k\), with \(D=\top\) when \(k=0\). Soundness gives \([D]\leq[C]\): any valuation satisfying \(D\) satisfies all used premises and hence \(C\). The filter contains \([D]\) by finite meet closure, and therefore contains \([C]\) by upward closure. Thus \(C\in T_F\).

Taking the inverse image and then the image of a filter returns it, since every class has a representative. For a closed theory, taking the image then inverse image returns the original theory by invariance under equivalence. Both constructions plainly preserve inclusion. Finally, \(0\in F_T\) exactly when \(\bot\in T\); for a closed theory this is exactly inconsistency.

A complete consistent theory decides every formula

A closed theory \(T\) is complete and consistent if it is consistent and, for each formula \(A\), either \(A\in T\) or \(\neg A\in T\). The alternatives cannot both hold, since together they derive \(\bot\). A maximal consistent closed theory is a consistent closed theory with no strictly larger consistent closed theory.

These definitions require consistency. The set of all formulas decides every formula but is not a complete consistent theory.

Ultrafilters correspond to complete consistent theories

For a closed theory \(T\), the following are equivalent: \(T\) is complete and consistent; \(T\) is maximal consistent among closed theories; and \(F_T\) is an ultrafilter.

The preceding correspondence preserves inclusion and properness, so maximal consistent closed theories correspond exactly to maximal proper filters. For a proper Boolean filter, maximality is equivalent to deciding every complementary pair: exactly one of \(x,\neg x\) belongs to it. Taking \(x=[A]\) translates this directly into exactly one of \(A,\neg A\) belonging to \(T\). This proves all three equivalences.

Every complete consistent theory comes from one truth assignment

Each valuation \(v\) determines the complete consistent theory \(T_v=\{A:v(A)=1\}\). Conversely, each complete consistent closed theory \(T\) is \(T_v\) for exactly one valuation, namely

\[ v_T(p)=1\quad\Longleftrightarrow\quad p\in T. \]

Consequently valuations correspond bijectively to ultrafilters on \(\mathbb B(P)\).

Soundness makes \(T_v\) closed. It cannot derive \(\bot\), because \(v(\bot)=0\). Each formula has exactly one truth value, so exactly one of \(A,\neg A\) is in \(T_v\).

Conversely define \(v_T\) by the displayed rule. We prove \(v_T(A)=1\) exactly when \(A\in T\), by structural induction. Atoms give the defining rule, and falsum is absent by consistency. For negation, completeness and consistency say \(\neg A\in T\) exactly when \(A\notin T\). For conjunction, \(A\wedge B\in T\) exactly when both \(A,B\in T\), using conjunction introduction and elimination. For disjunction, membership of either disjunct suffices. If neither belongs, completeness gives both negations in \(T\); these and \(A\vee B\) would derive a contradiction by disjunction elimination. Hence membership of the disjunction implies membership of a disjunct.

Finally \(A\to B\) is equivalent to \(\neg A\vee B\), so the implication case follows from invariance under equivalence and the two cases just proved. This completes the induction. Thus \(T=T_{v_T}\). Any valuation with this theory must agree with \(v_T\) on every atom, establishing uniqueness. Combining this with the filter correspondence proves the final assertion.

Consistent premises extend to a complete theory

Every consistent set of premises \(\Gamma\) is contained in a complete consistent closed theory. If \(\Gamma\nvdash A\), one can choose such a theory containing \(\Gamma\) and omitting \(A\).

By consistency and satisfiability, a consistent \(\Gamma\) has a satisfying valuation \(v\). Its theory \(T_v\) is the required extension. If \(\Gamma\nvdash A\), strong completeness says \(\Gamma\not\models A\). Thus there is a valuation satisfying \(\Gamma\) and making \(A\) false; its theory gives the strengthened conclusion. These arguments use the arbitrary-atom compactness theorem already established.

Does every set of valuations represent one formula?

Let \(P=\mathbb N\). Is the singleton consisting of the all-true valuation the truth set of a finite formula?

Show answerHide answer

No. A formula \(A\) contains only finitely many atoms. Choose \(p\) outside that finite set. If the all-true valuation satisfies \(A\), changing just \(p\) to false still satisfies \(A\), by locality of evaluation. Its truth set therefore cannot be that singleton. Thus the representation \(\Theta\) is a Boolean algebra of subsets, but for infinitely many atoms it need not be the entire power set. The distinction is the same one appearing in Boolean representation by sets.
