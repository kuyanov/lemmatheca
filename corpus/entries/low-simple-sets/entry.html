An oracle can leave the first halting degree unchanged

Write \(K\) for the ordinary diagonal halting set, and \(A'=\{e:\varphi_e^A(e)\downarrow\}\) for the jump in the fixed oracle-program numbering. A set \(A\subseteq\mathbb N\) is low if \(A'\equiv_T K\). This compares the halting problem for programs using \(A\) with ordinary halting; it does not assert that \(A\) itself is computable.

Every computable set is low. Indeed \(A\equiv_T\varnothing\), so jump monotonicity in both directions gives \(A'\equiv_T\varnothing'\), and \(\varnothing'\equiv_T K\). For every set, \(K\le_T A'\): apply the same monotonicity to \(\varnothing\le_T A\). Consequently proving lowness requires only the other comparison \(A'\le_T K\).

Every noncomputable low set has hyperimmune degree, because it lies below \(K\). Thus preserving the first jump degree does not make a noncomputable oracle hyperimmune-free.

A noncomputable low set therefore separates hyperimmune degree from highness. Highness requires the jump to compute the second halting problem; Martin’s characterization expresses this as computing one function eventually dominating every ordinary computable function.

A noncomputable low set is strictly below ordinary halting

If \(A\) is low, then \(A\le_T K\) and \(K\not\le_T A\). Hence a noncomputable low set has degree strictly between the computable degree and the halting degree.

The reduction \(A\le_T A'\) from membership queries to halting queries, followed by lowness, gives \(A\le_T K\). If \(K\le_T A\), then \(A'\le_T K\le_T A\), contradicting strictness of the jump. If \(A\) is additionally noncomputable, its degree is nonzero, proving both strict comparisons. Enumerability is not needed for this argument.

Combine positive enumeration requirements with jump protection

We construct one c.e. set \(A\) and a binary function \(g(s,e)\) guessing its jump. Its positive requirements and jump requirements, indexed by \(e\in\mathbb N\), are

\[P_e:\quad W_e\text{ infinite}\ \Longrightarrow\ W_e\cap A\ne\varnothing,\]
\[N_e(g):\quad\exists t\;\forall s\ge t\quad g(s,e)=\chi_{A'}(e).\]

Here \(W_{e,s}\) denotes the canonical finite approximation to the ordinary c.e. set \(W_e\). We will give a particular binary guess for each \(N_e\). Meeting all \(P_e\), while keeping the complement infinite, makes \(A\) simple. A converging computable approximation to \(A'\) will establish \(A'\le_T K\) by the limit lemma.

Positive requirement \(P_e\) must respect the protected computations for \(N_i\) with \(i<e\). It may destroy protection at indices \(i\ge e\), whose records are then discarded. No private reservoir is assigned to \(P_e\): an arbitrary infinite \(W_e\) need not contain a number from a prescribed reservoir.

A record stores a successful allowance rather than the current stage

At stage \(s\), the construction state consists of a binary list describing a finite set \(A_s\subseteq\{0,\ldots,s-1\}\), together with a list \(r_s(0),\ldots,r_s(s-1)\) of natural numbers. Missing entries are zero. The empty lists are the state at stage zero. A positive value \(r_s(i)=k\) is a protected certificate: it records that the bounded evaluator satisfies

\[0<B^{A_s}(k,i,i).\]

Encoded output zero means that no successful result was found within allowance \(k\); any positive encoded output certifies halting. Such a calculation only queries oracle positions below \(k\), by bounded query agreement. We therefore also use \(k\) as its restraint: enumerating numbers at least \(k\) preserves the whole calculation. Record zero means that no certificate is currently protected.

Once captured, a certificate is kept at its fixed allowance until an authorized injury discards it. Replacing it at every stage by the current stage number would give an unnecessarily growing restraint and would not establish stabilization of these records.

Find a new positive witness by a bounded search

At the transition from \(s\) to \(s+1\), call \((e,x)\) an eligible pair if

\[e\le s,\quad x\le s,\quad x\in W_{e,s+1},\quad 2e<x,\]
\[A_s\cap W_{e,s+1}=\varnothing,\qquad \forall i<e\quad r_s(i)\le x.\]

All these tests are bounded finite computations. The intersection test scans inputs at most \(s\); the restraint test scans indices below \(e\). If eligible pairs exist, choose the least eligible \(e\), and then the least eligible \(x\) for it. Say that \(P_e\) acts at stage \(s\). If no pair exists, there is no positive action. The strict threshold \(2e<x\) will keep enough numbers outside the final set.

Enumerate once, discard injured records, and capture new certificates

The successor state is given by the following three finite operations. First, if \((e,x)\) is selected, put \(A_{s+1}=A_s\cup\{x\}\); otherwise put \(A_{s+1}=A_s\). Extend the membership list to length \(s+1\).

Second, form the temporary records \(q(i)\), for \(i\le s\). If \(P_e\) acted, set \(q(i)=r_s(i)\) for \(i<e\) and \(q(i)=0\) for \(i\ge e\). With no action, keep every old record. The newly appended coordinate initially has value zero.

Third, for each \(i\le s\), define

\[r_{s+1}(i)=\begin{cases}q(i),&q(i)>0,\\s+1,&q(i)=0\text{ and }B^{A_{s+1}}(s+1,i,i)>0,\\0,&\text{otherwise}.\end{cases}\]

The oracle in this last test is the new finite set \(A_{s+1}\). All tests in this filling phase use that same set; writing a record does not alter the oracle. This specifies the entire recurrence, including stages with no eligible positive witness.

The complete sequence of finite states is computable

The state at stage \(s\), the selected positive index and witness when present, each membership bit \([x\in A_s]\), and each record \(r_s(i)\) are ordinary computable functions of their numerical inputs.

Encode the two finite lists by the established list coding and pair their codes. Membership bits, record lookups and appending zero are computable list operations. The finite \(W\)-stage test is uniform in its index, stage and input. The bounded evaluator with a supplied finite oracle has an ordinary finite-table algorithm. Every search in has an explicit finite bound, and the filling phase performs exactly \(s+1\) bounded evaluations. Consequently the successor map is a total computable numerical function. Primitive recursion on \(s\), starting with the empty state, computes every state and its projections. No test asks whether an unrestricted computation eventually halts.

Every protected record certifies a genuine current computation

For every \(s\), both lists have length \(s\), all membership entries are binary, and \(A_s\subseteq\{0,\ldots,s-1\}\). The sets increase, and each stage adds at most one new number. Moreover

\[r_s(i)\le s,\qquad r_s(i)>0\ \Longrightarrow\ B^{A_s}(r_s(i),i,i)>0.\]

Induct on \(s\). The empty state satisfies every assertion. An eligible witness has \(x\le s\), and the failed-intersection test ensures \(x\notin A_s\); setting that one bit therefore preserves the membership assertions. Old records above the acting positive index are discarded, and fresh certificates equal \(s+1\), preserving the record bound.

Consider an old positive record that survives a positive action of index \(e\). Its index \(i\) is below \(e\). Eligibility gives \(r_s(i)\le x\), so adding \(x\) changes no oracle position below its allowance. Bounded query agreement preserves its successful calculation in \(A_{s+1}\). A surviving record at a stage without action has the same oracle. A newly captured record is successful by the filling test itself. These are all cases, so every positive record retains the stated meaning.

The increasing union is an enumerable set with settling finite prefixes

Define the constructed set by \(A=\bigcup_s A_s\). It is c.e. For every \(u\), some stage \(t\) satisfies \(A_s\cap[0,u)=A\cap[0,u)\) at every \(s\ge t\).

To recognize \(x\in A\), compute successive states and accept when its membership bit is one. The stage algorithm is total, and acceptance occurs exactly for members of the union. Monotonicity makes every discovery permanent.

For each member of \(A\cap[0,u)\), choose an entry stage. There are finitely many such members, so one stage exceeds all their entry stages. Later finite sets contain them all. A nonmember of \(A\) never appears in a finite set. Thus all positions below \(u\) are correct thereafter. This is an existence proof of a settling stage, not a computable rule producing one.

Each positive requirement acts at most once

For each \(e\), there is at most one stage at which \(P_e\) acts. Consequently, for every \(e\) there is a stage after which no \(P_i\) with \(i\le e\) acts.

If \(P_e\) acts, its selected \(x\) belongs to both \(A_{s+1}\) and \(W_{e,s+1}\). Both approximations increase, so their intersection remains nonempty at every later test. Eligibility for another action of \(P_e\) is then impossible. This argument does not depend on whether its negative records are subsequently reset.

For a fixed finite family \(i\le e\), each index has at most one action stage. Choose a stage beyond all the actions that actually occur in this finite family. After that stage none of them acts. No uniform effective bound on these last action stages is asserted.

After the last injury a record can be filled only once

For every \(i\), the sequence \(r_s(i)\) is eventually constant. After the last positive action of an index at most \(i\), it is either permanently zero or eventually a fixed positive certificate.

Choose a stage \(t>i\) beyond all positive actions at indices at most \(i\), using . Every later positive action has index greater than \(i\), so it preserves this coordinate in the temporary records. The filling rule keeps an already positive coordinate unchanged. If \(r_t(i)>0\), it is fixed from this point. If \(r_t(i)=0\) and it is ever later filled, its first filling is permanent. If it is never filled, it remains zero. These cases prove eventual constancy without needing satisfaction of any positive requirement.

Every infinite enumerable set meets the constructed set

If \(W_e\) is infinite, then \(W_e\cap A\ne\varnothing\).

Choose a stage beyond all actions of indices below \(e\), and beyond stabilization of all records \(r_s(i)\) with \(i<e\). Write \(R\) for a common bound on these finitely many fixed records. Infinitude supplies \(x\in W_e\) with \(x>\max(2e,R)\). At sufficiently late stages, \(e\le s\), \(x\le s\), and \(x\in W_{e,s+1}\).

Suppose \(W_e\cap A\) were empty. Then the finite-intersection test is still negative, and this same \(x\) makes \((e,x)\) eligible. The least-priority search must select some index at most \(e\). Selecting a smaller index contradicts the chosen stage bound on higher actions. Selecting \(e\) puts a member of \(W_e\) into \(A\), contradicting the assumed disjointness. Therefore the intersection is nonempty. The witness may lie anywhere in the sufficiently large tail of \(W_e\), which is why private reservoirs were unnecessary.

The positive threshold leaves infinitely many omissions

For every \(n\), at most \(n\) elements of \(A\) lie in \(\{0,\ldots,2n\}\). Consequently \(A^c\) is infinite.

Every enumerated number \(x\le2n\) was added by some acting \(P_e\), and its threshold gives \(2e<x\le2n\), hence \(e<n\). Assign \(x\) to this producing index. One positive requirement acts at most once and adds only one number, so different enumerated numbers have different producers. This injects \(A\cap\{0,\ldots,2n\}\) into the \(n\) indices below \(n\), proving the bound.

The interval has \(2n+1\) elements, so at least \(n+1\) remain outside \(A\). A finite complement of cardinality \(m\) would violate this conclusion at \(n=m\). Thus the complement is infinite. Together with and , the characterization of simplicity proves that this same \(A\) is simple and therefore noncomputable.

An uninjured positive record certifies final-oracle halting

Fix \(i\). Suppose \(r_t(i)=k>0\), with \(t>i\), and no positive requirement of index at most \(i\) acts at any stage \(s\ge t\). Then \(r_s(i)=k\) for all \(s\ge t\), and \(\varphi_i^A(i)\downarrow\).

The record is preserved by the update rule. At each later stage, a positive action has index \(e>i\), and eligibility requires its new number to be at least \(r_s(i)=k\). Thus no later addition changes an oracle bit below \(k\). Induction gives agreement between \(A_t\) and every later finite oracle on this prefix; the union agrees there as well.

The invariant supplies \(B^{A_t}(k,i,i)>0\). Bounded query agreement gives the same positive value for \(B^A(k,i,i)\). The correctness of bounded evaluation turns this certificate into halting for the final oracle. The argument preserves a fixed successful calculation, rather than trying to make an ever-growing finite prefix correct at once.

The protected-record guesses converge to the jump

The specified jump approximation

\[g(s,i)=[r_s(i)>0]\]

is jointly computable, binary, and converges pointwise to \(\chi_{A'}\). Hence \(A'\) is limit computable.

Computability follows from the state algorithm and a numerical comparison. Fix \(i\), and go beyond its last possible injury and the stabilization of its record. If its fixed record is positive, proves \(i\in A'\), and all sufficiently late guesses are one.

Suppose instead its record is permanently zero. If \(\varphi_i^A(i)\) halted, bounded completeness would supply a fixed allowance \(k\) with \(B^A(k,i,i)>0\). By , the finite oracles eventually agree with \(A\) below \(k\). Query agreement then reproduces this successful calculation in \(A_{s+1}\) at allowance \(k\). Choose \(s\) late enough that also \(s+1\ge k\) and \(i\le s\). Increasing the allowance preserves success with this same finite oracle, so \(B^{A_{s+1}}(s+1,i,i)>0\). The filling rule must set \(r_{s+1}(i)=s+1\), contradicting permanent zero. Thus \(i\notin A'\), and every sufficiently late guess is zero.

These two cases prove the pointwise convergence, with a possibly different stabilization stage for each input. They supply precisely an ordinary computable limit approximation to the actual jump of the constructed set.

The construction gives a low simple enumerable set

The specified computable stages produce a simple c.e. set \(A\) such that \(A'\equiv_T K\). In particular, \(A\) is noncomputable and \(A<_T K\).

Simplicity was established in . The approximation in , together with the limit lemma, gives \(A'\le_T K\). The reverse reduction holds for every oracle by . Thus \(A\) is low. A simple set is noncomputable, and gives the strict upper bound. The same set satisfies all conclusions; no separate choice of a low oracle replaces the set produced by the stage recurrence.

Lowness can also be imposed while partitioning a prescribed enumerable set: Sacks splitting gives two low c.e. pieces whose union is the input, with simultaneous avoidance of a supplied noncomputable limit-computable set.

There are also noncomputable low 1-generic sets. A generic computes no noncomputable c.e. set, so its degree cannot be the degree of a noncomputable c.e. set.

Why discard a record after a higher-priority enumeration?

A program asks whether \(q\) belongs to its oracle, halts if the answer is zero, and runs forever if the answer is one. A finite oracle omits \(q\), so the program has a successful bounded certificate. What happens if an unrestricted later enumeration adds \(q\)?

Show answerHide answer

The final oracle now makes the program diverge. The earlier certificate therefore cannot certify its final-oracle halting. Protecting a prefix that contains \(q\) prevents this injury by lower-priority positive requirements. A higher-priority action is allowed to change such a bit, and resetting the affected records prevents their stale certificates from being used as permanent evidence. The filling phase may immediately find another valid current certificate; the convergence proof requires only that injuries to each fixed coordinate eventually cease.

Does a low jump make its original oracle computable?

If \(A'\equiv_T K\), must \(A\) be computable? Does the construction provide an ordinary algorithm for its final jump bits?

Show answerHide answer

No to both. The set in is low and noncomputable. Its jump is Turing equivalent to the undecidable set \(K\), so it too is undecidable. The ordinary construction computes stage guesses for its jump, and those guesses converge; it does not compute a stage after the last injury or after the final successful capture. The limit lemma explains exactly why a halting oracle can decide their limits.
