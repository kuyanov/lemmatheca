Bound the number of available parameters

Fix a nonempty first-order \(L\)-structure \(M\) and an infinite cardinal \(\kappa\). We use classical Choice, with no countability assumption on the language. For \(A\subseteq M\), let \(M_A\) be the expansion naming every point of \(A\), and put \(S_n^M(A)=S_n(\operatorname{Th}(M_A))\).

The structure is \(\kappa\)-saturated if

\[\forall A\subseteq M\ (|A|<\kappa)\quad\forall q\in S_1^M(A)\quad\exists b\in M\;[\operatorname{tp}^M(b/A)=q].\]

A structure with infinite carrier is saturated when it is \(|M|\)-saturated. The strict inequality bounds the parameter set, not the number of formulas in a type. Thus a type may have many formulas even when its parameter set is empty.

The definition includes the familiar small parameter tests

If \(\lambda\le\kappa\), then \(\kappa\)-saturation implies \(\lambda\)-saturation. Saturation at \(\aleph_0\) is exactly the finite-parameter condition; saturation at \(\aleph_1\) is exactly realization of all complete one-types over at most countable parameter sets. Every finite nonempty structure is \(\kappa\)-saturated for every infinite \(\kappa\).

The first assertion follows because \(|A|<\lambda\) implies \(|A|<\kappa\). A set has cardinality below \(\aleph_0\) exactly when it is finite, and below \(\aleph_1\) exactly when it is at most countable. These give the two specializations, including the ultraproduct convention. For finite \(M\), every type consistent with its named complete theory has a realization by the finite-structure type lemma, for any subset of parameters.

A partial elementary map may have an infinite domain

A partial elementary map from \(M\) to \(N\) is an injective function \(f:A\to N\), with \(A\subseteq M\), preserving every formula on every finite tuple from \(A\):

\[M\models\varphi(\bar a)\quad\Longleftrightarrow\quad N\models\varphi(f\bar a).\]

Write \(B=f[A]\), so \(f:A\to B\) is a bijection. Neither set must be a substructure; all terms and quantifiers are evaluated in the ambient structures. This extends the finite elementary-map definition. The empty tuple is allowed, so the empty map is elementary exactly when \(M\equiv N\). An extension retains every old value and may enlarge the domain; write \(f\subseteq g\) for inclusion of their graphs. Restrictions and inverse bijections are partial elementary by the same truth equivalences.

Move an actual type through the specified map

Let \(f:A\to B\) be partial elementary. Replace every parameter name \(c_a\) in an \(L(A)\)-formula by \(c_{f(a)}\), leaving its displayed variables and original language symbols fixed. Denote this parameter renaming by \(\varphi\mapsto\varphi^f\). For \(q\in S_n^M(A)\), its pushforward \(f_*q=\{\varphi^f:\varphi\in q\}\) belongs to \(S_n^N(B)\). The inverse renaming recovers the original type.

Every formula uses only finitely many of the named parameters, even when \(A\) is infinite. Given finitely many members of \(f_*q\), take their preimages in \(q\). Their conjunction is realized in \(M_A\) by the finite parameter-type test. Existentially quantify its displayed variables and replace its finitely many names by free variables. Partial elementarity transfers that formula, with its actual parameter tuple, to \(N\). The renamed conjunction is therefore realized in \(N_B\). This proves consistency with the named complete theory there. Renaming by a bijection is bijective on formulas and preserves negation. Since \(q\) decides every formula, so does its consistent image, proving completeness. Renaming back restores each formula. The argument also covers empty conjunctions and the context of zero displayed variables.

Saturation extends the given small map without changing its values

Suppose \(N\) is \(\kappa\)-saturated, \(f:A\to B\) is partial elementary, and \(|A|<\kappa\). For every \(a\in M\), there are \(b\in N\) and a partial elementary map

\[g:A\cup\{a\}\longrightarrow B\cup\{b\},\qquad f\subseteq g,\qquad g(a)=b.\]

If \(a\notin A\), then \(b\notin B\). Both enlarged sets still have size below \(\kappa\).

If \(a\in A\), keep the map and its existing value. Otherwise take \(q=\operatorname{tp}^M(a/A)\) and push it forward using . The bijection \(f:A\to B\) gives \(|B|=|A|<\kappa\), so saturation realizes \(f_*q\) at a point \(b\in N\). For every \(d\in A\), the formula \(x\ne c_d\) belongs to \(q\). Consequently \(b\ne f(d)\), and adjoining \(a\mapsto b\) is injective.

To check elementarity, take a finite tuple from \(A\cup\{a\}\). Replace each occurrence of \(a\) by the same new variable and each remaining coordinate by its actual parameter name. The resulting \(L(A)\)-formula is true at \(a\) exactly when it belongs to \(q\). Its parameter-renamed formula is true at \(b\) exactly when it belongs to \(f_*q\). These two conditions agree, proving the required truth equivalence for the original tuple. This also handles repeated coordinates. Since \(\kappa\) is infinite, adding one point to a set of size below it leaves its size below it.

One-variable saturation realizes all finite tuple types

The structure \(M\) is \(\kappa\)-saturated if and only if every partial type in any finite number \(n\) of variables over any \(A\subseteq M\) of size below \(\kappa\), consistent with \(\operatorname{Th}(M_A)\), is realized in \(M\).

A partial type has a complete extension, so it suffices to realize complete finite tuple types. By elementary realization, choose an elementary embedding \(e:M\to E\) and a tuple \(\bar c\in E^n\) realizing the requested conditions with parameters \(e[A]\). Start with the partial elementary map \(e(a)\mapsto a\), for \(a\in A\), from \(E\) back to \(M\). Apply successively to the coordinates of \(\bar c\). At each of these finitely many steps the domain has size at most \(|A|+n<\kappa\), and the old assignments remain fixed.

The resulting finite tuple \(\bar b\) in \(M\) satisfies every original type formula. Indeed such a formula has finitely many parameters from \(A\); apply the final map's elementary truth equivalence to that parameter tuple together with \(\bar c\). It fixes each indicated parameter and takes \(\bar c\) to \(\bar b\). For \(n=0\), the initial map already gives this conclusion, and the empty tuple is the realization. Conversely take \(n=1\) and a complete type to recover the defining saturation condition.

Compatible elementary maps have an elementary union

The graph union \(g=\bigcup_{i\in I}f_i\) of a nonempty chain of partial elementary maps, ordered by extension, is a partial elementary map. Its domain and range are the respective unions of the domains and ranges, and it retains every old value.

Two maps in the chain are comparable, so their values agree wherever both are defined. This makes the union a function. Any two arguments, and their values, occur together in one chain member; its injectivity proves injectivity of the union. More generally a finite tuple from the union's domain lies in one member: repeatedly take the larger member for its finitely many coordinates. For an empty tuple choose any member, using the nonemptiness assumption. That member's elementary truth equivalence proves the union's equivalence for the same formula and tuple. A value occurs in the union precisely when it occurs in a member, giving the asserted range identity.

Count new points instead of taking an unrestricted small union

Suppose a continuous increasing sequence of partial elementary maps starts with \(f_0:A_0\to B_0\), adds at most two new domain points and two new range points at each successor stage, and takes unions at nonzero limits. At every ordinal stage \(\alpha\),

\[|A_\alpha|\le |A_0|+2|\alpha|,\qquad |B_\alpha|\le |B_0|+2|\alpha|.\]

If \(\kappa\) is infinite, \(|A_0|,|B_0|<\kappa\), and \(\alpha<\kappa\), both stage sets have size below \(\kappa\).

Every point not in the initial domain appears first at a successor stage, since a limit stage is a union. For each stage order its at most two new points, and label each by that stage and its position, zero or one. This injects all added points before stage \(\alpha\) into \(\alpha\times\{0,1\}\). Together with the initial set this proves the domain bound; do the same for the range.

For \(\kappa=\aleph_0\), an ordinal \(\alpha<\kappa\) is finite, so this is a sum of finite sets. For uncountable \(\kappa\), finite sums of infinite cardinal bounds are their maximum. The maximum of \(|A_0|,|B_0|,|\alpha|,\aleph_0\) is below \(\kappa\), and bounds both displayed sums. This does not require \(\kappa\) to be regular. It avoids the different assertion that every union of fewer than \(\kappa\) sets of size below \(\kappa\) has size below \(\kappa\).

A saturated target receives a source of bounded size

Suppose \(N\) is \(\kappa\)-saturated, \(|M|\le\kappa\), and \(f\) is a partial elementary map from \(M\) to \(N\) whose domain has size below \(\kappa\). Then there is an elementary embedding \(e:M\to N\) extending the specified \(f\). In particular, if \(M\equiv N\), the empty map gives such an embedding.

Use Choice and \(|M|\le\kappa\) to enumerate the nonempty carrier as \((m_\alpha)_{\alpha<\kappa}\), allowing repetitions. Start with \(f_0=f\). At successor stage \(\alpha+1\), use to include \(m_\alpha\); a repeated request leaves the map unchanged. At each nonzero limit take the actual compatible union. The stage bound guarantees a domain below \(\kappa\) whenever \(\alpha<\kappa\), so every successor request is legitimate.

The union at \(\kappa\) has total domain because every source point was requested. It is injective and preserves every formula by the union lemma. Its total function is the desired elementary embedding, with all old values still equal to those of \(f\). The size of \(N\) is unrestricted in this one-way construction.

Answer requests from both structures at each round

Let \(M,N\) be \(\kappa\)-saturated, with \(|M|,|N|\le\kappa\). Every partial elementary map \(f\) from \(M\) to \(N\), of domain size below \(\kappa\), extends to an isomorphism \(M\cong N\). Consequently elementarily equivalent \(\kappa\)-saturated structures of size \(\kappa\) are isomorphic.

Enumerate both nonempty carriers by \(\kappa\), with repetitions. At round \(\alpha\), extend the current map to include \(m_\alpha\) in its domain. Now invert this extended map, use saturation of \(M\) to include \(n_\alpha\) in the inverse domain, and invert back. Both parts preserve every old assignment; the second also preserves the point just added by the first. Each round adds at most two points on each side.

At limits use compatible unions. The explicit size bound applies to each initial segment, and also to the intermediate first half-round after adding one point. It keeps both parameter sets below \(\kappa\) when needed. The final union has all of \(M\) as domain and all of \(N\) as range. It is therefore bijective and preserves every formula. In particular it preserves functions, constants and relations, hence is an isomorphism. For the consequence, elementary equivalence supplies the initial empty map.

The resulting automorphism preserves every prescribed old value

If \(M\) is \(\kappa\)-saturated and \(|M|\le\kappa\), every partial elementary self-map of domain size below \(\kappa\) extends to an automorphism. In particular, if \(A\subseteq M\) has size below \(\kappa\) and finite tuples \(\bar a,\bar b\) have the same type over \(A\), some automorphism fixes \(A\) pointwise and takes \(a_i\) to \(b_i\) for every coordinate.

The first assertion is with source and target both \(M\). For the second, join the identity on \(A\) with the assignments \(a_i\mapsto b_i\). Equality of the types preserves equalities between repeated coordinates and equalities to each named point of \(A\), so this is a well-defined injection. Every formula on its domain can be rewritten using the finite tuple variables and finitely many names from \(A\); equality of types gives its elementary truth equivalence. Its domain is contained in \(A\) plus finitely many coordinates, hence still has size below \(\kappa\). Extend this exact map by the first assertion.

What happens at a singular cardinal?

Take \(\kappa=\aleph_\omega\). An increasing union of countably many sets of sizes \(\aleph_n\) can have size \(\kappa\). Does this invalidate the construction above at a limit stage below \(\kappa\)?

Show answerHide answer

No. An arbitrary small-union principle would fail here, but our maps add at most two points per round. At stage \(\alpha<\kappa\), all new points are indexed by \(\alpha\times\{0,1\}\); their size is bounded by \(2|\alpha|\), independent of the earlier domains' possible bounds. Adding the fixed initial set gives the stage-size estimate. For instance at the countable stage \(\omega\), only countably many points were added, rather than successive families of sizes \(\aleph_n\). The proof therefore works at singular \(\kappa\) without a regularity assumption.

How far does the automorphism conclusion extend?

If \(M\) is \(\kappa\)-saturated but \(|M|>\kappa\), does the argument above prove that every small partial elementary map extends to an automorphism? Does it construct a saturated model in each prescribed cardinality?

Show answerHide answer

It proves neither statement. The global argument enumerates the whole carrier in \(\kappa\) rounds. With a larger carrier those requests need more rounds, where the stage domains need no longer have size below \(\kappa\); the one-point lemma then no longer supplies the next value. The one-point extension result itself still applies to every small map into a \(\kappa\)-saturated target. Producing saturated models of a prescribed size is a separate existence problem with its own cardinal arithmetic requirements. The existing unrestricted-size omega-saturated extension theorem does not give that size control.
