Permit different target sizes in the two colours

Work in ZFC. A two-colouring is a map \(c:[X]^2\to\{0,1\}\) on unordered pairs of distinct points, with the usual meaning of homogeneity. Write

\[\kappa\longrightarrow(\lambda,\mu)^2\]

when every such colouring on a set of size \(\kappa\) has either a \(0\)-homogeneous subset of size \(\lambda\), or a \(1\)-homogeneous subset of size \(\mu\). The order of the two targets matters. The notation \(\kappa\to(\lambda)^2_2\) requires size \(\lambda\) in either colour; a crossed arrow means that a counterexample colouring exists.

The real order has no strictly monotone omega one sequence

There is no strictly increasing sequence \((r_\alpha)_{\alpha<\omega_1}\) of real numbers, and no strictly decreasing one.

Proof

For an increasing sequence, choose a rational \(q_\alpha\) with \(r_\alpha<q_\alpha<r_{\alpha+1}\), using rational density. If \(\alpha<\beta\), then \(q_\alpha<r_{\alpha+1}\le r_\beta<q_\beta\). Thus the \(q_\alpha\)'s are distinct, an impossible injection of \(\omega_1\) into the countable set \(\mathbb Q\). Negating a decreasing sequence makes it increasing.

□

Sierpiński: uncountable Ramsey homogeneity fails

\(\omega_1\nrightarrow(\omega_1)^2_2\).

Proof

Since \(\aleph_1\le\mathfrak c\), choose distinct reals \(r_\alpha\), \(\alpha<\omega_1\). For \(\alpha<\beta\), define

\[c(\{\alpha,\beta\})=\begin{cases}0& r_\alpha<r_\beta,\\1&r_\beta<r_\alpha.\end{cases}\]

The reals are distinct, so exactly one case applies. Suppose \(H\subseteq\omega_1\) were uncountable and homogeneous. Its increasing enumeration has order type \(\omega_1\): every proper initial segment is countable, whereas \(H\) itself is not. Along that enumeration the corresponding real sequence is strictly increasing in colour \(0\), or strictly decreasing in colour \(1\). Both contradict .

□

Large neighbourhoods either persist or leave room for a recursion

Let \(\kappa\) be a regular infinite cardinal, and \(c:[\kappa]^2\to\{0,1\}\). For \(x\in\kappa\), put \(N_1(x)=\{y\ne x:c(\{x,y\})=1\}\). Exactly one of the following alternatives holds:

\[\begin{aligned}&\text{for every }X\subseteq\kappa\text{ with }|X|=\kappa,\ \exists x\in X:\ |N_1(x)\cap X|=\kappa;\\&\exists X\subseteq\kappa:\ |X|=\kappa\text{ and }\forall x\in X,\ |N_1(x)\cap X|<\kappa.\end{aligned}\]

Proof

The second assertion is the negation of the first, since all the neighbourhoods in question are subsets of a set of size \(\kappa\). This dichotomy does not use regularity yet.

□

Dushnik–Miller for regular infinite cardinals

For every regular infinite cardinal \(\kappa\), \(\kappa\to(\kappa,\omega)^2\).

Proof

Use . In its first case, start with \(X_0=\kappa\). Choose \(x_n\in X_n\) with \(|N_1(x_n)\cap X_n|=\kappa\), and put \(X_{n+1}=N_1(x_n)\cap X_n\). Every \(X_n\) still has size \(\kappa\). The chosen points are distinct because \(x_n\notin N_1(x_n)\); nesting shows that for \(i<j\), \(x_j\in N_1(x_i)\). Thus \(\{x_n:n<\omega\}\) is an infinite \(1\)-homogeneous set.

In the second case, choose a sequence \((x_\alpha)_{\alpha<\kappa}\) inside the supplied \(X\). At stage \(\alpha\), exclude the set

\[E_\alpha=\{x_\beta:\beta<\alpha\}\cup\bigcup_{\beta<\alpha}(N_1(x_\beta)\cap X).\]

This is a union of fewer than \(\kappa\) sets, each of size less than \(\kappa\). It has size less than \(\kappa\) by regularity, also for \(\kappa=\aleph_0\), when the union is finite. Hence \(X\setminus E_\alpha\) is nonempty; choose \(x_\alpha\) there. This gives \(\kappa\) distinct points, and every pair has colour \(0\) since the later point avoids the earlier point's \(1\)-neighbourhood.

□

Do the positive and negative results conflict?

How can \(\omega_1\to(\omega_1,\omega)^2\) hold while \(\omega_1\nrightarrow(\omega_1)^2_2\)?

Show answerHide answer

The positive assertion permits only a countably infinite set in colour \(1\). For Sierpiński's colouring there is no uncountable homogeneous set in either colour, so the positive assertion must supply an infinite \(1\)-homogeneous set, a decreasing sequence of the selected reals. Countable decreasing real sequences are possible; uncountable ones are not.

Where was regularity needed?

Which part of the proof fails to follow from the same estimates for a singular cardinal?

Show answerHide answer

The infinite \(1\)-homogeneous construction uses no regularity. The \(0\)-homogeneous construction requires \(|E_\alpha|<\kappa\). For singular \(\kappa\), the small-union characterization of regularity supplies fewer than \(\kappa\) sets of sizes less than \(\kappa\) whose union has size at least \(\kappa\). Choose a subset of the union of size \(\kappa\) and intersect each member with it: the resulting sets still have size less than \(\kappa\), and their union has size exactly \(\kappa\). For example, \(\aleph_\omega\) is the union of its initial segments of sizes \(\aleph_n\). This explains the limit of this proof, without supplying the singular-cardinal theorem.
