Countable initial segments give a matrix on omega one

Work in ZFC. A stationary set in a regular uncountable cardinal meets every closed unbounded set. Such sets need not contain a club. We will split one stationary set into many disjoint stationary pieces.

For each \(\beta<\omega_1\), choose an injection \(e_\beta:\beta\to\omega\), possible because \(\beta\) is countable. For \(n<\omega\) and \(\alpha<\omega_1\), define

\[A^n_\alpha=\{\beta<\omega_1:\alpha<\beta\text{ and }e_\beta(\alpha)=n\}.\]

The indices play different roles: for a fixed \(\alpha\), varying \(n\) partitions the tail above \(\alpha\); for a fixed \(n\), varying \(\alpha\) gives disjoint cells because each \(e_\beta\) is injective. This is an Ulam matrix.

Every stationary subset of omega one has omega one disjoint stationary pieces

If \(S\subseteq\omega_1\) is stationary, there are pairwise disjoint stationary sets \(S_\xi\subseteq S\), for \(\xi<\omega_1\).

Proof

For each \(\alpha\), the sets \(S\cap A^n_\alpha\), \(n<\omega\), cover the stationary tail \(S\setminus(\alpha+1)\). At least one is stationary: otherwise their countable union would be nonstationary by completeness of the nonstationary ideal. Choose one such index \(n(\alpha)\).

Some fiber \(H=\{\alpha:n(\alpha)=n_*\}\) is uncountable, since \(\omega_1\) is not a countable union of countable sets. List \(H\) without repetition as \((\alpha_\xi)_{\xi<\omega_1}\). Set \(S_\xi=S\cap A^{n_*}_{\alpha_\xi}\). These sets are stationary by the choice of the indices and disjoint by row injectivity.

□

The same matrix works on every infinite successor cardinal

Let \(\kappa\) be an infinite cardinal and \(\lambda=\kappa^+\), both identified with their initial ordinals. The cardinal \(\lambda\) is regular. Every \(\beta<\lambda\) has cardinality at most \(\kappa\), so choose an injection \(e_\beta:\beta\to\kappa\). Put

\[A^i_\alpha=\{\beta<\lambda:\alpha<\beta\text{ and }e_\beta(\alpha)=i\}\quad(i<\kappa,\ \alpha<\lambda).\]

The choice of all these injections uses Choice; the construction is indexed by the set \(\lambda\).

Rows and columns are disjoint, and columns cover tails

For the matrix just defined:

\[\begin{aligned}i\ne j&\implies A^i_\alpha\cap A^j_\alpha=\varnothing,\\\alpha\ne\gamma&\implies A^i_\alpha\cap A^i_\gamma=\varnothing,\\\bigcup_{i<\kappa}A^i_\alpha&=\lambda\setminus(\alpha+1).\end{aligned}\]

Proof

A function gives only one value to \(\alpha\), proving the first identity. If \(\beta\) belonged to the two cells in the second identity, injectivity of \(e_\beta\) would force \(\alpha=\gamma\). Every \(\beta>\alpha\) assigns some value below \(\kappa\) to \(\alpha\), giving the last identity.

□

Ulam splitting at successor cardinals

For every infinite cardinal \(\kappa\), every stationary \(S\subseteq\kappa^+\) is the union of \(\kappa^+\) pairwise disjoint stationary sets.

Proof

Put \(\lambda=\kappa^+\). Each column decomposes \(S\setminus(\alpha+1)\) into \(\kappa<\lambda\) cells. This tail is stationary, so one cell \(S\cap A^{i(\alpha)}_\alpha\) is stationary by the small-union property.

There is an \(i_*<\kappa\) whose fiber \(H=\{\alpha<\lambda:i(\alpha)=i_*\}\) has size \(\lambda\). Otherwise every fiber has size at most \(\kappa\), and their union has size at most \(\kappa\cdot\kappa=\kappa\), contradicting its size \(\lambda\). This uses infinite cardinal multiplication.

Choose a bijection \(\xi\mapsto\alpha_\xi\) from \(\lambda\) onto \(H\), and put \(P_\xi=S\cap A^{i_*}_{\alpha_\xi}\). The matrix identities give disjoint stationary subsets. To make a partition of all of \(S\), put \(R=S\setminus\bigcup_{\xi<\lambda}P_\xi\), replace \(P_0\) by \(P_0\cup R\), and keep all other cells. The enlarged cell is stationary because it contains a stationary set; the cells are disjoint and now cover \(S\).

□

Could every piece be a club?

Can two of the disjoint stationary pieces both contain clubs?

Show answerHide answer

No. Two clubs in the regular uncountable cardinal \(\lambda\) have club intersection, hence meet. If disjoint pieces each contained a club, those two clubs would be disjoint. In particular, none of the pieces of the partition can contain a club: it would have to meet every other stationary piece.

Why is the number of pieces optimal?

Could \(S\subseteq\kappa^+\) have more than \(\kappa^+\) nonempty disjoint pieces?

Show answerHide answer

No. Choose one point from each nonempty piece. Disjointness makes this choice map injective into \(S\subseteq\kappa^+\). The Ulam partition has the largest possible number of nonempty pieces. This upper-bound argument works for any ambient set. The Ulam construction above uses that the ambient cardinal is a successor; it does not establish splitting at every regular uncountable cardinal.
