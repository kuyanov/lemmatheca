Use full formulas and finite allowed assumptions

Fix a language \(L\) and a set \(X\) of free parameter names. We use the full formula trees with primitive \(\bot,\neg,\land,\lor,\to,\forall,\exists\), relation atoms and logical equality. A context \(\Gamma\) is a finite set of complete formulas over \(X\). Write \(\Gamma,A\) for \(\Gamma\cup\{A\}\). Assumptions may be used repeatedly; their order has no role.

A raw intuitionistic derivation of \(\Gamma\Rightarrow A\) is a finite tree generated by the rules in the next three definitions. Its undischarged assumptions must belong to \(\Gamma\), which may contain unused formulas. Temporary assumptions in an introduction or elimination branch are inserted into that branch's context. A derivation is the actual finite tree, rather than the assertion that its conclusion is true in some interpretation.

Apply constructive propositional rules to full formulas

The propositional rules are exactly the intuitionistic rules, now applied to arbitrary full first-order formulas. An assumption leaf gives \(\Gamma\Rightarrow A\) when \(A\in\Gamma\). Conjunction introduction combines proofs of \(A,B\) with the same context; its two eliminations project either factor. Disjunction introduction supplies either chosen disjunct, and its elimination is

\[\frac{\Gamma\Rightarrow A\lor B\quad\Gamma,A\Rightarrow C\quad\Gamma,B\Rightarrow C}{\Gamma\Rightarrow C}.\]

Implication and primitive negation have the rules

\[\frac{\Gamma,A\Rightarrow B}{\Gamma\Rightarrow A\to B},\qquad \frac{\Gamma\Rightarrow A\to B\quad\Gamma\Rightarrow A}{\Gamma\Rightarrow B}.\]
\[\frac{\Gamma,A\Rightarrow\bot}{\Gamma\Rightarrow\neg A},\qquad \frac{\Gamma\Rightarrow A\quad\Gamma\Rightarrow\neg A}{\Gamma\Rightarrow\bot}.\]

Falsum elimination gives \(\Gamma\Rightarrow C\) from \(\Gamma\Rightarrow\bot\). These are the entire propositional rule list. In particular, there is no rule deriving \(A\) merely from a contradiction under \(\neg A\). Conjunction, disjunction and existence keep their own full trees; the smaller classical abbreviations are not substituted for these constructive connectives.

Keep witnesses and arbitrary parameters distinct

Let \(B\) be a full one-slot body over \(X\), and let \(t\) be a term over \(X\). Its instance is \(B(t)\). The witness rules are

\[\frac{\Gamma\Rightarrow\forall xB}{\Gamma\Rightarrow B(t)},\qquad \frac{\Gamma\Rightarrow B(t)}{\Gamma\Rightarrow\exists xB}.\]

For the other two rules, extend free names to \(X\sqcup\{e\}\). Write \(\Gamma^\uparrow\) and \(C^\uparrow\) for renaming original names into the left component, and \(\operatorname{open}(B)\) for the body's available slot opened as the new right-tagged parameter \(e\). The eigenparameter rules are

\[\frac{\Gamma^\uparrow\Rightarrow\operatorname{open}(B)}{\Gamma\Rightarrow\forall xB},\qquad \frac{\Gamma\Rightarrow\exists xB\quad\Gamma^\uparrow,\operatorname{open}(B)\Rightarrow C^\uparrow}{\Gamma\Rightarrow C}.\]

The tag guarantees that \(e\) occurs in neither the lifted ambient assumptions nor the lifted concluding formula. Universal introduction can therefore vary its value without changing those assumptions. Existential elimination may reason from its witness assumption, but the conclusion may not retain that witness name. Each rule has finitely many premise trees; the universal rule does not contain a separate premise for every domain element.

Equality substitutes terms inside an arbitrary formula

The logical equality rules are reflexivity and replacement. For every term \(t\), there is a leaf deriving \(\Gamma\Rightarrow t=t\). For any one-slot full body \(B\) and terms \(s,t\), replacement is

\[\frac{\Gamma\Rightarrow s=t\quad\Gamma\Rightarrow B(s)}{\Gamma\Rightarrow B(t)}.\]

The body may contain quantifiers or any full connective. Its slot is instantiated capture-free, so replacement does not bind a free name of the inserted term. These rules speak about the logical equality constructor, not an arbitrary relation symbol whose printed name happens to be equality. An equality-disabled derivation omits both of these rules while keeping the logical rules; equality formulas, if present, then have only the status of uninterpreted atomic assumptions.

Permit temporary names without changing the conclusion

Fix a disjoint countable set \(U=\{u_0,u_1,\ldots\}\). An intuitionistic certificate of \(\Gamma\Rightarrow A\) is a raw derivation over \(X\sqcup U\), with end context and conclusion obtained by renaming \(\Gamma,A\) into the \(X\)-component. Write \(\Gamma\vdash_{\mathrm I}A\) when such a certificate exists. The same reserve convention applies to equality-disabled derivations.

No auxiliary name occurs in the end formulas, although finitely many may occur inside the proof. A language without constant symbols can consequently use a temporary name as a witness. This is the same reserve convention used for the established classical calculus. It is different from introducing a new nonlogical constant into \(L\): all term and relation symbols remain unchanged.

Enlarge the allowed assumptions

For raw derivations and certificates, if \(\Gamma\subseteq\Delta\), a supplied proof of \(\Gamma\Rightarrow A\) gives a proof of \(\Delta\Rightarrow A\). The transformation keeps the same logical rule at every corresponding node.

Recurse on the finite raw tree. An assumption leaf remains licensed by inclusion; a reflexivity leaf remains the same leaf. A propositional rule reapplies to its transformed premises. In a branch with temporary \(B\), enlarge the contexts by the same \(B\). For an eigenparameter branch, lifting context inclusion preserves inclusion, so transform that branch under \(\Gamma^\uparrow\subseteq\Delta^\uparrow\), again adding its witness assumption when required. The equality-replacement rule reapplies to the two transformed premises. These cases cover the entire rule list.

For a certificate, first rename the context inclusion into the reserve and apply the raw transformation. The end formulas are precisely the renamed formulas required by the certificate definition. No rule permitting an unrelated conclusion has been added.

Substitute throughout an entire proof

Let \(\sigma:X\to\operatorname{Term}(Y)\) be any free-parameter substitution. A supplied raw derivation of \(\Gamma\Rightarrow A\) gives one of \(\Gamma[\sigma]\Rightarrow A[\sigma]\). The same holds for certificates, including equality-disabled ones.

Induct on the proof with the target parameter set and substitution arbitrary. An assumption becomes its image in the image context. Propositional rules retain their shape, since substitution commutes with every full connective and with insertion of a temporary assumption. Reflexivity replaces \(t=t\) by \(t[\sigma]=t[\sigma]\).

At universal elimination or existential introduction, use the instance identity \((B(t))[\sigma]=(B[\sigma])(t[\sigma])\). This identifies the transformed premise and conclusion with a genuine instance of the same rule. At equality replacement, the identical law transforms the displayed body instances at both \(s\) and \(t\).

At an eigenparameter rule, extend \(\sigma\) by sending an original name to its replacement term with a left tag, and send the new right-tagged name to the new right-tagged name. This protected substitution transforms the lifted context to the lift of \(\Gamma[\sigma]\), and transforms \(\operatorname{open}(B)\) to \(\operatorname{open}(B[\sigma])\). These are exactly the full-syntax opening identities. The transformed rule therefore satisfies its freshness condition automatically.

For a certificate, extend \(\sigma\) also across the auxiliary reserve, leaving each \(u_i\) as its corresponding new auxiliary parameter. Apply the raw transformation; its renamed end formulas are the required image context and conclusion. No equality rule appears if none appeared in the input proof.

Replace open assumptions by supplied proofs

For any finite contexts \(\Gamma,\Delta\), a proof of \(\Gamma\Rightarrow A\), together with a proof of \(\Delta\Rightarrow B\) for every \(B\in\Gamma\), gives a proof of \(\Delta\Rightarrow A\). This is a syntactic transformation of raw derivations. It also holds for certificates and for each of the equality-enabled and equality-disabled calculi.

Induct on the consumer tree, with target context arbitrary. Replace an assumption leaf by its supplied proof, then reapply each rule to its transformed children. Under a temporary assumption \(C\), supply \(C\) by its own leaf and weaken the supplied ambient replacements to allow \(C\). This handles implication, negation and the two disjunction branches.

For an eigenparameter branch, first rename every ambient replacement into the larger parameter set. Thus a leaf coming from \(B^\uparrow\) receives the renamed proof of \(B\). If the branch also assumes \(\operatorname{open}(D)\), supply that assumption by its leaf and weaken the ambient replacements to allow it. These replacements are defined for every member of the branch context. Reapply the same eigenparameter rule; its lifted target context and conclusion still contain no new parameter.

For certificates, work in the shared auxiliary reserve. Renamed copies of the supplied proofs replace exactly the original-context leaves. The raw transformation therefore returns the required certificate. Logical equality rules, when enabled, simply reapply to transformed children. This argument neither introduces a classical step nor creates an equality step in the equality-disabled calculus.

Discharge an assumption and compose proofs

For finite contexts and arbitrary full formulas,

\[\Gamma,A\vdash_{\mathrm I}B\quad\Longleftrightarrow\quad\Gamma\vdash_{\mathrm I}A\to B.\]

Certificates of \(\Gamma\Rightarrow A\) and \(\Delta,A\Rightarrow B\) also give a certificate of \(\Gamma\cup\Delta\Rightarrow B\). Both assertions hold for raw derivations and for the equality-disabled fragment as well.

Implication introduction proves the forward deduction direction. Conversely, weaken the supplied implication to \(\Gamma,A\), use the assumption leaf of \(A\), and apply implication elimination. These operations use only stated primitive rules.

For composition, discharge the second proof's temporary \(A\), obtaining \(\Delta\Rightarrow A\to B\). Weaken this proof and the first proof to \(\Gamma\cup\Delta\), then apply implication elimination. Equivalently, use the replacement theorem with the proof of \(A\) and the unchanged remaining assumptions. This is admissible composition, not a new primitive cut constructor.

Proofs from a set retain finite support

For an arbitrary set \(T\) of full formulas, define intuitionistic consequence from \(T\), written \(T\vdash_{\mathrm I}A\), to mean that some finite \(\Gamma\subseteq T\) has a certificate of \(\Gamma\Rightarrow A\). This extends the finite-context notation: if \(T\) is finite, weakening identifies the two meanings.

Thus every such consequence has a finite supporting context. Conversely, every finite support provides a consequence by definition. The convention records that a proof has finitely many assumption leaves, while the collection of allowed axioms may be infinite. In particular, if each member of a finite support has a certificate from a finite subset of another premise set, take the union of those finitely many supporting subsets and apply proof replacement. This proves transitivity of the arbitrary-premise consequence relation without an infinitary inference rule.

Every rule preserves ordinary classical truth

For every raw intuitionistic derivation, every classical \(L\)-structure and every assignment of its free parameters, truth of all formulas in its context implies truth of its conclusion. For certificates, the same assertion holds in nonempty structures. In particular, neither calculus derives falsum without assumptions.

Induct on the raw tree, with the assignment arbitrary. Propositional cases use their defining truth clauses. Universal elimination evaluates its specified term; existential introduction uses that value as a witness. For universal introduction, extend the assignment by each possible value of the protected parameter. Lifted side formulas retain their original values, so the induction hypothesis proves the body for every value. For existential elimination, take a witness to its first premise and assign it to the protected parameter in its second premise; the concluding lifted formula has the same value as the original conclusion.

Reflexivity is reflexivity of values. In equality replacement the first premise says that \(s,t\) have the same value. The substitution truth law identifies truth of \(B(s)\) and \(B(t)\), so the second premise gives the conclusion. This handles arbitrary quantified bodies as well as atoms.

For a certificate, choose one element of the nonempty domain and assign it to every auxiliary name. Raw soundness applies; the end formulas contain only original names, so their truth is unchanged. Finally use a one-element structure, interpreting all functions by its unique possible values and all relations as false. Its empty context is satisfied and falsum is false, excluding a closed derivation or certificate of falsum.

The varying-domain Kripke soundness theorem also validates the intuitionistic rules, with implication and universal quantification tested at future worlds.

Erase equality atoms when equality rules are disabled

The equality erasure \(q(A)\) replaces every logical equality atom in a full formula by \(\bot\), retains relation atoms and falsum, and commutes with every propositional connective and either quantifier. The result is equality-free. If \(A\) is already equality-free, then \(q(A)=A\).

A pure derivation is an equality-disabled derivation in which every formula in every displayed context and conclusion is equality-free. Requiring only equality-free end formulas would not impose this condition on intermediate formulas. Erasure addresses this difference without changing a function symbol or a relation atom.

Purify the intermediates of equality-disabled proofs

Erasure commutes with scope substitution, including opening and instantiation. A supplied equality-disabled raw derivation of \(\Gamma\Rightarrow A\) gives a pure raw derivation of \(q[\Gamma]\Rightarrow q(A)\). Consequently, when every member of \(\Gamma\) and \(A\) is equality-free, it gives a pure derivation with exactly the same endsequent. The corresponding statement holds for certificates.

First induct on full formulas for the substitution identity. At an equality atom both orders give falsum, whatever the substituted terms. At a relation atom both orders use the same substituted term tuple. All remaining constructors are retained, using the same lifted substitution under a binder. This proves \(q(A\langle\sigma\rangle)=q(A)\langle\sigma\rangle\). The same tree induction proves equality-freeness of every erased formula and the identity on an equality-free formula.

Now recurse on the supplied proof. An assumption is replaced by its erased image in the erased context. Each logical rule reapplies, since erasure commutes with its constructors and with the opening and instantiation operations. The eigenparameter rule uses the same fresh tag. There are no equality-reflexivity or equality-replacement cases because these rules were disabled. Every formula displayed by the resulting tree is the erasure of a displayed input formula, so all are equality-free. If the end formulas were already equality-free, the identity property leaves them unchanged.

Erasure commutes with the renaming into the reserve, so the same transformation operates on certificates. This theorem does not concern proofs using equality's logical rules: erasing a reflexivity leaf \(t=t\) would turn it into an unjustified falsum leaf.

For the intuitionistic variant, the sequent translation with cut uses this purification before translating equality-free endpoints.

Isolate classical contradiction as one additional rule

A raw classical derivation has the same rules, optionally with equality disabled, and the additional classical contradiction rule

\[\frac{\Gamma,\neg A\Rightarrow\bot}{\Gamma\Rightarrow A}.\]

Its certificates use the same auxiliary reserve. Every intuitionistic derivation is a classical derivation by copying its tree. The weakening, substitution, replacement, discharge, equality-erasure and ordinary-truth arguments above extend to this variant: a classical step reapplies after transforming its branch. Equality erasure continues to require that equality rules be disabled.

Classical contradiction gives double-negation elimination: under \(\neg\neg A\), temporarily assume \(\neg A\), obtain falsum, and apply the displayed rule to conclude \(A\). It also gives excluded middle. Under \(\neg(A\lor\neg A)\), an additional \(A\) produces a contradiction by left disjunction introduction, yielding \(\neg A\) by discharge. Right disjunction introduction now gives another contradiction, and classical contradiction discharges the outer negative assumption. These are deductions in the full syntax, with no encoded disjunction substituted for the actual primitive one.

The classical proof translations compare this full calculus with the established smaller formula presentation, while preserving its auxiliary reserve and freshness restrictions.

The negative interpretation replaces this classical step by stability of its translated target. The resulting proof transformation preserves the chosen equality mode and the parameter supply.

Transport an existential witness through a universal implication

For unary relation symbols \(P,Q\), intuitionistic deduction proves

\[\bigl(\forall x(P(x)\to Q(x))\bigr)\to\bigl((\exists xP(x))\to\exists xQ(x)\bigr).\]

Assume the universal implication, and then the existential premise. Use existential elimination with protected parameter \(e\), so its branch has temporary assumption \(P(e)\). Universal elimination of the renamed universal implication at the term \(e\) gives \(P(e)\to Q(e)\). Implication elimination yields \(Q(e)\), and existential introduction yields \(\exists xQ(x)\). This conclusion and both ambient assumptions have no free \(e\), so existential elimination is licensed. Discharge the existential premise and then the universal premise. This proof uses no equality or classical contradiction rule.

Reflexivity and replacement give symmetry and transitivity

For all terms \(s,t,u\), intuitionistic deduction derives \(t=s\) from \(s=t\), and derives \(s=u\) from \(s=t,t=u\).

For symmetry, reflexivity gives \(s=s\). Apply equality replacement to the one-slot body \(B(z)\equiv z=s\), using the proof of \(s=t\); the resulting instance is \(t=s\). For transitivity use \(B(z)\equiv s=z\). Its instance at \(t\) is the assumption \(s=t\). Replacement along \(t=u\) gives \(s=u\). The terms are included as free terms in the body, so its distinguished slot is disjoint from all names already occurring in them.

Can an existential branch keep its temporary witness name?

Suppose an existential-elimination rule allowed \(\exists xP(x)\) and a branch assuming \(P(e)\) to conclude \(P(e)\), leaving \(e\) free in the result. Would that rule preserve intuitionistic consequences?

Show answerHide answer

No. In a two-element structure let \(P(0)\) hold and \(P(1)\) fail, and assign the displayed name \(e\) the value \(1\). The existential premise is true, and the branch's assumption proves its own conclusion. The proposed free conclusion \(P(e)\) is nevertheless false. Ordinary soundness therefore already rules out this inference in intuitionistic deduction.

In the genuine rule, the conclusion is \(C^\uparrow\), a renaming of a formula over the original parameter set. Its syntax consequently excludes the new right-tagged parameter. This is a condition on the conclusion as well as on the ambient assumptions.

How can a constant-free language prove a nonempty-domain existence?

In the language with no function or relation symbols and no displayed free names, can intuitionistic deduction prove \(\exists x(\bot\to\bot)\)? Is the auxiliary reserve relevant?

Show answerHide answer

There is a certificate. Implication introduction turns the assumption proof of \(\bot\) into a closed proof of \(\bot\to\bot\). Use the auxiliary term \(u_0\) in existential introduction. The body's distinguished variable is unused, so its instance at \(u_0\) is exactly that implication. The concluding formula has no auxiliary parameter.

There is no raw derivation over the empty parameter set. To see this without assuming a normalization theorem, interpret the empty language on the empty domain. Its unique assignment to the empty parameter set exists. The raw soundness induction applies even to this structure: eigenparameter premises are tested only after assigning an actual domain element, of which there are none. The existential conclusion is false in the empty domain, so a raw proof would contradict soundness.

The public certificate interpretation assumes a nonempty domain, which supplies values for the reserve. It therefore proves the displayed formula while the raw fixed-parameter presentation does not. No ground term in the original language has been produced.
