One point must answer a whole countable list

In the ultrapower of \((\mathbb N,<)\) by a nonprincipal ultrafilter on \(\mathbb N\), the class of the identity sequence lies above every standard natural number. It solves infinitely many inequalities at once. We will obtain the same conclusion for any countable list of first-order conditions whose finite parts have solutions in the ultraproduct.

Fix a set-sized first-order language \(L\), an ultrafilter \(\mathcal U\) on a set \(I\), and nonempty \(L\)-structures \(M_i\). Write \(M=\prod_{\mathcal U}M_i\), using the actual quotient structure, and work with classical choice. Let \(A\subseteq M\) be a set of parameters and let \(\bar x=(x_0,\ldots,x_{r-1})\) be a fixed finite tuple of variables.

A collection \(p(\bar x)\) of formulas in the parameter language \(L(A)\) is finitely realized in \(M\) if every finite subset has one common solution in \(M^r\), with each name for \(a\in A\) interpreted by that same \(a\). A tuple realizes \(p\) if it satisfies every member. This is the finite test for a parameter type; completeness of the type is not required.

The main result assumes that \(p\) is countable. At first neither the language nor the parameter set needs to be countable: only this chosen collection of conditions does.

Large sets can shrink to an empty intersection

An ultrafilter \(\mathcal U\) is countably incomplete if there are sets \(X_n\in\mathcal U\), for \(n\in\mathbb N\), such that

\[X_0=I,\qquad X_{n+1}\subseteq X_n,\qquad \bigcap_{n<\omega}X_n=\varnothing.\]

The normalization imposes no extra restriction on having a countable family of large sets with empty intersection. Given such a family \((E_n)\), put \(X_n=\bigcap_{k<n}E_k\). Finite-intersection closure makes each \(X_n\) large, the empty intersection gives \(X_0=I\), and the total intersection is still empty.

Every nonprincipal ultrafilter on \(\mathbb N\) is countably incomplete: take \(X_n=\{i:n\le i\}\). These sets are cofinite and hence large, while no natural number belongs to all of them. This is compatible with closure under finite intersections; an ultrafilter need not be closed under countable intersections.

Keep every parameter fixed by choosing its representative

For each \(a\in A\), choose a representative \(\widehat a\in\prod_i M_i\) with \([\widehat a]=a\). Expand \(M_i\) to an \(L(A)\)-structure \(N_i\) by interpreting the new constant \(c_a\) as \(\widehat a(i)\). Then the ultraproduct of the \(N_i\) is the named expansion \(M_A\), under the identity identification of their quotient carriers.

Adding constants changes neither the factors' carriers nor the equivalence relation on product functions. The old symbols therefore have their original ultraproduct interpretations. The interpretation of \(c_a\) in the expanded ultraproduct is \([i\mapsto\widehat a(i)]=a\), exactly its interpretation in \(M_A\). Thus the identity on classes preserves every symbol and is an isomorphism of the expanded structures. Induction on terms and formulas transfers satisfaction under this specified identification, including bound variables.

Consequently Łoś's theorem applies directly to formulas with these parameters: each occurrence of \(a\) is evaluated at \(\widehat a(i)\) in coordinate \(i\). One representative is chosen per parameter and used throughout the list, so repeated occurrences keep the same interpretation. Different representative choices yield the same truth in the named ultraproduct.

Finite solvability becomes a nested sequence of truth sets

List a countable \(p\) as \(\varphi_0,\varphi_1,\ldots\), allowing repetitions. If \(p\) is finite or empty, insert tautologies to obtain an infinite list without changing its realizations. In the expanded factors from , put

\[\theta_n(\bar x)=\bigwedge_{k<n}\varphi_k(\bar x),\qquad B_n=\{i:N_i\models\exists\bar x\,\theta_n(\bar x)\}.\]

Here \(\theta_0=\top\). If the list is finitely realized in \(M_A\), then every \(B_n\) is large, \(B_0=I\), and \(B_{n+1}\subseteq B_n\).

A common solution for the first \(n\) conditions says exactly that \(M_A\models\exists\bar x\,\theta_n\). Łoś's theorem makes its coordinate truth set \(B_n\) large. For the empty conjunction, each factor has a tuple of length \(r\), since its carrier is nonempty; for \(r=0\) use the unique empty tuple. Hence \(B_0=I\).

The conjunction \(\theta_{n+1}\) literally includes every conjunct of \(\theta_n\). Thus any coordinate witness for the former is a witness for the latter, proving actual inclusion of truth sets. Merely knowing that two sentences imply one another in the ultraproduct would give agreement on a large set, not this inclusion at every coordinate. Using the prefix conjunctions supplies the needed coordinatewise implication.

Every coordinate receives a finite task

Choose a normalized sequence \((X_n)\) witnessing countable incompleteness, and set \(Y_n=X_n\cap B_n\). These are decreasing large sets, with \(Y_0=I\) and empty total intersection. For every \(i\in I\), the set \(\{n:i\in Y_n\}\) is a nonempty finite initial segment of \(\mathbb N\). Define

\[n(i)=\max\{n:i\in Y_n\}.\]

The set contains \(0\) because \(Y_0=I\). Since the total intersection is empty, some \(m\) has \(i\notin Y_m\). Decreasingness excludes membership in all \(Y_n\) for \(n\ge m\), leaving a finite set below \(m\). Its maximum is therefore defined, and \(i\in Y_{n(i)}\subseteq B_{n(i)}\).

For each fixed \(j\), membership in \(Y_{j+1}\) forces \(n(i)\ge j+1\). Thus the coordinates assigned at least the first \(j+1\) conditions form a large set. Each individual coordinate receives only finitely many conditions, while every fixed condition is assigned on a large set.

Choose witnesses to the finite tasks and take their classes

At coordinate \(i\), choose \(\bar f(i)\in M_i^r\) satisfying \(\theta_{n(i)}\), which is possible because \(i\in B_{n(i)}\). This defines representative functions \(f_0,\ldots,f_{r-1}\) by their coordinates. The specified tuple \(([f_0],\ldots,[f_{r-1}])\) realizes every \(\varphi_j\) in \(M_A\).

Fix \(j\). On the large set \(Y_{j+1}\), the cutoff satisfies \(j<n(i)\). The chosen coordinate tuple satisfies the whole prefix \(\theta_{n(i)}\), so it satisfies \(\varphi_j\). Therefore

\[Y_{j+1}\subseteq\{i:N_i\models\varphi_j(\bar f(i))\}.\]

Upward closure makes the right-hand truth set large, and Łoś's theorem makes \(\varphi_j\) true at the tuple of classes. This holds for every \(j\), with the same chosen tuple and the original parameters.

When \(n(i)=0\), the task is the empty conjunction; any coordinate tuple works. Normalizing \(Y_0=I\) ensures that the cutoff never asks for the maximum of an empty set. Choice supplies the witnesses for all coordinates. No choice of one common coordinate surviving every \(Y_n\) is made or needed.

Countably incomplete ultraproducts realize countable types

Let \(\mathcal U\) be a countably incomplete ultrafilter on \(I\), and let the \(M_i\) be nonempty structures in the same set-sized language. Every countable collection of formulas in a fixed finite tuple, with parameters from their ultraproduct, that is finitely realized in that ultraproduct is realized there.

Name the parameters using , enumerate the conditions with tautology padding if necessary, and form their finite-prefix truth sets. Combine these with a countable-incompleteness witness and apply . The resulting tuple lies in this very ultraproduct, and the naming identification keeps every parameter at its original value.

For a partial type consistent with the complete theory of the named ultraproduct, the parameter finite test supplies finite realizability. The theorem therefore applies to partial as well as complete types. The countability hypothesis concerns the formulas of the type, not the size of the ultraproduct or the total number of its types.

In a countable language this gives aleph-one saturation

A structure is \(\aleph_1\)-saturated if it realizes every complete one-type over every at most countable subset of its carrier. In this definition, types are consistent with the complete theory of the named structure. This asks for more parameter sets than omega-saturation, where only finite parameter sets are required.

In a countable first-order language, an ultraproduct of nonempty structures by a countably incomplete ultrafilter is \(\aleph_1\)-saturated. The conclusion also holds for every partial type in a finite tuple over at most countably many parameters.

For countable \(L\) and countable \(A\), adjoining the constants \(c_a\) leaves a countable collection of symbols. Terms and formulas are finite syntactic expressions over these symbols and a countable supply of variables, so the formulas in each finite context form a countable set. Every type in that context is consequently countable.

Consistency with the named complete theory gives finite realizability by the parameter finite test. Apply . This proves the finite-tuple partial-type conclusion directly, and in particular the complete one-type condition in the definition of \(\aleph_1\)-saturation. It also proves omega-saturation by restricting to finite parameter sets.

In particular every nonprincipal ultrafilter on \(\mathbb N\) gives this conclusion. For a single nonempty structure \(N\) in a countable language, its ultrapower is thus an \(\aleph_1\)-saturated elementary extension through the specified diagonal embedding. The general omega-saturated extension construction applies to every set-sized language, while the present stronger saturation conclusion uses the countability of the language to count all formulas over a countable parameter set.

The inequalities above every standard integer are one instance

Let \(M=(\mathbb N,<)^{\mathbb N}/\mathcal U\), where \(\mathcal U\) is nonprincipal, and write \(d(k)\) for the diagonal image of \(k\). The countable type

\[p(x)=\{d(k)<x:k\in\mathbb N\}\]

has a solution for every finite part: take \(d(m)\) with \(m\) larger than all indices mentioned. The realization theorem supplies a solution to the whole type. The earlier identity-sequence argument already identifies a particular one, \(H=[i\mapsto i]\), since \(\{i:k<i\}\) is cofinite for each \(k\).

The standard structure \((\mathbb N,<)\) itself has no element satisfying all inequalities \(k<x\). Finite solvability in a structure and realization in that same structure remain different requirements; the ultraproduct theorem proves their coincidence for countable types under its ultrafilter hypothesis.

Can a point ultrafilter give the same guarantee?

Why does the proof fail for the point ultrafilter at \(i_0\)? Is its ultraproduct necessarily saturated?

Show answerHide answer

Every large set contains \(i_0\), so any sequence of large sets has \(i_0\) in its intersection. There is no countable-incompleteness witness, and no finite cutoff can assign arbitrarily long tasks on large sets.

The representative evaluation map identifies this ultraproduct with \(M_{i_0}\). There is no general saturation conclusion: taking every factor to be \((\mathbb N,<)\) returns the standard natural-number order, which omits the finitely realized countable type of all standard lower bounds. A point ultrafilter can still return a saturated factor, for example a finite structure; the missing hypothesis removes the guarantee.

Countable types do not mean a countable saturated carrier

No infinite structure with countable carrier is \(\aleph_1\)-saturated, in any first-order language. Enumerate its carrier as \(a_0,a_1,\ldots\) and use the countable parameter set consisting of the whole carrier. The type

\[\{x\ne a_n:n\in\mathbb N\}\]

is finitely realized, since finitely many exclusions leave some point in an infinite domain, but it has no realization. It is a partial type by the parameter finite test, and completing it would give an omitted complete one-type. This contradicts \(\aleph_1\)-saturation.

Thus the ultraproduct theorem asserts realization of countable descriptions, with no countable bound on the resulting carrier. Infinite \(\aleph_1\)-saturated ultraproducts have uncountable carriers. Finite structures cause no conflict: excluding every point then already gives an unsatisfiable finite collection.
