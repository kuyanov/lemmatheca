Removing quantifiers with the help of axioms

Fix a language \(L\) and a theory \(T\). All structures have nonempty domains. For formulas with a common finite list of available free variables, write \(\varphi\equiv_T\psi\) when every model of \(T\), at every assignment to that list, gives the two formulas the same truth value. In scoped notation the same requirement applies to any surrounding placeholders. This is equivalence modulo \(T\), rather than equivalence in every structure.

The theory \(T\) has quantifier elimination if every formula \(\varphi(\bar y)\) is equivalent modulo \(T\) to a quantifier-free formula \(\psi(\bar y)\). No new free variable or nonlogical symbol is introduced; some free variables may disappear. We allow the quantifier-free constants \(\top\) and \(\bot\), including when the variable list is empty. Quantifier elimination removes quantifiers, whereas prenex normal form only moves them.

For example, in a dense linear order, \(\exists x\,(y<x\land x<z)\) is equivalent to \(y<z\). The assertion can fail in a discrete order, so the theory matters.

It is enough to eliminate one existential quantifier

Suppose that, for every finite conjunction of literals \(\theta(x,\bar y)\), the formula \(\exists x\,\theta(x,\bar y)\) has a quantifier-free equivalent modulo \(T\), using only the variables \(\bar y\). Then \(T\) has quantifier elimination. An empty conjunction means \(\top\), and an empty disjunction means \(\bot\).

Induct on formulas. Atomic formulas and \(\bot\) need no change. Boolean connectives combine the quantifier-free equivalents supplied by induction. Replace a universal quantifier by \(\neg\exists x\neg\). At an existential step, first replace the body by its quantifier-free equivalent. Regard its finitely many atomic formulas as propositional atoms and use disjunctive normal form to write it as a finite disjunction of conjunctions of literals. Then

\[ \exists x\,\bigvee_{i<k}\theta_i(x,\bar y) \equiv_T \bigvee_{i<k}\exists x\,\theta_i(x,\bar y). \]

A witness for the left side satisfies one disjunct, and a witness for any disjunct satisfies the left side. Apply the hypothesis to each conjunction. Each step uses only the remaining free variables.

In the two languages treated below—equality alone, and equality with one binary order relation—there are no function or constant symbols, so every term is a variable. For a fixed finite list of variables there are therefore only finitely many equality atoms, or equality and order atoms. A useful alternative is to record every atom's truth or falsity in a complete atomic pattern, a conjunction containing one literal for each atom. A quantifier-free formula can be written as a disjunction of such patterns. Discard inconsistent patterns before using a witness argument: an arbitrary list of truth values need not respect equality or order.

For another application of finite atomic patterns, see quantifier elimination for the random graph theory, where the patterns record equalities and edges.

Compare all quantifier-free information about two tuples

Fix a theory \(T\), a finite context \(\bar x=(x_0,\ldots,x_{n-1})\), and tuples \(\bar a\in M^n\), \(\bar b\in N^n\) in nonempty models of \(T\). They have the same quantifier-free information if

\[M\models\theta[\bar a]\quad\Longleftrightarrow\quad N\models\theta[\bar b]\]

for every quantifier-free \(L\)-formula \(\theta(\bar x)\). They have the same full information if this holds for every \(L\)-formula in that context. The structures and tuples can be different. When \(n=0\), each tuple is empty, and the comparison concerns sentences.

Write \(Q_M(\bar a)\) for the quantifier-free description consisting of all quantifier-free formulas true at \(\bar a\). Negations are allowed: for every quantifier-free \(\theta\), this description contains exactly one of \(\theta,\neg\theta\). Consequently a tuple satisfying all of \(Q_M(\bar a)\) has exactly the same quantifier-free information as \(\bar a\).

Compactness replaces one complete description by finitely many conditions

Let \(\varphi(\bar x)\) have the same truth value on any two tuples in models of \(T\) with the same quantifier-free information. If \(M\models T\) and \(M\models\varphi[\bar a]\), there is a finite conjunction \(\delta(\bar x)\) of members of \(Q_M(\bar a)\) such that

\[M\models\delta[\bar a],\qquad T\models\forall\bar x\,(\delta\to\varphi).\]

The empty conjunction is \(\top\).

Replace the available variables by a fixed tuple of fresh constants \(\bar c\). Every model of \(T\cup Q_M(\bar a)(\bar c)\) interprets those constants by a tuple with the same quantifier-free information as \(\bar a\). The hypothesis therefore makes \(\varphi(\bar c)\) true there. By finite consequence, a finite part of this named theory already implies \(\varphi(\bar c)\).

Keep all of \(T\), and let \(\delta\) be the conjunction of just the finitely many selected description formulas. Then \(T\cup\{\delta(\bar c)\}\models\varphi(\bar c)\), while \(\delta\) holds at \(\bar a\). The constants were fresh and their interpretations arbitrary, so conservativity of the naming expansion gives the displayed universally quantified implication in the original language. This also works for the empty context, when no fresh constants are needed.

Quantifier elimination is exactly preservation of full tuple information

A first-order theory \(T\) has quantifier elimination if and only if, for every finite context and any two tuples in nonempty models of \(T\), the same quantifier-free information implies the same full information. No completeness or satisfiability assumption on \(T\) is required.

If \(T\) has quantifier elimination, replace any formula by its quantifier-free equivalent. The two tuples agree on that equivalent, so they agree on the original formula.

Conversely assume the tuple condition, and fix \(\varphi(\bar x)\). Let \(\mathcal I_\varphi\) consist of all quantifier-free formulas \(\delta(\bar x)\) such that \(T\models\forall\bar x\,(\delta\to\varphi)\). Every tuple satisfying \(\varphi\) in a model of \(T\) satisfies some member of \(\mathcal I_\varphi\), by . Hence, after replacing \(\bar x\) by fresh constants \(\bar c\),

\[T\cup\{\varphi(\bar c)\}\cup\{\neg\delta(\bar c):\delta\in\mathcal I_\varphi\}\]

has no model. Compactness supplies finitely many members \(\delta_1,\ldots,\delta_k\) whose negations, together with \(T\) and \(\varphi(\bar c)\), still have no model. Their disjunction \(\psi=\delta_1\vee\cdots\vee\delta_k\) is quantifier-free. Every tuple satisfying \(\varphi\) satisfies \(\psi\); every tuple satisfying \(\psi\) satisfies \(\varphi\), because each disjunct implies it modulo \(T\). Thus \(\varphi\equiv_T\psi\), with no new free variables or symbols.

If compactness needs none of the negated conditions, take \(\psi=\bot\): then \(\varphi\) has no realization in any model of \(T\). In particular an inconsistent \(T\) causes no exception. The empty context uses the same argument with sentences and the allowed constants \(\top,\bot\). This proves quantifier elimination in every finite context.

Empty tuples still carry sentence information

In the equality-only language, let \(T=\varnothing\). Do its one-element and two-element models agree on all quantifier-free sentences? Do they agree on every sentence?

Show answerHide answer

They agree on all quantifier-free sentences. There are no closed terms in this language, hence no closed atomic equalities; such a sentence is a Boolean combination of \(\top,\bot\), with a truth value independent of the model. But \(\exists x\exists y\,(x\ne y)\) is false in the one-element model and true in the two-element model. Their empty tuples therefore have the same quantifier-free information and different full information. By , the empty theory of equality does not have quantifier elimination.

Comparing tuples only inside one chosen model would also miss this obstruction: its unique empty tuple always agrees with itself. The criterion quantifies over every pair of models, not just over one preferred example.

Infinite sets with equality alone

The pure equality language \(L_=\) has no nonlogical symbols: equality is part of the logic. Let the theory of infinite sets \(T_\infty\) consist of the sentences asserting at least each finite number of distinct elements. For each positive integer \(n\), this sentence is:

\[ \exists x_0\cdots\exists x_{n-1} \bigwedge_{i<j<n} x_i\ne x_j. \]

Its models are exactly the infinite sets, with equality as their only available relation. Indeed, an infinite set contains each finite number of distinct elements; a finite set of size \(m\) fails the axiom for \(m+1\). The natural numbers supply a model.

Equality quantifiers reduce to finite equality patterns

The theory \(T_\infty\) of infinite sets in the equality language has quantifier elimination.

By , consider \(\exists x\,\theta(x,\bar y)\), where \(\theta\) is a conjunction of equalities and inequalities. Delete \(x=x\); if \(x\ne x\) occurs, the answer is \(\bot\). Reverse equalities or inequalities when needed to put \(x\) on the left.

If a conjunct is \(x=y_i\), substitute \(y_i\) for \(x\) in every other conjunct. The resulting conjunction is the required equivalent: any witness must equal \(y_i\), and \(y_i\) itself is a witness whenever that conjunction holds. This also detects contradictory requirements, such as \(x=y_i\) together with \(x\ne y_i\).

If there is no equality fixing \(x\), write the remaining conjunction as

\[ C(\bar y)\land\bigwedge_{i\in F}x\ne y_i, \]

where \(C\) contains every conjunct independent of \(x\), and \(F\) is finite. An infinite domain has an element outside the finite set of values \(\{y_i:i\in F\}\). Thus the existential formula is equivalent to \(C(\bar y)\). This includes \(F=\varnothing\), using nonemptiness. Every case gives a quantifier-free formula in the original remaining variables.

Being different from finitely many named elements

Over \(T_\infty\), eliminate the quantifiers in \(\exists x\,(x\ne y\land x\ne z)\) and \(\exists x\,(x=y\land x\ne z)\). Why can the first answer fail in a finite set?

Show answerHide answer

The first formula is equivalent to \(\top\), since two parameter values exclude at most two elements. The second is equivalent to \(y\ne z\): its witness must be \(y\). In a two-element set, assigning the two distinct elements to \(y,z\) leaves no possible witness to the first formula.

Dense linear orders without endpoints

Now use the language \(L_<=\{<\}\), with one binary relation and no function or constant symbols. The theory of dense linear orders without endpoints \(T_{\mathrm{dlo}}\) asserts that \( < \) is a strict linear order, is dense, and has no endpoints. In detail, the relation is irreflexive and transitive, distinct elements are comparable, and

\[\forall u\forall v\;(u<v\to\exists x\,(u<x\land x<v)),\qquad \forall u\exists x\;(x<u),\qquad \forall u\exists x\;(u<x).\]

The rational and real numbers with their usual orders are models; the integers fail density. The set-theoretic dense-order treatment studies the same order properties from a set-theoretic viewpoint. Here we study every first-order formula in the order language.

Linearity lets us remove negated atomic formulas:

\[u\ne v \equiv_{T_{\mathrm{dlo}}} (u<v\lor v<u),\qquad \neg(u<v) \equiv_{T_{\mathrm{dlo}}} (u=v\lor v<u).\]

Consequently, after distributing finite Boolean combinations, it is enough to eliminate \(\exists x\) from conjunctions of positive equalities and strict inequalities.

When finitely many lower and upper bounds have a witness

In a nonempty dense linear order without endpoints, let \(L,U\) be finite sets of elements and let \(C\) be a condition independent of \(x\). Then

\[\exists x\Bigl(C\land\bigwedge_{\ell\in L}\ell<x\land\bigwedge_{u\in U}x<u\Bigr)\quad\Longleftrightarrow\quad C\land\bigwedge_{\ell\in L,\,u\in U}\ell<u.\]

A witness gives every comparison on the right by transitivity. Conversely, retain \(C\). If both bound sets are nonempty, let \(\ell_*\) be the greatest member of \(L\), and \(u_*\) the least member of \(U\). These are extrema of finite sets, not suprema of arbitrary sets. The comparisons give \(\ell_*<u_*\); density supplies a witness between them. If only \(L\) is nonempty, choose an element above its greatest member using the absence of a greatest element. If only \(U\) is nonempty, choose an element below its least member. If both are empty, choose any domain element. In the last three cases the empty comparison conjunction on the right is \(\top\).

The condition \(C\) remains in every case. Removing the quantifier does not erase requirements imposed on the parameters.

Dense-order quantifiers reduce to comparisons

The theory \(T_{\mathrm{dlo}}\) of dense linear orders without endpoints has quantifier elimination in the language with equality and strict order.

Use and the positive-conjunction reduction in . In a conjunction under \(\exists x\), a conjunct \(x<x\) makes the answer \(\bot\), while \(x=x\) can be deleted. Collect all conjuncts independent of \(x\) into \(C(\bar y)\).

If an equality \(x=y_i\) remains, substitute \(y_i\) for \(x\) throughout the conjunction. As in the equality argument, this gives a necessary and sufficient quantifier-free condition, including all comparisons and any additional equalities. If no equality fixes \(x\), every remaining atom involving \(x\) has the form \(y_i<x\) or \(x<y_j\). Apply : the result is \(C(\bar y)\) conjoined with every comparison \(y_i<y_j\) from a lower-bound variable to an upper-bound variable. The four bound cases cover all possibilities. Induction then eliminates every quantifier.

A bound, a forced witness, and a missing interval

Eliminate \(\exists x\,(a<x\land x<b\land c<d)\) and \(\exists x\,(a<x\land x<b\land x=c)\) modulo \(T_{\mathrm{dlo}}\). Why does the theory of all linear orders fail quantifier elimination?

Show answerHide answer

The answers are \((a<b)\land(c<d)\) and \((a<c)\land(c<b)\), respectively. The first retains the condition independent of \(x\); the second substitutes the forced witness.

In \((\mathbb Z,<)\), the pairs \((0,1)\) and \((0,2)\) satisfy exactly the same atomic equality and order formulas in two variables. Every quantifier-free formula therefore has the same truth value on the two pairs, by induction on Boolean connectives. However, \(\exists x\,(y<x\land x<z)\) is false at \((0,1)\) and true at \((0,2)\), with witness \(1\). It has no quantifier-free equivalent even in this one structure, hence none valid over all linear orders.

What one-variable formulas can define

With parameters allowed, the definable subsets of an infinite equality structure are exactly the finite and cofinite subsets. The definable subsets of a dense linear order without endpoints are exactly the finite unions of singletons and open intervals, allowing rays and the whole domain. Interval endpoints and isolated points may be chosen among the finitely many parameters used.

First replace a defining formula by its quantifier-free equivalent. In the equality language, an atomic formula involving the variable \(x\) is either constant in truth or an equality \(x=a_i\) to a parameter. Outside the finite set of parameter values every such equality is false, so every Boolean combination has a single truth value there. The defined set is contained in that finite set, or contains its complement. Conversely, a finite set is defined by a finite disjunction of parameter equalities; negate that formula for its complement.

For the order language, arrange the distinct parameter values as \(a_1<\cdots<a_k\). They divide the domain into singleton cells \(\{a_i\}\) and the open cells

\[ (-\infty,a_1),\ (a_1,a_2),\ldots,\ (a_{k-1},a_k),\ (a_k,+\infty). \]

The infinity signs mean unbounded rays, not extra elements. On each cell every atomic comparison with a parameter has a fixed truth value; so does every Boolean combination. The defined set is a union of some of these finitely many cells. If there are no parameters, there is just the whole-domain cell. Conversely, each listed cell has a quantifier-free definition: \(x=a_i\), \(a_i<x<a_{i+1}\), \(x<a_1\), or \(a_k<x\). The whole-domain cell is defined by \(\top\), and the empty set by \(\bot\); finite disjunctions define their unions.

In particular, in either language the only parameter-free unary definable subsets are the empty set and the whole domain. The richer possibilities above come from supplying parameters.

For the resulting closure calculation over any parameter set, see definable and algebraic closure in equality and dense orders.

Both theories decide every sentence

The theories \(T_\infty\) and \(T_{\mathrm{dlo}}\) are complete: each is satisfiable, and each sentence is true in all its models or false in all its models.

The natural numbers model \(T_\infty\), and the rationals model \(T_{\mathrm{dlo}}\). Eliminate the quantifiers from a sentence. Neither language has constants or function symbols, so a closed term does not exist. There is therefore no closed atomic equality or order formula. A quantifier-free sentence is built from \(\top,\bot\) by Boolean operations, and has a truth value independent of the structure. Its equivalent sentence has that same value in every model of the relevant theory. This proves completeness, or equivalently agreement of all models on sentences.

The completeness argument uses the absence of closed atomic sentences in these particular languages, as well as quantifier elimination.

Inclusions between models preserve every formula

Every inclusion of one infinite equality structure into another is elementary. The same holds for an inclusion of dense linear orders without endpoints when the smaller domain has the order induced from the larger one. More generally, any injection between infinite equality structures, and any order embedding between such dense orders, is elementary.

Let \(f:M\to N\) be the injection or order embedding in question. It preserves and reflects equality; in the order case it also preserves and reflects strict order. It therefore preserves the truth of every quantifier-free formula by induction on Boolean connectives. Given \(\varphi(\bar y)\), choose a quantifier-free equivalent \(\psi(\bar y)\) modulo the common theory. For a tuple \(\bar a\) from \(M\),

\[M\models\varphi(\bar a)\iff M\models\psi(\bar a)\iff N\models\psi(f\bar a)\iff N\models\varphi(f\bar a).\]

This is exactly the definition of an elementary embedding. In the inclusion case it says that \(M\) is an elementary substructure of \(N\). Both structures must be models of the stated theory; an arbitrary ordered subset can lose density or endpoints and need not be elementary.

The general property that every embedding between models is elementary is called model completeness.
