Exclude equality of enumerable domains at every index

Use the fixed ordinary program numbering \(\varphi_e\) and its c.e. domains \(W_e=\{x:\varphi_e(x)\downarrow\}\). A total numerical function \(f:\mathbb N\to\mathbb N\) is fixed-point-free on domain indices, abbreviated FPF, if

\[\forall e\quad W_{f(e)}\ne W_e.\]

An oracle \(A\) computes an FPF function if one actual \(A\)-oracle program computes such a total \(f\). This uses the established natural-valued oracle computation. The inequality concerns entire domains. It is stronger than requiring different numerical indices, and does not merely require different output values on a common domain.

No total computable function is fixed-point-free

No ordinary total computable \(f\) is FPF.

The ordinary recursion theorem supplies an index \(e\) with \(\varphi_e\simeq\varphi_{f(e)}\). Equal partial functions have equal domains, so \(W_e=W_{f(e)}\), contrary to the FPF requirement.

Halting information computes a fixed-point-free function

The ordinary diagonal halting set \(K\) computes a total FPF function. Fix ordinary indices \(b,c\) with \(W_b=\varnothing\) and \(W_c=\{0\}\). Using the ordinary input-freezing map \(F_{\mathrm{ord}}\), put

\[v(e)=F_{\mathrm{ord}}(e,0),\qquad f_K(e)=\begin{cases}b,&v(e)\in K,\\c,&v(e)\notin K.\end{cases}\]

The freezing identity gives \(v(e)\in K\) exactly when \(0\in W_e\). In that case \(0\notin W_{f_K(e)}\); otherwise \(0\in W_{f_K(e)}\). Thus zero witnesses unequal domains in both cases. One oracle program computes \(v(e)\), queries \(K\), and returns the indicated fixed index; it is total. If \(K\le_T A\), query substitution converts this same program into an \(A\)-program for \(f_K\).

Replace a computably enumerable oracle by its finite stages

For the converse, fix a c.e. set \(A=W_a\), its supplied ordinary index \(a\), and an actual oracle-program index \(e\) computing a total \(f\) from \(A\). Put \(A_s=W_{a,s}\), using the increasing finite stages. Define the ordinary numerical approximation

\[\widehat f(s,n)=b^{A_s}(s,e,n)-1.\]

Here \(b^B(k,e,n)\) is the actual bounded output code: zero means failure and \(y+1\) means output \(y\); subtraction is truncated at zero. This definition retains the output value, rather than just recording whether a simulation halted.

The finite-oracle approximation is jointly ordinary computable

The specified \(\widehat f(s,n)\) is total computable jointly in \(s,n\), with the supplied \(a,e\) fixed.

The stage \(A_s\) lies below \(s\) and has a uniform total computable membership test. Compute its finite word of membership bits at \(0,\ldots,s-1\). The total finite-word oracle for this word is exactly \(A_s\), since every larger input is absent. The established finite-oracle evaluator computes \(b^{A_s}(s,e,n)\) from that word and the numerical parameters. Apply predecessor to decode its output. All these computations terminate. They give one ordinary program for the joint approximation even before a successful allowance is known.

The original oracle can locate a permanently correct finite prefix

There is an actual \(A\)-oracle program, built from the supplied index \(a\), computing

\[\tau_a(k)=\min\{s:\forall q<k\;[q\notin A\ \lor\ q\in A_s]\}.\]

At every \(s\ge\tau_a(k)\), the sets \(A_s\) and \(A\) agree below \(k\).

At a candidate stage, query \(A\) on each of the finitely many inputs below \(k\), and check that each positive answer has appeared in \(A_s\). This is a terminating finite test. All finitely many positive inputs eventually enter, so least search terminates; when \(k=0\), stage zero passes. The resulting instructions use ordinary stage tests, queries, and finite recursion, hence actual oracle-program constructors.

Every stage is contained in \(A\), so negative oracle answers are already correct. Positive answers remain correct afterward because the stages increase. Thus the first passing stage settles this whole prefix permanently. This permanence uses c.e. monotonicity; a first correct prefix in an arbitrary changing approximation need not remain correct.

Total computation from a c.e. oracle has an oracle-computable modulus

Let \(k_e^A(n)\) be the least successful evaluation allowance for the supplied total program. The specified function

\[m(n)=\max\bigl(k_e^A(n),\tau_a(k_e^A(n))\bigr)\]

is total \(A\)-computable and satisfies

\[\forall n\;\forall s\ge m(n)\quad\widehat f(s,n)=f(n).\]

One actual program computes the least successful allowance, passes that value to the prefix-settling program, and returns their maximum. Both searches terminate under the supplied totality and c.e. hypotheses.

Fix \(n\), put \(k=k_e^A(n)\), and let \(s\ge m(n)\). Soundness gives \(b^A(k,e,n)=f(n)+1\). The settled prefix below \(k\) lets bounded query agreement replay this fixed successful allowance with oracle \(A_s\). Now keep \(A_s\) fixed and increase only the allowance from \(k\) to \(s\); evaluation monotonicity preserves the output. Therefore \(b^{A_s}(s,e,n)=f(n)+1\), and decoding gives the displayed identity. This proves convergence together with a genuine modulus computed from \(A\).

Wait for a halting event before choosing one approximated index

Use the ordinary increasing halting stages \(K_s\). Define the ordinary partial procedure \(G(z,n,x)\): search for the first \(s\) with \(n\in K_s\); compute \(j=\widehat f(s,z)\); then simulate \(\varphi_j(x)\). If the event never occurs, the procedure remains undefined.

This is jointly partial recursive. Every stage test and approximation value is computed by an ordinary terminating program, and the final simulation is universal evaluation. Once the first event occurs, that single value of \(\widehat f\) is frozen. Later changes in the approximation do not change the copied program.

Compile one self-referential copying family before the oracle values vary

The parameterized theorem for partial output rules supplies one ordinary primitive-recursive \(h\) with

\[\varphi_{h(n)}(x)\simeq G(h(n),n,x)\qquad(n,x\in\mathbb N).\]

For \(n\in K\), let \(\sigma(n)=\min\{s:n\in K_s\}\). Then

\[W_{h(n)}=\begin{cases}W_{\widehat f(\sigma(n),h(n))},&n\in K,\\\varnothing,&n\notin K.\end{cases}\]

Apply the existing partial-family construction to this one joint procedure \(G\). It chooses a single ordinary master index and specializes it to \(n\), so \(h\) is primitive recursive. The construction depends on the fixed ordinary approximation program; it does not query \(A\) to build its indices. If the event occurs, the defining evaluation identity copies exactly the displayed program on every input. Otherwise its first search diverges on every input, giving the empty domain. The set-theoretic notation \(\sigma(n)\) is used only in the branch where its minimum exists.

A sufficiently late event forces a domain fixed point

If \(n\in K\) and \(m(h(n))\le\sigma(n)\), then \(W_{h(n)}=W_{f(h(n))}\). Consequently, if \(f\) is FPF,

\[n\in K\quad\Longrightarrow\quad\sigma(n)<m(h(n)).\]

The modulus gives \(\widehat f(\sigma(n),h(n))=f(h(n))\) under the stated inequality. Substitute this numerical equality into the exact copying identity in . It makes \(h(n)\) a domain fixed point of \(f\), which an FPF function excludes. Thus the entry stage must be strictly smaller than the modulus bound.

A fixed-point-free function makes the modulus decide halting

If the supplied total \(A\)-computable \(f\) is FPF, then

\[n\in K\quad\Longleftrightarrow\quad n\in K_{m(h(n))}.\]

There is an actual \(A\)-oracle program computing the characteristic bit of the right-hand condition, so \(K\le_T A\).

If \(n\in K\), puts its first entry strictly before \(m(h(n))\); increasingness of the stages gives membership in the displayed stage. The reverse direction follows because every halting stage lies in \(K\).

The deciding program first computes the ordinary primitive-recursive value \(h(n)\), then computes \(m(h(n))\) with the specified \(A\)-program, and finally runs the ordinary total halting-stage test on \(n\) and that stage. It terminates and returns exactly \(\chi_K(n)\). Thus the contradiction to incompleteness is supplied by a concrete reduction, not by an attempt to test equality of two c.e. domains.

A c.e. oracle computes a fixed-point-free function exactly when it is complete

For every c.e. set \(A\),

\[K\le_T A\quad\Longleftrightarrow\quad A\text{ computes a total FPF function}.\]

This is Arslanov’s completeness criterion. Since a c.e. set is computable from \(K\), its left side also says \(A\equiv_T K\).

The forward implication is the explicit function from and query substitution. For the reverse implication, choose the supplied c.e. index and an actual program for the total FPF function. The approximation, modulus and self-referential family constructed above give the actual halting decider in . These steps establish both implications with the given oracle and ordinary domain numbering.

Every total function computed by an incomplete c.e. oracle has a domain fixed point

If \(A\) is c.e., \(K\nleq_T A\), and a total \(f\) is computable from \(A\), then some \(e\) satisfies \(W_{f(e)}=W_e\).

If there were no such index, \(f\) would be FPF. The criterion would then imply \(K\le_T A\), a contradiction. More concretely, among the halting parameters in , at least one must have a final approximation value at its first entry; otherwise would decide halting from \(A\). Its copying index is a domain fixed point. This assertion concerns domains; it does not assert equality of the programs’ output values.

A diagonally noncomputable function supplies an explicit FPF function

Let \(g:\mathbb N\to\mathbb N\) be total and diagonally noncomputable: whenever \(\varphi_j(j)\) is defined, it differs from \(g(j)\). There are fixed ordinary primitive-recursive index maps \(d,c\) such that

\[F_g(e)=c(g(d(e)))\]

is FPF and is computable with any oracle computing \(g\).

First compile the relation \(R_e(z,y)\) meaning \(y\in W_e\). One fixed ordinary master ignores \(z\), simulates \(\varphi_e(y)\), and returns zero if that simulation finishes. Specialization gives a primitive-recursive relation-index map. Compose it with the actual uniform selector compiler to obtain \(d(e)\). Every defined output of this program lies in \(W_e\), and if \(W_e\) is nonempty the selector is total. In particular, if \(W_e=\{v\}\), then \(\varphi_{d(e)}(d(e))=v\). No least numerical member is being computed.

For \(c(v)\), use the existing finite-fragment compiler on the singleton table \([(v,0)]\). This is a primitive-recursive numerical map and \(W_{c(v)}=\{v\}\). If \(W_{F_g(e)}=W_e\), then \(W_e=\{g(d(e))\}\), forcing \(\varphi_{d(e)}(d(e))=g(d(e))\), contrary to DNC. Thus the domains differ for every \(e\). The numerical composition computes \(F_g\) from the same supplied program for \(g\), proving the final assertion.

Can the c.e. hypothesis be removed?

Does every oracle computing a total FPF function compute \(K\)? Use an existing incomplete oracle to test the proposed extension.

No. The low binary DNC example supplies a set \(D\) with \(K\nleq_T D\) whose characteristic function is binary DNC. Apply to \(g=\chi_D\). The resulting total FPF function is computed from \(D\), although \(D\) does not compute \(K\).

The set \(D\) cannot be c.e.: otherwise would force \(K\le_T D\). The example therefore explains exactly why the enumerable-oracle hypothesis matters.

Does the primitive-recursive family select a fixed point at every parameter?

In the incomplete-oracle argument, is every \(h(n)\) from necessarily a domain fixed point of \(f\)? Does primitive recursiveness of \(h\) by itself supply an algorithm choosing a successful halting parameter?

Show answerHide answer

No. For a concrete test, let \(f\) be the constant function returning an index for the total constant-zero program, so every \(W_{f(e)}=\mathbb N\). This is already ordinary computable. If \(n\notin K\), the family has \(W_{h(n)}=\varnothing\), and hence that \(h(n)\) is not a domain fixed point.

The argument guarantees that at least one halting parameter yields the required agreement when the oracle is incomplete. The construction of \(h\) alone does not identify that parameter, and the proof gives no terminating test for equality of its two domains. Primitive recursiveness of the whole candidate family must therefore be kept separate from an effective choice of a successful member. No computable parameterized fixed-point selector follows from this argument.
