Send symbols to symbols of the same arity

Let \(L,K\) be first-order languages. A language map \(j:L\to K\) consists of maps from the \(n\)-ary function symbols of \(L\) to the \(n\)-ary function symbols of \(K\), and likewise for relation symbols, for every finite arity \(n\). Constants are function symbols of arity zero. Logical connectives, equality, free variable names, and quantified placeholders are fixed. A language inclusion is a language map injective on each of these symbol sets. An actual sublanguage is a special case: \(L\subseteq K\) and \(j\) is inclusion.

The symbol translation \(j_*\) is defined by recursion on terms and scoped formulas:

\[j_*x=x,\qquad j_*f(t_0,\ldots,t_{n-1})=j(f)(j_*t_0,\ldots,j_*t_{n-1}).\]

It sends \(t=u\) to \(j_*t=j_*u\), and \(R(\bar t)\) to \(j(R)(j_*\bar t)\). It commutes with falsity, implication, and universal quantification. Thus it also commutes with all our defined connectives and the existential quantifier. Translation changes no variable or placeholder and therefore changes no binding. For a theory \(T\), put \(j_*T=\{j_*A:A\in T\}\).

The definition applies even when \(j\) identifies symbols. Renaming, in the strict sense of replacing symbols by distinct new symbols, is an inclusion; an invertible language map is a language isomorphism.

Translation respects substitution and composition

For language maps \(j:L\to K\), \(k:K\to H\), a term substitution \(\sigma\), and a scoped formula \(A\),

\[j_*(A[\sigma])=(j_*A)[j_*\sigma],\qquad (k\circ j)_*A=k_*(j_*A),\qquad (\mathrm{id}_L)_*A=A.\]

The analogous identities hold for terms. Translation also commutes with turning the outermost placeholder into a fresh name and with instantiating a bound slot. In particular, it takes sentences to sentences and closed terms to closed terms.

Induct first on terms. A variable is unchanged, so the substitution identity is its defining clause. At a function application the induction hypotheses apply to every argument, and both sides have outer function symbol \(j(f)\). For formulas, an equality or relation uses this term identity. An implication uses the two induction hypotheses. Under a universal quantifier, the substitution is lifted by leaving its new placeholder fixed. Symbol translation fixes that placeholder too, so the two lifted substitutions agree. This proves the formula identity in every context size, rather than just for sentences.

The same inductions prove the identity and composition laws. Replacing a placeholder by a name or a term is a variable operation; the proof just given works for that operation as well. No choice of fresh names is needed for symbol translation itself.

Read a structure through a language map

If \(N\) is a nonempty \(K\)-structure and \(j:L\to K\), its reduct along \(j\), denoted \(N\upharpoonright j\), has the same domain and interprets each \(L\)-symbol using its image:

\[f^{N\upharpoonright j}=j(f)^N,\qquad R^{N\upharpoonright j}=j(R)^N.\]

For a sublanguage inclusion, this simply forgets the additional symbols. An expansion along an inclusion \(j:L\hookrightarrow K\) of an \(L\)-structure \(M\) is a \(K\)-structure on the same domain whose reduct is \(M\). This generalizes the expansions used for Skolem functions.

A noninjective map also has a reduct, but it forces symbols with the same image to have the same interpretation. Consequently an arbitrary \(L\)-structure need not have an expansion along such a map.

Translated formulas have exactly their original truth conditions

Let \(j:L\to K\), let \(N\) be a nonempty \(K\)-structure, and use the same assignments to free names and placeholders in \(N\) and \(N\upharpoonright j\). Then every term \(t\) and scoped formula \(A\) satisfy

\[ (j_*t)^N=t^{N\upharpoonright j},\qquad N\models j_*A[\bar a]\quad\Longleftrightarrow\quad N\upharpoonright j\models A[\bar a].\]

Induct on terms. The variable case uses the shared assignment. For a function application, evaluate its translated arguments using the induction hypotheses, then use \(f^{N\upharpoonright j}=j(f)^N\). For an atomic formula, equality uses actual equality of these term values; a relation uses the defining relation clause of the reduct. Falsity and implication preserve truth by their semantic clauses.

For \(\forall x\,A\), both sides quantify over exactly the same domain. For each domain element, extend both placeholder assignments by that element; the induction hypothesis for the body identifies their truth values. Thus the universal statements agree. This is why the induction includes every placeholder context. The semantics of the defined connectives gives their cases too.

In particular, \(N\models j_*T\) if and only if \(N\upharpoonright j\models T\). This includes theories with any set of sentences, since satisfaction means satisfying each sentence separately.

An inclusion permits arbitrary interpretations of the new symbols

For any inclusion \(j:L\hookrightarrow K\), every nonempty \(L\)-structure \(M\) has an expansion along \(j\). Hence \(T\) is satisfiable if and only if \(j_*T\) is satisfiable.

Choose \(m_0\in M\). For a \(K\)-function symbol in the image of \(j\), use the interpretation of its unique preimage. Interpret every other function as the constant function with value \(m_0\), including new constants. For an image relation use its unique preimage's interpretation; interpret every other relation as false. Injectivity makes these instructions unambiguous. They give an expansion with reduct exactly \(M\).

An expansion of a model of \(T\) satisfies \(j_*T\) by . Conversely, the reduct of a model of \(j_*T\) satisfies \(T\). We use classical set theory with choice throughout, as in the model-existence development.

Translate the actual natural-deduction tree

For every language map \(j:L\to K\), theory \(T\), and sentence \(A\),

\[T\vdash_L A\quad\Longrightarrow\quad j_*T\vdash_K j_*A.\]

More precisely, translating every formula and term in any finite proof from \(\Gamma\) gives a proof from \(j_*\Gamma\), using the same primitive natural-deduction rules.

Induct on the finite proof tree. An assumption translates to a member of the translated assumption set. Each connective rule translates to the same rule, since translation commutes with its connective. Discharged assumptions remain the translated discharged assumptions; if distinct assumptions happen to become equal, a finite assumption set simply contains that formula once.

For universal elimination and existential introduction, translate the closed instantiating term and use : the translated instance is precisely the instance of the translated body. For universal introduction, the new auxiliary name is kept separate from all existing names; translation changes signature symbols, not names. The translated lifted assumptions therefore still exclude the protected name, and the translated premise is the translated body's fresh-name instance. The same observation preserves existential elimination, including its side condition on the conclusion.

Equality introduction translates \(t=t\) to \(j_*t=j_*t\). In equality elimination, the same instance identity identifies the two translated instances with the body at \(j_*s\) and \(j_*t\), so the original equality rule applies. These cover every primitive rule. The additional reserve of auxiliary names allowed in a proof is unchanged, so the construction also gives a proof in that convention. Finally, the original proof uses finitely many assumptions from \(T\); their translations form a finite subset of \(j_*T\).

Injectivity of \(j\) is unnecessary here. Protected auxiliary names supply quantifier freshness independently of the signature. This proof transformation does not appeal to completeness.

Record every symbol that an expression uses

The symbol support \(\operatorname{sym}(t)\) of a term is the set of its function symbols, with their arities recorded. Define it recursively by

\[\operatorname{sym}(x)=\varnothing,\qquad \operatorname{sym}(f(\bar t))=\{f\}\cup\bigcup_{i<n}\operatorname{sym}(t_i).\]

The symbol support of a formula is defined by taking the union of its term supports at equality, adding \(R\) and its argument supports at \(R(\bar t)\), taking unions at connectives, and leaving the support unchanged when adding a quantifier. Falsity has empty support. Function and relation symbols are tagged separately, even if written with the same letter. These sets are finite: every union here has finitely many finite constituents, so structural induction proves the claim.

For a finite set \(\Gamma\) of sentences, put \(\operatorname{sym}(\Gamma)=\bigcup_{B\in\Gamma}\operatorname{sym}(B)\). This is finite too. This support records signature symbols, not free names or quantified variables.

A finite collection lives in a finite sublanguage

Let \(\Gamma\) be a finite set of \(L\)-sentences and let \(A\) be an \(L\)-sentence. There are a finite sublanguage \(L_0\), its inclusion \(i:L_0\hookrightarrow L\), sentences \(A_0\) and \(B_0\) for every \(B\in\Gamma\), with

\[i_*A_0=A,\qquad i_*B_0=B.\]

The sublanguage may be chosen to have exactly the symbols in \(\operatorname{sym}(\Gamma)\cup\operatorname{sym}(A)\). It need not contain a constant.

Take that finite set of symbols, keeping their kinds and arities. To restrict a term to \(L_0\), keep each variable and replace each symbol \(f\) by that same symbol regarded as a member of \(L_0\). Every symbol encountered belongs to the support, so this operation is defined. Recurse through the arguments. An induction gives that including the restricted term back into \(L\) recovers the original term.

Perform the same construction on formulas, keeping equality and the logical constructors and restricting their terms. Quantifier bodies use the same symbol set as their quantified formulas, so all placeholder contexts are handled together. The recovery identity follows by structural induction. Apply it to \(A\) and every member of \(\Gamma\). This also treats an empty support: formulas using only equality and logical symbols restrict to the language without nonlogical symbols.

Compactness reduces a consequence to finitely many axioms

For an arbitrary set-sized first-order language \(L\), if \(T\models A\), some finite \(\Gamma\subseteq T\) satisfies \(\Gamma\models A\).

Suppose no finite subset has this property. For every finite \(\Gamma\subseteq T\), there is an \(L\)-model of \(\Gamma\) in which \(A\) is false. Consequently every finite subset of \(T\cup\{\neg A\}\) is satisfiable: select its finitely many premises from \(T\), and use such a countermodel, which also satisfies \(\neg A\) whether or not that sentence was selected.

Semantic compactness for arbitrary languages gives a model of all of \(T\cup\{\neg A\}\), contrary to \(T\models A\). Thus a finite \(\Gamma\) exists. The compactness result used here was proved by an ultraproduct, independently of the deductive completeness theorem we are about to obtain.

Completeness holds for every set-sized first-order language

Let \(L\) have any set of symbols, let \(T\) be an \(L\)-theory, and let \(A\) be an \(L\)-sentence. Then

\[T\models A\quad\Longleftrightarrow\quad T\vdash_L A.\]

When these conditions hold, there is a finite \(\Gamma\subseteq T\) with \(\Gamma\vdash_L A\).

Soundness gives the right-to-left implication. Suppose \(T\models A\). By , choose finite \(\Gamma\subseteq T\) with \(\Gamma\models A\). Use to find the finite sublanguage \(L_0\), inclusion \(i\), and restricted sentences. Write \(\Gamma_0\) for the set of restricted members, so \(i_*\Gamma_0=\Gamma\) and \(i_*A_0=A\).

We claim \(\Gamma_0\models A_0\). Indeed, an arbitrary nonempty \(L_0\)-model \(M\) of \(\Gamma_0\) has an \(L\)-expansion \(M^+\) by . Satisfaction translation makes it a model of \(\Gamma\), so \(M^+\models A\). The same translation then gives \(M\models A_0\). This proves the claim for every \(M\), including when \(\Gamma_0\) has no model.

The finite language \(L_0\) is countable. Countable-language deductive completeness therefore supplies an actual natural-deduction proof \(\Gamma_0\vdash_{L_0}A_0\). Translate its tree along \(i\) using . Its assumptions become \(\Gamma\) and its conclusion becomes \(A\), giving \(\Gamma\vdash_L A\). Since \(\Gamma\subseteq T\), the same proof gives \(T\vdash_L A\).

Only the finite vocabulary of one consequence was reduced. We have not enumerated an arbitrary language or extended the countable Henkin enumeration to an uncountable list.

Adding uninterpreted symbols preserves old consequences

If \(j:L\hookrightarrow K\) is an inclusion, then for every \(L\)-theory \(T\) and \(L\)-sentence \(A\),

\[j_*T\models j_*A\ \Longleftrightarrow\ T\models A,\qquad j_*T\vdash_K j_*A\ \Longleftrightarrow\ T\vdash_L A.\]

In particular, the translated theory is consistent exactly when the original theory is consistent.

If \(T\models A\), take the reduct of any model of \(j_*T\) and apply satisfaction translation. Conversely, expand any model of \(T\) along \(j\); the assumed translated consequence gives its truth of \(A\). This proves the semantic equivalence. Apply to both languages for the deductive equivalence. Consistency is the absence of a derivation of falsity, and falsity is unchanged by translation.

This generalizes conservative addition of fresh constants. That earlier syntactic proof remains part of the construction of countable completeness; the present argument uses the now established theorem and cannot replace a prerequisite step in its proof.

What fails if two constants get the same name?

Let \(L\) have distinct constants \(c,d\), and let \(j:L\to K\) send both to one constant \(e\). Is the translated theory of \(T=\{\neg(c=d)\}\) consistent? Does every \(L\)-structure expand along \(j\)?

The original theory has a two-element model with distinct values for \(c,d\), so soundness makes it consistent. Its translation is \(\{\neg(e=e)\}\). Equality introduction proves \(e=e\), and the translated assumption gives a contradiction. Thus a language map need not preserve consistency, even though it preserves every existing proof.

In every reduct along \(j\), the interpretations of \(c\) and \(d\) are both the interpretation of \(e\). The two-element structure with distinct values for them is therefore no such reduct. This is exactly where injectivity was needed in the expansion and conservativity arguments.
