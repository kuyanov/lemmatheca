Decide axiom membership in the actual sentence coding

Fix a first-order language \(L\) with an effective signature \(S\), and use its existing original-language sentence code \(\ulcorner A\urcorner\). For an actual set \(T\) of \(L\)-sentences, write

\[\operatorname{Codes}(T)=\{\ulcorner A\urcorner:A\in T\},\qquad \operatorname{Cn}(T)=\{A:T\vdash A\}.\]

The proof relation is the existing sentence natural-deduction calculus. A code-enumerable axiom set has c.e. code set; a code-decidable axiom set has decidable code set. Decisions are defined on every natural number and reject numbers that code no original-language sentence. The consequence closure is also the set of semantic consequences by soundness and completeness.

Turn an enumeration into a total stream of finite conjunctions

Let \(T\) be code-enumerable, and choose an ordinary index \(e\) whose domain \(W_e\) is exactly \(\operatorname{Codes}(T)\). Use the canonical finite stage sets \(W_{e,s}\). At stage \(s\), list their genuine sentence codes in increasing numerical order, using the decidable sentencehood test, and decode them as \(A_{s,0},\ldots,A_{s,m_s-1}\). Every listed sentence belongs to \(T\).

Fix the tautology \(\tau=(\bot\to\bot)\). The snapshot sentence \(F_s\) is the left-associated conjunction starting at \(\tau\) and adjoining that finite list:

\[C_{s,0}=\tau,\qquad C_{s,j+1}=C_{s,j}\land A_{s,j},\qquad F_s=C_{s,m_s}.\]

An empty list gives \(F_s=\tau\). Thus a snapshot is specified at every stage, including when the original enumeration has no outputs at all.

Every snapshot code can be computed without waiting for another axiom

The map \(s\mapsto\ulcorner F_s\urcorner\) is total computable, and every returned code is an actual sentence code.

Scan the finite list \(0,\ldots,s-1\), retaining a number exactly when it belongs to \(W_{e,s}\) and passes the sentence test. These are total finite tests. Start the accumulator at \(\ulcorner\tau\urcorner\); for each retained code \(a\), replace accumulator \(c\) by the existing numerical constructor \(\operatorname{andCode}(c,a)\). This constructor expands conjunction by the fixed syntactic abbreviation, with no logical simplification. Finite recursion computes the final accumulator.

The faithful syntax coding decodes every retained code to its unique sentence. Induction through the accumulator shows that its numerical value is precisely the code of the stated conjunction. No search for a next enumerated axiom occurs, so every stage terminates even for empty or finite input.

The snapshots and the original axioms have the same consequences

Every \(F_s\) is derivable from \(T\). Conversely, for every \(A\in T\), some single snapshot \(F_s\) proves \(A\). Hence the snapshot family has exactly the same models and deductive closure as \(T\).

The tautology \(\tau\) has an assumption-free derivation. Every other conjunct of \(F_s\) is an axiom of \(T\). Repeated conjunction introduction therefore derives \(F_s\) from \(T\). For \(A\in T\), its code belongs to \(W_e\), so the stage-union property gives some \(s\) with \(\ulcorner A\urcorner\in W_{e,s}\). It is a sentence code and appears in that stage's list. Repeated conjunction elimination along the finite left-associated expression extracts this occurrence of \(A\) from \(F_s\).

Every model of \(T\) therefore satisfies every snapshot, and every model of all snapshots satisfies each original axiom. They have the same models. The existing soundness and completeness theorem gives the same deductive consequences as well.

Record a numerical position by repeating one sentence

The padding of a sentence \(A\) by \(n\) is the literal expression

\[P_0(A)=A,\qquad P_{n+1}(A)=P_n(A)\land A.\]

Thus \(P_n(A)\) has \(n+1\) copies with the stated left association. The padding-code function uses the same recurrence on natural numbers:

\[p(0,a)=a,\qquad p(n+1,a)=\operatorname{andCode}(p(n,a),a).\]

It is total computable by finite recursion and satisfies \(p(n,\ulcorner A\urcorner)=\ulcorner P_n(A)\urcorner\). Padding keeps the syntax; it does not simplify a conjunction of identical sentences back to one copy.

Padding preserves every derivable consequence

For every sentence \(A\), natural number \(n\), and set \(\Gamma\) of sentences,

\[\Gamma\vdash P_n(A)\quad\Longleftrightarrow\quad\Gamma\vdash A.\]

At \(n=0\), the expressions are identical. Given a derivation of \(A\), the induction hypothesis derives \(P_n(A)\) as well. Combining the two derivations by conjunction introduction proves the successor case. Conversely, a derivation of \(P_{n+1}(A)=P_n(A)\land A\) yields \(A\) by conjunction elimination. These are the existing propositional rules used inside the actual first-order calculus. No new inference rule or change of theory is introduced.

A candidate sentence code bounds its possible padding position

For all natural numbers \(n,a\), \(n\le p(n,a)\). In particular, if \(p(n,\ulcorner F_n\urcorner)=z\), then \(n\le z\).

For any numerical codes \(a,b\),

\[a<\operatorname{andCode}(a,b).\]

Indeed, conjunction expands to \(\neg(a\to\neg b)\). Its code is the implication code for \((a\to(b\to\bot))\to\bot\). The input code \(a\) is a child of the inner implication code, which is itself a child of the outer implication code. Apply the earlier strict child-code bounds twice. These bounds hold for raw constructor codes as well as valid formulas.

Induct on \(n\). The base is \(0\le a\). If \(n\le p(n,a)\), the strict increase gives \(n+1\le p(n+1,a)\). Substituting a candidate equality proves the final bound.

Make the new axiom at each position carry that position's padding

The Craig axiom set associated to the chosen snapshots is the actual set of sentences

\[B=\{P_n(F_n):n\in\mathbb N\}.\]

Its code set is the range of \(n\mapsto p(n,\ulcorner F_n\urcorner)\). The construction may introduce theorems of \(T\) that were not among its original axioms.

A finite scan decides the padded axiom set

The code set of \(B\) is decidable. An exact membership test, on every natural-number input \(z\), is

\[z\in\operatorname{Codes}(B)\quad\Longleftrightarrow\quad\operatorname{Sent}(z)\text{ and }\exists n\le z\;p(n,\ulcorner F_n\urcorner)=z.\]

If the input fails the sentencehood test, reject it. Otherwise run through \(n=0,1,\ldots,z\). For each position, compute its snapshot code, form the specified padding code, and compare it with \(z\). Accept at a match and reject after the last failed comparison. Every snapshot and padding computation terminates, and there are finitely many candidates. This gives a total computable test.

An accepted candidate is literally the code of a member \(P_n(F_n)\) of \(B\). Conversely, if \(z\) codes a member of \(B\), its defining witness \(n\) satisfies \(n\le z\) by , so the scan includes it. Every family member is an actual sentence, giving the stated sentencehood condition too. These implications prove the exact test.

Each axiom family derives the other one

Every sentence in \(B\) is derivable from \(T\), and every sentence in \(T\) is derivable from \(B\).

A new axiom has the form \(P_n(F_n)\). By , \(T\vdash F_n\), and gives \(T\vdash P_n(F_n)\). Conversely, let \(A\in T\). Some snapshot \(F_s\) proves \(A\). The new axiom \(P_s(F_s)\) belongs to \(B\), so conjunction elimination gives \(B\vdash F_s\). Extracting the original conjunct gives \(B\vdash A\). Equivalently, use the existing proof-substitution operation to combine those derivations. All expressions are sentences in the original language.

Every enumerable axiom set has an equivalent decidable axiom set

For every code-enumerable axiom set \(T\) in the fixed effective first-order language, the specified Craig axiom set \(B\) is code-decidable and satisfies

\[\operatorname{Cn}(B)=\operatorname{Cn}(T).\]

It has exactly the same models as \(T\), and its semantic consequence closure is the same. No consistency or completeness assumption is required. This is Craig reaxiomatization.

Decidability is the actual finite algorithm in . The two derivability directions in , combined with proof substitution, show that either axiom family derives exactly the same sentences. Soundness gives the same models from those directions, and therefore the same semantic consequences. The effective symbol names make the signature countable, so the existing completeness theorem also identifies these consequences with the same deductive closure. None of these arguments asked whether a contradiction or every sentence is derivable.

A closed theory is enumerable exactly when it has decidable axioms

Let \(U\) be deductively closed in the fixed effective language. Its sentence-code set is c.e. if and only if \(U=\operatorname{Cn}(B)\) for some code-decidable axiom set \(B\).

If \(U\) is code-enumerable, apply with \(T=U\). Closedness gives \(\operatorname{Cn}(U)=U\), so its new decidable axioms have closure exactly \(U\). Conversely, decidable axioms are enumerable, and the earlier theorem-enumeration theorem makes their closure's code set c.e. This is the usual closed-theory formulation of the result.

An empty enumeration still produces a valid axiomatization

If \(T=\varnothing\), every snapshot is \(\tau\), and \(B=\{P_n(\tau):n\in\mathbb N\}\) consists entirely of logical theorems. Its closure is precisely the set of valid sentences.

No stage contains an original axiom code, so each finite conjunction has only its initial tautology. By , every padded copy of that tautology has an assumption-free derivation. Adding these logical theorems changes no derivable consequence of the empty theory, by . Soundness and completeness identify that closure with validity. In particular the construction never needs to wait for an axiom that may not exist.

Does the syntax determine a unique padding position?

Can a sentence's literal syntax determine a unique pair \(n,A\) with that sentence equal to \(P_n(A)\)? Would choosing just one such decomposition suffice for the axiom-membership test?

Show answerHide answer

No: \(A\land A=P_1(A)=P_0(A\land A)\). Unique decoding of a formula determines its syntax tree, but these are two different padding descriptions of that same tree. For empty original axioms, every snapshot is \(\tau\). The sentence \(\tau\land\tau=P_1(F_1)\) belongs to \(B\), but its position-zero description would compare it with \(F_0=\tau\), whose code is strictly smaller by the padding growth bound. Choosing only that description would reject an actual new axiom. The actual recognizer tries every position up to the input code and compares against that position's computed snapshot. The code bound makes all those comparisons finite.

What happens to the decision problem for consequences?

Suppose the code set of \(\operatorname{Cn}(T)\) is undecidable. Can the new decision procedure for membership in \(B\) turn its theoremhood problem into a decidable one?

Show answerHide answer

No. The code sets of \(\operatorname{Cn}(B)\) and \(\operatorname{Cn}(T)\) are equal, so a decision procedure for either one would be a decision procedure for the other. More generally, their decidability statuses coincide exactly. The new finite test decides which padded sentences are axioms. The earlier enumeration of all proofs still recognizes exactly the same consequence set.
