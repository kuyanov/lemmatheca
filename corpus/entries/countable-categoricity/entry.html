One countably infinite model, up to isomorphism

Throughout, let \(T\) be a satisfiable complete theory in a countable first-order language \(L\), and suppose \(T\) has an infinite model. All structures are nonempty. The theory is countably categorical, or \(\aleph_0\)-categorical, if it has a countably infinite model and any two such models are isomorphic.

In fact every model of \(T\) is infinite. For each positive integer \(r\), the sentence asserting at least \(r\) distinct elements holds in the given infinite model. Completeness of \(T\) makes it hold in every model. Thus a countable model of \(T\) is automatically countably infinite.

Write \(S_n(T)\) for the complete types in the fixed free context \(x_0,\ldots,x_{n-1}\). Formulas may leave some of those variables unused. Include \(n=0\): there is one empty tuple and, because \(T\) is complete, one zero-type.

For complete theories with several countable models, a named dense-order example gives exactly three, while Vaught's theorem rules out exactly two.

Every complete finite-tuple type occurs in a countable model

Every \(p\in S_n(T)\) has a realization in a countable model of \(T\). In particular, \(T\) has a countably infinite model.

Consistency of a complete type gives a model \(N\models T\) and a tuple \(\bar a\) realizing it. Apply downward Löwenheim–Skolem to the finite set of coordinates of \(\bar a\). This gives a countable elementary submodel \(M\preccurlyeq N\) containing every coordinate. It models \(T\), and elementarity preserves every formula of \(p\) at the same tuple.

For the empty tuple, use any model of \(T\) and the empty prescribed set. Every resulting countable model is infinite by .

Uniqueness of the countable model is equivalent to isolation of every type

The theory \(T\) is countably categorical if and only if every type in every \(S_n(T)\) is isolated.

Suppose \(T\) is countably categorical and \(p\) is nonisolated. Omitting types gives a countable model \(M\) omitting \(p\), while gives a countable model \(N\) realizing it. These models cannot be isomorphic: isomorphisms preserve all formulas and hence realization of a complete type. This contradicts categoricity.

Conversely, suppose all finite-tuple types are isolated. Every model of \(T\) is then atomic, since each of its realized tuple types is isolated. The uniqueness theorem for countable atomic models makes any two countable models isomorphic. The preceding lemma supplies one, so \(T\) is countably categorical.

Identify formulas that agree throughout the theory

Two formulas in the same \(n\)-variable context are equivalent modulo \(T\) if

\[\varphi\equiv_T\psi\quad\Longleftrightarrow\quad T\models\forall\bar x\,(\varphi\leftrightarrow\psi).\]

This is an equivalence relation: equality of truth values at every tuple in every model is reflexive, symmetric and transitive. Let \(F_n(T)\) denote its set of equivalence classes, and write \([\varphi]_T\) for the class of \(\varphi\).

A formula class has a type truth set

\[V_n([\varphi]_T)=\{p\in S_n(T):\varphi\in p\}.\]

This is well-defined. Realize a type in a model of \(T\); equivalent formulas have equal truth values there, so one belongs to the type exactly when the other does.

Finitely many types and finitely many formula classes are equivalent

For each finite \(n\), the set \(S_n(T)\) is finite if and only if \(F_n(T)\) is finite.

The map \(V_n:F_n(T)\to\mathcal P(S_n(T))\) is injective. If the two classes have the same type truth set, take any tuple in any model of \(T\). Its complete type contains the first formula exactly when it contains the second; the tuple therefore satisfies them together or fails them together. This is equivalence modulo \(T\). A finite \(S_n(T)\) has a finite power set, proving this direction.

For the converse, send each type \(p\) to its set of formula classes \(\{[\varphi]_T:\varphi\in p\}\). Membership is independent of the representative by the same realization argument. Different types disagree on a formula, so this map from \(S_n(T)\) into \(\mathcal P(F_n(T))\) is injective. If \(F_n(T)\) is finite, its power set is finite, and so is \(S_n(T)\).

The countable categoricity theorem

For a satisfiable complete theory \(T\) in a countable language with an infinite model, the following conditions are equivalent:

  1. \(T\) is countably categorical.
  2. For every finite \(n\), every type in \(S_n(T)\) is isolated.
  3. For every finite \(n\), \(S_n(T)\) is finite.
  4. For every finite \(n\), there are only finitely many formulas in that context up to equivalence modulo \(T\).

The first two conditions are equivalent by . The second and third are equivalent by the finite-type isolation theorem, applied separately in each context. The third and fourth are equivalent by . This proves all four equivalences, including the empty context.

This is the Engeler–Ryll-Nardzewski–Svenonius theorem in its type and formula formulations.

Move tuples by symmetries of the whole model

For an \(L\)-structure \(M\), let \(\operatorname{Aut}(M)\) be its automorphisms. Tuples \(\bar a,\bar b\in M^n\) lie in the same automorphism orbit if some \(g\in\operatorname{Aut}(M)\) satisfies \(g(a_i)=b_i\) for every \(i<n\).

This is an equivalence relation. The identity map proves reflexivity, the inverse automorphism proves symmetry, and composition proves transitivity. Write \(M^n/\operatorname{Aut}(M)\) for the orbit set. Say that the automorphisms are oligomorphic if this set is finite for every finite \(n\). The empty tuple has one orbit.

Automorphisms preserve complete types, since isomorphisms preserve every formula. Thus each orbit consists of tuples of one complete type.

In the unique countable model, types are exactly symmetry orbits

Suppose \(T\) is countably categorical and \(M\models T\) is countable. Two finite tuples in \(M\) have the same complete type if and only if they lie in the same automorphism orbit. Every type in \(S_n(T)\) is realized in \(M\), so the orbit set is in bijection with \(S_n(T)\). Each orbit is defined without parameters by an isolating formula for its type.

Only the forward implication about two tuples needs proof. If \(\operatorname{tp}(\bar a)=\operatorname{tp}(\bar b)\), the assignment \(a_i\mapsto b_i\) defines a bijection between their finite coordinate sets. It is well-defined and injective because the two types agree on every equality \(x_i=x_j\). Any formula with parameters from the first set can be expressed using the coordinate tuple, repeating or omitting coordinates as needed. Equality of the tuple types then says exactly that this finite map preserves that formula's truth.

By , \(M\) is atomic. Apply the prescribed-map form of atomic uniqueness with both models equal to \(M\). It extends this particular finite elementary map to an automorphism \(g\), so \(g(a_i)=b_i\) at every coordinate.

Every type is isolated by the same criterion and is realized in every model of the complete theory, hence in \(M\). This proves the claimed bijection. If \(\theta_p\) isolates \(p\), a tuple satisfies \(\theta_p\) exactly when it realizes \(p\). The equivalence just proved makes its solution set the orbit of any realizing tuple.

These finite definable orbits also imply that a subset of a finite tuple power is parameter-free definable exactly when it is invariant under every automorphism.

A model realizing only finitely many types cannot miss another one

If a model \(M\models T\) realizes only finitely many \(n\)-types, then it realizes every type in \(S_n(T)\), and that set is finite.

List the realized types as \(q_0,\ldots,q_{r-1}\). Suppose another type \(p\) were omitted. For each \(q_i\), choose \(\varphi_i\in p\) with \(\neg\varphi_i\in q_i\), using separation of distinct complete types. Let \(\theta=\bigwedge_{i<r}\varphi_i\).

A realization of \(p\) in some model satisfies \(\theta\). Completeness therefore gives \(T\models\exists\bar x\,\theta\), so \(M\) has a tuple satisfying \(\theta\). Its type is one of the \(q_i\), which also contains \(\neg\varphi_i\). The tuple would satisfy both \(\varphi_i\) and its negation, a contradiction. Consequently every type is on the finite list.

Finitely many tuple orbits characterize countable categoricity

The theory \(T\) is countably categorical if and only if it has a countable model whose automorphisms are oligomorphic. When this holds, the automorphisms of every countable model of \(T\) are oligomorphic.

If \(T\) is countably categorical, identifies the orbits in each finite context with the finite set \(S_n(T)\), so every countable model has finitely many orbits.

Conversely, let \(M\) be a countable model with finitely many orbits in every finite context. Each orbit has one type, so \(M\) realizes only finitely many \(n\)-types for every \(n\). By , each whole set \(S_n(T)\) is finite. The categoricity criterion proves that \(T\) is countably categorical.

A finite parameter set allows only finitely many unary definable sets

Suppose \(T\) is countably categorical. For every model \(M\models T\) and every finite \(A\subseteq M\), there are only finitely many \(A\)-definable subsets of \(M\). The model need not be countable.

List \(A\) without repetition as \(\bar a=(a_0,\ldots,a_{m-1})\). Any unary formula with parameters in \(A\) can be written as \(\varphi(x,\bar a)\) for an \(L\)-formula in \(m+1\) variables. Replace each parameter name \(a_i\) by a separate free variable \(y_i\), keeping \(x\) free and choosing bound variables apart. The same term/formula induction used for constant lifting preserves truth at every assignment: a replaced parameter has its assigned \(y_i\)-value, old symbols retain their interpretations, and quantifiers leave the free \(x,\bar y\)-values fixed. Evaluating \(\bar y\) at \(\bar a\) therefore recovers the original definition. Unused parameters simply give unused variables.

Equivalent formulas modulo \(T\) give the same subset of this fixed \(M\) at the same fixed tuple \(\bar a\). Thus the map \([\varphi]_T\mapsto\varphi(M,\bar a)\) from \(F_{m+1}(T)\) onto the family of \(A\)-definable unary sets is well-defined and surjective. Its domain is finite by , so its image is finite.

Finite parameters have finite algebraic closure and a finite generated carrier

Suppose \(T\) is countably categorical, \(M\models T\), and \(A\subseteq M\) is finite. Then \(\operatorname{acl}_M(A)\), \(\operatorname{dcl}_M(A)\), and the carrier generated by \(A\) are all finite.

Let \(\mathcal D_A\) be the family of unary \(A\)-definable subsets of \(M\). The definition of algebraic closure gives

\[\operatorname{acl}_M(A)=\bigcup\{D\in\mathcal D_A:D\text{ is finite}\}.\]

The family \(\mathcal D_A\) is finite by . The displayed union is therefore a finite union of finite sets. Since definable closure is contained in algebraic closure, it too is finite.

By the closure-under-functions lemma, \(\operatorname{dcl}_M(A)\) contains \(A\), all constant values, and every function value on its elements. Minimality of the generated carrier puts it inside \(\operatorname{dcl}_M(A)\), proving finiteness. If \(A\) is empty and the language has no constants, its generated carrier is empty; the finiteness assertion includes this case and does not assert that an empty carrier is a model.

Can the bound depend only on the number of generators?

For each finite \(m\), is there one bound, depending only on \(T\) and \(m\), for the size of the carrier generated by any \(m\)-tuple in any model of a countably categorical \(T\)?

Show answerHide answer

Yes. The finite number \(K_m=|F_{m+1}(T)|\) is a uniform bound.

By the term-value description, every element of the carrier generated by \(\bar a\) is the value of a term using finitely many parameters from its range. For each such parameter choose an index \(i<m\) at which it occurs in \(\bar a\), and relabel that variable by \(y_i\). The resulting term \(t(\bar y)\) has value \(t^M(\bar a)\), even when the original tuple repeats coordinates. Ground terms cover \(m=0\).

Associate to a term the formula \(x=t(\bar y)\). If two such formulas are equivalent modulo \(T\), evaluate them at \(\bar y=\bar a\) and \(x=t^M(\bar a)\). The equivalence forces the two term values to be equal. Hence terms producing distinct elements give distinct classes in \(F_{m+1}(T)\). Choosing a representative term for each generated element gives an injection into this finite class set, so the generated carrier has at most \(K_m\) elements.

This proves uniform local finiteness: the same bound works for every parameter tuple of that length in every model. The preceding theorem also proves finiteness of algebraic closure, which can contain more than just the term-generated elements.

Equality patterns and ordered patterns give the basic examples

The complete theory of infinite equality structures and the complete theory of nonempty dense linear orders without endpoints are countably categorical.

The equality-pattern classification gives finitely many complete types in every finite context for infinite equality structures. The ordered-pattern classification does the same for dense orders. Apply in each case.

In a countable infinite equality structure, ordered pairs have two automorphism orbits: equal coordinates and different coordinates. In a countable dense order, pairs have three orbits: \(x_0=x_1\), \(x_0<x_1\), and \(x_1<x_0\). These are exactly the previously classified pair types by ; repeated coordinates are included.
