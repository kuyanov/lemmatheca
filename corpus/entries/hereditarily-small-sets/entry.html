Count every membership descendant

The singleton \(\{\omega_1\}\) has one member, but that member contains every countable ordinal. Cardinality alone misses this hidden size. Throughout this entry we work in ZFC and identify cardinals with initial ordinals.

Write \(\operatorname{TC}(a)\) for the least transitive set containing \(a\) as a subset. Define the hereditary size of \(x\) by

\[ h(x)=\bigl|\operatorname{TC}(\{x\})\bigr|. \]

The singleton ensures that \(x\) itself is counted, together with its members, their members, and all further membership descendants. Thus \(x\in\operatorname{TC}(\{x\})\) and \(x\subseteq\operatorname{TC}(\{x\})\), so \(|x|\le h(x)\). For an infinite cardinal \(\kappa\), put

\[ H_\kappa=\{x:h(x)<\kappa\}. \label{eq:hereditary-definition} \]

This initially describes a class. We will prove that it is a set. Including \(x\) changes some finite hereditary sizes, but not whether they are below an infinite cardinal.

A small transitive carrier bounds its members' ranks

Let \(\theta\) be an infinite regular cardinal. If \(T\) is transitive and \(|T|<\theta\), then \(\operatorname{rank}(y)<\theta\) for every \(y\in T\).

Proof

Use membership induction. For \(y\in T\), transitivity gives \(y\subseteq T\), so \(|y|<\theta\). Every \(z\in y\) lies in \(T\) and has rank below \(\theta\) by induction. Since an infinite cardinal is a limit ordinal, \(\operatorname{rank}(z)+1<\theta\). Regularity bounds this family of fewer than \(\theta\) successor ranks strictly below \(\theta\). The rank equation

\[ \operatorname{rank}(y)=\sup_{z\in y}\bigl(\operatorname{rank}(z)+1\bigr) \]

therefore gives the required inequality, including rank zero when \(y\) is empty. □

Hereditary smallness gives a bounded rank and a set

For every infinite cardinal \(\kappa\),

\[ h(x)<\kappa\quad\Longrightarrow\quad\operatorname{rank}(x)<\kappa. \]

Consequently \(H_\kappa\subseteq V_\kappa\), and \(H_\kappa\) is a set. No regularity hypothesis on \(\kappa\) is needed here.

Proof

Let \(T=\operatorname{TC}(\{x\})\), with \(|T|<\kappa\). If \(T\) is finite, \(x\) is hereditarily finite, so its rank is below \(\omega\le\kappa\).

Otherwise \(\mu=|T|\) is an infinite cardinal below \(\kappa\). Its successor cardinal \(\mu^+\) is regular, and \(\mu^+\le\kappa\). Apply with \(\theta=\mu^+\). Since \(x\in T\), we get \(\operatorname{rank}(x)<\mu^+\le\kappa\).

The rank characterization of hierarchy stages gives \(x\in V_\kappa\). Now Separation on \(V_\kappa\) makes \eqref{eq:hereditary-definition} a set. □

The hereditary levels are transitive and exhaust all sets

Each \(H_\kappa\) is transitive. If \(\kappa\le\lambda\) are infinite cardinals, then \(H_\kappa\subseteq H_\lambda\). Every set belongs to some \(H_\kappa\).

Proof

If \(y\in x\in H_\kappa\), then \(y\in T=\operatorname{TC}(\{x\})\). The transitive set \(T\) contains \(\{y\}\) as a subset. Leastness of transitive closure gives \(\operatorname{TC}(\{y\})\subseteq T\), so \(h(y)\le h(x)<\kappa\).

Monotonicity follows by comparing the strict size bounds. For exhaustion, \(\operatorname{TC}(\{x\})\) is a set. Taking \(\kappa=(\max(\aleph_0,h(x)))^+\) gives an infinite cardinal with \(h(x)<\kappa\). □

The ordinal members are exactly the smaller ordinals

For every ordinal \(\alpha\),

\[ \operatorname{TC}(\{\alpha\})=\alpha\cup\{\alpha\}=\alpha+1,\qquad \alpha\in H_\kappa\ \Longleftrightarrow\ \alpha<\kappa. \]

Proof

The successor ordinal \(\alpha+1\) is transitive and contains \(\alpha\) as a member. Conversely, every transitive set containing \(\alpha\) contains all members of \(\alpha\), so it contains \(\alpha+1\). This proves the closure equality.

If \(\alpha<\kappa\), then \(\alpha+1<\kappa\), since \(\kappa\) is an infinite initial ordinal, and consequently \(|\alpha+1|<\kappa\). If \(\alpha\ge\kappa\), its successor contains \(\kappa\) as a subset, so its size is at least \(\kappa\). □

Subsets, pairs, and unions preserve hereditary smallness

For every infinite \(\kappa\), if \(x,y\in H_\kappa\) and \(u\subseteq x\), then

\[ u\in H_\kappa,\qquad\{x,y\}\in H_\kappa,\qquad\bigcup x\in H_\kappa. \]

Proof

Put \(T_x=\operatorname{TC}(\{x\})\) and define \(T_y\) similarly. The sets \(\{u\}\cup T_x\), \(\{\{x,y\}\}\cup T_x\cup T_y\), and \(\{\bigcup x\}\cup T_x\) are transitive: their new members have all their members in the indicated transitive closures. Each contains the singleton of the set whose hereditary size we are bounding. Leastness of transitive closure therefore bounds that hereditary size by the container's cardinality.

Each container has size below \(\kappa\). This uses only a finite union of sets of size below an infinite cardinal: finite sizes remain finite, and any infinite size absorbs the finite sum. Regularity is unnecessary for a finite family. □

A regular bound allows small collections of small sets

Let \(\kappa\) be an infinite regular cardinal. If \(A\subseteq H_\kappa\) and \(|A|<\kappa\), then \(A\in H_\kappa\).

Equivalently, any family \((x_i)_{i\in I}\) of members of \(H_\kappa\) indexed by a set of size below \(\kappa\) has both its range and its union in \(H_\kappa\).

Proof

For each \(x\in A\), put \(T_x=\operatorname{TC}(\{x\})\). The set

\[ B=\{A\}\cup\bigcup_{x\in A}T_x \]

is transitive. Every member of \(A\) lies in its own \(T_x\), and the union of the transitive sets \(T_x\) is transitive. By closure under small unions, the union has size below \(\kappa\); adjoining the one point \(A\) preserves that bound. Hence \(\operatorname{TC}(\{A\})\subseteq B\) has size below \(\kappa\).

For an indexed family, its range \(A=\{x_i:i\in I\}\) has size at most \(|I|\), so the first assertion applies. Then gives \(\bigcup_{i\in I}x_i=\bigcup A\in H_\kappa\). Empty families give the empty range and empty union. Conversely, index any such \(A\) by itself. □

The first uncountable bound gives hereditary countability

At \(\kappa=\aleph_0\), the definition is hereditary finiteness, so \(H_{\aleph_0}=V_\omega\). At \(\kappa=\aleph_1\), membership means that \(\operatorname{TC}(\{x\})\) is finite or countably infinite. Such a set is called hereditarily countable.

Every countable ordinal is hereditarily countable by . Every \(A\subseteq\omega\) is hereditarily countable: \(\{A\}\cup\omega\) is a countable transitive container. Since \(\aleph_1\) is regular, a countable family of hereditarily countable sets is itself hereditarily countable.

Can a finite set fail to be hereditarily countable?

Decide whether \(\{\omega\}\), \(\{\omega_1\}\), and \(\mathcal P(\omega)\) are hereditarily countable. Which of them are countable?

Show answerHide answer

Both singletons are finite. The closure \(\operatorname{TC}(\{\{\omega\}\})=\{\{\omega\},\omega\}\cup\omega\) is countable, so \(\{\omega\}\) is hereditarily countable. The closure for \(\{\omega_1\}\) contains \(\omega_1\), so its size is at least \(\aleph_1\); this finite set is not hereditarily countable.

The set \(\mathcal P(\omega)\) is uncountable by Cantor's theorem, and its hereditary size is at least its own size. It is therefore neither countable nor hereditarily countable, even though each of its members is hereditarily countable.

Bounded rank need not give bounded hereditary size

Hereditary countability is strictly stronger than rank below \(\omega_1\):

\[ H_{\aleph_1}\subsetneq V_{\omega_1}. \]

Moreover \(H_{\aleph_1}\) contains \(\omega\) but does not contain \(\mathcal P(\omega)\), so it is not closed under taking power sets.

Proof

The inclusion is . The ordinal \(\omega\) is hereditarily countable, while \(\mathcal P(\omega)\) is not. Yet the power-set rank formula gives \(\operatorname{rank}(\mathcal P(\omega))=\omega+1<\omega_1\), placing it in \(V_{\omega_1}\). □

Rank measures the height of membership. Hereditary size also measures how many sets occur across that height. Power sets can increase the second measure without increasing the first very far.

Why is regularity needed for small collections?

Let \(\kappa=\aleph_\omega\) and \(A=\{\aleph_n:n<\omega\}\), viewing each cardinal as an ordinal. Show that \(A\) is a countable subset of \(H_\kappa\), but \(A\notin H_\kappa\).

Show answerHide answer

Each \(\aleph_n<\aleph_\omega\) belongs to \(H_\kappa\) by . The sequence is strictly increasing, so its range \(A\) is countably infinite and has size below \(\kappa\).

The transitive closure \(\operatorname{TC}(\{A\})\) contains every member \(\aleph_n\) of \(A\), and hence every member of every \(\aleph_n\). It therefore contains

\[ \bigcup_{n<\omega}\aleph_n=\aleph_\omega=\kappa. \]

Its size is at least \(\kappa\), so \(A\notin H_\kappa\). The singularity of \(\aleph_\omega\) permits the hereditary sizes of the individual members to approach the bound.
