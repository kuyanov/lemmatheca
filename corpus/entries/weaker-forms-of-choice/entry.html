Different amounts of choice for different tasks

The axiom of choice supplies selections for arbitrary set-indexed families of nonempty sets. Two more restricted principles concern countably many selections: countable choice chooses from a given sequence of sets, while dependent choice permits each successive selection to depend on earlier selections.

Our background theory is ZF. Each result states when it additionally assumes one of these principles. We use finite sets, countability, and natural-number recursion, writing \(\omega\) for the natural numbers as sets. An infinite set means one that is not finite; we do not build the existence of a countably infinite subset into this definition.

Countable choice selects from a prescribed sequence

The axiom of countable choice, written \(\mathrm{AC}_\omega\), says: for every sequence \((A_n)_{n\in\omega}\) of nonempty sets, there is a function \(c\) on \(\omega\) with \(c(n)\in A_n\) for every \(n\).

No disjointness or distinctness of the sets is required. All candidate values belong to the set \(U=\bigcup_{n\in\omega}A_n\), and the resulting function has codomain \(U\). This is equivalent to allowing any countable index set: finite families have choice functions in ZF, and a countably infinite index set has a bijection with \(\omega\) along which we can transfer the sequence and the selections.

For every finite \(m\), a choice function on the first \(m\) sets exists in ZF. These separate finite existence statements do not themselves supply one function on all of \(\omega\). Replacement collects uniquely specified outputs, not unspecified selections.

Dependent choice follows a relation from a starting point

A relation \(R\subseteq X\times X\) is serial if every \(x\in X\) has some successor \(y\in X\) with \(x\,R\,y\). The axiom of dependent choice, written DC, says: for every nonempty set \(X\), every serial relation \(R\) on it, and every prescribed \(x_0\in X\), there is a function \(f:\omega\to X\) such that

\[ f(0)=x_0,\qquad f(n)\,R\,f(n+1)\quad(n\in\omega). \]

The sequence need not be injective. Seriality asserts existence of a possible next point, but does not give a uniquely specified next point. When a step function \(g:X\to X\) is already supplied, ordinary recursion constructs \(f(n+1)=g(f(n))\) without any extra choice principle.

The nonemptiness assumption matters: the empty relation on the empty carrier is serial vacuously, but there is no function from \(\omega\) into the empty set.

Allowing an unspecified start gives the same principle

DC is equivalent to the version that asks only for some infinite \(R\)-sequence on each nonempty serial carrier, without specifying its first point.

Proof

The prescribed-start version immediately gives the other version by fixing one point of a nonempty carrier. Conversely, fix \(x_0\in X\). Let \(T\) be the set of nonempty finite \(R\)-paths beginning at \(x_0\). It is a set, since its graphs lie in \(\mathcal P(\omega\times X)\), and it contains the one-term path. Relate each path to its one-term extensions. Seriality of \(R\) makes this relation serial on \(T\).

An infinite sequence of such extensions, supplied by the unspecified-start version, consists of compatible paths whose lengths increase by one each time. Their union is a function on \(\omega\), since those lengths are unbounded in \(\omega\). Every path starts at \(x_0\), and each successive pair in the union occurs in a sufficiently long path. Thus the union is an \(R\)-sequence with the prescribed start. □

Full choice supplies a step function

Over ZF, \(\mathrm{AC}\Rightarrow\mathrm{DC}\).

Proof

Let \(X\) be nonempty and \(R\) serial, and fix \(x_0\in X\). For each \(x\in X\), the successor set \(S_x=\{y\in X:x\,R\,y\}\) is nonempty. Apply AC to this \(X\)-indexed family to obtain \(g:X\to X\) with \(g(x)\in S_x\). Recursion from \(x_0\) gives a sequence with \(f(n+1)=g(f(n))\), hence \(f(n)\,R\,f(n+1)\). □

Successive extensions choose from an entire sequence

Over ZF, \(\mathrm{DC}\Rightarrow\mathrm{AC}_\omega\). Consequently

\[ \mathrm{AC}\ \Longrightarrow\ \mathrm{DC}\ \Longrightarrow\ \mathrm{AC}_\omega. \]

Proof

Let \((A_n)_{n\in\omega}\) be nonempty sets, and put \(U=\bigcup_n A_n\). Let \(T\) be the set of functions \(s\) on some finite ordinal \(m\), with \(s(i)\in A_i\) for \(i<m\). These graphs form a subset of \(\mathcal P(\omega\times U)\), so \(T\) is a set; it contains the empty function.

Define \(s\,R\,t\) when \(t\) extends \(s\) by exactly one new value: if \(\operatorname{dom}(s)=m\), then \(t=s\cup\{(m,a)\}\) for some \(a\in A_m\). The relation is serial because each \(A_m\) is nonempty. Apply DC starting at the empty function. Induction shows that the resulting \(s_n\) has domain \(n\), and every \(s_{n+1}\) extends \(s_n\).

The union \(c=\bigcup_n s_n\) is a set function with domain \(\omega\). At index \(i\), its value agrees with \(s_{i+1}(i)\in A_i\). Thus \(c\) is the required choice function. □

These proofs establish the displayed implications. They do not prove that any reverse implication fails; non-implication and independence require separate model arguments.

A whole finite history can be the state of a selection process

Assume DC. Let \(X\) be a set and \(T\) a nonempty set of finite sequences in \(X\). If every \(s\in T\) has a one-term extension in \(T\), then for any prescribed \(s_0\in T\) there is a sequence \(f:\omega\to X\) extending \(s_0\), whose initial segment of each length at least \(\operatorname{dom}(s_0)\) belongs to \(T\).

Proof

Use \(T\) as the carrier and one-term extension as the serial relation, starting at \(s_0\). The path lengths are \(m,m+1,m+2,\ldots\), where \(m\) is the length of \(s_0\). Their union is a function on \(\omega\), and its indicated initial segments are exactly those path values. □

Thus a requirement may depend on the entire finite history, rather than only its last selected element. The proof does not replace that requirement by independent choices from a predetermined family.

Dedekind infinity means matching a proper subset

A set \(A\) is Dedekind infinite if there is a bijection from \(A\) onto a proper subset of itself. Equivalently, there is an injective self-map \(u:A\to A\) that is not surjective: restricting its codomain to its image gives the bijection, and composing a proper-subset bijection with inclusion gives the self-map. A set that is not Dedekind infinite is Dedekind finite.

Every finite set is Dedekind finite, by the finite self-map theorem. Hence every Dedekind-infinite set is infinite. The converse is a distinct assertion, for which we will explicitly assume countable choice.

Dedekind infinity is equivalent to a countably infinite subset

In ZF, a set \(A\) is Dedekind infinite if and only if there is an injection \(e:\omega\to A\), or equivalently a countably infinite subset of \(A\).

Proof

Given an injective nonsurjective self-map \(u\), fix \(a_0\in A\setminus u(A)\), and recursively put \(a_{n+1}=u(a_n)\). If \(a_m=a_n\) with \(m<n\), injectivity cancels \(m\) iterations and gives \(a_0=a_{n-m}\). The right side is a value of \(u\), contrary to the choice of \(a_0\). Thus \(n\mapsto a_n\) is injective. This uses a single chosen point and a specified step function, not a choice principle.

Conversely, let \(e:\omega\to A\) be injective. Define \(u(e(n))=e(n+1)\), and let \(u(x)=x\) outside \(e(\omega)\). Injectivity of \(e\) makes the definition unambiguous. The two image parts are disjoint, and the shift is injective on the first, so \(u\) is injective on \(A\). Its image is exactly \(A\setminus\{e(0)\}\), a proper subset. Finally, an injection is a bijection onto its image, establishing the countably infinite subset formulation. □

Countable choice makes every infinite set Dedekind infinite

Assume \(\mathrm{AC}_\omega\). Every infinite set contains a countably infinite subset, and hence is Dedekind infinite.

Proof

Let \(A\) be infinite. For each positive natural number \(n\), the set \(I_n\) of injections \(n\to A\) is nonempty. To see this, construct a finite list of distinct points by finite induction: a finite range cannot exhaust \(A\), so one more point exists. All \(I_n\) are sets of graphs in \(\mathcal P(\omega\times A)\). Countable choice supplies one injection \(e_n\in I_n\) for each positive \(n\).

Put \(B=\bigcup_{n\ge1}\operatorname{ran}(e_n)\). This set is infinite: if it had \(m\) members, \(e_{m+1}\) would inject \(m+1\) into an \(m\)-element set, contradicting finite pigeonhole.

We now have specified finite lists, so no further choices are needed. Fix \(b_*=e_1(0)\). Define a map on \(\omega\times\omega\) by

\[ q(n,k)=\begin{cases}e_{n+1}(k),&k<n+1,\\ b_*,&k\ge n+1.\end{cases} \]

It is a surjection onto \(B\). Composing with the diagonal enumeration of pairs gives a surjection \(\omega\to B\). The first-occurrence construction removes repetitions, and since \(B\) is infinite it gives a bijection \(\omega\to B\). Inclusion into \(A\) and complete the proof. □

Countable choice was applied to the already defined sets of finite injections. Simply saying “choose a new element at each step” would instead invoke a successive-selection principle without identifying it.

Countable choice makes a countable union countable

Assume \(\mathrm{AC}_\omega\). If \((A_n)_{n\in\omega}\) is a sequence of countable sets, then \(U=\bigcup_n A_n\) is countable, including when some or all \(A_n\) are empty.

Proof

For each \(n\), let \(E_n\) be the set of injections \(A_n\to\omega\). It is nonempty by the encoding characterization; for an empty domain it contains the empty function. Each \(E_n\) is a set of graphs, and Replacement forms their sequence. Countable choice supplies an encoding \(j_n\in E_n\) for every \(n\).

For \(x\in U\), there is a least \(n(x)\) with \(x\in A_{n(x)}\). Map

\[ x\longmapsto\bigl(n(x),j_{n(x)}(x)\bigr)\in\omega\times\omega. \]

Equality of pairs gives equality of the first indices, then equality of the points by the corresponding encoding. Thus this map is injective. Compose with a natural-number code for pairs to inject \(U\) into \(\omega\), proving countability. If \(U\) is empty the same argument gives the empty encoding. □

If encodings \(j_n\) are supplied as part of the data, this construction works in ZF without countable choice. The extra principle is used to pass from “each set admits an encoding” to “a sequence of encodings exists.”

Dependent choice turns failure of minimality into a descending sequence

In ZF, a well-founded relation on a set has no infinite descending sequence. Under DC, the converse also holds.

Proof

For the forward implication, a descending sequence \(a_{n+1}\,R\,a_n\) has a nonempty range. Any minimal point of that range is some \(a_n\), but \(a_{n+1}\) is a predecessor in the same range, a contradiction.

Conversely, suppose \(R\) is not well-founded on \(A\). Some nonempty \(B\subseteq A\) has no \(R\)-minimal point. Thus every \(b\in B\) has a predecessor \(c\in B\) with \(c\,R\,b\). On \(B\) define \(b\,S\,c\) to mean \(c\,R\,b\). This is a serial relation. DC, from any fixed point of \(B\), supplies an \(S\)-sequence, which is exactly an infinite descending \(R\)-sequence. □

This is why a ZF-only argument must not replace the minimal-element definition of well-foundedness by the absence of infinite descending sequences without an additional justification.

Which constructions already specify their next value?

Compare choosing from nonempty subsets of \(\omega\), iterating a given function, and extending arbitrary finite choice functions. Where is an additional choice principle used?

Show answerHide answer

Nonempty subsets of \(\omega\) have uniquely specified least members, so taking minima needs no extra principle, even for a set-indexed family. Iterating a supplied function also needs only recursion. Arbitrary extendible finite histories provide possible next values without specifying a rule for selecting them; DC supplies a coherent infinite chain of extensions. For a prescribed sequence of nonempty sets, countable choice suffices for the full choice function, as its definition states.

None of these examples proves a non-implication between principles. Constructing infinite Dedekind-finite sets in models or separating AC, DC, and countable choice requires model-theoretic material outside this entry.

Countably many countable ordinals stay below omega one

Assume countable choice. Every countable set \(C\subseteq\omega_1\) has a strict upper bound below \(\omega_1\): there is \(\beta<\omega_1\) with \(\alpha<\beta\) for all \(\alpha\in C\).

Proof

Recall that \(\omega_1\) consists of the countable ordinals. Each \(\alpha+1\), for \(\alpha\in C\), is countable. If \(C\) is nonempty, list it using the list characterization of countability, allowing repetitions when it is finite. By ,

\[ \beta=\bigcup_{\alpha\in C}(\alpha+1)=\sup_{\alpha\in C}(\alpha+1) \]

is countable, so \(\beta<\omega_1\); and \(\alpha+1\le\beta\) gives \(\alpha<\beta\). If \(C\) is empty, take \(\beta=0\). □

Thus countable choice suffices for the regularity of \(\omega_1\): any subset of \(\omega_1\) with smaller cardinality is countable and hence not cofinal. In the cofinality notation, \(\operatorname{cf}(\omega_1)=\omega_1\). This conclusion was obtained from countable choice alone, without reusing a theorem whose proof assumes full Choice.
