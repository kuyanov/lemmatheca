Compare relative halting sets using ordinary maps

For an oracle \(A\subseteq\mathbb N\), use the established oracle program numbering \(\varphi_e^A\). Its zero-input halting set is

\[K_A=\{e:\varphi_e^A(0)\downarrow\}.\]

The diagonal jump is \(J(A)=\{e:\varphi_e^A(e)\downarrow\}\). The fixed injective recodings \(\alpha:K_A\le_1J(A)\) and \(\beta:J(A)\le_1K_A\) work for every oracle. Write \(S\le_mT\) and \(S\le_1T\) for ordinary total computable reductions, the latter also injective. Thus the translating map has no oracle, even when \(S,T\) are relative halting sets.

A computable isomorphism from \(S\) to \(T\) is a total computable permutation \(P\) with \(x\in S\Longleftrightarrow P(x)\in T\). Its inverse is total computable as well. Write \(S\cong_{\mathrm{comp}}T\) for this relation.

Record finitely many equivalent halting queries

Fix an ordinary total computable map \(g:\mathbb N\to\mathbb N\). For a finite list \(L\) of indices, its image list is \(B_g(L)=L.\operatorname{map}(g)\); the notation \(y\in B_g(L)\) means that \(y=g(j)\) for some entry \(j\) of \(L\). Repetitions are allowed. The numerical list coding makes computing this list and testing its membership ordinary finite algorithms.

Relative to \(A\), a list \(L\) is compatible with \(e\) when

\[\forall j\in L\quad(j\in K_A\Longleftrightarrow e\in K_A).\]

Compatibility is a mathematical invariant; the construction will not decide it. In the escape argument assume that \(g\) reduces \(K_A\) to a set \(C\), meaning \(j\in K_A\Longleftrightarrow g(j)\in C\) for every \(j\).

Two transformers inspect only finite numerical data

Let \(d\) be the fixed oracle index of a program that searches the constant sequence of ones for a zero. This program diverges on every input under every oracle. Let \(u\) be the fixed index of the constant-one program. These use the existing search operation and constant programs.

Define the first numerical transformer \(F_1(t,p)\) by decoding \(p=\langle e,\operatorname{code}(L)\rangle\) and setting

\[F_1(t,p)=\begin{cases}e,&g(t)\notin B_g(L),\\d,&g(t)\in B_g(L).\end{cases}\]

Define the rescue transformer \(F_2(t,c)\), with \(L=\operatorname{decode}(c)\), by

\[F_2(t,c)=\begin{cases}u,&g(t)\in B_g(L),\\d,&g(t)\notin B_g(L).\end{cases}\]

Both transformers are ordinary total computable functions of their numerical inputs. They run \(g\) on finitely many numbers and compare numbers; neither uses an oracle nor tests membership in \(C\). List decoding is total, so these rules specify transformers on every input.

Choose both selectors before choosing an oracle

For the fixed computable \(g\), there are ordinary primitive-recursive selectors \(N,M:\mathbb N\to\mathbb N\). Put

\[\begin{aligned}n(e,L)&=N(\langle e,\operatorname{code}(L)\rangle),\\m(L)&=M(\operatorname{code}(L)).\end{aligned}\]

For every oracle \(Z\), every \(e,L,x\), write \(n=n(e,L)\) and \(m=m(L)\). These same selectors satisfy

\[\varphi_n^Z(x)\simeq \begin{cases}\varphi_e^Z(x),&g(n)\notin B_g(L),\\\uparrow,&g(n)\in B_g(L),\end{cases}\]
\[\varphi_m^Z(x)\simeq \begin{cases}1,&g(m)\in B_g(L),\\\uparrow,&g(m)\notin B_g(L).\end{cases}\]

Here \(\simeq\) is equality of partial computations, including divergence.

Apply the common parameterized recursion theorem to each of the ordinary numerical transformers \(F_1,F_2\). It supplies \(N\) with \(\varphi_{N(p)}^Z(x)\simeq\varphi_{F_1(N(p),p)}^Z(x)\), simultaneously for every \(Z,p,x\), and similarly supplies \(M\) for \(F_2\). Substitute the transformer definitions and the two fixed programs' behavior.

The order of choices matters: first fix a program for \(g\), then the two transformers and their common selectors; only afterwards choose \(A,C\) for which \(g\) has the required reduction property. No separate choice of a selector for each oracle is used.

A collision in the first selector forces divergence

Suppose \(g:K_A\le_m C\), and \(L\) is compatible with \(e\). If \(g(n(e,L))\notin B_g(L)\), then \(\varphi_{n(e,L)}^A\simeq\varphi_e^A\). If \(g(n(e,L))\in B_g(L)\), then \(e\notin K_A\).

The fresh case is the first selector identity. In the collision case choose \(j\in L\) with \(g(n(e,L))=g(j)\). Since \(g\) is a reduction and \(L\) is compatible,

\[\begin{aligned}n(e,L)\in K_A&\Longleftrightarrow g(n(e,L))\in C\\ &\Longleftrightarrow g(j)\in C\Longleftrightarrow e\in K_A.\end{aligned}\]

The selector identity also says that \(n(e,L)\notin K_A\), because its program diverges. Therefore \(e\notin K_A\). This inference uses the reduction property in the proof, without asking the algorithm to decide it.

The rescue selector must escape a compatible record

Under the hypotheses of , if the first selector collides, then \(g(m(L))\notin B_g(L)\), and \(m(L)\notin K_A\). Consequently \(m(L)\in K_A\Longleftrightarrow e\in K_A\).

The first collision gives \(e\notin K_A\). Hence every \(j\in L\) lies outside \(K_A\). If \(g(m(L))\in B_g(L)\), choose an old \(j\) with the same image. The rescue identity makes \(m(L)\) halt with output one, while the reduction gives

\[\begin{aligned}m(L)\in K_A&\Longleftrightarrow g(m(L))\in C\\ &\Longleftrightarrow g(j)\in C\Longleftrightarrow j\in K_A.\end{aligned}\]

The right side is false, a contradiction. Thus the rescue image is fresh. Its selector identity now makes it diverge. Both \(m(L)\) and \(e\) lie outside \(K_A\), proving the equivalence.

Make one effective escape step

The escape step is the ordinary numerical function

\[E_g(e,L)=\begin{cases}n(e,L),&g(n(e,L))\notin B_g(L),\\m(L),&g(n(e,L))\in B_g(L).\end{cases}\]

It is total computable on all inputs, since the selectors, \(g\), and the finite test are total computable. Whenever \(g:K_A\le_m C\) and \(L\) is compatible with \(e\), the two cases just proved give

\[E_g(e,L)\in K_A\Longleftrightarrow e\in K_A,\qquad g(E_g(e,L))\notin B_g(L).\]

The choice between the selectors uses the first image's collision test only. It does not wait for either oracle computation to halt.

Append one new equivalent query at each stage

For each \(e\), define its query history \(Q_{e,k}\) and query sequence \(h(e,k)\) by

\[Q_{e,0}=[e],\qquad h(e,0)=e,\]
\[h(e,k+1)=E_g(e,Q_{e,k}),\qquad Q_{e,k+1}=Q_{e,k}\mathbin{+\!+}[h(e,k+1)].\]

Thus \(Q_{e,k}=[h(e,0),\ldots,h(e,k)]\). These recurrences are ordinary total computable operations on coded lists; a prescribed \(k\) requires exactly \(k\) escape steps.

The history keeps its status and gains a distinct image

If \(g:K_A\le_m C\), then for every \(e,k\), the history \(Q_{e,k}\) has length \(k+1\), is compatible with \(e\), and its image list \(B_g(Q_{e,k})\) has no repetitions. In particular, \(h(e,k)\in K_A\Longleftrightarrow e\in K_A\), and \(k\mapsto g(h(e,k))\) is injective.

Use induction on \(k\), for each fixed \(e\). At zero the history contains just \(e\), so all three assertions hold. Assume them at \(k\). The escape-step assertion gives a new query with the same halting status as \(e\), so appending it preserves compatibility. Its image is absent from the whole old image list, so appending that image preserves the absence of repetitions. Appending one element increases the length by one.

For distinct positions \(r<s\), the query at position \(r\) is already present in \(Q_{e,s-1}\), whereas the image of the new query \(h(e,s)\) avoids that history. Their images differ. This proves the asserted injectivity across arbitrary stages.

A bounded scan avoids any finite list of target values

For a finite forbidden list \(F\), let the avoidance position \(k(e,F)\) be the least \(k\le |F|\) with \(g(h(e,k))\notin F\). To define a total numerical function without assuming a valid reduction, use the bounded scan with sentinel \(|F|+1\) when no such position exists. The avoiding image is

\[r(e,F)=g(h(e,k(e,F))).\]

Both functions are ordinary total computable on every \(e,F\). If \(g:K_A\le_m C\), the sentinel is never reached: the first \(|F|+1\) image values are distinct by , whereas \(F\) has at most \(|F|\) distinct entries. Thus some tested image is absent from \(F\). For a valid reduction,

\[r(e,F)\notin F,\qquad e\in K_A\Longleftrightarrow r(e,F)\in C.\]

The membership equivalence follows first from the query's compatibility and then from the reduction property of \(g\).

Keep a second history of previously chosen outputs

Define the output history \(F_e\) and injective replacement \(b\) simultaneously by

\[F_0=[],\qquad b(e)=r(e,F_e),\qquad F_{e+1}=F_e\mathbin{+\!+}[b(e)].\]

Thus \(F_e=[b(0),\ldots,b(e-1)]\). This is ordinary finite recursion: on input \(e\), compute the earlier outputs, then the bounded avoiding image. The function is total computable even when no oracle makes \(g\) a reduction; correctness requires that reduction hypothesis.

Every ordinary reduction out of relative halting has an injective replacement

Fix an ordinary total computable \(g\), and common selectors as above. The specified \(b\) is ordinary total computable. For every \(A,C\) such that \(g:K_A\le_m C\), it is injective and

\[e\in K_A\quad\Longleftrightarrow\quad b(e)\in C.\]

In particular, \(K_A\le_m C\) implies \(K_A\le_1C\).

The preceding recurrences prove total computability independently of \(A,C\). Under the reduction hypothesis, finite avoidance gives \(b(e)\notin F_e\). If \(j<e\), then \(b(j)\) belongs to \(F_e\), so \(b(e)\ne b(j)\). Thus \(b\) is injective. Finite avoidance also gives the displayed membership equivalence for every input.

Computing \(b\) uses a fixed ordinary program for \(g\), the two common selectors and finite histories. The oracle computations occur in the correctness proof; their membership answers are never used by the algorithm.

Padding makes a reduction into relative halting injective

If an ordinary total computable \(f\) reduces \(C\) to \(K_A\), then

\[i_0(x)=\operatorname{pad}(f(x),x)\]

is an ordinary total computable injective reduction of \(C\) to \(K_A\).

The actual padding map is jointly primitive recursive and jointly injective, and preserves evaluation under every oracle. Hence \(\varphi_{i_0(x)}^A(0)\simeq\varphi_{f(x)}^A(0)\), proving membership preservation. If \(i_0(x)=i_0(y)\), joint injectivity gives equality of the second arguments, so \(x=y\). Composition proves ordinary total computability.

Many-one equivalence to a jump determines a computable permutation

For every oracle \(A\) and every set \(C\), the following are equivalent:

\[\begin{aligned}C\equiv_mJ(A)&\Longleftrightarrow C\equiv_1J(A)\\ &\Longleftrightarrow C\cong_{\mathrm{comp}}J(A).\end{aligned}\]

More explicitly, supplied ordinary reductions \(f:C\le_mK_A\) and \(g:K_A\le_mC\) determine the injections

\[i(x)=\alpha(\operatorname{pad}(f(x),x)),\qquad j(y)=b(\beta(y)),\]

directed from \(C\) to \(J(A)\) and back. Let \(P=\operatorname{forward}(i,j)\) and \(Q=\operatorname{backward}(i,j)\) be the specified finite-stage Myhill maps. They are ordinary total computable and satisfy

\[Q(P(x))=x,\qquad P(Q(y))=y,\]
\[x\in C\quad\Longleftrightarrow\quad P(x)\in J(A).\]

If \(C\equiv_mJ(A)\), compose the given reductions with the fixed recodings \(\alpha,\beta\) to obtain \(f,g\) as stated. The reverse-injection lemma and injective-upgrade theorem give \(i,j\), with their indicated membership equivalences. Myhill's computability theorem, inverse identities, and membership-label preservation give exactly the asserted properties of these same \(P,Q\). Thus many-one equivalence yields one-one equivalence and a computable isomorphism.

Conversely a computable isomorphism and its computable inverse give the two injective reductions; forgetting injectivity gives many-one equivalence. No enumerability assumption on \(C\) is needed. Programs witnessing the reductions may be chosen using facts about \(A,C\), but running the resulting permutation queries neither set. This construction does not decide whether arbitrary proposed programs are valid reductions.

Every positive existential level has one complete isomorphism type

For every base oracle \(B\), every \(n>0\), and every \(H\subseteq\mathbb N\),

\[H\text{ is }\Sigma_n^B\text{-complete} \quad\Longleftrightarrow\quad H\cong_{\mathrm{comp}}B^{(n)}.\]

Any two \(\Sigma_n^B\)-complete sets are therefore computably isomorphic, using ordinary computable permutations and inverses.

Use the existing completeness characterization, with its ordinary many-one maps: completeness is equivalent to \(H\equiv_m B^{(n)}\). Since \(n>0\), write \(n=k+1\). The canonical iterate is \(B^{(n)}=J(B^{(k)})\), so applies with oracle \(A=B^{(k)}\). Conversely a computable isomorphism gives both ordinary many-one reductions, and the same characterization proves completeness.

For two complete sets \(H,D\), let \(P_H,Q_H\) and \(P_D,Q_D\) be the constructed maps to and from \(B^{(n)}\). The ordinary computable maps \(Q_D\circ P_H\) and \(Q_H\circ P_D\) are inverse by their two identities. Their membership equivalences show that the first maps \(H\) onto \(D\). These are explicit compositions of the supplied constructions.

Use the same ordinary reduction convention for universal levels

For a base \(B\) and a positive \(n\), a set \(H\) is \(\Pi_n^B\)-complete if \(H\in\Pi_n^B\) and every \(S\in\Pi_n^B\) has an ordinary total computable many-one reduction to \(H\). The hierarchy classes have the existing quantifier definitions; completeness adds the stated universality property.

Complementing both sides preserves the reduction map

For \(n>0\), a set \(H\) is \(\Pi_n^B\)-complete if and only if \(\overline H\) is \(\Sigma_n^B\)-complete. Moreover every computable isomorphism from \(S\) to \(T\), with its same inverse, is an isomorphism from \(\overline S\) to \(\overline T\).

A numerical \(f\) satisfies \(x\in S\Longleftrightarrow f(x)\in T\) exactly when it satisfies \(x\notin S\Longleftrightarrow f(x)\notin T\): negate both sides. Thus the same ordinary map reduces the two complements, and all computability or injectivity properties are retained. Complement duality exchanges \(\Sigma_n^B\) with \(\Pi_n^B\).

If \(H\) is \(\Pi_n^B\)-complete and \(S\in\Sigma_n^B\), then \(\overline S\in\Pi_n^B\) reduces to \(H\); the same map reduces \(S\) to \(\overline H\). Membership of \(\overline H\) in \(\Sigma_n^B\) follows from duality, so it is complete. Conversely apply this argument with the polarities exchanged and complement twice. For an isomorphism, complementing the membership equivalence leaves the two numerical inverse identities unchanged, proving the final assertion.

Universal complete sets have the complementary canonical type

For every base \(B\), every \(n>0\), and every \(H\),

\[H\text{ is }\Pi_n^B\text{-complete} \quad\Longleftrightarrow\quad H\cong_{\mathrm{comp}}\overline{B^{(n)}}.\]

Any two \(\Pi_n^B\)-complete sets are computably isomorphic. In particular, with \(B=\varnothing\), each positive ordinary \(\Sigma_n\) level has the canonical complete type \(\varnothing^{(n)}\), and each positive ordinary \(\Pi_n\) level has its complement as canonical complete type.

The complement-completeness lemma reduces the first assertion to . If \(P,Q\) relate \(\overline H\) and \(B^{(n)}\), those exact maps relate \(H\) and \(\overline{B^{(n)}}\). Conversely complement any isomorphism in the displayed statement and use the existential-level classification. Compose the two specified pairs of inverse maps through the common canonical set to compare any two universal complete sets, exactly as in the existential case. Taking the empty base gives the ordinary specializations.

Totality and infinite domain differ by a computable renaming

The index sets \(\mathrm{TOT}=\{e:\varphi_e\text{ is total}\}\) and \(\mathrm{INF}=\{e:\operatorname{dom}\varphi_e\text{ is infinite}\}\) are computably isomorphic.

They are respectively \(\Pi_2\)-complete and \(\Pi_2\)-complete, so apply with the empty base and \(n=2\). This gives ordinary total computable inverse permutations preserving the two membership predicates. The sets need not be equal: the specified index of the program that halts exactly on even inputs belongs to \(\mathrm{INF}\) but not \(\mathrm{TOT}\).

Can the positive-level hypothesis be dropped?

If the completeness definition is extended to \(n=0\), must two ordinary \(\Sigma_0\)-complete sets be computably isomorphic? More generally, does arbitrary many-one equivalence force a computable isomorphism?

Show answerHide answer

No to both questions. Let \(S=\{0,1\}\) and \(T=\{0\}\). The ordinary level \(\Sigma_0\) consists of computable sets. Both \(S,T\) are computable and nontrivial. For any computable \(D\), the total computable function returning zero on members of \(D\) and two on nonmembers reduces \(D\) to either set. Thus both are complete for this extended level-zero definition, and they are many-one equivalent.

They cannot be computably isomorphic, or even isomorphic by an arbitrary permutation preserving membership. Such a permutation would send both zero and one into the singleton \(T\), contradicting injectivity, as in the existing finite counterexample. The proof at positive levels uses \(n=k+1\) to exhibit the canonical complete set as a jump; that step is unavailable at zero.
