Ask whether finitely many predetermined answers decide halting

A simple c.e. set cannot be many-one complete. A truth-table procedure may instead combine several answers, including their negations. We will prove that a simple set can be complete for this stronger form of reduction, while a hypersimple set cannot.

Let \(K=\{e:\varphi_e(e)\downarrow\}\) be the diagonal halting set. A c.e. set \(A\) is truth-table complete if every c.e. set is truth-table reducible to \(A\). Since every c.e. set is many-one reducible to \(K\), and many-one reductions give truth tables, this is equivalent to \(K\le_{\mathrm{tt}}A\).

Write \(A\equiv_{\mathrm{tt}}B\) for reductions in both directions, and \(A<_{\mathrm{tt}}B\) for \(A\le_{\mathrm{tt}}B\) with \(B\not\le_{\mathrm{tt}}A\). Recall that hypersimplicity means that \(A\) is c.e. and its infinite complement is hyperimmune. We use classical reasoning and the fixed ordinary program enumeration throughout.

Write a truth-table computation as a propositional formula

Fix a truth-table reduction \(K\le_{\mathrm{tt}}A\). There is a total computable sequence of propositional formulas \(\theta_e\), in atoms \(P_0,P_1,\ldots\), such that

\[e\in\overline K\quad\Longleftrightarrow\quad\chi_A\models\theta_e.\]

Here a set is read as its membership valuation, so \(\chi_A(P_i)=1\) exactly when \(i\in A\).

On input \(e\), compute the scheme's finite prefix bound \(u(e)\) and all its binary rows. For every row where the halting table outputs zero, form the conjunction that specifies precisely that row: use \(P_i\) for bit one and \(\neg P_i\) for bit zero, for \(i<u(e)\). Let \(\theta_e\) be the disjunction of these conjunctions. The row formulas and DNF construction prove the equivalence. Empty conjunctions and disjunctions cover a zero bound or a table with no zero-output row.

This is an effective construction of formula text: generate the finite rows, compute their outputs, and concatenate the indicated constructors in a fixed order. It gives a total computable map on formula codes, rather than merely choosing a formula for each input. Equivalently, it complements the output of the original table and then represents that Boolean function.

Finite propositional consequence is a terminating computation

Given finite lists of natural-number atoms and propositional formulas, and a proposed conclusion \(\eta\), it is decidable whether every valuation satisfying the listed premises also satisfies \(\eta\). The complete list of atoms occurring in a formula can also be computed.

Scan the finite syntax trees and list the union of their occurring atoms. Enumerate every binary assignment to this finite list and evaluate each formula by its truth tables. Consequence holds exactly when no row makes all premises true and the conclusion false. An empty atom list has one row, so the test also handles constant formulas and empty premises. Inconsistent premises pass every consequence test.

The computation uses finite list coding, bounded loops and finite syntax evaluation. One explicit effective syntax coding uses \(4i\) for \(P_i\), \(1\) for \(\bot\), \(4c+2\) for negation of code \(c\), and \(4\langle c,d\rangle+3\) for conjunction. Subformula codes are smaller than their parent code. Parsing, collecting supports and evaluating can therefore be computed by a finite table through the input code, reusing earlier entries. Malformed codes are rejected. Other connectives are expanded into negation and conjunction before coding. These algorithms are ordinary recursive procedures on numerical inputs.

Compile an index uniformly from the whole finite prefix

Let \(A\) be c.e., fix an index recognizing it, and put \(\Gamma_A=\{P_i:i\in A\}\). For every finite formula list \(\ell\), define

\[V_\ell=\{e:\Gamma_A\cup\ell\models\theta_e\}.\]

There is a single total computable index map \(q\) on finite lists such that \(W_{q(\ell)}=V_\ell\). The map is defined even when \(\ell\) contains false or inconsistent premises.

Use the fixed finite-stage enumeration \(A_s\) of \(A\). A recognizer with inputs \((\ell,e)\) first computes \(\theta_e\). At stages \(s=0,1,\ldots\), apply to the finite premises \(\{P_i:i\in A_s\}\cup\ell\) and conclusion \(\theta_e\). Return zero at the first successful stage. Every success is sound because the finite positive premises belong to \(\Gamma_A\).

Conversely, suppose \(\Gamma_A\cup\ell\models\theta_e\). Let \(S\) be the finite union of the supports of \(\ell\) and \(\theta_e\). The positive premises \(\{P_i:i\in A\cap S\}\cup\ell\) already imply \(\theta_e\). Otherwise a countervaluation on \(S\) could be extended by setting every atom outside \(S\) to one. It would satisfy all of \(\Gamma_A\cup\ell\) and still falsify \(\theta_e\), contradicting the assumption. Eventually every member of the finite set \(A\cap S\) has entered \(A_s\), so the stage test succeeds. Thus the recognizer has exactly the required domain.

The recognizer is partial recursive jointly in the coded list and input: computing \(\theta_e\), producing a finite enumeration stage and performing the finite test are total recursive, followed by least-stage search. Choose one paired-input index \(v\) for this actual procedure. The parameter theorem gives \(q(\ell)=s(v,\operatorname{code}(\ell))\) and

\[\varphi_{q(\ell)}(e)\simeq\text{the preceding recognition procedure on }(\ell,e).\]

Consequently this same compiler has the stated domain identity for every finite prefix. It is primitive recursive as a transformation of the prefix code; the possibly longer computation of \(\theta_e\) occurs inside the compiled program.

Use the compiled index itself as the next escape point

Starting with the empty list \(\ell_0\), define the successive formula list by

\[\rho_n=\theta_{q(\ell_n)},\qquad \ell_{n+1}=\ell_n\mathbin{{}^\frown}[\rho_n].\]

The map \(n\mapsto\rho_n\) is total computable. Compute the current finite list, compile its index by \(q\), run the total formula producer \(\theta\) on that index, and append its result. Finite recursion gives the whole construction. No stage asks whether the current premises are true or whether their consequences lie in \(\overline K\).

Every formula is true but is not forced by its predecessors

For every \(n\), the constructed formulas satisfy

\[\chi_A\models\rho_n,\qquad \Gamma_A\cup\{\rho_j:j<n\}\not\models\rho_n.\]

Induct on \(n\). Assuming the earlier formulas true at \(\chi_A\), every consequence of \(\Gamma_A\cup\ell_n\) is true there. The defining equivalence for \(\theta\) therefore gives \(W_{q(\ell_n)}\subseteq\overline K\).

The identity productive function for \(\overline K\), applied to this very compiled index, gives

\[q(\ell_n)\in\overline K\setminus W_{q(\ell_n)}.\]

The first membership makes \(\rho_n=\theta_{q(\ell_n)}\) true at \(\chi_A\). The second says that \(\Gamma_A\cup\ell_n\) does not imply that formula, by the exact domain identity of . This proves both claims and closes the induction. The argument concerns not being forced by earlier formulas; it makes no stronger assertion that all assignments of signs to the list are consistent.

Bound all coordinates used by a finite collection of formulas

For a formula \(\rho\), let \(\operatorname{supp}(\rho)\) be its finite set of occurring atom indices. Put

\[N(n)=2^{2^n},\qquad m(n)=1+\max\left(\{n\}\cup\bigcup_{k\le N(n)}\operatorname{supp}(\rho_k)\right).\]

The support bound \(m\) is total computable: compute the first \(N(n)+1\) formulas, their finite supports and the finite maximum. In particular \(m(n)>n\), and every atom used in any of those formulas has index strictly below \(m(n)\). Including \(n\) makes the maximum nonempty even when all the supports are empty.

Each interval contains an omitted number

For every \(n\), the finite interval \([n,m(n))\) meets \(\overline A\).

Suppose instead that \([n,m(n))\subseteq A\). For each \(k\le N(n)\), replace every atom of \(\rho_k\) with index at least \(n\) by \(\top\), obtaining \(\rho_k^*\). Every replaced atom has index below \(m(n)\), by , so it is one of the positive premises of \(\Gamma_A\). Hence \(\Gamma_A\models\rho_k\leftrightarrow\rho_k^*\).

The new formulas use only \(P_0,\ldots,P_{n-1}\). There are \(2^n\) assignments to these atoms and exactly \(2^{2^n}=N(n)\) Boolean truth functions. Among the \(N(n)+1\) formulas \(\rho_0^*,\ldots,\rho_{N(n)}^*\), two, say \(i<j\), therefore have identical truth functions. By locality they are equivalent under every valuation. It follows that \(\Gamma_A\models\rho_i\leftrightarrow\rho_j\).

But \(\rho_i\) is among the premises preceding \(\rho_j\), so this equivalence would force \(\rho_j\) from its predecessors, contradicting . This proves the claim. At \(n=0\) there are just two constant truth functions, and the same count uses three formulas.

The omitted numbers are hit by a computable strong array

Under the assumption \(K\le_{\mathrm{tt}}A\), with \(A\) c.e., define \(a_0=0\) and \(a_{k+1}=m(a_k)\). Then the finite sets \(F_k=[a_k,a_{k+1})\) form a strong array hitting \(\overline A\).

The endpoint recursion is total computable, and \(m(n)>n\) makes the endpoints strictly increase. Enumerating each integer between successive endpoints gives a total computable finite-list description of \(F_k\). The half-open intervals are nonempty and pairwise disjoint. Each meets \(\overline A\) by . Thus the array has all the required properties with the specified endpoints and lists.

A hypersimple set is truth-table incomplete

Every hypersimple c.e. set \(A\) satisfies \(A<_{\mathrm{tt}}K\). In particular, \(K\not\le_{\mathrm{tt}}A\).

If \(K\le_{\mathrm{tt}}A\), supplies a computable strong array hitting \(\overline A\). This contradicts its hyperimmunity. Thus the reverse reduction fails. Since \(A\) is c.e., \(A\le_m K\), which gives \(A\le_{\mathrm{tt}}K\). These are exactly the two assertions in the strict comparison.

Use the earlier Post set to reserve a missing point in every block

Now let \(B\) be the particular Post simple set already constructed. Write \(c\) for the increasing enumeration of \(\overline B\), indexed from zero. Its principal-function bound is \(c(n)\le2n\), while increasingness gives \(n\le c(n)\). Define the coding endpoints and blocks by

\[n_0=0,\qquad n_{k+1}=2n_k+1,\qquad I_k=[n_k,n_{k+1}).\]

The endpoints are primitive recursive, strictly increasing and satisfy \(n_k\ge k\). Thus the blocks partition \(\mathbb N\). Their block selector \(b(x)\) is the unique \(k\) with \(x\in I_k\): search \(k\le x\) for the first \(x<n_{k+1}\). The bound works because \(n_{x+1}\ge x+1\), and minimality places \(x\) at or above \(n_k\). This gives a total computable selector.

Each coding block has a specified omission from the Post set

For every \(k\), the point \(c(n_k)\) lies in \(I_k\setminus B\).

It lies outside \(B\) by the definition of the principal function, and

\[n_k\le c(n_k)\le2n_k<2n_k+1=n_{k+1}.\]

Thus it is a member of the stated half-open block. This identifies a mathematical witness; the construction does not claim that the principal function or these omitted points can be computed.

Fill the block when its index enters halting

Define the specified set

\[C=B\cup\bigcup_{k\in K}I_k.\]

Then \(C\) is c.e. More precisely, from the earlier recognizer for \(B\) and the fixed universal program one obtains an ordinary recognizer whose domain is exactly this \(C\).

On input \(x\), compute the block selector \(b(x)\). Dovetail the earlier \(B\)-recognizer on \(x\) with the computation \(\varphi_{b(x)}(b(x))\), and halt with output zero as soon as either computation halts. The selector is a total ordinary computation, and parallel simulation gives a partial recursive recognizer.

Uniqueness of the block containing \(x\) gives \(x\in C\) exactly when \(x\in B\) or \(b(x)\in K\). These are precisely the two successful branches of this program. Its fixed code therefore enumerates the actual displayed set, without requiring a procedure for recognizing permanently unfilled blocks.

A finite conjunction of block bits recovers halting

For every \(k\),

\[k\in K\quad\Longleftrightarrow\quad I_k\subseteq C\quad\Longleftrightarrow\quad\bigwedge_{n_k\le x<n_{k+1}}\chi_C(x)=1.\]

This is a truth-table reduction \(K\le_{\mathrm{tt}}C\), with computable prefix bound \(u(k)=n_{k+1}\).

If \(k\in K\), its entire block is added to \(C\). If \(k\notin K\), disjointness of the blocks makes \(C\cap I_k=B\cap I_k\). The point \(c(n_k)\) from remains omitted, so the conjunction is false.

To produce the actual finite table on input \(k\), compute \(n_k,n_{k+1}\), list all binary words of length \(u(k)\), and label a word one exactly when all its positions in \(I_k\) are one. Label it zero otherwise; give malformed or wrong-length word codes the default output zero. The finite-row algorithm and lookup are total computable by the prefix-table construction. This scheme terminates on every row for every oracle, and the preceding equivalence proves its answer under \(C\).

Infinitely many unfilled blocks retain an immune complement

The complement \(\overline C\) is infinite and immune. Hence \(C\) is simple.

The set \(\overline K\) is infinite. For every \(k\in\overline K\), the point \(c(n_k)\) remains outside \(C\), by . Distinct such indices give distinct points because they lie in pairwise disjoint blocks. This gives infinitely many omissions.

Since \(B\subseteq C\), one has \(\overline C\subseteq\overline B\). Every c.e. subset of \(\overline C\) is therefore a c.e. subset of the immune set \(\overline B\), so is finite. Together with the just-proved infinitude, this makes \(\overline C\) immune. The set \(C\) is c.e. by its actual recognizer, proving simplicity. Infinitude must be proved separately: an arbitrary c.e. superset of a simple set could have finite or empty complement.

A simple set can have the full truth-table degree of halting

The specified set \(C=B\cup\bigcup_{k\in K}I_k\) is simple and satisfies \(C\equiv_{\mathrm{tt}}K\). It is not many-one complete and is not hypersimple.

Simplicity is , and the explicit block table gives \(K\le_{\mathrm{tt}}C\). Since \(C\) is c.e., diagonal-halting completeness gives \(C\le_m K\), hence \(C\le_{\mathrm{tt}}K\). Every simple set is many-one incomplete. If this \(C\) were hypersimple, would contradict its truth-table completeness.

Does the simple complete set solve Post's Turing-degree problem?

What do the proved comparisons say about \(C\)'s Turing degree and about the difference between truth-table and weak truth-table reducibility?

The set \(C\) has the same Turing degree as \(K\): both truth-table reductions are Turing reductions. Thus it is Turing complete and does not give a degree strictly between the computable degree and halting. Its many-one incompleteness illustrates how that more restrictive reduction can fail even when a fixed finite table of oracle answers suffices.

The results compare hypersimplicity and simplicity with truth-table completeness. They do not supply a pair separating truth-table from weak truth-table reducibility. In particular, the constructed \(C\) is complete for both, since its halting reduction is already a truth table. The separate finite-injury solution of Post's problem establishes intermediate Turing degrees.
