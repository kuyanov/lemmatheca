Verify the axioms in the constructible class

The constructible hierarchy gives a definable transitive proper class \(L\) containing every ordinal. We now work in ambient ZF and prove that its actual-membership structure satisfies ZF and Choice.

An inner model of ZF is a transitive proper class containing every ordinal and satisfying each ZF axiom, including each fixed instance of Separation and Replacement. For a definable class, satisfaction is the formula-by-formula relativization convention. Thus \(L\models\varphi[\bar a]\) abbreviates the particular formula \(\varphi^L(\bar a)\). An axiom-schema assertion here means a corresponding proof for each fixed formula, not a global truth predicate for a proper class.

The construction will first verify ZF. Only then will it use the hierarchy's absoluteness to prove that \(L\) internally satisfies “every set is constructible,” written \(V=L\). An explicit recursion of well-orders will derive Choice inside that model.

Reflect fixed formulas before assuming any axioms in the union

For every fixed finite family of formulas, arbitrarily large levels \(L_\alpha\) agree with \(L\) on those formulas at every parameter tuple from \(L_\alpha\).

The levels are definable transitive sets, increasing at successors and continuous at nonzero limits. Their union is nonempty. These are exactly the hypotheses of general hierarchy reflection. Apply that theorem to this hierarchy. Its witness-bound construction uses ambient ZF and does not require the union class to model ZF.

In particular, finitely many already chosen parameters can be included by starting above levels containing them. Agreement then holds for every additional parameter tuple present in the reflecting level.

Transitivity and definability supply the elementary witnesses

The class \(L\) satisfies Extensionality, Foundation, Empty Set, Pairing, Union and Infinity.

Transitivity ensures that every actual member of an object in \(L\) remains in \(L\). Equal internal member collections are therefore equal actual member collections, so ambient Extensionality identifies the objects. For an internally nonempty set \(x\in L\), ambient Foundation gives \(y\in x\) with no member in common with \(x\). Transitivity puts \(y\) in \(L\), where the same exclusion still holds. This proves internal Foundation.

The empty set belongs to \(L_1\). Given \(x,y\in L\), choose a level \(L_\alpha\) containing both. The formula \(z=x\lor z=y\), with those two parameters, defines their actual pair as a subset of \(L_\alpha\). Thus \(\{x,y\}\in L_{\alpha+1}\).

If \(x\in L_\alpha\), every member of every member of \(x\) lies in \(L_\alpha\). The bounded formula \(\exists u\in x\,(z\in u)\) consequently defines the actual union of \(x\) over that level: every possible witness \(u\in x\) is present. Its defining subset lies in \(L_{\alpha+1}\). Finally \(\omega\) belongs to \(L\), since every ordinal does. Its zero and all finite successors have their actual meanings in this transitive class, so it witnesses Infinity.

Reflection converts class Separation into definability over one level

The class \(L\) satisfies every instance of Separation.

Fix a formula \(\varphi(z,\bar p)\), parameters \(\bar p\in L\), and \(x\in L\). The desired subset in the ambient universe is

\[A=\{z\in x:L\models\varphi(z,\bar p)\}.\]

This is a set by ambient Separation applied to the fixed relativized formula. Choose a reflecting \(L_\alpha\) containing \(x\) and all parameters and agreeing with \(L\) on \(\varphi\). Every member of \(x\) lies in the level by transitivity. At each such member, reflection identifies class truth with truth over that level.

Consequently \(A\) is exactly the subset of \(L_\alpha\) defined there by \(z\in x\land\varphi(z,\bar p)\). This uses only parameters in \(L_\alpha\), so \(A\in\operatorname{Def}(L_\alpha)=L_{\alpha+1}\). Its defining membership condition is the requested internal Separation instance. The same construction works for each fixed formula.

A set of constructible objects has one stage bound

If \(A\) is an ambient set and \(A\subseteq L\), then \(A\subseteq L_\delta\) for some ordinal \(\delta\).

For each \(a\in A\), choose no arbitrary witness: take the least ordinal \(\beta_a\) with \(a\in L_{\beta_a}\). Such a stage exists by membership in \(L\), and a least one exists among ordinals below any witnessing stage. This is a uniquely defined function on the set \(A\). Ambient Replacement collects its ordinal values.

Let \(\delta=\sup\{\beta_a:a\in A\}+1\). Then \(\beta_a<\delta\) for each \(a\), and increasing levels give \(a\in L_\delta\). The same rule gives \(\delta=1\) when \(A\) is empty, where the assertion is vacuous. No Choice or size restriction on \(A\) is needed.

Collect outputs externally, then define their exact range at a reflecting level

The class \(L\) satisfies every instance of Replacement.

Fix \(\varphi(a,b,\bar p)\), its parameters in \(L\), and \(x\in L\). Suppose \(L\) satisfies that each \(a\in x\) has exactly one output \(b\) satisfying this formula. Ambient Replacement applied to the fixed condition \(b\in L\land\varphi^L(a,b,\bar p)\) collects the actual outputs into a set \(Y\subseteq L\). This use of Replacement is legitimate before knowing any Replacement axiom inside \(L\).

Apply to bound all of \(Y\) in one level. Choose a larger reflecting level \(L_\alpha\) that also contains \(x\) and \(\bar p\), and agrees with \(L\) on \(\varphi\). For every \(b\in L_\alpha\),

\[b\in Y\quad\Longleftrightarrow\quad L_\alpha\models\exists a\in x\,\varphi(a,b,\bar p).\]

Indeed all members of \(x\) are present, and reflection transfers the matrix for every such \(a\) and every candidate \(b\) in the level. The externally collected set consists of exactly these outputs, and none of them lies above the level by its chosen bound.

This equivalence defines \(Y\) as a subset of \(L_\alpha\) using the available parameters. Hence \(Y\in L_{\alpha+1}\subseteq L\). Its actual output condition, which holds against every \(b\in L\), gives the required internal Replacement instance. The formula and parameters were arbitrary within the fixed-instance convention.

Collect exactly the constructible subsets of the given object

For every \(x\in L\), its internal power set in \(L\) is

\[\mathcal P^L(x)=\{z\in\mathcal P(x):z\in L\},\]

and this set belongs to \(L\).

Ambient Power Set and Separation first form the displayed set \(A\). It is an ambient set of constructible objects, so gives a bound on all its members. Choose \(\beta\) large enough that \(A\subseteq L_\beta\) and \(x\in L_\beta\).

For a candidate \(z\in L_\beta\), its bounded subset test agrees with actual \(z\subseteq x\), by bounded absoluteness. Since all candidates are constructible and every member of \(A\) is present, \(A\) is exactly the subset defined over \(L_\beta\) by that test. Thus \(A\in\operatorname{Def}(L_\beta)=L_{\beta+1}\).

The class \(L\) is transitive too, so its internal subset test also agrees with actual inclusion at its candidates. The members of \(A\) are therefore exactly the objects that its Power Set axiom requests. This proves that axiom without asserting that \(L\) contains every ambient subset of \(x\).

The constructible class satisfies all ZF axioms

In ambient ZF, the constructible class \(L\) is an inner model of ZF: it is transitive, contains every ordinal, and satisfies every axiom, including each instance of Separation and Replacement.

Transitivity and the presence of every ordinal were proved from the hierarchy construction. The elementary axiom checks give Extensionality, Foundation, Empty Set, Pairing, Union and Infinity. The preceding three constructions give every Separation and Replacement instance and the internal Power Set. These exhaust ZF. Every argument uses a particular finite formula or particular axiom; none invokes truth for all formulas of a proper class at once.

Constructing inside L gives L again

The hierarchy computed inside \(L\) agrees with the ambient hierarchy at every ordinal. Consequently \(L^L=L\), and \(L\) satisfies \(V=L\).

We now know that \(L\) is a transitive ZF model. It contains every ordinal, so absoluteness of the hierarchy recursion applies at each ordinal \(\alpha\): its internal level \(L_\alpha^L\) is the actual \(L_\alpha\). Both constructions use all the same ordinal indices, hence their union classes agree.

Given \(x\in L\), some ambient level contains it. That same level is internally constructible in \(L\), so the assertion that \(x\) is constructible is true inside \(L\). This holds for every object in its domain, which is precisely its assertion \(V=L\).

Every inner ZF model contains the constructible class

If \(N\) is an inner model of ZF, then \(L\subseteq N\).

Every ordinal \(\alpha\) belongs to \(N\). Its ZF recursion therefore constructs its internal level \(L_\alpha^N\) as an object of \(N\), and hierarchy absoluteness identifies that level with the actual \(L_\alpha\). By transitivity of \(N\), all members of this level also belong to \(N\). Every member of \(L\) belongs to such a level, proving the inclusion.

Thus “smallest” refers to inclusion among transitive ZF inner models containing every ordinal. It makes no assertion here about arbitrary non-well-founded first-order models of ZF.

A well-ordered level gives a well-order of its definition codes

Let \(M\) have a specified well-order \(r\). There is a specified well-order of the formula-and-parameter codes defining subsets of \(M\).

Fix once and for all an enumeration of membership formulas together with their finite parameter arities by natural-number codes. Order codes first by that natural number. For a fixed formula code of arity \(k\), order its parameter tuples in \(M^k\) lexicographically using \(r\), with the first coordinate compared first.

A finite lexicographic product of a well-order is a well-order: for a nonempty set of tuples, minimize the first coordinate attained, then the second among tuples retaining that coordinate, and continue through the fixed finite length. At length zero there is one empty tuple. For a nonempty set of complete codes, first minimize the attained formula number, then minimize the tuple within that one fixed arity. This gives its least code. All these are set constructions from \(M\) and \(r\).

Each definable subset has at least one such code, so it has a unique least one. Distinct subsets have distinct least codes, because a fixed code defines exactly one subset. Transporting the code order therefore well-orders the definable subsets and any chosen subcollection of them.

Extend the old well-order before adding newly definable objects

ZF constructs a definable family \((r_\alpha)\) such that each \(r_\alpha\) well-orders \(L_\alpha\), and earlier levels are initial segments with their orders unchanged.

At zero use the empty order. Suppose \(r_\alpha\) has been defined. For each new object in \(L_{\alpha+1}\setminus L_\alpha\), take its least definition code over the already well-ordered \(L_\alpha\), as in . Put all old objects first in their old order, then put the new objects in the order of their least codes. The concatenation is a well-order and extends the old order as an initial segment. The new ordering never requires a well-order of the new objects as an input.

At a nonzero limit \(\lambda\), take \(r_\lambda=\bigcup_{\alpha<\lambda}r_\alpha\). Coherence makes this a linear order on the union level. If \(A\subseteq L_\lambda\) is nonempty, some earlier level meets it. The least point of that intersection in the earlier well-order precedes every point outside that level, since it is an initial segment. It is therefore least in all of \(A\). This proves the well-order property at limits.

The rule uniquely determines a set relation from the earlier history. Least-code selection is definable, uses the fixed set satisfaction construction, and chooses no arbitrary family of objects. Set-valued recursion and Replacement therefore construct this definable family in ZF.

An object's first definability parent stage is the least \(\delta\) for which it belongs to \(\operatorname{Def}(L_\delta)\). A new object at \(\delta+1\) is coded using parameters from \(L_\delta\). Using its first membership stage and allowing parameters from that very new stage would destroy the recursive order of this construction.

The well-orders exist inside a ZF universe satisfying V equals L

ZF together with \(V=L\) proves Choice.

Perform the preceding definable recursion inside a universe satisfying those axioms. For any set \(x\), the assumption \(V=L\) gives a level containing \(x\); transitivity then gives \(x\subseteq L_\alpha\) for that index \(\alpha\). Its recursion produces the relation \(r_\alpha\) as an actual set of that universe.

Separation restricts this relation to \(x\times x\). The restriction is a well-order of \(x\), so every set in this universe has a well-order. The ZF equivalence of well-ordering and Choice gives Choice there. In particular, this argument produces a set relation available internally; it is not merely an external ordering of the universe's objects.

The constructible inner model satisfies Choice

In ambient ZF, the constructible class \(L\) is an inner model of ZFC and internally satisfies \(V=L\).

The earlier checks established ZF in \(L\), and idempotence established its internal assertion \(V=L\). Apply the ZF argument from within that model. Its own recursion and Separation produce the required well-orders of its sets, and hence Choice. Together with its ZF axioms this gives ZFC in the stated schematic class-model sense.

Why does the Power Set proof use construction stages?

Why not use the full ambient \(\mathcal P(x)\) directly, as in an inaccessible rank model?

Show answerHide answer

The rank-model proof placed every ambient subset below a rank bound. The constructible hierarchy instead iterates definable subsets, and we have not assumed that every ambient subset of \(x\) is constructible. Its internal Power Set axiom quantifies only over candidates that belong to \(L\).

Ambient Separation selects those constructible subsets from \(\mathcal P(x)\). Because this is a set, their least construction stages have an ordinal bound; this lets one later level define exactly that collection. If all ambient subsets happen to be constructible, the two power sets coincide, but that equality is not needed by the proof.

Which stage supplies the parameters for a new object?

Suppose \(x\) first belongs to \(L_{\delta+1}\). When constructing its least definition code, which level's parameters and well-order may be used?

Show answerHide answer

The parameters come from \(L_\delta\), and their tuples are ordered using the already constructed \(r_\delta\). Indeed \(x\in L_{\delta+1}=\operatorname{Def}(L_\delta)\), while no earlier definability parent can contain a code for \(x\), or \(x\) would have appeared earlier.

The new level may itself contain \(x\), so using arbitrary parameters from \(L_{\delta+1}\) would make the intended coding depend on the new objects whose order is still being constructed. Placing the old level first and using its order to compare codes avoids that circularity.
