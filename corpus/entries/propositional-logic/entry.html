Formulas record how statements are combined

Suppose that if it rains, the path is wet, and that it rains. The path must then be wet. The same argument works with any two statements in place of “it rains” and “the path is wet.” Propositional logic studies this dependence on the way statements are combined.

Fix a set \(P\) of atoms, or propositional letters, such as \(p,q,r\). A formula is a finite construction made by these rules:

  • Each atom \(p\in P\) is a formula, and the falsity symbol \(\bot\) is a formula.
  • If \(A\) is a formula, then \(\neg A\) is a formula.
  • If \(A,B\) are formulas, then \((A\land B)\), \((A\lor B)\), and \((A\to B)\) are formulas.
  • There are no other formulas.

The construction is part of the formula: its outermost operation and its immediate constituent formulas are specified. Parentheses display that structure. We may omit an outermost pair, but retain parentheses that distinguish, for example, \((p\to q)\to r\) from \(p\to(q\to r)\). The expressions \(\top:=\neg\bot\) and \(A\leftrightarrow B:=(A\to B)\land(B\to A)\) are abbreviations.

A formula is an object we study; a statement about all formulas is part of the ordinary mathematics used to study it. We use classical reasoning in that surrounding mathematics. The familiar language of sets and functions will describe assignments to atoms.

Structural induction follows the construction

To prove a property of every formula, it suffices to prove it for every atom and for \(\bot\), prove it for \(\neg A\) whenever it holds for \(A\), and prove it for each of \(A\land B,A\lor B,A\to B\) whenever it holds for both \(A\) and \(B\). This is structural induction.

Proof

Give atoms and \(\bot\) height zero. Give \(\neg A\) height \(1+h(A)\), and give a binary construction from \(A,B\) height \(1+\max(h(A),h(B))\). Each immediate constituent has smaller height. Strong induction on height now proves the property: the height-zero cases are the base formulas, and the construction rule proves every remaining case from its constituents. Strong induction follows from ordinary induction applied to the assertion that the property holds at every height below a given bound. □

The same structure supports recursive definitions: assign values to the base formulas and specify how to combine the already assigned values of the immediate constituents.

A valuation gives truth values to atoms

A valuation is a function \(v:P\to\{0,1\}\), where \(1\) means true and \(0\) means false. Its evaluation of a formula, written \(\llbracket A\rrbracket_v\), is defined recursively. An atom has value \(v(p)\), and \(\bot\) has value \(0\). Negation exchanges \(0\) and \(1\). The three binary operations use the following table.

For a compound formula, \(a,b\) are the values of its constituents. Thus “or” is inclusive, and \(A\to B\) is false precisely when \(A\) is true and \(B\) is false. This operation is material implication; it does not express a causal connection.

The clauses give an evaluation for each finite construction. They give only one: structural induction shows that any two evaluations obeying the clauses agree on the bases and then on each compound formula. In particular \(\top\) has value \(1\) under every valuation.

Truth, satisfiability, and consequence

A formula \(A\) is a tautology if \(\llbracket A\rrbracket_v=1\) for every valuation, and a contradiction if its value is always \(0\). Formulas \(A,B\) are semantically equivalent if their values agree under every valuation. This compares truth values rather than the constructions themselves.

Throughout this entry, \(\Gamma\) is a finite set of formulas. It is satisfiable if some valuation makes every member true. We write \(v\models A\) when \(\llbracket A\rrbracket_v=1\), and \(v\models\Gamma\) when \(v\models B\) for every \(B\in\Gamma\). The semantic consequence relation is

\[ \Gamma\models A\quad\Longleftrightarrow\quad \text{every valuation }v\text{ with }v\models\Gamma\text{ also satisfies }v\models A. \]

A valuation making all premises true and the conclusion false is a countervaluation. Its existence means \(\Gamma\not\models A\). Consequence from the empty set means that \(A\) is a tautology. If \(\Gamma\) is unsatisfiable, it entails every formula, because there is no valuation satisfying its premises.

The symbol \(\models\) describes a relation between formulas; \(\to\) constructs a formula. The truth table gives \(\{A\}\models B\) exactly when \(A\to B\) is a tautology: both conditions exclude a valuation making \(A\) true and \(B\) false.

Only the occurring atoms matter

Let \(\operatorname{At}(A)\) be the set of atoms occurring in \(A\). Recursively, \(\operatorname{At}(p)=\{p\}\), \(\operatorname{At}(\bot)=\varnothing\), negation preserves the atom set, and a binary construction takes the union of the two constituent atom sets. These sets are finite, by structural induction.

If valuations \(v,w\) agree on \(\operatorname{At}(A)\), then

\[ \llbracket A\rrbracket_v=\llbracket A\rrbracket_w. \]

Proof

At an atom this is the agreement hypothesis; at \(\bot\) both values are zero. For a negation, the induction hypothesis gives equal constituent values, so their negations agree. For a binary construction, agreement on the union gives agreement on both constituent atom sets. Their values agree by induction, and applying the same binary truth operation gives equal results. □

For a finite set of premises, put \(\operatorname{At}(\Gamma):=\bigcup_{B\in\Gamma}\operatorname{At}(B)\). This is finite as well. Atoms absent from all premises and the conclusion cannot affect whether a valuation is a countervaluation.

Substitution replaces atoms by formulas

Let \(Q\) be another atom set. A substitution assigns a formula over \(Q\) to each atom of \(P\), giving a function \(\sigma:P\to\operatorname{Form}(Q)\). Here \(\operatorname{Form}(Q)\) denotes the formulas over \(Q\). Extend it recursively by

\[ \begin{aligned} \sigma(\bot)&=\bot,&\qquad \sigma(\neg A)&=\neg\sigma(A),\\ \sigma(A\mathbin{*}B)&=\sigma(A)\mathbin{*}\sigma(B) &&(*\in\{\land,\lor,\to\}). \end{aligned} \]

This is simultaneous replacement. The inserted formulas are not substituted into again during the same operation. For distinct atoms \(p,q\), exchanging them sends \(p\to q\) to \(q\to p\). Replacing \(p\) by \(q\) first and then replacing every \(q\) by \(p\) would instead give \(p\to p\). For premises, write \(\sigma[\Gamma]:=\{\sigma(B):B\in\Gamma\}\).

Substitution preserves valid reasoning

For every substitution \(\sigma:P\to\operatorname{Form}(Q)\), valuation \(v:Q\to\{0,1\}\), and formula \(A\) over \(P\), define \(u(p):=\llbracket\sigma(p)\rrbracket_v\). Then

\[ \llbracket\sigma(A)\rrbracket_v=\llbracket A\rrbracket_u. \]

Consequently a substitution instance of a tautology is a tautology, and for finite \(\Gamma\), \(\Gamma\models A\) implies \(\sigma[\Gamma]\models\sigma(A)\).

Proof

Use structural induction for the displayed identity. At an atom it is the definition of \(u\); at \(\bot\) both sides are zero. A negation applies the same operation to the equal values given by induction. For each of the three binary constructors, substitution keeps its outer operation, and induction gives equal values for both constituents, so the results agree.

If \(A\) is a tautology, its value under this induced \(u\) is \(1\). For consequence, take any \(v\models\sigma[\Gamma]\). The identity gives \(u\models\Gamma\), hence \(u\models A\), and then \(v\models\sigma(A)\). □

A truth table lists the finite possibilities

Choose a finite list of distinct atoms containing every atom in the formulas being tested. A row assigns either \(0\) or \(1\) to each listed atom. Extend it to a valuation by giving every unlisted atom value \(0\), and evaluate the formulas recursively.

There are \(2^n\) rows for \(n\) listed atoms. The empty list has one assignment, and appending one new atom gives two extensions of each old row. Induction therefore doubles the count at each step. Repeated occurrences of an atom do not add rows.

For distinct atoms \(p,q\), the following table includes every assignment to them.

The rain argument
\(p\)\(q\)\(p\to q\)\((p\land(p\to q))\to q\)
1111
1001
0111
0011

The last column is always \(1\), and every row satisfying both \(p\) and \(p\to q\) satisfies \(q\). Thus \(\{p,p\to q\}\models q\), which is the rain argument. The third row also shows that \(\{p\to q,q\}\not\models p\): a wet path need not establish rain.

For constructing a formula from a prescribed table, see disjunctive and conjunctive normal forms.

Finite truth tables decide finite consequence

Let \(\Gamma\) be a finite set of formulas, let \(A\) be a formula, and list all atoms in \(S:=\operatorname{At}(\Gamma)\cup\operatorname{At}(A)\) once. Then \(\Gamma\models A\) exactly when no row of the resulting truth table makes every member of \(\Gamma\) true and \(A\) false. A row violating this condition supplies a countervaluation by extending it with value \(0\) outside \(S\).

Proof

Every extended row is a valuation, so a violating row refutes consequence. Conversely, restrict an arbitrary valuation to \(S\) and take its row. By , the extended row agrees with the original valuation on every premise and on \(A\). If all rows pass the test, every valuation satisfying the premises satisfies \(A\). □

With atom names that can be compared for equality, this gives a terminating procedure: collect and remove duplicate atoms, list the finitely many rows, evaluate each finite formula, and check the condition. The same rows test satisfiability by looking for a row where all premises are true, tautology by checking every row, and equivalence by comparing two formula columns.

Empty premises impose no conditions. If \(S=\varnothing\), the table has one row rather than no rows: it correctly gives \(\top\) value \(1\) and \(\bot\) value \(0\).

A failed consequence need not entail the negation

For distinct atoms \(p,q\), let \(\Gamma=\{p\to q,q\}\). Does \(\Gamma\models p\)? If that fails, must \(\Gamma\models\neg p\)?

Neither consequence holds. A valuation with \(v(p)=0,v(q)=1\) satisfies both premises and refutes \(p\). A valuation with \(v(p)=1,v(q)=1\) satisfies both premises and refutes \(\neg p\). Give any remaining atoms value \(0\).

To refute a consequence we need one countervaluation. This leaves room for another valuation satisfying the premises and the proposed conclusion.
