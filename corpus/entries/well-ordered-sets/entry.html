Every nonempty subset has a first element

A well-order on a set \(A\) is a total order \(\le\) such that every nonempty subset \(S\subseteq A\) has a least element. Its strict order is \(x<y\) when \(x\le y\) and \(x\ne y\). We call \((A,\le)\) a well-ordered set.

“Every subset” includes infinite subsets and \(A\) itself. Having a least element in \(A\) alone is insufficient. A least element of a nonempty subset is unique: two such elements would each be at most the other, so antisymmetry makes them equal. In a total order, a minimal element is least, because it is comparable with every other element.

The empty set with its empty order is well-ordered: it has no nonempty subsets. Every singleton is well-ordered. The natural numbers with their usual order are well-ordered by the least-member principle used in finite counting. We continue to take \(\mathbb N=\{0,1,2,\ldots\}\).

Subsets inherit a well-order

Every subset of a well-ordered set is well-ordered by the restricted order. Every finite totally ordered set is well-ordered.

Proof

If \(B\subseteq A\), the restricted relation is still a total order. A nonempty subset of \(B\) is a nonempty subset of \(A\), and its least element remains least in the restricted order. For a finite total order, every nonempty subset is finite and has a minimal element by the finite-extrema lemma. Totality makes that element least. □

Totality matters in the finite assertion. Two distinct incomparable elements, with only reflexive comparisons, form a finite partial order whose full set has no least element.

Which familiar orders are well-orders?

Consider \(\mathbb Z\), \(\mathbb Q\), \(\mathbb R\), and \([0,1]\) in their usual orders. Does the answer mean that \(\mathbb Z\) cannot be well-ordered by a different relation?

Show answerHide answer

The usual order on \(\mathbb Z\) is not a well-order: the whole set has no least integer, since \(z-1<z\). The usual orders on \(\mathbb Q\) and \(\mathbb R\) also fail. The subset \((0,1)\cap\mathbb Q\), or \((0,1)\) respectively, has no least element, since \(0<x/2<x\) for any of its elements. The same subset disproves well-ordering of \([0,1]\), even though that interval itself has the least element zero.

A different order on \(\mathbb Z\) does work. Use the bijection \(z:\mathbb N\to\mathbb Z\) from the integer enumeration and declare \(z(i)\prec z(j)\) exactly when \(i<j\). A nonempty set of integers has a nonempty set of indices, hence a least index. This order begins \(0\prec-1\prec1\prec-2\prec2\prec\cdots\). Well-ordering is a property of the chosen relation as well as the underlying set.

A last point and successive infinite blocks

Let \(L=\mathbb N\sqcup\{\ell\}\), where \(\ell\) is a new element distinct from every natural number. Keep the usual order among naturals and put \(n<\ell\) for every \(n\in\mathbb N\). This is a well-order: a nonempty subset containing a natural number has a least natural member, and the only nonempty subset with no natural members is \(\{\ell\}\).

Another well-order is the lexicographic order on \(\mathbb N\times\mathbb N\):

\[ (i,j)<_{\mathrm{lex}}(k,m) \quad\Longleftrightarrow\quad i<k\ \text{or}\ (i=k\ \text{and}\ j<m). \]

It consists of the entire block \((0,0),(0,1),(0,2),\ldots\), then the block \((1,0),(1,1),\ldots\), and so on. Lexicographic comparison is a total order. To find the least member of a nonempty subset, first take the least first coordinate that occurs, and then take the least second coordinate among members with that first coordinate.

Both examples are countably infinite as sets: enumerate \(L\) by putting \(\ell\) first and then the naturals, and use countability of finite products for \(\mathbb N\times\mathbb N\), which is infinite since \(n\mapsto(n,0)\) is injective. Neither has the same order structure as the usual natural numbers. In \(L\), the point \(\ell\) is greatest. In the lexicographic example, \((1,0)\) has infinitely many predecessors. Every natural number has only finitely many predecessors in its usual order. A bijection between sets need not preserve these order properties.

Initial segments contain everything earlier

A subset \(I\subseteq A\) is an initial segment if it is downward closed: whenever \(x\in I\) and \(y<x\), we have \(y\in I\). We allow \(I=\varnothing\) and \(I=A\). For \(a\in A\), write

\[ A_{<a}=\{x\in A:x<a\}. \]

This is a proper initial segment, because it does not contain \(a\). We use the order inherited from \(A\) on each segment. The closed segment \(\{x\in A:x\le a\}\) is also downward closed.

For \(\mathbb N\), the segment \(\mathbb N_{<n}\) is \(\{0,\ldots,n-1\}\). In \(L\), the segment \(L_{<\ell}\) is all of \(\mathbb N\). In the lexicographic example, the segment below \((1,0)\) is \(\{0\}\times\mathbb N\). An inherited well-order need not be an initial segment: the even natural numbers contain two but omit the earlier number one.

Every proper initial segment ends at a cut

If \(I\subsetneq A\) is an initial segment of a well-ordered set, there is a unique \(a\in A\) such that \(I=A_{<a}\). It is the least member of \(A\setminus I\). The initial segments of \(A\) are linearly ordered by inclusion.

Proof

The nonempty complement has a least member \(a\). Every \(x<a\) belongs to \(I\), or \(a\) would not be least in the complement. Conversely, if \(x\in I\), then \(x\ne a\); the possibility \(a<x\) would force \(a\in I\) by downward closure. Thus \(x<a\), giving \(I=A_{<a}\). The least missing member determines \(a\) uniquely.

If \(a<b\), then \(A_{<a}\subsetneq A_{<b}\): transitivity gives the inclusion, and \(a\) belongs only to the latter segment. Totality compares any two endpoints; \(A\) itself contains every initial segment. □

In a nonempty well-order, the empty segment is the segment below its least element. For the empty well-order there are no proper initial segments.

Some points have no immediate predecessor

If \(a\) is not greatest, its successor is the least member of \(\{x\in A:a<x\}\), written \(s(a)\). Thus \(a<s(a)\) and no element lies strictly between them. A point \(b\) is a successor point if \(b=s(a)\) for some \(a\); that \(a\) is its immediate predecessor.

For a nonempty well-order, every point is exactly one of: its least point, a successor point, or a limit point, meaning a nonleast point with no immediate predecessor. Here “limit” describes the order; no topological limit is being defined.

A greatest point has no successor, but it may itself be a successor point or a limit point. In a finite nonempty well-order, every point after the first has an immediate predecessor: its nonempty finite predecessor set has a greatest member.

In \(L\), each \(n+1\) succeeds \(n\), while \(\ell\) is a limit point and is also greatest. In the lexicographic order, \((i,j+1)\) succeeds \((i,j)\); each \((i,0)\) with \(i>0\) is a limit point.

If \(b\) is a limit point, then for every \(a<b\) there is some \(c\) with \(a<c<b\). Otherwise \(a\) would be greatest among the predecessors of \(b\), making \(b=s(a)\). This explains why no last predecessor is available at a limit point.

Induction from all earlier elements

Let \(P(a)\) be a property of elements of a well-ordered set \(A\). If

\[ \forall a\in A,\quad \bigl((\forall b<a,\ P(b))\Longrightarrow P(a)\bigr), \]

then \(P(a)\) holds for every \(a\in A\).

Proof

If the set \(E=\{a\in A:\neg P(a)\}\) were nonempty, take its least member \(e\). Every \(b<e\) lies outside \(E\), so \(P(b)\) holds for all such \(b\). The assumed implication then gives \(P(e)\), contradicting \(e\in E\). Thus \(E\) is empty. □

The premise is called the induction step. At the least point there are no earlier elements, so its antecedent is true and the step must establish the base case. For \(A=\mathbb N\), this is strong induction. For \(A=\varnothing\), the conclusion is vacuous.

The induction principle detects a well-order

A total order is a well-order if and only if the principle in holds for every property of its elements.

Proof

One direction is the theorem. Conversely, suppose a nonempty subset \(S\) has no least element. Let \(P(a)\) mean \(a\notin S\). If all elements below \(a\) satisfy \(P\), then \(a\) cannot belong to \(S\): in a total order, a member of \(S\) with no member of \(S\) below it would be least. Thus \(P\) satisfies the induction step. The principle would make \(P\) true everywhere, contradicting nonemptiness of \(S\). □

Base, successor, and limit cases

On a nonempty well-order, it suffices to prove \(P\) at the least point, prove \(P(s(a))\) whenever \(s(a)\) exists and \(P(a)\) holds, and prove \(P(b)\) at each limit point \(b\) assuming \(P(a)\) for every \(a<b\).

Proof

To check the step of at \(b\), assume \(P\) below \(b\). If \(b\) is least, use the base case. If \(b=s(a)\), the assumption includes \(P(a)\), so use the successor case. Otherwise \(b\) is a limit point, and its case applies. The induction theorem gives the result. □

The limit case is essential when the order has limit points. Its hypothesis concerns the entire earlier segment, which may be infinite.

Why are base and successor cases insufficient?

In \(L=\mathbb N\sqcup\{\ell\}\), let \(P(x)\) mean \(x\in\mathbb N\). Does it satisfy the base and successor requirements? Does it hold everywhere?

Show answerHide answer

The least point is zero, where \(P\) holds. The successor of each natural number \(n\) is \(n+1\), where it also holds. The point \(\ell\) has no successor, so there is no extra successor requirement starting there.

Nevertheless \(P(\ell)\) is false. All predecessors of \(\ell\) satisfy \(P\), precisely the hypothesis under which the limit case would require \(P(\ell)\). This property fails the full induction step at \(\ell\).

An order isomorphism between well-orders is unique

If \(f,g:A\to B\) are order isomorphisms between well-ordered sets, then \(f=g\).

Proof

By , fix \(a\in A\) and assume \(f(b)=g(b)\) for every \(b<a\). Suppose \(f(a)<g(a)\), using the order on \(B\). The point \(b=g^{-1}(f(a))\) lies below \(a\), because \(g\) reflects order. The hypothesis gives \(f(b)=g(b)=f(a)\). Injectivity of \(f\) then gives \(b=a\), contradicting \(b<a\). The possibility \(g(a)<f(a)\) is ruled out by exchanging \(f\) and \(g\). Totality on \(B\) leaves \(f(a)=g(a)\). Induction proves equality at every input. □

In particular, the only order automorphism of a well-order is the identity. Arbitrary bijections between the underlying sets can still be plentiful.

A well-order is not isomorphic to a proper initial segment

A well-ordered set \(A\) is not order-isomorphic to \(A_{<a}\) for any \(a\in A\).

Proof

First, every strictly increasing map \(f:A\to A\) satisfies \(x\le f(x)\). Otherwise take the least \(x\) with \(f(x)<x\). Minimality gives \(f(x)\le f(f(x))\), since \(f(x)\) is earlier than \(x\). But strict increase applied to \(f(x)<x\) gives \(f(f(x))<f(x)\), a contradiction.

Now an order isomorphism \(A\to A_{<a}\), followed by inclusion into \(A\), would be strictly increasing and satisfy \(f(a)<a\). This contradicts the preceding inequality. □

The natural numbers are in bijection with their proper subset of positive elements. That subset is not an initial segment of the usual natural-number order. The theorem concerns both the order structure and the position of the subset.

Well-founded reasoning allows incomparable elements

A relation \(R\) on a set \(A\) is well-founded if every nonempty subset \(S\subseteq A\) contains an \(R\)-minimal member: an \(a\in S\) for which there is no \(b\in S\) with \(b\,R\,a\). The direction \(b\,R\,a\) means that \(b\) is a permitted earlier dependency of \(a\).

The strict relation of a well-order is well-founded. Totality is not required for a general well-founded relation. For example, on \(\{p,q,r\}\) take just \(p\,R\,r\) and \(q\,R\,r\). Every nonempty subset has an \(R\)-minimal member, although \(p\) and \(q\) are incomparable. A subset containing only \(r\) has \(r\) as a minimal member.

We use a strict dependency relation: a self-dependency \(a\,R\,a\) would violate well-foundedness on \(\{a\}\). Well-foundedness also rules out an infinite descending sequence \(a_{n+1}\,R\,a_n\): the set of its values would have a minimal member \(a_k\), yet \(a_{k+1}\) would be an earlier member of that same set.

Induction along a well-founded relation

Let \(R\) be well-founded on \(A\). If for every \(a\in A\), the truth of \(P(b)\) for all \(b\,R\,a\) implies \(P(a)\), then \(P\) holds everywhere on \(A\).

Proof

A nonempty set of counterexamples would have an \(R\)-minimal member \(a\). Every \(b\,R\,a\) would satisfy \(P\), since no such \(b\) could belong to the counterexample set. The step would give \(P(a)\), a contradiction. □

A useful way to establish well-foundedness is a natural-number measure. If \(\mu:A\to\mathbb N\) satisfies \(\mu(b)<\mu(a)\) whenever \(b\,R\,a\), choose a member of any nonempty \(S\) having the least occurring measure. It has no \(R\)-predecessor in \(S\). For instance, proper divisibility of positive integers is well-founded, because a positive proper divisor is smaller than the integer it divides.

A recursion rule reads the earlier history

Induction proves properties; recursion defines values. Let \(A\) be well-ordered and let \(S\) be a fixed set of possible values. For every \(a\in A\), suppose a map

\[ \Phi_a:S^{A_{<a}}\longrightarrow S \]

has been given, where \(S^{A_{<a}}\) denotes all functions from the earlier segment \(A_{<a}\) to \(S\). The intended definition of \(F:A\to S\) is

\[ F(a)=\Phi_a\bigl(F|_{A_{<a}}\bigr). \label{eq:well-order-recursion} \]

The rule at \(a\) is specified for every possible earlier history, not only for histories we expect to obtain. At the least point, its input is the unique empty function. At a limit point, the history can have an infinite domain. The rules may depend on the position \(a\), and need not describe an algorithm.

A partial solution is a function \(h:I\to S\), with \(I\) an initial segment of \(A\), satisfying the same equation at every \(a\in I\). Downward closure ensures that the whole segment \(A_{<a}\) is in its domain, so the restriction needed by the equation exists.

Partial solutions agree wherever both are defined

Any two partial solutions for the same rules agree on the intersection of their domains. In particular, there is at most one full solution of \eqref{eq:well-order-recursion}.

Proof

Let \(h:I\to S\) and \(k:J\to S\) be partial solutions. If they disagree anywhere in \(I\cap J\), take the least disagreement \(a\). Every predecessor of \(a\) lies in both domains and has the same value under the two functions. Thus their restrictions to \(A_{<a}\) are equal. Applying the same map \(\Phi_a\) gives \(h(a)=k(a)\), a contradiction. □

This agreement is what permits compatible pieces of a recursive definition to be assembled, including across infinitely many earlier positions.

The recursion rules give a unique function

For the well-order \(A\), fixed value set \(S\), and maps \(\Phi_a\) in , there exists a unique function \(F:A\to S\) satisfying \eqref{eq:well-order-recursion} at every \(a\in A\).

Proof

Regard partial solutions as their graphs, subsets of \(A\times S\). The collection \(\mathcal H\) of all such solutions is therefore a set, contained in \(\mathcal P(A\times S)\); it contains the empty solution. Form the union of their graphs, \(F=\bigcup_{h\in\mathcal H}h\). By , two graphs never assign different values to the same input, so this union is a function into \(S\). Its domain \(D\), the union of their initial segments, is itself an initial segment.

For any \(a\in D\), some partial solution \(h\) contains \(a\) in its domain. It also contains every predecessor of \(a\). Compatibility makes the restriction of \(F\) to those predecessors equal to the restriction of \(h\). Hence \(F\) obeys the recursion rule at \(a\), and is a partial solution.

If \(D\ne A\), take the least missing point \(a\). Then \(D=A_{<a}\) by . Extend \(F\) to a function \(\widetilde F\) by assigning \(\widetilde F(a)=\Phi_a(F|_D)\) and keeping its values on \(D\). The extended domain \(D\cup\{a\}\) is an initial segment. No earlier equation changes, because the newly assigned point is later than every member of \(D\); the new equation holds by construction. This gives another member of \(\mathcal H\). Its graph must already be contained in the union defining \(F\), contradicting that \(a\) was missing. Thus \(D=A\), proving existence. Uniqueness follows from . □

Ordinary recursive sequences are a special case

Given a set \(S\), an element \(c\in S\), and a map \(T:\mathbb N\times S\to S\), there is a unique \(F:\mathbb N\to S\) with

\[ F(0)=c,\qquad F(n+1)=T(n,F(n)). \]

Proof

Set \(\Phi_0(u)=c\). At \(n+1\), let \(\Phi_{n+1}(u)=T(n,u(n))\); the coordinate \(n\) is in the earlier segment, so this value is available. The full recursion theorem supplies a unique function. Its equations are exactly the two displayed rules. □

For example, choose \(S=\mathbb N\), \(c=1\), and \(T(n,x)=(n+1)x\). The resulting function is factorial: \(F(0)=1\), \(F(1)=1\), \(F(2)=2\), \(F(3)=6\), and \(F(4)=24\). A rule can also read several earlier coordinates, as in the Fibonacci rules \(F(0)=0\), \(F(1)=1\), and \(F(n+2)=F(n+1)+F(n)\).

What value belongs at a limit point?

On \(L=\mathbb N\sqcup\{\ell\}\), take the value set \(S=\mathcal P(\mathbb N)\) and the rules

\[ F(0)=\varnothing,\qquad F(n+1)=F(n)\cup\{n\},\qquad F(\ell)=\bigcup_{n\in\mathbb N}F(n). \]

Find \(F(n)\) and \(F(\ell)\). Would the first two rules alone determine the value at \(\ell\)?

Show answerHide answer

Induction on natural numbers gives \(F(n)=\{0,\ldots,n-1\}\). Their union is \(\mathbb N\): each \(k\) belongs to \(F(k+1)\), and every term is a subset of \(\mathbb N\). Thus \(F(\ell)=\mathbb N\).

These are valid recursion rules on all histories. At zero the rule returns the empty set; at \(n+1\) it returns \(u(n)\cup\{n\}\); at \(\ell\) it returns the union of the values of \(u:\mathbb N\to\mathcal P(\mathbb N)\). Each output is in the fixed value set \(S\).

The first two rules impose no equation at \(\ell\). Any subset of \(\mathbb N\) could be assigned there while retaining those two rules. The specified limit rule makes the full solution unique.

What do the empty and singleton cases require?

What is recursion on the empty well-order? On a singleton \(\{a\}\)? Can a nonempty well-order have a recursive solution with empty value set?

Show answerHide answer

For \(A=\varnothing\), there are no rules to specify and there is one function \(A\to S\), the empty function, even if \(S=\varnothing\). On \(\{a\}\), the earlier segment is empty, so the unique value is \(F(a)=\Phi_a(\varnothing)\), where the argument denotes the empty function.

If \(A\) is nonempty and \(S=\varnothing\), there is no function \(A\to S\). The hypotheses of the recursion theorem cannot be met either: at the least point, the history set \(S^\varnothing\) has the empty function as its sole element, and no map from this singleton into \(\varnothing\) exists.
