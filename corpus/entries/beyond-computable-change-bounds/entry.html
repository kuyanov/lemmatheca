Ask what the clipped simulator needs at one input

Use the clipped guess \(Q(n,p,s,x)\), with state \((k_s,b_s,c_s)\), and its row set \(R_{n,p}\). An ordinary program \(p\) presents \(a\) at input \(x\) when \(\varphi_p(\langle k,x\rangle)=a(k,x)\) for every \(k\). Each equality requires that computation to halt with the displayed value.

For the next three results, fix \(n,p,x\) and assume this presentation, binary values \(a(k,x)\in\{0,1\}\), the initial value \(a(0,x)=0\), and the pointwise bound \(c_a(k,x)\le n\) for every \(k\). The counter counts successive changes. No bound on any other input is assumed.

The processed-prefix invariant only needs the chosen input

Under the promises in , every state of the specified clipped simulation satisfies

\[b_s=a(k_s-1,x),\qquad c_s=c_a(k_s-1,x).\]

Subtraction is truncated at zero. If \(c_s=n\), then \(a(t,x)=b_s\) for every \(t\ge k_s-1\).

At stage zero, the cursor and counters are zero and the bit equality uses \(a(0,x)=0\). A waiting step preserves the equalities. On an accepting step, soundness identifies the successful output with \(a(k_s,x)\). If \(k_s=0\), this is the initial zero again and no change is charged. If \(k_s>0\), the new charge is precisely the transition from candidate stage \(k_s-1\) to stage \(k_s\), establishing the equalities after the cursor advances.

If the counter equals \(n\), a later different answer would make the counter strictly larger by the endpoint counter lemma, contradicting the bound at this input. Thus exhaustion already identifies every later candidate answer. Every step in this argument concerns the single fixed \(x\).

Each requested prefix is reached unless the allowance is exhausted

Under the same pointwise promises, for every \(m\) there is a global stage \(s\) with \(k_s\ge m\) or \(c_s=n\).

Induct on \(m\). The assertion for zero holds initially. Suppose the cursor has reached \(m\), and the allowance is not exhausted. If the cursor later exceeds \(m\), the next induction step is done. Otherwise its monotonicity makes it remain \(m\). The assumed presentation at \(x\) makes \(\varphi_p(\langle m,x\rangle)\) halt with a binary value. At some allowance that output is found, and every larger allowance finds it too. At a sufficiently large global stage the update must accept it and advance to \(m+1\), a contradiction.

If an exhausted stage occurs instead, that stage witnesses the alternative for every requested prefix. The proof never asks whether the candidate is total on all inputs.

A bound at one input preserves that input's limit

Under the promises in , if \(a(k,x)\to\ell\in\{0,1\}\), then \(Q(n,p,s,x)\to\ell\), and \(x\in R_{n,p}\) exactly when \(\ell=1\).

Choose a candidate convergence stage \(t\). By , some simulation stage has cursor at least \(t+1\) or has exhausted its allowance. In the first case the prefix invariant identifies its bit, and every later bit, with a candidate value whose stage is at least \(t\). In the second case identifies the exhausted bit with all later candidate values, including one past \(t\); the fixed-state update retains that bit. Both cases give the stated convergence. The definition of \(R_{n,p}\) then gives the membership equivalence.

In particular, a bound \(b(x)\) may be used as \(n\) here even when other inputs require larger bounds. That substitution needs this pointwise result, rather than a theorem whose hypothesis imposes one common bound on every input.

Supply a proposed approximation together with a proposed bound program

Decode \(e=\langle p,q\rangle\) using the fixed computable pairing bijection. The candidate pair uses \(p\) to propose approximation values and \(q\) to propose the permitted number of revisions at each input. The program \(q\) may be partial. With \(V(s,q,x)\) the bounded output code, define the candidate guess

\[G(s,e,x)=\begin{cases}0,&V(s,q,x)=0,\\Q(V(s,q,x)-1,p,s,x),&V(s,q,x)>0.\end{cases}\]

A successful code \(n+1\) therefore selects the allowance \(n\). While no bound output has been found, the guess remains zero. When a bound is found, the rule uses the clipped simulator at the current global stage; it does not replace the earlier stages of \(G\).

Every stage is computable without a totality test

The function \((s,e,x)\mapsto G(s,e,x)\) is jointly total computable, is always zero or one, and satisfies \(G(0,e,x)=0\).

Decode \(e\), compute the one bounded output code, compare it with zero and, if it is positive, call the jointly computable function \(Q\) with the displayed allowance. Each operation terminates. The output is zero or a binary clipped bit. At stage zero every clipped guess is zero, regardless of its parameters, so the same is true of \(G\). Neither branch requires deciding whether \(q\) will ever halt, or whether its outputs form a valid bound.

At each input the bound either stays pending or eventually becomes fixed

Fix \(e=\langle p,q\rangle\) and \(x\). If \(\varphi_q(x)\) is undefined, then \(G(s,e,x)=0\) for every \(s\). If \(\varphi_q(x)=n\), then some \(t\) satisfies

\[G(s,e,x)=Q(n,p,s,x)\qquad\text{for all }s\ge t.\]

In the undefined case, a positive bounded output code would give an actual output, contradicting divergence. Thus every code is zero. In the defined case, completeness supplies an allowance finding output \(n\), and monotonicity preserves that same output at every larger allowance. The code is then always \(n+1\), and substitution into the defining rule gives the exact tail equality.

The equality is a proof about the eventual behavior of the algorithm. The algorithm never receives a certificate that the undefined case holds.

Specify the set represented by each candidate pair

For \(e=\langle p,q\rangle\), the candidate set is

\[H_e=\{x:\exists n\;(\varphi_q(x)=n\text{ and }x\in R_{n,p})\}.\]

Thus a diverging bound computation excludes the input. A defined bound selects the eventual bit of that particular clipped row. This defines \(H_e\) for every pair of ordinary indices, with no totality assumption on either program.

Every candidate pair has a binary limit

For every \(e\), the specified approximation \(G(s,e,x)\) converges to \(\chi_{H_e}(x)\) at every input. In particular each \(H_e\) is limit computable.

Fix \(x\). If the bound computation diverges, gives a constantly zero row, agreeing with its exclusion from \(H_e\). Otherwise it has one uniquely determined output \(n\). The tail of \(G\) is then exactly \(Q(n,p,s,x)\), which converges to \(\chi_{R_{n,p}}(x)\) by clipped-row convergence. Uniqueness of the bound output makes membership of \(x\) in \(H_e\) equivalent to membership in \(R_{n,p}\). Taking the larger of the bound-discovery stage and that clipped row's convergence stage proves the assertion. Joint computability and binary values were established in .

Every computably bounded presentation occurs as one candidate set

If \(a\) presents an \(\omega\)-c.e. set \(A\) with computable change bound \(b\), and \(p,q\) compute \(a\) and \(b\), respectively, then

\[H_{\langle p,q\rangle}=A.\]

Consequently every \(\omega\)-c.e. set equals \(H_e\) for some \(e\).

Fix \(x\). The bound program returns \(b(x)\), so the candidate-set definition reduces membership to \(x\in R_{b(x),p}\). At this one input, \(p\) presents the binary, initial-zero approximation \(a\), and its counter is at most \(b(x)\) at every stage. Its limit is \(\chi_A(x)\). Apply with \(n=b(x)\) to obtain the required membership equivalence. This holds for every input, proving the displayed equality.

For an arbitrary \(\omega\)-c.e. set, choose its witnessing approximation and total computable bound. Ordinary universality supplies indices \(p,q\) for these two actual functions. The same pair works on all inputs, so it supplies the claimed \(e\).

Reverse the candidate's answer at its own index

The diagonal set and its delayed diagonal approximation are

\[D=\{e:e\notin H_e\},\qquad d(0,e)=0,\qquad d(s+1,e)=1-G(s,e,e).\]

The one-stage delay preserves the initial-zero convention. The input \(e\) is both the index of a candidate pair and the argument on which that candidate's limit is reversed.

The diagonal has a computable convergent approximation

The specified \(d\) is jointly computable, binary, initial zero and converges to \(\chi_D\). Hence \(D\) is limit computable.

The diagonal function \((s,e)\mapsto G(s,e,e)\) is jointly computable and binary by . By , its limit on input \(e\) is one exactly when \(e\in H_e\). Apply the established delayed-complement construction. It gives the exact displayed \(d\), its initial zero, and convergence to the complementary bit for \(e\notin H_e\), which is the definition of \(D\).

Computable change bounds omit some limit-computable sets

The specified \(D\) is limit computable and is not \(\omega\)-c.e. Therefore the \(\omega\)-c.e. sets form a proper subclass of the limit-computable sets. In particular \(D\) is not \(n\)-c.e. for any finite \(n\).

Limit computability is . If \(D\) were \(\omega\)-c.e., would supply \(e\) with \(H_e=D\). At that input the diagonal definition gives \(e\in D\) exactly when \(e\notin H_e\), hence exactly when \(e\notin D\), a contradiction. The existing class inclusions place every \(\omega\)-c.e. set among the limit-computable sets and every finite change class among the \(\omega\)-c.e. sets. These inclusions and this witness establish both remaining conclusions.

Finite counts need not have computable upper estimates

For each input \(e\), the displayed approximation \(d(s,e)\) has some finite bound on its counter. There is no total computable function supplying such bounds for all \(e\). There is also no jointly total computable \(B(e,x)\) bounding the counter of \(G(s,e,x)\) for every candidate and input.

Fix \(e\) and choose a convergence stage \(t\) for \(d(s,e)\). No transition after \(t\) changes the bit, so every counter value is at most \(c_d(t,e)\): earlier values are no larger by monotonicity, and later values equal it by induction. This provides a finite bound separately for each input. A computable function of these bounds would make this very approximation an \(\omega\)-c.e. presentation of \(D\), contradicting .

Finally suppose the function \(B\) in the last assertion existed. The diagonal row \(G(s,e,e)\) would have computable bound \(B(e,e)\). Its delayed complement would have computable bound \(B(e,e)+1\), by the exact complement count. That again makes \(D\) \(\omega\)-c.e. The candidate family covers all valid computably bounded presentations, but it cannot provide one uniform computable bound for all its own rows.

Must the bound program be total for its candidate to converge?

Suppose the proposed bound program halts on some inputs and diverges on others. Does this prevent \(G\) from representing a limit-computable set?

Show answerHide answer

No. At each divergent input the guess stays zero. At each defined input it eventually follows one fixed clipped row and converges. These are exactly the two cases in . Totality is needed when \(q\) is claimed to compute a valid bound function for a prescribed \(\omega\)-c.e. presentation, but it is not needed for convergence of this construction. There is no step deciding which of the two cases an input belongs to.

Could a different approximation restore a computable bound?

The supplied \(d\) has no computable change bound. Could a different jointly computable, initial-zero binary approximation to the same \(D\) have one? Could it have a computable natural-number countdown?

Show answerHide answer

Neither is possible. Either kind of presentation would make the set \(D\) itself \(\omega\)-c.e., using the countdown characterization in the second case. That contradicts , whose diagonal proof excludes all computably bounded presentations, rather than just the particular \(d\). Finite bounds chosen separately after the computations settle therefore cannot in general be replaced by an effective sequence of allowances.
