Two nonzero degrees can have only zero below both

The zero Turing degree consists of the computable sets. A pair \(\mathbf a,\mathbf b\) is an ordinary minimal pair if both degrees are nonzero and

\[\forall\mathbf c\;[\mathbf c\le\mathbf a\ \land\ \mathbf c\le\mathbf b\ \Longrightarrow\ \mathbf c=\mathbf0].\]

Equivalently, representatives \(A,B\subseteq\mathbb N\) are both noncomputable, and every set \(C\) satisfying \(C\le_T A\) and \(C\le_T B\) is computable. This equivalence uses the degree order and its least-degree characterization. The adjective “ordinary” places no enumerability requirement on the representatives. We will not construct a c.e. minimal pair here.

Control a pair of programs whenever their outputs agree

Retain the fixed oracle-program numbering \(\varphi_e^X\). A displayed equality to a function means equality at every input, including definedness. For each pair of indices \(e,f\), impose

\[R_{e,f}:\quad\forall g:\mathbb N\to\mathbb N\;[\varphi_e^A=g=\varphi_f^B\ \Longrightarrow\ g\text{ is computable}].\]

It is useful to demand this for arbitrary total numerical outputs, rather than only membership bits. Choosing \(g=\chi_C\), where \(\chi_C\) is the characteristic function of \(C\), will handle a common lower bound. The two indices are retained throughout the argument: we do not change which programs compute the common function.

Search for two persistent, unequal finite outputs

Use the binary words, prefix relation \(\preceq\), and bounded checker \(D(\sigma,e,x)\). Thus \(D(\sigma,e,x)=y+1\) certifies the output \(y\); zero certifies nothing. Word codes, their lengths, prefix comparison and this checker are primitive recursive. Every actual halting computation has a certifying prefix extending any prescribed prefix, and certificates persist under extension.

For fixed words \(\sigma,\tau\), call a triple \((x,\rho,\eta)\) a disagreement witness for \((e,f,\sigma,\tau)\) if \(\sigma\preceq\rho\), \(\tau\preceq\eta\), both \(D(\rho,e,x)\) and \(D(\eta,f,x)\) are positive, and these two numbers differ. Their decoded outputs consequently differ as well. Checking a proposed triple is primitive recursive; deciding whether any such triple exists need not be computable.

A disagreement witness excludes a common total output

If \((x,\rho,\eta)\) is a disagreement witness, then no sets \(X,Y\) extending \(\rho,\eta\), respectively, can satisfy \(\varphi_e^X=g=\varphi_f^Y\) for a total function \(g\).

Write the two positive certificate values as \(y+1\) and \(z+1\), with \(y\ne z\). Certificate soundness gives \(\varphi_e^X(x)=y\) and \(\varphi_f^Y(x)=z\). A common function would give \(y=g(x)=z\), a contradiction. The same argument applies after any further finite extensions.

Fix one ordinary search program before choosing a common function

Fix an index \(e\) and a word \(\sigma\). On input \(x\), enumerate all numerical binary-word codes \(u=0,1,2,\ldots\). Interpret a code by decoding its finite list and reducing its entries modulo two; this enumeration contains every binary word. Search until the corresponding word \(\rho_u\) satisfies

\[\sigma\preceq\rho_u\quad\text{and}\quad D(\rho_u,e,x)>0,\]

then return \(D(\rho_u,e,x)-1\). Denote this partial function by \(S_{e,\sigma}(x)\). The displayed test is primitive recursive in \((x,u)\). Unbounded least search followed by subtraction therefore supplies an ordinary partial-recursive program for \(S_{e,\sigma}\); it makes no oracle queries. This particular program depends only on \(e,\sigma\), before a common function \(g\) is chosen. It is not claimed to halt on every input without further assumptions.

Without a disagreement, that search computes every common total output

Suppose there is no disagreement witness for \((e,f,\sigma,\tau)\), the sets \(X,Y\) extend \(\sigma,\tau\), and \(\varphi_e^X=g=\varphi_f^Y\) is total. Then the specified ordinary program \(S_{e,\sigma}\) halts on every input and returns \(g(x)\). In particular \(g\) is computable.

Fix \(x\). Since \(\varphi_e^X(x)=g(x)\), prefix adequacy gives a word \(\rho\succeq\sigma\) with \(D(\rho,e,x)=g(x)+1\). Its code eventually occurs in the search, so the search halts. Let \(\widehat\rho\) be the first successful word, whose output is \(y\). This word need not be a prefix of \(X\), which is why soundness on \(X\) alone does not justify the decoder.

Instead use \(\varphi_f^Y(x)=g(x)\). Prefix adequacy gives \(\eta\succeq\tau\) with \(D(\eta,f,x)=g(x)+1\). If \(y\ne g(x)\), then \((x,\widehat\rho,\eta)\) is a disagreement witness. Thus \(y=g(x)\). The ordinary partial-recursive search is consequently total with exactly the function \(g\) as its output, so \(g\) is computable.

One extension settles a pair of indices

Define \(E_{e,f}(\sigma,\tau)\) as follows. If there is a disagreement witness, choose the one with the least numerical triple code and retain its words \(\rho,\eta\). If there is none, retain \(\sigma,\tau\). In either case append a zero to both retained words. This padding ensures proper growth without losing a successful certificate.

The choice is definite: use the established finite sequence coding and the standard pairing map to enumerate triples. No effective method for choosing between the two cases is asserted.

The extension works for every completion of its two words

Write \((\sigma',\tau')=E_{e,f}(\sigma,\tau)\). Both new words properly extend their inputs. For all sets \(X,Y\) extending \(\sigma',\tau'\), respectively, and every total \(g\),

\[\varphi_e^X=g=\varphi_f^Y\quad\Longrightarrow\quad g\text{ is computable}.\]

In the witness case, the old words extend to \(\rho,\eta\), and appending zero preserves their unequal outputs. The antecedent is impossible by . In the other case the new sets still extend \(\sigma,\tau\), so proves the conclusion using the fixed program \(S_{e,\sigma}\). Each word gains at least one position in either case. Because the assertion holds for every completion, later stages cannot undo it.

A separate bit makes one set different from one computable candidate

For an index \(e\) and word \(\sigma\), put \(m=|\sigma|\) and define

\[b=\begin{cases}1,&\varphi_e^{\varnothing}(m)\downarrow=0,\\0,&\text{otherwise},\end{cases}\qquad H_e(\sigma)=\sigma b.\]

Then every \(X\) extending \(H_e(\sigma)\) differs, as a total characteristic function, from \(\varphi_e^{\varnothing}\).

If the displayed computation returns zero, then \(\chi_X(m)=1\). Otherwise \(\chi_X(m)=0\), while that computation either diverges or has a nonzero output. In all cases \(\varphi_e^{\varnothing}(m)\ne\chi_X(m)\). Outputs larger than one cause no problem. Every ordinary computable characteristic function occurs in the empty-oracle numbering, by the ordinary-program bridge, so meeting all these requirements makes \(X\) noncomputable.

At each round diagonalize twice and settle one program pair

Start with \(\sigma_0=\tau_0=[]\). At round \(n\), first form \(u=H_n(\sigma_n)\) and \(v=H_n(\tau_n)\). Decode \(n=\langle e,f\rangle\) using the fixed pairing bijection, and set

\[(\sigma_{n+1},\tau_{n+1})=E_{e,f}(u,v).\]

This defines the actual sequences of words and the actual sets

\[A=\bigcup_n\sigma_n,\qquad B=\bigcup_n\tau_n.\]

The unions mean the sets whose characteristic sequences extend every displayed word. Both operations preserve prefixes and append a bit, so \(|\sigma_{n+1}|\ge|\sigma_n|+2\) and \(|\tau_{n+1}|\ge|\tau_n|+2\). In particular the lengths are at least \(n\), and the coherent-union lemma makes \(A,B\) well defined. Concretely \(\chi_A(x)=\sigma_{x+1}(x)\) and \(\chi_B(x)=\tau_{x+1}(x)\).

The two constructed sets form an ordinary minimal pair

The sets \(A,B\) in are noncomputable, and every \(C\subseteq\mathbb N\) satisfies

\[C\le_T A\ \land\ C\le_T B\quad\Longrightarrow\quad C\text{ is computable}.\]

At round \(e\), the first two operations impose the ordinary diagonal requirements for index \(e\) on \(A\) and \(B\). Every later word extends those outputs, and so do the final unions. Thus neither set has a computable characteristic function.

Now suppose \(C\le_T A\) and \(C\le_T B\). Choose the actual oracle-program indices \(e,f\) witnessing these reductions, so \(\varphi_e^A=\chi_C=\varphi_f^B\). At round \(\langle e,f\rangle\), settles exactly this pair. The final unions extend that round's output words, so the same theorem makes \(\chi_C\) computable. Computability of the characteristic function is exactly computability of \(C\).

These degrees are incomparable and have greatest lower bound zero

Let \(\mathbf a=\deg_T A\) and \(\mathbf b=\deg_T B\) for the constructed sets. Then \(\mathbf0<\mathbf a\), \(\mathbf0<\mathbf b\), the degrees are incomparable, and \(\mathbf0\) is their greatest lower bound.

Noncomputability and the least-degree characterization give positivity. If \(\mathbf a\le\mathbf b\), then \(\mathbf a\) itself would be a common lower bound. The minimal-pair conclusion would give \(\mathbf a=\mathbf0\), a contradiction. Exchange the two degrees for the other direction. Finally \(\mathbf0\) is a lower bound of every pair of degrees, while the theorem says every common lower bound of this pair equals \(\mathbf0\). This is exactly the greatest-lower-bound property.

The exact-pair construction gives a different outcome: an incomparable pair with no greatest common lower bound.

A common nonzero lower bound survives taking joins

Take any incomparable degrees \(\mathbf a,\mathbf b\), and choose a nonzero degree \(\mathbf d\). Can the joins \(\mathbf a\vee\mathbf d\) and \(\mathbf b\vee\mathbf d\) form a minimal pair? Must they remain incomparable?

Show answerHide answer

The joins need not even remain incomparable: for example choosing \(\mathbf d=\mathbf a\vee\mathbf b\) makes them equal. Whether or not they are incomparable, they cannot form a minimal pair, because \(\mathbf d\ne\mathbf0\) lies below both. The minimal-pair requirement controls all common lower bounds, so it is a different requirement from checking the two comparisons between a given pair.

Have we constructed a computably enumerable minimal pair?

Does the finite-stage construction supply enumerations of \(A\) and \(B\), or a computable function returning their stage words?

Show answerHide answer

No such procedure is supplied. A round chooses between the existence and nonexistence of any disagreement witness, and the diagonal bit uses a halting-output test. Although each finite certificate can be checked effectively, those case choices are not claimed computable. The construction commits to both zero and one bits, whereas an enumeration of a c.e. set only lists positive members. Proving the existence of c.e. minimal pairs requires an additional argument; the finite-injury incomparability theorem alone also does not prove minimality.
