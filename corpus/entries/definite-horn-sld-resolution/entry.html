Work backward from the facts being requested

The rules for addition can justify an answer without first listing every addition fact. Starting with a request for a sum, one matches a rule's conclusion and replaces that request by the rule's premises. The substitutions used during this process also determine values for the original unknowns.

Fix an equality-free first-order language \(L\). A definite clause has the form \(H\leftarrow B_1,\ldots,B_m\), where all displayed expressions are relation atoms on the shared finite terms. It asserts the universal closure of \((B_1\land\cdots\land B_m)\to H\). For \(m=0\) it is a fact, asserting its head universally. A program \(P\) is a finite list of definite clauses, each with its own finite variable context.

A goal \(G=[A_1,\ldots,A_k]\) is an ordered finite list of atoms with variables from \(\mathbb N\). It requests their conjunction. The empty goal requests the true empty conjunction. Lists retain order and repetitions: two occurrences of the same atom are two requests. At a valuation \(v\) in an actual nonempty structure, the goal is true when every listed atom is true at \(v\). Write \(P\models\exists G\) when every model of the universal program admits such a valuation. Only the finitely many variables occurring in \(G\) need existential witnesses.

For models and least-model semantics, forgetting body order and repetitions recovers the existing definite Horn rules. Operationally we keep both, since they determine the remaining list of requests.

Every use of a clause gets fresh variables

Keep a finite variable history \(U\), initially containing every variable of the original goal. If a clause uses a local variable context \(\{0,\ldots,n-1\}\), choose an injection \(\nu\) from that context into \(\mathbb N\) whose range misses \(U\). Replacing each local variable by \(x_{\nu(i)}\) gives a fresh variant \(H'\leftarrow B'_1,\ldots,B'_m\). One specified choice is \(\nu(i)=b+i\), where \(b\) is larger than every member of \(U\); take \(b=0\) when \(U\) is empty.

Freshness is relative to all previously used variables, including those retained in the current images of original answer variables. It is stronger than disjointness from the current goal alone. An injective renaming does not identify local variables and preserves the universally asserted clause. This is the same independence requirement as standardizing resolution parents apart, with the current goal left in its existing names.

Resolve one selected atom and substitute the entire new goal

Select one occurrence \(A\) in a nonempty goal, writing \(G=G_\ell\mathbin{+\!+}[A]\mathbin{+\!+}G_r\). Choose a fresh variant of a program clause. If \(A\) and its head \(H'\) have a most general atom unifier \(\mu\), one SLD step has successor

\[G'=\bigl(G_\ell\mathbin{+\!+}[B'_1,\ldots,B'_m]\mathbin{+\!+}G_r\bigr)\mu.\]

Here substitution acts on every atom in the list, including the unselected requests. The selected occurrence is replaced at its position by the ordered body. A fact removes it. Different relation symbols, incompatible arities, or a failed occurs check give no step with that clause.

After the step enlarge the history to include its old members, the fresh clause variables, and all variables in \(\mu(x)\) for each old or fresh tracked variable \(x\). This is still finite. It includes every variable in \(G'\) and in the updated images of the original answer variables. Thus the freshness requirement can be maintained at each later step.

Compose the answers in chronological order

An SLD derivation is a sequence of these steps, with fresh variants chosen anew at each use. A finite derivation ending in the empty goal is an SLD refutation of the initial goal. A branch ending in a nonempty goal with no applicable clause is a failure, not a refutation.

Suppose the successive unifiers are \(\mu_1,\ldots,\mu_r\). Using the existing composition convention, set

\[\theta=\mu_r\star\cdots\star\mu_1,\qquad (\tau\star\sigma)(x)=\sigma(x)[\tau].\]

The computed answer is the restriction of \(\theta\) to the variables of the original goal. The empty refutation has identity answer. Later substitutions act inside terms assigned earlier; collecting unrelated bindings without composing them can give a wrong answer. When \(G\theta\) still has variables, its asserted truth means truth under every assignment to those remaining variables.

Compute the missing summand

Let \(0\) be a constant, \(s\) unary, and \(\operatorname{Add}\) ternary. Use the program

\[\operatorname{Add}(0,y,y)\leftarrow,\qquad \operatorname{Add}(s(u),v,s(w))\leftarrow\operatorname{Add}(u,v,w).\]

Refute the goal \([\operatorname{Add}(s(0),x_0,s(s(0)))]\) and give its computed answer.

Show answerHide answer

Take a fresh recursive clause with variables \(u,v,w\), all distinct from \(x_0\). The selected atom and head have the most general unifier

\[\mu_1=[0/u,\ x_0/v,\ s(0)/w].\]

It gives the successor \([\operatorname{Add}(0,x_0,s(0))]\). A fresh fact with variable \(z\) then has most general unifier \(\mu_2=[s(0)/x_0,\ s(0)/z]\). Its body is empty, so this step finishes the refutation. The composite sends the original variable \(x_0\) to \(s(0)\).

For the first unifier, equality of the first and third argument trees forces the images of \(u,w\), and equality of the second forces the image of \(v\) to be that of \(x_0\). Any other unifier is therefore a further instance of the displayed substitution. The same argument for the fact forces the images of \(x_0,z\) to be \(s(0)\). The third argument of the original query has two successors. Changing it to \(s(0)\) would change the requested sum and the answer.

These rules force the particular positive instances used here and put this indicated addition instance in their least Herbrand model. They do not say that every model interprets \(\operatorname{Add}\) as exactly the ordinary addition graph: interpreting that relation as all triples also satisfies both positive clauses.

A successful successor proves the selected request

For an SLD step \(G\to G'\) with unifier \(\mu\), every model of \(P\) and valuation \(v\) satisfying \(G'\) also satisfies \(G\mu\) at \(v\).

Every unselected atom of \(G\mu\) occurs in \(G'\). The substituted body atoms also occur there, so all are true at \(v\). The fresh clause is universally true in the model. Apply it at the valuation sending each of its variables to the value of its image under \(\mu\), evaluated at \(v\). By semantic substitution, its head \(H'\mu\) is true at \(v\). Unification makes this the same atom as the selected request \(A\mu\). Thus every atom of \(G\mu\) is true. Most-generality is not needed for this implication; being a unifier suffices.

A computed answer is valid for the original query

If an SLD refutation of \(G_0\) computes \(\theta\), then every nonempty model of \(P\) satisfies \(G_0\theta\) at every valuation. In particular, \(P\models\exists G_0\).

Induct backward along the finite refutation. The empty final goal is true at every valuation. If the tail of a refutation proves the current successor after its remaining composite substitution \(\tau\), apply at the valuation \(x\mapsto\llbracket\tau(x)\rrbracket_v\). The substitution identity gives truth of \(G(\tau\star\mu)\) at \(v\). Repeating this argument yields exactly the chronological composite \(\theta\), including its action inside earlier images.

Finally choose any valuation in a nonempty model and assign each original variable the value of its image under \(\theta\). Semantic substitution makes the original goal true at that assignment. Only its original variable set matters, so restricting the computed answer loses no information about the query.

Least-model membership has a finite proof tree

Assume first that closed terms exist, and let \(L_P\) be the least Herbrand model. A ground proof tree for an atom labels its root by a ground instance of a program-clause head, and gives it one child proof for each occurrence in that instance's body list. A fact gives a node without children. The root atom belongs to \(L_P\) if and only if it has such a finite tree.

By finite appearance in the least-model stages, a root first appears at a finite stage. Its producing ground clause has all body atoms at the preceding stage. Induct on the stage, taking a child tree for each listed occurrence; if the root was retained from an earlier stage, use its earlier tree. Repeated body atoms get repeated child slots, even if their trees happen to be equal. Stage zero contains no atoms.

Conversely, induction up a finite tree puts every child in \(L_P\); closure under its ground clause puts the parent there. Thus forgetting body order and repetitions for the semantic closure does not lose the ordered, repeated children needed by an operational proof.

Any selected ground request can be reduced

Suppose every atom of a finite ground goal belongs to \(L_P\). Fix any rule for selecting one occurrence from each nonempty goal. There is a finite reduction to the empty goal, always selecting that occurrence and replacing it by the body of an appropriate ground clause instance.

Choose a finite proof tree for each goal occurrence. Let the forest weight be the sum of the numbers of nodes in these trees. If the goal is nonempty, its selected occurrence has a root clause and a list of child trees. Replace that occurrence by this body list and replace its tree by those child trees. All other goal atoms and their proof trees stay in place.

The old root tree had one node more than the sum of its children's node counts. Therefore the total weight decreases by exactly one, regardless of which occurrence was selected. Induction on this natural number reaches weight zero, where the forest and goal are empty. Counting only tree heights would not give this argument: replacing a root can introduce several children of nearly the same height. The conclusion permits any atom-selection rule, while the program-clause choices must still be suitable ones.

Lift the selected ground step through its most general unifier

Let \(G\sigma\) be a ground instance of a goal, with its variables contained in a finite history \(U\). Suppose its selected atom is proved using a ground instance of a program clause. Choose a fresh variant \(H'\leftarrow\mathbf B'\) outside \(U\). Then the selected symbolic atom \(A\) and \(H'\) have a most general unifier \(\mu\), and the resulting symbolic successor \(G'\) has a ground instance equal to the given ground successor.

The ground clause instance supplies a closed replacement term for each fresh clause variable. Merge those replacements with \(\sigma\), obtaining a substitution \(\gamma\) that equals \(\sigma\) on \(U\) and uses the specified replacements on the fresh variables. These prescriptions do not conflict because freshness makes the two finite sets disjoint; fill other variables arbitrarily with an existing closed term. Every atom of \(G\) uses variables in \(U\), so \(G\gamma=G\sigma\). The fresh clause under \(\gamma\) is the prescribed ground clause.

In particular \(A\gamma=H'\gamma\). The atom-unification theorem provides an actual most general unifier \(\mu\) and a residual ground substitution \(\rho\) with \(\gamma=\rho\star\mu\) on every variable. Applying the atom and list substitution identities gives

\[G'\rho=\bigl(G_\ell\mathbin{+\!+}\mathbf B'\mathbin{+\!+}G_r\bigr)\gamma.\]

This is exactly the ground successor, with each body occurrence and each unselected occurrence retained. Furthermore \(\mu(x)[\rho]=\sigma(x)\) for every \(x\in U\). This factorization on all tracked variables will preserve the original answer through later steps. No equality between unrelated parent variables was assumed.

A refutation covers every correct ground answer

Fix any atom-selection rule. If every atom of \(G_0\sigma\) belongs to \(L_P\), there is an SLD refutation following that rule with computed answer \(\theta\), and a ground substitution \(\delta\) such that

\[\theta(x)[\delta]=\sigma(x)\qquad\text{for every variable }x\text{ of }G_0.\]

Thus every correct ground answer is an instance of some computed answer.

Use the proof forest for \(G_0\sigma\), and induct on its total node count as in . The empty forest gives the identity answer and residual substitution \(\sigma\). Otherwise lift the root step of the selected tree by . The new ground forest consists of its children and the unchanged other trees, so its weight is one smaller. Its symbolic goal is \(G'\), instantiated by the residual \(\rho\).

For the induction maintain the stronger assertion that the final factorization holds on every variable of the current finite history. The updated history contains every variable in \(\mu(x)\) for each old tracked \(x\). If the recursive refutation has answer \(\tau\) and residual \(\delta\), its factorization on that updated history gives \(\tau(y)[\delta]=\rho(y)\) for each variable occurring in \(\mu(x)\). Substitution through the finite term \(\mu(x)\) therefore yields

\[(\tau\star\mu)(x)[\delta]=\mu(x)[\rho]=\sigma(x).\]

The prefixed step has computed answer \(\tau\star\mu\), so the invariant holds on the old history and in particular on the original query variables. Fresh variants exist at every recursive call because that history stays finite. The proof can choose the specified freshening and the successful most general unifier returned by the unification algorithm at each step.

Existentially forced goals have SLD refutations

For every finite definite program and finite goal, and every atom-selection rule,

\[P\models\exists G\quad\Longleftrightarrow\quad G\text{ has an SLD refutation following that rule}.\]

Answer soundness proves the reverse implication. For the forward implication, first suppose closed terms exist. The actual least Herbrand structure is a nonempty model of \(P\). The hypothesis supplies a valuation in its term domain making the whole goal true. This is a single ground substitution \(\sigma\) making all goal atoms members of \(L_P\), with the same term used at every occurrence of each variable. Apply .

If the original language has no closed terms, use the existing fresh-constant method: adjoin one constant \(c\), form the least Herbrand model, and take its old-language reduct. This reduct is a nonempty \(L\)-model of \(P\), so it also supplies witnesses. Equivalently, its domain consists of native \(L\)-terms over one protected generator \(\ast\), interpreted as \(c\). Function applications form terms and the generator supplies nonemptiness. The two term descriptions correspond by replacing \(\ast\) with \(c\).

The ground-tree and lifting arguments work with terms over this protected generator as their residual substitution images. It is a fixed parameter, not an SLD variable: all fresh variants, unification problems and computed answers still use the original signature and the variable stock \(\mathbb N\). Hence the lifted refutation is an original-language SLD refutation. This proves existential-query completeness, without asserting that all universally correct nonground substitutions are computed answers.

Make a finite set of successors at every node

To turn the existence theorem into a search, fix a computable atom-selection rule, the specified fresh-variable offset, and a deterministic most general unifier returned by the term-unification algorithm. For a finite encoded program with decidable function- and relation-symbol equality, try each program clause once against the selected atom. A successful unification gives its successor, its enlarged history, and its updated answer; a failed one gives none. This defines the SLD search tree.

There are at most \(|P|\) children at a node. Fresh variants and different spellings of most general unifiers are not additional infinite search choices: the fixed procedures select one for each attempted clause. The root carries the original goal and identity answer. Every child carries the chronological composition with its parent's answer. An empty-goal node records success.

Breadth-first search finds every finite successful branch

For these fixed effective choices, breadth-first search eventually finds a refutation whenever \(P\models\exists G\).

Start with the singleton root frontier. The next frontier concatenates the finite child lists of the current one. Induction shows that each frontier is finite and that it contains every node at its depth: every node at the next depth is a child of a node already included. The completeness proof above can use exactly the fixed freshening and canonical successful unifier, so some empty-goal node occurs at a finite depth \(r\).

Computing and checking each finite frontier takes finitely many operations. After the first \(r\) levels, breadth-first search therefore inspects that successful node. More generally, any fair traversal that eventually visits every finite-depth node has this property. There need not be a bound on \(r\) known in advance, and an unsuccessful search need not terminate.

Can depth-first execution miss an existing proof?

Put the two clauses \(p\leftarrow p\) and \(p\leftarrow\) in that order, where \(p\) is a nullary relation. What happens to the goal \([p]\) if execution always tries the first clause and explores its successor before returning to alternatives?

Show answerHide answer

The first clause replaces \([p]\) by \([p]\), with identity unifier. Repeating that choice gives an infinite branch whose goal never becomes empty. This depth-first execution does not return to the root to try its second clause. Yet that fact gives a one-step refutation, also with identity answer. The least model contains \(p\), and breadth-first search inspects the successful child at depth one.

There is only one atom to select in this example. The failure comes from the order in which program-clause alternatives are explored, not from any inadequacy of the atom-selection completeness theorem. SLD completeness guarantees a finite proof exists; fair search guarantees such a proof is eventually visited.
