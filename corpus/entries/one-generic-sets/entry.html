Meet an enumerable collection of words, or avoid it permanently

Use the finite binary words \(\sigma\in2^{<\mathbb N}\), their list codes \(u_\sigma\), and prefix notation \(\sigma\preceq\rho\) and \(\sigma\preceq A\). A valid word code is a number whose decoded list contains only zeros and ones. For every numerical input \(u\), its normalization \(N(u)\) is the code obtained by reducing every decoded entry modulo two. Thus \(N(u_\sigma)=u_\sigma\); length, normalization and validity are ordinary computable finite-list operations.

A set \(A\subseteq\mathbb N\) meets \(S\subseteq2^{<\mathbb N}\) if some prefix of \(A\) belongs to \(S\). It avoids \(S\) above \(\sigma\preceq A\) if no extension \(\rho\succeq\sigma\) belongs to \(S\). The collection \(S\) is dense if every word has an extension in \(S\). This is forcing-order density for finite words ordered by reverse extension.

A set \(G\) is 1-generic if, for every c.e. collection \(S\) of binary words, it either meets \(S\) or avoids it above some prefix. Here c.e. means that the set of valid codes of members is c.e. For the fixed domain numbering \(W_e\), put \(S_e=\{\sigma:u_\sigma\in W_e\}\). Malformed word codes in \(W_e\) are discarded. These \(S_e\) include every c.e. collection of words.

Adding the avoidance words makes every collection dense

For any collection \(S\) of binary words, its densification

\[S^*=S\cup\{\sigma:\text{no extension of }\sigma\text{ belongs to }S\}\]

is dense. A set is 1-generic exactly when it meets \(S_e^*\) for every \(e\).

Fix a word \(\sigma\). If it has an extension in \(S\), that extension belongs to \(S^*\). Otherwise \(\sigma\) itself belongs to the second part of \(S^*\). This proves density, including for \(S=\varnothing\). Meeting the first part means meeting \(S\); meeting the second means having a prefix above which \(S\) is avoided. These are precisely the two alternatives in the definition.

The avoidance part is defined by a negative extension-existence question. Density is an existence statement here; the effective selector below will decide that question with the halting oracle.

One ordinary program searches for an enumerable extension

There are a fixed ordinary search program and a total computable index map \(q(e,u)\) with the following exact behavior. Write \(t=\langle v,s\rangle\), and let \(C(e,u,t)\) be the decidable test

\[v\text{ is valid},\qquad N(u)\preceq v,\qquad v\in W_{e,s}.\]

Prefix notation between codes means prefix comparison of their decoded binary words. The search tests \(t=0,1,2,\ldots\), returns the least successful \(t\), and diverges if none exists. The program with ordinary index \(q(e,u)\) ignores its runtime input and performs exactly this search. Consequently, for the ordinary diagonal halting set \(K\),

\[q(e,u)\in K\quad\Longleftrightarrow\quad\exists\rho\succeq\operatorname{decode}(N(u))\;[\rho\in S_e].\]

Validity and prefix comparison inspect finite lists. The uniform finite-stage membership test decides the last condition, so \(C\) is a total computable test in all its numerical arguments. Unbounded search is an ordinary partial-recursive program. The parameter theorem freezes the pair \(\langle e,u\rangle\) into a program that ignores its remaining input; this specified compiler gives \(q\). Its diagonal input therefore makes no difference to its evaluation.

A successful candidate supplies an extension in \(S_e\). Conversely any such word has a valid code \(v\) appearing in some \(W_{e,s}\), so \(\langle v,s\rangle\) eventually passes. We order candidate pairs by their numerical pair code, rather than by an unspecified enumeration arrival. This fixes all ties and will fix the same extension in every later use.

Fix a deterministic extension program using the halting oracle

Define \(H(e,u)\) to return \(N(u)\) if \(q(e,u)\notin K\), and otherwise to return the word coordinate \(v\) of the least \(t=\langle v,s\rangle\) passing \(C(e,u,t)\). There is one fixed actual oracle program \(\mathsf h\), called the extension selector, satisfying

\[E_K(\mathsf h,\langle e,u\rangle)\downarrow=H(e,u)\qquad\text{for every }e,u.\]

Its output is valid, extends \(N(u)\), and belongs to \(S_e^*\). For a word \(\sigma\), write \(H(e,\sigma)\) for the decoded output on \(u_\sigma\).

Here is an actual finite-program construction, including its behavior with a different oracle. On input \(z=\langle e,u\rangle\), form \(a=\langle z,b\rangle\), where \(b\) is the query answer at \(q(e,u)\). Let \(r_{\mathrm{test}}\) be an ordinary program whose value on \(\langle a,t\rangle\) is zero exactly when

\[(b=0\land t=0)\ \lor\ (b=1\land C(e,u,t)),\]

and is one otherwise. Let \(r_{\mathrm{out}}\) return \(N(u)\) when \(b=0\), and the first coordinate of \(t\) otherwise. Both are ordinary total computable programs, with all projections and finite tests just specified. Write \(I\) for the identity program and \(\iota\) for the ordinary-program embedding. Form

\[R=\operatorname{pair}\bigl(I,\operatorname{comp}(\mathbf Q,\iota(q))\bigr),\]
\[L=\operatorname{comp}\bigl(\operatorname{find}'(\iota(r_{\mathrm{test}})),\operatorname{pair}(R,\mathbf0)\bigr),\]
\[\mathsf h=\operatorname{comp}\bigl(\iota(r_{\mathrm{out}}),\operatorname{pair}(R,L)\bigr).\]

Here \(\iota(q)\) means the embedding of a fixed ordinary program computing \(z\mapsto q(z_0,z_1)\). The search constructor starts at zero and retains \(a\) as its parameter. Under any oracle \(A\), a negative query answer makes its first test succeed at \(t=0\); its output is \(N(u)\). A positive answer makes it perform exactly the ordinary least-candidate search, returning its word coordinate if successful, and diverging if no candidate exists. This is an evaluation identity for the displayed program, not an assumption that arbitrary oracle answers are correct.

Under \(K\) the positive branch always has a witness, by . Its output is an extension in \(S_e\). In the negative branch no such extension exists, so the unchanged normalized word lies in the avoidance part of \(S_e^*\). Both branches prove all the stated conclusions. No potentially divergent branch is evaluated when the answer is negative.

The jump-inversion construction reuses this exact selector and records one target-oracle bit immediately after each selected word. Its recovery induction depends on making the same first-candidate choice again, so that the appended bit is read at the same position.

Lengthen the selected word at every stage

For a supplied binary word \(\rho\), define its generic history by the exact recurrence

\[\sigma_0=\rho,\qquad\tau_n=H(n,\sigma_n),\qquad\sigma_{n+1}=\tau_n0.\]

The selector returns a word extending \(\sigma_n\), and the appended zero makes \(|\sigma_{n+1}|\ge|\sigma_n|+1\). Thus \(\sigma_n\preceq\sigma_{n+1}\) and \(|\sigma_n|\ge|\rho|+n\) by induction. Define the constructed set \(G_\rho\) by

\[\chi_{G_\rho}(x)=\sigma_{x+1}(x).\]

The indicated bit exists by the length bound. The compatible-union lemma proves that \(G_\rho\) is exactly the unique set extending every \(\sigma_n\), in particular the supplied \(\rho\).

Every finite word extends to a specified generic below the halting set

For every binary word \(\rho\), the same specified construction yields a 1-generic set \(G_\rho\) extending \(\rho\), with \(G_\rho\le_T K\).

At stage \(e\), the selected word \(\tau_e\) belongs to \(S_e^*\). If it belongs to \(S_e\), the union meets that collection. In the other case it has no \(S_e\)-extension, and the union avoids the collection above \(\tau_e\). Every subsequent word extends \(\tau_e\), so the chosen alternative is permanent. This works for every index \(e\), proving genericity.

To compute the union, retain a numerical state \(\langle n,u_{\sigma_n}\rangle\). Starting at \(\langle0,u_\rho\rangle\), one transition applies the fixed program \(\mathsf h\) to \(\langle n,u_{\sigma_n}\rangle\), appends zero by ordinary list-code operations, and increments \(n\). Each transition is total under \(K\). The relative primitive-recursion rules therefore give one actual oracle program for the stage state, uniform in the supplied initial code and stage number.

On input \(x\), iterate exactly \(x+1\) transitions and return bit \(x\) of the retained word. The history induction identifies this state with \(\sigma_{x+1}\), and the length bound makes the bit access valid. The output is precisely the displayed definition of \(\chi_{G_\rho}(x)\). This is a total characteristic program for that same union, establishing the reduction.

No computable set can be 1-generic

Every 1-generic set is noncomputable.

Suppose \(G\) were computable. The collection \(S=\{\sigma:\sigma\not\preceq G\}\) would then be computable: compare each of the finitely many bits with the corresponding computed bit of \(G\). It is dense. A word already incompatible with \(G\) itself belongs to \(S\); a prefix \(\sigma\preceq G\) has an extension obtained by appending the opposite of \(\chi_G(|\sigma|)\), and this extension belongs to \(S\).

No prefix of \(G\) belongs to \(S\), so \(G\) does not meet it. Density also prevents any prefix from avoiding it. This contradicts 1-genericity for the c.e. collection \(S\).

A prefix can certify convergence or exclude every convergence certificate

Use the established bounded checker \(D(\sigma,e,x)\). It is positive exactly when \(\sigma\) certifies some output of \(\varphi_e(x)\), using only positions below \(|\sigma|\). Define forcing convergence and forcing divergence by

\[\sigma\Vdash\varphi_e(x)\downarrow\quad\Longleftrightarrow\quad D(\sigma,e,x)>0,\]
\[\sigma\Vdash\varphi_e(x)\uparrow\quad\Longleftrightarrow\quad\forall\rho\succeq\sigma\;[D(\rho,e,x)=0].\]

The symbol \(\Vdash\) here has only these two defined meanings. For convergence, \(\sigma\) already contains a successful bounded computation. For divergence, the assertion excludes successful computations throughout the entire cone of extensions; failure of the current bounded checker alone does not suffice.

Convergence prefixes form a uniformly enumerable collection

The collections \(B_{e,x}=\{\sigma:D(\sigma,e,x)>0\}\) are c.e. uniformly in \(e,x\). Fix a total computable index compiler \(a(e,x)\) satisfying \(S_{a(e,x)}=B_{e,x}\). Every word forcing convergence gives actual convergence for all sets extending it; every word forcing divergence gives actual divergence for all such sets. Both forcing relations persist under extension and cannot hold simultaneously.

The bounded checker and validity test are ordinary computable. An ordinary program returns zero exactly when its input is a valid word code with positive checker value, and otherwise searches forever. The parameter theorem freezes \(e,x\) in this fixed program; choose this compiler as \(a\). This specifies its domain, including rejection of all malformed codes.

Certificate persistence transfers a positive checker value to every longer word and every infinite extension. If a set extending a divergence-forcing word had a halting computation, prefix adequacy would supply a positive certificate extending that word, a contradiction. Divergence forcing persists because a smaller cone still has no positive certificate. Convergence and divergence cannot coexist since the original word is one of its own extensions.

Must every divergent computation have a divergence-forcing prefix?

Consider the program that queries successive natural numbers and stops at the first negative answer. It diverges with oracle \(\mathbb N\). Can any prefix of that oracle force its divergence?

No. A prefix of length \(k\) consists of \(k\) ones. Extend it by a zero and then complete it to an infinite set. The program halts at position \(k\). Prefix adequacy supplies a finite successful certificate extending the original word, increasing the allowance further if necessary. Thus the original prefix does not force divergence. This is the same failure of finite-use stability for divergence. The stronger conclusion below requires genericity of the actual oracle.

A single program recognizes when its oracle meets an indexed collection

There is an ordinary total computable map \(p(e)\) to actual oracle-program indices such that, for every oracle \(A\) and runtime input \(x\),

\[\varphi_{p(e)}^A(x)\downarrow\quad\Longleftrightarrow\quad\exists\sigma\preceq A\;[\sigma\in S_e].\]

For stage \(k\), scan the finitely many numbers \(v<k\). Test validity and \(v\in W_{e,k}\). For each passing code, query the finitely many bits below its word length and check agreement with \(A\). Let a fixed oracle program \(r\) on \(\langle e,k\rangle\) return zero if any such word is a prefix of \(A\), and one otherwise. These are finite loops through total tests and queries, so the relative closure rules construct this actual total program. Define

\[P=\operatorname{comp}\bigl(\operatorname{find}'(r),\operatorname{pair}(I,\mathbf0)\bigr),\qquad p(e)=\#\operatorname{comp}(P,\mathsf{const}(e)).\]

The code map is ordinary computable and independent of \(A\). Its evaluation is the least successful stage \(k\), independently of \(x\), and diverges if no stage succeeds. A successful stage displays a prefix in \(S_e\). Conversely any such prefix has a code \(v\) in some finite stage, and hence in \(W_{e,k}\) for all sufficiently large \(k>v\). Its finite agreement test then succeeds. This proves the identity for every oracle.

Genericity is exactly the existence of finite halting decisions

A set \(G\) is 1-generic if and only if, for every oracle-program index \(e\) and input \(x\), some \(\sigma\preceq G\) forces convergence or forces divergence of \(\varphi_e(x)\).

If \(G\) is generic, apply its definition to the c.e. collection \(B_{e,x}\). Meeting that collection gives a convergence-forcing prefix. Avoiding it above a prefix is precisely forcing divergence.

Conversely assume the stated decision property and fix \(S_e\). Apply it to the actual program of index \(p(e)\) at input zero. If a prefix forces convergence, the program really halts under \(G\), so its evaluation identity proves that \(G\) meets \(S_e\). If a prefix \(\sigma\) forces divergence, no \(\rho\succeq\sigma\) can belong to \(S_e\). Indeed complete such a \(\rho\) to any infinite oracle \(A\). The program would halt under \(A\); adequacy would then give a successful certifying prefix extending \(\rho\), contrary to divergence forcing at \(\sigma\). Thus \(G\) avoids \(S_e\). These alternatives prove genericity.

For a generic oracle, convergence and divergence each have a finite witness

If \(G\) is 1-generic, then for every \(e,x\),

\[\varphi_e^G(x)\downarrow\quad\Longleftrightarrow\quad\exists\sigma\preceq G\;[\sigma\Vdash\varphi_e(x)\downarrow],\]
\[\varphi_e^G(x)\uparrow\quad\Longleftrightarrow\quad\exists\sigma\preceq G\;[\sigma\Vdash\varphi_e(x)\uparrow].\]

The convergence equivalence is prefix adequacy and certificate soundness; it holds for every oracle. For divergence, a forcing prefix always gives actual divergence by the cone argument above. In the other direction, genericity supplies one of the two finite decisions. Actual divergence excludes a convergence certificate by soundness, so the supplied decision must force divergence. The two alternatives therefore agree with the actual computation.

Search along the oracle until a halting decision appears

There is a fixed actual oracle program \(\mathsf j\) such that, for every 1-generic \(G\),

\[E_{G\oplus K}(\mathsf j,e)\downarrow=\chi_{G'}(e)\qquad\text{for every }e.\]

We specify this program on an arbitrary oracle \(A\) first. On parameters \(e,n\), use the even-position answers \(\chi_A(2i)\), \(i<n\), to build a finite word \(\sigma_{A,n}\). Compute its checker value \(D(\sigma_{A,n},e,e)\) and the ordinary number \(q(a(e,e),u_{\sigma_{A,n}})\). A fixed total oracle program \(T\) returns zero exactly when

\[D(\sigma_{A,n},e,e)>0\quad\lor\quad\chi_A\bigl(2q(a(e,e),u_{\sigma_{A,n}})+1\bigr)=0,\]

and one otherwise. All loops in this test have the supplied finite bound \(n\); the ordinary maps terminate and oracle queries return bits. A second fixed total oracle program \(V\) on \(\langle e,n\rangle\) returns one if that checker value is positive, and zero otherwise. The relative closure rules construct both programs from the stated finite operations. Set

\[U=\operatorname{comp}\bigl(\operatorname{find}'(T),\operatorname{pair}(I,\mathbf0)\bigr),\qquad\mathsf j=\operatorname{comp}\bigl(V,\operatorname{pair}(I,U)\bigr).\]

Thus under any \(A\), \(U\) searches for the least successful \(n\), and \(\mathsf j\) returns the specified Boolean checker result there. If no such \(n\) exists it diverges. This describes its complete evaluation, without supposing the arbitrary odd-position answers decide halting.

Now take \(A=G\oplus K\), with the even/odd join convention. The word \(\sigma_{A,n}\) is exactly \(G\upharpoonright n\). By the specified index maps \(a\) and \(q\), the negative odd-position answer says that this word has no extension in \(B_{e,e}\), precisely the divergence alternative. The positive-checker test is the convergence alternative. Genericity ensures that at least one prefix has one of them, so this search terminates. Their forced-truth properties and mutual exclusion say that \(V\) returns one exactly when \(\varphi_e^G(e)\downarrow\). This is exactly the characteristic function of the jump.

The jump of a generic is its join with ordinary halting

Every 1-generic set \(G\) satisfies the generalized-low identity

\[G'\equiv_T G\oplus K.\]

The fixed program in proves \(G'\le_T G\oplus K\). For the reverse reduction, membership reduces to the jump, so \(G\le_T G'\). Also \(\varnothing\le_T G\), so jump monotonicity gives \(J(\varnothing)\le_T G'\). The ordinary halting equivalence gives \(K\le_T G'\). The universal property of the join combines these two actual reductions into \(G\oplus K\le_T G'\), completing the equivalence.

If \(K\le_T B\), one can choose the generic so that \(B\equiv_T G\oplus K\). The identity above then gives \(G^{\prime}\equiv_T B\), realizing the prescribed degree as a jump.

The constructed generics are noncomputable and low

For every supplied binary word \(\rho\), the constructed set is low, meaning that its jump is Turing equivalent to \(K\), and satisfies

\[G_\rho'\equiv_T K,\qquad\varnothing<_T G_\rho<_T K.\]

We proved genericity and \(G_\rho\le_T K\). The join universal property gives \(G_\rho\oplus K\equiv_T K\), so the generalized-low identity makes \(G_\rho'\equiv_T K\), the stated lowness condition. The same definition is used in the construction of low simple sets. Generic noncomputability makes its degree positive. If \(K\le_T G_\rho\), then \(G_\rho'\le_T K\le_T G_\rho\), contradicting jump strictness. The upper comparison is therefore also strict.

A generic cannot compute a noncomputable enumerable set

If \(G\) is 1-generic, \(X\) is c.e., and \(X\le_T G\), then \(X\) is computable. In particular no 1-generic has a noncomputable c.e. degree.

Fix an actual program \(\varphi_e^G=\chi_X\). The collection

\[S=\{\sigma:\exists x\in X\;[D(\sigma,e,x)=1]\}\]

is c.e.: dovetail the enumeration of \(X\) with the decidable finite certificate tests. Here checker value one means output zero. The set \(G\) cannot meet \(S\), since soundness would give \(\varphi_e^G(x)=0\) for a member \(x\in X\), contrary to the characteristic-function identity. Genericity therefore supplies a fixed prefix \(\tau\preceq G\) above which \(S\) is avoided.

Build an ordinary decision program with this finite word \(\tau\) hard-coded. On input \(x\), dovetail two searches: look for \(x\) entering the c.e. enumeration of \(X\), and look through all valid words \(\sigma\succeq\tau\) for one with \(D(\sigma,e,x)=1\). Return one if the first search succeeds and zero if the second does. The searches have decidable finite stages, so this is an ordinary partial-recursive program.

If \(x\in X\), its enumeration eventually succeeds and avoidance excludes every certificate sought by the second search. If \(x\notin X\), totality of the given reduction gives output zero under \(G\); adequacy supplies a certifying prefix extending \(\tau\), so the second search succeeds, while the first never does. Exactly the correct search thus succeeds on each input, making the program a total decider. Finally, a c.e. set Turing equivalent to a generic would be computable by this result, making the generic computable as well, a contradiction.
