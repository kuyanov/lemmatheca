Bounds with and without finitely many exceptions

For total functions \(f,g:\mathbb N\to\mathbb N\), say that \(g\) majorizes \(f\) if \(f(n)\le g(n)\) for every \(n\). Write \(f\le^*g\) when \(g\) eventually dominates \(f\):

\[f\le^*g\quad\Longleftrightarrow\quad\exists N\;\forall n\ge N\quad f(n)\le g(n).\]

This is the same eventual order used for arbitrary families of functions. Here the proposed bound \(g\) will be required to be ordinary total computable. The threshold may depend on both functions.

A finite patch turns an eventual computable bound into a pointwise bound

A total \(f:\mathbb N\to\mathbb N\) has a total computable eventual bound if and only if it has a total computable majorant.

Suppose \(g\) is computable and \(f(n)\le g(n)\) for \(n\ge N\). Put

\[M=\max\bigl(\{0\}\cup\{f(i):i<N\}\bigr),\qquad h(n)=\max(M,g(n)).\]

The fixed natural number \(M\) can be built into a program, so \(h\) is computable. For \(n<N\), its constant part bounds \(f(n)\); for \(n\ge N\), its other part does. Conversely a pointwise bound is an eventual bound with threshold zero. This proves an existence equivalence even when the finitely many exceptional values were not supplied effectively from \(f\).

Natural-valued oracle computations and their graphs

A total function \(f:\mathbb N\to\mathbb N\) is computable from \(A\), written \(f\le_T A\), if one finite oracle program \(c\) satisfies \(E_A(c,n)\downarrow=f(n)\) for every \(n\). Define its coded graph by \(G_f=\{\langle n,y\rangle:f(n)=y\}\). The established graph-oracle bridge gives

\[f\le_T A\quad\Longleftrightarrow\quad G_f\le_T A.\]

The bridge uses actual programs: a common graph-search program retrieves the unique \(y\), and a program computing \(f\) decides \(G_f\) by computing \(f(n)\) and comparing it with \(y\). Given a set reduction \(A\le_T B\), substituting its characteristic program into \(c\) computes the same \(f\) from \(B\), by query substitution. These facts fix the meaning of the function notation; it does not introduce a second reducibility unrelated to the set model.

Functions that escape all computable bounds

A total \(f:\mathbb N\to\mathbb N\) is hyperimmune if no total computable function eventually dominates it. Equivalently, by , it has no total computable majorant. In explicit quantifiers,

\[\forall g\text{ total computable}\;\forall N\;\exists n\ge N\quad g(n)<f(n).\]

An oracle \(A\) has hyperimmune degree if it computes a hyperimmune function. It is hyperimmune-free if every total \(f\le_T A\) has a total computable eventual bound. Thus exactly one of these alternatives holds for each oracle. The bound may depend on the particular total function; no one computable function is required to bound them all.

Noncomputable hyperimmune-free oracles exist: the hyperimmune-free basis theorem gives such a path in a computable binary tree with no computable paths. Every noncomputable member with this property lies outside the sets computable from ordinary halting.

Highness has a stronger numerical characterization: one oracle-computed function eventually dominates every ordinary total computable function. It implies hyperimmune degree, while the specified low simple set separates the converse.

These properties depend only on the Turing degree

Hyperimmune degree is upward closed under \(\le_T\), and hyperimmune-freeness is downward closed. In particular both are invariant under \(\equiv_T\), and the computable degree is hyperimmune-free.

If \(A\le_T B\) and \(A\) computes a hyperimmune \(f\), the substituted program from computes that same \(f\) from \(B\). If \(B\) is hyperimmune-free and \(f\le_T A\), that substitution gives \(f\le_T B\), so a computable bound exists. Mutual reducibility gives both invariance assertions and hence properties of the Turing degrees.

When \(A\) is computable, oracle elimination converts every total \(A\)-program into an ordinary program for the same function. That function bounds itself, proving hyperimmune-freeness of the computable degree.

Enumerate an infinite set in increasing order

For an infinite \(X\subseteq\mathbb N\), its principal function \(p_X\) is the increasing enumeration starting at index zero:

\[p_X(0)=\min X,\qquad p_X(n+1)=\min\{m\in X:p_X(n)<m\}.\]

Every required minimum exists because an infinite subset of \(\mathbb N\) is unbounded. This gives a strictly increasing function with range \(X\), and \(n\le p_X(n)\). Indeed the recurrence chooses each next member with no omitted member in between; every \(x\in X\) occurs by index at most \(x\). A hyperimmune set is an infinite set whose principal function is hyperimmune.

One common oracle program computes every infinite set's principal function

There is one oracle program \(P\), chosen independently of \(X\), such that \(E_X(P,n)\downarrow=p_X(n)\) whenever \(X\) is infinite. Conversely one common program with oracle \(G_{p_X}\) decides \(X\). Hence \(G_{p_X}\equiv_T X\).

To compute the first value, query \(0,1,2,\ldots\) until a yes answer appears. To compute a successor value from \(v=p_X(n)\), query \(v+1,v+2,\ldots\) until the next yes answer. Least search and primitive recursion are constructors of the oracle program model, so these instructions specify one finite program \(P\). Induction on \(n\) proves both termination, by unboundedness of \(X\), and the displayed evaluation identity.

For the reverse reduction, on input \(x\) use the fixed graph lookup program to compute \(p_X(0),\ldots,p_X(x)\), and answer one exactly when one of them equals \(x\). These are finitely many terminating calls. Since \(p_X(n)\ge n\), a later value cannot equal \(x\), and since the range is \(X\), this is exactly \(\chi_X(x)\). Composing \(P\) with a supplied reduction for \(X\) likewise computes \(p_X\) from any oracle computing \(X\).

Disjoint finite tests supplied effectively

A strong array is a sequence \((D_n)_{n\in\mathbb N}\) of pairwise disjoint finite subsets of \(\mathbb N\), supplied by a total computable function returning a finite list code for \(D_n\). Repeated entries in an individual list do not change its set. The array hits \(X\) if \(D_n\cap X\ne\varnothing\) for every \(n\).

Having finite sets is not enough: their full finite descriptions must be computable uniformly in \(n\). In a hitting array every \(D_n\) is nonempty.

Hyperimmunity is equivalent to escaping every strong array

For an infinite set \(X\), the principal function \(p_X\) has a computable majorant if and only if some strong array hits \(X\). Consequently \(X\) is hyperimmune exactly when no strong array hits it.

Suppose \((D_n)\) hits \(X\). The union \(D_0\cup\cdots\cup D_n\) contains at least \(n+1\) distinct members of \(X\), since one can select a member in each intersection and the finite sets are disjoint. Define

\[H(n)=\max\bigl(\{0\}\cup D_0\cup\cdots\cup D_n\bigr).\]

Computing the first \(n+1\) list codes and their maximum is an ordinary terminating procedure. At least \(n+1\) members of \(X\) are at most \(H(n)\), so its member of index \(n\) satisfies \(p_X(n)\le H(n)\).

Conversely let a total computable \(h\) majorize \(p_X\). Define the computable increasing endpoints

\[b_0=0,\qquad b_{n+1}=1+\max\bigl(b_n,h(b_n)\bigr),\qquad D_n=[b_n,b_{n+1})\cap\mathbb N.\]

The displayed interval has a computable finite list and successive intervals are disjoint. Moreover \(b_n\le p_X(b_n)\le h(b_n)<b_{n+1}\). Thus \(p_X(b_n)\) is an explicit member of \(D_n\cap X\) for every \(n\). These two constructions establish the equivalence; also covers a majorant originally supplied only eventually.

A hyperimmune set has no infinite enumerable subset

Every hyperimmune set is immune.

Suppose an infinite c.e. set \(W\) were contained in \(X\). Its enumeration computes a strictly increasing sequence \(w_0,w_1,\ldots\) of elements of \(W\): wait for a first discovered element, and after choosing \(w_n\), wait for a discovered element greater than it. Each wait terminates because \(W\) is unbounded. Fixing the enumeration and its order makes this an ordinary total computable sequence.

The singleton sets \(D_n=\{w_n\}\) are a strong array hitting \(X\), contrary to . Thus no infinite c.e. subset exists; infinitude is already part of hyperimmunity.

A growing sequence can preserve every oracle bit

Given a total \(f:\mathbb N\to\mathbb N\) and a set \(A\), define the parity growth sequence \(g=g_{A,f}\) by

\[g(0)=2f(0)+\chi_A(0),\qquad g(n+1)=2\bigl(g(n)+f(n+1)+1\bigr)+\chi_A(n+1).\]

It is strictly increasing, \(f(n)\le g(n)\), and \(g(n)\bmod2=\chi_A(n)\). Its range \(X_g\) is infinite and has principal function \(p_{X_g}=g\).

The two possible bits are zero and one, so each displayed value has the asserted parity. The base value is at least \(f(0)\). At a successor, the expression exceeds \(g(n)\) and is at least \(f(n+1)\). These statements prove the inequalities by induction and show that the range is infinite. A strictly increasing sequence already lists its range in order, so it is precisely that range's principal function.

The range and the original oracle compute one another

For every actual oracle program \(c\) computing a total \(f\) from \(A\), there are programs \(C_c,R_c\) with

\[E_A(C_c,n)\downarrow=g_{A,f}(n),\qquad E_A(R_c,x)\downarrow=\chi_{X_g}(x).\]

There is also one common program \(D\), independent of \(A,f,c\), with \(E_{X_g}(D,n)\downarrow=\chi_A(n)\). Thus \(X_g\equiv_T A\); if \(f\) is hyperimmune, then \(X_g\) is hyperimmune.

Build \(C_c\) by the recurrence in . Its base calls \(c\) at zero and queries zero; its successor at \(n\) calls \(c\) at \(n+1\), queries \(n+1\), and combines those answers with the preceding numerical value. Composition, pairing, ordinary arithmetic programs and oracle primitive recursion give one finite syntax from \(c\). Induction on the counter proves exactly the asserted identity for \(C_c\).

The program \(R_c\), on input \(x\), computes this recurrence through index \(x\) and tests whether one of those values equals \(x\). Since the sequence is increasing and \(g(n)\ge n\), no larger index can equal \(x\). The test therefore returns exactly its range's characteristic bit. Both constructions use the same supplied program \(c\), rather than asking for an index of the set-theoretic function \(f\) by some separate oracle.

For \(D\), compute the principal function by the common program \(P\) of and return its parity. On \(X_g\), that principal value is \(g(n)\), whose parity is \(\chi_A(n)\). This specifies the inverse reduction by a fixed program. Finally a computable eventual bound for \(p_{X_g}=g\) would also bound \(f\), because \(f\le g\), proving the last assertion.

A hyperimmune degree contains a hyperimmune set

An oracle \(A\) has hyperimmune degree if and only if there is a hyperimmune set \(X\) with \(X\equiv_T A\). Equivalently, a Turing degree is hyperimmune-free exactly when none of its representatives is a hyperimmune set.

If \(A\) computes a hyperimmune function \(f\), gives the hyperimmune set \(X_g\) of exactly the same degree. Conversely, if \(X\equiv_T A\) is hyperimmune, its principal function is hyperimmune and is computed from \(X\) by \(P\). Substituting the supplied reduction \(X\le_T A\) into \(P\) computes that function from \(A\). The two alternatives in give the final equivalence.

The first correct prefix need not remain correct forever

Let \(a(s,x)\) be a total computable binary approximation converging pointwise to \(\chi_A(x)\), in the sense of limit computability. Its first correct prefix time is

\[r(n)=\min\{s>n:\forall x\le n\quad a(s,x)=\chi_A(x)\}.\]

The minimum exists by finite-prefix convergence. There is an actual \(A\)-oracle program \(Q_a\), built once from a supplied ordinary program for \(a\), with \(E_A(Q_a,n)\downarrow=r(n)\): search \(s=n+1,n+2,\ldots\), and at each stage compare the finitely many computed bits \(a(s,0),\ldots,a(s,n)\) with direct membership queries to \(A\). Each test terminates, and convergence guarantees a successful test.

This is a first agreement time. An approximation can later disagree again. No settling modulus or oracle test for all later stages is used.

A computable bound on the first correct times decides the limit

If a total computable \(h\) majorizes the first correct prefix time \(r\), then \(A\) is computable. More precisely, the following ordinary program, constructed from the programs for \(a,h\), is total and returns \(\chi_A(x)\): search \(n=x,x+1,\ldots\) until the bits \(a(s,x)\), for \(n<s\le h(n)\), are all equal, then return that common bit.

For every \(n\), the bound gives \(n<r(n)\le h(n)\), so the tested interval is nonempty. Its test is an ordinary finite computation: compute \(h(n)\), use \(a(n+1,x)\) as the candidate bit, and compare the remaining stages through \(h(n)\).

If a test succeeds at \(n\ge x\), its interval includes \(r(n)\). At that stage the first \(n+1\) bits agree with \(A\), so in particular \(a(r(n),x)=\chi_A(x)\). The interval's common bit is therefore correct. For termination, choose a convergence stage \(t\) for this one input \(x\). Any \(n\ge\max(x,t)\) has only correct stages in the tested interval, so its test succeeds. Least search followed by evaluation of \(a(n+1,x)\) is thus an ordinary total program for \(\chi_A\), with the claimed identity.

Every nonzero degree below halting is hyperimmune

Every noncomputable \(A\le_T K\), equivalently every noncomputable \(\Delta_2\) set, has hyperimmune degree. Consequently every noncomputable c.e. set has hyperimmune degree, and a hyperimmune-free set below \(K\) is computable. Every noncomputable low set, meaning \(A'\equiv_T K\), also has hyperimmune degree.

The limit lemma supplies a computable approximation \(a\) to \(A\). Its first correct prefix time \(r\) is total and \(A\)-computable by . A computable eventual bound for \(r\) could be patched to a computable majorant by . Then would make \(A\) computable, a contradiction. Thus \(r\) is a hyperimmune function witnessing the degree assertion. A c.e. set is limit computable, giving the stated c.e. consequence. The last conclusion is the contrapositive.

For the low-set assertion, the established reduction \(A\le_T A'\) gives \(A\le_T K\). Thus lowness does not imply hyperimmune-freeness for a noncomputable oracle.

A total oracle computation can find its own first successful allowance

Fix an actual oracle-program index \(e\) such that \(\varphi_e^A(x)\) is defined for every \(x\). Write \(b_A(k,e,x)\) for the bounded evaluator's output code, with zero for failure and \(y+1\) for output \(y\). Then

\[u_e^A(x)=\min\{k:0<b_A(k,e,x)\}\]

is a total \(A\)-computable function. A single program \(U_e\), selected before \(A\), satisfies \(E_A(U_e,x)\downarrow=u_e^A(x)\) whenever the supplied program is total relative to \(A\). Moreover, if \(u_e^A(x)\le k\) and \(\varphi_e^A(x)\downarrow=y\), then \(b_A(k,e,x)=y+1\).

The common allowance-search program on input \(\langle e,x\rangle\) runs the bounded evaluator for \(k=0,1,2,\ldots\) and returns the first positive allowance. Freezing the first parameter to \(e\) gives \(U_e\). Each bounded evaluation is itself a terminating oracle computation, so this is actual program syntax with the stated search identity. Completeness supplies a successful allowance because \(\varphi_e^A(x)\) halts. At the least successful one, soundness identifies the output with \(y\); monotonicity preserves that output at every larger allowance. This proves all assertions using the resource of the fixed evaluator.

Below a hyperimmune-free oracle, Turing computation has a truth table

If \(A\) is hyperimmune-free and \(B\le_T A\), then \(B\le_{\mathrm{tt}}A\).

Choose the actual index \(e\) for a total reduction, so \(\varphi_e^A(x)\downarrow=\chi_B(x)\). The function \(u_e^A\) in is total and \(A\)-computable. Hyperimmune-freeness and the finite patch supply a total computable \(h\) with \(u_e^A(x)\le h(x)\) for all \(x\). The evaluator identity is therefore

\[b_A(h(x),e,x)=\chi_B(x)+1.\]

This is exactly the bounded-allowance criterion for truth-table reducibility. Explicitly, give the table prefix bound \(h(x)\). On a supplied finite-word code for \(\sigma\), run the fixed finite checker with allowance \(h(x)\), program \(e\), input \(x\), and those oracle bits. Return one if its output code is two, and return zero otherwise. This is a total computable Boolean lookup for every finite word. On the actual prefix \(A\upharpoonright h(x)\), bounded query agreement makes its result exactly the displayed code, so its Boolean output is \(\chi_B(x)\).

The bound applies to a successful evaluation allowance, which also controls the finite check. A bound only on queried positions would not justify a terminating computation for the other rows of a truth table. Here every row terminates because the calculation itself is bounded.

Can an enumerable set be hyperimmune, or have hyperimmune degree?

Can an infinite c.e. set itself be hyperimmune? Can its Turing degree nevertheless contain a hyperimmune set? Give an established example for the second question.

Show answerHide answer

An infinite c.e. set is not immune, because it contains itself as an infinite c.e. subset. Hence it is not hyperimmune by . The property of a particular set is different from the property of its degree.

The ordinary halting set \(K\) is c.e. and noncomputable, so gives it hyperimmune degree. The parity construction consequently produces a hyperimmune set \(X\equiv_T K\). This \(X\) cannot itself be c.e. The example satisfies both requirements without identifying the hyperimmune representative with the original c.e. representative.

The deficiency construction gives a further distinction for every noncomputable c.e. set: its degree contains both a hypersimple c.e. representative and that representative’s hyperimmune complement. The two complementary sets have the same degree, although only the complement is hyperimmune.
