Finite conditions on many binary columns

Let \(M\) be an externally countable transitive set model of ZFC, with the ground-model and forcing conventions already in force. Write \(\kappa\) for \(\omega_2^M\). A binary real is a function \(\omega\to2\), identified with the subset of \(\omega\) where its value is one. Thus the number of binary reals in a model is its \(2^{\aleph_0}\).

The many-coordinate Cohen order is the order that \(M\) forms as

\[P=\operatorname{Fn}(\omega\times\kappa,2,{<}\omega).\]

A condition is a finite partial binary function on the displayed product. Regard \(n\) as a row and \(\alpha<\kappa\) as a column; write \(p(n,\alpha)=b\) when \(p\) assigns bit \(b\) there. The order is reverse inclusion: \(q\le p\) means that \(q\) extends every assignment of \(p\). The largest condition \(1_P\) is the empty map.

These descriptions have the same members inside and outside \(M\). All coordinates and bits of an externally finite such map belong to \(M\), so Pairing and Union build its graph in \(M\). Conversely an internally finite domain is actually finite by transitivity. The function, coordinate and value tests are bounded tests. Power Set and Separation inside \(M\) collect the conditions into \(P\in M\), just as for the one-column Cohen order.

The column index remains the second uncountable cardinal

The ground model regards \(P\) as ccc. For every \(M\)-generic filter \(G\subseteq P\), the models \(M\) and \(M[G]\) have the same cardinals and cofinalities. In particular,

\[\omega_1^{M[G]}=\omega_1^M,\qquad \omega_2^{M[G]}=\kappa.\]

Apply ccc for arbitrary finite binary maps inside \(M\) to its set \(\omega\times\kappa\). The delta-system proof works for this index set without a size restriction. Hence the hypothesis is the required internal statement \(M\models\text{“}P\text{ is ccc”}\).

The cardinal and cofinality preservation theorems now apply. The models have the same ordinals and the same cardinal ordinals. They therefore select the same first and second uncountable cardinals from that common order. This proves the displayed identities. External countability of \(P\) alone would not give this conclusion.

The generic union fills every row and column

Let \(G\subseteq P\) be \(M\)-generic. Its graph union \(u=\bigcup G\) is a total function \(\omega\times\kappa\to2\), and every \(p\in G\) is a restriction of \(u\). For each \(\alpha<\kappa\), define its column real by \(c_\alpha(n)=u(n,\alpha)\).

Any two conditions in \(G\) have a common stronger member in \(G\). It extends both, so their assignments agree wherever both are defined. Thus the graph union is a partial function and contains every condition in the filter.

For each \(n\in\omega\) and \(\alpha<\kappa\), let

\[D_{n,\alpha}=\{p\in P:(n,\alpha)\in\operatorname{dom}(p)\}.\]

This set belongs to \(M\) by Separation with its displayed parameters. It is dense: a condition already assigning that coordinate belongs to it; otherwise append value zero at that coordinate. The new finite map belongs to \(M\) and extends the old condition. Genericity gives \(G\cap D_{n,\alpha}\ne\varnothing\), so \(u\) is defined at \((n,\alpha)\). This holds for every coordinate. It is the same totality mechanism as the one-column union proof.

Each column is the value of an explicit ground-model name

For each \(\alpha<\kappa\), define the coordinate name using the check names and ordered-pair name \(\operatorname{op}\):

\[\dot c_\alpha=\{(\operatorname{op}(\check n,\check b),p):p\in P,\ n\in\omega,\ p(n,\alpha)=b\}.\]

It is a \(P\)-name belonging to \(M\), and \(\dot c_\alpha[G]\) is exactly the graph of \(c_\alpha\). In particular, each column real belongs to \(M[G]\).

Inside \(M\), first use Separation on \(P\times\omega\times2\) to select the triples with \(p(n,\alpha)=b\). Check names and ordered-pair names are constructed there; Replacement collects their displayed attachments. Each attached first component is a \(P\)-name, so the recursive name definition makes \(\dot c_\alpha\) a \(P\)-name in \(M\).

Evaluating an active attachment, with \(p\in G\), gives the ordered pair \((n,b)\). Therefore its value consists exactly of the pairs \((n,b)\) assigned in column \(\alpha\) by some condition in \(G\). By , these are exactly the pairs \((n,c_\alpha(n))\). The definition of the extension then puts this graph in \(M[G]\), which recognizes it as a function \(\omega\to2\). This is the coordinate version of the earlier Cohen-real name.

A fresh row separates any two distinct columns

If \(\alpha,\beta<\kappa\) and \(\alpha\ne\beta\), then \(c_\alpha\ne c_\beta\).

For these fixed distinct indices, put

\[E_{\alpha,\beta}=\{p\in P:\exists n\ (p(n,\alpha)\text{ and }p(n,\beta)\text{ are defined and unequal})\}.\]

The defining search can be bounded by the finite domain of \(p\), so Separation gives \(E_{\alpha,\beta}\in M\). Given a condition \(p\), only finitely many rows occur in either of its columns \(\alpha,\beta\). Choose \(n\) outside that finite union. Extend \(p\) by assigning zero at \((n,\alpha)\) and one at \((n,\beta)\). The two coordinates are distinct because \(\alpha\ne\beta\), and neither had an old assignment. Their union with \(p\) is therefore a condition in \(M\) extending \(p\), and lies in \(E_{\alpha,\beta}\).

Genericity supplies \(q\in G\cap E_{\alpha,\beta}\). Its witnessing row \(n\) has unequal assigned bits in the two columns. Since \(q\subseteq u\), those bits are \(c_\alpha(n)\) and \(c_\beta(n)\). Thus the column reals differ. No condition is required to separate all pairs at once; the generic filter meets the separate ground dense set for each pair.

Every column differs from every old binary real

For each \(\alpha<\kappa\) and each binary real \(f\in M\), we have \(c_\alpha\ne f\). Consequently \(c_\alpha\notin M\).

Let \(E_{\alpha,f}\) contain those conditions assigning, in column \(\alpha\), a bit different from \(f(n)\) at some row \(n\). This set belongs to \(M\) by Separation using \(\alpha,f\in M\). It is dense: given \(p\), choose a row not used by \(p\) in that column and append the opposite bit \(1-f(n)\). All parameters and the resulting finite graph belong to \(M\).

A condition in \(G\cap E_{\alpha,f}\) has a witnessing row, and \(u\) retains its bit, proving \(c_\alpha\ne f\). If \(c_\alpha\) itself belonged to \(M\), the bounded function, domain and value tests would make it one of \(M\)'s binary reals, contradicting the conclusion for that \(f\). This repeats the old-real disagreement argument separately in each column.

The whole family is a function inside the extension

The map \(F:\kappa\to(2^\omega)^{M[G]}\) given by \(F(\alpha)=c_\alpha\) belongs to \(M[G]\). It is the value of the explicit column-family name

\[\dot F=\{(\operatorname{op}(\check\alpha,\dot c_\alpha),1_P):\alpha<\kappa\}.\]

This map is injective. Its membership in the extension, in addition to injectivity as an external map, is what permits a cardinal comparison inside \(M[G]\).

The construction of \(\dot c_\alpha\) is uniform in \(\alpha\) inside \(M\). Replacement there collects that family of names and then the displayed attachments over the set \(\kappa\in M\). Ordered-pair names again give a \(P\)-name \(\dot F\in M\).

The largest condition \(1_P\) belongs to every filter, by nonemptiness and upward closure. All these attachments are therefore active. Their values are exactly \((\alpha,c_\alpha)\), so \(\dot F[G]\) is the graph of the specified function \(F\). Its domain is the old ordinal \(\kappa\), whose elements are unchanged, and its values are binary reals by . The extension recognizes these function properties, and proves its injectivity there.

Many Cohen reals give a model in which CH fails

Every externally countable transitive set model \(M\models\mathrm{ZFC}\) has an externally countable transitive generic extension \(N\models\mathrm{ZFC}\) with the same cardinals and cofinalities and satisfying

\[N\models 2^{\aleph_0}\ge\aleph_2\quad\text{and hence}\quad N\models\neg\mathrm{CH}.\]

For the order above, every \(M\)-generic \(G\) gives such \(N=M[G]\), and the family \((c_\alpha)_{\alpha<\omega_2^M}\) consists of distinct binary reals outside \(M\).

The ground-model hypothesis supplies an \(M\)-generic filter for its order \(P\). The generic-extension theorem makes \(M[G]\) an externally countable transitive ZFC-model. By , its cardinal \(\omega_2\) is the same ordinal \(\kappa=\omega_2^M\), and all other cardinals and cofinalities are preserved too.

The named injection in belongs to this extension and sends \(\kappa\) into its binary reals. Thus \(M[G]\) computes \(\kappa\le 2^{\aleph_0}\). Since \(\kappa\) is its second uncountable cardinal, this contradicts CH. The newness of every column gives the final assertion.

The hypothesis here is existence of an externally countable transitive ZFC-model. A model obtained from mere consistency by completeness need not be transitive or well founded, as the relative-consistency discussion explains. The construction proves the stated model theorem under its actual hypothesis.

Why not use only one or countably many columns?

Replace \(\kappa\) by \(1\), or by \(\omega\), in the construction. What cardinal lower bound does the injection of columns supply? Is that lower bound enough to refute CH?

It supplies only \(1\le 2^{\aleph_0}\), or \(\aleph_0\le2^{\aleph_0}\), respectively. The coordinate totality, newness and pair-separation proofs still apply, but these two lower bounds are already weaker than Cantor's uncountability theorem. They are compatible with \(2^{\aleph_0}=\aleph_1\) and do not refute CH.

Using \(\omega_2^M\) provides the needed uncountable index strictly above the extension's \(\omega_1\), and ccc preservation ensures that it remains there. Producing a new real and producing this particular cardinal lower bound are different conclusions.

Does the construction determine the exact continuum?

Suppose the ground model additionally satisfies \(2^{\aleph_0}\ge\aleph_3\). What lower bound holds in the many-coordinate extension? Can the preceding argument then give \(2^{\aleph_0}=\aleph_2\)?

Show answerHide answer

All old binary reals remain binary reals in the extension. In \(M\), choose an injection from \(\omega_3^M\) into its set of binary reals, using the extra cardinal assumption. The graph of this injection belongs to \(M\) and remains an injection in \(M[G]\). Cardinal preservation identifies \(\omega_3^M\) with \(\omega_3^{M[G]}\). Thus the extension also satisfies \(2^{\aleph_0}\ge\aleph_3\), so equality with \(\aleph_2\) is impossible under this extra hypothesis.

The general conclusion of is a lower bound. An exact upper bound would need additional counting of names and suitable assumptions on ground cardinal arithmetic; it is not supplied by the coordinate injection.
