A carrier closed under the interpreted functions

Fix a nonempty \(L\)-structure \(M\). A function-closed carrier in \(M\) is a subset \(C\subseteq |M|\) such that, for every \(n\)-ary function symbol \(f\) and every tuple \(\bar a\in C^n\),

\[f^M(\bar a)\in C.\]

This includes arity zero: the unique empty tuple forces the value of each constant into \(C\). Relation symbols impose no closure requirement. The whole domain is function-closed. A function-closed carrier may be empty; we reserve the word structure for a nonempty domain, as throughout these entries. When \(C\ne\varnothing\), restricting the functions and relations gives the substructure defined next.

Keeping the interpreted operations and relations

A substructure \(A\subseteq M\) has a nonempty function-closed carrier \(|A|\subseteq|M|\). Functions and relations in \(A\) are the restrictions of those in \(M\). Thus, for a \(k\)-ary relation symbol \(R\),

\[R^A=R^M\cap|A|^k.\]

For a function symbol \(f\), closure says that \(f^M(a_0,\ldots,a_{k-1})\in|A|\) whenever all the arguments belong to \(|A|\), and its value in \(A\) is the same element. A zero-argument function is a constant, so this condition includes constants.

In a language with just the strict-order relation \(<\), the positive natural numbers form a substructure of \((\mathbb N,<)\). However, the formula \(\exists y\,(y<x)\) is true at \(x=1\) in \(\mathbb N\), using the witness \(0\), and false in the positive-natural substructure. Restricting the domain can remove witnesses.

The carrier generated by a set of parameters

For any \(A\subseteq |M|\), the carrier generated by \(A\) is

\[\langle A\rangle_M=\bigcap\{C\subseteq |M|:A\subseteq C\text{ and }C\text{ is function-closed}\}.\]

The family being intersected contains \(|M|\), so it is nonempty. We also call this the function closure of \(A\). When the generated carrier is nonempty, its induced structure is the substructure generated by \(A\). The notation \(\langle A\rangle_M\) will always name the carrier, including when it is empty.

The generated carrier is the smallest function-closed carrier containing the parameters

For every \(A\subseteq |M|\), the set \(\langle A\rangle_M\) contains \(A\), is function-closed, and is contained in every function-closed carrier containing \(A\). Consequently, for every function-closed \(C\),

\[\langle A\rangle_M\subseteq C\quad\Longleftrightarrow\quad A\subseteq C.\]

Every intersected carrier contains \(A\), proving the first claim. If all entries of a tuple lie in the intersection, they lie in each carrier \(C\) in the family. Its interpreted function value lies in each such \(C\), and hence in the intersection. This also applies to the empty tuple, so the intersection contains every constant value. Finally an intersection is contained in each of its constituent sets. If \(\langle A\rangle_M\subseteq C\), then \(A\subseteq C\) because \(A\subseteq\langle A\rangle_M\). Conversely, if \(A\subseteq C\) and \(C\) is function-closed, then \(C\) is one of the intersected carriers, so \(\langle A\rangle_M\subseteq C\).

The generated elements are exactly the values of terms in finitely many parameters

An element \(b\in |M|\) belongs to \(\langle A\rangle_M\) if and only if there are a finite \(n\), a tuple \(\bar a\in A^n\), and an \(L\)-term \(t(x_0,\ldots,x_{n-1})\) such that

\[b=t^M[\bar a].\]

The tuple may repeat elements, and variables in its context may be unused. The case \(n=0\) includes all ground terms, meaning terms with no variables.

Let \(V\) be the set of displayed term values. Induction on terms shows that every function-closed carrier containing \(A\) contains \(V\): variables take their values in \(A\), and the function step uses closure. Thus \(V\subseteq\langle A\rangle_M\).

Conversely, \(A\subseteq V\) by the one-variable term \(x_0\). The set \(V\) is function-closed. Indeed, for an \(r\)-ary symbol \(f\) and inputs \(b_0,\ldots,b_{r-1}\in V\), choose terms and finite parameter tuples representing them. Concatenate those finitely many parameter tuples into one finite tuple. Rename each term's variables to the positions of its own block in this tuple, using term relabeling. Applying \(f\) to the resulting terms gives a term with value \(f^M(\bar b)\). If \(r=0\), this is the ground term \(f()\), using the empty parameter tuple. Therefore minimality gives \(\langle A\rangle_M\subseteq V\), proving equality.

Empty parameters, ground terms and relational languages

The set \(\langle\varnothing\rangle_M\) consists exactly of ground-term values. It is empty when \(L\) has no constant symbols, and is nonempty when \(L\) has a constant symbol. If \(A\ne\varnothing\), then \(\langle A\rangle_M\ne\varnothing\). In a language with no function symbols at any arity, \(\langle A\rangle_M=A\) for every \(A\).

In the term description, an empty parameter set admits a tuple only when \(n=0\). These are exactly the ground terms. A constant itself supplies such a term. Without constants no ground term exists: induct on a purported term. There is no variable in the empty context; a zero-arity function would be a constant, while a function of positive arity has a first subterm, contradicting the induction hypothesis for that subterm.

A nonempty parameter set is contained in its generated carrier, so its carrier is nonempty. With no function symbols, every set is function-closed, and minimality gives \(\langle A\rangle_M=A\). In particular, an empty generated carrier is legitimate closure data, but it is not a nonempty model.

An embedding retains all the interpreted operations and relations

An embedding \(f:M\hookrightarrow N\) between nonempty \(L\)-structures is an injective map satisfying, for every function symbol \(g\), relation symbol \(R\), and tuple of the appropriate finite arity,

\[f(g^M(\bar a))=g^N(f\bar a),\qquad M\models R[\bar a]\ \Longleftrightarrow\ N\models R[f\bar a].\]

Here \(f\bar a\) means applying \(f\) to each coordinate. The function condition includes constants. The relation condition includes both preservation and reflection, not just the forward implication. A substructure inclusion is an embedding. An isomorphism is a bijective embedding, agreeing with the earlier definition.

An embedding is an isomorphism onto its image

For an embedding \(f:M\hookrightarrow N\), the image \(f[M]\) is the carrier of a nonempty substructure of \(N\), and the specified map \(a\mapsto f(a)\), with codomain restricted to that image, is an isomorphism. Conversely, an isomorphism from \(M\) to a substructure of \(N\), followed by inclusion, is an embedding.

The image is nonempty because \(M\) is. For a tuple in the image, choose preimages of its finitely many entries. Preservation of a function value shows that the corresponding value in \(N\) is the image of a value in \(M\). This includes constants, so the image is function-closed and has its induced substructure. The restricted map is onto the image and is injective. It preserves functions and preserves and reflects relations by the embedding conditions, so it is an isomorphism. Conversely, both the isomorphism and the inclusion preserve functions and preserve and reflect relations, and their composite is injective; their composite is therefore an embedding.

What an embedding already preserves

For an embedding \(f:M\hookrightarrow N\), every term and every quantifier-free formula satisfy

\[f(t^M[\bar a])=t^N[f\bar a],\qquad M\models\theta[\bar a]\ \Longleftrightarrow\ N\models\theta[f\bar a].\]

A quantifier-free formula is built without quantifiers. In particular, substructure inclusions preserve and reflect all such formulas.

Induct on terms. A variable transports by definition, and the function step uses preservation of the interpreted function. Injectivity then gives agreement on equalities; preservation and reflection of the interpreted relations gives agreement on atomic relation formulas. The logical connectives preserve this agreement by induction, with no quantifier case needed.

The positive-natural substructure in shows why agreement cannot simply be extended to all formulas.

Atomic formulas recognize the embeddings

A specified map \(f:|M|\to|N|\) between nonempty structures is an embedding if and only if it preserves and reflects every atomic formula at every finite tuple. Equivalently, it preserves every literal, meaning an atomic formula or its negation.

For an embedding, quantifier-free agreement includes the atoms and their negations. Conversely, agreement on \(x=y\) makes \(f\) injective. Apply preservation to the true atomic formula \(y=g(\bar x)\), with \(y\) assigned \(g^M(\bar a)\), to obtain preservation of the function value. This includes constants. Agreement on atomic relation formulas gives preservation and reflection of every relation. These are precisely the embedding conditions.

Finally, preserving both an atomic formula and its negation gives agreement on the atomic formula: if it were false in \(M\) and true in \(N\), preservation of its negation would give a contradiction. Thus preserving literals is equivalent to atomic agreement.

Agreement for every formula with parameters

A substructure \(A\subseteq M\) is an elementary substructure, written \(A\preccurlyeq M\), if for every formula \(\varphi(x_0,\ldots,x_{n-1})\) and every tuple \(\bar a\in|A|^n\),

\[A\models\varphi[\bar a]\quad\Longleftrightarrow\quad M\models\varphi[\bar a].\]

The brackets specify the values of all free variables occurring in the formula, using the satisfaction convention. Bound variables still range over the domain of the structure in which the formula is evaluated. We also call \(A\) an elementary submodel of \(M\), and \(M\) an elementary extension of \(A\).

Taking \(n=0\) gives agreement on every sentence. Hence \(A\) and \(M\) satisfy exactly the same theories. Structures agreeing on all sentences are called elementarily equivalent; elementarity of an inclusion requires the stronger agreement with parameters. If \(A\preccurlyeq M\), then \(A\) and \(M\) need not have the same cardinality.

Transporting parameters by an elementary embedding

A map \(h:|A|\to|M|\) is an elementary embedding if, for every formula and parameter tuple,

\[A\models\varphi[\bar a]\quad\Longleftrightarrow\quad M\models\varphi[h(\bar a)].\]

Here \(h(\bar a)\) means apply \(h\) to each coordinate. This condition implies injectivity: apply it to \(x_0=x_1\). It also preserves and reflects relations, by applying it to relation formulas. Applying it to \(y=f(x_0,\ldots,x_{k-1})\), with \(y\) assigned the function value in \(A\), gives

\[h(f^A(\bar a))=f^M(h(\bar a)).\]

Thus \(h\) is an ordinary embedding, so its image is a substructure isomorphic to its source. The image is elementary, using isomorphism invariance. Conversely, an isomorphism onto an elementary substructure gives an elementary embedding. In particular, the inclusion of an elementary substructure is elementary, and every isomorphism is elementary.

Consequently every isomorphism is an elementary embedding, and every elementary embedding is an ordinary embedding. The identity is elementary. A composite of elementary embeddings is elementary by composing their formula equivalences. Taking sentences also shows that an elementary embedding makes its source and target elementarily equivalent.

The Tarski–Vaught witness criterion

A nonempty substructure \(A\subseteq M\) is elementary if and only if the following holds: whenever \(\bar a\) is a finite tuple from \(A\) and

\[M\models\exists y\,\psi[\bar a,y],\]

there is \(b\in|A|\) such that \(M\models\psi[\bar a,b]\). The formula \(\psi\) may contain further quantifiers. All truth assertions in this witness condition concern the ambient structure \(M\).

If \(A\preccurlyeq M\), the existential formula is true in \(A\). Choose its witness \(b\in|A|\), then use elementarity once more on the body to obtain \(M\models\psi[\bar a,b]\).

Conversely, assume the witness condition. Induct on formulas to prove agreement in the two structures. The atomic cases and logical connectives are as in . For an existential formula, a witness in \(A\) satisfies the body in \(M\) by induction, so truth in \(A\) implies truth in \(M\). In the other direction, the witness condition supplies \(b\in|A|\) satisfying the body in \(M\), and induction makes the body true in \(A\). This proves existential agreement. The universal case follows from the quantifier-duality equivalence between \(\forall y\,\chi\) and \(\neg\exists y\,\neg\chi\), or by the same argument applied to a counterexample.

Choosing functions that supply witnesses

We work in the surrounding mathematics with the axiom of choice. Choose \(m_*\in|M|\). For every formula \(\psi(\bar x,y)\), choose a function \(w_\psi:|M|^n\to|M|\) such that

\[M\models\exists y\,\psi[\bar a,y]\quad\Longrightarrow\quad M\models\psi[\bar a,w_\psi(\bar a)].\]

If no witness exists for a tuple, set the value to \(m_*\). These selected witness functions, often called Skolem functions for \(M\), need not have graphs definable by formulas of \(L\). The witness-function construction supplies these choices; Skolemization of a sentence additionally represents the choices by fresh function symbols. Here they are chosen functions used to close a subset of \(M\).

If a nonempty subset is closed under these functions, it contains all constants and is closed under the original functions as well. For a constant use the formula \(y=c\), whose unique witness is \(c^M\). For an interpreted function use \(y=f(\bar x)\), whose unique witness at \(\bar a\) is \(f^M(\bar a)\).

Closing a prescribed set under witnesses

Given \(X\subseteq|M|\), put \(X_0=X\cup\{m_*\}\), and recursively define

\[X_{r+1}=X_r\cup\{w_\psi(\bar a):\psi(\bar x,y)\text{ is an }L\text{-formula and }\bar a\in X_r^n\}.\]

Then \(A=\bigcup_{r<\omega}X_r\) is the domain of an elementary substructure of \(M\) containing \(X\).

The seed makes \(A\) nonempty. Every finite tuple from \(A\) lies in one stage: take the largest of the finitely many indices at which its coordinates enter. The empty tuple is available at every stage. Its selected witness therefore belongs to the next stage, so \(A\) is closed under every witness function. By it is a substructure. For any existential formula true in \(M\) with parameters in \(A\), its selected witness lies in \(A\). Now apply .

Representing witness choices by function symbols throughout an iterated language expansion leads to elementary Skolem hulls, the generated structures used with indiscernible skeletons.

A countable language gives countable elementary submodels

If \(L\) has at most countably many nonlogical symbols, \(M\) is a nonempty \(L\)-structure, and \(X\subseteq|M|\) is countable, then some countable elementary substructure \(A\preccurlyeq M\) contains \(X\). Here countable includes finite.

Use . The variables, logical symbols and nonlogical symbols form a countable alphabet. Its finite strings form a countable set: each fixed-length set is countable by finite products, and take a countable union over lengths. Formulas, with their finite lists of parameter variables, form a subset of this set.

Inductively, if \(X_r\) is countable, its finite tuples form a countable set by the same argument. The requests consisting of a formula and a tuple are countable, and their selected witnesses form a countable image. Thus \(X_{r+1}\) is countable. Finally \(A\) is a countable union of countable sets.

For example, apply this to the real-number strict-order structure and the prescribed set \(X=\mathbb Z\cup\{\pi\}\). There is a countable elementary substructure whose domain contains those numbers. It must contain additional elements: \(0,1\in X\), and \(\mathbb R\models\exists y\,(0<y\land y<1)\), but no member of \(X\) lies strictly between \(0\) and \(1\). Thus \(X\) itself fails the witness criterion.

The general downward Löwenheim–Skolem bound

Let \(|L|\) denote the cardinality of the set of nonlogical symbols. For every nonempty \(L\)-structure \(M\) and \(X\subseteq|M|\), there is \(A\preccurlyeq M\) containing \(X\) with

\[|A|\le\lambda:=\max(\aleph_0,|L|,|X|).\]

More precisely, if \(\lambda\le\kappa\le|M|\), there is such an \(A\) with \(|A|=\kappa\).

The witness-closure construction still works. Since \(\lambda\) is infinite, an alphabet of size at most \(\lambda\) has at most \(\lambda\) finite strings: for each positive finite length use finite powers of an infinite cardinal, then use \(\lambda\cdot\aleph_0=\lambda\). The empty string contributes one element. Thus there are at most \(\lambda\) formulas and parameter-variable lists.

If \(|X_r|\le\lambda\), there are at most \(\lambda\) finite tuples from \(X_r\). Consequently there are at most \(\lambda\cdot\lambda=\lambda\) witness requests, and at most \(\lambda\) chosen values. The same bound holds at the next stage and at the countable union of all stages. This proves the upper bound.

For the exact-size assertion, choose \(Y\subseteq|M|\) of size \(\kappa\), possible because \(\kappa\le|M|\). Start the construction from \(X\cup Y\). Its size is at most \(\kappa\), so the upper-bound argument gives \(|A|\le\kappa\), while \(Y\subseteq A\) gives \(\kappa\le|A|\). Hence \(|A|=\kappa\).

Could the elementary submodel of an infinite structure be finite?

The countable theorem allows finite domains in its conclusion. If \(M\) is infinite, could its elementary substructure \(A\) be finite?

Show answerHide answer

No. An elementary substructure of an infinite structure is infinite.

For each positive integer \(n\), the sentence

\[\exists x_0\cdots\exists x_{n-1}\;\bigwedge_{i<j<n}x_i\ne x_j\]

says that there are at least \(n\) distinct elements. The conjunction is true when it is empty. An infinite \(M\) satisfies every such sentence, so an elementary \(A\) does too. If \(|A|=k\), the sentence for \(n=k+1\) fails by the finite pigeonhole principle, a contradiction. Therefore a countable elementary substructure of an infinite structure is countably infinite.

Can the implications between the three kinds of maps be reversed?

Must an embedding be elementary? Must an elementary embedding be an isomorphism onto its whole target?

Show answerHide answer

Neither converse holds.

The inclusion of the positive natural numbers into the natural numbers, with strict order alone, is an embedding but is not elementary, by the missing-predecessor example.

Apply downward Löwenheim–Skolem to \((\mathbb R,<)\). It gives a nonempty countable \(A\preccurlyeq(\mathbb R,<)\). Its inclusion is an elementary embedding. The real line is uncountable, so this countable image is not the whole target. The inclusion is therefore not an isomorphism onto \(\mathbb R\).
