Keeping the interpreted operations and relations

Fix a nonempty first-order structure \(M\) in a language \(L\). A substructure \(A\subseteq M\) has a nonempty domain \(|A|\subseteq|M|\), contains the value of every constant, and is closed under every interpreted function. Functions and relations in \(A\) are the restrictions of those in \(M\). Thus, for a \(k\)-ary relation symbol \(R\),

\[R^A=R^M\cap|A|^k.\]

For a function symbol \(f\), closure says that \(f^M(a_0,\ldots,a_{k-1})\in|A|\) whenever all the arguments belong to \(|A|\), and its value in \(A\) is the same element. A zero-argument function is a constant, so this condition includes constants.

In a language with just the strict-order relation \(<\), the positive natural numbers form a substructure of \((\mathbb N,<)\). However, the formula \(\exists y\,(y<x)\) is true at \(x=1\) in \(\mathbb N\), using the witness \(0\), and false in the positive-natural substructure. Restricting the domain can remove witnesses.

What a substructure already preserves

If \(A\subseteq M\), terms evaluated at elements of \(A\) have the same values in both structures. Every quantifier-free formula, meaning a formula built without quantifiers, also has the same truth value at such parameters.

Proof

Induct on terms. A variable has the specified value in \(A\), and a function applied to equal argument values has the same value by restriction. Closure ensures that this value stays in \(A\). Equality and relation formulas therefore agree. The clauses for the logical connectives then preserve agreement by induction. No quantifier clause is needed. □

Agreement for every formula with parameters

A substructure \(A\subseteq M\) is an elementary substructure, written \(A\preccurlyeq M\), if for every formula \(\varphi(x_0,\ldots,x_{n-1})\) and every tuple \(\bar a\in|A|^n\),

\[A\models\varphi[\bar a]\quad\Longleftrightarrow\quad M\models\varphi[\bar a].\]

The brackets specify the values of all free variables occurring in the formula, using the satisfaction convention. Bound variables still range over the domain of the structure in which the formula is evaluated. We also call \(A\) an elementary submodel of \(M\), and \(M\) an elementary extension of \(A\).

Taking \(n=0\) gives agreement on every sentence. Hence \(A\) and \(M\) satisfy exactly the same theories. Structures agreeing on all sentences are called elementarily equivalent; elementarity of an inclusion requires the stronger agreement with parameters. If \(A\preccurlyeq M\), then \(A\) and \(M\) need not have the same cardinality.

Transporting parameters by an elementary embedding

A map \(h:|A|\to|M|\) is an elementary embedding if, for every formula and parameter tuple,

\[A\models\varphi[\bar a]\quad\Longleftrightarrow\quad M\models\varphi[h(\bar a)].\]

Here \(h(\bar a)\) means apply \(h\) to each coordinate. This condition implies injectivity: apply it to \(x_0=x_1\). It also preserves and reflects relations, by applying it to relation formulas. Applying it to \(y=f(x_0,\ldots,x_{k-1})\), with \(y\) assigned the function value in \(A\), gives

\[h(f^A(\bar a))=f^M(h(\bar a)).\]

Thus the image is a substructure, and \(h\) is an isomorphism onto it. The image is elementary, using isomorphism invariance. Conversely, an isomorphism onto an elementary substructure gives an elementary embedding. In particular, the inclusion of an elementary substructure is elementary, and every isomorphism is elementary.

The identity is elementary. A composite of elementary embeddings is elementary by composing their formula equivalences. Taking sentences also shows that an elementary embedding makes its source and target elementarily equivalent.

The Tarski–Vaught witness criterion

A nonempty substructure \(A\subseteq M\) is elementary if and only if the following holds: whenever \(\bar a\) is a finite tuple from \(A\) and

\[M\models\exists y\,\psi[\bar a,y],\]

there is \(b\in|A|\) such that \(M\models\psi[\bar a,b]\). The formula \(\psi\) may contain further quantifiers. All truth assertions in this witness condition concern the ambient structure \(M\).

Proof

If \(A\preccurlyeq M\), the existential formula is true in \(A\). Choose its witness \(b\in|A|\), then use elementarity once more on the body to obtain \(M\models\psi[\bar a,b]\).

Conversely, assume the witness condition. Induct on formulas to prove agreement in the two structures. The atomic cases and logical connectives are as in . For an existential formula, a witness in \(A\) satisfies the body in \(M\) by induction, so truth in \(A\) implies truth in \(M\). In the other direction, the witness condition supplies \(b\in|A|\) satisfying the body in \(M\), and induction makes the body true in \(A\). This proves existential agreement. The universal case follows from \(\forall y\,\chi\) being equivalent to \(\neg\exists y\,\neg\chi\), or by the same argument applied to a counterexample. □

Choosing functions that supply witnesses

We work in the surrounding mathematics with the axiom of choice. Choose \(m_*\in|M|\). For every formula \(\psi(\bar x,y)\), choose a function \(w_\psi:|M|^n\to|M|\) such that

\[M\models\exists y\,\psi[\bar a,y]\quad\Longrightarrow\quad M\models\psi[\bar a,w_\psi(\bar a)].\]

If no witness exists for a tuple, set the value to \(m_*\). These selected witness functions, often called Skolem functions for \(M\), need not be definable by formulas of \(L\). They are chosen functions used in our construction, rather than an assertion about which axioms \(M\) satisfies.

If a nonempty subset is closed under these functions, it contains all constants and is closed under the original functions as well. For a constant use the formula \(y=c\), whose unique witness is \(c^M\). For an interpreted function use \(y=f(\bar x)\), whose unique witness at \(\bar a\) is \(f^M(\bar a)\).

Closing a prescribed set under witnesses

Given \(X\subseteq|M|\), put \(X_0=X\cup\{m_*\}\), and recursively define

\[X_{r+1}=X_r\cup\{w_\psi(\bar a):\psi(\bar x,y)\text{ is an }L\text{-formula and }\bar a\in X_r^n\}.\]

Then \(A=\bigcup_{r<\omega}X_r\) is the domain of an elementary substructure of \(M\) containing \(X\).

Proof

The seed makes \(A\) nonempty. Every finite tuple from \(A\) lies in one stage: take the largest of the finitely many indices at which its coordinates enter. The empty tuple is available at every stage. Its selected witness therefore belongs to the next stage, so \(A\) is closed under every witness function. By it is a substructure. For any existential formula true in \(M\) with parameters in \(A\), its selected witness lies in \(A\). Now apply . □

A countable language gives countable elementary submodels

If \(L\) has at most countably many nonlogical symbols, \(M\) is a nonempty \(L\)-structure, and \(X\subseteq|M|\) is countable, then some countable elementary substructure \(A\preccurlyeq M\) contains \(X\). Here countable includes finite.

Proof

Use . The variables, logical symbols and nonlogical symbols form a countable alphabet. Its finite strings form a countable set: each fixed-length set is countable by finite products, and take a countable union over lengths. Formulas, with their finite lists of parameter variables, form a subset of this set.

Inductively, if \(X_r\) is countable, its finite tuples form a countable set by the same argument. The requests consisting of a formula and a tuple are countable, and their selected witnesses form a countable image. Thus \(X_{r+1}\) is countable. Finally \(A\) is a countable union of countable sets. □

For example, apply this to the real-number strict-order structure and the prescribed set \(X=\mathbb Q\cup\{\pi\}\). There is a countable elementary substructure whose domain contains those numbers. The theorem does not identify that domain with \(X\): additional witnesses may have to be included.

The general downward Löwenheim–Skolem bound

Let \(|L|\) denote the cardinality of the set of nonlogical symbols. For every nonempty \(L\)-structure \(M\) and \(X\subseteq|M|\), there is \(A\preccurlyeq M\) containing \(X\) with

\[|A|\le\lambda:=\max(\aleph_0,|L|,|X|).\]

More precisely, if \(\lambda\le\kappa\le|M|\), there is such an \(A\) with \(|A|=\kappa\).

Proof

The witness-closure construction still works. Since \(\lambda\) is infinite, an alphabet of size at most \(\lambda\) has at most \(\lambda\) finite strings: for each positive finite length use finite powers of an infinite cardinal, then use \(\lambda\cdot\aleph_0=\lambda\). The empty string contributes one element. Thus there are at most \(\lambda\) formulas and parameter-variable lists.

If \(|X_r|\le\lambda\), there are at most \(\lambda\) finite tuples from \(X_r\). Consequently there are at most \(\lambda\cdot\lambda=\lambda\) witness requests, and at most \(\lambda\) chosen values. The same bound holds at the next stage and at the countable union of all stages. This proves the upper bound.

For the exact-size assertion, choose \(Y\subseteq|M|\) of size \(\kappa\), possible because \(\kappa\le|M|\). Start the construction from \(X\cup Y\). Its size is at most \(\kappa\), so the upper-bound argument gives \(|A|\le\kappa\), while \(Y\subseteq A\) gives \(\kappa\le|A|\). Hence \(|A|=\kappa\). □

Could the elementary submodel of an infinite structure be finite?

The countable theorem allows finite domains in its conclusion. If \(M\) is infinite, could its elementary substructure \(A\) be finite?

Show answerHide answer

No. For each positive integer \(n\), the sentence

\[\exists x_0\cdots\exists x_{n-1}\;\bigwedge_{i<j<n}x_i\ne x_j\]

says that there are at least \(n\) distinct elements. The conjunction is true when it is empty. An infinite \(M\) satisfies every such sentence, so an elementary \(A\) does too. If \(|A|=k\), the sentence for \(n=k+1\) fails by the finite pigeonhole principle, a contradiction. Therefore a countable elementary substructure of an infinite structure is countably infinite.
