Keep every subformula needed by a finite problem

Use the shared propositional formulas with numbered atoms, including primitive negation. The subformula set of a formula is defined recursively:

\[\operatorname{Sub}(p_i)=\{p_i\},\qquad\operatorname{Sub}(\bot)=\{\bot\},\qquad\operatorname{Sub}(\neg B)=\{\neg B\}\cup\operatorname{Sub}(B).\]
\[\operatorname{Sub}(B\circ C)=\{B\circ C\}\cup\operatorname{Sub}(B)\cup\operatorname{Sub}(C),\qquad\circ\in\{\land,\lor,\to\}.\]

A finite formula set \(\Sigma\) is subformula closed if \(A\in\Sigma\) implies \(\operatorname{Sub}(A)\subseteq\Sigma\). For a finite premise set \(\Gamma\) and conclusion \(A\), define the tracked set and atom support of the problem by

\[\Sigma(\Gamma,A):=\operatorname{Sub}(A)\cup\bigcup_{B\in\Gamma}\operatorname{Sub}(B),\qquad S(\Gamma,A):=\operatorname{At}(A)\cup\bigcup_{B\in\Gamma}\operatorname{At}(B).\]

Here \(\operatorname{At}\) is the finite set of occurring atom names. Both displayed constructions are finite calculations on the given formulas.

The tracked set contains its children and exactly the required atoms

Every \(\operatorname{Sub}(A)\) is finite, contains \(A\), and is subformula closed. Consequently \(\Sigma(\Gamma,A)\) is finite and subformula closed, contains \(\Gamma\cup\{A\}\), and satisfies

\[p_i\in\Sigma(\Gamma,A)\quad\Longleftrightarrow\quad i\in S(\Gamma,A).\]

Induct on a formula. An atom and falsum give singleton sets. At a negation, adjoining the formula to the child's finite closed set keeps the result finite; every proper subformula already occurs in that child. At a binary connective the same argument uses the union of its two children's sets. This also proves that if \(C\in\operatorname{Sub}(B)\), then \(\operatorname{Sub}(C)\subseteq\operatorname{Sub}(B)\). Hence a finite union of these sets is closed.

In the same induction, an atomic formula \(p_i\) is a subformula exactly when its name occurs in the formula: negation preserves the atom names, and a binary connective takes their union. Taking the finite union over the problem proves the last equivalence. In particular, a tracked negation brings its argument with it, and a tracked binary connective brings both arguments.

Replace a prime theory by its finite trace

Fix a finite subformula-closed \(\Sigma\). For a prime intuitionistic theory \(T\), its trace is

\[t_\Sigma(T):=T\cap\Sigma.\]

The trace worlds are all distinct subsets obtained this way:

\[W_\Sigma:=\{t_\Sigma(T):T\text{ is a prime theory}\},\qquad s\leq t\iff s\subseteq t.\]

A world is the subset itself; two theories with the same trace give one world. Every world has at least one prime representative, but no representative is chosen to define its atom values. Inclusion makes \(W_\Sigma\) a partial order.

Give the finite worlds a persistent atom valuation

The finite trace model \(\mathcal C_\Sigma\) has frame \(W_\Sigma\) and valuation

\[s\Vdash_\Sigma p_i\quad\Longleftrightarrow\quad p_i\in s.\]

Since \(s\subseteq\Sigma\), every atom absent from \(\Sigma\) is false at every world. For tracked atoms, the formula \(p_i\) belongs to \(t_\Sigma(T)\) exactly when it belongs to \(T\). Thus the valuation is specified on all atom names and depends only on the trace.

These data define a nonempty finite Kripke model, and

\[1\leq |W_\Sigma|\leq 2^{|\Sigma|}.\]

Inclusion is reflexive, transitive and antisymmetric. If \(s\subseteq t\), every atom in \(s\) also lies in \(t\), proving persistence. The canonical model has a prime world, whose trace witnesses nonemptiness. Every trace is a subset of the finite set \(\Sigma\), so the inclusion into its power set is injective. That power set has \(2^{|\Sigma|}\) members, giving finiteness and the stated bound.

Know exactly what trace inclusion preserves

If prime theories satisfy \(T\subseteq U\), then \(t_\Sigma(T)\subseteq t_\Sigma(U)\). Conversely, if their traces satisfy this inclusion and \(B\in\Sigma\cap T\), then \(B\in U\).

The first assertion follows by intersecting a subset inclusion with \(\Sigma\). For the second, \(B\in T\cap\Sigma=t_\Sigma(T)\); trace inclusion puts it in \(t_\Sigma(U)=U\cap\Sigma\), hence in \(U\).

The converse assertion does not claim \(T\subseteq U\). Trace inclusion need only preserve tracked formulas. This is enough for the implication and negation cases below, because their principal formulas themselves belong to \(\Sigma\).

The finite model preserves every tracked formula

For every finite subformula-closed \(\Sigma\), prime theory \(T\), and \(B\in\Sigma\),

\[\mathcal C_\Sigma,t_\Sigma(T)\Vdash B\quad\Longleftrightarrow\quad B\in T.\]

Induct on \(B\), proving the assertion for all prime representatives simultaneously. For an atom, membership in the trace is membership in \(T\), since the atom is tracked. Falsum fails on both sides: its forcing clause is false, and a consistent theory cannot contain it. A tracked conjunction or disjunction has tracked children. Their forcing clauses, the induction hypotheses, and the prime-theory membership laws give the equivalence.

Suppose \(B=C\to D\) belongs to \(T\). Take any later trace \(s\supseteq t_\Sigma(T)\), and choose a prime representative \(U\) of \(s\). Since \(C\to D\) is tracked, trace inclusion puts that implication in \(U\). If \(s\Vdash C\), induction gives \(C\in U\). Deductive closure and implication elimination give \(D\in U\), and induction gives \(s\Vdash D\). Thus the implication is forced. Conversely, if \(C\to D\notin T\), the specified prime extension \(U\supseteq T\) contains \(C\) and omits \(D\). Its trace extends that of \(T\), and induction makes it a world forcing \(C\) without forcing \(D\). Hence the implication fails.

For native \(B=\neg C\), membership \(\neg C\in T\) transfers to every later trace's prime representative by the same tracked-formula argument. Such a representative cannot contain \(C\), by consistency, so induction says that no later trace forces \(C\). This is exactly forcing \(\neg C\). If instead \(\neg C\notin T\), the negation extension lemma gives a prime \(U\supseteq T\) containing \(C\). Its trace is later and forces \(C\) by induction, so the negation fails. All induction applications are legitimate because the children lie in \(\Sigma\).

A failed finite deduction has a bounded finite partial-order countermodel

Let \(\Gamma\) be a finite set of numbered-atom formulas. If \(\Gamma\nvdash_{\mathrm I}A\), there is a nonempty finite partially ordered Kripke model and a world forcing every member of \(\Gamma\) without forcing \(A\). It can be chosen with at most

\[N(\Gamma,A):=2^{|\Sigma(\Gamma,A)|}\]

worlds. A specified choice is \(\mathcal C_{\Sigma(\Gamma,A)}\) at the trace of \(\mathsf E(\Gamma,A)\).

Canonical completeness supplies the prime theory \(T=\mathsf E(\Gamma,A)\), which contains \(\Gamma\) and omits \(A\). Each premise and the conclusion belongs to the tracked set. The bounded truth lemma therefore makes \(t_\Sigma(T)\) force all the premises and fail the conclusion in the precise trace model. Its frame is a partial order and has the preceding cardinal bound.

Finite models suffice to test propositional validity

For every numbered-atom formula \(A\), the following are equivalent: \(\vdash_{\mathrm I}A\); \(A\) is valid in every Kripke model; and \(A\) is valid in every nonempty finite partially ordered Kripke model. If \(A\) is not a theorem, a countermodel with at most \(2^{|\operatorname{Sub}(A)|}\) worlds suffices. This is the finite model property.

Soundness gives validity in all models from a proof, and this implies validity in the stated finite subclass. If no proof exists, apply the bounded countermodel theorem with \(\Gamma=\varnothing\). It gives a member of that very subclass refuting \(A\), so validity there implies theoremhood. The tracked set for empty premises is exactly \(\operatorname{Sub}(A)\).

Maximal worlds in these finite partial orders behave like Boolean valuations. This gives a proof of Glivenko’s theorem: every classical propositional theorem has an intuitionistic double-negated theorem.

Describe a finite candidate by two Boolean tables

For a natural number \(n\), write \([n]=\{0,\ldots,n-1\}\). Fix a finite atom set \(S\). A finite model code on \([n]\) consists of a relation table \(r:[n]\times[n]\to\{0,1\}\) and an atom table \(v:[n]\times S\to\{0,1\}\). Its extended atom table is

\[\widehat v(i,p):=\begin{cases}v(i,p),&p\in S,\\0,&p\notin S.\end{cases}\]

A code is admissible when \(r\) is reflexive and transitive and its atom table persists:

\[r(i,j)=1\text{ and }v(i,p)=1\quad\Longrightarrow\quad v(j,p)=1\qquad(i,j\in[n],\ p\in S).\]

Every condition is checked by finite loops through these tables. There are \(2^{n^2}\) relation tables and \(2^{n|S|}\) atom tables. Antisymmetry is not required for the search.

An admissible table gives an actual persistent model

If \(n>0\), an admissible code defines a Kripke model \(M_{r,v}\) with worlds \([n]\), accessibility \(i\leq_r j\iff r(i,j)=1\), and atom verification \(\widehat v(i,p)=1\).

The first two admissibility tests are exactly reflexivity and transitivity of accessibility. For persistence, a verified atom must lie in \(S\), since all other values were set to zero. The third test therefore applies and keeps the atom verified. The world \(0\in[n]\) witnesses nonemptiness. Hence these are precisely the required model data, rather than arbitrary tables on which soundness has been assumed.

Compute forcing by recursion through a finite model code

For any two tables, even before testing admissibility, define the Boolean forcing value \(e_{r,v}(i,B)\) by recursion on the actual formula:

\[e(i,p)=\widehat v(i,p),\qquad e(i,\bot)=0.\]
\[e(i,B\land C)=e(i,B)\land e(i,C),\qquad e(i,B\lor C)=e(i,B)\lor e(i,C).\]
\[e(i,\neg B)=\bigwedge_{j<n}\bigl(\neg r(i,j)\lor\neg e(j,B)\bigr).\]
\[e(i,B\to C)=\bigwedge_{j<n}\bigl(\neg r(i,j)\lor\neg e(j,B)\lor e(j,C)\bigr).\]

The operations on the right are Boolean operations; a finite conjunction is one exactly when every factor is one. A conjunction over no indices has value one. Every recursive formula argument is a proper subformula, so this is a terminating calculation; the future-world loops range only over \([n]\).

The finite calculation agrees with native forcing

For an admissible code with \(n>0\), every formula \(B\) and \(i\in[n]\) satisfy

\[e_{r,v}(i,B)=1\quad\Longleftrightarrow\quad M_{r,v},i\Vdash B.\]

Induct on \(B\), simultaneously at all worlds. The atomic clause is the model valuation, and falsum has value zero and is never forced. Boolean conjunction and disjunction agree with the two current-world forcing clauses by induction. For a negation, its finite conjunction is one exactly when every \(j\) satisfying \(r(i,j)=1\) has \(e(j,B)=0\). Induction identifies this with failure to force \(B\) at every extension, the native negation clause. The implication calculation similarly says that every extension forcing the antecedent also forces the consequent. This handles every constructor without replacing negation by a different syntax.

Every finite countermodel can be presented by such tables

Let \(M\) be a nonempty finite preordered Kripke model with \(n\) worlds, and let \(S\) be finite. Choose a bijection \(b:[n]\to W\), and define

\[r(i,j)=1\iff b(i)\leq b(j),\qquad v(i,p)=1\iff M,b(i)\Vdash p\quad(p\in S).\]

The code is admissible. For every formula \(B\) whose atom support is contained in \(S\),

\[e_{r,v}(i,B)=1\quad\Longleftrightarrow\quad M,b(i)\Vdash B.\]

Reflexivity, transitivity and persistence follow from the corresponding properties of \(M\). For the formula assertion, induct on \(B\). Every atom under consideration lies in \(S\), so its table entry has exactly the original value. Falsum and the two current-world binary clauses follow directly. For negation and implication, surjectivity of \(b\) identifies the finite loop through all \(j\in[n]\) with all original worlds; the relation table identifies precisely the accessible ones. Apply the induction hypotheses to their proper subformulas, whose atom supports remain in \(S\).

A designated original world is represented by its unique preimage under \(b\). Thus both premise forcing and failure of a supported conclusion transfer to the displayed finite tables. No preservation is asserted for atoms outside \(S\), whose original values may have been discarded.

Scan every candidate within the proved world bound

A presented finite problem is a finite list \(H\) of numbered-atom formulas together with a conclusion \(A\). Its premise set is \(\Gamma=\operatorname{set}(H)\); repetitions are allowed. Compute \(\Sigma=\Sigma(\Gamma,A)\), \(S=S(\Gamma,A)\), and \(N=2^{|\Sigma|}\).

The bounded countermodel test \(\operatorname{Refute}(H,A)\) has value one exactly when a scan of the following finite collection succeeds: for each \(0\leq n\leq N\), each relation table \(r\), each atom table \(v\), and each \(i\in[n]\), test admissibility and then test

\[e_{r,v}(i,A)=0\quad\text{and}\quad e_{r,v}(i,B)=1\text{ for every formula }B\text{ in }H.\]

Return one if any candidate passes and zero if none does. The scan can enumerate all Boolean functions on the indicated finite domains; its answer is independent of the enumeration order. The case \(n=0\) has no designated world and contributes no candidate. The finite table tests and formula recursion make this an explicit terminating calculation, including empty premise lists and atom-free formulas.

The bounded scan decides finite intuitionistic consequence

For every finite problem \((H,A)\), with \(\Gamma=\operatorname{set}(H)\),

\[\operatorname{Refute}(H,A)=1\quad\Longleftrightarrow\quad\Gamma\nvdash_{\mathrm I}A.\]

Consequently its zero answer is equivalent to \(\Gamma\vdash_{\mathrm I}A\), so the scan decides intuitionistic derivability for finite presented premises.

If a candidate passes, its designated world makes \(n>0\). The admissible tables give an actual model. Boolean-forcing correctness turns the tests into premise forcing and conclusion failure, so soundness rules out a derivation.

Conversely, a failed deduction has the particular bounded finite partial-order countermodel from the trace construction. Let \(n\) be its number of worlds; then \(1\leq n\leq N\). Relabel it by \([n]\) and restrict its atom table to the computed support \(S\). Every input formula has support in \(S\), so the relabeling lemma preserves all required truth values at the counterexample world. The resulting admissible candidate is included in the finite scan and passes. Thus the test returns one.

All loops have bounds obtained from the finite input. This proves termination and correctness, without a claim that the total search is short. The procedure need not enumerate proofs while waiting for a countermodel; the cardinal bound already makes the model scan exhaustive.

Read the excluded-middle countermodel as a finite code

For the conclusion \(p_0\lor\neg p_0\) with no premises, the tracked set is \(\{p_0,\neg p_0,p_0\lor\neg p_0\}\), the support is \(\{0\}\), and \(N=8\). An accepted candidate already occurs at \(n=2\):

\[r=\begin{pmatrix}1&1\\0&1\end{pmatrix},\qquad v(0,0)=0,\qquad v(1,0)=1.\]

The matrix is reflexive and transitive, and its only growing atom value is persistent. At world \(0\), the atom has value zero. The negation calculation includes the later world \(1\), where the atom has value one, so that negation also has value zero. The disjunction is therefore zero at \(0\). With no premises there are no further tests, and the candidate is accepted. Hence \(\operatorname{Refute}([],p_0\lor\neg p_0)=1\), in agreement with the earlier chain countermodel.

Why track subformulas and specify all atom values?

Can one use an arbitrary finite \(\Sigma\), giving an atom the value it has in any chosen representative? What happens to the trace model when \(\Sigma=\varnothing\)?

Show answerHide answer

Representative values are not well defined for untracked atoms. In the two-world chain, both worlds force \(p_0\to p_0\), so their truth theories have the same trace on \(\Sigma=\{p_0\to p_0\}\). Yet they disagree on \(p_0\). Assigning its value from an arbitrary representative would give two different answers at the same trace.

Setting untracked atoms to zero removes that ambiguity, but subformula closure is still necessary for the truth assertion. Take \(\Sigma=\{\neg p_0\}\). In the chain's lower-world prime theory, \(\neg p_0\) is absent. Our trace valuation makes \(p_0\) false at every trace, because \(p_0\notin\Sigma\). Consequently every trace forces \(\neg p_0\), so its forcing no longer agrees with membership in that theory. Including the missing subformula \(p_0\) prevents this failure.

For \(\Sigma=\varnothing\), every prime theory has the one trace \(\varnothing\). Thus there is exactly one world, all atoms are false, and the bounded truth lemma is vacuous. The model is nonempty and the bound \(2^0=1\) is attained. The finite-model construction does not confuse an empty tracked set with an empty frame.
