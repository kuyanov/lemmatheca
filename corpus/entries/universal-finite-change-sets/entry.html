Read an arbitrary program as a proposed sequence of guesses

Use the fixed ordinary program numbering. A candidate approximation of index \(e\) proposes the value \(\varphi_e(\langle k,x\rangle)\) at stage \(k\) and input \(x\), with the fixed pairing code. A candidate may fail to halt, return a number other than zero or one, begin with one, or change its answers too often. All indices are admitted to the construction.

Write \(V(s,e,z)\) for the bounded output code of the existing bounded evaluator: zero means that no output was found with allowance \(s\), and \(y+1\) means that output \(y\) was found. This is a total computable numerical function. A positive code supplies the actual output of \(\varphi_e(z)\); every actual output is found at some allowance and at every larger allowance. Increasing the allowance never changes a successful output. Thus codes one and two represent the binary outputs zero and one.

Store a cursor, a bit, and a spent allowance

Fix \(n,e,x\in\mathbb N\). The clipped simulation state at global stage \(s\) is a triple \(S_s=(k_s,b_s,c_s)\): the cursor \(k_s\) names the next candidate stage to inspect, \(b_s\) is the current binary answer, and \(c_s\) counts accepted revisions. Start with \(S_0=(0,0,0)\). The universal clipped guess is

\[Q(n,e,s,x)=b_s.\]

The parameter \(n\) is the permitted number of changes. The global stage \(s\), which controls the simulation allowance, is separate from the candidate stage \(k_s\). The same finite update rule below defines \(Q\) for all four parameters together.

Accept the next binary value while revisions remain available

The successor update from \(S_s=(k,b,c)\) is as follows. If \(c\ge n\), keep the state fixed. Otherwise compute \(v=V(s,e,\langle k,x\rangle)\). If \(v=1\) or \(v=2\), put \(y=v-1\) and set

\[S_{s+1}=(k+1,\;y,\;c+[y\ne b]).\]

If \(v\) is neither one nor two, keep the state fixed. The bracket is one when its assertion holds and zero otherwise. A zero output code leaves the computation pending; it does not certify divergence. A nonbinary output cannot later become a different binary output of the same candidate computation, so leaving that cursor fixed is harmless. No unbounded search occurs within one successor stage.

Even if the next accepted value equals \(b\), the cursor advances: this value has been processed, while the count remains unchanged. If a revision spends the last available unit, all later states remain fixed. With \(n=0\), the initial state already has this property.

Every generated row remains binary and within its allowance

For every \(n,e,s,x\), the state satisfies \(b_s\in\{0,1\}\), \(c_s\le n\), and \(k_s\le k_{s+1}\). Its count is exactly the prefix change counter of the generated row:

\[c_s=c_{Q(n,e,\cdot,x)}(s).\]

At stage zero the bit and both counts are zero. A fixed-state update preserves every assertion. In an accepting update the output code is one or two, so the new bit is zero or one. Acceptance occurs only when \(c<n\); adding at most one therefore leaves the new count at most \(n\). The cursor increases by exactly one. Finally, the stored count adds one exactly when the generated bit changes, which is the defining recurrence of the prefix counter. Induction on \(s\) proves all the claims.

One total computable function implements all allowances and indices

The function \((n,e,s,x)\mapsto Q(n,e,s,x)\) is jointly computable. For every fixed \(n,e\), its row is binary, starts at zero and changes at most \(n\) times per input.

Encode the state triple by the fixed pairing operations. Each update uses a bounded evaluation, comparisons, subtraction of one from a positive output code, and additions. All of these operations are total computable jointly in the numerical parameters and the stored state. Iterate this update for exactly \(s\) steps, carrying \(n,e,x\) as fixed parameters, and project its bit component. This finite recursion is an algorithm for the displayed four-variable function. The bound and initial value follow from . No test of totality of the candidate program was used.

Define the set represented by each clipped row

The row set represented by \(n,e\) is

\[R_{n,e}=\{x:\exists t\;\forall s\ge t\;Q(n,e,s,x)=1\}.\]

The bounded-count convergence lemma shows that each row eventually has a constant bit, separately for each input. Therefore \(Q(n,e,s,x)\to\chi_{R_{n,e}}(x)\), and \(R_{n,e}\) is \(n\)-c.e. This defines a set for every candidate index, including indices of partial programs. No algorithm deciding its eventual bit is asserted.

State precisely when a candidate is faithful

A candidate index \(e\) presents an approximation \(a(k,x)\) when

\[\forall k,x\qquad\varphi_e(\langle k,x\rangle)=a(k,x).\]

The equality means that the partial computation is defined and has the indicated numerical value. Every jointly computable numerical approximation has such an index by universality, after decoding the input pair. For the following three arguments, assume that \(e\) presents a binary approximation \(a\), that \(a(0,x)=0\), and that every row of \(a\) has at most \(n\) changes. These are hypotheses for the coverage proof, not tests performed by the simulation.

A faithful state records a processed candidate prefix

Under the hypotheses of , the state \((k_s,b_s,c_s)\) satisfies

\[b_s=a(k_s-1,x),\qquad c_s=c_a(k_s-1,x),\]

where subtraction is truncated at zero. In particular, if \(c_s=n\), then \(b_s\) equals every sufficiently late candidate answer.

At the initial state, \(k_s=0\), the bit equality uses \(a(0,x)=0\), and both counters are zero. A waiting update preserves the invariant. In an accepting update, soundness of bounded evaluation identifies the accepted output with \(a(k_s,x)\). If the old cursor is zero, the accepted bit is again \(a(0,x)=0\), so no revision is charged. If it is positive, the stored count increases by exactly the transition from candidate stage \(k_s-1\) to stage \(k_s\). In both cases the new cursor is \(k_s+1\), giving the displayed invariant at the successor stage.

If the counter has reached \(n\), a later candidate answer different from \(a(k_s-1,x)\) would force a strict counter increase by the endpoint counter lemma. This would exceed \(n\). Hence all candidate answers from that processed stage onward are the stored bit. The fixed-state rule then retains that final answer.

Every finite candidate prefix is processed unless the final answer is fixed

Under the hypotheses of , for every input \(x\) and every requested cursor value \(m\), some global stage satisfies \(k_s\ge m\) or \(c_s=n\).

If the allowance is ever exhausted, that stage proves the assertion for every \(m\). Otherwise \(c_s<n\) at all stages. We prove that the cursor eventually reaches each \(m\) by induction. It starts at zero. Suppose it has reached \(m\). If it ever becomes larger, the next induction step is done. If it never becomes larger, monotonicity makes it constantly \(m\) from that point onward. The total computation \(\varphi_e(\langle m,x\rangle)\) has a binary output, so some allowance \(u\) finds it and every larger allowance finds that same output. At a global stage at least \(u\), the update must therefore accept it and increase the cursor to \(m+1\), a contradiction. Thus every finite cursor bound is eventually reached.

The argument does not seek a stage at which totality has been established. For each fixed candidate input, its assumed halting supplies the finite allowance needed in this proof.

Clipping preserves every valid finite-change limit

If \(e\) presents an initial-zero binary approximation \(a\) with at most \(n\) changes and \(a(k,x)\to\chi_A(x)\), then \(R_{n,e}=A\).

Fix \(x\) and a candidate convergence stage \(t\). If the simulation ever exhausts its allowance, identifies its permanently stored bit with the candidate limit. Otherwise gives a global stage with cursor at least \(t+1\). The prefix invariant then identifies its bit with \(a(k_s-1,x)=\chi_A(x)\). The cursor never decreases, so the same argument applies at every later global stage. Thus the clipped row converges to the same characteristic bit on every input, proving equality with its row set.

The simulation can repeat a guess while waiting for a candidate computation. Equality of the limit sets is what is preserved; the candidate's stage numbers need not be reproduced.

The pointwise version needs an allowance only at the chosen input and therefore permits bounds that vary with the input.

Put every row into one coded membership problem

The universal \(n\)-change set is

\[U_n=\{\langle e,x\rangle:x\in R_{n,e}\}.\]

Its specified approximation is \(u_n(s,z)=Q(n,\pi_1(z),s,\pi_2(z))\), where \(\pi_1,\pi_2\) decode the fixed pairing bijection. Joint computability and the row bound show that \(u_n\) is computable, binary, initial zero and has at most \(n\) changes per input. Its limit is exactly the characteristic function of \(U_n\), so \(U_n\) is \(n\)-c.e.

The universal set receives every problem with the same allowance

For every \(n\), the set \(U_n\) is \(n\)-c.e., and every \(n\)-c.e. set \(A\) has an injective total computable reduction to \(U_n\).

Choose a witnessing approximation \(a\) for \(A\), and choose its ordinary candidate index \(e\). The hypotheses of hold, so \(R_{n,e}=A\). The specified reduction \(f_e(x)=\langle e,x\rangle\) is total computable and injective, and

\[x\in A\quad\Longleftrightarrow\quad\langle e,x\rangle\in U_n.\]

This is an ordinary numerical translation, with no oracle. Membership in \(U_n\) is not required to be decidable. Its own approximation was supplied in .

Reverse the diagonal answer after one initial stage

Define the diagonal escape set and its delayed diagonal approximation by

\[D_n=\{e:e\notin R_{n,e}\},\qquad d_n(0,e)=0,\qquad d_n(s+1,e)=1-Q(n,e,s,e).\]

The diagonal row \(Q(n,e,s,e)\) is jointly computable in \(n,s,e\), binary and initial zero. The delayed-complement construction therefore gives \(d_n\to\chi_{D_n}\) and

\[c_{d_n}(s+1,e)=1+c_{Q(n,e,\cdot,e)}(s)\le n+1.\]

Consequently \(D_n\) is \((n+1)\)-c.e. The construction is jointly computable in \(n\) as well as the input and stage. The delay keeps the prescribed initial bit zero.

The diagonal escape cannot have the original allowance

For every \(n\), the set \(D_n\) is not \(n\)-c.e.

Suppose that \(D_n\) were \(n\)-c.e. By and the existence of a candidate index, there would be an \(e\) with \(R_{n,e}=D_n\). At its own input this gives

\[e\in D_n\quad\Longleftrightarrow\quad e\notin R_{n,e}\quad\Longleftrightarrow\quad e\notin D_n,\]

which is impossible. The diagonal argument uses the limits of the clipped rows; it never waits for a computational certificate that one of those rows has settled.

The universal set does not belong to the opposite class

The complement of \(U_n\) is not \(n\)-c.e.; equivalently, \(U_n\) is not co-\(n\)-c.e.

The map \(g(e)=\langle e,e\rangle\) is total computable. By the definitions, \(D_n=g^{-1}(U_n^c)\). If \(U_n^c\) were \(n\)-c.e., closure under computable preimages would make \(D_n\) \(n\)-c.e., contradicting . The same witnesses apply when \(n=0\).

Every additional permitted revision enlarges the class

For every \(n\ge0\), \(\mathcal E_n\) is a proper subclass of \(\mathcal E_{n+1}\). The specified witness is \(D_n\in\mathcal E_{n+1}\setminus\mathcal E_n\).

The allowance inclusion gives \(\mathcal E_n\subseteq\mathcal E_{n+1}\). The delayed diagonal construction gives the asserted membership of \(D_n\), and diagonal disagreement excludes its membership at level \(n\). Iterating these inclusions also separates every pair of finite levels \(m<n\). These are classes of sets equipped with bounded-revision approximations; no assertion about strictness of their Turing-degree classes is part of the conclusion.

Does the construction work when no revision is allowed?

Determine \(Q(0,e,s,x)\), \(U_0\) and \(D_0\). Does the strictness proof still give a witness?

Show answerHide answer

The initial count is already zero, so every state is fixed and \(Q(0,e,s,x)=0\). Hence every row set is empty, \(U_0=\varnothing\), and \(D_0=\mathbb N\). Its delayed approximation is zero at stage zero and one at every positive stage, so it makes exactly one change on every input. It is therefore a one-change witness outside the zero-change class, which contains only the empty set.

Can a stalled first computation destroy the construction?

Suppose \(\varphi_e(\langle0,x\rangle)\) is undefined for one input \(x\), while later candidate-stage inputs may halt. What does the generated row do on \(x\)?

Show answerHide answer

It stays zero forever on this input. Soundness of the bounded evaluator makes every attempted output code zero at cursor zero. Thus no accepting transition occurs and \((k_s,b_s,c_s)=(0,0,0)\) at every stage, by induction. The generated row is still a valid bounded-change approximation. It need not reproduce the values at later candidate stages, because this candidate does not satisfy the totality hypothesis of the coverage theorem. Partial computations were allowed from the start; no stage decides that this one will remain pending forever.
