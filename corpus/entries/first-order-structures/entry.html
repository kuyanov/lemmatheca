Interpreting a language

Fix a first-order language \(L\). An \(L\)-structure \(M\) consists of a nonempty set \(|M|\), its domain, together with an interpretation \(f^M:|M|^k\to|M|\) for each function symbol \(f\in F_k\), and an interpretation \(R^M\subseteq|M|^k\) for each relation symbol \(R\in R_k\). Equality is interpreted as equality of domain elements.

A zero-argument function chooses one element, so a constant \(c\) has a value \(c^M\in|M|\). A zero-argument relation chooses whether the unique empty tuple belongs to it, hence a truth value. The functions are total on their indicated domains.

For a language with one binary relation symbol \(<\), both \(\{0,1\}\) with its usual strict order and \(\mathbb N\) with its usual strict order are structures. An arbitrary binary relation would also be an interpretation; the signature itself imposes no order axioms. This separates a symbol from its meaning.

Assignments and values of terms

An assignment \(a\) gives each free variable \(x_i\) an element \(a(x_i)\in|M|\). In a context of size \(n\), also specify a tuple \(b=(b_0,\ldots,b_{n-1})\) of values for its placeholders. Define a term's value \(\llbracket t\rrbracket^M_{a,b}\) recursively:

\[ \llbracket x_i\rrbracket^M_{a,b}=a(x_i),\qquad \llbracket z_j\rrbracket^M_{a,b}=b_j,\qquad \llbracket f(t_0,\ldots,t_{k-1})\rrbracket^M_{a,b} =f^M(\llbracket t_0\rrbracket^M_{a,b},\ldots,\llbracket t_{k-1}\rrbracket^M_{a,b}). \]

For a constant this reads \(\llbracket c\rrbracket^M_{a,b}=c^M\). With no placeholders in scope, omit \(b\). For a unary symbol \(s\), evaluating \(s(s(x_0))\) gives \(s^M(s^M(a(x_0)))\). The symbol need not mean successor.

When a formula is satisfied

Write \(M,a,b\models\varphi\) when the scoped formula \(\varphi\) is satisfied at those values. Define this by recursion on its finite tree:

  • \(M,a,b\not\models\bot\).
  • \(M,a,b\models t=u\) precisely when \(\llbracket t\rrbracket^M_{a,b}=\llbracket u\rrbracket^M_{a,b}\).
  • \(M,a,b\models R(t_0,\ldots,t_{k-1})\) precisely when the tuple of term values belongs to \(R^M\).
  • \(M,a,b\models\varphi\to\psi\) precisely when satisfaction of \(\varphi\) implies satisfaction of \(\psi\).
  • \(M,a,b\models\forall z_n\varphi\) precisely when \(M,a,(b_0,\ldots,b_{n-1},m)\models\varphi\) for every \(m\in|M|\).

The defined connectives consequently satisfy their usual classical clauses: negation reverses truth, conjunction requires both children, disjunction requires at least one, and \(\exists z_n\varphi\) holds precisely when some \(m\in|M|\) makes the body true with the extended tuple. These follow by expanding the abbreviations; for existence, use \(\neg\forall m\neg P(m)\) iff \(\exists m P(m)\).

For a complete formula the tuple is empty, and we write \(M,a\models\varphi\). Quantifiers range over domain elements, not names for them. There is no requirement that every element have a constant symbol naming it.

Only occurring free variables affect truth

Fix the same structure and the same placeholder tuple. If assignments \(a,a'\) agree on \(\operatorname{FV}(t)\), then \(\llbracket t\rrbracket^M_{a,b}=\llbracket t\rrbracket^M_{a',b}\). If they agree on \(\operatorname{FV}(\varphi)\), then

\[M,a,b\models\varphi\quad\Longleftrightarrow\quad M,a',b\models\varphi.\]

In particular, satisfaction of a sentence is independent of the assignment.

Proof

Induct on terms. For a free variable use the assumed agreement; a placeholder has the same tuple value; a function receives equal argument values by induction. Constants have no arguments.

Then induct on scoped formulas, allowing arbitrary assignments and tuples at every context size. Falsity is unchanged. Equality and relation application use the term result. For implication, agreement on the union of the children's free-variable sets gives the same truth values for both children. For \(\forall z_n\varphi\), the body's free-variable set equals that of the quantified formula. For each domain element \(m\), the two extended tuples are identical, so induction gives agreement on the body. Universal quantification of these equivalences proves the claim. Empty free-variable sets impose no condition, giving the sentence conclusion. □

For a sentence \(\theta\), we therefore write \(M\models\theta\), and say that \(\theta\) is true in \(M\). Equivalently it is satisfied under every assignment, or under one assignment. An assignment exists because the domain is nonempty.

Substitution agrees with assigning a term's value

Let \(\sigma\) be a simultaneous substitution by terms containing only free variables. Given an assignment \(a\), define \(a_\sigma(x_i)=\llbracket\sigma(x_i)\rrbracket^M_a\).

For every scoped term \(t\), formula \(\varphi\), and placeholder tuple \(b\),

\[ \llbracket t[\sigma]\rrbracket^M_{a,b}=\llbracket t\rrbracket^M_{a_\sigma,b},\qquad M,a,b\models\varphi[\sigma]\ \Longleftrightarrow\ M,a_\sigma,b\models\varphi. \]

Proof

For terms, induction gives the chosen replacement value at a free variable, the unchanged tuple value at a placeholder, and equal inputs to each interpreted function. Next induct on formulas. Equality and relation application use those term equalities; falsity and implication follow from their truth clauses. At a universal quantifier, compare the bodies at each extended tuple \((b,m)\). The assignment \(a_\sigma\) is the same for every \(m\), because replacement terms contain no placeholders. The induction equivalence can therefore be quantified over \(m\). □

For a single substitution \([t/x_i]\), \(a_\sigma\) is just \(a\) with its value at \(x_i\) changed to \(\llbracket t\rrbracket^M_a\). This is why a substitution that captured a free variable would give the wrong semantic rule.

Opening a bound slot assigns the term's value

Let \(A\) be a scoped formula with one available placeholder, let \(t\) contain no placeholders, and let \(A(t)\) be its capture-safe instance. For every structure \(M\) and free-variable assignment \(a\),

\[ M,a\models A(t)\quad\Longleftrightarrow\quad M,a,(\llbracket t\rrbracket^M_a)\models A. \]

Thus opening the slot has the same effect on truth as assigning that slot the term's value. The original free-variable assignment stays fixed.

Proof

Put \(m=\llbracket t\rrbracket^M_a\). To handle nested binders, prove a stronger assertion at every depth \(r\): replacing the outer slot \(z_0\) by \(t\) and shifting each remaining \(z_{j+1}\) to \(z_j\) preserves term values and formula truth when the original tuple \((m,b_0,\ldots,b_{r-1})\) is replaced by \((b_0,\ldots,b_{r-1})\). The assignment \(a\) remains unchanged, and the assertion ranges over every tuple of retained values.

First induct on terms. A free variable keeps its assigned value. The removed placeholder \(z_0\) has value \(m\), which is also the value of its replacement \(t\); this value is independent of the tuple because \(t\) has no placeholders. Each shifted placeholder keeps the same retained value. Function application then receives the same argument values on both sides.

Now induct on scoped formulas. Equality and relation application use the term result; falsity and implication use their truth clauses. At a universal quantifier, append the same arbitrary element \(u\) to both tuples. The induction hypothesis at depth \(r+1\) compares the two bodies, with original tuple \((m,b_0,\ldots,b_{r-1},u)\) and resulting tuple \((b_0,\ldots,b_{r-1},u)\). Quantifying over \(u\) gives the required equivalence. Taking \(r=0\) proves the displayed statement. □

In particular, if \(s\) and \(t\) have the same value under \(a\), then \(A(s)\) and \(A(t)\) have the same truth value: both are evaluated by assigning that common value to the slot.

The same formula in two structures

In the language with one binary relation \(<\), put \(\varphi(x_0)=\exists z_0\,(x_0<z_0)\). What are its truth values in \(M=\{0,1\}\) and \(N=\mathbb N\), each with the usual strict order? What happens to \(\theta=\forall z_0\exists z_1\,(z_0<z_1)\)?

Show answerHide answer

In \(M\), \(\varphi\) is true when \(a(x_0)=0\), using witness \(1\), and false when \(a(x_0)=1\), since neither domain element is larger. Thus \(M\not\models\theta\).

In \(N\), \(a(x_0)+1\) is always a witness, so \(\varphi\) holds for every assignment and \(N\models\theta\). By contrast, \(\exists z_0\,(z_0<z_0)\) is false in both structures: no element is strictly smaller than itself. This confirms why the captured expression differs from the intended substitution.

Bijections preserving the interpreted symbols

An isomorphism \(h:M\to N\) of \(L\)-structures is a bijection of their domains such that, for every symbol and tuple,

\[ h(f^M(m_0,\ldots,m_{k-1}))=f^N(h(m_0),\ldots,h(m_{k-1})), \]
\[ (m_0,\ldots,m_{k-1})\in R^M \quad\Longleftrightarrow\quad (h(m_0),\ldots,h(m_{k-1}))\in R^N. \]

For constants the first condition says \(h(c^M)=c^N\). Relations must be preserved in both directions. Compose \(h\) with an assignment or apply it to each entry of a tuple to transport their values to \(N\).

Isomorphisms preserve satisfaction

If \(h:M\to N\) is an isomorphism, then every term and scoped formula satisfy

\[ h(\llbracket t\rrbracket^M_{a,b})=\llbracket t\rrbracket^N_{h\circ a,h(b)},\qquad M,a,b\models\varphi\ \Longleftrightarrow\ N,h\circ a,h(b)\models\varphi. \]

Consequently \(M\models\theta\) iff \(N\models\theta\) for every sentence \(\theta\).

Proof

The term identity follows by induction: variables transport by definition, and the function step is exactly preservation of the interpreted function. For formulas, equality uses that identity and injectivity of \(h\); relation application uses the defining equivalence for relations. Falsity and implication preserve the resulting truth values.

For a universal quantifier, truth in \(M\) gives truth of the body at every \(m\in|M|\). Induction gives truth in \(N\) at \(h(m)\); surjectivity says these exhaust \(|N|\). Conversely, truth at all elements of \(N\) includes every \(h(m)\), so induction gives truth at all \(m\). The sentence conclusion follows from assignment independence. □

Theories specify collections of requirements

An \(L\)-theory \(T\) is a set of \(L\)-sentences. A structure \(M\) is a model of \(T\), written \(M\models T\), if \(M\models\theta\) for every \(\theta\in T\). The theory is satisfiable if it has a model. These are semantic definitions.

For example, the sentence \(\forall z_0\forall z_1\,(z_0=z_1)\) holds exactly in structures whose domains have one element. The universal clause says all pairs of domain elements are equal; nonemptiness supplies the single element. The theory consisting of this sentence and its negation has no model, since a sentence and its negation cannot both be true.

An isomorphism preserves being a model of any fixed theory: apply to each sentence of the theory. A schema can specify such a set by giving one sentence for each permitted formula; this is a way of listing requirements in the surrounding mathematics, not an object-language quantifier over formulas.

Why require a nonempty domain?

What truth value does \(\exists z_0\,(z_0=z_0)\) have under our convention? What would its existential clause say if we admitted an empty domain?

Show answerHide answer

It is true in every structure we admit: choose any domain element, which equals itself. To discuss the boundary case, use the equality-only language and evaluate a closed sentence directly by the recursive truth clauses, assigning values only to the variables currently in scope. This convention requires no assignment to unused free-variable names. With an empty domain the existential sentence is false, since no witness exists. Its universal counterpart \(\forall z_0\,(z_0=z_0)\) would remain true, because every element of the empty domain satisfies the equality vacuously. Thus permitting empty domains changes the truth of some sentences, even in a language with no nonlogical symbols.
