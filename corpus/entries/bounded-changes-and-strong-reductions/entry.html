Ask whether a specified number of revisions ever occurs

Fix an \(\omega\)-c.e. presentation of a set \(A\): a jointly computable binary approximation \(a(s,x)\), initially zero and converging to \(\chi_A(x)\), with a total computable bound \(b(x)\) on its change counter \(c_a(s,x)\). Its change-threshold set is

\[H_a=\{\langle x,k\rangle:\exists s\;k<c_a(s,x)\}.\]

The question indexed by \(k\) asks whether at least \(k+1\) revisions occur. The first possible question has \(k=0\). Questions with \(k\ge b(x)\) always have answer no, since every prefix count is at most \(b(x)\).

One ordinary program recognizes all the change thresholds

The set \(H_a\) is c.e. There is one ordinary program index \(h_a\), fixed before \(x,k\) vary, whose program on input \(\langle x,k\rangle\) halts with output zero exactly when that pair belongs to \(H_a\). Consequently the ordinary primitive-recursive map

\[r_a(x,k)=f_{\mathrm{ord}}(h_a,\langle x,k\rangle)\]

satisfies \(r_a(x,k)\in K\) exactly when \(\langle x,k\rangle\in H_a\), where \(f_{\mathrm{ord}}\) is the ordinary input-freezing map and \(K\) is ordinary diagonal halting.

Supply one ordinary code computing the joint function \(a\). On paired input \(\langle x,k\rangle\), start the counter at zero. Compute the successive bits \(a(0,x),a(1,x),\ldots\); at each transition add one precisely when the new bit differs from the previous bit. Halt with output zero at the first count strictly above \(k\). All finite iterations are total, and unbounded search is partial recursive. This gives one recognizer for the entire paired relation, with the prescribed output whenever it halts.

Freeze that recognizer's input. The freezing identity is \(\varphi_{r_a(x,k)}(y)\simeq\varphi_{h_a}(\langle x,k\rangle)\) for every \(y\), so it also holds at the new program's diagonal input. The numerical map builds a constant-input program; it does not wait for the threshold event. Neither \(b\) nor membership answers about \(A\) are needed to choose \(h_a\).

The parity of the change count is the current bit

For every \(s,x\),

\[a(s,x)=c_a(s,x)\bmod2.\]

If \(m(x)\) is the largest attained prefix count at input \(x\), then \(m(x)\le b(x)\), \(\chi_A(x)=m(x)\bmod2\), and

\[m(x)=\sum_{k<b(x)}\chi_K(r_a(x,k)).\]

Induct on \(s\). Both values are zero initially. If the bit stays fixed, the count does not change. If the bit changes, binary values force it to switch between zero and one, while the counter increases by one and changes parity. This proves the identity.

The nondecreasing counter takes values in the finite set \(\{0,\ldots,b(x)\}\), so it attains a largest value and remains there afterward. The parity identity and convergence identify its parity with \(\chi_A(x)\). Exactly the thresholds \(k=0,\ldots,m(x)-1\) are ever exceeded, which proves the sum identity, including \(m(x)=0\).

Put the threshold answers into one finite truth table

The threshold truth-table scheme associated with \(a,b\) has width and value function

\[\begin{aligned}U(x)&=\max\bigl(\{r_a(x,k)+1:k<b(x)\}\cup\{0\}\bigr),\\ T(x,w)&=\left(\sum_{k<b(x)}\beta(w,r_a(x,k))\right)\bmod2.\end{aligned}\]

Here \(w\) is a numerical word code and \(\beta(w,q)\) is its total binary entry function, with zero outside the decoded word. These formulas define \(U\) and \(T\) on all inputs, including codes that are not rows of width \(U(x)\). They use the same prefix-table convention as truth-table reducibility.

Computably bounded changes give a truth-table reduction to halting

The specified scheme \((U,T)\) is total computable, always returns a bit, and presents \(A\) from \(K\). In particular \(A\le_{\mathrm{tt}}K\).

Compute \(b(x)\), then the finitely many numbers \(r_a(x,k)\), and take the displayed finite maximum. Given \(w\), finite lookup, addition and remainder compute \(T(x,w)\). The remainder is zero or one. Every queried position \(r_a(x,k)\) lies below \(U(x)\), so the corresponding entry in the actual \(K\)-prefix is exactly \(\chi_K(r_a(x,k))\). The two identities in therefore give \(T(x,K\mathbin{\upharpoonright}U(x))=\chi_A(x)\).

If \(b(x)=0\), the width and empty sum are both zero. No oracle query is made, and the output is zero, as required by an initially zero approximation with no revisions. For example, if \(b(x)=3\) and exactly two revisions occur, the three threshold answers are \(1,1,0\), so the table returns zero. The entire query list is selected from \(x\) before any halting answer is received.

Freeze the use window while the evaluation allowance grows

Now fix an actual weak truth-table reduction of \(A\) to \(K\), given by an oracle program \(p\) and a total computable use bound \(u\). Write \(e=\#p\). Use the increasing computable halting stages \(K_s\), initially empty. Write \(F(w,k,e,x)\) for the ordinary finite-oracle evaluator: it evaluates program index \(e\) on input \(x\) with allowance \(k\), answering each query \(q\) by \(\beta(w,q)\). It returns zero on failure and \(y+1\) on a successful output \(y\). Define the fixed-use snapshot and the bounded-run approximation by

\[\begin{aligned}C_{s,x}&=K_s\cap[0,u(x)),\\ w(s,x)&=\operatorname{code}\bigl([\chi_{K_s}(0),\ldots,\chi_{K_s}(u(x)-1)]\bigr),\\ d(s,x)&=\begin{cases}1,&F(w(s,x),s,e,x)=2,\\0,&\text{otherwise}.\end{cases}\end{aligned}\]

The finite evaluator returns zero on failure and \(y+1\) on a successful output \(y\). Thus the test for the bit one is equality with two. Its ordinary finite oracle is \(C_{s,x}\): positions outside the word answer zero. The word always has length \(u(x)\); only the evaluation allowance \(s\) increases.

The bounded-run guesses are computable, binary, and initially zero

The function \(d\) is jointly ordinary computable, has values in \(\{0,1\}\), and satisfies \(d(0,x)=0\) for every \(x\).

The bound \(u(x)\) is computable. Forming the finite list uses only that many values of the joint computable halting-stage test. The coded finite evaluator is an ordinary total computable function of its word, allowance, program index and input. Its equality test with two is a computable bit. At allowance zero the evaluator fails, so the initial guess is zero. No test here decides whether a program eventually halts.

Count the halting discoveries inside the fixed window

The prefix discovery count is

\[E(s,x)=\sum_{q<u(x)}\chi_{K_s}(q).\]

It is computable, starts at zero, is nondecreasing in \(s\), and is at most \(u(x)\). Moreover, if \(E(s+1,x)=E(s,x)\), then \(C_{s+1,x}=C_{s,x}\). Indeed, each summand is a nondecreasing bit. Any new positive bit would strictly increase their finite sum; equality of the sums means that no bit in the window changed.

Without a new prefix discovery, a successful bit cannot disappear

If \(E(s+1,x)=E(s,x)\), then \(d(s,x)\le d(s+1,x)\).

The two finite words are identical by . If \(d(s,x)=1\), the evaluator with that fixed oracle returned output one at allowance \(s\). Monotonicity in the evaluation allowance preserves exactly the same successful output at allowance \(s+1\), giving \(d(s+1,x)=1\). If the old bit is zero, the inequality follows from the new bit being nonnegative. An unchanged prefix may therefore allow a transition from zero to one when a computation first finishes, but not a transition from one to zero.

Each prefix discovery pays for at most two revisions

For every stage and input, the specified approximation satisfies the invariant

\[c_d(s,x)\le2E(s,x)+d(s,x).\]

Induct on \(s\), keeping \(x\) fixed. At stage zero the counter, discovery count and guess are all zero. Write \(\varepsilon=1\) if the next guess differs and \(\varepsilon=0\) otherwise, so \(c_d(s+1,x)=c_d(s,x)+\varepsilon\).

If the discovery count is unchanged, says the binary guesses cannot decrease. For equal bits, \(d(s,x)+\varepsilon=d(s+1,x)\); for the only possible unequal pair, \(0,1\), this is also true. Adding the new revision to the induction bound proves the invariant at the next stage.

If the discovery count increases, its natural-number values give \(E(s+1,x)\ge E(s,x)+1\). Both \(d(s,x)\) and \(\varepsilon\) are at most one, so the new counter is at most \(2E(s,x)+2\), hence at most \(2E(s+1,x)\). Adding the nonnegative new bit gives the required bound. These cases exhaust the nondecreasing discovery counts and complete the induction.

The supplied use bound gives a computable revision budget

The total computable function \(b_p(x)=2u(x)+1\) bounds every prefix change count of \(d\).

Combine with \(E(s,x)\le u(x)\) and \(d(s,x)\le1\). Ordinary multiplication and addition preserve computability of the supplied \(u\).

The extra one includes a first transition away from the required initial zero, even if no oracle answer changes. In particular, \(u(x)=0\) still allows a query-free computation eventually to return one. A zero query bound therefore does not justify a zero revision allowance for this specified approximation.

Settling the use window recovers the original successful computation

For every \(x\), \(d(s,x)\) eventually equals \(\chi_A(x)\).

Fix \(x\). The finitely many halting answers below \(u(x)\) eventually settle. Thus there is \(N\) such that, for all \(s\ge N\), \(C_{s,x}\) is the same finite oracle \(C_x=K\cap[0,u(x))\). This oracle agrees with \(K\) at every position used by the supplied successful reduction. The bounded replay theorem gives \(p^{C_x}(x)=\chi_A(x)\), even though answers beyond the use window have been replaced by zero.

Completeness of the bounded evaluator supplies an allowance \(k\) returning that same output with oracle \(C_x\). For every \(s\ge\max(N,k)\), the snapshot oracle is \(C_x\), and increasing the allowance to \(s\) preserves the successful value \(\chi_A(x)+1\). The test for equality with two therefore gives exactly \(\chi_A(x)\), whether the final bit is zero or one. This proves pointwise convergence without computing \(N\) or \(k\).

A weak truth-table computation from halting has bounded changes

If \(A\le_{\mathrm{wtt}}K\), the specified \(d\), with bound \(b_p(x)=2u(x)+1\), is an \(\omega\)-c.e. presentation of \(A\).

The supplied reduction fixes \(p,u\). The approximation is jointly computable, binary and initially zero by , has the displayed computable change bound by , and converges to the specified \(A\) by . These are exactly the requirements in the definition of \(\omega\)-c.e.; the argument retains this approximation and this bound throughout.

Bounded changes, truth tables, and bounded use give the same halting cone

For every set \(A\subseteq\mathbb N\),

\[A\text{ is }\omega\text{-c.e.}\quad\Longleftrightarrow\quad A\le_{\mathrm{tt}}K\quad\Longleftrightarrow\quad A\le_{\mathrm{wtt}}K.\]

The threshold scheme proves the first implication by . Every truth-table reduction is a weak truth-table reduction. The reverse implication to bounded changes is . These implications establish all three equivalences.

The existing diagonal set separates bounded use from Turing computation

Let \(D\) be the specified diagonal set beyond computable change bounds. Then

\[D\le_TK,\qquad D\nleq_{\mathrm{wtt}}K.\]

Thus weak truth-table reducibility is a proper restriction of Turing reducibility.

The diagonal construction proves that this very \(D\) is limit computable and not \(\omega\)-c.e. The limit lemma gives \(D\le_TK\). If \(D\le_{\mathrm{wtt}}K\), would make \(D\) \(\omega\)-c.e., a contradiction. Together with the implication from every weak truth-table reduction to a Turing reduction, this gives strictness of the relations, rather than failure of one particular program.

Why does a partial witness not separate truth tables from bounded use?

An oracle program asks only whether zero belongs to its oracle. It returns zero if the answer is yes and otherwise runs forever. With \(B=\{0\}\), does this program prove that \(\varnothing\le_{\mathrm{wtt}}B\) but \(\varnothing\nleq_{\mathrm{tt}}B\)? Does settle the comparison for every target oracle?

No. The supplied program witnesses a weak truth-table reduction with use bound one and fails to halt for an oracle omitting zero. But the constant-zero truth table, of width zero, also computes \(\varnothing\) from \(B\). A different witness already supplies the truth-table reduction.

The equivalence proved here concerns sets reducible to the particular oracle \(K\). It does not convert arbitrary bounded-use programs into all-oracle total programs. A separation of truth-table and weak truth-table reducibility would require a pair \(A,B\) for which a bounded-use reduction exists and every truth-table scheme fails. The argument for the specified \(D,K\) proves the distinct wtt-versus-Turing separation.
