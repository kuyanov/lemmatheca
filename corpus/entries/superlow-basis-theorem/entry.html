Require a finite table for the jump

A set \(X\subseteq\mathbb N\) is superlow if \(X'\le_{\mathrm{tt}}K\), where \(X'=\{e:\Phi_e^X(e)\downarrow\}\) is its jump and \(K\) is ordinary diagonal halting. This uses the existing prefix truth-table convention: the whole finite table is selected before its halting answers are received.

Superlowness is a computable change bound on the jump

For every set \(X\), superlowness is equivalent to \(X'\) being \(\omega\)-c.e., and also to \(X'\le_{\mathrm{wtt}}K\). Every superlow set is low.

Apply the bounded-change characterization to the set \(X'\). A truth-table reduction is a Turing reduction, so \(X'\le_TK\); the universal lower bound \(K\le_TX'\) gives \(X'\equiv_TK\).

Every weaker oracle inherits superlowness

If \(X\le_TY\) and \(Y\) is superlow, then \(X\) is superlow. Consequently superlowness depends only on Turing degree.

The actual jump translation supplies an ordinary total computable map \(f\) reducing \(X'\) many-one to \(Y'\). Let \((u,t)\) be a table presenting \(Y'\) from \(K\). The width \(u(f(e))\) and lookup \(t(f(e),w)\) are total computable and binary, and at the true halting prefix they return \(\chi_{Y'}(f(e))=\chi_{X'}(e)\). Thus these specified data present \(X'\) from \(K\). Apply this argument in both directions for Turing-equivalent sets.

Run the same history rule with any answer oracle

Fix the computable binary tree \(T\) and its fixed node decider from the low-basis construction. Its divergence restrictions are \(T_L\), and its ordinary primitive-recursive map \(\delta_T\) satisfies \(\delta_T(\ulcorner L\urcorner)\in K\) exactly when \(T_L\) has an empty level.

For an arbitrary set \(C\), define the answer-oracle histories by

\[\begin{aligned}L^C_0&=[],\\ \gamma_C(i)&=\chi_C\bigl(\delta_T(\ulcorner i::L^C_i\urcorner)\bigr),\\ L^C_{i+1}&=\begin{cases}L^C_i,&\gamma_C(i)=1,\\ i::L^C_i,&\gamma_C(i)=0.\end{cases}\end{aligned}\]

At \(C=K\) these are exactly the earlier histories \(L_i\) and recorded bits \(b(i)\). No correctness of an arbitrary oracle's answers is assumed.

The existing jump program terminates for every answer oracle

The very same oracle program \(J_T\) satisfies \(J_T^C(e)\downarrow=\gamma_C(e)\) for every oracle \(C\) and input \(e\). In particular it is total under all oracles and always returns a bit.

Its loop makes exactly \(e\) history updates, followed by one final query. Every list operation terminates, and \(\delta_T\) is an ordinary total numerical map on every list code. Computing that number does not run the empty-level search whose halting it encodes. Each oracle query returns either zero or one, and either update branch is a terminating list operation.

Induct on the loop counter. Starting from the empty list, after \(i\) updates its stored code is exactly \(\ulcorner L^C_i\urcorner\). The next query and branch therefore give exactly the displayed recursion. At the final query the returned bit is \(\gamma_C(e)\). This argument does not use the special equivalence between \(K\)-answers and failed restrictions.

List the questions from every possible finite history

For a binary word \(\eta\) of length \(e+1\), form histories \(L^\eta_i\) for \(i\le e\) by the same list update, using \(\eta(i)\) as the answer at step \(i\). Define the finite history-query set and its history width by

\[Q_T(e)=\{\delta_T(\ulcorner i::L^\eta_i\urcorner):\eta\in2^{e+1},\ i\le e\}.\]
\[U_T(e)=\max\bigl(\{q+1:q\in Q_T(e)\}\cup\{0\}\bigr).\]

Different words may repeat a query or describe answers inconsistent with one oracle. Keeping all these histories is harmless: a bound may include questions that are never asked in a real run.

A computable width bounds every actual run

The function \(U_T\) is ordinary total computable. On input \(e\), every query made by \(J_T\) under any oracle lies below \(U_T(e)\).

List the \(2^{e+1}\) binary words of the specified length. For each word, carry out its finitely many list updates and compute the \(e+1\) candidate query numbers. The fixed total map \(\delta_T\) makes every step terminate. Take the finite maximum, with zero as default. This is one ordinary algorithm in \(e\).

In any actual run, record the \(e+1\) answers as a word \(\eta\). Induction through the updates identifies its stored histories with \(L^\eta_i\). Each actual question consequently belongs to \(Q_T(e)\), and its successor is at most the defining maximum. No oracle is used to compute that maximum.

Replay the history against a finite word

The history lookup \(t_T(e,w)\) starts with the empty list, makes the same \(e\) updates as \(J_T\), and answers each candidate query \(q\) by the existing total word bit \(\beta(w,q)\). It then returns the last candidate answer. Together with \(U_T\), this gives the history table data \((U_T,t_T)\).

This rule is defined on every numerical word code \(w\), with zero beyond the decoded word. It does not search for an empty tree level or for an infinite path.

The finite table returns the exact recorded jump bit

The specified history data form a total computable binary prefix scheme, and for every \(e\),

\[t_T\bigl(e,\operatorname{code}(K\upharpoonright U_T(e))\bigr)=b(e).\]

The replay has a fixed finite number of updates. Ordinary total list operations, \(\delta_T\), and word lookup compute it jointly in \(e,w\); its returned answer is always a bit. The width is computable by .

Give the replay the true prefix of \(K\) of length \(U_T(e)\). Every possible candidate query during a replay is in the finite history-query set, by recording the answers just used. Thus each question is within that prefix and its lookup is the true \(K\)-answer. Induction on the update counter makes the stored list equal to the earlier \(L_i\). The final lookup is exactly the defining query for \(b(e)\), proving the identity.

Every common path of the original construction is superlow

Assume \(T\) has a node at every length. If \(X\in[T_{L_i}]\) for every \(i\), then the specified history table presents \(X'\) from \(K\). Hence this very \(X\) is superlow.

The earlier exact-jump theorem gives \(\chi_{X'}(e)=b(e)\) at every input. Substitute that identity into . All scheme data were fixed from the original tree decider, before this common path was chosen. The same program's all-oracle termination also proves the reduction through the general total-functional characterization.

Every infinite computable binary tree has a superlow path

If \(T\subseteq2^{<\omega}\) is a computable binary tree with a node at every length, then some \(X\in[T]\) satisfies \(X'\le_{\mathrm{tt}}K\).

Use the original \(K\)-guided restriction histories. Their survival proof makes the trees nested with every level nonempty. The descending finite-level argument gives a path common to all their path classes. Since \(L_0=[]\), this path belongs to \([T]\), and makes it superlow. This strengthens the low basis theorem using its own construction.

Every nonempty effectively closed binary class has a superlow member

Every nonempty effectively closed \(\mathcal P\subseteq2^{\mathbb N}\) contains a superlow set. The same holds for a nonempty path class of a co-c.e. binary tree.

The computable-tree representation gives a computable binary tree with exactly the paths in \(\mathcal P\). Nonemptiness witnesses a node at every length. Apply and transfer its member through that equality of classes. For a co-c.e. tree, first use its same-path computable conversion.

A noncomputable diagonal-avoiding set can have a bounded-change jump

There exists a superlow set \(X\) with binary diagonally noncomputable characteristic function. It is noncomputable and satisfies \(X<_TK\).

The binary DNC class is effectively closed and nonempty. Apply . The diagonal argument excludes computable members. Superlowness gives \(X'\le_TK\), and \(X\le_TX'\) gives \(X\le_TK\). If \(K\le_TX\), jump monotonicity would give \(K'\le_TX'\le_TK\), contrary to jump strictness. Thus the upper comparison is strict.

Which conclusions need the true halting answers?

Does termination of \(J_T\) under every oracle mean that arbitrary answers preserve a nonempty tree? If \(T\) has no computable path, could one of its paths be both superlow and hyperimmune-free?

No. With the empty answer oracle, every decision is zero, so every program is eventually added as a divergence requirement. In particular the index of the always-halting constant-zero oracle program is added. Its positive certificate excludes some whole level even of the full binary tree. The loop still terminates; its artificial restrictions need not survive. Correct preservation and exact identification with a path's jump use the actual \(K\)-answers.

The second possibility also fails. A superlow path is low and therefore computable from \(K\). If it is noncomputable, the hyperimmunity theorem below halting makes its degree hyperimmune. It is consequently not hyperimmune-free. The two basis theorems need not choose the same member of a class with no computable members.
