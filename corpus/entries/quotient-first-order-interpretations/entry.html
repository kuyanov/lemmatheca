A tuple may represent the same object as another tuple

The tuple interpretation construction makes every selected tuple a separate object. We now allow a definable equivalence relation to identify tuples. Fix languages \(L,K\) and a positive finite dimension \(d\). A quotient interpretation datum consists of a domain formula \(\delta(\bar x)\), an equality formula \(\varepsilon(\bar x,\bar y)\), an \(n\)-input function graph formula \(\gamma_f(\bar x_0,\ldots,\bar x_{n-1},\bar y)\) for each \(f\in L\), and a relation formula \(\rho_R(\bar x_0,\ldots,\bar x_{n-1})\) for each \(R\in L\). Every barred variable has \(d\) coordinates, and different blocks are disjoint.

There is a useful precise organization of these data. Form the expanded language \(L^E\) with the same function symbols as \(L\) and one fresh binary relation symbol \(E\). The same formulas give a finite-dimensional syntactic datum \(J:L^E\to K\), with \(\rho_E=\varepsilon\). This reuses its actual block translation, but we do not assume its ordinary unique-tuple graph condition.

Compare only the selected tuples

In a \(K\)-structure \(M\), put \(D=\{\bar a\in M^d:M\models\delta(\bar a)\}\). Define the represented equality on \(D\) by

\[a\sim b\quad\Longleftrightarrow\quad M\models\varepsilon(a,b).\]

Require this relation to be reflexive, symmetric and transitive on \(D\), and require \(D\ne\varnothing\). No equivalence condition is imposed on tuples outside \(D\). The quotient domain is \(Q=D/{\sim}\), with its specified projection \(q(a)=[a]\). It is nonempty, \(q\) is surjective, and

\[q(a)=q(b)\quad\Longleftrightarrow\quad a\sim b.\]

These are the ordinary quotient-set facts. Equality of classes, rather than coordinatewise equality of their representatives, will be the logical equality of the interpreted structure.

A function needs one output class, not one output tuple

As for tuple interpretations, use the guarded graph \(\widehat\gamma_f(\bar x,y)=\delta(y)\land\gamma_f(\bar x,y)\). For each selected input tuple \(a\in D^n\), require a guarded output and uniqueness modulo represented equality:

\[\exists y\in D\;M\models\gamma_f(a,y),\qquad M\models\gamma_f(a,y)\land\gamma_f(a,z)\Longrightarrow y\sim z\quad(y,z\in D).\]

The congruence conditions say that old relations and function graphs are invariant on equivalent selected representatives. Whenever \(a_i\sim b_i\) for every input coordinate and \(y\sim z\), require

\[M\models\rho_R(a)\iff M\models\rho_R(b),\qquad M\models\gamma_f(a,y)\iff M\models\gamma_f(b,z).\]

A datum is quotient-good in \(M\) when these conditions and the preceding nonemptiness and equivalence conditions hold. Each input and output in a congruence test is selected. Constants use the empty input tuple: they need a nonempty graph whose outputs all represent one class. Nullary relation invariance imposes no extra restriction.

The formulas define actual operations and relations on classes

Suppose the datum is quotient-good in \(M\). There is a specified interpreted structure on \(Q\), defined by

\[f^Q(q(a_0),\ldots,q(a_{n-1}))=q(y)\quad\text{if }M\models\gamma_f(a,y),\]
\[R^Q(q(a_0),\ldots,q(a_{n-1}))\quad\Longleftrightarrow\quad M\models\rho_R(a).\]

Both rules are independent of all representatives and graph-output choices.

For fixed selected inputs, totality supplies an output and uniqueness modulo \(\sim\) gives one output class. If \(a_i\sim b_i\), graph invariance with the same output \(y\) transfers its graph assertion to the inputs \(b\), using reflexivity at \(y\). Any output \(z\) at \(b\) is therefore equivalent to \(y\) by uniqueness at \(b\). The output class is unchanged. Relation invariance proves the corresponding representative independence for \(R\). Surjectivity of \(q\) supplies representative input tuples for every finite tuple of classes, including the empty tuple. The quotient-map criterion now gives the operations and relations asserted above. Nonemptiness of \(D\) gives nonemptiness of \(Q\).

Temporary choices on representatives do not change the quotient

Choose one guarded output \(F_f(a)\in D\) for each symbol and selected input tuple. On \(D\), interpret each function by this chosen output, each old relation by \(\rho_R\), and the new relation \(E\) by \(\sim\). Call this the representative structure \(N\). It satisfies the equality congruence axioms, and their quotient construction is exactly the specified structure \(Q\).

The first three axioms are the assumed equivalence laws. For equivalent input tuples, the argument in shows \(F_f(a)\sim F_f(b)\), giving function congruence. Relation congruence is an assumed invariant-truth equivalence. The equality-axiom quotient thus uses \([F_f(a)]\) and \(\rho_R(a)\), which are exactly the rules just proved independent of choices. In particular

\[t^Q[q\circ v]=q(t^N[v])\]

for every actual \(L\)-term \(t\) and selected assignment \(v\). This follows by term induction from the function rule, or from the established quotient term and truth argument. Choosing functions on representatives is an auxiliary construction; it is not a claim that their coordinate outputs were unique.

Translate logical equality before expanding coordinate blocks

Let \(A^E\) be the existing native equality translation: replace each source equality atom \(s=t\) by \(E(s,t)\), and retain its free names, protected slots, functions and other constructors. It has no logical equality atoms. Define the quotient translation by

\[A^I=(A^E)^J,\]

using the actual coordinate-block recurrence for \(J\). If \(G_t\) is that recurrence's term graph, an equality atom is consequently translated as

\[(s=t)^I=\exists\bar u\,\exists\bar v\;(G_s(\bar u)\land G_t(\bar v)\land\varepsilon(\bar u,\bar v)).\]

The displayed formula abbreviates the corresponding disjoint intermediate blocks and finite conjunction. A variable term graph still equates its output coordinates with that variable's coordinates. Logical equality between source objects, however, is tested by \(\varepsilon\) after finding term representatives. Universal quantification uses \(\forall\bar y(\delta(\bar y)\to\cdots)\), with precisely the last-placeholder block rebinding. All these are ordinary native formulas; no semantic truth predicate is used to define the translation.

Term graphs have outputs, and every output has the right class

Under quotient-goodness, let \(v\) be a selected assignment, and evaluate an \(L^E\)-term \(t\) in the representative structure \(N\). Its specified coordinate term graph has at least one selected output. Every ambient tuple \(y\) satisfying that graph is selected and obeys

\[y\sim t^N[v],\qquad q(y)=q(t^N[v]).\]

This is existence plus agreement modulo represented equality. It does not assert that every representative of that class satisfies the graph, or that the graph has one tuple output.

Induct on the term, retaining arbitrary proposed output tuples for the second assertion. A variable graph has exactly the supplied tuple as output, so existence and reflexive agreement hold. For \(f(t_0,\ldots,t_{n-1})\), choose graph outputs \(b_i\) for the children by induction. They are selected, and each is equivalent to the corresponding child value in \(N\). Totality supplies a graph output at the tuple \(b\); these child outputs and that output witness the composite term graph.

Conversely any witnesses to the composite graph give selected child outputs equivalent to their actual child values. Graph invariance transfers the final graph assertion to those actual values, leaving its selected output \(y\) unchanged. The chosen representative value \(F_f\) is another output at those inputs. Uniqueness modulo \(\sim\) therefore relates \(y\) to the chosen function value. The output guard proves that \(y\) is selected. Constants have no child witnesses and use the same totality and uniqueness argument. The quotient projection gives the displayed class equality. When the term is an original \(L\)-term, viewed in \(L^E\) through the unchanged function symbols, the quotient term identity in also identifies this class with \(t^Q[q\circ v]\).

Invariant atoms allow the block translation despite nonunique outputs

Assume quotient-goodness. For every equality-free native \(L^E\)-formula \(B\), with any selected free and protected-slot assignments,

\[N\models B[v]\quad\Longleftrightarrow\quad M\models B^J[v^\flat].\]

Here \(v^\flat\) lists all coordinates of those assignments. The equality-free restriction concerns logical equality atoms, and permits the relation symbol \(E\).

At an old relation atom, translated term graphs have outputs by . Any such outputs are equivalent to the actual term values; relation invariance makes their \(\rho_R\)-truth agree with its truth at those values. Thus the existential block of graph witnesses is equivalent to the original relation assertion. For an \(E\)-atom use the same argument and the equivalence laws: replacing either argument by an equivalent one preserves whether the two are equivalent. There is no logical-equality case, precisely because of the hypothesis on \(B\).

Falsity and implication use their ordinary truth clauses and the induction hypotheses. In a universal clause, an ambient tuple is admitted exactly when it satisfies \(\delta\). Such a tuple is exactly an element of \(D\); appending its coordinates to the free-coordinate context agrees with appending it as the last protected source slot. The specified rebinding map leaves all older coordinates fixed. The induction hypothesis therefore identifies all the tests on both sides. This proves the assertion with every protected slot retained. It is a new invariant-atom argument, not an invocation of the ordinary tuple truth theorem, whose unique-tuple hypothesis need not hold.

The specified translation preserves truth in the quotient

If the datum is quotient-good in \(M\), then for every actual scoped \(L\)-formula \(A\), every free assignment \(v\) into \(D\), and every available-slot assignment \(w\) into \(D\),

\[Q\models A[q\circ v,q\circ w]\quad\Longleftrightarrow\quad M\models A^I[v^\flat,w^\flat].\]

The same statement holds for complete formulas and sentences. Every assignment of quotient classes has representatives, so the equivalence describes all quotient assignments.

The actual scoped quotient truth theorem, applied to the representative structure's equality congruence axioms, identifies the left side with \(N\models A^E[v,w]\). The formula \(A^E\) is equality-free in the required sense. Apply to identify this with the right side, by the definition of \(A^I\). Both bridges retain the original formula and assignments.

In particular, equality of term values is equality of their quotient classes, exactly the \(\varepsilon\)-test in its translated atom. For quantified class assignments, surjectivity of \(q\) gives a representative at each newly quantified slot. For a whole free assignment, choose one representative for each assigned class. If two representative assignments project to the same class assignment, the left side is unchanged; hence their translated truth values agree as well. No claim of equivalence for arbitrary unselected coordinate assignments is needed.

The required congruence tests are first-order sentences

The datum's side-condition sentences are the nonemptiness sentence and the universal closures of all its equivalence, graph-totality, output-uniqueness and congruence conditions. Every tested tuple receives its domain guard. For example, output uniqueness is the closure of

\[\left(\bigwedge_{i<n}\delta(\bar x_i)\land\widehat\gamma_f(\bar x,\bar y)\land\widehat\gamma_f(\bar x,\bar z)\right)\to\varepsilon(\bar y,\bar z).\]

For graph invariance, universally quantify two input lists and two output blocks, assume all their domain guards, the inputwise \(\varepsilon\)-tests and the output \(\varepsilon\)-test, and conclude the biconditional between the two graph formulas. For relation invariance omit the output blocks. Equivalence uses one, two or three guarded blocks for reflexivity, symmetry or transitivity. Totality universally quantifies selected input blocks and existentially quantifies a guarded output block. All blocks are finite, so these instructions use only native formula constructors and the established finite-block closure operations.

A datum is admissible over a \(K\)-theory \(S\) when the native first-order calculus derives every side-condition sentence from \(S\). Unfolding ordinary satisfaction of these guarded closures shows that they hold in a structure exactly when the datum is quotient-good there. This connects the syntactic requirements to the conditions used in the truth theorem.

Quotient interpretations transfer models and native consequences

The datum quotient-interprets \(T\) in \(S\) when it is admissible over \(S\) and \(S\vdash\sigma^I\) for every axiom \(\sigma\in T\).

Every nonempty \(S\)-model then supplies a nonempty quotient \(T\)-model. For every \(L\)-sentence \(\sigma\),

\[T\vdash\sigma\quad\Longrightarrow\quad S\vdash\sigma^I.\]

Soundness makes all derived side conditions true in an \(S\)-model, so the datum is quotient-good. The translated axioms are true there as well. The sentence case of makes their original axioms true in the interpreted quotient. That quotient is nonempty, proving the model assertion.

If \(T\vdash\sigma\), soundness gives its truth in this quotient model. Quotient truth gives the translated sentence in the arbitrary \(S\)-model. The native completeness theorem then supplies a derivation \(S\vdash\sigma^I\). This is existence of a native derivation, not a specified effective proof-code transformation. Since falsity translates to falsity, consistency of \(S\) implies consistency of \(T\).

Discarding a redundant coordinate recovers the ambient structure

Let \(K\) have a unary function \(s\) and unary relation \(p\), and let \(L\) have one unary function \(f\) and one unary relation \(P\). In dimension two select all pairs and define

\[\varepsilon((a,b),(c,e))\equiv a=c,\qquad\gamma_f((a,b),(u,v))\equiv u=s(a),\qquad\rho_P(a,b)\equiv p(a).\]

In every nonempty \(K\)-structure this is quotient-good. The specified map \(q(a,b)\mapsto a\) is an isomorphism from its interpreted quotient to the structure on \(M\) with function \(s\) and predicate \(p\). Its inverse sends \(a\) to \(q(a,a)\).

Equality of first coordinates is an equivalence relation. At input \((a,b)\), the output \((s(a),b)\) proves totality. Any two outputs have first coordinate \(s(a)\), proving uniqueness modulo represented equality. Equivalent input and output representatives have the same first coordinates, so both graph and relation formulas are invariant.

The proposed map is well-defined because equivalent pairs have the same first coordinate. Its proposed inverse has that coordinate, and every \((a,b)\) is equivalent to \((a,a)\), proving both inverse identities. The graph forces the first coordinate of the output to be \(s(a)\), and the relation tests exactly \(p(a)\), proving preservation of both symbols. Thus the native translated sentence \(\forall x\,P(f(x))\) holds exactly when \(p(s(a))\) holds for every \(a\in M\), by and this specified isomorphism.

Why does ordinary tuple uniqueness ask too much?

In the redundant-coordinate example, assume \(M\) has distinct elements \(b,c\). Does its function graph have a unique actual tuple output at each input? Could logical equality in the quotient be translated using coordinate equality instead of \(\varepsilon\)?

No to both claims. At any input \((a,e)\), the tuples \((s(a),b)\) and \((s(a),c)\) are distinct outputs. Their first coordinates agree, so they represent the same required output class. The graph therefore fails the ordinary unique-tuple condition while satisfying the quotient conditions.

Likewise \((a,b)\) and \((a,c)\) are distinct tuples with equal quotient classes. Under an assignment sending two source variables to that class, their equality atom is true. Coordinate equality of the chosen representatives would be false. Translating the atom by \(\varepsilon\), after its term graphs, is exactly what keeps the original class equality true. An arbitrary equivalence relation also needs the stated symbol congruences: equivalent representatives may otherwise give different relation truth values.
