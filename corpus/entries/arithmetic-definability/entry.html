A formula can describe a set without deciding it

Fix the standard arithmetic structure \(\mathbb N_A=(\mathbb N,0,S,+,\cdot)\). An arithmetic formula \(A(x)\) defines a set \(X\subseteq\mathbb N\) in this structure if, for every \(n\in\mathbb N\),

\[n\in X\quad\Longleftrightarrow\quad\mathbb N_A\models A(n).\]

The same convention defines relations with any fixed finite number of arguments. Numerical constants can be written as numerals, so allowing finitely many fixed natural-number parameters does not change which sets are definable. The formula uses only arithmetic symbols; names for programs, lists or computable functions must be replaced by arithmetic formulas describing them.

This asks about truth in one specified structure. Representing a relation in Robinson arithmetic asks for proofs of its positive and negative numeral instances. Those are different requirements. We will identify exactly the sets whose membership has an arithmetic description consisting of an unbounded search followed by a finite check.

A bounded formula has a terminating truth test

For every fixed bounded arithmetic formula \(D(\bar x)\), its truth relation \(\mathbb N_A\models D(\bar x)\) is primitive recursive. Both strict and inclusive bounds are allowed, and their bounding terms do not contain the variable being quantified.

Evaluate terms by their finite construction from zero, successor, addition and multiplication. Their values are primitive-recursive functions of the input tuple. Equality and the order abbreviations can then be checked by primitive-recursive comparisons. Boolean connectives combine these tests by Boolean operations.

For \(\forall u\lt t(\bar x)\,E(\bar x,u)\), first evaluate the bound \(b=t(\bar x)\). Run the test for \(E\) at each of \(0,\ldots,b-1\), keeping a Boolean conjunction. Existential quantification keeps a disjunction instead. These are precisely the bounded quantifier operations. Inclusive bounds use the loop of length \(b+1\). At a strict zero bound, the conjunction is true and the disjunction false. Induction on the fixed formula completes the construction.

The algorithm is specific to the given formula. This lemma supplies a terminating test for each bounded relation, without asserting a single primitive-recursive interpreter for arbitrary formula codes.

Count the unbounded quantifier blocks

A \(\Sigma_1\) formula has the form \(\exists u_0\cdots\exists u_{r-1}D(\bar x,\bar u)\), where \(D\) is bounded. A \(\Pi_1\) formula has the corresponding form \(\forall u_0\cdots\forall u_{r-1}D(\bar x,\bar u)\). Empty prefixes are allowed. The bounded quantifiers inside \(D\) are not counted as unbounded blocks.

A relation is \(\Sigma_1\)-definable if some formula of the first form defines it in \(\mathbb N_A\); define \(\Pi_1\)-definable similarly. A relation is \(\Delta_1\)-definable if it is both \(\Sigma_1\)-definable and \(\Pi_1\)-definable. The two witnessing formulas may be different: their standard interpretations, rather than their strings of symbols, must agree.

Superscripted notation \(\Sigma^0_1,\Pi^0_1,\Delta^0_1\) is also common. The superscript distinguishes this hierarchy of arithmetic definitions from hierarchies in which sets or functions are themselves quantified over.

An existential bounded description can be recognized

Every \(\Sigma_1\)-definable set is computably enumerable.

For \(A(x)=\exists\bar u\,D(x,\bar u)\), enumerate the finite tuples \(\bar u\) using the existing effective finite-sequence coding. Reject codes of the wrong length, and apply the bounded truth test to each decoded tuple. Accept \(x\) as soon as a successful tuple appears. Every genuine witness tuple has a code, so the search accepts exactly the members of the set. An empty witness tuple also has a code, covering a prefix of length zero.

This is a partial recursive search for a finite certificate. It need not terminate on inputs outside the set, which is permitted in the certificate characterization of enumerability.

Collect the witnesses needed by a finite history

Let \(\delta(\bar x,i,u)\) be bounded. Write \(B(c,d,i,u)\) for the bounded remainder-decoding formula. In the standard natural numbers,

\[\forall i\lt n\;\exists u\,\delta(\bar x,i,u)\]

is equivalent to

\[\exists c,d\;\forall i\lt n\;\exists u\le c\;\bigl(B(c,d,i,u)\land\delta(\bar x,i,u)\bigr).\]

The formula after \(\exists c,d\) is bounded. Thus a bounded universal quantifier over existential bounded assertions can still be expressed with one existential block followed by a bounded matrix. The same holds for a fixed finite tuple of witnesses at each index.

Choose one witness for each of the finitely many indices \(i\lt n\). The finite sequence coding lemma supplies \(c,d\) whose remainders are exactly those witnesses. A remainder of \(c\) is at most \(c\), so the displayed bounded existential quantifier can recover it. Conversely the right-hand formula directly supplies a witness for each index. When \(n=0\), both universal assertions are empty, and any \(c,d\) suffice.

For several witness coordinates, use one pair of codes per coordinate. This is still a fixed finite collection of outer existential variables. The only remaining quantifiers run below \(n\), below one of the codes, or below terms in the bounded decoder. No sequence length or code is being added as a new arithmetic function symbol.

Primitive-recursive graphs have existential bounded formulas

Every primitive-recursive function \(f:\mathbb N^k\to\mathbb N\) has a \(\Sigma_1\) graph formula \(G_f(\bar x,y)\) such that

\[\mathbb N_A\models G_f(\bar a,b)\quad\Longleftrightarrow\quad f(\bar a)=b.\]

Consequently every primitive-recursive relation is \(\Sigma_1\)-definable.

Induct on the primitive-recursive construction. Zero, successor and projections have bounded equality graphs. For a composition, existentially name the intermediate outputs, conjoin their graph formulas with the outer graph formula, and move their existential prefixes to the front after choosing distinct witness variables. Conjunction introduces no new unbounded universal quantifier.

For primitive recursion, suppose \(h(\bar x,0)=f(\bar x)\) and \(h(\bar x,i+1)=g(\bar x,i,h(\bar x,i))\). Existentially choose \(c,d\) coding the history of length \(n+1\). Require that its first entry satisfies \(G_f\), that for every \(i\lt n\) the adjacent entries satisfy \(G_g\), and that its last entry equals \(y\). Entries are recovered by the bounded formula \(B\), with recovered values bounded by \(c\).

The ingredient graph formulas may themselves have existential witnesses. At the initial and final conditions these simply join the outer prefix. In the step condition they vary with \(i\); collect those finite witness lists into further remainder codes. What remains after the outer existential block is bounded. A true computation supplies the history and all witnesses. Conversely induction through the decoded finite history, using the defining equations of \(h\), forces its \(i\)-th value to be \(h(\bar x,i)\). Its last value is therefore exactly the proposed output.

Finally apply the graph construction to the primitive-recursive characteristic function of a relation and substitute the numeral \(1\) for its output. Term substitution preserves boundedness and the existential-prefix form. This proves the relation claim.

This argument concerns finite sequences of ordinary natural numbers. It does not require a theorem about the existence of coded histories inside arbitrary models of arithmetic.

Enumerable membership is exactly existential bounded definability

For every \(X\subseteq\mathbb N\),

\[X\text{ is computably enumerable}\quad\Longleftrightarrow\quad X\text{ is }\Sigma_1\text{-definable in }\mathbb N_A.\]

The same equivalence holds for relations of any fixed finite arity.

The reverse implication is witness search. For the forward implication, the primitive-recursive certificate theorem gives a primitive-recursive relation \(R(x,t)\) such that \(x\in X\) exactly when \(\exists t\,R(x,t)\). By the graph construction, write \(R(x,t)\) as \(\exists\bar w\,D(x,t,\bar w)\) with bounded \(D\). Then \(\exists t\,\exists\bar w\,D(x,t,\bar w)\) defines \(X\) and is already in the required form.

For several free inputs, use their effective tuple code when applying the certificate theorem, and then the primitive-recursive certificate relation on that tuple. The resulting arithmetic formula retains the individual input variables.

Partial computations are described by their successful outputs

For a partial function \(f:\mathbb N\rightharpoonup\mathbb N\), the following are equivalent: \(f\) is partial recursive; its graph is computably enumerable; its graph is \(\Sigma_1\)-definable. If it is partial recursive, its domain is also \(\Sigma_1\)-definable.

Choose an index \(e\) for \(f\) in the existing universal evaluator. The primitive-recursive bounded evaluator gives

\[f(x)\mathbin\downarrow=y\quad\Longleftrightarrow\quad\exists k\;b(k,e,x)=y+1.\]

The extra one distinguishes a successful output of zero from failure to finish within the allowance. The right-hand side is a primitive-recursive certificate relation with an existential witness, so the graph is enumerable. The main theorem makes it \(\Sigma_1\)-definable.

Conversely, if the graph is enumerable, on input \(x\) search its finite certificates over all pairs consisting of a proposed output \(y\) and a certificate. Return the first certified output. If \(f(x)\) is defined, its certificate eventually appears. If it is undefined, none appears. Since this is the graph of a partial function, all certified outputs at a fixed input agree. This constructs a partial recursive function with exactly the given graph.

If \(G(x,y)\) is an existential bounded graph formula, then \(\exists y\,G(x,y)\) is again existential bounded and defines the domain. No totality is asserted. In particular, \(\neg\exists y\,G(x,y)\) expresses divergence, rather than assigning an artificial output.

Universal definitions and two-sided decisions

A set is co-computably enumerable, meaning that its complement is enumerable, exactly when it is \(\Pi_1\)-definable. Moreover,

\[X\text{ is decidable}\quad\Longleftrightarrow\quad X\text{ is }\Delta_1\text{-definable in }\mathbb N_A.\]

Negating \(\exists\bar u\,D(x,\bar u)\) gives the equivalent \(\forall\bar u\,\neg D(x,\bar u)\). The negated matrix is still bounded. The same argument in reverse converts the complement of a \(\Pi_1\)-defined set into a \(\Sigma_1\)-defined set. Apply the main equivalence to the complement.

A decidable set and its complement are both enumerable, so it has both kinds of definition. Conversely, a \(\Sigma_1\) definition provides a search accepting members, and the negation of a \(\Pi_1\) definition provides a search accepting nonmembers. Run the two searches in parallel. Exactly one must succeed, and its side supplies the answer. This is the existing two-sided recognition theorem.

A short arithmetic description need not decide membership

Let \(K=\{e:\varphi_e(e)\mathbin\downarrow\}\), using the diagonal halting set. It is enumerable and undecidable, so it is \(\Sigma_1\)-definable. Its complement is \(\Pi_1\)-definable.

Moreover, \(K\) is not \(\Pi_1\)-definable and its complement is not \(\Sigma_1\)-definable.

The set \(K\) cannot also be \(\Pi_1\)-definable: then it would be \(\Delta_1\)-definable, and the decision theorem would make it decidable. Similarly its complement cannot be \(\Sigma_1\)-definable. Thus the two kinds of description already differ at the first level.

A \(\Pi_1\) sentence is true when all its bounded tests succeed. A failed test provides a finite counterexample; truth need not have a finite certificate that can be found by a terminating search.

Does a pair of definitions give a provable equivalence?

Suppose a \(\Sigma_1\) formula \(A(x)\) and a \(\Pi_1\) formula \(B(x)\) define the same set. Does our definition of \(\Delta_1\)-definability require \(Q\vdash\forall x(A(x)\leftrightarrow B(x))\)?

No. It requires agreement for every ordinary natural number in \(\mathbb N_A\). Provability of their universal equivalence in \(Q\), or in PA, is a separate stronger requirement on those particular formulas. The decision proof uses their standard agreement to ensure that one of the two searches eventually succeeds; it does not claim that arithmetic proves this termination assertion. Likewise \(\Delta_1\) is a class of relations with two definitions, rather than a demand that one literal formula have both prefix shapes.

More alternations of unbounded quantifiers

The same notation continues. At level zero, both prefix classes consist of bounded formulas. A \(\Sigma_{r+1}\) prefix is a finite existential block followed by a \(\Pi_r\) prefix; a \(\Pi_{r+1}\) prefix starts with a finite universal block followed by a \(\Sigma_r\) prefix. Thus a \(\Sigma_2\) formula has the pattern \(\exists\bar u\,\forall\bar v\,D\), and a \(\Pi_2\) formula has the pattern \(\forall\bar u\,\exists\bar v\,D\), with bounded \(D\).

A relation belongs to the corresponding definability class when some formula with that prefix pattern defines it in \(\mathbb N_A\). Blocks may be empty. These patterns specify forms of definition; seeing an alternation in one displayed formula does not prove that its relation lacks a simpler definition. No assertion about strictness at later levels is needed here.

Totality asks for a witness separately at every input

The graph of the universal partial function \((e,x)\mapsto\varphi_e(x)\) is \(\Sigma_1\)-definable. Write a graph definition as \(\exists\bar w\,D(e,x,y,\bar w)\), where \(D\) is bounded. Then the indices of total programs have the \(\Pi_2\) definition

\[\forall x\;\exists y,\bar w\;D(e,x,y,\bar w).\]

For each fixed input \(x\), an output \(y\) and graph witnesses exist exactly when \(\varphi_e(x)\) is defined. Quantifying this condition over all inputs is precisely totality. Combining \(y\) with the finite graph-witness tuple leaves one existential block after the universal input block, with bounded matrix.

The witnesses may depend on \(x\). The definition asks for an output and a successful finite computation at each input, not for one bound on the running times of all inputs. This illustrates what an additional unbounded quantifier block says. We have not classified its optimal complexity or proved a general hierarchy theorem.

The totality index set is undecidable. Its displayed quantifier form alone does not prove that no decision procedure exists.
