One answer or finitely many possible answers

Fix a nonempty \(L\)-structure \(M\) and a parameter set \(A\subseteq M\). Recall that an \(A\)-definable set is defined by a first-order formula using a finite tuple of parameters from \(A\). All closures in this entry are taken inside this specified \(M\).

An element \(b\in M\) is definable over \(A\) if the singleton \(\{b\}\) is \(A\)-definable. It is algebraic over \(A\) if it belongs to some finite \(A\)-definable subset of \(M\). Define the definable closure and algebraic closure by

\[\operatorname{dcl}_M(A)=\{b\in M:\{b\}\text{ is }A\text{-definable}\},\]
\[\operatorname{acl}_M(A)=\{b\in M:b\text{ belongs to a finite }A\text{-definable set}\}.\]

Equivalently, choose a formula \(\varphi(x,\bar y)\) and a finite tuple \(\bar a\) from \(A\). Definability of \(b\) asks that \(\varphi(M,\bar a)=\{b\}\); algebraicity asks that this solution set be finite and contain \(b\). Language constants are already available, even when \(A=\varnothing\). The word “algebraic” here does not assume that \(M\) is a field.

Enlarging the parameter set and using only finitely many parameters

For all \(A,B\subseteq M\),

\[A\subseteq\operatorname{dcl}_M(A)\subseteq\operatorname{acl}_M(A).\]

If \(A\subseteq B\), then \(\operatorname{dcl}_M(A)\subseteq\operatorname{dcl}_M(B)\) and \(\operatorname{acl}_M(A)\subseteq\operatorname{acl}_M(B)\). Each membership has finite character: an element belongs to either closure of \(A\) if and only if it belongs to the same closure of some finite subset \(A_0\subseteq A\).

For \(a\in A\), the formula \(x=a\) defines \(\{a\}\), and a singleton is finite. A formula using parameters from \(A\) also uses parameters from \(B\) when \(A\subseteq B\), proving monotonicity. Finally every defining formula uses only finitely many parameter values. Collect them into \(A_0\); its solution set is unchanged. The reverse finite-character implication is monotonicity.

Can a finite choice fail to determine a point?

Let \(M\) have exactly two elements and only equality in its language. Determine \(\operatorname{dcl}_M(\varnothing)\) and \(\operatorname{acl}_M(\varnothing)\).

The formula \(x=x\) defines all of \(M\), a finite set, so \(\operatorname{acl}_M(\varnothing)=M\). The permutation interchanging the two points is an automorphism. A parameter-free definable singleton would be preserved by it, contradicting automorphism invariance. Neither singleton is definable, so \(\operatorname{dcl}_M(\varnothing)=\varnothing\). Thus definable and algebraic closure can differ even in a finite structure.

Eliminate parameters that already have unique definitions

If \(B\subseteq\operatorname{dcl}_M(A)\), every \(B\)-definable subset of a finite power of \(M\) is \(A\)-definable.

Let the set be defined by \(\varphi(\bar x,b_0,\ldots,b_{n-1})\). For each \(i<n\), choose an \(A\)-formula \(\psi_i(y_i,\bar a_i)\) whose unique solution is \(b_i\). Combine the finitely many parameter lists \(\bar a_i\) into one finite list from \(A\), and rename bound variables to keep all displayed variables free and distinct. Then the original set is defined by

\[\exists y_0\cdots\exists y_{n-1}\;\left(\bigwedge_{i<n}\psi_i(y_i,\bar a_i)\land\varphi(\bar x,\bar y)\right).\]

The tuple \(\bar b\) witnesses the forward direction. In the reverse direction, uniqueness forces every chosen \(y_i\) to equal \(b_i\). This is a first-order formula with parameters only from \(A\). For \(n=0\), the conjunction is \(\top\), and the quantifier block is empty. The construction uses the Boolean closure and projection rules for definability.

Say inside a formula that a fiber has bounded size

For a fixed natural number \(m\) and formula \(\varphi(x,\bar y)\), the at-most-\(m\)-solutions formula is

\[B_m\varphi(\bar y)=\exists z_0\cdots\exists z_{m-1}\,\forall x\;\left(\varphi(x,\bar y)\to\bigvee_{j<m}x=z_j\right).\]

Its truth at \(\bar c\) means exactly that \(\varphi(M,\bar c)\) has at most \(m\) elements. Bound names are chosen fresh, so this construction retains the free tuple \(\bar y\).

If the formula holds, its finitely many witnesses cover the solution set. Conversely, enumerate that finite set and, when it has fewer than \(m\) elements, fill the remaining slots with any point of the nonempty domain. For \(m=0\), there are no witnesses and the disjunction is \(\bot\); the formula says that the solution set is empty.

Taking either closure twice adds nothing

For every \(A\subseteq M\),

\[\operatorname{dcl}_M(\operatorname{dcl}_M(A))=\operatorname{dcl}_M(A),\qquad \operatorname{acl}_M(\operatorname{acl}_M(A))=\operatorname{acl}_M(A).\]

Extensivity gives one inclusion in each equality. If a singleton is definable over \(\operatorname{dcl}_M(A)\), gives its definition over \(A\). This proves the other inclusion for definable closure.

For algebraic closure, let \(c\in\operatorname{acl}_M(\operatorname{acl}_M(A))\). Choose \(\varphi(x,\bar b)\) with a finite solution set containing \(c\), where every \(b_i\in\operatorname{acl}_M(A)\). Let \(m\) be the size of this particular solution set. For each \(i<n\), choose an \(A\)-formula \(\psi_i(y_i,\bar a_i)\) with finite solution set containing \(b_i\).

Only finitely many tuples \(\bar y\) satisfy all the \(\psi_i\): they belong to a finite product of finite sets. Some such tuples might make \(\varphi(M,\bar y)\) infinite. Exclude them by the first-order size condition from . Put

\[\Delta(\bar y)=\bigwedge_{i<n}\psi_i(y_i,\bar a_i)\land B_m\varphi(\bar y),\qquad \chi(x)=\exists\bar y\;(\Delta(\bar y)\land\varphi(x,\bar y)).\]

The formula \(\chi\) uses only the combined finite parameter list from \(A\). Its solution set is contained in a union, over finitely many candidate tuples, of sets with at most \(m\) elements. It is therefore finite. The original tuple \(\bar b\) satisfies \(\Delta\), so \(\chi(c)\) holds. Thus \(c\in\operatorname{acl}_M(A)\). Empty parameter tuples give one candidate, the empty tuple, and the same proof applies.

For models of a strongly minimal theory, algebraic closure also satisfies exchange. Together with these closure laws, this gives a pregeometry and a well-defined dimension for finitely generated closed sets.

Closures contain constants and are closed under the language functions

Both \(\operatorname{dcl}_M(A)\) and \(\operatorname{acl}_M(A)\) contain the interpretations of all language constants and are closed under every language function. They are therefore function-closed carriers in \(M\). When a carrier is nonempty, its induced structure is an \(L\)-substructure of \(M\). An empty closure is allowed as carrier data; it is not a nonempty model.

For an \(n\)-ary function symbol \(f\) and tuple \(\bar b\), the formula \(x=f(b_0,\ldots,b_{n-1})\) uniquely defines the output over the input tuple. If all inputs belong to \(\operatorname{dcl}_M(A)\), this output belongs to \(\operatorname{dcl}_M(\operatorname{dcl}_M(A))=\operatorname{dcl}_M(A)\). If all inputs belong to \(\operatorname{acl}_M(A)\), the output belongs to \(\operatorname{dcl}_M(\operatorname{acl}_M(A))\subseteq\operatorname{acl}_M(\operatorname{acl}_M(A))=\operatorname{acl}_M(A)\). Here monotonicity allows the finite input tuple as parameters, and the equalities are idempotence. For \(n=0\), the tuple is empty and the same argument covers every constant symbol.

For stronger finiteness conclusions under countable categoricity, see closures of finite parameter sets.

Elementary maps preserve an entire finite solution set

Let \(f:M\to N\) be an elementary embedding. If \(S=\varphi(M,\bar a)\) is finite, then

\[\varphi(N,f(\bar a))=f[S].\]

Enumerate \(S=\{b_0,\ldots,b_{m-1}\}\). In \(M\), the formula

\[\forall x\;\left(\varphi(x,\bar a)\leftrightarrow\bigvee_{j<m}x=b_j\right)\]

is true. Regard \(\bar a,\bar b\) as its finite free parameter tuple before evaluating it. Elementarity transfers this same formula to \(N\), with parameters \(f(\bar a),f(\bar b)\). Its truth says exactly that the displayed solution set in \(N\) is \(\{f(b_0),\ldots,f(b_{m-1})\}\). This also handles \(m=0\): an empty solution set cannot gain a witness under an elementary embedding.

Closures agree along an elementary embedding

For every elementary embedding \(f:M\to N\) and every \(A\subseteq M\),

\[f[\operatorname{dcl}_M(A)]=\operatorname{dcl}_N(f[A]),\qquad f[\operatorname{acl}_M(A)]=\operatorname{acl}_N(f[A]).\]

If \(b\) belongs to either closure in \(M\), take its defining singleton or finite solution set over a finite tuple from \(A\). By , the same formula with transported parameters defines exactly its image in \(N\). The image is again a singleton or a finite set, respectively. This proves both forward inclusions.

Conversely, suppose \(c\in\operatorname{acl}_N(f[A])\). Choose a finite solution set \(S_N=\varphi(N,f(\bar a))\) containing \(c\), lifting its finitely many parameters to a tuple \(\bar a\) from \(A\). Elementarity gives \(f[S_M]\subseteq S_N\), where \(S_M=\varphi(M,\bar a)\). Injectivity of \(f\) makes \(S_M\) finite. The preceding lemma now gives \(S_N=f[S_M]\), so \(c=f(b)\) for some \(b\in S_M\subseteq\operatorname{acl}_M(A)\). If \(S_N=\{c\}\), then \(S_M\) is a singleton as well, because its image is that nonempty singleton and \(f\) is injective. This proves the reverse definable-closure inclusion too.

Symmetries preserve closures and fix uniquely defined points

For every automorphism \(g\) of \(M\),

\[g[\operatorname{dcl}_M(A)]=\operatorname{dcl}_M(g[A]),\qquad g[\operatorname{acl}_M(A)]=\operatorname{acl}_M(g[A]).\]

If \(g\) fixes \(A\) pointwise, it fixes every element of \(\operatorname{dcl}_M(A)\) pointwise and preserves \(\operatorname{acl}_M(A)\) as a set.

An isomorphism is elementary, so the image equalities follow from . When \(g\) fixes \(A\), we have \(g[A]=A\), giving preservation of both closures as sets. For the stronger pointwise assertion, take an \(A\)-definable singleton \(\{b\}\). Definability makes this singleton invariant under \(g\), so \(g(b)=b\).

The converse characterizations hold in countable omega-saturated models over finite parameter sets: singleton orbits characterize definable closure, and finite orbits characterize algebraic closure.

Equality and dense order add no points to the parameters

For an infinite equality structure \(M\), and for a nonempty dense linear order without endpoints in the strict-order language, every \(A\subseteq M\) satisfies

\[\operatorname{dcl}_M(A)=\operatorname{acl}_M(A)=A.\]

Consider first an infinite equality structure, and a finite \(A\)-definable set \(S\). Its formula uses a finite parameter set \(A_0\subseteq A\). If \(b\in S\setminus A_0\), choose \(d\) outside the finite set \(S\cup A_0\), using infinitude. The permutation swapping \(b,d\) and fixing every other point is an automorphism of the equality structure fixing \(A_0\). Invariance of \(S\) would give \(d\in S\), a contradiction. Hence \(S\subseteq A_0\subseteq A\).

In a dense linear order, quantifier elimination describes an \(A\)-definable set as a finite union of points from \(A\) and open intervals or rays with endpoints, when finite, in \(A\). Every nonempty interval or ray contains infinitely many points. For a bounded interval, density repeatedly inserts another point before its upper endpoint; for a ray, use density together with the missing-endpoint condition. Thus a finite definable set can receive no point from a nonempty interval or ray, and all its points belong to \(A\).

In either case, every finite \(A\)-definable set is contained in \(A\), so \(\operatorname{acl}_M(A)\subseteq A\). The inclusions in then give both equalities. In particular, both closures of \(\varnothing\) are empty in these languages. The infinitude hypothesis for equality is essential, as shows.
