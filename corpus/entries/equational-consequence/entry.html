An identity must hold at every assignment

Suppose a binary operation satisfies \(f(x,y)=x\). Replacing \(x\) by \(f(u,v)\) suggests \(f(f(u,v),w)=f(u,v)\), and hence \(f(f(u,v),w)=u\). Which rules justify such deductions, and do they derive every equation forced by the original laws?

Fix a functional signature \(L\): for each finite arity \(k\), a set of \(k\)-ary function symbols. Constants are the symbols of arity zero. Use the fixed variable set \(X=\{x_0,x_1,\ldots\}\), identified with \(\mathbb N\), and the finite terms \(\operatorname{Term}_L(X)\). An identity is an ordered pair of terms, written \(s\approx t\). Let \(\Sigma\) be any set of identities; it need not be finite.

An algebra is a nonempty set \(A\) interpreting every \(k\)-ary symbol \(f\) by a function \(f^A:A^k\to A\). Write \(\llbracket t\rrbracket^A_v\) for the value of a term at a valuation \(v:X\to A\). We say \(A\models s\approx t\) if these values are equal for every valuation. Write \(A\models\Sigma\) if this holds for every member of \(\Sigma\), and write \(\Sigma\models s\approx t\) if every nonempty algebra satisfying \(\Sigma\) satisfies that identity. There are no relation symbols or quantified formulas in this calculus; the universal quantification over variables is part of what “identity” means.

Substitution changes the valuation

A substitution is a map \(\sigma:X\to\operatorname{Term}_L(X)\). Its simultaneous action \(t[\sigma]\) replaces each variable by its assigned term, once, and retains function symbols. For every algebra and valuation,

\[\llbracket t[\sigma]\rrbracket^A_v=\llbracket t\rrbracket^A_{v_\sigma},\qquad v_\sigma(x)=\llbracket\sigma(x)\rrbracket^A_v.\]

This is the term substitution identity. At a variable both sides are the value of its replacement. At a function application, evaluation first evaluates its arguments; applying the induction hypotheses to those finitely many arguments proves equality. For a constant the tuple of arguments is empty.

Consequently, if an identity holds under every valuation in \(A\), all its substitution instances do too. A substitution need not fix variables absent from the displayed identity, and its images can contain any of our variables.

Six rules produce finite equational proofs

A derivation from \(\Sigma\) is a finite tree formed by the following rules. Its conclusion is denoted \(\Sigma\vdash s\approx t\).

  • Axiom: infer \(s\approx t\) when \((s,t)\in\Sigma\).
  • Reflexivity: infer \(t\approx t\) for any term \(t\).
  • Symmetry: from \(s\approx t\), infer \(t\approx s\).
  • Transitivity: from \(r\approx s\) and \(s\approx t\), infer \(r\approx t\).
  • Congruence: from \(s_i\approx t_i\) for every \(i<k\), infer the following identity, for each \(k\)-ary symbol \(f\):
    \[f(s_0,\ldots,s_{k-1})\approx f(t_0,\ldots,t_{k-1}).\]
  • Substitution: from \(s\approx t\), infer its instance under any substitution \(\sigma\):
    \[s[\sigma]\approx t[\sigma].\]

Congruence at arity zero has no premises and yields the reflexive equation for that constant. Every rule has finitely many premises because every arity is finite. No rule cancels a function symbol: equality of \(f(s)\) and \(f(t)\) need not imply equality of \(s\) and \(t\).

Derive a nested projection law

In a signature with one binary symbol \(f\), let \(\Sigma=\{f(x_0,x_1)\approx x_0\}\). Derive \(f(f(x_0,x_1),x_2)\approx x_0\). Explain which occurrence of an axiom is instantiated.

Show answerHide answer

Start with the axiom and use the substitution sending \(x_0\) to \(f(x_0,x_1)\), \(x_1\) to \(x_2\), and every other variable to itself. Simultaneous replacement gives

\[f(f(x_0,x_1),x_2)\approx f(x_0,x_1).\]

The replacement inside the new image of \(x_0\) is not performed again. A second use of the original axiom gives \(f(x_0,x_1)\approx x_0\). Transitivity yields the required conclusion. The new equation uses the old law with a compound term in its first argument.

Every derivable identity holds in every model

For every set of identities \(\Sigma\), if \(\Sigma\vdash s\approx t\), then \(\Sigma\models s\approx t\).

Fix an arbitrary nonempty algebra \(A\models\Sigma\). Induct on the finite derivation, proving that each conclusion holds at every valuation. An axiom holds because \(A\models\Sigma\). Reflexivity, symmetry and transitivity follow from the corresponding properties of equality in \(A\). In a congruence inference, fix a valuation; the induction hypotheses make the corresponding argument values equal, so applying the same function \(f^A\) gives equal outputs.

For substitution, the induction hypothesis says that \(s\) and \(t\) have equal values under every valuation, including the valuation \(v_\sigma\) from . That identity makes the values of \(s[\sigma]\) and \(t[\sigma]\) equal at the arbitrary original valuation \(v\). This covers all six rules and every model.

Derivability is the least substitution-invariant congruence

Define \(s\sim_\Sigma t\) to mean \(\Sigma\vdash s\approx t\). A congruence on terms is an equivalence relation preserved by every function application. It is substitution-invariant if \(s\sim t\) implies \(s[\sigma]\sim t[\sigma]\) for every substitution. The relation \(\sim_\Sigma\) is the least such congruence containing every pair in \(\Sigma\).

Reflexivity, symmetry and transitivity are rules of the calculus, so \(\sim_\Sigma\) is an equivalence relation. The congruence rule gives compatibility with each operation, the substitution rule gives substitution invariance, and the axiom rule includes \(\Sigma\).

Now let \(R\) be any substitution-invariant congruence containing \(\Sigma\). Induction on a derivation proves that its endpoint terms are \(R\)-related. The axiom case uses containment, the three equality rules use equivalence, the congruence case uses compatibility, and the last case uses substitution invariance. Thus \(\sim_\Sigma\subseteq R\), proving leastness. This is a syntactic construction from the rules, without using semantic completeness.

The restricted congruence closure for ground constraints instead operates on a finite retained set of closed terms. Here all variable-containing terms and all substitution instances are present; the present theorem makes no claim that this infinite closure is decidable.

Take derivable equality classes of terms

The term quotient algebra is \(Q_\Sigma=\operatorname{Term}_L(X)/{\sim_\Sigma}\). Denote the class of \(t\) by \([t]\). Its carrier is nonempty: \([x_0]\) exists even when the signature has no constants. By the defining property of a quotient,

\[[s]=[t]\quad\Longleftrightarrow\quad\Sigma\vdash s\approx t.\]

Interpret each \(k\)-ary function symbol by

\[f^{Q_\Sigma}([t_0],\ldots,[t_{k-1}])=[f(t_0,\ldots,t_{k-1})].\]

This is well-defined: choosing another representative \(u_i\) of each input gives \(\Sigma\vdash t_i\approx u_i\), and the congruence rule identifies the two output terms. For a constant the formula simply gives its term class. This is the quotient construction for compatible operations, now applied to a relation generated by proofs. It defines all operations on the entire carrier, with no default values needed.

Evaluating a term returns its substituted class

Given a substitution \(\sigma\), let \(v_\sigma(x)=[\sigma(x)]\) in \(Q_\Sigma\). Then for every term \(t\),

\[\llbracket t\rrbracket^{Q_\Sigma}_{v_\sigma}=[t[\sigma]].\]

In particular, the canonical valuation \(\eta(x)=[x]\) satisfies \(\llbracket t\rrbracket^{Q_\Sigma}_\eta=[t]\).

Induct on \(t\). For a variable the equation is the definition of \(v_\sigma\). At \(f(t_0,\ldots,t_{k-1})\), the induction hypotheses give the argument values \([t_i[\sigma]]\). The definition of the quotient operation returns \([f(t_0[\sigma],\ldots,t_{k-1}[\sigma])]\), which is the class of the substituted application. The same argument includes zero-arity applications. The identity substitution gives the canonical assertion by the identity law for substitution.

The quotient satisfies the axioms under every valuation

The nonempty algebra \(Q_\Sigma\) satisfies every identity in \(\Sigma\).

Fix an axiom \((s,t)\in\Sigma\) and an arbitrary valuation \(v:X\to Q_\Sigma\). Each value is a term class. Choose representatives \(\sigma(x)\) with \([\sigma(x)]=v(x)\) for all variables. This uses an ordinary choice of representatives; it does not require constants in the signature. The selected terms form a substitution.

The axiom rule gives \(\Sigma\vdash s\approx t\), and substitution gives \(\Sigma\vdash s[\sigma]\approx t[\sigma]\). Hence their quotient classes are equal. By , these classes are exactly the values of \(s\) and \(t\) at \(v\). Since the axiom and valuation were arbitrary, \(Q_\Sigma\models\Sigma\). Checking only the canonical valuation would not establish this assertion about every valuation.

Every nonderivable identity has a term countermodel

For every \(\Sigma,s,t\),

\[\Sigma\vdash s\approx t\quad\Longleftrightarrow\quad\Sigma\models s\approx t.\]

More explicitly, if \(\Sigma\nvdash s\approx t\), the nonempty algebra \(Q_\Sigma\models\Sigma\) falsifies \(s\approx t\) at its canonical valuation.

Soundness proves the forward implication. For the reverse, suppose the identity is not derivable. The quotient criterion in gives \([s]\ne[t]\). Canonical evaluation identifies these two classes with the values of \(s\) and \(t\). Thus this valuation falsifies the identity, while shows that the quotient satisfies every premise. It follows that \(\Sigma\not\models s\approx t\). Taking the contrapositive proves completeness.

The construction needs no bound on the number of function symbols or axioms. The countably infinite stock of variables provides a nonempty term carrier and includes every finite term we used; it is not a countability assumption on the signature or on the resulting algebra.

Every consequence uses finitely many axioms

If \(\Sigma\vdash s\approx t\), there is a finite set \(\Sigma_0\subseteq\Sigma\) with \(\Sigma_0\vdash s\approx t\). Consequently,

\[\Sigma\models s\approx t\quad\Longleftrightarrow\quad\Sigma_0\models s\approx t\text{ for some finite }\Sigma_0\subseteq\Sigma.\]

First observe monotonicity: a derivation from \(\Gamma\) is still a derivation from any larger premise set, by retaining the whole tree and using inclusion at each axiom leaf. Now induct on a derivation from \(\Sigma\). An axiom leaf uses its singleton premise set; reflexivity uses the empty set. Symmetry and substitution retain the finite set given for their single premise. Transitivity uses the union of the two finite premise sets. A congruence inference uses the union of the finitely many finite sets for its argument derivations, one for each \(i<k\). Each premise can be derived from this union by monotonicity, so the same rule gives the conclusion there. At arity zero this union is empty.

For semantic consequence, completeness supplies a derivation and the first assertion reduces its premises to \(\Sigma_0\); soundness gives the finite semantic consequence. Conversely, every model of \(\Sigma\) is a model of its subset \(\Sigma_0\). This finite-premise result follows from the equational calculus itself; no separate compactness theorem is needed.

Does the projection axiom force its arguments to agree?

For the binary signature and \(\Sigma=\{f(x_0,x_1)\approx x_0\}\), can one derive \(f(x_0,x_1)\approx x_1\)?

Show answerHide answer

No. On \(A=\{0,1\}\), interpret \(f^A(a,b)=a\). The given axiom holds under every valuation, since the value of its left side is always the first argument. At a valuation with \(v(x_0)=0\) and \(v(x_1)=1\), the proposed conclusion has values \(0\) and \(1\), which are distinct. This is a nonempty countermodel, so soundness excludes a derivation.

The same model also shows that the original axiom does not force \(x_0\approx x_1\). Identities can describe a noninjective operation without identifying all elements of its domain.

Why is truth at one valuation insufficient for substitution?

Can an equation be true at a valuation while a substitution instance is false at that same valuation?

Show answerHide answer

Yes. Use the empty signature and the nonempty carrier \(\{0,1\}\). Let \(v(x_2)=1\) and let \(v(x_j)=0\) for every \(j\ne2\). The terms \(x_0,x_1\) have the same value. Take a substitution sending \(x_0\) to \(x_2\) and fixing all other variables. Its instance \(x_2\approx x_1\) has different values at \(v\).

The semantic substitution identity still holds: the original equation is now evaluated at the changed valuation \(v_\sigma\), where its two sides differ. Substitution preserves an identity valid at every valuation because that changed valuation is included. It need not preserve a coincidence at one chosen assignment. Also distinguish this question from syntactic unification, which asks for identical substituted term trees rather than equality of values forced by a set of identities.
