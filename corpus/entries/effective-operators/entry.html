Order partial functions by the observations they preserve

A partial numerical function \(f:\mathbb N\rightharpoonup\mathbb N\) may be undefined at some inputs. Write \(f(x)\downarrow=y\) for a defined value and use the existing graph inclusion \(f\sqsubseteq g\): every defined value of \(f\) is the same defined value of \(g\). The functions considered here need not be computable.

Keep exactly the earlier finite-fragment coding. A valid code \(d\) records a consistent finite list \(D_d\) of input–output pairs and denotes the partial function \(\delta_d\) defined precisely on that table. Its specified primitive-recursive compiler \(u(d)\) satisfies \(\varphi_{u(d)}\simeq\delta_d\). Repeated identical pairs are allowed. The empty table denotes the nowhere-defined function.

Compatible tables have a common finite extension

Call two valid fragments compatible if they never assign different outputs to the same input. They are compatible exactly when their decoded lists can be concatenated to form a consistent table. In that case there is a valid fragment extending both, and hence a partial computable function extending both.

If the concatenated table is consistent, any pair from the first table and any pair from the second agree when their inputs agree. Conversely, consistency within each table and compatibility between the tables check every pair in the concatenation. Its associated partial function therefore extends both original tables. Code the concatenation and apply the fragment compiler. In particular, two fragments included in one arbitrary partial function are compatible, since that function has only one output at each input. The argument also covers either table being empty.

Give one enumerable family of finite positive rules

A positive rule relation is a jointly c.e. relation \(R(d,x,y)\) on three natural numbers such that every rule has a valid fragment code \(d\). Its meaning is: the observations in \(D_d\) suffice to produce output \(y\) at input \(x\). Joint enumerability means that the single set

\[\{\langle d,\langle x,y\rangle\rangle:R(d,x,y)\}\]

is c.e.; separately choosing a recognizer for each pair \(x,y\) would not supply this condition. The relation is coherent when

\[R(d,x,y)\text{ and }R(c,x,z)\text{ and }d,c\text{ compatible}\quad\Longrightarrow\quad y=z.\]

The input \(x\) must be the same in this condition. Rules for different inputs may give different outputs.

A rule succeeds whenever the supplied function contains its evidence

For a coherent positive rule relation \(R\), define its finite-information operator \(\Phi_R\) on all partial numerical functions by

\[\Phi_R(f)(x)\downarrow=y\quad\Longleftrightarrow\quad\exists d\;[\delta_d\sqsubseteq f\text{ and }R(d,x,y)].\]

When no rule has its evidence included in \(f\), the value at \(x\) is undefined. An effective operator here means an operator represented by some coherent jointly c.e. positive rule relation. This definition gives a mathematical action even on noncomputable \(f\); it does not assert that an ordinary program receives such a function as a finite input.

Coherence makes every resulting output single-valued

For every coherent positive rule relation \(R\), every partial function \(f\) and input \(x\), the rule for \(\Phi_R(f)(x)\) gives at most one output. An empty rule relation gives the nowhere-defined output function for every \(f\).

If two rules produce \(y\) and \(z\), their evidence fragments are both included in \(f\), so they are compatible by . Coherence gives \(y=z\). Thus the displayed relation is the graph of a partial function. If there are no rules, the existential condition never holds. Coherence cannot be omitted: two rules with empty evidence, the same input and different outputs would otherwise give two values at that input.

Defined outputs persist under extension and already occur on finite evidence

Every effective operator is monotone for graph inclusion: \(f\sqsubseteq g\) implies \(\Phi_R(f)\sqsubseteq\Phi_R(g)\). Moreover, for arbitrary \(f,x,y\),

\[\Phi_R(f)(x)\downarrow=y\quad\Longleftrightarrow\quad\exists d\;[\operatorname{Valid}(d),\ \delta_d\sqsubseteq f,\ \Phi_R(\delta_d)(x)\downarrow=y].\]

A rule whose finite evidence is included in \(f\) remains applicable in any extension \(g\), proving monotonicity. For the forward implication of the displayed equivalence, take the fragment from a successful rule. It is valid by the rule-relation assumption and, being included in itself, already triggers that rule on \(\delta_d\). Conversely, a value obtained on \(\delta_d\sqsubseteq f\) persists by monotonicity. This is finite positive evidence: no divergence at an unlisted input is certified.

Finite positive evidence also gives preservation of increasing unions. Starting an effective endofunction with no defined answers and repeatedly applying it yields a computable least fixed point, with leastness even among noncomputable solutions.

The same idea of finite positive evidence gives enumeration operators on sets. Their outputs are sets, so different outputs on compatible evidence cause no conflict and no single-valued coherence condition is needed. Their rule indices admit an explicit uniform composition by combining finite input witnesses.

Compile one ordinary search from the rule index and the input-program index

Fix an ordinary index \(r\) enumerating the coded rule relation \(R\). The joint rule search \(V(r,e,x)\) searches natural codes of quadruples \((d,y,s,t)\) in increasing code order. It accepts a candidate when

\[\operatorname{Valid}(d),\qquad \langle d,\langle x,y\rangle\rangle\in W_{r,s},\qquad \operatorname{Match}(e,d,t).\]

Here \(W_{r,s}\) is the existing finite stage, and the finite match test certifies every recorded output of \(D_d\) in \(\varphi_e\). At the first successful code the search returns its \(y\); if none succeeds, it remains undefined. It does not run one possibly divergent input computation before considering the next.

Every candidate test terminates. One fixed ordinary program \(v\), chosen before \(r,e,x\) vary, therefore computes this joint partial-recursive procedure on input \(\langle r,\langle e,x\rangle\rangle\). Define the operator compiler

\[q(r,e)=s(s(v,r),e),\qquad \varphi_{q(r,e)}(x)\simeq V(r,e,x).\]

The actual specialization map makes \(q\) primitive recursive jointly in \(r,e\). Forming this program index does not require the search to halt.

The compiled program computes exactly the operator on the indexed partial function

If \(r\) enumerates a coherent positive rule relation \(R\), then for every \(e,x\),

\[\varphi_{q(r,e)}(x)\simeq\Phi_R(\varphi_e)(x).\]

The same \(q(r,e)\) works on every runtime input \(x\), including inputs where the operator is undefined.

A successful candidate supplies an actual rule \(R(d,x,y)\) and a finite match. The match theorem gives \(\delta_d\sqsubseteq\varphi_e\), so the returned value is an output of \(\Phi_R(\varphi_e)(x)\). Conversely, if this operator has output \(y\), choose its successful fragment \(d\). The rule appears in some stage \(s\), and the finitely many required computations have a common match bound \(t\). The search eventually reaches the corresponding quadruple. An earlier successful quadruple might have different evidence, but coherence forces its returned value to be the same \(y\). If the operator has no value, the first implication rules out every successful candidate, so the program diverges. This establishes equality of entire partial functions, rather than only equality on their halting inputs.

Require a numerical transformation to respect computed behavior

A total computable map \(H:\mathbb N\to\mathbb N\) is an extensional index transformation when

\[\varphi_e\simeq\varphi_b\quad\Longrightarrow\quad\varphi_{H(e)}\simeq\varphi_{H(b)}.\]

Thus its action on programs determines an action on partial computable functions. The outputs \(H(e)\) and \(H(b)\) need not be equal as numbers. The operator compiler above is such a transformation for each coherent rule index \(r\): if two input programs compute the same function, gives the same output function.

Each specified output gives an extensional enumerable index property

For a total computable extensional \(H\), put \(A_{x,y}=\{e:\varphi_{H(e)}(x)\downarrow=y\}\). This property is c.e. and extensional for every \(x,y\), and its recognition is jointly effective in \(e,x,y\).

Compute \(H(e)\), then search bounded computation certificates for its output \(y\) at \(x\). Equivalently, membership means that some bounded evaluator value is \(y+1\). This is a search through total computable tests, jointly in the three variables. If \(\varphi_e\simeq\varphi_b\), extensionality of \(H\) makes their transformed programs agree at \(x\), so either both produce \(y\) or neither does. The statement concerns successful outputs and does not require either transformed program to be total.

Use a single canonical rule relation instead of separately chosen bases

For total computable extensional \(H\), define its canonical rule relation by

\[R_H(d,x,y)\quad\Longleftrightarrow\quad\operatorname{Valid}(d)\text{ and }\varphi_{H(u(d))}(x)\downarrow=y.\]

This is one jointly c.e. relation: validity is decidable, \(u\) is primitive recursive, \(H\) is total computable, and universal evaluation recognizes the displayed output.

More explicitly, if an ordinary index \(a\) computes \(H\), a canonical-rule recognizer remains undefined on an invalid \(d\). Otherwise it computes \(\varphi_a(u(d))\), runs the returned program at \(x\), and halts exactly when its output equals \(y\), remaining undefined on a different output. One fixed program \(w\) implements this procedure on \(\langle a,\langle d,\langle x,y\rangle\rangle\rangle\). Its primitive-recursive index map \(r(a)=s(w,a)\) enumerates precisely \(R_H\). The same recognizer construction is defined for every numerical \(a\), even when that index does not compute a total extensional transformation. Coherence is asserted only under the stated hypotheses on \(H\).

Rice–Shapiro makes the canonical rules coherent

For every total computable extensional \(H\), the canonical relation \(R_H\) is coherent. For all \(e,x,y\), it also satisfies

\[\varphi_{H(e)}(x)\downarrow=y\quad\Longleftrightarrow\quad\exists d\;[\delta_d\sqsubseteq\varphi_e\text{ and }R_H(d,x,y)].\]

Fix \(x,y\). The canonical Rice–Shapiro basis for \(A_{x,y}\) is exactly the set of valid \(d\) for which \(u(d)\in A_{x,y}\), which is \(R_H(d,x,y)\). Its basis equivalence gives the displayed assertion. Although this argument fixes \(x,y\) to invoke Rice–Shapiro, the preceding construction already supplied one joint rule recognizer before those variables varied.

To prove coherence, suppose compatible \(d,c\) give rules with the same input \(x\) and outputs \(y,z\). Their common finite extension has some fragment code \(b\). Since \(\delta_d\sqsubseteq\delta_b\), the upward-closure theorem applied to \(A_{x,y}\) transfers the output from the fragment index \(u(d)\) to \(u(b)\). The rule at \(c\) similarly forces the transformed program at \(u(b)\) to output \(z\). A partial function has only one output at \(x\), so \(y=z\). The common extension was finite and therefore computable; no index of a noncomputable function was used.

The canonical operator agrees with the transformation on every computable argument

Let \(H\) be total computable and extensional. Its canonical rules define an effective operator on every partial function and satisfy

\[\Phi_{R_H}(\varphi_e)\simeq\varphi_{H(e)}\qquad(e\in\mathbb N).\]

If \(a\) computes \(H\), the specified primitive-recursive composite \(G(a,e)=q(r(a),e)\) therefore satisfies \(\varphi_{G(a,e)}\simeq\varphi_{H(e)}\) for every \(e\).

Joint enumerability and coherence have been proved for \(R_H\). The operator definition and the output equivalence in identify every defined output on \(\varphi_e\), in both directions. They also identify undefined inputs, since neither side can have an output unless the other does. Finally apply using the actual rule recognizer \(r(a)\). Both index constructors are primitive recursive and fixed before \(e\) or its runtime input varies, so their composite has the stated uniformity.

Agreement on finite functions determines the whole finite-information operator

If two effective operators \(\Phi_R,\Phi_S\) agree on every valid finite fragment \(\delta_d\), then they agree on every partial function, including all noncomputable ones. In particular, agreement on all partial computable functions suffices.

Suppose \(\Phi_R(f)(x)\downarrow=y\). By , some valid \(d\) with \(\delta_d\sqsubseteq f\) already gives \(\Phi_R(\delta_d)(x)\downarrow=y\). The assumed agreement gives the same value for \(\Phi_S(\delta_d)\), and monotonicity of \(\Phi_S\) gives it for \(\Phi_S(f)\). Interchange \(R,S\) for the reverse implication. Thus both operators have exactly the same defined outputs, and their undefined inputs agree too. Every finite fragment is partial computable, so agreement on all computable arguments includes the required finite cases.

Extensional program transformations are exactly effective finite-information operators

Every total computable extensional index transformation \(H\) has a unique effective operator extension \(\Phi\) to all partial numerical functions, satisfying \(\Phi(\varphi_e)\simeq\varphi_{H(e)}\) for every \(e\). Conversely, every effective operator has a specified primitive-recursive index transformation computing its action on all partial computable arguments. This is the Myhill–Shepherdson theorem in the finite-information representation.

The canonical operator supplies existence and its actual compiler by . Any other effective extension agrees with it on every \(\varphi_e\), so proves uniqueness on all partial functions. Conversely, a coherent rule index \(r\) gives the primitive-recursive transformation \(e\mapsto q(r,e)\), with its entire output function identified by ; it is extensional by . Uniqueness concerns the operator, not the rule relation or numerical program names used to describe it.

Precomposing with a computable input map gives positive finite rules

For any total computable \(k:\mathbb N\to\mathbb N\), the operator \(C_k(f)(x)\simeq f(k(x))\) is effective on arbitrary partial functions.

Use the rules \(R(d,x,y)\) saying that \(d\) is valid and its table contains \((k(x),y)\). This is a jointly decidable, hence c.e., relation. Compatible tables cannot give different values at \(k(x)\), proving coherence. A successful rule gives exactly the specified value of \(f(k(x))\); conversely that value supplies the singleton fragment \([(k(x),y)]\). No other input of \(f\) must be defined. The compiler consequently gives a program with the same strict partial behavior as this composition.

A positive rule can accept either of two successful observations

The operator \(P\) defined, for every \(x\), by

\[P(f)(x)\downarrow=0\quad\Longleftrightarrow\quad f(0)\downarrow\text{ or }f(1)\downarrow\]

is effective and has no other output values.

Take all valid tables containing a pair with first coordinate zero or one, and allow exactly output zero at every input \(x\). Finite table inspection decides these rules, and coherence holds because all their outputs are zero. A rule is applicable precisely when one of those two computations has a value; a singleton table suffices for the converse. On a computable argument the compiled rule search dovetails certificates rather than waiting for one chosen call to finish.

A sequential implementation that calls \(f(0)\) first would wait forever when \(f(0)\) is undefined but \(f(1)=0\). Reversing those two calls fails when only \(f(0)=0\) is defined. These examples explain why the positive-evidence interface must not be identified with either of those strict sequential implementations.

A negative answer about the whole graph is a different kind of information

Let \(G_f=\{\langle a,b\rangle:f(a)\downarrow=b\}\). The operator that returns zero on every input exactly when \(\langle0,0\rangle\notin G_f\), and is otherwise nowhere defined, is computable with a membership oracle for \(G_f\), but is not an effective operator in the positive-rule sense.

A membership-oracle program asks the one specified question; on a negative answer it returns zero, and on a positive answer it runs forever. The existing oracle instructions permit both answers to be used. For the nowhere-defined \(f\), the proposed operator returns zero. Extend \(f\) by the single observation \((0,0)\); now the operator returns no value. This violates the monotonicity required by , so no coherent positive rule relation represents it. A negative graph answer concerns absence, which finite positive tables do not assert.

Does the unique extension have a unique rule relation?

The Myhill–Shepherdson extension is unique. Must two coherent positive rule relations representing it be equal?

Show answerHide answer

No. Let \(d_\varnothing\) code the empty table. The relation consisting of the single rule \(R(d_\varnothing,0,0)\) always returns zero at input zero and is undefined at every other input. Add the distinct rule \(R(c,0,0)\), where \(c\) codes \([(0,7)]\). The added evidence can never produce a new output: the empty-evidence rule already applies to every partial function. Both finite rule relations are jointly c.e. and coherent, but they are different relations representing the same operator.

The uniqueness theorem identifies partial output functions on all arguments. It does not identify their descriptions, just as equal partial computable functions may have different program indices.
