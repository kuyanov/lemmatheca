# A sumset is at least as large as either summand

Let \(A\) and \(B\) be finite nonempty subsets of an additive abelian group.
Then

\[
|A+B|\geq\max\{|A|,|B|\}.
\]

The idea is to find a translated copy of each summand inside the sumset.
Translation moves a set without merging any of its elements.

Both nonemptiness assumptions matter. If \(A=\varnothing\) and
\(B=\{0\}\), then \(A+B=\varnothing\), so the displayed inequality fails.
